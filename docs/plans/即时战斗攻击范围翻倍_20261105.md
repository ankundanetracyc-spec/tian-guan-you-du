# 即时战斗攻击范围翻倍

> 2026-11-05状态：历史实验，已停止作为现行方案。用户要求恢复原回合制战斗及相关面板，见[恢复原回合制战斗与面板_20261105](恢复原回合制战斗与面板_20261105.md)。下文保留此前阶段事实与参数，不再授权即时迁移或覆盖原队列技能、属性、心法与化法规则。

2026-11-05，现行调整入口。用户要求当前所有技能范围增加一倍，随后明确只翻倍攻击范围，错步位移不改；架招没有防御距离，只判断防御期间自身正面的来袭伤害。

本案覆盖所列即时动作规则的旧攻击长度，不覆盖旧队列格距，不恢复暂缓的剑式动作制作，不将舒卷图谱标成已实装。

## 规则与范围

- 攻击的地面距离、半径与判定宽度乘2；属性成长系数和距离硬上限同乘2，得到每个属性档位都恰为原先两倍的范围。扇形角度保持，实际面积不按两倍解释。
- 玩家与敌人共用同一范围来源；真实命中、范围提示与特效使用相同最终范围，不只放大画面。
- 伤害、命中、会心、费用、CD、出手／连段时序、攻击层高度和资源／状态触发保持。拳掌0费仍受动作互斥、整套CD和最低CD限制，无返费、抽牌、额外行动或新增资源。
- 错步、拳掌贴步、剑式前压、云岚前压和血浪击退属于位移或控制距离，不乘2；相关化法百分比保持原值。
- 架招不设防御半径或对攻击者的距离上限，只在自身受击时按正面来向判定。已确认的持续架招3秒／180°／共享化解额度仍以独立主案为准，原演练尚未迁移，不借本轮范围调整冒称完成。

## 化法与衍生边界

百骸第四卷拳掌距离化法仍乘1.25，主修血气额外延伸仍乘1.15；均在各自已经翻倍的基础长度上作用一次。血气不对已经翻倍的本体再乘2，血浪独立读取440。血浪仍按浪头实际扫过判伤，每道每敌最多一次；起始波前6变12，使全程半径曲线同倍变化。24单位／0.12秒击退保持。

舒卷剑式前压化法仍使6／14变9／21，错步距离化法仍使100变120，均不把位移当作本轮攻击长度。剑意上限10、心法9层／主修8层门槛、连击增伤与化法比例保持。
