# 跨境界状态与净化系统规划

> 状态：规则定稿，待接入卡牌与战斗结算。

## 一、目标

本系统服务于带有境界差的行动条战斗，解决以下问题：

1. 低境界角色不应依靠稳定叠加 DOT 或减益耗死高境界角色；
2. 高境界卡牌应有比低境界卡牌更稳定的状态施加能力；
3. 百分比团队增益可以存在，但低境界队友不能把高境界角色异常放大；
4. DOT、控制和减益流必须有明确、可预期的净化反制；
5. 普通驱散不得清空高境界角色的心法与整套核心构筑。

系统以少量统一规则完成上述目标：状态只在施加时判定一次；净化和驱散为确定性结算；高低境界差主要影响状态能否挂上，而不在状态持续期间反复追加随机或衰减规则。

## 二、状态施加判定

### 2.1 基本原则

- 所有会施加状态的卡牌，都只在状态施加时判定一次。
- 判定成功后，状态完全按卡牌和状态资源写明的层数、持续时间与结算时机运行。
- 不做维持判定、每跳判定、自动衰减或额外的跨境界削层。
- 给自身施加正面状态时必中。
- 对敌方施加减益、对队友施加正面状态时，均须进行一次状态判定。
- 最终成功率统一限制在 `1%—99%`。

### 2.2 每张状态牌的公式

每个 `status_effect` 直接保存自己的命中公式；不同毒、火、控制、标记和辅助牌可以使用不同属性关系。

通用表达为：

```text
成功率 =
基础概率
+ 施法者属性 × 施法系数
- 目标属性 × 抵抗系数
+ 卡牌境界修正
- 跨境界修正
```

其中“目标属性”并不总是负项。给队友施加增益时，可使用目标神魂、灵慧等作为正项，表示其接引、承载或配合术法的能力。

示例：

```text
中毒：45% + 施法者灵慧 × 2% - 目标体魄 × 1.5% + 卡牌境界修正 - 跨境界修正
定身：35% + 施法者神魂 × 2.5% - 目标身心协调值 × 2% + 卡牌境界修正 - 跨境界修正
护持队友：70% + 施法者神魂 × 2% + 目标神魂 × 1% + 卡牌境界修正 - 跨境界修正
```

卡牌可按自己的定位调整基础概率与各属性系数；不设全局万能抗性属性。

### 2.3 卡牌境界修正

高境界卡牌代表更成熟的术式，因此提供额外的状态施加稳定度。初版使用固定修正：

| 卡牌所属境界 | 修正 |
|---|---:|
| 凡俗 | 0% |
| 云息 | +10% |
| 玄基 | +20% |
| 金丹 | +30% |
| 神胎 | +40% |

卡牌境界不足时不可使用。越阶使用不是本系统的基础规则；若未来需要，应作为独立的高风险玩法设计，不能直接获得完整高境界修正。

### 2.4 跨境界修正

跨境界修正只按大境界计算：

| 施法者相对目标 | 修正 |
|---|---:|
| 同大境界 | 0% |
| 低一大境界 | -20% |
| 低两大境界 | -40% |
| 高一大境界 | +10% |
| 高两大境界 | +20% |

该修正进入单次施加判定，不改变已经挂上的状态。低境界仍可偶尔影响高境界目标，但无法稳定建立长期 DOT 或减益循环。

## 三、正面状态与团队辅助

### 3.1 自身、队友与境界限制

- 施法者给自身施加正面状态：必中。
- 施法者给同境界或更低境界队友施加正面状态：进行一次该牌的状态判定。
- 若受益者比施法者高至少一个大境界：不能获得该施法者施加的正面状态。
- 上述限制只针对正面状态；直接治疗、物品交付及不产生状态实例的效果不受此规则限制。

这条规则直接阻止低境界辅助角色对高境界主力提供增伤、减伤、护盾、加速等状态，保留同境界协作与高境界护持低境界队友的空间。

### 3.2 百分比增益

百分比增益是可用且必要的团队辅助手段。

- 外源百分比增益不设置“同组取最高值”或全局叠加限制。
- 是否可叠加、如何叠加、最大层数及持续时间，完全由具体状态与卡牌配置决定。
- 设计每张百分比增益牌时，必须明确其作用对象、层数上限、持续时间与叠加方式。
- 对高境界受益者的主要限制只使用第 3.1 节的境界门槛，不再额外压低其已允许获得的外源 Buff 数值。

## 四、DOT 与减益流

### 4.1 DOT 的构成

DOT 可以同时拥有固定伤害与百分比伤害；两部分都由该状态资源或施加卡牌明确配置。

```text
每次 DOT 伤害 = 固定伤害部分 + 目标最大生命 × 百分比伤害部分
```

- 固定伤害部分可随施法者属性、卡牌效果或状态层数变化。
- 百分比伤害部分直接按牌面定义，必须写清“每层”或“总计”的关系。
- DOT 是否可叠层、同名状态是刷新还是加层、每层的伤害变化，均由状态资源明确写出。

### 4.2 结算时机

DOT 不设统一的强制结算时机。中毒、灼烧、蚀魂、流血等状态可各自写明：

- 目标行动开始；
- 目标行动结束；
- 施法者行动开始或结束；
- 受到指定事件后；
- 固定帧或固定时间间隔。

结算时机是流派差异的一部分，不由跨境界规则改写。跨境界平衡主要依赖施加判定，而不是改动已施加 DOT 的跳数或节奏。

### 4.3 DOT 的边界

- DOT 不因境界差自动缩短、削层或失效。
- DOT 是否触发会心、是否吃增伤、是否被护盾或防御吸收，必须由状态类型和伤害结算规则明确，不能隐式沿用普通攻击规则。
- 高境界目标面对低境界 DOT 的主要安全性来自更难被施加，而不是一旦挂上就被系统额外豁免。

## 五、净化与驱散

### 5.1 设计原则

- 净化与驱散不进行概率判定，均为确定性结算。
- 不做万能全清；每张牌处理什么类别、能处理到什么位阶、能移除多少层，必须明确写在牌面上。
- 净化处理己方减益；驱散处理敌方正面状态。
- 心法、法宝、阵法、血脉和天赋等根基状态，不被普通净化或普通驱散处理。

### 5.2 状态最小分类

首批状态仅使用四类可净化减益：

| 类别 | 典型内容 |
|---|---|
| 毒 | 中毒、蚀毒、腐化类 DOT |
| 火 | 灼烧、焚身类 DOT |
| 形 | 定身、迟滞、减速、肉身限制 |
| 魂 | 心神压制、魂伤、识海限制 |

后续按流派和境界需要再加入气、诅咒、法宝、阵法等类别；首批不预设这些复杂分支。

### 5.3 状态的净化/驱散字段

每个状态增加或维护以下信息：

| 字段 | 说明 |
|---|---|
| 类别 | 毒、火、形、魂等；可为一个或两个类别 |
| 位阶 | 凡俗、云息、玄基等 |
| 当前层数 | 净化可按层数部分处理 |
| 可净化 | 是否可被己方净化处理 |
| 可驱散 | 是否可被敌方驱散处理 |
| 根基状态 | 是否排除在普通净化/驱散外 |

### 5.4 净化规则

净化牌需要写明：可处理类别、最高可处理位阶、移除层数。

```text
解毒散：选择己方一名角色的一项毒类状态；若其位阶不高于云息，移除 2 层。
清火符：选择己方一名角色的一项火类状态；若其位阶不高于云息，移除全部层数。
定神诀：选择己方一名角色的一项魂类状态；若其位阶不高于云息，移除 1 层。
```

- 玩家先选择目标单位，再选择该单位头顶的指定状态；不随机选择，不按隐藏优先级误清。
- 多层 DOT 可被部分净化，因此 DOT 流可通过叠层形成持续资源压力；净化方也需要付出相应卡牌、费用和行动。
- 净化牌的位阶必须不低于目标状态的位阶；低阶净化无法处理高阶异常。

### 5.5 驱散规则

驱散牌需要写明：可驱散的正面状态范围、最高可处理位阶、移除层数。

首批普通驱散仅处理：

- 护盾、化解、身法等临时战术防御；
- 短时增伤、减伤、加速；
- 队友施加的外源 Buff；
- 短时姿态。

普通驱散不得处理：

- 心法；
- 本命或持续法宝；
- 阵法核心；
- 血脉与妖兽天赋；
- 已完成的蓄势成果；
- 明确写为根基状态的专属构筑核心。

破功、夺器、破阵等能够处理根基状态的机制，留待对应高境界流派单独设计，不能作为前期通用驱散。

## 六、首批实现范围

1. 为状态实例和状态定义补充类别、位阶、可净化、可驱散、根基状态等字段；
2. 为每张会施加状态的卡牌配置独立公式，并在统一入口加入卡牌境界修正与跨境界修正；
3. 自身正面状态必中；低至少一个大境界的施法者不能给高境界受益者施加正面状态；
4. DOT 支持固定伤害和百分比伤害，以及卡牌/状态自定义结算时机；
5. 先实现毒、火、形、魂四类净化，以及移除一个临时正面状态的普通驱散；
6. 暂不实现万能全清、气类/诅咒类净化、破功、夺器、破阵与越阶用卡。
