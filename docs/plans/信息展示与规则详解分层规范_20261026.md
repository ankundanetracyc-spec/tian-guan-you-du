# 信息简略与详细显示规范

状态：2026-10-26用户最新确认，现行。本次覆盖此前“默认页不显示公式、draw.io公式仅放独立详解页”的约定。效果数值、目标、费用与规则计算不变。

## 游戏内两档显示

游戏设置新增“信息显示：简略／详细”，开始菜单与游戏内暂停菜单共用，切换立即生效并保存到通用游戏设置，不写入角色存档。未设置过该选项时默认详细；恢复默认也选详细。

- **简略版**：只显示效果结果，以及费用、目标、关键词、独有触发条件、次数、冷却和真实代价；不带公式或属性代入。
- **详细版**：在对应结果后紧接全角括号显示公式，例如“自身获得8层周流（体魄[10]×0.8 = 8）。”不另起“计算公式”标题，不把公式堆到效果末尾。
- 固定数值没有依赖计算时不凑公式；动态数值使用当前施术者的真实代入值。伤害继续称为预估伤害，不能称为目标最终承伤。
- 2026-10-28用户确认：所有人物属性数值的详细版必须展示完整代入计算过程，说明当前结果如何从基础值、倍率、固定加值及其他实际生效修正得出；派生属性同样代入当前数值，保留运算顺序和实际结果。悬停不显示四舍五入、向上／向下取整等底层处理用语，不因隐藏用语改变实际计算。只有基础值的简单样例不能代替有加成场景的验证。“18（基础值[8]×倍率[2]＋固定加值[2]＝18）”是格式示例，不是新境界或属性规则。简略版继续只显示结果。
- 结果依赖未来攻击、目标或状态时，说明何时确定，并在详细版保留其计算方式，不编造结果。
- 两档使用同一份详细源说明；切换不会把详细源覆盖成简略文字。已打开的悬停和已经创建的正文即时刷新，之后新开的信息栏同样遵守设置。
- 悬停公式不展开四舍五入、向上取整、向下取整等底层处理用语；保留算术项、必要分组与实际结算结果。其他仍需表达的函数使用可读中文，不直接显示max等代码函数名。正式策划的计算规则仍保留精确算法，悬停布局draw.io按玩家实际看到的公式展示；不改变数学结算。

## 通用结算说明与规则详解

“只计自身增伤、未计命中／会心／防御”等通用结算清单不因选择详细版而回到主栏；这些仍通过“规则详解 [F1]”主动查阅。详细版所增加的是对应效果的计算公式。

内部实例编号、资源路径、快照、兼容字段等实现信息不进入两档玩家正文。没有实际效果的配置说明不作为长段正文。必要触发条件、多段次数、风险与资源代价始终保留。

独立规则阅读面板可以滚动，有关闭入口；主悬停继续完整展开且无内部滚动条。规则阅读不执行技能、不扣物品、不改变队列，也不增加自动暂停。行囊单击只显示可用操作的规则保持。

## 覆盖范围

丹药通用悬停按[丹药定稿](技能与物品信息栏整理方案_20261025.md#丹药通用悬停定稿2026-10-26用户确认)展示丹阶、丹效、药效、丹毒和简介，每项一行；少数使用条件写入简介。无数量、评分、容器说明和规则详解入口；空简介占位，未配置档位不虚构。简略／详细公式切换及真实人物修正保持。

材料通用悬停另遵循[材料定稿](技能与物品信息栏整理方案_20261025.md#材料通用悬停定稿2026-10-26用户确认)：图标名称、品阶、五行、质地、相性、功用、简介；每个字段独占一行，简介为空也保留标签。不显示材料分类、数量、价格、贡献与领取来源，所有页面共用。

用户后续确认全部材料移除“规则详解”入口，F1也不打开材料规则页；简介为最后一块。材料两档的结果／括号公式切换保留，其他类型的规则阅读入口不受影响。

共用悬停覆盖技能栏、行动队列、状态、人物属性、行囊、交易、兑换、领取、地图等内容；人物技能库、秘籍、百科、旧卡牌正文和动态更新的详情同样适用。

只改变显示方式，不改任何伤害公式、状态机制、体力／法力／灵识规则、返费、资源生成、额外行动、射程或位移。

## 策划案与draw.io固定采用详细版

策划案和draw.io不随玩家设置切换，正式主稿均为详细版。静态图没有实际施术者，使用A、B等字母表示不同结果，在结果后以括号紧接符号公式；同一结果的引用继续对应同一公式，不代入虚构角色数值。

75份此前分层的相关draw.io已将97个公式节点恢复到默认主页面，并改为结果后括号公式；默认页不再使用“相应数值／层数”代替已有公式。独立规则详解页作为完整原参考保留，主稿阅读不再要求切页。

设计稿应保留真实效果、条件和公式；不把未实装提案描述成现行运行内容，不恢复旧三分类与内部资源路径。
