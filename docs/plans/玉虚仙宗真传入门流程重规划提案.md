# 玉虚仙宗真传入门流程重规划提案

> 状态：2026-10-13 已确认，并已并入现行权威主案[《玉虚仙宗真传入门与师承培养流程》](玉虚仙宗真传入门与师承培养流程.md)。本文保留详细设计与流程依据，不再作为待确认提案。山门迎真、宗门问答、因果事实展示、引路、正式拜师、录籍存档及峰内直达已接入首版；青溪里三项序章事实已纳入玩家因果记录。全世界经历采集及玉虚硬性门规的可核验规则目录仍待后续实现/定案。本文不新增境界、资源、任务奖励或时间数值。
>
> 目标：让天灵根角色成为玉虚真传时，感受到宗门在接纳与安置一位稀少的新成员；不再像先办理一项手续、再自行跨峰跑数个功能点。

## 一、核对到的当前流程与问题

此前的实施记录中，入门按钮位于观复峰；和光峰承担事务板与善功堂。旧入门路径把择师、带教安排和宗门登记压在同一确认流程，随后再提示玩家自行衔接玄览峰选书与紫府峰研读、汇报。此处描述的是被本次重规划替换的旧路径，不代表本次文档更新已改动运行时入口。

因此问题不只是“是否去和光峰”：当前手续被放在普通弟子生活的观复峰，真传的实际生活在紫府峰，传承服务又在玄览峰；玩家要自己理解并串接这些制度。择师候选是否存在甚至会阻断入门。和光峰不应成为任何真传入门前置。

现行设定中仍保留的基础事实：天灵根入门即为真传；真传免费居所在紫府峰；可选择金丹后期或圆满的师父，由师父安排云息十层同门带教；首卷候选继续使用现有三本秘籍与现有门槛；师承不发贡献，也不属于和光峰委托。

## 二、叙事参考与本项目取法

- 《凡人修仙传》中，韩立并非仅凭一句“入门成功”就完成身份转换；升仙令与升仙大会构成资格凭据，正式入黄枫谷后才逐渐进入宗门秩序。可借鉴的是“资格被组织确认、接引与正式归属有明确场面”，不照搬令牌、擂台或其宗门制度。[《凡人修仙传》第一百四十一章“升仙令”](https://www.readnovel.com/chapter/22305390000123802/95801079488772229)
- 《一念永恒》的宗门生活会落到具体山峰、日常职责和同门关系中，而非把入门等同于领取一串任务。可借鉴的是“安置后通过人和日常逐渐认识宗门”，不照搬火灶房、晋升试炼或人物桥段。[《一念永恒》宗门日常相关剧情介绍](https://k.sina.com.cn/article_6101748127_16bb1499f00100qc6e.html)

据此，玉虚流程应把“录籍、安置、师承、修行”分成有因果关系但不互相卡死的阶段；重要选择由角色在合适场景中作出，宗门接引者负责把人带到正确的生活位置，峰内功能则留在各峰自身。

## 三、建议采用的完整入门流程

### 0. 入口：点击玉虚仙宗，直接开始山门迎真

玩家在大世界抵达玉虚仙宗地点后，点击“进入玉虚仙宗”即触发山门迎真。这个点击本身就是山门接引入口；不先进入普通峰内场景，不再要求玩家寻找第二个山门按钮，也不新增大世界节点或中转地图。

### 1. 金丹长老察看跟脚、资质，只问是否已有宗门

迎真由一位**具观因察果之能的金丹境山门接引长老**主持。不是每位金丹修士都能做到这一点；神胎及以上修士则已能察看修士经历因果。接引长老不是掌门，也不是之后正式收徒的金丹师父。“迎真”是仪式/交互名称，不需要另设“迎真长老”官职。可以由具有稳定 NPC 身份的随机人物担任，不要求新增剧情模板人物；普通来访仍可由门下弟子接待。

本案中的“跟脚”专指一个人一路行事留下的经历与因果脉络，不是血统、出生地或灵根的别称；“资质”则另看灵根与现有人物资质资料。长老先观跟脚，再察资质。这里复用现有人物交互里的判定展示：逐项显示长老察觉到的经历线索、与玉虚门风的相合/相违之处，以及对资质的判断；以神色、停顿和简短言语体现结果，不用底部剧情对话栏，不公开计算式。

玉虚仙宗的审视标准沿用宗门生态：承续正统道统、重视传法秩序与内部责任，并对魔修、魔功持零容忍态度。长老看的是具体行为及其因由，不按“杀过人”“业力为负”一刀切；自卫、履责、无故害人、背弃同道等要结合真实事件脉络辨别。普通的褒贬或未明因果可以让长老的态度更审慎，却不能凭空变成新门规。明确触及现有零容忍红线的情形，则不能被“尚无宗门”一句绕过正常审查。

长老的称呼按双方境界差使用“小友”，语气有长辈的分寸，不像审讯犯人。结果文案由真实经历与资质分别驱动，例如：

- 经历与门风相合：“长老循着几段因果看去，目光稍停，眉间的审视渐渐舒开，颔首道：‘小友所行之事，倒未失正。’”只有确有相应经历时才提“护人、守诺”等具体内容。
- 经历尚浅或无重大因果：“长老循过小友一路行止，未见可辨的深重纠缠，便收回神识，淡淡点头。”不把“没有记录”写成已经证明品行高洁。
- 行事复杂、因由未明：“数缕因果交错而过。长老没有妄下断语，只将目光在小友身上多停了一刻。”这表示审慎，不自动等于拒绝。
- 资质出众：“长老的神识在你灵机间略一停驻，眼底掠过一丝讶色，随即满意地点了点头。”
- 资质平实但符合现行入门条件：“长老细察片刻，收回神识，只淡淡颔首：‘根性已看过了。’”
- 明确触及既有硬性门规：“长老的神色沉了下来，直言此等修行与行止，玉虚不纳。”只用于已被实际因果记录证实、且触及玉虚现行零容忍规矩的情形，不扩展成道德分数线。

同一结果可有数种语气相近的表达，但不能随机改写判定本身，也不能让同一存档重进时出现互相矛盾的结论。长老观因不等于洞悉私念、所有秘密或行囊；他只读取已发生且能由因果察见的行为脉络。

主角穿越而来的异世经历及其因果受天道遮掩。长老看不到穿越身份，也不会把遮掩本身察觉成邪异或可疑；他只会看见主角在此世实际经历留下的因果，因此此设定不造成迎真障碍，也不在交互文案中提前揭露。

若观因已显出明确违反玉虚既有硬性门规的事实，则按该门规处理；除此之外，长老**只问一句：“可有宗门？”**玩家回答“有”时，长老不再追问，也不继续办理入门；以礼相待，迎真交互就此结束，玩家宗门身份不变。玩家回答“无”时，长老命一名弟子领玩家走后续入门流程；不追加“为何来”“是否愿意”等第二轮问答，不另造忠诚、品性或性格门槛。

回应文案可保持简短而有分寸：“既有所属，老夫便不相邀。小友请便。”／“既无宗门，便随这位弟子去吧，余下的入门之礼由他带你办妥。”后一句直接进入带路流程，不再要求玩家重复表态。

人物主案规定业力是善恶倾向的单一净值，正负相抵不能抹去重大行为事实；且业力、区域声望、势力态度和个人关系彼此独立。因此长老不能只看业力数字或声望来代替“观跟脚”。实现所需的依据应是可追溯的具体经历/因果记录；记录不足时就显示未见重大因果，不虚构过往，也不把净业力当作完整履历。

### 2. 师门会面：金丹师父正式收徒并委派带教同门

玩家回答“无”后，由长老指定的弟子领路进入后续手续。按现有方向，玩家仍可从符合条件的金丹后期或金丹圆满师长中择一；选择不再是脱离场景的“加入弹窗”，而是在引路弟子安排下与师长正式会面、当面行礼、师父收徒。候选介绍只展示 NPC 数据真实具备的信息，不凭空添加师父专长或隐藏加成。真传入门必须落定一位金丹师父。

师父会亲自露面完成收徒与初步交代，但不长时间陪同。他说明自己仍需处理峰务/宗门事务，随后指定一名云息十层师兄或师姐负责新弟子最初的带路、日常问题和首卷研习协助。师父不是消失或被带教者替代：重要传承、阶段指点仍归师父；带教者负责日常照应。师父与带教者的稳定 NPC ID 分别写入师承记录，不能因重进场景或过月重抽。

师父与带教者是两种不同关系：前者决定师承并承担关键教导，后者负责日常引路与近身照应。NPC 人口与入门候选配置必须保证有合格师父及可承担带教的云息十层同门；候选池暂空属于生成或数据问题，不应变成宗门拒收理由。系统应在入门流程开始前确保候选，不能让玩家看见“无人可拜师”或在录籍后回滚身份。

### 3. 录籍与名册：收徒礼后真传身份当场生效

行礼收徒后，接引长老当场完成宗门录籍：宗门归属与起始/当前身份记录为玉虚真传，师父和带教者 ID 一并写入存档，入门时间保存。天灵根真传稀少，可有同门在场注意、低声议论或致礼；这只表现名声与关注，不自动增加陌生 NPC 的私人好感、势力态度或关系阶段。已有区域声望公式继续独立计算，不额外增加未定义的入门奖励。

### 4. 安置：师兄/师姐陪同入紫府，不让新弟子自行找住处

录籍和收徒完成后，师父便回到自己的事务；带教同门陪玩家直接转至紫府峰。建议用短场景转场表现同行引路，不要求玩家回大世界走格、逐峰寻路或先去办理庶务；转场不额外推进游戏时间。首个落脚点是紫府峰，而不是观复峰或和光峰。

带教者到达后介绍真传的免费基础居所、静室、休息处及月例入口。只说明既有服务，不强迫领取月例、不新增赠品，也不把付费洞府混入入门礼包。带教者以真实同门身份回答眼前问题，不作为任务发布者，也不发每日清单。

### 5. 首卷引路：师父定方向，带教者陪同办理

师父在收徒时交代首阶段的修行方向，并说明玄览峰负责典籍阅览；具体日常引导交由带教同门。带教者可提出“现在陪你去玄览峰看看，还是等你安顿好再去”。玩家愿意继续时，由带教者引入玄览峰的峰内场景，不需自行在大世界找路，更不经过和光峰；暂缓不影响真传身份、居所、静室和自由修行。

首卷选择仍使用现有《黄庭养形篇》《乘物游骸真经》《阴符应物经》及其原有门槛。师父可以给出建议，但不替玩家违反门槛或自动授予未定义内容。无符合条件的候选时，带教者解释可先按当前所学修炼，之后再来；不得让“暂时不能选书”变成拒收或软锁。

选定首卷后回到紫府峰，在身份对应的静室依现有秘籍章节、时间和体力规则研读；不降低门槛、不跳过章节事件、不额外发贡献或属性。首卷研读是师父安排的培养起步，但它不是接取任务，也不阻断玩家先做其他事情。

### 6. 首卷回报：带教者承接日常，师父保留正式指导

完成首卷后，玩家在紫府峰向带教者说明所得；带教者核对实际章节完成记录，并将进展转达师父。师父在其事务允许时给出简短回应或在后续相见时亲自指点；不要求玩家追着师父跨峰，也不让带教者取代师父做高阶传承决定。入门前已完成该首卷者无需重复研读。

### 7. 收束：入门流程结束，转入自由宗门生活

师门会面、录籍和紫府安置完成后，即视为“正式入门流程”结束；首卷研读与汇报是有明确师父/带教关系的首阶段培养，不是宗门手续或任务链门槛。玩家可以：

- 在紫府峰静室修炼、研读已掌握功法、休息和领取月例；
- 通过宗门总览自主了解各峰，按各峰既有职责使用其服务；
- 选择是否接取和光峰发布的宗门公事；
- 与同门自然交往，形成自己的关系。

入门与师承进度如需提示，集中显示为一条可忽略的“师门引路/行记”记录，不拆成数张像事务板一样的待办；不生成贡献流水、任务期限或强制导航。和光峰只在玩家自行想接公事或使用善功堂时前往，与真传入门无关。

## 四、入门后的活人感：宗门接纳不是一次弹窗

玩家是少见的天灵根真传，宗门身份会使其更容易被听闻，但“有名”不等于“人人自动熟识”。建议以月度世界演算承接已提出的同门来访方向：角色入门后的第一个完整月度结算之后，可由一名符合当前位置与关系条件的程序生成同门主动来访，表达认识、请教或观察；具体来意由其性格、所重、对玩家的已有认知与当时情境决定。玩家选择接受或婉拒，沿用现有人物交互界面和结果反馈。

该来访是宗门生活事件，不是新手任务，不保证所有 NPC 都来、不自动成为朋友、不重复刷关系；若玩家正处于不适合打断的流程，则延后到合适场景，不在场景切换或每次读档时重抽。具体触发频率及 NPC 池需与现行月度演算和来访规则对齐后再实现，不在本提案中新增概率数值。

## 六、实现边界与待接入事项

本案方向已确认并并入现行师承主案；后续实现按以下边界拆分。本文件只记录策划，不据此宣称任一运行时功能已接入：

1. 将“申请拜入”改为世界地图点击玉虚仙宗“进入”后直接触发山门迎真；不经过观复峰/和光峰，不增加第二个入口按钮或中转地图。
2. 复用人物交互的场景与逐项反馈机制，新增“山门迎真”交互上下文；呈现长老察看跟脚、资质的结果，只保留“可有宗门”一个问题，不使用普通闲谈对白或底栏剧情框。
3. “有”分支立即礼貌结束迎真，不再追问或办理加入；“无”分支由长老派弟子引入现有入门流程，不增加第二个意愿问答。
4. 跟脚/资质评语依据人物实际数据和现有资格规则生成，允许同一结果有多种不矛盾的措辞；不增加隐藏门槛、数值奖惩或未定义的性格属性。
5. 山门接引长老由身份稳定的金丹境 NPC 承担；迎真结果和分支状态不应因重进场景或读档而被随机改写、重复结算。
6. 保留后续师门会面与金丹师父正式收徒；师父简短出现并交代，由其指定云息十层同门负责日常带教。为旧档已有师承/带教 ID 提供无损兼容，不重抽已有关系。
7. 解耦“师父候选”与“带教者候选”：候选数据必须稳定且满足真传入门，不得因生成缺失而拒收或回滚身份。
8. 录籍完成后由带教同门直接引至紫府峰并展示免费基础居所；不改动普通弟子仍住观复峰的既定规则。
9. 玄览选书由师父定方向、带教同门陪同办理；保留三本候选、既有门槛与章节结算，不要求手动跑大世界或经过和光峰。
10. 首卷进展先向带教者回报，再由其转达师父；不新增贡献、灵石、道具、隐藏属性或定期考核数值。
11. 与同门月度来访功能对接前，先核实现有来访时间、去重、存档和场景延后机制，不另建一套平行交往系统。

## 七、确认范围与实现状态
