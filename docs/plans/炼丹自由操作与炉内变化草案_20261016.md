# 炼丹自由操作与炉内变化草案（2026-10-16）

状态：当前讨论草案，不是已完成的实装规格。已确认规则与本次建议分开列出；未确认系数不得直接加入演算。

**本体关系最新修正**：[药材、药性与功用关系](炼丹药材药性与功用关系_20261016.md)。用户确认功用是药性的不同能力，不是分别独立原料。下文“功用分别炼出/消耗”的库存解释需按最新文档修正为能力可用程度、保存程度及对应药性来源核算；不得将旧条文理解成十二份物质库存。

## 已确认边界

- 主药一味，种类从丹方候选选择，数量可增；辅药多味。主辅共用材料案十二功用基础含义，所有功用可参与过程。
- 同材功用分别炼出，品级越高越难；不按材料最高功用一并带出全部功用。
- 操作不强制划分阶段，不由玩家设定精确目标火候。以加火、减火等手段影响实际炉况。
- 造诣承担操作施展门槛与技术学习资格；达到资格不自动学会。造诣无100上限，九品丹最低造诣8。
- 法力有总量，供火消耗；副手顶炉时本人可恢复，也可服药。灵识按占用，超过80%不支，超过100%通常炸炉。
- 用户确认允许减产保效，但单颗有上限。
- 用户确认功用按实际作用区分消耗；例如生修复消耗相应药性，固已经形成的稳定结构不每息重复扣除。下方分项细则仍为草案。
- 每颗丹效0—100整数，<20不成丹，20—50薄效、51—75良效、76—90优效、91—100极效；丹效计算公式未定，留存不直接作为丹效。

## 炉内对象建议

以每次实际投入为一批，保存材料本体与独立功用。材料本体提供质地、数量、共同受热和结构变化；每条功用记录自身未炼出、已炼出及受损/散失部分。相同材料跨息投入也保留不同炉内经历，前景图标可合并数量，详情仍能展开批次。

炉内同时计算：材料受热与结构变化、功用释放、药液接触/流动/混合、反应与损伤、药性散失、药液汇集与成形。不同批次可以处于不同情况，没有全炉阶段切换。

损伤建议分清可恢复失调、不可恢复烧毁和已离炉散失。生的修复只针对前者；护发生在受损前，藏针对散失。具体边界需要专项定案，不先新增没有用途的界面条。

## 基础手段建议

|手段|直接改变|持续存在的炉况|
|---|---|---|
|加火|提高当前供火力度|炉温随后变化，不瞬间变成某个数|
|减火|降低当前供火力度|仍有余热，不瞬间冷却|
|维持|延续供火及已有照管|炼化、流动、损伤等照常推进|
|运药|以灵识推动药液流动及接触|不替代未完成的材料炼化|
|收束|以灵识使药液聚拢、逐渐形成丹药|可以提前尝试，未混匀会留下分配与成形问题|
|出炉|结束本炉并检查实际成品|提前出炉可能得到未成形或未达丹方要求的结果|

建议每息安排一个主要手段，投料另行安排并合计负担，具体行动数量尚未确认。操作上限取决于已掌握手段及其施展条件。供火由法力承担，精细控制由灵识承担，不能把运药/收束直接当作额外火候。

## 十二功用需要改变的真实变化

|功用|作用对象|必须能观察到的结果|
|---|---|---|
|破|尚未打开的材料结构|结构更易打开，后续药性释放条件改善|
|化|已经受热但尚未炼化的材料|逐渐成为可参与药液的部分|
|通|不同批次药液之间的联系|能够交换药性、逐渐连通|
|行|已经连通的药液|实际循环、交换更充分|
|聚|分散药性|逐渐集中，局部药性分布改变|
|引|流动药性|流向被导向目标药团，分配改变|
|固|已经聚拢的药团|更能保持成形，减少散开|
|镇|剧烈反应/躁动|波动受压制，避免继续恶化|
|护|正遭受外来热伤/冲突的材料或药液|实际承受损伤减少|
|生|可恢复损伤|修复该部分，不恢复烧毁或离炉部分|
|藏|已经炼出的药性|留在炉内的量增加，实际散失减少|
|明|炉内观察|更清楚识别未炼开、受损和分布不均，不自动减少灵识占用|

不要求一炉必须使用十二种功用，也不要求每项每息生效；没有对应对象时可以暂不发挥。普通操作提供基本处理能力，功用改善相关变化，新技术提供更有针对性的主动处理。是否设置某丹方的必需功用必须由丹方显式规定，不能全局隐式强制。

## 品级难度与数量建议

功用品级分别影响炼出难度、炼出后的作用强度和控制负担，三者不能只用一个品级乘数替代。质地决定材料如何受热、打开与承受火候；高品功用可能需要更持久有效的供火、更精细的操作，而不是一律更高温。

同材低品功用可能先炼出，高品功用仍在等待条件。已经炼出的药性仍经历后续炉况，因此继续追求高品功用有时间、法力、损伤和散失方面的取舍。不能直接点击指定释放百分比。

材料数量增加提高实际加热负担，更多批次同时变化增加灵识照管负担；已炼出的强功用也增加控制难度。尚未释放部分不按其全部强度视为已经在炉内发挥，但尝试精细炼化仍需要相应操作条件。

不预先设定“造诣不足便整味药不可入炉”。能否继续炼出由已掌握手段能否满足实际条件决定，具体条件需在操作表里定清。

## 造诣与技术建议

每项技术定义四件事：学习资格、学习来源、实际施展条件、改变哪种炉内变化。不能只有名称和造诣数字。

候选方向：缓慢催火（更小幅改变供火）、分批细投（少量持续投入，降低单息投料冲击）、分别照管（对不同药液施加不同控制）、定向引药（更明确地控制流向）。均为候选，不新增已学习资源或技能。

造诣门槛可检查操作强度、投料规模及可同时控制的对象；法力检查供火能力和余额，灵识检查当前占用，三者分别失败并反馈原因。不再默认每点造诣直接增加炼化速度或打折灵识占用。

## 减产、分配与丹效

主药用量提供理论产量。用户可选择减少实际尝试形成的丹药数，把符合丹方要求的可用药性集中分配，单颗有明确上限；超过上限不能无限提高丹效。额外无关辅药不自动贡献成品药效。

减产只能缓解每颗分得不足，不能纠正配伍不合要求、修复不可恢复损伤或找回散失药性。分配不均可使同炉各丹评级不同。聚改变集中程度，引改变流向，通/行影响交换与均匀分配，固影响成形保持。

需要单独确定各丹方的成丹硬条件、每颗药性的有效范围及满效上限，再制定丹效计算；不把一个过程条直接换成四档。具体公式仍空缺，不能借用旧原型最小值评分。

## 单息结算建议

检查操作条件及资源 → 投料与操作生效 → 按实际供火更新炉况 → 各批材料结构与各功用释放 → 已释放功用作用于对应对象 → 药液接触/流动/反应/汇集/成形 → 损伤和散失 → 更新占用及可观察信息。

所有变化每息检查，不因操作按钮不同而关闭某类过程。新释放功用何时首次发挥、操作负担的峰值计算需要下一步明确，防止同息自助炼化或先超载后释放等时序漏洞。

## 下一步待定

优先把每种基础手段的幅度、对象、法力及灵识要求，与功用品级的炼出条件对上；再明确损伤边界和功用作用消耗，随后制定丹方成丹条件与丹效标尺。本轮仅设计，不实现新系数，不用旧演示作为验证。

## 功用消耗原则与分项草案

用户已确认按实际作用区分消耗，未确认具体系数。建议共同规则：没有作用对象时不扣除作用消耗，但受热、受损、散失仍照常计算；实际处理量越大，所需功用药性越多；消耗只来自已炼出的可用部分，不能透支尚未释放部分。已完成变化保留，停止作用不自动把材料结构恢复或把药团还原。

|功用|本轮分项建议|
|---|---|
|破、化|按实际打开结构、炼化材料的处理量消耗；处理完成不重复收费|
|生|按实际修复的可恢复损伤消耗；无可恢复损伤时不扣修复消耗|
|护|按实际隔绝、抵挡的损伤消耗；不能无代价抵挡无限热伤|
|镇|按实际压制的躁动消耗；平稳炉况不扣压制消耗|
|聚、引、行|按实际汇集、引导、推动的药性量与操作强度消耗|
|通、固、藏|按建立、加强连通/稳定/封存关系所需作用消耗；已有结果保留，遇扰动需要维护时再消耗|
|明|按实际显化作用及维持需要设计消耗；不得把打开面板、悬停等查看行为计为游戏消耗|

作用消耗、不可恢复损伤及炉外散失分账，避免同一部分重复扣除，也避免生修复变相返还已使用药性。每份功用记录剩余未炼出、已炼出可用、实际作用消耗、受损/散失等去向；高品更难炼出且作用更强，不推定其必然按同倍率消耗。

原型尚未实现这些分项，不新增另一条“功用能量”资源；药材数量与实际释放量提供可用药性的来源。
