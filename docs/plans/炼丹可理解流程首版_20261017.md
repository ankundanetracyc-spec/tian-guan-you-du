# 炼丹可理解流程首版（2026-10-17）

状态：当前项目内炼丹测试入口的可理解性修订。只约束测试演算与测试界面，不确认为正式平衡。数值可调；材料功用仍以[物品词缀系统设计](物品词缀系统设计.md)为准，完整逻辑边界见[炼丹系统逻辑主案](炼丹系统逻辑主案_20261017.md)。

## 目标

玩家看过几次操作后，能预判这次操作会改变什么、哪味药会受影响、风险来自哪里。每次反馈使用同一顺序：

```text
玩家操作 → 炉温变化 → 材料反应 → 本息实际发挥的功用 → 风险或收获
```

界面只突出当前决策需要的信息；其余质量账、功用投入和来源去向放在侧栏详情与炉记。

## 参考其他游戏后做的取舍

- 《觅长生》的丹方提供一个可验证的目标，药性相同的材料可以替换，材料品阶与数量带来成本取舍。我们保留“丹方写清成丹要求、以后允许多条材料路线比较”的思路，不照搬主药/辅药/药引槽位或整套药力算术。[炼丹入门](https://wiki.biligame.com/mcs/%E7%82%BC%E4%B8%B9%E5%85%A5%E9%97%A8)
- 《Potion Craft》让玩家亲自投料、搅动和加热，并能从操作看到药液往目标方向变化。我们采用“点一次就有可见因果反馈”的方法，不搬它的炼金地图、研磨前置和路径机关。[Steam 商店页](https://store.steampowered.com/app/1210320/_/?l=english)
- 《了不起的修仙模拟器》把炼丹成功和炼丹人能力、丹药品阶联系起来，产量也由角色和技能影响。我们保留“材料决定可提供什么，丹师决定能控制到什么程度”的分工，不采用隐藏成功率自动掷骰。[炼丹说明](https://www.gamersky.com/handbook/201901/1143681_9.shtml)

因此本轮具体做了这些加减：

1. 保留共用炉温、旧原型档三项参数、批次投药、法力供火、灵识负担和造诣门槛；它们都能直接解释玩家刚做的操作。
2. 合并“混匀程度”和“分配均匀度”的重复读数；“引”直接按每颗丹的实际缺口导药，不再另外学一个做同一件事的“定向分配”。
3. 去掉每项功用单独的累计照管进度和逐项保存字典。高品功用能发挥多少，只看药性实际炼出多少、炉次达到的最高控制精度、材料是否受损。
4. 丹效不再让玩家面对七条并列评分轴，改为三项短句：主药发挥、配伍协调、丹体稳定；丹效取最低项，因此关键缺陷仍不能互相抵消。细项数值留在丹方判定里。
5. 保留“分离”和“排渣”两个动作，因为前者提高分离程度，后者真的把残渣和夹带药性带出炉；这是有代价的选择，不是重复按钮。

## 玩家只需先学会三条

1. **火候管炼化速度和热损伤。** 加火、减火只改变供火档位；炉温逐息跟随供火。减火后仍有余热。炉温未过材料的开炼线时不会靠火炼出药性；超过开炼线后，火候越足，炼化越快；超过耐热线会损伤材料。
2. **材料分类说明主导加工响应。** 测试入口仍按旧原型档读取三项数值：开炼火候、基础炼化速度、耐热线。新版百科分类与原型参数档分开保存，原型数值不从六种分类推算。不同批次各自保留炼化进度，但共用同一个炉温，不再显示每批独立温度、吸热率、适温点、产物形态等多套指标。
3. **功用是材料药性具备的能力。** 功用不等于另一种可提取物；只有存在对应对象时才实际发挥。高品功用需要足够的药性释放和控制精度；热损伤与躁动会削弱实际能力。炉记会指出来源材料、作用对象、实际变化和投入去向。没有目标时不扣作用药性。

每次操作点击后推进一息。玩家不用另按推进。投药确认也推进一息；开侧栏、看丹方和调整计划不推进。

## 测试火候规则

以实际炉温 `T`、旧原型档开炼线 `O`、耐热线 `S` 计算本息热度适配：

```text
热度适配 = clamp((T - O) / (S - O), 0, 1)
```

- `T < O`：基础热炼化为零；若有“破”等功用，它仍只在有可打开结构时发挥。
- `O ≤ T ≤ S`：热度适配从0逐渐升至1，温度越高基础炼化越快。
- `T > S`：基础炼化不再因超温继续加快；热损伤随超出耐热线的程度增长。

材料结构打开进度与炼化进度连续并行，没有固定阶段锁。“破”可打开实际结构；“化”可帮助炼化为可用药性。两者只有取得到可用能力且有相应对象时才消耗药性。造诣和灵识影响本息控制精度，控制精度参与打开与炼化速度；达到操作阈值、学会相应技术后才可提高规模或使用新手段。

供火与炉温继续使用测试参数中的炉体响应和丹火效率。测试预测在行动前显示下一息炉温，行动后显示实际炉温与材料变化。相同材料、造诣、器具和操作，演算必须得到相同结果，不加入随机加减。

## 一炉中的事件

|操作/事件|玩家能观察到的结果|功用怎样参与|
|---|---|---|
|加火、减火、维持|供火档位和预测/实际炉温改变；各批按自己的质地条件并行炼化|破、化可在有材料结构或待炼原料时辅助处理；其余功用不因点击火候按钮凭空生效|
|投药|新批次立即处于当前炉温；炉温低则等待开炼，过高可能当息受损|只在该批能力已可用且本息出现对应对象时参与|
|搅动药性|已炼出的药性发生接触，混匀上升或因过急接触产生躁动|通建立可交换联系，行推动联系中的交换，镇可压实际躁动|
|分离、排渣|分离让药性和残渣更清楚地分开；排渣按实际夹带带走物质|明只帮助实际辨识/分离；护、生、藏等只对应真实损伤或散失|
|凝丹|可用药性转入指定颗数，逐颗形成真实药团|聚汇集、引按缺口分配、固维持已形成结构|
|出炉|逐颗按丹方要求判定；失败原因可追溯到实际材料和操作|只计算已真正形成并保存在成品中的能力|

主药仍只有一种，须从所选丹药的候选中选择；辅药可以多味、自由替换。投料次序由“何时能承受炉况、何时需要其能力、当时是否有控制余量”决定；丹方给配伍和操作参考，不规定辅材范围，也不按固定第几息锁定投料。

## 界面反馈

主画面以丹炉为中心，只保留行囊、丹方、维持、加火、减火和一个技法入口。其余操作放进技法菜单；不在炉旁铺开参数表。每次操作后只在炉记顶部显示本息变化，旧记录可以继续翻查。

右侧侧栏收拢为三页：

- **炉况**：一条预测显示炉温变化、当前材料会怎样反应和本息法力消耗；下一条显示当前掌炉者的法力与灵识状态。阴阳只显示一个数值和简短倾向，不再同时铺多条重复进度。
- **药材**：按批显示材料、投入时点、炼化状态和可用药性。点击一批后才展开质地、五行、阴阳、功用及完整来源账。
- **炉记**：默认只显示最近几条变化；完整操作、功用来源和十二功用对照按需打开。

丹方弹窗先给常方、三项判定概述和本炉结果；完整阈值与逐颗缺口由“查看具体判定”展开。参数表、逐项功用数值和来源账不与主要操作同时抢占画面。

每次操作前，炉况页显示：

- 当前炉温与本息预计炉温；
- 主药是否低于开炼线、正在炼化或超过耐热线；
- 本息法力花费与灵识负担。

每次操作后，炉记用简短文字说明：

- 本息操作和炉温前后变化；
- 哪批实际炼化了多少，得到多少可用药性；
- 哪项功用确实作用、作用对象和实际去向；没有作用时说明缺少什么对象。

药材详情仅突出：当前材料分类、旧原型档三项试验规则、材料状态、已炼化/可用药性/未炼部分/炉渣、原材料上的功用及本息实际作用。精确强度、灵识来源账等不放在第一层说明中。

丹方详情先按玩家能采取行动的原因归纳成三类：**主药发挥**看有效主药量和该丹种指定的核心功用；**配伍协调**看混匀程度与丹种自己的阴阳目标是否满足；**丹体稳定**看成形、实际夹渣与损伤。每项各自得分，成品丹效取三项最低；缺陷不能靠其他项补分。辅材没有固定清单，丹方详情展示的材料和数量是建议组合。展开后可查每项具体门槛和下一分缺口。丹效仍只负责评级；实际药效由丹种曲线独立计算。

功用显现不再维护独立的“照管累计值”。测试里，一项功用的可发挥比例由三件事共同决定：已经炼出的药性比例、这炉曾达到的最高有效控制精度、当前受损程度；功用品级越高，所需精度越高。这样丹道造诣和细致操作会解锁高品能力，但不会直接给最终丹效加分。

## 调整界限

以下属于本测试首版而非最终规则：旧原型档数值、每息供热、炉体响应、80%可用比例、功用作用强度、控制精度曲线、丹效曲线。变更后必须同时更新本页、参数表和实际界面；不得只改文案或把某组数值写成玩家已确认的正式设定。

## 学习性验收

体验者看完三次“加火/维持/减火”后，应能回答：

1. 供火档位和实际炉温有什么区别？
2. 为什么加火后有的药开始炼化，有的仍没反应？
3. 为什么炉温过了耐热线后继续加火会造成损失？

看完一次搅动、分离、凝丹后，应能指出至少一条真实发生的功用，以及一条本息没有发生作用的原因。若不能回答，优先调整规则或反馈文案，不追加隐藏系数。
