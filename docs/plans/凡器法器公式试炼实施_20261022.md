## 一、玩家操作与交付边界

入口：首页“试演与预览→炼器工坊·剑类试炼”，或“百工→法宝→进入炼器工坊·试炼”。选剑大类，配置岗位材料与整数份数，开炼后揭示器物，可在器物册重看。

一级仍为身、质、性、和、燃；身材内部为主体、承接、辅体。内部兼容键“复合身材”只在数据中保留，玩家统一看到辅体。玩家不预选剑形、功用或表达方法，也没有效果开关。器物自身不保存功用字段，直接保存本体、实际效果及来源快照。

炼前界面只读取 `Preparation`：材料、数量、投入五行/七档阴阳、造诣、供热、工时、试炼精力、操作合法性。它没有成器结果或评阶字段；不提前调用完整结算，不显示器阶、属性、达标、配伍优劣及补料建议。通用说明讲原理，炼后显示实际效果。成器详情分器物信息、能力详情、炼制记录；不把内部 C/R/T/S/H、效力池和未利用数字塞进玩家面板。

每次进入的库存独立，每种材料30份；不会补正式装备、修改人物属性、推进正式时间或写存档。非法提交不扣料；合法尝试消耗本页实物，供热不足记录失败。相同草稿版本只结算一次；改料或重新载入可再尝试。

必填主体、承接、燃料；质材、性材和和材按需选。缺质材时主体作为配伍基准，不以材料岗位身份禁止成器。造诣影响保留率，位置复杂度仍按20/32/50开放，不能据此认定器阶。

## 二、可复用的来源计算

运行参数统一位于 `resources/crafting/process_forging_candidate_v2.json`。首批13种既有材料只填加工参数，不填“成品给什么技能”。材料本身的五行、阴阳、功用品级读取现有材性资源，没有改炼丹的词缀或材性口径。

对同岗位同材先合并，q为实物份数：

```text
Q(q) = (1-exp(-q/3)) / (1-exp(-1/3))
W(g) = 1.6^(g-1)，无此功用时为0
η = 基础保留 × [0.8+0.2×clamp((造诣-加工难度)/40,0,1)]
P = 8 × Q(q) × max(W) × η
p[u] = P × W(g[u]) / ΣW
```

多功用分享一个 P，不复制总量；每份实物只属于当前岗位。无有效功用的材料不产生该类潜力，但有加工数据时仍可形成物理本体。实物份数用于扣料、供热和工时，不拿 Q 扣库存。

五行送达系数：同/根生源1，源生根0.9，相克0.6，无行0.85；阴阳系数为 `exp(-0.2×max(0,|根阴阳-源阴阳|-3))`，二者相乘。质材按 P 加权为根；没有质材时取主体。阴阳用七档 -3…3；同向至阴/至阳不受惩罚，局部冲突不能用整炉平均抹去。旧材性 ±1 解码为阴/阳，优先采用已有相性标签，不改公共资源。

性材支路可用沿相生方向所需的真实和材通关，成功后五行系数0.9。通关逐根、逐源独占实际份数：消费一份就扣该来源初始供给的1/q，不把剩余量重跑Q。缺少任一中介则不扣这一条，保持原系数；燃料不充当火行和材。来源顺序按岗位和定义ID固定，不依玩家投料先后。

剩余有效来源按同一个岗位矩阵分账：

| 岗位 | 本体 | 角色潜力 | 工艺 |
| --- | ---: | ---: | ---: |
| 身材 | 0.75 | 0.10 | 0.15 |
| 质材 | 0.30 | 0.20 | 0.50 |
| 性材 | 0.10 | 0.75 | 0.15 |
| 和材 | 0.10 | 0.10 | 0.80 |

每一来源满足：本体+角色+工艺+通关消费+配伍损失=P。身材和性材只是主要来源，不是其他岗位归零。燃料只供热，增加燃料不额外增加效果或改变器性。

## 三、本体、锋锐及评阶

主体、辅体的体量 `Vᵢ=Q×η×可成形体量`；承接不重复作为剑刃体量。以 V 加权延展比 λ 和厚度比 τ：

```text
V = ΣVᵢ
宽 = (V/(λτ))^(1/3)，长=宽λ，厚=宽τ
连接K = ΣQη×连接能力
连接需求 = 0.25V，连接率k = min(1,K/需求)
整体材评G = clamp(ceil(2g₁+0.5g₂+0.25Σ其余g),1,27)
本体成长F = exp(0.12×max(G-1,0))
结构承载C = 6 × Σ(Vᵢ×结构强度ᵢ×Fᵢ) × k
```

G沿用现有材评综合口径，没有功用时按无成长处理；不再拿它给性材收益重复乘倍率。形态名只是长宽厚的描述，没有名字倍率。

锋锐计算：

```text
开刃材质 = V加权(刃性×F)
加工完成 = V加权η
刃形系数 = clamp(sqrt(0.15/τ),0.75,1.25)
间接支撑 = Σ非身材(该源本体分量 × 该源(0.5破+0.2固)/P)
锋锐 = floor(4×开刃材质×加工完成×刃形系数 + 0.03×间接支撑)
```

这是剑自身固有属性，凡器也可有。候选表现为剑参与的合法物理攻伐忽略锋锐点物防；本轮只生成说明，尚未决定多剑叠加/百分比穿防顺序、攻击来源识别与正式战斗接线，不声称已经影响实际伤害。

定义 B[u] 为本体向量、J[u] 为工艺向量，各公共指标读取向量，不读取材名：

```text
C灵 = min(C, 1.5k×(0.6ΣB+0.3B固+0.2B护))
R灵 = 0.2ΣJ+J藏+0.45J固+0.2J生 + 0.05ΣB
T灵 = 1.6k×(0.1ΣJ+J通)
稳定支撑 = 0.6ΣJ+0.8J藏+0.6J固+0.8J护+0.3ΣB
L = 0.5Σ[P×(1-送达)] + max(0,连接需求-K) + 0.02Σ[P×(1-η)]
S = exp(-L/稳定支撑)，支撑为0则S=0
H = min(C灵,R灵,T灵)×S
```

完整成器且 H≥10、S≥0.8，试评法器；否则为凡器。S是稳定维持比例，不是随机成功率。没有原料品级/造诣身份门槛，不用锋锐或技能数量替代标准，也不因成为法器给属性再乘一轮倍率。

本轮只区分凡器/法器，**没有足够标定数据时不填“下品”默认值**。法器四小档、法宝以上水准和额外加成仍按主案后续标定，不将本公式线性外推为高阶标准。

## 四、效果组合与共同约束

角色潜力按功用维度提供资格；有限效果原子负责可理解的内容，不以材料名、配方、剑形查表。当前候选：破对应物伤百分比/物理穿防比例/基础物伤，固对应物防/化解/护盾。映射是全材料共用的公开语义表，新材料的同一功用自动适配。

| 表达 | 内容 | 每单位额外工艺成本 | 基础偏好 |
| --- | --- | --- | ---: |
| 基础加成 | 物伤%、物防 | 无 | 1 |
| 关键词常驻 | 剑关键词技能的物伤% | 通0.5、藏0.1 | 0.8 |
| 定向化法 | 物理穿防%、实际应对化解 | 通0.35 | 0.7 |
| 条件触发 | 自身护盾 | 通0.3、聚0.3 | 0.4 |
| 直施 | 基础物伤或护盾 | 聚0.4 | 0.4 |
| 御器 | 御使物伤或护盾 | 通0.2、藏0.25 | 0.4 |

每种表达同时占对应角色来源1、C1、R灵1。工艺预算为J中的通/聚/藏剩余量；属性和工艺为分开的实物贡献，不一份两用。C/R等容量约束是器物能承受的上限，不是额外可发放来源。

特殊表达偏好再乘 `相关工艺量/(相关工艺量+10)`：关键词/化法取通，触发/直施取聚，御器取藏。每个来源的候选偏好归一化。求解：

```text
最大化 Σwᵢ ln(1+xᵢ)
满足：每个共同资源 Σ成本ᵢ×xᵢ ≤ 实际预算
```

x是实际分配量。每条至少1.5，整数效果还须足够生成1点；连续求解后淘汰不足者并重新分配，避免零值奖励。求解器按固定ID顺序迭代，末尾仅收缩透支资源涉及的变量。示例：来源40、两个等权表达，其中关键词最多使用通12，解为基础28/关键词12；通40时各20，通0时基础40/关键词0。加更多表达分享同一份来源。

效果统一换算：物伤%=0.5x，物防=floor(0.5x)，物理穿防比例=min(0.35,0.01x)，化解=floor(0.5x)，基础物伤/护盾=floor(1.2x)。取整、封顶损失与未利用余量进入内部快照，不再发放其他奖励。

凡器只允许基础表达；法器按真实工艺和分配可兼有多类或没有特殊表达，不设两功用/两条收益上限。御器还须实体体量≥7；真实生成御器效果后才产生器体：

```text
器体上限=floor(2C/6)
在场灵识=max(1,ceil(0.15V+0.1Σ御器实际分配))
```

器蕴规则未完成标定，当前列表为空；不从“破/固”直接补发虚构套系层数。主动技能的费用、目标、限次、冷却、召出/御使接口仍未装配，本轮不能把描述放进战斗技能栏。

触发护盾仅是候选描述：剑关键词原始攻击首次对生灵造成物伤后，同次多段/群攻只计一次，衍生段不递归。尚未向战斗注册新事件。化法描述区分类别、关键词与实际效果，未把近身当关键词，也未修改任何既有卡牌。

## 五、器物档案及拓展

器物保存 schema2、实例ID、类别、形态、器阶、锋锐、五行阴阳、器体/灵识、效果列表、空器蕴列表、实际材料快照、规则版本、参数原文、输入哈希、预算使用/余量和炼制成本。效果保存内容、表达、范围、事件、条件及来源分配，不再嵌套功用结果。

已归档器物按副本读取；运行参数对外也返回副本。复算只使用器物自带的材料和参数，不反查后来更新的资源。旧v1测试快照拒绝自动转为v2，不涉及正式存档迁移。

新增同类材料只需材性向量、性相与物理加工档案。测试用同数值新金属替换铜髓矿，所有效果、锋锐与数值账本相同；输入哈希/显示名改变。若要扩展新的效果内容，只增加公共原子及兼容规则，不给新材料单写配方。
