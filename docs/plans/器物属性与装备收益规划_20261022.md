## 一、一件器物分清三件事

最新层级补充见[凡器与器类专属属性](凡器与器类专属属性设计_20261022.md)：凡器仅基础加成；每类器物有专属本体属性，剑拟为锋锐，自带物防忽略的基础性能。该本体性能来自身材，与性材产生的角色额外收益分开；凡器不因此获得特殊关键词规则、化法、技能或器蕴。

### 最新确认：本体与角色收益分开生成

质材的当前职责是建立器物的灵性基础，主要贡献共同根性支撑、效力维持及稳定实现能力，影响其他材料潜力有多少能够发挥；自身性相也参与实际配伍。它与身材的实体成形、性材的收益方向、和材的配伍/通路各有侧重，均非独占来源。质材不单独决定器阶，也不预设只能使用灵石。

用户进一步强调“主要”不等于“唯一”。各岗位可按公共贡献权重参与本体、角色收益及工艺，但同一来源必须分账守恒，不可分别领取满额；不能将身材对角色或性材对本体的贡献一律归零。法器的具体通灵标准与岗位权重候选见[法器阶段](法器阶段设计_20261022.md)。

用户确认：器物自身属性与身材等有关，给予角色的加成与性材等有关；身材不能过低级，材料自身层次及对应功用品级越高应有更强的相应表现。

身材的主体、承接、辅体主要形成器物的实际形态、结构、承载与器体基础；长期耐久潜力随维护方案另定。这些不直接等于人物物理防御或物伤加成。物防、物伤加成、关键词规则、化法与获授能力的实际收益主要来自性材，经质材支撑、和材通路及加工结果实现。

这使同名材料在岗位间有不同职责：身材中的固可以改善器物自身结构；独立份数投入性材后，其中固的有效贡献才进入角色防护收益。不能用一份材料同时领取两份完整贡献。

按最新意见，材料层次参与真实加工和结构计算，不设置原料几品或造诣多少才能评某档器物的身份门槛。是否足以承受能力由实际成器水准判断；堆量、连接与复合的效果都由公式体现。实际达到标准就认可等级，少量高级辅体只有确实改善结果才贡献评阶。

材料整体品级体现综合层次；相关功用品级决定某一方向的潜力。其他条件相同时，相关功用品级提升必须使该方向潜力不下降；高品生不能代替高品固获得同等防护收益。现行整体材评由功用品级综合计算，因此不能在性材潜力上再无条件乘一次整体品级倍率，重复放大同一来源。

**器物是什么**：剑、甲等大类，实际形态，五行阴阳，工艺品质与完好程度。

**装备后给予什么**：常驻属性、化法、可装配的主动技能、单件器蕴贡献。并非每件器物必有全部收益，也不因名称叫剑就免费附赠一套攻击属性。

**本场发生什么**：是否召出、剩余器体、灵识占用、技能次数和冷却。单场状态不写入器物的固定属性，更不能混同耐久。

建议器物系统采用“固定成器数据 + 人物装备配置 + 单场运行态”三层。炼器决定能力基础；装备决定玩家如何使用已有能力；战斗记录实际使用情况。

## 三、常驻属性如何设计

通用计算入口：[炼器效果通用计算公式](炼器效果通用计算公式_20261022.md)。后续使用来源贡献、公共效果算子、共同资源约束及统一换算求出成器，不穷举材料效果或组合配方。

材料如何生成这些效果的配套提案见[材料到器物效果生成设计](材料到器物效果生成设计_20261022.md)：明确来源、工艺通路、共同分配和三组剑材料组合。新增关键词规则与事件效果尚未进入试炼计算。

### 3.0 常驻收益包含数值与规则

用户补充确认：常驻收益不限于增加角色战斗属性，也可以对所有满足条件的技能持续施加修正，或在合法事件发生时附带效果。总称建议为“常驻效果”，基础属性是其中一类；化法与获授技能继续单独记录。

| 常驻效果类型 | 表达方式 | 生效范围 |
| --- | --- | --- |
| 基础属性 | 物理防御增加、物理伤害加成等 | 汇入角色现行战斗属性 |
| 条件修正 | 所有带剑关键词的技能，其物理伤害提高；或造成物理伤害时忽略部分物防 | 自动筛选全部合格技能，无需指定绑定位置 |
| 条件触发 | 带指定关键词的技能命中后附带已有合法效果；或实际完成指定应对后产生收益 | 装备期间持续监听明确事件，发生时自动结算 |

这些是效果方向，不是本篇新建的战斗卡；未设定正式数值、费用或新状态。剑关键词是用户指定的条件示例，实施时必须核对实际关键词定义与技能数据，不凭技能名称、剑类器物或近身出手方式推断。

**常驻条件修正与化法的区别在于作用范围和绑定方式**：常驻规则自动覆盖所有合格技能；化法由玩家选择一个合格技能引用绑定，随该技能生效。两者都不需要额外释放，不能因为会改变技能效果就全部归入化法。获授主动技能则需装入技能槽并排入行动队列。

### 常驻规则需要记录什么

每项规则除来源实例、效果ID及炼制来源外，还须明确：

- 匹配条件：技能关键词、类别、实际效果结构、必要时才有的出手方式，以及条件之间的且/或关系。
- 结算时点：修改技能的哪一类伤害，或监听使用、命中、实际造成伤害、实际应对等哪个事件；这些事件不相互混用。
- 具体收益：修正原有结算还是另行附带效果，数值、单位、接收者及适用目标。
- 作用次数：按技能执行、伤害段、目标还是回合计数；是否覆盖群攻、多段、追加和器体，须逐效果定义。
- 叠加与防递归：与其他常驻、化法及秘籍如何汇总；附带效果保留来源，不能递归触发自身形成无限链。

触发失败、未命中、没有实际伤害等是否产生收益按该规则的真实条件判定，不能仅因队列中出现合格技能就先发收益。卸下来源后撤销常驻规则；同一事件不能因反复刷新界面或重建技能副本重复注册。

常驻效果的强度预算同时考虑适用范围、实际触发频率及单次收益。覆盖所有剑技能的规则与只绑定一个技能的化法不能直接套用同一转换系数；限制条件也不自动等价于可以任意提高数值。两者依然竞争材料与加工所形成的真实效力，不新增免费效果来源。

### 3.1 只使用明确的属性

第一批直接沿用已经试算的两项：破功用可表达物理伤害加成；固功用可表达物理防御。后续根据成品模板逐项扩展，不能把所有材料功用都临时解释为某种战斗加成。

| 属性方向 | 可对应的现行属性 | 首期处理 |
| --- | --- | --- |
| 攻伐 | 物理伤害加成 | 破的常驻模板已在试炼生成说明 |
| 防护 | 物理防御 | 固的常驻模板已在试炼生成说明；甲类同样需有对应有效来源 |
| 生存 | 最大生命、受治疗加成等现行字段 | 预留方向，须有对应功用模板后开放 |
| 精准与身法 | 精准、闪避数值 | 预留，不能把固定值写成百分比，也不能凭轻剑外形免费赠送 |
| 会心 | 会心、抗会心 | 预留；数值不等于会心概率，按现行战斗解释展示 |
| 行动 | 行动速度 | 高影响属性，独立模板与预算审核后再开放 |
| 特定资源 | 合法境界下的法力上限等 | 后续专项模板，不通过法宝绕过现有境界与资源规则 |

以上“预留”表示属性候选范围，并非已经支持的炼器产物。当前没有统一的“攻击力”作为所有技能的通用底数，也不能为了凑齐装备面板直接发明“法术防御”等未定义属性。

### 3.2 数量与强度

成器直接保存实际常驻效果清单，不再用“最多两项功用”定义器物结构，也不将它机械转换为最多两条属性、两个技能或两项化法。具体收益数量与强度上限随材料、承载和效力分配另行校准；原候选内部的两来源筛选尚未调整，不代表新上限已定。暂不另外随机抽取一串基础词条、随机前后缀或插孔，避免与器蕴及材料推导重复。

每条属性必须记录：真实属性键、固定值/百分比单位、数值、效果ID、生效条件与炼制来源引用。来源引用可追溯材料功用及效力分配，但不另建成器功用列表。同类常驻按现有属性规则汇总，不新增一个隐蔽的法宝乘区。上限由对应战斗属性统一管理，不能各件法宝分别绕过。

属性来自分配给常驻的效力。质材和身材提供共同可实现条件，不重复发一份同名常驻加成；品质和器型不在最终值上再次相乘。

## 四、化法与获授技能的信息

### 4.1 化法是已有技能的附加修正

记录：来源器物ID、来源功用、修正内容及实际数值、技能类别要求、关键词要求、效果结构要求、当前绑定引用。

筛选必须分开检查技能类别、关键词、出手方式及实际效果。气血是关键词；近身是出手方式，两者不互代。仅当某化法明确要求近身时才检查该条件，不能给全部剑类化法默认添加近身限制。

沿用当前候选：破的化法要求攻伐、气血、含单体物理伤害；固的化法要求守御、含实际应对化解。它们只修正对应结算；穿防不变为伤害倍率或绕过护盾，未触发应对不追加化解。

绑定后自动随原技能生效，不需另行释放，也不单独占一个主动技能位。没有合格技能时只显示“当前无可绑定技能”，不把未生效收益兑换成额外属性。与秘籍化法的追加顺序沿用现行已确认方案；多个器物争用同一技能的规则仍需装备配置专题定案，本篇不据此放开无限叠加。

### 4.2 获授技能是可供装配的能力

记录：授予来源、模板ID、具体效果、目标规则、费用、次数、冷却、是否含召出/御使分支。费用等只由审核后的技能模板提供，不因炼出一个数值就补猜一张可用卡。

玩家装备器物后获得装配资格，主动选入技能栏才可排队执行；不自动顶掉原技能。直施可直接发挥效果，御器先召出器体、后续御使。两者可并存；组合为几个技能、每个技能含几项效果须随模板审核，不能将两项功用的所有说明默认免费合成一张卡。

同一来源技能不重复占多个技能位；卸下或失去来源后清空对应引用，其他位置不前移。重新装备后按装配规则处理，不保留无来源的技能。

本篇规划数据与装配关系，不新增战斗卡，不设定新的技能费用或目标。

## 五、器体、灵识与耐久

| 项目 | 含义 | 变化周期 |
| --- | --- | --- |
| 器体上限 | 可召出器物在本场承受伤害的基础上限，来自有效结构及御器模板 | 成器快照固定；战斗修正另记 |
| 剩余器体 | 召出后实际剩余值，受合法器体伤害减少 | 单场运行态 |
| 在场灵识 | 御器实体成功召出后持续占用的容量 | 在场占用，崩解/离场/战斗结束释放 |
| 耐久上限 | 长期完好程度的基准，来自结构及正式维护规则 | 器物实例 |
| 当前耐久 | 历次合法耗损与修复后的剩余量 | 跨战斗保留 |

没有御器表达的器物不显示器体上限或在场灵识零值；显示“不具备御器能力”即可。常驻属性和化法不会因为未召出而失效，也不因此单独收取在场灵识。

**耐久建议采用明确的使用状态门槛**：完好/可使用时按固定快照发挥；破损时停止提供需要器物正常工作的收益并提示修复。暂不加入每掉一点耐久就降低一点属性的连续衰减，避免战斗中所有数值随磨损跳动。

耐久归零建议进入破损而非默认永久销毁。该提案尚未实施；扣损事件、扣损量、修复材料、维修上限和破损时各收益的具体处理仍需单独评审，不能把它直接写进当前试炼。

器体崩解只说明本场实体失效；不直接归零耐久，不自动销毁器物。战后报告先记录使用与崩解事实，正式维护规则之后再决定如何消费报告。

## 六、品级、品质与效力

这三件事分开，否则玩家会误以为品名越高所有数字都必定更高。

- **材料功用品级**：说明原料某项潜力，是炼制输入，不直接继承成器品级。
- **器物阶位**：描述器物的能力层级及工艺上限，后续须与境界/材料阶段统一。本篇只预留字段，不采用旧代码默认“凡器”等名称，也不暂造一套九品对照。
- **工艺品质**：评价本次把投入组织成有效器物的完成程度。建议候选四档为粗制、合格、精良、上乘，阈值待覆盖样本后定。

品质评价应检查关键结构是否完整、必要通路是否实际完成，以及有效能力相对该次投入可实现潜力的保留程度。失败不混入最低品质作为可正常装备的器物；合法单功用不会因为少一种功用而降品质，极阴极阳不会因偏离和而扣品质。原料故意过量导致的未利用量也不能提升评价。

品质只概括已经发生的加工结果，不在实际效果后再追加一次“上乘×倍率”。同样原料下造诣提高，能提高实际保留与复杂工艺完成情况；相关效果已体现在具体数值中，品质只是帮助阅读。

因此，低层次材料做得精良，可以比同类粗制品更有效；也不保证超过另一层次材料制作的所有器物。比较时应看实际能力，而不是单看品质名称。

## 七、器蕴与装备汇总

器蕴记录本件实际贡献的蕴种、层数、来源功用与规则版本。来自最终有效能力，未被保留的原材料标签不贡献层数。

当前试炼中的功用效力3/12对应1/2层只是候选刻度，不是正式套系平衡表。后续套系表独立声明：蕴种、门槛、激活效果、叠加规则及版本。

全身累计与套系激活属于人物装备配置。单件详情显示“本件贡献”，装备对比显示换装后累计与门槛变化。不能把全身累计保存为某一件法宝的固有层数，也不能在卸装后保留已失去的激活效果。

器蕴本身不再生成一串随机词缀。单件贡献取自真实成器结果；套系奖励只从达到门槛的组合产生。正式奖励需要连同多装备的总体强度一起校核。

## 八、炼器岗位如何影响属性

| 来源 | 主要决定 | 不直接决定 |
| --- | --- | --- |
| 身材／主体 | 基本成材、器体结构、实际形态及结构承载 | 名称为剑就自动加攻击 |
| 身材／承接 | 连接与成器完整性；具体材料适用依加工档案 | 另附赠一项完整功用 |
| 身材／辅体 | 补充并改变实际结构与形态 | 固定等于厚脊、固定提高所有效果 |
| 质材 | 共用根性及送达支撑，影响实际能实现多少潜力 | 为每项功用各复制一套支撑 |
| 性材 | 最多两项有效功用及来源潜力 | 玩家勾选的预定成品 |
| 和材 | 配伍与收益通路的实际支撑 | 同一单位同时支付通关、化法、御器 |
| 燃料 | 处理所需供热 | 额外常驻伤害或器物阴阳 |
| 炼器造诣 | 处理资格、实际加工保留、复杂组合掌握 | 没有来源的新属性和额外功用 |

器型与属性共同来自实际结构和工艺：同样叫修长剑的两件器，材料与通路不同，收益可以不同；反过来，两件同功用剑也可能形成不同宽厚。器型名称不成为属性固定模板。

## 九、给玩家看的器物详情

普通详情建议按这个顺序：

1. 名称、大类、形态说明；品质和阶位只有正式规则可用时才显示。
2. 本件常驻属性，紧接说明适用范围。
3. 化法的实际修正、绑定条件与当前状态。
4. 获授技能及是否已装配；御器才展开器体与在场灵识。
5. 本件器蕴贡献及已知套系说明。
6. 五行、七档阴阳、耐久/使用状态、制作来源。

进阶的体量、来源效力、共同预算、损耗和取整记录仍在炼制记录页。与旧试炼字段布局相比，这是下一步器物详情调整提案，不声称本轮已改界面。

比较器物时分列常驻、化法、获授技能、器蕴及使用要求，不生成一个把所有效果相加的“战力分”。化法没有合格绑定目标、主动技能没有装配或灵识不足时，明确标示当前不能发挥的部分。

## 十、用现有样方解释成器

以下沿用已经运行的候选结果，不设定新的战斗卡：

| 信息 | 基础成材 | 复合配伍 |
| --- | --- | --- |
| 最终形态 | 宽展薄脊剑 | 修长薄脊剑 |
| 器性 | 和 | 偏阳 |
| 常驻属性 | 物理伤害+6% | 物理防御+1、物理伤害+1% |
| 化法说明 | 无 | 实际应对追加1化解；合格物理攻击忽略2.11%物防 |
| 直施说明 | 无 | 自身护盾+6；基础物伤5 |
| 御使说明 | 无 | 自身护盾+5；基础物伤4 |
| 器体／在场灵识 | 不具备御器能力 | 24／2 |
| 单件器蕴 | 破蕴2层 | 固蕴2层、破蕴2层 |
| 耐久、品质及阶位 | 尚未启用，不补默认值 | 尚未启用，不补默认值 |

复合器物列出的各表达是能力说明，尚不是已审核、已装配的技能。不能把“直施护盾+6、物伤5”直接理解为一次行动同时免费获得两者。

它展示的是不同投入的实际组织方式：专精器物把效力集中在常驻；复合器物需要更多材料和工艺，把功用池拆给多个使用方式。二者不是同等投入的严格平衡对照，正式比较必须控制材料成本与造诣。

## 十一、后续实施顺序

先完成器物静态信息和详情、两项现有常驻属性的装备汇总、化法绑定，再逐个审核并接入获授技能及御器运行态；之后加入器蕴装备汇总。耐久维修与工艺品质分别定案，不阻塞当前炼制验证。

正式装备实现前还需评审装备位数量/同类限制、同技能多来源化法冲突、主动技能模板与取舍，以及常驻与套系的总体预算。本篇提供属性目录和生成原则，不自行修改这些未统一的规则。
