# 前传前期主线规划：单主角修仙起步

> 状态：后续 DLC 候选，当前不进入制作
> 范围：第二世降临此界后，从无修为到正式踏入云息的前期主线。  
> 约束：不新增既有世界观的角色、地名、组织、灾难或玄镜人格；具体剧情内容全部使用“任务槽位”，等待后续确定。  
> 参考方向：取《鬼谷八荒》的“探索—机缘—成长”节奏，以及《觅长生》的“修行准备—资源筹措—构筑战斗”节奏；不复制其具体设定、角色或事件。本文是独立前传 DLC 草案，当前项目主线不依赖它，且当前不进入制作。

## 一、核心定位

前传前期是**线性引导下的单主角修仙开局**：只围绕主角的修行、物资、交易、探索和战斗做选择。

主线的唯一大目标是：

```text
活下来 → 获得修行门径 → 准备入道条件 → 完成云息入门
```

前期结束后，才逐步展开更大的探索、交易网络与据点内容。涤瑕道号、开天及飞升真相全部不在前期揭示。

## 二、玄镜的正确定位

玄镜**没有意识、没有人格、不会对话，也不是主角的伙伴或叙事主体**。它只是第二世主角携带的金手指/器物。

前期只把玄镜做成有限功能入口，功能表现为信息与规则优势，而非替主角做决定：

| 功能方向 | 玩家得到的内容 | 玩家仍要承担的内容 |
|---|---|---|
| 映照 | 物品、地点、敌人或人物的部分隐藏信息 | 如何利用、是否接触、付出什么代价 |
| 推演 | 某个行动的趋势、风险区间或可能条件 | 最终结果、路线、战斗与资源消耗 |
| 记忆 | 已见信息、关系和重要线索的整理 | 判断哪些线索值得投入 |

前期只开放一个最小能力。第二项能力放到前期结束后，避免玄镜过早变成“万能提示器”。

## 三、参考玩法的取法

借鉴的是节奏，不是叙事设定：

| 参考方向 | 要学习的体验 | 在本项目中的实现 |
|---|---|---|
| 《鬼谷八荒》 | 出门探索会遇见机缘、风险与资源机会，角色成长推动可到达范围 | 小区域地图上的地点、事件、采集和探索；主线只引导，不剥夺短期选择 |
| 《觅长生》 | 修行不是点击升级，需要功法、资源、准备和战斗构筑共同支撑 | 研读/修行、物资交易、装备消耗品、手牌战斗与突破准备相互连接 |

前期不做开放世界全图。采用“**主线目标 + 半开放小区域**”：每个主线任务给出一个明确目的，但玩家可以在目的地周边探索、交易、准备或绕开风险。

## 四、前期主线结构

### 任务 0：降临与操作建立

**目标：**让玩家进入第二世，理解主角无修为、玄镜只是随身器物。

**玩法：**

- 基础移动、查看、拾取与时间推进；
- 只给最少的补给/状态压力；
- 第一次展示玄镜界面，但只允许查看，不开放主动能力。

**完成输出：**解锁小区域地图和第一个“寻找修行门径”的主目标。

**剧情槽位：**降临位置、起始身份、第一名接触者、第一处地点，均待确定。

### 任务 1：寻法

**目标：**找到一条可验证的修行门径，而不是直接获得完整强力功法。

**玩法：**

- 主线给出若干线索来源，例如交易消息、地点探索、人物交流或旧物辨识；具体采用哪个来源待定。
- 玩家必须完成一次探索或交易，取得“可研读/可验证”的修行线索。
- 玄镜首次开放一个最小能力，用于识别线索的有效条件或风险，不直接揭示完整答案。

**完成输出：**获得第一份修行内容或明确的获取条件；解锁研读/参悟界面。

**设计原则：**玩家应感觉自己“找到了路”，而不是开局被系统塞进一套完整毕业构筑。

### 任务 2：筹资

**目标：**让玩家理解入道需要准备，交易是修行的一部分。

**玩法：**

- 修行门径提出一项或数项明确的前置需要：可由物资、时间、环境、信息或战斗准备构成，具体条件待功法专题确认。
- 玩家在小区域内选择一种主要手段完成准备：采集/探索、交易/委托、或战斗获取。
- 第一个市场只提供少量物品、有限库存与明确价格；至少有一件物资既可卖出，也可留作入道准备。

**完成输出：**完成第一次“卖、买、留”的资源取舍，并获得入道所需的准备条件。

**设计原则：**不做复杂市场模拟；用一次真实的资源取舍证明交易和修行相互关联。

### 任务 3：历练

**目标：**让玩家用战斗检验准备，并取得入道前的关键结果。

**玩法：**

- 一次主线历练地点，包含移动、环境、敌对遭遇和可撤离出口。
- 教学现有手牌战斗的最小闭环：抽牌、资源、移动牌、攻击/防御、结束回合。
- 战斗目标不强制写死为击杀；可以是取得物品、到达位置、脱离区域等，具体情境待定。
- 允许撤离。撤离、胜利、失败都记录不同的资源/伤势/线索结果，但不会让主线卡死。

**完成输出：**取得入道的最后条件，或取得能够换取该条件的资源与信息。

**设计原则：**战斗应是高价值机会的门槛，不是重复刷怪；第一次就让玩家知道“准备不足可以撤”。

### 任务 4：入道

**目标：**完成正式修行，进入云息一层。

**玩法：**

- 研读或参悟第一份主修内容；
- 在满足已展示条件的地点/时机开始修行；
- 玄镜提供一次有限的信息优势，例如显示当前条件是否满足，不直接替代修行结果；
- 修行完成后，装配第一批可用牌或基础能力。

**完成输出：**主角进入云息一层；解锁“修行—探索—交易—历练”的可重复循环。

**叙事作用：**前期到这里结束。玩家此时只是刚入道的修士，尚未拥有道号、势力或开天目标。

## 五、前期循环

主线任务之间允许玩家短暂自由活动，但循环保持简单：

```text
查看主线目标
  → 探索 / 交易 / 接取一项小委托
  → 获得物资、信息或战斗机会
  → 研读、修行、调整装备或牌组
  → 前往下一主线地点
```

每次循环只消耗和产出少量东西，避免前期同时引入组织经营、复杂关系网、建设树和多队管理。

## 六、最小内容清单

前期纵切片只需要以下内容，且每项都服务上述五个任务：

| 类别 | 最小需求 |
|---|---|
| 可控角色 | 一个第二世主角；无多角色队伍管理 |
| 区域 | 一个半开放小区域、一个安全落脚点、一个市场、一个历练地点 |
| 玄镜 | 一个无人格的映照/推演功能与信息记录页 |
| 交易 | 三至五种货物、有限库存、一次买卖取舍、一个轻量委托 |
| 战斗 | 一套基础技能库、一场可撤离遭遇、明确的资源与伤势反馈 |
| 修行 | 第一份修行内容、一次研读/参悟、云息一层解锁 |
| 持久化 | 主线任务状态、物品、伤势、玄镜已知信息、前传标记 |

## 七、明确不做

- 玄镜说话、表达情感、替玩家判断，或被写成同行角色；
- 前期直接获得涤瑕道号、接触开天或飞升真相；
- 组织治理、多人角色管理、跨地点据点经营；
- 大世界全图、全部修炼流派、玄基以上内容；
- 为了主线而强制玩家反复刷资源或打必胜战斗。

## 八、下一步：先定任务内容，不先写大剧情

进入具体策划前，只需由项目决定以下四个任务槽位：

1. `寻法`：第一份修行线索的来源类型；
2. `筹资`：入道前需要玩家准备的具体条件；
3. `历练`：第一场战斗的目标类型；
4. `入道`：第一份主修内容与云息一层的表现。

这四项确认后，再为每项补人物、地点、对白和任务文本；在此之前不继续添加世界观设定。
