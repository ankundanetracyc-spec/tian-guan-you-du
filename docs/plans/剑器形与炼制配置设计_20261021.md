## 一、现行来源与覆盖范围

| 内容 | 来源与本轮口径 |
| --- | --- |
| 剑器形 | 用户确认细身剑、阔刃剑、厚脊剑。按形制表达性能方向，不预设攻击剑、防御剑等互斥用途。 |
| 法宝战斗参与 | 用户确认器蕴、直接属性、化法、主动技能可以组合。主动技能可以直接施展，也可以召出御使；技能和化法可都有、都无或只有其中一项。 |
| 功用与方法 | 最多两项功用；同一功用可以采用多种炼制方法。方法越多，材料与工艺要求越高，同等投入下效力越分散。 |
| 材料 | [物品词缀系统设计](物品词缀系统设计.md)。五行、质地、功用、相性、品阶各有职责；当前质地为纤维、致密、颗粒、黏胶、液体、气体。材料品阶不换算法宝品级。 |
| 战斗底座 | [即时队列战斗系统设计](即时队列战斗系统设计.md)、[战斗构筑与三资源系统](design-plan.md)。沿用技能栏、队列与体力／法力／在场灵识，不增加战斗资源、射程或位移。 |
| 既有实现 | [炼器制作闭环与战斗接入设计第十二节](炼器制作闭环与战斗接入设计_20261016.md#十二法器战斗接入首版用户批准的实施规格)描述旧双剑测试接入。它是已有实现记录，不代表本篇新制作设计已经实现。 |

下列旧制作口径由本轮用户方向替换：一器一功用、内炼与外祭互斥、所有器形固定同一套单槽材料结构、炼前显示完整成品结果、阴阳必须接近中和，以及由鸣锋／守锋名称预定用途。测试样本的既有行为仍保持，迁移另行实施。

本篇不把此前讨论中尚未确认的器蕴层数、崩解后其他收益是否保留等建议当成已定规则；相关待决项见第十三节。

## 二、三种形制及其取舍

| 器形 | 形制 | 设计侧重 | 代价与边界 |
| --- | --- | --- | --- |
| 细身剑 | 剑身狭长、结构轻简 | 以较简单的结构集中发挥一项功用，适合投入较少的专精配置 | 复合方法的承载空间较小；不是自动减体力、减法力或加行动速度。 |
| 阔刃剑 | 主体与刃面分工清楚，剑身较宽 | 更擅长把投入转化为直接攻伐强度 | 主体与刃面需要分别用料；优势只作用于明确的攻伐方法，不能扩展为所有效果统一增强。 |
| 厚脊剑 | 剑身与剑脊分工，骨架厚实 | 更擅长组织多种方法与复合功用 | 结构投入更多；同等总投入下不应同时取得最强单项攻伐与最大复合承载。 |

三者都可以采用合规的常驻、化法、直接施展和御器方法。所有形制都受最多两项功用限制；结构简单不等于只能单功用，结构复杂也不自动获得第二功用。

不采用细身→阔刃→厚脊的全面升级关系。需要用同等总投入的样方比较专精强度、可容纳配置和材料成本，确保三者长期有用途。

## 三、图谱的动态槽位

### 3.1 身材部件

以下作为本轮默认图谱草案。实际份数需要另填，不能把一个部件槽解释为固定一份材料。

| 图谱 | 必填身材槽 | 部件职责 |
| --- | --- | --- |
| 细身剑 | 剑身、承接 | 剑身完成主体与刃部；承接完成握持与连接。 |
| 阔刃剑 | 主体、刃面、承接 | 主体支撑结构，刃面承担图谱规定的加工与功用导出要求，承接连接整器。 |
| 厚脊剑 | 剑身、剑脊、承接 | 剑身承担器物主体，剑脊提供复合工艺需要的结构支撑，承接连接整器。 |

刃面槽、剑脊槽不能互换；仅材料份数相同也不视为同一个图谱。以后新增剑形时，可以另定部件与数量，不受本表固定二槽／三槽限制。

### 3.2 灵性材料与燃料

| 岗位 | 本轮草案 | 规则 |
| --- | --- | --- |
| 质材 | 每份基础图谱一个根材槽 | 确立根性并支撑已选功用；不因承担两项功用就按满额重复计入。 |
| 性材 | 最多两个功用来源位置 | 第二功用可选；每项从对应投料中选一个已有功用。多份同类材料可以供给同一项功用，但不会扩展为第三功用。 |
| 和材 | 由图谱与方法声明所需位置 | 可选调和与方法必需投入要区分。位置数量、可处理支路和份数待定，不设置全局固定上限作为已定规则。 |
| 燃料 | 按本次方法组合列出需求 | 首轮候选已指定松心炭底火与地脉焰炭催火；具体供热和份数见试算方案，尚非正式平衡表。 |

第一项性材是否允许省略、仅制成具有基础属性与器蕴的剑，尚待定。当前至少支持：选定功用全部用于常驻收益，从而没有技能、也没有化法。

添加方法只能启用图谱明确预留的辅助位置。图谱没有可用位置时不能自动新增无限和材或身材槽。

### 3.3 投料与消耗

每槽分别保存材料选择、用途、所需份数与实际分配份数。部件完成数与材料份数分别展示；必要部件不能因为造诣低而被省略。

同一份实物不能同时支付两个槽。建议允许同种物品的不同份数分别投放，按物品合并核对总库存；这不等于把一份性材的效力算两次。正式扣料需要配方份数和库存事务定案后接入。

## 四、材料准入与候选

“五行金”不等于物理上的金属，“致密”也不保证能加工成剑身。部件要有明确的成形要求，材料要有可核对的加工适用说明；这些判定不能依靠名称、旧材类兼容字段或材评高低自动推断。

| 部件或岗位 | 要求如何写 | 不采用的判断 |
| --- | --- | --- |
| 剑身／主体 | 能完成该图谱要求的实体结构与加工；明确材料条件 | 所有致密材料自动可用；所有金行材料自动可用。 |
| 刃面 | 能满足刃部成形及该方法的导出条件 | 名称有“裂甲”就能作刃面。 |
| 剑脊 | 能完成图谱规定的支撑与复合工艺 | 单纯多交矿石就无上限增加承载。 |
| 承接 | 能连接所选部件并满足已选工艺 | 任意木类、液体或胶状材料都能独立作柄。 |
| 质／性／和材 | 按该岗位读取五行、相性、选定功用及方法明确条件 | 其他材料功用自动成为战斗效果。 |

核对现有资源后的候选如下。这里只说明可研究用途，不构成已批准配方、加工白名单或强度表。

| 现有材料 | 已有性质 | 可研究的投入位置 |
| --- | --- | --- |
| 玄铁 | 金行、致密，带固结 | 剑身／主体／剑脊的成形候选；也可用独立份数作固结性材。 |
| 铜髓矿 | 金行、致密，带固结 | 结构与质材候选；需先定义如何完成对应加工。 |
| 青木芯 | 木行、致密，带疏通、生发 | 承接候选；作为性材时必须另占投料并明确选择功用。 |
| 裂甲石 | 金行、致密，带破障 | 破障性材候选；不能据此判为可用剑身或刃面。 |
| 风纹石英 | 金行、致密，带疏通 | 疏通性材、质材或调和候选；不能把旧晶类兼容字段当作公开质地。 |

当前材料资源的相性数值尚不是完整七档实现。不得把旧数值直接带入新阴阳公式；先完成七档映射与参与规则定案。

## 五、功用与炼制方法

### 5.1 分开决定“做什么”与“如何发挥”

每项性材明确选定一个功用，同一功用下可添加多个已掌握的方法。方法需要同时检查器形支持、材料、结构、造诣和最低效力，不做整件剑的化法式／御器式单选。

| 方法类别 | 获得的内容 | 主要独立条件 |
| --- | --- | --- |
| 常驻发挥 | 额外属性或明确被动 | 持续生效方式、适用战斗属性、强度上限。 |
| 附加化法 | 对合规技能的追加或改写 | 技能类别、真实关键词、必要的出手方式，以及追加时点。 |
| 直接施展 | 可装配主动技能 | 自己的费用、目标、效果、限次与冷却。 |
| 召出御使 | 可装配御器技能 | 召唤与御使各自费用、器体、在场灵识、御使效果与离场处理。 |

常驻、化法、直接施展、召出御使之间没有全局互斥。每个具体方法最多添加一次，不能靠重复添加同一个条目复制能力。需要多个独立技能或多个化法目标时，必须有对应工艺与投入规定。

### 5.2 首轮验证内容

首轮建议用已有测试验证过语义的破障、固结完成方法组合，不把三种形制分别绑定某项功用。疏通等其余功用先记录候选，待战斗语义明确后逐项开放。

| 功用 | 本轮研究方向 | 当前边界 |
| --- | --- | --- |
| 破障 | 合规攻伐技能的物防穿透化法、直接攻伐、御器攻伐 | 穿透只修正该次明确的物防计算；正式方法的目标、费用、伤害与倍率未定。常驻穿透若要支持，另定作用范围，不能自动强化所有攻击。 |
| 固结 | 明确防护属性的常驻强化、实际应对时的化解追加、直接护持或御使护持 | 未触发应对不追加化解；不能把物防、化解与护盾视为同一数值池随意兑换。具体方法未定。 |

上表是方法设计范围，不是新增卡牌效果正文，也不授予当前角色任何技能。不能把旧样本的穿透、器体、伤害、护盾与费用照填为正式值。

化法的关键词门槛需要逐方法选择真实、已定义的关键词；近身／远程单列为出手方式。不得为适配法宝，临时给技能加“剑”“攻击”等未定关键词。最终接入前须按卡牌流程完善技能全文、词典与验证。

## 六、承载与效力分配

### 6.1 两类限制

器身承载限制方法组合能否成立；每项功用的有效供给限制这项功用能分配多少强度。整器对两项功用的支撑也要分配，不能把同一质材满额复制给两个分支。

材料改善首先改变对应部位或对应功用的上限，不自动改善其他位置。燃料与和材处理各自明确的条件，不充当万能输出材料。

### 6.2 主次设置

两项功用可选主用／兼用或并重。功用内部的方法可选主用／兼用；系统先满足所有方法的最低投入，再按明确配置分配剩余效力。分配规则与系数尚待校准，不在首版提供任意百分比滑杆。

若最低投入总需求已超出供给，改变主次不能使配置合法，必须改善材料与配伍或减少方法。强度不足时不得静默取消方法、删掉一个技能或改成另一种功用。

器物成形的基础属性与功用产生的额外收益分开核算。新增方法不会凭空使实体结构消失，但分给常驻强化的效力减少后，相关额外属性会降低。

### 6.3 形制倾向如何起作用

细身剑的优势是较简单的结构投入与专精配置；阔刃剑的优势落实到明确攻伐方法的效力转化；厚脊剑的优势落实到复合结构承载。它们不是新增玩家战斗属性，不能自动解释为攻击力、暴击、攻速、射程或位移加成。

必须比较同等总材料投入，而不是只比较相同性材。阔刃、厚脊额外部件所耗材料也计入成本；任何形制都不能在所有方案上全面优于其他形制。

### 6.4 成器锁定

方法组合、材料投入和主次分配在成器时固定。战前不装某个主动技能、未绑定某项化法，或战中御器失败，都不会把预留效力返还给其他能力。改变法宝配置属于后续重炼规则，不以战前勾选免费完成。

## 七、五行、阴阳与器蕴

五行围绕根材与每项性材分别判断，显示实际材料与调和路径。相克关系需要明确有效的处理方式；不能只检查有无和材，更不能一份和材默认覆盖全部支路。桥材方向、无行与多行情况、材料复用范围尚待补表。

阴阳保留七档：**至阴、阴、偏阴、和、偏阳、阳、至阳**。质材主导、其他岗位如何参与、有效份数与权重需要统一参数表；燃料不默认直接贡献阴阳。器形不把极阴／极阳标成错误，也不按阴阳强制选择化法或御器。

器蕴按整件剑形成，和部件数量、方法数量分开。首轮试算方案提出锋锐／凝固、每件一层、两档奖励的完整候选，并验证阈值与撤装重算；这些新提案未自动成为已确认效果，不写入正式角色。

图谱至少要预留：整器器蕴判定条件、材料来源说明、装备贡献与撤销方式。相同器蕴不能因剑身、刃面、承接分别计数而重复累计。

## 八、造诣与技术学习

造诣决定学习和运用工艺的资格；具体图谱、方法仍需掌握。三种剑不是按造诣顺序全面替代，四类方法也不形成常驻低级、御器高级的单一路线。

| 学习方向 | 开放的工艺空间 | 不直接给予 |
| --- | --- | --- |
| 器形加工 | 完成对应部件和材料加工 | 无条件省去必填部件。 |
| 方法掌握 | 选用具体常驻、化法、直接或御器方法 | 自动学会所有剑的主动技能。 |
| 同功复合 | 同一功用组织多种方法 | 多个方法各自取得完整强度。 |
| 双功组织 | 同时组织两项功用并确定主次 | 第三项功用。 |
| 配伍与调候 | 处理特定五行路径和阴阳条件 | 所有冲突自动消失。 |

造诣对加工损失的改善须有上限，不能突破材料供给与结构承载。门槛、学习来源、实践奖励与熟练衰减待校准，不使用炼丹现有门槛数字替代。

成器结果固定在实例上，持有者的炼器造诣不会重新计算它的数值。制造资格与装备、技能装配、在场灵识资格分别检查。

## 九、战斗接入边界

法宝装备本身不统一占技能槽。常驻属性和器蕴按装备关系处理；化法战前选择合法目标技能，局内随该技能生效；主动技能由玩家装入技能槽并排队使用。

一个御器技能内的召唤／御使共用技能身份与槽位，每次各占行动位。法宝如提供不同独立主动技能，各自装配与占位；不得由旧实现“同实例只能装一槽”推断新设计禁止多个独立授予技能，正式接口迁移另列任务。

召唤成功才检查并占用在场灵识，检查包含其他持续实体；御使不重复占用。直接施展不会自动召出；使用化法技能不会顺便结算御器；没有新增实体时不额外占灵识。

化法保留秘籍化法的已有结果，按明确追加规则组合；不修改共享技能资源。旧测试允许绑定的具体技能名单不直接作为新化法的通用准入表。

崩解后装备属性、器蕴、化法及其他独立技能是否继续存在，以及哪些条目明确依赖器体在场，需要单独定案。当前旧样本的本场禁用处理不自动推广到新四类收益。

## 十、界面与操作

视觉沿用炼丹的纸墨、低饱和青绿与铜饰，布局采用剑器形图谱驱动。中央为长案、器坯夹具、侧向火槽与淬洗位置；不复用丹炉主体，不把所有材料画成投进一个鼎中。

### 10.1 结构与投料

- 左上固定器形选择；左下按当前图谱展开真实部件和材料位，分组可折叠、独立滚动。
- 中央结构图随细身／阔刃／厚脊切换；点击剑身、刃面、剑脊或承接，与左侧对应材料槽联动。
- 必填、可选、技术未掌握分别标记；必填完成数不混入可选空位，材料份数单列。

### 10.2 功用与方法

每项已选功用显示来源、整器主次、已添加方法和新增入口；方法可共存。选中方法显示已知资格、材料与承载要求，以及与现有方法共同分配效力的提示。

添加方法先说明新增需求，再更新投料页；不能自动替换材料。删除方法解除对应需求并保留材料选择草稿，不把不再需要的材料偷偷算入最终扣料。

右侧统一显示待补项目、当前可核对的耗时／精力／实际扣料与开炼按钮。缺项可直接定位，不重复放成品属性或大幅成品轮廓。费用与耗时未定案时正式开炼不可用，不能用零值伪装。

### 10.3 切换与记录

各器形保留独立未扣料草稿。切换图谱不能静默把刃面材料变成剑脊材料；转用材料需逐槽验证并由玩家选择。全部草稿不共同锁定或消耗真实库存，开炼仅核对当前配置。

成器后保存图谱、投料份数、功用、方法、主次及完整结果。配方记录可回看和再次填料，但材料变化后不冒充原配方的已知成品。

## 十一、首轮比较样方

下表是验证场景，不是可执行配方；所有方法必须先补齐完整效果、费用、条件与参数。

| 场景 | 配置 | 需要验证的取舍 |
| --- | --- | --- |
| 专精比较 | 三种剑各做单破障、单化法 | 同等总投入下，简单结构与形制转化各有用途；不能都由厚脊全面胜出。 |
| 攻伐比较 | 三种剑各做单破障、直接施展 | 阔刃的攻伐优势成立，同时计入刃面投入，不额外免战斗费用。 |
| 同功复合 | 破障化法＋破障直接施展／御器 | 增加方法提高要求并分散同一功用效力；不使用其中一项也不返还。 |
| 双功复合 | 两项合法功用，各采用一项方法 | 两份来源分别校验，共用支撑不重复计入；厚脊有承载价值。 |
| 常驻与技能并存 | 固结常驻＋化法／主动护持候选 | 常驻强化参与分配，基础结构单独保留；物防、化解、护盾不等值兑换。 |
| 无主动能力 | 只采用常驻方法 | 无需主动技能槽，仍可参与装备属性和整器器蕴。 |
| 承载不足 | 合法方法分别成立、组合后超载 | 明确指出结构问题，不通过补任意燃料放行。 |
| 效力不足 | 材料性质满足但无法支付各方法最低投入 | 调整主次不能伪造合法能力，不静默删除方法。 |

## 十二、参数落地与验收顺序

1. 补三份图谱：部件准入、每槽份数范围、根材与性材位置、辅助位与燃料位置。
2. 补材料加工与供给表：来源必须有真实物品；同份投料不跨岗重复扣用；材评不直接换算法宝品级。
3. 补方法全文：适用器形与功用、学习资格、必要材料、结构负担、最低效力、强度曲线与战斗规则。
4. 补承载与分配参数，用第十一节场景比较同等总成本，不把测试样本当公式。
5. 补造诣学习节奏、七档阴阳参与规则、五行路径表与器蕴规则。
6. 参数获确认后再实施材料输入、结果计算、技能生成与存档迁移；正式开放前补制作、装备、战斗回传闭环验收。
