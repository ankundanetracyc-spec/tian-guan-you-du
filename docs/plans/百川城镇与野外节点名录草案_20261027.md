## 七、命名取意与既有名称

背景设定已有云梦泽及其相柳毒瘴含义；本稿取其古典山川命名气质，新湖泽采用涵虚泽，不另复制一处云梦泽。一般城镇也保留生活感，不把所有地名堆成“仙灵玄”。

| 流丹坊 | 王勃《滕王阁序》“飞阁流丹”：[原文](https://zh.wikisource.org/zh-hans/滕王阁序) |
| 溪云城 | 许浑《咸阳城东楼》“溪云初起日沈阁”：[原文](https://zh.wikisource.org/wiki/咸陽城東樓) |

## 八、迁移边界

白石城仍沿用原白石镇的地点身份 white_stone_town，澜浦渡仍是 lanpu_ferry，不将城市或渡口 ID 直接改成宗门。镇岳观核对已有 fulan_temple；新增山门与资源地要独立身份。

本轮补三大近域、修订规划、关系表、数据和图稿，运行时、人口、旅行、材料数值和美术未随之实施。旧按十二辖域分组与四大领地合并的资料只作迁移线索。
