# 材料与过程量驱动炼器设计

> 2026-10-22，当前炼器规划入口。用户确认：只选择剑等法宝大类；不先选细分器型、不先选打造方向，由材料等过程量决定最终功用、属性与器型。
> 最新修订：器物本身不需要功用字段。材料功用只参与炼制推导与追溯；成器直接记录属性、化法、技能、器蕴及自身信息。下文原“成品功用”的表述按历史推导概念理解，不再作为成器字段。当前试炼仍有旧分组，后续实施同步调整。
> 本篇覆盖2026-10-21方案中的“预选三种剑形、预选成品功用，再分配投料”。旧数值模型、样方及界面转为历史试炼，不能只换名称便作为新模型。正式平衡未定，不生成正式装备或战斗技能。

> 当前候选实现：[试炼与器物信息](炼器新模型试炼与器物信息设计_20261022.md)。用户要求成熟设计并接入测试后，岗位分账、连续器形与收益分配已有独立可运行模型；具体材料档案、门槛与数值均为试炼候选，不冒充正式定案。结构依据见[过程推导细案](炼器过程量与成器推导细案_20261022.md)。

## 一、已确认的输入与输出

最新等级补充：法器之前增加凡器，只有基础属性加成。每类器物另有由本体形成的专属属性，剑拟名锋锐，表示用剑物理攻伐的物防忽略能力；凡器同样具有这项基础性能。见[凡器与专属属性设计](凡器与器类专属属性设计_20261022.md)。

器物等级已确认采用法器、法宝、灵宝、道器四大阶，各分下品、中品、上品、极品；大阶差距很大，高阶另有加成。先设计[法器阶段](法器阶段设计_20261022.md)，其中具体材料/工艺门槛仍属候选，尚未改试炼。

最新材料→成器效果提案：[材料到器物效果生成设计](材料到器物效果生成设计_20261022.md)。以常驻数值、剑关键词修正、事件附带效果与定向化法解释实际材料的去向；新通路及分配尚未实施，不以旧试炼的两功用分组作为最终器物结构。

器物属性与使用信息的配套提案见[器物属性与装备收益规划](器物属性与装备收益规划_20261022.md)：区分本体属性、装备收益、战斗运行态，补齐品质、耐久、器蕴贡献与玩家详情结构；新增规则尚未实装。

玩家先选择法宝大类，例如剑、甲、鼎。当前先研究剑，不表示其他大类的岗位已定案。

玩家配置材料及炼制过程，最终功用、属性和具体器型由过程结果形成。玩家可以有目的地安排投入，但不直接勾选“破障剑”“固结剑”，也不先选“细身剑”“阔刃剑”“厚脊剑”作为固定配方。

```text
法宝大类：剑
  → 材料性质、实际份数、配伍与炼制过程
  → 各岗位实际发挥的过程量
  → 最终功用、属性及器型
```

过程量是炼制计算的中间状态，不是材料物品上新增的词缀。“过程”也不自动等于增加实时小游戏。

## 二、延续的规则

- 最新确认：器物自身属性主要由身材等形成，给予角色的收益主要由性材等形成；器身须满足能力层次要求，不能以低级身材无限堆量承载高级能力。材料整体品级与对应功用品级越高，分别提升相应本体潜力与效果潜力，具体曲线及门槛待标定。

- 材料功用不原样复制为成器字段。原“成品最多两项功用”不再作为成器属性结构约束；实际收益的数量与预算另行校准，不机械转成两个技能或两条属性。
- 五行生克、阴阳七档继续参与；至阴、至阳可以是正常方向，不要求归和。
- 材料五行、质地、相性、功用、品阶各有职责；金行或致密不能单独证明加工适用，材料品阶不直接换算法宝品级。
- 器蕴、常驻属性、化法、主动技能仍为可能的法宝收益；技能与化法可并存、单独存在或均不存在。具体如何由新过程产生须继续规定。
- 组合更多收益需要承担材料、工艺与分配要求；同一投入不能免费重复计算。旧模型的具体负荷、费用和效力公式不自动沿用。
- 齐边矩形水墨风格保留。开炼前显示投入与工艺条件，成器后揭示最终功用、属性和器型。

## 三、推导框架提案，尚非已定公式

建议追踪材料经过加工后实际留下的有效贡献，不以材料名称直接查询固定成品。

| 输出 | 需要解释的中间依据 | 不直接采用的替代 |
| --- | --- | --- |
| 功用 | 材料在岗位中的有效贡献、配伍和过程保留 | 玩家预选成品功用；所有材料功用自动生效 |
| 属性 | 成器功用强度、结构支撑与实际分配 | 多一种材料即额外获得一套满额效果 |
| 器型 | 实际成形结构、有效身材与工艺结果 | 先选三器型之一，再套固定部件表 |
| 阴阳与五行 | 有效参与的材料及过程关系 | 强制归和；燃料自动按性材计入效果 |
| 收益表达方式 | 尚待规定的工艺与承载条件 | 默认内炼／外祭互斥；直接把旧方法开关当作新规则 |

中间量名称、单位、权重、主副功用提取、最低成器条件、器型边界和冲突处理均待设计。本表的解释性用语不直接成为物品或战斗的新属性。

器型可以有直观形态描述，但不是开局必选的细分分类。旧“细身、阔刃、厚脊”可作表现参考，不据此认定新案仍只有三个离散结果。

## 四、界面与样例改动

左侧原三器形选择应改为法宝大类。岗位与材料位置按大类及工艺需求规划，具体开放规则待定，不继续按三套预选器型保存互斥配方。

原“破障／固结”成品功用开关不能继续决定输出。可展示材料的有效投入、配伍障碍、供热与缺项；不能将这些中间状态直接包装为已确定的成品答案。

新完整样例按“选择剑 → 投入材料 → 安排过程并检查中间状态 → 开炼 → 揭示结果及其材料／工艺依据”展开。不能预写“破障化法＋固结御使”的答案，再反向填满材料槽。

本轮制作中的“厚脊双功”样例基于旧模型，转为留档。其11时辰、22精力、12%穿防、5护盾不属于本篇的新模型结果。旧截图与报告仅用于回看旧方案，不代表新流程已实现。

## 五、后续待定接口

1. 材料在各岗位经过工艺后如何形成过程量。
2. 如何从中间量产生至多两项功用，以及弱项、主副、冲突和阈值处理。
3. 如何确定属性及器型，避免材料总份数一项包办全部结果。
4. 常驻、化法、直施、御使分别由哪些工艺条件形成，玩家安排哪些过程；不默认延续旧成品方法开关。
5. 哪些中间状态向玩家公开，哪些结果只在成器后揭示；数值、失败与消耗一起校核。

本篇记录已确认的因果关系与正式待定接口。候选阈值及器物信息模型已在配套试炼篇单独列明并实现；不迁移正式存档，不修改旧双剑战斗定义。
