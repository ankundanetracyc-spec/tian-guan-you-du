# 开始界面修行百科设计

> 状态：现行首版；百科只读，不改变角色成长、战斗状态、资源或解锁进度。

## 目标

玩家可在开始界面、进入存档前查阅战斗 Buff／状态和物品资料。百科不依赖已载入的角色或存档；进入旅程后通过开始界面返回即可再次查阅。游戏内“见闻”继续记录经历、传闻、人物和任务。

## 入口与界面

- 开始界面提供“修行百科”入口，位于新建旅程、载入旅程等主菜单选项中。
- 打开后以全屏宣纸卷轴面板展示，只保留“Buff”和“物品”两类。
- 左侧目录以图标、名称和简要分类展示词条，右侧展示选中词条的大图标与资料；搜索匹配名称、分类和说明。
- 面板支持收卷按钮与 Escape 返回；打开时覆盖开始界面，关闭后回到开始界面。
- 视觉沿用见闻卷轴的暖纸、墨色和浅金风格，确保长说明可滚动阅读。

## 收录与来源

### 收录边界

不在百科中收录功法卷章和主动招式；秘籍若作为物品存在，只在“物品”类显示其物品图标和物品资料。

### Buff

运行时扫描 `resources/battle/statuses/` 下的战斗状态资源，显示状态图标、增益／负面分类、叠加上限和效果说明。常驻心法被动也按 Buff 词条展示图标、来源和效果；气血、血炉、护盾等公共战斗资源作为独立词条纳入。百科统一读取状态专属图标；不在血条状态栏显示的内部机制状态仍保留百科词条和图标，缺少专属图标时使用统一水墨图标。

### 物品

运行时扫描 `resources/entities/items/` 下的物品资源，显示物品图标、名称、类别、已有词缀、堆叠与使用范围；存在战斗技能数据的物品同时显示其战斗效果。普通材料显示由材性计算出的材料品阶与材评，并在每个“功用”词缀后显示该功用自己的品级；秘籍不显示物品品阶，只显示其对应修习境界。没有专属物品图标时使用通用占位图标，不隐藏物品。

## 内容边界

- 百科是信息面板，不设置收藏、解锁、奖励或教学事件。
- 图标和资料从现有状态、心法与物品资源读取；UI 素材只用于分类标识、缺图占位和缺少专属图标的状态，不覆盖资源自身图标。
- 后续扩展其他资料时另行确认范围，不自动加入本版百科。

## 首版验收

1. 未新建或载入存档时，可从开始界面打开百科；Escape 与收卷按钮都能关闭并返回开始界面。
2. Buff 与物品两类可切换并搜索，目录行和详情区都展示对应图标。
3. 状态、常驻心法和气血、血炉、护盾等公共战斗资源均有对应 Buff 词条。
4. 普通材料的功用词缀显示各自品级；秘籍不出现物品品阶字段，只显示功法配置中的对应境界。
5. 物品词条读取现有图标与物品数据；缺少图标的资源使用通用占位图。
6. 百科目录与词条在没有已载入角色和存档时仍可正常显示；见闻内容和入口保持原用途。
