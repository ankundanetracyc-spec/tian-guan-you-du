## 一、确定的主干

1. 行囊保存器物，装备决定哪些合法收益生效；衣、剑、甲、珠等统一管理，不另建常规穿戴与法宝两套收益栏。装备本身不占灵识。
2. 御用指器体召出在场；御使指执行一次具体指令。未在场不默认使用本体锋锐等属性。
3. 身材主要贡献器体等本体，性材主要贡献角色收益；各岗位有真实交叉贡献，但同一潜力分账守恒。
4. 器物可同时或分别具有基础加成、常驻效能、化法、主动技能与器蕴。不设置成器功用字段，不强制最多两条，不恢复内炼/外祭互斥分类。
5. 可御用器物的御用入口占一个现有技能位置：未在场用于召出，在场后同槽变为其在场技能。
6. 在场持续占D；主动器物技能/主动借器施法临时占T，结束归还；化法不额外占灵识。D、T与其他真实占用共用一份容量。
7. 成套剑器是一个器物实例，多柄是其构成与表现。整套只提供实际形成的一份收益/器蕴；成套御用通常灵识要求极高。
8. 相同器物合并同化为一套是后续方向，兼容性、投入消耗与结果公式尚未定案。

## 二、三层数据和生命周期

| 层 | 记录内容 | 保存边界 |
| --- | --- | --- |
| 固定器物 | 身份、名称/图标、类别、形态、器阶、阴阳、本体、收益、技能模板、器蕴贡献、炼制来源与版本 | 成器后固定，不因打开页面重新结算 |
| 人物配置 | 持有实例、装备引用、一个化法对象、十个技能位置的来源引用 | 局外配置随人物保存；不复制物品 |
| 单场状态 | 未召出/在场/崩解/离场、器体、分体状态、D、技能次数与冷却、当前施法T | 战斗建立和清理；不写成永久物品状态 |

同名不同实例不能混淆，同一实例不能被多个来源重复计算。装备布局现为武器1、护具1、器物2；多器收益与同类并用的执行后端仍须逐步接入，不能用旧法宝位代替新规则。

器物不新增整器五行字段、不补“无属性”字段；材料五行继续影响炼制配伍。阴阳七档保留。长期耐久不是器体，维护方案未定前不填虚构耐久数值。

## 三、器物详情如何组织

| 区块 | 显示内容 | 说明 |
| --- | --- | --- |
| 身份 | 图标、名称、类别、实际器阶与形态、阴阳 | 不凭名字赋予属性 |
| 本体 | 器体、锋锐；成套按实际结构显示总量/分体 | 属于在场器物，不混成人物属性 |
| 基础加成 | 已形成的固定值角色属性 | 普通词条优先固定值，不默认生成物伤百分比 |
| 器物效能 | 条件修正、合法触发 | 文案明确“带有‘剑’关键词的技能”等真实条件 |
| 化法 | 一个集中区块、共同适用条件、各项修正 | 只绑定一个技能，不另收T |
| 技能 | 御用/在场两态或独立直施型能力；对应目标、费用、D/T、限次/冷却 | 首版一对一同槽变换，多在场技能共槽方式另定 |
| 器蕴 | 本件蕴种及贡献，公共激活效果可展开 | 不把全身累计冒充单件固定属性 |

只显示实际存在的内容，不为没有御器能力的器物补器体0、占用0等行。技能模板尚未装配的试炼描述须如实标明，不能因有描述就成为可排队技能。运行版仍有旧参数时不得只替换百分号伪称固定值已实现。

## 四、从炼器到战斗的完整流程

1. 玩家选择剑等大类，投入身/质/性/和材料及份数。无燃料，不预选最终细器形；炼前只显示客观过程与用度，不提示成品或达标走向。
2. 公共材性与加工公式分配本体、角色收益、工艺、能力及器蕴潜力，生成并保存成器结果。
3. 成器先成为人物行囊中的唯一实例；正式入包需要真实扣料/精力/时间的事务闭环，不能把试演材料变成正式产出。
4. 人物装备器物，提供合法角色收益与器蕴贡献，但不自动占技能位或召出本体。
5. 玩家可绑定化法；要御用该器物时，将其御用入口放入十个位置之一，不自动挤掉其他技能。
6. 战斗中首次执行召出，成功后建立器体及D，同槽显示在场技能；之后每次施放检查T与其他费用，结束释放T。
7. 器体离场释放D；战斗结束清理运行态，保留人物持有与配置。器体崩解对独立装备收益的影响仍待定。

普通直施型器物能力不强制先召出，其模板若不要求在场则只按主动施法规则；不得借此默认读取未在场本体属性。凡器普通持用与零灵识人物本体性能的关系仍需单独确认。

## 五、技能槽变换与队列意图

槽位保存器物来源，显示随运行态变化；变换不新建永久技能，不刷新次数/冷却、不占第二个位置。

规划时可多次把同一入口排队。示意：

```text
行动1：该器物〔召出〕
行动2：普通技能
行动3：该器物〔在场施法〕
行动4：该器物〔在场施法〕
```

每项各占一次行动。预演考虑前序可能成功建立的在场状态，重排后重算分支、目标与费用。确认队列后锁定意图；实际召出失败，后续在场施法不会改成召唤，也不免费补行动。

悬停、槽位、队列要分别展示当前分支或该项锁定分支。例如槽位已经变为在场技能，前面已完成召出项的记录仍显示召出，不能被统一改名造成历史混淆。

限次与冷却按原模板和分支管理，不因图标变换重置。召出不默认消耗御使次数或启动其冷却；独立技能有无额外限制需模板明示。失去装备来源清空相应技能位置，其他位置不前移，秘籍化法保留。

## 六、灵识提交与释放

```text
已用 = Σ在场持续D + Σ当前尚未结束的施法T + 其他真实占用O
本次可用 = max(0, 上限S - 已用)
```

普通装备、纯化法没有新增占用。多个连续行动各自在开始时提交T、结束归还，不把一轮所有T永久加在一起。若有真实嵌套执行，外层尚未结束的T必须保留，不让同一份容量同时被使用两次。

执行前校验来源、在场要求、目标、容量、体力/法力、次数/冷却。全部通过再提交本次费用及T；未通过则沿当前失败规则处理，不先扣后漏退。

合法释放后被闪避或没有造成伤害，不等同于没有施放：原体力/法力、限次与冷却依原技能规则结算，不能因为T归还就自动退还其他费用。结束、中止、死亡和战斗终止都需清理对应临时占用，不能重复释放。中断机制本身不由本案新增。

施法完成后仅退本次T，仍在场的D保留；普通状态效果持续不等于T一直存在。生成持续实体则另建它的D，不混用旧T当作永久占用。

召出分支是否另有T，以及新D建立时是否与召出T发生重叠，须在完整召出模板中明确并展示峰值，不在本案凭空收费或默认免费。容量0不视为无限。

## 七、成套与同化

同源成套剑器按一器、一份装备收益、一份器蕴、一个御用入口处理。多柄出击可以是一项在场技能的多段，不能逐柄复制整套基础伤害、器体或锋锐总和；合法固定增伤仍按每段完整追加。

共享器体/逐柄器体为两种可设计模型，实际采用需明确。一体群攻不能按剑图数量重复扣同一生命池；逐柄模型不能对分体与父组双重扣血。数量变化如何影响攻击段与D需按公共模型实现，不用特效数量代替真实机制。

成套高灵识需求体现在D的分体维持和协同负担，并为复杂施法另保留T；不是额外装备维系费。数量、体量、连接/稳定及技能控制复杂度参与成本，系数未定，不提高角色上限掩盖不合理参数。

同化未来按兼容器物投入、共同结构重整、收益/技能/器蕴/占用重算形成成套结果。相同名称不足以判定相同器物；原件消耗、拆回、结果身份与绑定迁移均待专项方案。当前不实施同化，不把多件完整效果直接求和后压成一件一槽。

## 八、器蕴与固定词条

当前两种器蕴为惊鸿、抱朴：前者提高带有“剑”关键词的技能所造成的物理伤害百分比，后者提高角色物防百分比。激活不额外收灵识。贡献按装备实例去重累计，成套不按分体加点。

单件1—3点、2/4点门槛及具体比例仍是候选参数。各档显示最终总比例，高档不重复叠加低档完整比例；仅持有不贡献。材料潜力分给器蕴就不能同时全额用于单件属性。

物理防御、带有“剑”关键词的技能每段固定增伤、真实应对化解为首批效果方向；后续剑意和护盾触发须有完整模板，不因剑标签自动生成新效果。技能类别、关键词与出手方式分别判断，近身不视为关键词。

## 九、材料计算的统一约束

不新增材料名到成品效果的一对一配方表。沿用有效供给、份数递减、品级作用、加工保留、共同结构/根性/通路与效力分配；新增材料填写共享档案后参与同一公式。

对每个来源维度u，分给本体、基础属性、效能、化法/技能及器蕴的量合计不能超过实际供给Eᵤ。同一来源不能全额复制到多个方向。主要岗位关系不是独占，身材强度也不能直接等同于角色物防强度。

固定值候选转换按分得效力、适用覆盖/事件成本和公共系数计算，整数取整并记录损失；百分比器蕴另按公共激活表，不把旧百分比值直接换单位。分体数量、共同化法兼容方案及D/T新增系数尚需离线标定，不能由现有旧公式猜出。

## 十、最小交付与验收

先做单件法器、一个召出入口及一个在场技能，不要求首次交付就有四件装备、六柄分体、同化或全部器蕴。

| 阶段 | 必须证明的闭环 |
| --- | --- |
| 物品 | 新成器真实入包、图标/统一信息栏、同名实例区分、重启读档 |
| 装备 | 合法角色固定收益与来源撤销，普通装备不占灵识 |
| 化法 | 共同条件、单对象、秘籍兼容、化法不新增T |
| 御用 | 手动装槽、召出成功、器体/本体、D登记、同槽切换 |
| 御使 | 队列锁意图、目标/资源/容量检查、T提交与归还、跨回合 |
| 清理 | 失败、死亡、离场、战斗结束不遗留占用，重复提交不重复结算 |
| 扩展 | 模型确认后再做成套、逐柄受击、多器、器蕴汇总与同化 |

正式战斗卡数据编辑前须执行项目规定的卡牌阅读、规则摘要及验收流程；本汇总不替代费用、目标、关键词、数值的具体定案。

## 十一、实际实现状态和待定事项
