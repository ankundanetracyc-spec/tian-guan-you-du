## 写作方法

- 炼制指引有古意、有古文韵味，凝练而不艰涩；先写清参与条件的药位与药性，再酌句式，不套统一模板。
- 用「」标示功用和药位，删除“识别”等系统术语与可省的赘词。用户定稿示例：“以「通」性之材为「君」，方入通脉丹之列。”
- 指引只说明进入丹种候选的条件，不讲成功门槛、提高丹效、五行阴阳调配或完整配方，不承诺成功。
- 古风小句自然简短，不限字数、对仗或分句。药品简述以意象与用途传达丹药性情，不固定起句或格式，不新增正式药效。
- 丹阶与名称读取现有模板。具体服用效果未配置，文中用途属于意象说明，不授权实现回复、增益等新机制。

春未老，一点青意，入丹来。

**药品简述：**采草木生发之意，凝为一丸，服之可温养生机。药性平和，为丹道入门常习之丹。

**炼制指引：**以蕴「生」性之材为「君」，立回春之本。

### 通脉丹 · 九品

一缕清流，过重关。

**药品简述：**药意如清流行于经脉，疏其壅滞，畅其气机。

**炼制指引：**以「通」性之材为「君」，方入通脉丹之列。

### 静心丹 · 九品

尘声渐远，心湖自平。

**药品简述：**收浮躁，敛纷扰，取一分静水涵月之意，凝于丹中。

**炼制指引：**「君」药蕴「镇」性，乃得静心之意。

## 界面与维护

与“内置样方”“我的丹方”并列第三页签，沿用浅纸深墨、左目录右详情。目录从模板枚举，展示名称和丹阶；首次进入选第一种，关闭重开保留有效选择。切丹后正文滚回顶部。正文依次为图、名称与丹阶、小句、简述、指引，长文可滚动。

图文在 `AlchemyPillDescriptions.cs` 中以模板 ID 集中关联；模板名称及 Rank 为身份来源，图文不参与结算。不读取旧分步流程的 Formula、SupportingRequirements 或探索方向作为指引。新增模板时须补齐关联，专项检查验证模板与图文 ID 集合相等；漏配运行时明确显示“此丹图文尚待补录”。

丹药页隐藏载入、删除、名称输入、保存、覆盖和本地丹方状态提示，并在操作函数入口拒绝丹药页调用。进入页签清除配方选择及待确认删除状态，避免串用。切回恢复原有操作及资格判断。通用说明固定为：

> 丹方所记为投料配伍，成丹种类仍由君药药性与实际炼制推定。
