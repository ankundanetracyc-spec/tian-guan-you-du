# NPC 月度药材求购与私委托管预留

状态：现行首轮测试。2026-10-12 用户确认先做灵石求购；私委只预留托管结构，不给 NPC 凭空补贡献。上位来源：人物来访主案、NPC 月度演算主案、玉虚委托主案与人口性能主案。本篇不改变原以物易物界面或善功堂贡献标价。

## 已确认规则

- NPC 需求生成与维护随统一过月演算，不在进入地点、移动、查看菜单、读档或每帧刷新时生成。不新增现实计时或离线收益；跨多个月逐月处理。
- 首轮仅玉虚真实同门的补充随身药材目标。当前目标文本“补齐随身的药材和干粮”匹配药材需求；不为所有人物强加需求，不推定尚未接入的配方或消耗。
- 雾铃花、苦苔根两种现行图标物品，自身随身物不足一份时可选一种求购一份，每份两枚灵石。两枚是本轮用户确认的独立测试价，不由贡献价换算，不改物品静态定义或旧交易估值。
- 余额不足不生成新报价；已有需求在展示、确认时重新核验可支付能力。只查 NPC 自己的目标、资产和持有物，不预先读取玩家行囊来挑需求。
- 同月最多生成一笔，完成当月不再生成。未完成需求保留原 ID 与报价；尚未配置期限，不暗中超时。目标改变或自己已经备齐药材后不再报价，过月清理该旧需求。
- 不模拟尚未定义的药材消耗。买到的一份实际留在 NPC 随身物中，不能为了反复出任务偷偷删除；两种药材都已备齐时不再生成这一测试需求。

## 现场交互与结算

- 有报价且真实同地的非敌对人物，其现有人物菜单追加“求购”；宗内主动来访沿用同峰、实际认知、性格候选和每月最多一位限制。选中来访者有有效求购时先表达此来意，不新增每月第二次弹窗。
- 复用现有独立纸面交互浮层、真实头像、出售／取消或婉拒、可略过过程及结果，不使用剧情底部对话栏。过程行仅反映实际交付与支付，不硬凑行数，也不直说隐藏性格算法。
- 取消／婉拒免费，不改变关系、名声或需求。打开报价不扣费。确认出售时重新核验稳定人物引用、同地、非敌对、需求 ID、双方资产与精力。
- 成交即时扣玩家药材一份，转入 NPC `carried_items`；从 NPC `resources[灵石]` 扣两枚，向玩家行囊放入两枚灵石；沿用已有交易精力一，不额外推进日历或增减好感、贡献、声望。
- 先在轻量行囊副本上移除药材、试算灵石堆叠及空位。失败不改双方资产、需求状态和精力；卖出最后一份腾出的空位可用于收款。全部通过后同步提交，通知观察者时双方已处于完成态，只发一次行囊通知。
- 唯一需求 ID、完成状态与完成月份防重复。连续点击、旧回调和读档不能重复支付。真实成交记录进入 NPC 行动历史与交际所得，但不自动交换姓名、透露境界或揭示完整性格。

## 存档与私委边界

`WorldNpcData` 新增月游标、当前需求资源、私委托管资源数组，随既有 NPC 深复制与正式进度保存。旧档缺省无需求、月游标为 -1；首次后续跨月再检查，不补造历史成交或恢复弹窗。不改正式存档外层版本。

私委仅准备委托／模板 ID、双方 ID、草拟状态、报酬预留、费用预留及预留／收费／结算／退款流水 ID。默认全部金额为零。不增加 NPC 贡献、贡献收入或自动发布按钮，不把灵石当贡献，不宣称托管扣款、转账和退款已经可玩。未来正式开启仍须落实个人贡献来源、可支付余额与统一账本，并按委托主案的 10% 向上取整费用执行；本轮不覆盖实施路线“私委发布暂缓”。

## 性能与验收

月度检查嵌在现有人物循环内，每人每月检查两个固定药材，稳定 ID 选缺项，不生成额外人物两两扫描或寻路。物品资源强引用缓存；现场仅查询选中人物。继续复用已有加载面板与分帧预算，完整月结算末尾统一刷新；不抽样人物、不跳月、不丢行动历史。

专用检查 `NpcPurchaseSmoke` 覆盖目标与资金不足、已备齐不求购、稳定选择、查看不刷新、真实月度入口、主动来访限流、拒绝免费、无物品、离场、付款能力变化、精力不足、资产守恒、一次通知、满行囊原子失败／释放空位、重复成交、真实资源存读和私委零金额结构。性能数据只报告测试实测，不作全游戏帧率保证。
