## 一、入口与一次炼制

正式入口：人物百工→丹药→进入炼丹房。从当前人物读取丹道造诣、人物灵识总值、已占用灵识、行囊和精力。原首页独立预览仍是免扣资源的试演，两者使用同一结算器。

玩家配置君、臣、佐、使与整数剂量，点击一次炼丹；数量由配伍自动结算，不由玩家选择。没有手动控火、节点网、逐息按钮或额外小游戏。君药一种、臣药一种，佐使各最多三种，解锁门槛沿旧案；每味至少1整份，不设每味4份或全炉8份上限；用量由灵识与实际库存约束、同材不重复占位。炼前不预测成丹品质或结果。

**2026-10-23用户修订：取消手动颗数。** 君药有效药性、核心功用品级、剂量、掌控率与臣位聚性共同决定候选丹胚数量（当前0—4颗）。随后逐颗判定是否成丹，因此最终数量可少于候选量。想改变数量需要改变配伍或剂量，不提供减产按钮。引性仍可在既有丹胚间集中君药药性，不能增加总量。内部指定颗数试算仅保留作计算诊断，不进入玩家界面或正式入口。

丹种由君药实际携带的已知核心功用识别。多个核心均对应已知丹种时，优先较高品级核心，同级再比较是否可开炼、是否成丹和实际最高评分，最后按目录稳定顺序处理同分。不能因为旧丹方保存过颗数而改变自动产量或丹种。不会因为一颗丹的分配微差，让低品核心轻易抢走高品核心对应的丹种。样方不指定最终结果，也不授予额外效果。

## 二、灵识与精力

顶部：**剩余可支配灵识／人物灵识总值**。分母保持人物总值，分子扣其他事务真实占用；当前配伍不提前收费。右侧：本炉灵识需求。需求≤剩余可支配额度才可炼，不能拿人物总值直接与本炉需求比较。

行囊刷新、材料入包和服用丹药不能把共同灵识占用池重写成“器物占用”。局外持有／御用免费，不代表其他事务占用为0；器体在场和其他事务各自负责登记及释放。本轮修正了旧行囊刷新清零共同占用的行为。

沿用上一修订的每味占用：

```
v = material_grade_value()，0—27
材料基础 B = 1.00 + 0.13v + 0.0065v²
功用负担 F = 本位各实际参与功用的分级负担之和
药位 R = 君1.4、臣1.2、佐1.0、使0.9
剂量 D = 1 + 0.40×(份数−1) + 0.04×(份数−1)²
本炉需求 = ceil(Σ(B+F)×R×D)
```

功用九品至一品负担为0.75/1/1.4/2/3/4.5/7/11/17。本位不发挥的功用不收功用费，但材料基础负担仍计。原有造诣掌控率K掌沿用；本轮不增加造诣直接加分或灵识折扣，不设计新技巧树。

精力原公式继续使用，颗数项读取配伍自动推导的候选颗数。配置查看不扣精力；开炼成功、普通失败、炸炉都扣本次精力与投料。没有局外法力新资源。

精力公式为`ceil(20+B阶+1.5×max(0,K候选−1)+max(0,M−1)+0.5×max(0,F总−1)+0.25N)`，M为材料种数、N为总份数、F总为本次实际读取的材料—功用组合数。九品至一品的B阶为0/1/2/4/6/8/11/14/18。已知丹种即使核心不足成胚，也按自动候选颗数计费；未知丹种沿原案最低尝试费用，不另计不存在的候选丹胚费。

沿用原功用药力S（九品至一品）：1/1.65/2.9/5.4/10.7/22.6/50.9/121/304。对应掌控门槛为8/32/68/122/203/325/508/783/1196，`K掌=min(1,造诣/该功用门槛)`；`Pᵤ=Σ本位材料份数×S该功用/S丹阶×K掌`。主药支持量`Y=M主药可用×S核心×K掌/(25S丹阶)`；Y≥1时，自动候选数为`clamp(floor(Y×min(1,0.75+0.05P聚)),1,4)`，Y<1时没有候选丹胚。候选数由本炉组合决定，不接受手动覆盖。

## 三、处理与功用

基础原料质量每份100；基础得率按现有材性档案读取。破先处理致密残余（最多致密原料10%），化随后处理剩余残余（自身最多全炉15%），两者共享最多全炉20%的转换预算；每次等量减少残余、增加有效药性。

|功用|当前位置与实际作用|
|---|---|
|生|当前回春丹的君位核心，真实参与每颗核心药力计算；不把它虚构为独立药性原料或无条件回复其他材料|
|聚|臣位，提高君药支持范围内的自动候选颗数；最终数量还受逐颗成丹判定影响|
|固|臣／佐位，按该颗实际分到的药性支撑丹体；不能替代阴阳、核心和纯度|
|破|佐位，转化致密材料残余|
|化|佐位，转化全炉剩余残余，与破共享预算|
|镇|佐位，先减少真实阴阳相激，再改善混合效率与危险值|
|护|佐位，仅减少炸炉危险，不追回已损失药性|
|明|佐位，降低残余夹带率，不凭空转化残余|
|通|使位，改善混合；按各丹分到的通路贡献决定各丹通路评分；亦可作为通脉丹君位核心|
|行|使位，提高药性送达率|
|引|使位，把其他丹胚的一部分君药药性转给首颗；真实搬运，不再给全炉乘额外药力倍率|
|藏|佐／使位，减少已炼出药性的炉内自然散失；不再参与固的稳形公式，也不再改变成品药效时长|

未扩张旧案的其他药位范围，不自动应用旧讨论稿的君位全功用或臣使扩展矩阵。功用始终是同一份药性的能力，多个功用不重复记材料质量。

通／行／镇／护等基础混合与风险公式沿用原案。藏新增保存率：

```
保存率 = 1 − 0.03×max(0,1−0.20P藏)
整炉送达 = 有效药性总量×混合率×行送达率×保存率
夹带率 = 0.15/(1+P明)
夹带质量 = 未转化残余×夹带率
```

其中多味混合通路率`min(1,0.70+0.10P通)`，单味为1；相激`Z₀=200×min(阴药性质量,阳药性质量)/总可用药性质量`，空炉为0；`Z镇后=max(0,Z₀−10P镇)`；混合率为通路率乘`1−0.20Z镇后/100`。行送达率`min(1,0.60+0.10P行)`。危险`max(0,Z镇后−5P护)≥90`时整炉炸炉。各项都读取破化处理后实际质量。

基础得率及天然成形支撑分开：纤维85%、致密75%、颗粒80%、黏胶90%、液体95%、气体90%。转换优先基础得率低的来源，再按君药、角色顺序及稳定材料路径处理同值，调用者改变输入枚举顺序不能改变转换分配。

五行仍按各丹实际来源质量组成，`K五行=clamp(1+0.25×(0.50−D)+0.125×(生我份额−克我份额),0.75,1.25)`；D为目标向量总变差距离。依木/火/土/金/水顺序：回春目标0.50/0/0.10/0.05/0.35，锚定木；通脉0.20/0.10/0.20/0/0.50，锚定水；静心0.30/0.05/0.25/0.10/0.30，锚定土。阴阳目标分别0/0/−0.50，20分容限0.72/0.68/0.68，100分容限0.20/0.16/0.16。五行倍率作用于实际核心和固的药力，不改变质量，不另列重复评分轴。

明由原来低份数即把夹带压到0，改为连续递减；高纯度可以结合低残余材料、破化转换与明性处理实现。藏最多挽回这项3%的自然散失，不能追回其他损失。所有损失计入炉内废弃质量；不生成可拾取药渣物品。

## 四、逐颗分配及守恒

先求整炉每味送达总量，再分给自动形成的K颗。每味保留双精度质量，最后一颗获得实际余量，确保不因取整复制或损失质量。先按材料稳定路径排序，生成稳定差异；同一配伍、剂量、药位和K重复炼制结果一致。

普通分配权重：共同偏差幅度 `s=0.12+0.10×(1−混合通路率)`；第j颗（从0起）与第i种来源的权重为：

```
K=1：权重1
K>1：w=1+s×(K−1−2j)/(K−1)+0.025×(K−1−2((j+i) mod K))/(K−1)
每味分配 = 该味整炉送达量×w/Σw
```

这使多数普通炉次只有小幅质量、配伍和通路差别，可能同档或相邻档；不强制每炉跨档。充足到所有轴饱和时允许同炉全满效。没有额外随机倍率或固定“幸运极品”。

引的搬运比例 `f=min(0.25,0.05P引)`：第2至K颗各把自身君药质量的f转给第1颗。残余不随之复制；各丹残余仍均分真实夹带质量。K=1时没有可转移来源。强引可能让少数丹升档、其他丹降档，允许比分配自然差异更大的档差；不能保证集中后一定升档，其他短板仍限制结果。

每颗独立按实际分到的来源重算五行、阴阳、核心、稳形和夹带。各丹通路贡献按该丹分得的通性来源相对平均份额计算，平均份额仍对应整炉通性负担；不能用引复制通性。整炉送达总量等于各丹各来源质量之和，各丹夹带质量之和等于整炉夹带总量。

## 五、跨档评分

不再使用按有效材料味数强制封顶。有效材料数仅留作贡献诊断；高效依靠真实质量、药力、配伍与用度，少味高阶与多味低阶都能尝试。

每项先换成过程完成度，再统一按以下连续折线换成丹效分。档位交界附近有更长的实际改善区间，不加指定材料／指定功用的晋档资格。

|丹效分|0|20|50|51|75|76|90|91|99|100|
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
|过程完成度锚点|0|20|44|51|65|76|84|91|97|100|
|核心与稳形的需求倍率锚点|0|1.00|1.25|1.50|1.80|2.20|2.55|3.20|3.60|4.00|

在需求倍率锚点间线性插值到过程完成度，再在过程锚点间插值到丹效分；等价于连续的需求→评分曲线。

- 核心质量倍率=`每颗君药质量/12`；核心药力倍率=`每颗实际君药药力/(8×丹阶基准药力)`。两项各自换分，取较低值；从零连续增长，低于成丹标准不直接归零。
- 稳形倍率=`(该颗固的真实药力+材性天然成形支撑)/(8×丹阶基准药力)`；基础完成度至少45，保证没有指定辅功仍可尝试。材性支撑按实际分到质量乘系数：纤维0.10、致密0.04、颗粒0.06、黏胶0.22、液体0.04、气体0.01。高等级需求可通过固或材性／质量构筑承担。
- 多味通路完成度=`65+35×min(1,该颗等效通贡献/6)`，单味为100。物理混合率仍沿旧式计算，不把这条评分反复乘回质量。
- 阴阳在100分容限内完成度100；从100分容限到20分容限连续线性降至20；超出20分容限后继续在额外0.12偏差宽度内降到0。
- 夹带比例J≤6%时，纯度完成度=`20+80×clamp((0.06−J)/0.057,0,1)`；J从6%到10%时继续从20降到0，超过10%为0。稳形与纯度取最低。

最终每颗取核心、阴阳、通路、稳形与纯度的最低评分，向下取整。关键缺陷不能被其他超额项目补分。低于20的丹胚不成丹，其余各自成丹；炸炉整炉无丹。20—50薄效、51—75良效、76—90优效、91—99极效、100满效。

满效表示所有关键项达到有限可满足的上限范围，不要求浮点数恰巧等于某一点。分数只用于本次判级和诊断，正式物品不保存每颗原始分数。`Result.Quality`为本炉最高成丹评分的兼容摘要，`Result.Pills`才是逐颗权威数据，不能用最高分代表整炉。

## 七、正式事务与历法

点击时重新读取真实材料定义、人物造诣、人物总灵识、其他占用、当前精力和库存。由材料稳定路径解析，不能把试演中伪造的材性对象写入正式产物。检查人物存活、药位、剂量、颗数、资源、材料余额，确定本炉实际产出后，在独立数组里试排扣料与入包；排包允许扣料腾出的格位，并计入已有法宝实例格。

任一预检失败都不开始，不扣材料精力，也不推进时间。所有检查通过后一次发布库存变化与精力扣除，普通失败与炸炉也扣料扣精力，无丹无药渣。成功只将合格丹胚按各自档位入包。满包不会吞料、丢丹或向地面抛物。事务与页面都防重入；连续点击属于新的炉次，仍重新检查余额。

正式炼丹同步完成，然后按原案耗时推进历法：九品1时辰，每升一品翻倍，超过四味每味加25%；一时辰换算两游戏小时。没有后台持续炼制状态，不留下长期灵识预约；推进后续世界事件时，本炉物品事务已完成。炼丹本身不额外授予休息恢复。通过既有世界精力通知标记存档变化。

模拟器只负责计算，正式扣料入包由`Character.TryBrewAlchemy`负责；独立试演不写人物、库存或时间。正式入口返回只关闭炼丹页面，不切回首页或重置游戏。未来若增加丹炉耐久或新技巧，需要独立定义数据接口；本次不伪造已有丹炉耐久字段或技能树。
