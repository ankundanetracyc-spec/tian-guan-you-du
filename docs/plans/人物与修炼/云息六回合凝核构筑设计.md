## 一、过程与设计目标

修士将前六层炼就的灵力整体收拢、压聚，形成能够维持自身的高密度气团。开始时没有灵核；紧密的中心气团在连续运功中逐渐出现，六回合结束后才合核。

压聚使灵气趋向中心，同时产生向外舒张的回弹。回弹不会立即消失，玩家能够预见其到来的回合，并通过手法重新导向内部。数股回弹一起引回时，还能顺势吸入少量周围灵气。这里的收益代表同一团灵力被组织得更紧密，不代表凭空生成角色修为。

策略主体是组牌、留牌、出牌先后与跨回合安排。玩法无倒计时、手速判定与随机成败骰。随机只来自牌库顺序；具体牌效、回弹时间和结果均固定并可预览。

本局只显示一个主要数值：**凝聚程度**。回合、剩余出手、手牌与回弹标记属于局势信息。凝聚程度初始为0，最低为0，无局内硬上限；不是灵力缕数，不等于144缕，不写成角色长期属性。移除旧压合度、得分S、灵核承量K与后台Q的结算方式，不为本游戏另设专属天赋、五行属性或天气系统。

## 二、构筑与开局

### 1. 固定规则

| 项目 | 规则 |
|---|---|
| 对局 | 六回合，六回合结束后统一合核 |
| 牌组 | 恰好24张，当前可用手法可重复配置，同名最多4张 |
| 手牌 | 上限6张，未使用手牌跨回合保留 |
| 每回合出手 | 最多3次，未用机会不累积 |
| 一次出手 | 打出一张手法牌，或使用一次基础调息 |
| 外物 | 最多携带2件，同名最多1件，各使用一次；每回合最多用1件，不占出手 |
| 弃牌 | 本局不洗回，不能主动查看或改变未公开的牌库顺序 |
| 补牌 | 第一回合起手6张；第二至第六回合开始补足6张 |
| 普通换牌 | 第二至第六回合补牌后，可弃1抽1一次，不占出手 |
| 起手换牌 | 最多2张，替代第一回合普通换牌 |

全部基础手法是本小游戏共通牌池，不读取战斗卡牌、体力、法力、灵识，也不新增凝核专用秘籍或天赋养成。牌的解锁来源与角色已有功法如何接入，尚未定案；第一版试玩全部开放。不得用尚未确认的角色属性修正牌效。

没有强制的牌型配额。构筑界面显示压聚牌、引回牌与调度牌的张数，并提示缺少接应的风险；除张数与同名上限外，不替玩家限制流派。

### 2. 起手

1. 确认牌组和备用外物，将24张牌洗匀后抽6张。
2. 可以同时选择0—2张更换；先将所选牌暂放一旁。
3. 从剩余牌库抽取相同张数，再把暂放牌洗回牌库。因此不会立即换回同一张实体牌，但可能抽到它的另一张同名牌。
4. 起手换牌结束，进入第一回合出手阶段，不再额外抽牌或普通换牌。

起手选择、构筑和效果预览不触发局外材料消耗。正式突破投入与不可撤销点在接入修炼系统时确定，不沿用旧稿核媒、K或逐息导入规则。

## 三、每回合流程与牌区规则

### 1. 回合开始与换牌

第二至第六回合，自动抽取牌库顶牌，直到手牌6张或牌库耗尽。随后允许一次普通换牌：选一张手牌弃掉，再抽一张。换下的牌进入弃牌堆，本局不会回来；牌库为空时，普通换牌按钮不可用。

普通换牌只能在本回合首次出手或使用外物之前进行，选择“开始行功”后关闭换牌阶段。回弹轨道在换牌时已经公开，玩家能够据此留牌。

### 2. 出手阶段

每回合最多三次。点击一张牌先预览，确认才扣除出手并执行效果。牌离开手中后进入桌面施法区；即时效果处理完进入弃牌堆，持续效果按自身规则留在桌面。

出牌不自动抽牌。只有牌或外物明示抽牌时才抽牌。抽牌不返还出手机会，也不允许突破三次出手限制。

外物可在首次出手前、两次出手之间、第三次出手后使用；均须在确认结束回合之前。每回合最多使用一件。外物不改变“上一出手”的记录，不打断叠压的衔接。

可以提前结束回合，甚至不出手。结束按钮先列出本轮回弹的处理结果，玩家确认后开始结算；结算开始后不能插入牌或外物。

### 3. 手牌保留、溢出与耗尽

- 回合结束不自动弃牌，普通手牌全部保留，不收留牌费。
- 额外抽牌处理完整个牌效后，手牌超过6张时，由玩家弃至6张。弃掉的牌不触发补抽。
- 带“抽牌后弃牌”的手法，先完成其指定弃牌，再检查手牌上限，避免重复弃同一张牌。
- 牌库不足时能抽几张就抽几张；抽空不回洗。
- 牌库耗尽后仍可出手、调息、使用外物，少于六张手牌不补虚拟牌。
- 手牌、桌面持续牌、未抽牌库、弃牌堆明确分开；已使用的引回和蓄劲不会混回手牌。

常规打满三次时，初始6张加五次补3张，共抽21张，剩余3张用于换牌或额外抽牌。第二至第六回合均换牌时可能提前抽空，但24张仍足以支撑18次普通出牌、5次换牌并留1张；额外抽弃会改变这项余量。

## 四、回弹与凝聚的统一规则

### 1. 回弹事件

每股回弹独立记录来源、强度、到达回合与唯一编号。以牌结束执行时所在回合为起点：

- “下一回合”：当前回合数加1。
- “隔两回合”：当前回合数加2。
- 第五、六回合仍可产生第七、八回合的回弹，放入轨道的“合核时仍需处理”区域。
- 相同回合到来的多股回弹分别保留身份，不自动合并；引回奖励据独立股数计算。
- 强度代表凝聚变化，不是新资源条。

所有压聚牌先增加凝聚，再产生一股牌面规定的回弹。若有待生效蓄劲，在这张压聚牌上一次性增加2点凝聚和1点回弹强度，然后移除蓄劲。

### 2. 回合末结算

设本回合到来的回弹共若干股，其强度总和可从轨道直接查看。

若本回合使用引回：
1. 全部当前回弹转向中心，凝聚增加其强度总和。
2. 接住两股及以上时额外增加1点凝聚。
3. 若有随势，额外按接住的股数增加凝聚，最多增加3点。
4. 本回合护气、调息、定息丹的减损效果不再提供额外收益。

若未使用引回：
1. 合计当前回弹强度。
2. 减去护气、调息、定息丹合计的减损，最低损失0。
3. 从凝聚程度扣除该损失，凝聚最低为0。

随后移除已结算回弹，清理引回、随势与本轮减损牌。未触发的蓄劲跨回合保留；本回合的减损不跨回合保存。

### 3. 第六回合收尾

先正常结算第六回合，再把仍安排在第七回合及以后的回弹全部释放，按强度总和扣除凝聚，最低为0。第六回合的引回和减损只作用于第六回合的正常结算，不能处理这次余波。

要利用未来回弹，必须在出手阶段用催回、导气符等把它移入第六回合。缓行不能借延后逃避最终扣除。

六回合必须全部经过；玩家可以结束当前回合，但不能提前整局合核。

## 五、十二种基础手法

以下为第一轮平衡值。“压聚”是牌效分类，便于判断蓄劲和叠压，不是五行属性或战斗关键词。

| 手法 | 分类 | 完整效果 |
|---|---|---|
| 轻压 | 压聚 | 凝聚+2，隔两回合产生强度1的回弹。 |
| 重压 | 压聚 | 凝聚+4，下一回合产生强度3的回弹。 |
| 叠压 | 压聚 | 本回合上一出手必须是压聚牌，才能使用；凝聚+3，下一回合产生强度2的回弹。叠压本身可衔接下一张叠压。 |
| 引回 | 引回 | 留在桌面，本回合末引回全部当前回弹。每回合最多施展1张。允许先打引回，再用催回移入回弹；若回合末没有回弹，则无收益。 |
| 缓行 | 调度 | 选一股未结算回弹，其到达回合+1。可以选择当前回合回弹。 |
| 催回 | 调度 | 选一股未来回弹，其到达回合−1；不能移至当前回合之前，不能选择已经到达当前回合的回弹。 |
| 并流 | 调度 | 选择两股到达回合不同的待结算回弹，把较早一股移到较晚一股所在回合。两股仍分别计算，不改变强度。 |
| 蓄劲 | 蓄势 | 留在桌面，下一张压聚牌凝聚额外+2，回弹强度额外+1，之后移除。最多保留1张；已有蓄劲时不能再打第二张。 |
| 随势 | 蓄势 | 本回合已经施展引回时可用；回合末每引回一股，额外凝聚+1，最多+3。本回合最多施展1张。 |
| 匀气 | 整理 | 凝聚+1；抽2张，再弃1张。实际未抽到任何牌时免去指定弃牌；只抽到1张时仍需弃1张。效果完成后检查六张上限。 |
| 护气 | 护持 | 凝聚+1，本回合未引回的回弹损失减少3。多张减损相加，最低损失0。 |
| 归拢 | 护持 | 选一股未结算回弹将其消解，凝聚+1；被消解的回弹不再到来，也不计入引回股数。可选当前或未来回弹。 |

无合法目标的缓行、催回、并流、归拢不能确认施展，也不扣牌或出手。引回可提前布置，护气可仅为+1凝聚施展；预览明确提示其附带效果当前是否能生效。叠压条件被其他手法或基础调息打断，外物不打断。

基础调息不在牌组内，随时可用，占一次出手，本回合未引回的回弹损失减少1。它不抽牌、不增加凝聚、不生成回弹。每回合可使用多次，最多受三次出手限制。用于牌库耗尽或接应牌不足时减轻反冲。

### 组合示例

- 蓄劲→重压→引回：强化一次压聚，同时处理当前回弹，下一轮会面对更强反冲。
- 重压→叠压→叠压：立即凝聚+10，下一回合三股回弹强度合计7。接住后会再增加8；接不住则损失7。要提前留引回或准备补救。
- 引回→随势→催回：把未来回弹移入当前，在集中引回中增加收益；必须先确认这一股确实能提前到当前。
- 并流→蓄劲→重压：先将已有回弹推向后续集中处理，再强化一次压聚；要检查新回弹能否一起接应，不能只看本轮凝聚收益。
- 归拢→重压→重压：消解眼前反冲以继续压聚，但消解也放弃了将该股引回的潜在收益。

## 六、三套24张示例构筑

| 手法 | 稳妥凝聚 | 集中引回 | 连续强压 |
|---|---:|---:|---:|
| 轻压 | 4 | 4 | 1 |
| 重压 | 2 | 3 | 4 |
| 叠压 | 0 | 0 | 4 |
| 引回 | 4 | 4 | 4 |
| 缓行 | 3 | 2 | 1 |
| 催回 | 2 | 3 | 3 |
| 并流 | 0 | 3 | 0 |
| 蓄劲 | 1 | 0 | 4 |
| 随势 | 0 | 3 | 0 |
| 匀气 | 3 | 2 | 1 |
| 护气 | 3 | 0 | 1 |
| 归拢 | 2 | 0 | 1 |
| 合计 | 24 | 24 | 24 |

稳妥凝聚用低强度回弹和护持控制损失，适合初次理解规则。集中引回通过并流、缓行与催回节省引回牌，并为随势创造多股收益。连续强压把较大收益与反冲放在相邻回合，强调接应牌的保留，末段需要及时转入收尾。

初始牌池全部开放，三套可直接载入并修改。当前没有逐牌等级、卡牌强化、稀有度或专属天赋修正。三套是否同样容易成核、极限收益是否差距过大，属于首轮试玩平衡问题，不标为已验证。

## 七、外物辅助

最多带2件，同名最多1件，每件使用一次，每回合最多用1件，不占三次出手，不进入牌库或弃牌堆。使用前预览，确认后消耗。外物使用不推进回合，也不触发补牌或返还出手。

| 外物工作名 | 完整局内效果 | 定位 |
|---|---|---|
| 定息丹 | 本回合未引回的回弹损失减少3，与其他减损相加，最低损失0。 | 接应不足时减损 |
| 聚气丹 | 凝聚+2，不产生回弹。 | 稳定补足凝聚 |
| 导气符 | 选一股待结算回弹，提前或延后一回合；不能移到当前回合以前。 | 组合安排与收尾 |
| 观息符 | 查看牌库顶至多3张，选1张入手，其余按原相对顺序置于牌库底，再处理六张上限。牌库为空不能使用。 | 寻找手法 |

定息丹不是自动接住回弹，不会获得引回收益；没有当前回弹时也允许预先使用，但若之后仍无回弹则减损无收益。导气符必须有合法目标，观息符必须至少有一张可查看牌；不满足条件时不消耗外物。

使用外物后仍须遵守每回合三次出手。第三次出手后使用观息符抽到的牌，只能留到下一回合；第六回合此时抽到的牌不能再打。

外物全部是已处理的丹药、符箓成品，不使用未炼化材料作为临时操作。这里的名称为工作名；品阶、通用功用词缀、获取与炼制待丹药及符箓系统对接，不凭本稿新增物品等级。

## 八、六回合过程与结果

前两回合通常在铺设压聚及回弹；第三、四回合容易形成集中引回；第五、六回合开始关注余波。上述是由延迟效果自然形成的节奏，不另设阶段限定、指定出牌或每轮新规则。

第一轮数值草案以最终凝聚**18**为成核底线。正常第六回合结算与余波扣除全部完成后，最终不足18，本局未形成可自持的灵核；达到18，成核。超过底线的最终凝聚用于比较凝核结果，暂不赋予正式品阶名，也不直接推导后续灵力倍率。

只按最终凝聚判定本局结果，不另计连击分、失误次数、操作分或随机成功率。曾经散开后仍可重新收聚。外物作用已进入该数值，不在结果页重复加分。

18是新的首轮试玩值，不能与旧两次出手方案的12或旧K≥72混用。全境界的永久品质、门槛倍率、失败消耗与复试条件须另行确认接入。本稿不把旧承量模型或核媒消耗反向带入新牌局。

### 定序教学对局

以下固定牌序只用于讲清出牌与回弹规则，已逐步核对手牌合法性及数值；它不是随机对局的平均收益，也不证明三套构筑已平衡。玩家先体验完整组合，再在正常对局中面对不同抽牌顺序。

牌库从顶到底依次为：

轻压、轻压、蓄劲、重压、引回、匀气、轻压、缓行、重压、随势、重压、引回、轻压、催回、重压、引回、催回、缓行、护气、引回、匀气、归拢、并流、并流。

共24张，同名均不超过4张；不进行起手或普通换牌，不使用外物。第三回合匀气抽到轻压、催回，弃催回；第六回合匀气抽到两张并流，弃手中的归拢。

| 回合 | 三次出手 | 本轮回弹处理 | 回合末凝聚 |
|---|---|---|---:|

| 3 | 引回、重压、匀气 | 引回两股，强度合计5，另获集中引回+1 | 23 |
| 4 | 引回、随势、重压 | 引回三股，强度合计5，集中+1、随势+3 | 36 |
| 5 | 轻压、重压、引回 | 引回一股强度3；轻压的回弹在第7回合，重压在第6回合 | 45 |

## 九、界面与新玩家说明

### 2. 操作预览

点击手法只选中；有目标时继续点选回弹。预览显示立即凝聚变化、移动或新增的回弹、剩余出手，以及若现在结束回合的结果。确认后才执行；已执行的操作不撤回。

带抽牌的效果不能预览未公开牌面，只提示抽弃张数。观息符确认使用后才公开牌库顶牌，再选择要拿的牌。不能通过取消预览反复窥看牌序。

结束回合先列出当前回弹与处理结果，第六回合额外列出余波扣除及最终预计凝聚；确认后播放动画。计算在逻辑上一次完成，动画无操作窗口，结束后可直接继续。

### 3. 动画

压聚让灵云向中心收缩，产生向外舒张的细微波动，对应回弹标记进入轨道。引回时当前回弹标记依次化为向内流动的灵气；数股一起引回时，外围少量散气随之卷入。

未处理回弹使中心云团松散、光色变淡；凝聚尚低时没有完整灵核。第六回合结算及余波处理后，合格气团才缩为能够自持的小核，内部仍有细微流动。未成核则散回松散灵云。动画可加速或跳过，不影响结算。

### 4. 玩家首次介绍

> 六回合内，将灵气压聚成核。每回合可以施展三次手法，手中的牌会保留到下一回合。
>
> 压聚后会有回弹，轨道会告诉你何时到来。用引回把它导向中心，几股一起引回效果更好。
>
> 第六回合结束时，未来回弹也会释放。提前安排收尾，最终凝聚达到18即可成核。
>
> 备用丹药和符箓不占出手，但每回合只能用一件，全局最多两件。

## 十、实现与审阅边界

本稿为小游戏策划，不修改战斗系统、卡牌词典、修炼速率或全境界数值；现有网页没有实现这些规则，不能作为验收结果。

建议对局状态包含：牌组与洗牌种子、牌库顺序、手牌、弃牌、桌面待生效牌、当前回合、剩余出手、普通换牌是否用过、当前凝聚、回弹事件列表、本轮减损、上一出手类别、备用外物与本轮使用记录。它们是本局状态，不新增人物长期成长指标。需要中途保存时必须保存整局状态，不能读档重新洗牌。

后续验证至少覆盖：起手不立即换回实体牌、留牌补足与溢出、牌库耗尽、蓄劲跨回合及不可叠放、叠压衔接、同回合多股独立引回、调度后的到达回合、第六回合余波、外物使用次数、抽牌预览不能窥序、三套构筑的成核与收益差异。仅完成文字规则不能宣称平衡或玩法已验证。
