# 云息期性命双修与主境界接入（初版）

> 状态：初版 v0.1，待审。本文把现有修命、修性专题放回云息主境界线中安排阶段；不替代各专题已经确认的规则，也不把尚待审的参数写成正式定案。
>
> 本稿承接本轮方向：云息期开放观天象、地文、物华全部三部分。修命以现有六部位淬体为主体。

## 一、设计结论

云息期同时开启修命与修性，两者伴随主境界推进，但不成为普通晋层、凝核或归元九息的额外硬性门槛。

主境界仍按现行结构推进：凡人 → 云息一至六层 → 六层凝核至七层 → 云息七至十层 → 十层归元九息 → 九息圆满后准备铸玄基。

两条养成轴与主线并行：

| 养成轴 | 云息期内容 | 成长记录 |
| --- | --- | --- |
| 修性 | 天象观变、地文察势、物华应物三类观法全部开放 | 图录、装配景、单景重数、聚焦景 |
| 修命 | 皮、筋、骨、血、脏、心六部位均可养形与淬炼 | 六部位各自的累计炼度与节点奖励 |

境界提供修炼阶段和内容展开空间；修命、修性记录角色的长期积累。三观和六部位都不替代主线灵力、主修资格、丹药或凝核规则，也不要求角色在每次晋层前把某项支线练到指定等级。

## 二、按主境界安排的阶段

| 主线阶段 | 修性安排 | 修命安排 | 与主境界的关系 |
| --- | --- | --- | --- |
| 初入云息 | 开放天象、地文、物华三类观法。建议承接现行提案，初始取得一轮寒月、远山积雪、江心孤灯各一幅、各一重，并组成《寒江照月图》。 | 开放六部位总览、养形与已掌握的淬炼法；日常养形和主动淬体并行。 | 进入云息即开放两条养成轴，不要求先有特定主修秘籍。 |
| 云息一至六层 | 三类均可观、可装配；由聚焦景决定温观分配，观法可主动推进指定图景。 | 建议将现有一至五炼淬炼法作为云息前段的基础内容，使玩家可选择推进若干部位的首个五炼节点。 | 支线成长不参与每层突破判定；不要求六个部位全部到五炼。 |
| 六层至七层凝核 | 三景进度与装配继续保留，不重置、不要求达到特定重数。 | 六部位炼度与节点记录继续保留，不要求达到特定炼度；凝核仍按云息主案结算。 | 凝核是主境界的质变节点，不额外检查三观或六部位。 |
| 云息七至十层 | 三观继续成长，后续图景可逐步加入图录；具体获得来源依世界内容配置。 | 建议逐步补齐支持六至十炼的淬炼法和材料，使第二个五炼节点成为云息后段可追求的养命目标。 | 后段内容拓展修炼深度，不把十炼设为九至十层或九息的前置条件。 |
| 云息十层归元九息 | 图录、重数和装配持续保存。现行三景各达五十重只代表显境资格，不自动产生领域或战斗效果。 | 六部位炼度与节点奖励持续保存。当前九息是独立的十层内部修炼流程。 | 九息继续按云息主案推进，不新增三观或淬体要求。九息期间是否另结算温观、养形，见第六节。 |
| 准备铸玄基及以后 | 显境、图景效果和高境界修性表现由后续专题定义。 | 玄基阶段首次由灵气进一步哺育形体；十五炼及其后的内容安排在相应淬炼法和玄基方案中细化。 | 建议把性命积累作为铸基质量或后续成长的辅助输入；不在本稿设定公式、奖励或硬性资格。 |

## 三、修命：云息期的养命路线

### 3.1 六部位并行开放

六部位固定沿用修命专题：皮、筋、骨、血、脏、心。云息期间六项进度分别保存，玩家可自由选择淬炼目标；不把角色预先分成单一部位流派，也不要求六项同步成长。

云息期修命分成两种来源：

1. **养形**：正常修炼时，按当前主修秘籍的养形谱缓慢增加部位炼度；它是稳定的小幅积累。
2. **淬体**：在静室选择已掌握的淬炼法，按法门时长、材料和部位分配主动推进；云息期不直接消耗灵力修为，也不采用灵力灌体。

每五炼的部位节点是修命自身的成长里程碑。云息一至六层以一至五炼的基础淬炼内容为主；凝核后可逐步扩展至六至十炼；十五炼及以上留待玄基阶段的内容规划。这个阶段映射是本稿建议，不是境界硬门槛。即使部位节点奖励已有候选数值，也继续以《修命淬体养成规划》的审定状态为准。

### 3.2 凝核前后如何衔接

六层凝核承担云息主线的阶段变化，修命在这里不发生强制重置或自动跳级。凝核前累积的部位炼度、已领节点和淬炼法记录全部保留；凝核成功后，内容进度可以从低阶淬炼扩展到更高炼度。

云息七层以后仍以淬炼法、时间和材料作为主动养命手段。修命专题已经明确，突破玄基时才由灵气进一步哺育形体；因此不在云息中提前加入灵力灌体或新增体内养命资源。

## 四、修性：云息期完整三观

云息期开放完整三观：

- **天象观变**：观日月、昼夜、云气等变化；
- **地文察势**：观山川、风雪、水势和地势纹理；
- **物华应物**：观灯、器物、草木、禽兽等具体事物。

三者是所有修士共同的观照维度，不是三条职业路线。建议沿用现有提案的起始《寒江照月图》：寒月、远山、孤灯分别占据天象、地文、物华位置。单次观法按“选景、取象、守观、收景”组织；三观的观察重点、基础法门和扩展意象候选见[性命双修养成重构提案](性命双修养成重构提案.md)中的“观法方式与意象库”。图景获得、重数和装配仍按修性专题保存；替换图景不清除原图景积累。

成长方式沿用性命提案，不在本稿重造规则：正常吐纳温观、静室主动观法，以及与具体图景相符的探索机缘。现行提案中的每日温观量、聚焦景分配和五重节点仍按待审状态处理；图景尚未配置的属性或战斗效果继续留空。三景各五十重只取得显境资格，不作为铸玄基条件。

## 五、主境界与性命养成的接口原则

1. **云息解锁两条轴**：进入云息后可查看修命和修性；修性三类观法同时开放，修命六部位同时可见。
2. **境界决定阶段，不决定支线合格线**：云息层数、凝核和九息仍按主境界方案判定；支线等级不加成或替代其既有门槛。
3. **成长跨阶段保留**：凝核、晋层和开始归元九息均不清除三景、六部位或已经领取的节点进度。
4. **不增加平行资源**：沿用灵力、图景重数和部位炼度；不新增性命经验、兑换货币、被动槽或独立 Buff。
5. **玄基再承接结果**：云息累积的性命成长可以进入后续铸基方案作为辅助输入，但具体效果须由玄基专题明确；本稿不补写成功率、属性或消耗。

## 六、待审事项与内容缺口

1. **六至十炼的淬炼内容**：当前修命专题列出五炼、十炼、十五炼节点，但候选淬炼法的有效区间主要覆盖一至五炼。要把十炼规划为云息后段目标，须先补齐高炼度法门、材料要求、产出范围与来源。
2. **归元九息是否推进温观和养形**：当前代码中的普通吐纳会结算养形与温观，归元九息使用独立推进流程。本稿建议先维持这一区分；若希望九息期间也养性命，应另定专属结算方式和上限，不能直接把普通日常速率乘以九息时长。
3. **玄基如何读取性命积累**：修命专题已提出玄基时灵气进一步哺体，但具体算法未定；修性也没有与铸基结果的现行接口。后续应明确哪些积累可作辅助输入、其影响形式及边界，再决定是否产生结果差异。
4. **三景的具体效果**：本稿确认三观开放，不替寒月、远山、孤灯或其他图景新增属性、被动与联动；逐景规则仍按修性主提案审定。

在以上缺口补齐前，本稿可作为云息期入口和阶段组织的初版依据；具体数值、部位节点收益、图景战斗效果与玄基结算分别回到各自专题审定。
