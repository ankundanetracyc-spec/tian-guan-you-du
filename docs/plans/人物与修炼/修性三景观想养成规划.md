# 修性三景观想养成规划（迁移与实现记录）

> 现行规则唯一来源为[性命双修养成重构提案](性命双修养成重构提案.md)。本文只记录三景数据与旧实现的迁移边界，不另设养成数值、战斗效果或角色分类。

## 当前定位

修性是所有修士共通的长期养成。三景心相图由天象、地文、物华三个构件组成；图录、重数和装配用于表达角色的修性成长。已学秘籍的心法仍由主修、辅修槽位自动生效，不受三景装配影响。

## 保留与迁移

- 保留角色已有的三景图录、单景进度、当前装配和温观／观法记录，不要求重练。
- 一轮寒月、远山积雪、江心孤灯等已有图景作为当前图录内容保留；每景的属性、被动和组合效果以现行提案中已经确认的配置为准。未配置的效果保持未定义。
- 迁移存档时保留已有图景、重数与装配数据；历史未审定的属性和五行参悟数据不折算为修性收益。
- 旧存档中的 `dao_*`、五行参悟、灵感和节点字段仅为读取兼容保留，不参与资格校验、属性奖励或战斗行为。

## 规则边界

- 修性不增加新的战斗资源、Buff、心法槽或技能槽。
- 三景被动如需影响战斗，必须在现行提案或对应专题中明确定义触发时点、目标、数值、持续与移除条件；不得由未审定的历史配置自动推定。
- 本文与现行提案冲突时，以现行提案为准；实现状态以代码为准，但代码不能替代未确认的设计规则。
