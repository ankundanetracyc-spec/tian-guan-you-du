- [独立属性冷却](即时战斗六招节奏调整_20261104.md)：沿用费用1体力、0法力，不占灵识；CD为max(1.5,5−min(体魄,神魂)×0.03)秒，从结束或中断后计算。
- [状态系统](../状态系统设计.md)：通用化解只对应一次来袭行动，余量不跨招。本轮用户确认的“整次架招共享额度”作为本招明确的特殊来源；不扩大其他化解来源的公共生命周期。
- [舒卷天章即时讨论稿](舒卷天章云息篇即时战斗规划_20261105.md)与[百骸云息实装](百骸云息篇即时实装与自选对练_20261104.md)：分别涉及架招获得剑意与基础化解量提高20%，必须随架招迁移核对。

## 已明确的改动

1. 按住技能键时维持防御，松开结束；不能再用原0.20秒单次窗口代替持续防御。
2. 只能化解正面来袭，侧后方不符合范围时正常结算。
3. 维持期间普通移动速度乘0.20；结束立即移除本招的速度修正，不新增通用减速状态。

用户随后明确：架招没有防御距离。只在防御者自身受击时判断伤害是否来自正面，不按攻击者与自身的距离另作半径筛选；正面180°是来向限制，不是向外覆盖的扇形防御区域。本轮攻击范围翻倍不作用于架招。

## 已确认参数

下表为本轮确认的设计；当前代码和旧词典仍按原实现，不据此宣称已改好运行表现。

| 项目 | 规则 |
| --- | --- |
| 目标／关键词 | 自身；化解、应对 |
| 发动费用 | 1体力、0法力，不占灵识；成功开始时支付一次，维持期间不追加费用 |
| 最长持续 | 3秒，松开可提前结束 |
| 正面范围 | 随当前朝向的前方180°；命中时判定 |
| 化解总额度 | A=3+floor(P/4)+floor(min(P×0.25,S×0.20))，P、S为发动时的非负体魄与神魂 |
| 额度方式 | 本次防御共用一份A，按实际抵消的物理伤害扣减，可用于持续期间不同的正面来袭；不是每次受击重新获得A |
| 结束 | 松开、持续到上限、额度耗尽、成功切换其他技能、明确打断或死亡 |
| 冷却 | 沿用max(1.5,5−min(P,S)×0.03)秒，结束／中断时读取属性起算；维持时间不抵扣CD |

样例：体魄8、神魂8时，总化解额度6，原CD为4.76秒。未计其他伤害修正的正面物理来袭依次为4点和5点时，第一次抵消4点、剩2；第二次抵消2点、额度耗尽，余下3点再走原物防与减伤流程。化解位于固定物防和百分比减伤之前，仍按现行顺序处理。

## 交互与结算边界

- 玩家维持时可以慢速移动并朝鼠标转向；不增加转速属性。防御不能和主动攻击同时维持；错步或其他合法、就绪且已成功支付费用的技能可以结束防御，未发动成功不免费取消。
- 近身来袭按真实攻击来源相对防御者的方向判定；飞行物和波前按实际接触时的入射方向判定，不以施术者后来移动到的位置反改来向。没有可判断正面来向的伤害不自动纳入。
- 身法闪避、错步无敌与空间落空不消耗额度，不触发架招成功；只有实际抵消物理伤害大于0才触发本次成功事件。神魂伤害不由本招抵消。
- 同一帧多人或多段来袭按现有结算顺序依次扣同一剩余额度。正面一次命中后，额度未耗尽则继续防御；侧后方命中不扣这份额度。
- 当前公共化解不直接改成持续护罩。后续实现须让本招保存剩余额度，每次合法来袭按原化解流程抵消并回写实际消耗，不生成护盾或新的支付资源。
- 达到上限或耗尽后，即使仍按住也不能自动续开；重新发动必须松开后再次按下，并满足费用与CD。结束清除剩余额度，不跨次保留。
- 暂停冻结动作及CD；进入帮助、配置或失去焦点时清除按住输入，恢复时不自动重新进入防御，按现行清理约定处理。死亡、重开、战斗结束与退出清除临时防御状态，不回写存档。
- 本招移动限制只影响普通移动，不改写已批准的击退控制或错步位移；成功错步先结束架招，原速度修正随之移除。

## 化法迁移

舒卷第一卷化法效果正文：**持剑时，本次架招首次实际化解伤害，获得2层剑意。**

每次发动架招最多获得一次；后续继续化解不再产剑意。只按住、空放、背后受击、属性闪避或无实际抵消均不获得。沿用公共剑意上限与回落规则。

百骸第二卷既有化法仍在架招起手气血至少4层时，使本次基础化解量提高20%。共享额度只在起手将初始A乘1.20并四舍五入，不在每次来袭时补满或重算；本轮不更改该化法的触发门槛与比例。

其他尚未迁移的旧队列架招化法不自动获得新的每击触发机会，须逐项按自身明文条件处理。
