# 战斗技能动态数值展示规范

## 目的

统一战斗技能牌、技能槽、行动队列、人物技能详情及卡牌词典中的动态数值格式。游戏运行时按设置显示简略结果或详细括号公式；策划案与静态图稿固定采用详细版，用字母标记动态结果，并在结果后紧接括号公式。同一技能不得在局内、词典和秘籍图谱中使用互相矛盾的公式来源。

## 局内展示（2026-10-26用户最新修订，现行）

以[信息简略与详细显示规范](信息展示与规则详解分层规范_20261026.md)为准。

- 游戏内设置可切换简略／详细，立即生效并保存；默认详细。
- 简略版只显示结果与必要条件；详细版在结果后紧接括号公式，例如“获得9点护盾（四舍五入(6 + 灵慧[5]×0.20 + 神魂[4]×0.20 + 术法造诣[5]×0.25) = 9）。”
- 伤害仍显示预估值；每段伤害、段数、状态层数等各自对应公式。费用、目标、关键词、独有触发条件、次数和冷却始终保留。
- 固定值不重复凑公式。无法预知的结果只描述实际效果与确定时机，详细版保留计算方式，不编造当前值。
- 通用命中、会心、防御等结算说明仍只在规则详解查阅；显示详细版不改变计算与支付。

## 静态策划案与draw.io（固定详细版）

静态图稿没有实际施术者。动态数值在效果文案中用字母标记，并在对应结果后紧接括号公式；不代入示例属性、状态层数或计算结果。

- 效果按字母引用数值，例如“造成A点物理伤害（A=表达式）……追加一段，造成A点物理伤害（A=同一表达式）。”同一技能中，完全相同的计算结果或公式重复出现时复用原字母；只有不同结果才新增字母。公式在对应结果后的括号中展示，不再仅放在效果末尾或独立详解页。
- 每项技能从 A 开始，按不同结果首次出现的顺序使用 B、C 等；原技能与化法沿用同一顺序，引用原效果数值时保留原字母。不同技能重新从 A 开始。
- 技能效果公式直接列出实际参与计算的基础属性及各自系数；原“身心协调值”项展开为 `min(体魄×a, 神魂×b)`，a、b 按具体技能分别确定，不把该派生值写进技能公式。
- 公式保留规则本身的常量与倍率，但不写角色代入值（如“体魄[16]”），也不附带某个示例的计算结果（如“=20点”）。
- 固定数值且不依赖属性或状态的效果直接写固定值；不为固定数值添加字母或公式。
- 静态技能、心法节点与化法公式只列该效果自身的基础公式及专属修正，不追加通用的物理伤害加成倍率，不为其单独增加提示行。此规则按2026-10-26用户裁定统一；运行时实际伤害仍按既有结算读取通用增伤。
- 不能预知的分支在运行时写“本次结算后确定”，计算方式放入规则详解，不以0冒充实际结果，也不把占位字母显示给玩家。

## 规则来源与范围

技能效果、费用、目标、关键词、触发、伤害及状态结算仍以[即时队列战斗系统设计](即时队列战斗系统设计.md)、[云息现行秘籍战斗技能与费用规范](云息现行秘籍战斗技能与费用规范.md)及对应技能资源为准；牌面不再展示攻伐／守御／术诀分类。卡牌图与秘籍图只同步描述格式及可核验公式，不借此改变效果数值。
