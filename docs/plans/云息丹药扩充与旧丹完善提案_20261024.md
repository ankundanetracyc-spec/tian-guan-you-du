## 二、药效设计原则

1. 每种丹先解决一个清楚的问题。回血、补气血、护盾、物防分开；直接回法与补炁周天分开；即时治疗、持续治疗与处理伤势分清主次；疗伤丹可附带少量回血，但必须有对应伤势才可服用。
2. 通用丹提供稳定的应急能力；构筑丹用于提前达到门槛或强化已有节奏，不赠送未学心法、招式、显臂或法器。
3. 短时物防适合连续小伤害，护盾适合先挡一段总伤害；慢回丹能有更高总量，但不能在即将倒下时顶替立即治疗。
4. 每种丹固定具有薄效、良效、优效、极效、满效五档，五档完整基础药效必须互不相同。高档提升实际效果，不另加稀有材料身份奖励。同一丹的持续／触发规则尽量固定，只让主要药效随档位增长。
5. 原有规则未明确的内容只写为提案。尤其战斗服丹入口、临时药效Buff和修炼药效存档，需要确认后才实现。

## 三、战斗服丹的配套提案（细则待审；2026-10-24最新方向见第十二节）

用户已确定方向：每名参战角色配置3个丹药／消耗型符箓共用战备位，每位最多放5件同一物品；丹药只限本人使用，不作主控角色专属限制。局内服丹拟作为系统行动排入本人队列，占1行动位，不占十个技能装配槽；不额外扣体力／法力／灵识仍为建议，实际生效时才扣对应战备物品。催血、休整与服丹拟在各自技能／行动定义上添加可供特定应对技能匹配的关键词，暂定名为“破绽”；这不是统一的行动类别，也不是角色身上的状态。只有应对效果明确写有“打断”时才取消当前行动。角色死亡或服用前置不成立时跳过；若药效无任何收益则保留物品。服丹不能被复制为免费药效，不凭空触发“施展剑技”“完成应对”等事件；它造成的真实治疗、气血变化、周天等仍触发现有公共事件。

战备位数量与容量已按用户确认方向记录为每人3位、每位最多5件同一真实消耗品；丹药与消耗型符箓共用这3位。单场最多服用量由实际编入数量决定，不另加“每回合最多一次、每场最多三次”的丹药通用上限。2026-10-26 回春／通脉已接入战斗战备位，静心仍只有世界用途，详见12.4实装边界。

同名持续药效不相加：较高档替换较低档并按新持续时间重新计时，同档刷新，低档不能覆盖高档；当前作用对象若不可能得到任何收益，不扣药并保留战备物品。若只剩部分缺口，允许服用但按上限截断。不同药效只按明写字段生效，不让同一份加成反复重算。

下文“2回合”按现有Buff口径：获得回合不扣时长，从下一完整回合结束开始递减，战斗结束清除。周期治疗在此药效的后续自身回合开始时结算，共两次；不在获得时额外跳一次。技能次数型药效只读取后续真正成功结算的合格技能，落空不消耗药效次数，战斗结束清除。

### 旧丹的完善细节

**回春丹**：名义治疗提高为30／50／80／120／160，五档都是不同的固定值；继续只写“恢复N点生命值”；修复生命与伤势处理分开。局内版不增加临时生命上限、不复活，不在战前囤治疗转成超额生命。回春用于马上活下来，续生用于还有时间时提高总恢复量。

**通脉丹**：当前`floor(法力上限×比例)`在上限1—3时经常为0，这是真实的前期体验缺口。建议改为：`法力上限>0 && 当前法力<上限`时恢复`min(缺口,max(1,floor(当前上限×比例)))`，否则无收益不可用。这里读取当前有效上限，不能借丹药恢复斫基已燃烧的法力上限。低法力角色不同档可能都实际只回1点，是容量截断，不另造“同档不同基础药效”。五档百分比仍固定。此修正未实施。

**静心丹**：守住“世界负心境恢复”的用途，不加免控、洗心隙或恢复局内神魂等无关效果；负值不足时到0为止。以后若做战斗净化，应另设明确药物与可净化目录。

**接骨／和中**：现有内伤／外伤最多4层，单靠整数解除层数无法排出5个非零且各不相同的档位。因此改为“解除对应伤势＋少量生命恢复”的完整疗伤效果。五档分别为1层＋8生命、1层＋16生命、2层＋24生命、3层＋36生命、4层＋48生命，完整药效严格不同。只有受伤时才可服用：没有对应伤势时，即使生命未满也不扣药，避免取代回春；生命已满但存在对应伤势时仍可用于治疗伤势。较高档收益按现有伤势／生命缺口截断。

五档的完整基础效果必须不同；不允许再把1／1／2／2／3作为这类丹药的整套效果。实际生命、法力缺口或资源上限导致收益相同，是目标当前状态截断，不额外生成“溢出奖励”。

### 关键联动与限制

- **赤髓不是回血丹。** 增加气血不会即时触发回落治疗；只有之后发生符合既有规则的气血降低才治疗。散血不触发回落，药物不能把散血改成治疗。
- **培元不赠送当前层数。** 例如气血6/8服下优效后变6/11，不变9/11。只提升上限，本场结束一并清除；不会自动显臂或提高别的上限。采用战斗型时长，避免中途到期强行压低气血、凭空触发回落治疗。
- **百骸门槛照旧。** 第二卷一臂4层、第三卷两臂4／8层、第四卷3／7层。丹药只让当前气血达到门槛，是否有臂、臂数和追加段仍由真实心法决定。
- **引炁与通脉不同。** 通脉救当前法力；引炁可触发周天及玄枢槽10，但可能未达到阈值，也会清掉溢出。当前法力上限为0时不服用引炁／续灯；不是无条件“完整周天丹”。
- **续灯不修复斫基燃烧。** 斫基以法力上限燃烧换来的费用转换保留；续灯只按当时的实际法力上限触发公共周天，不取消代价，不再次赠送被转换技能。
- **抱朴要求真实应对事件。** 队首架招空放不触发；服药自身不是应对。百骸自动应对若按既有系统实际触发，也可计一次；不能同时按物理伤害段、血臂数量、状态显示多扣多发。
- **藏锋按一次完整技能消费。** 在该技能所有物理伤害段及其已有规则追加段上使用同一增伤率，只应用一次，不为每个段把35%复乘；神魂伤害、其他人追击或之后自动施展的另一项技能不继承。命中、目标、应对与费用保持原技能规则；不额外生成伤害段。
- **凝念不是“念加伤药”。** 目标搜索沿当前寄念的后续主动技能逻辑，不选系统行动、法器召出入口或服丹本身，还需该技能实际读取念。无目标则本次不扣丹；念遵守实例共享、战后清空规则。若当前开放技能没有可用读取者，暂缓上架凝念丹，不为它新造一招。

### 世界药效的补充判定

- 纳灵丹不能把超出本层门槛的灵力预存到突破后；满门槛、十层归元养息阶段或不使用该灵力进度的境界不扣药。纳灵负责直接购得少量进度，培灵负责让真实修炼时间更有效。
- 培灵与益思分别只维护一条同名有效药效，按高档替换／同档刷新规则处理，不能叠多个百分比。没有同时真实吐纳和真实研读的同一时段，因此不重复消费两种时长。状态需保存剩余有效小时，不能用退出／分段修炼复制24小时收益。
- 吐纳经过瓶颈和境界等既有修正后，在对应药效时段乘一次加成；跨越药效到期、瓶颈或晋层门槛必须拆分结算，不对整段时间重复乘。归元九息不读取普通吐纳加成。
- 养伤丹是明确的新恢复来源提案，不把普通行旅、修炼计为休息。`重伤`恢复已接近完成时只抵扣剩余值；实例标记用药次数，重新受伤的新实例重新计数。超出云息的伤势先不开放，避免九品／八品药以固定规则跳过高境界恢复门槛。
- 两种突破丹不增加突破成功率，不取代其他条件，不把旧旅程赠送资源偷偷升级为高档物品。现有突破物品如何迁移到五档需另审：旧物品不扣回、不自动增送，新造档位与旧持有判定统一后再接炼制来源。

## 七、几组具体选择

### 7.1 凝罡丹与金肌丹

优效凝罡给64护盾；优效金肌给3物防、持续2回合。凝罡更适合承受眼前的高伤害，金肌的收益随有效物理伤害段数增加；在每段都有至少3点可减伤的简化条件下，2回合内20段最多减少60点伤害。金肌也可用于对抗仍读取物防的穿盾攻击。此为区别示例，不代替正式伤害顺序；物防与护盾的平衡需按实际战斗段数再校准。

### 7.2 回春丹与续生丹

优效回春立即恢复80；优效续生后续两次各50、总100。前者救急，后者在能活到后续回合时更省药。两者都不移除重伤、内伤或外伤。接骨／和中优效只回24，但同时解除对应伤势2层，药物职责不同。

### 7.3 百骸与赤髓丹

第三卷气血2层时，优效赤髓+3到5，达到单臂门槛，但不够8层双臂；气血5层服用同一颗可到8，出现双臂。丹药相同，构筑当时的资源决定战术收益。没有装备该心法者只获得气血，不凭空得到手臂。

### 7.4 玄枢／斫基与引炁丹

当前法力上限M=3、炁4，优效引炁+3使炁达到7≥6，完成一次周天，炁清零而不是保留1，法力回到3；有玄枢心法时再按原规则触发槽10。若斫基已把上限烧至1，阈值为2，同一药物仍至多完成一次周天、只把法力补到1，不修复被烧掉的上限。

### 7.5 剑式的两种药物

剑意2层时优效砺锋+3到5，可让尽锋比未服药多读3层剑意；每层2点的现行公式下多6点基础公式项，仍需命中才消耗。优效藏锋提高下一项带“剑”关键词的物理伤害技能20%，依赖该招原本强度，和砺锋的固定层数路线不同；两者共同竞争服丹额度，不能同一回合连吃两颗当免费爆发。

这些是**丹药效果目录**，不是25套材料脚本。方向上，凝罡偏护、金肌偏固、续生偏生与藏、轻身偏行、赤髓偏生与聚、引炁偏聚与通、砺锋偏聚与引、安神偏镇与明；这里只表达应去材料原表寻找的能力组合，不给任何材料新增专有效果。

当前运行结算器仍只识别生→回春、通→通脉、镇→静心三个核心；若直接加“生→续生、赤髓”等同核心丹种，单靠取最高评分会互相抢结果。扩充设计现已按核心、全炉五行及阴阳划分方向；不增加每丹固定辅功资格清单，辅位仍走现行通道。不能让“载入某丹方”直接强制变成该丹，更不能按材料名字硬编码药效。

本轮不伪造材料白名单、未试算的阴阳阈值或保证满效的丹方。获认可后先做首批丹种的成丹需求表，再用现有材料自由组合跑出多条真实路线，最后将高效组合记录为样方；保持当前“药性要求→自由组合→总结丹方”的方向。原有君臣佐使功用范围、味数解锁和份数灵识限制不因本提案自动扩张。

## 九、建议实施顺序

1. **先做容易理解的通用药**：完善回春／通脉／静心，加入凝罡、金肌、赤髓、引炁、砺锋；先验证局内服丹的行动与物品消耗闭环。此阶段不塞满25种。
2. **再加维持与反制选择**：轻身、续生、接骨、和中、回气、抱朴、藏锋、续灯。重点检查与现有应对、气血回落、周天、复制技能的触发边界。
3. **随后做世界长期药效**：纳灵、培灵、益思、返元、养伤。先补有效小时／实例限制的保存与分段结算，避免切时间套利。
4. **最后接突破丹迁移**：保留旧物品与晋层条件，确认五档收益后再接丹种识别、炼制获得、持有检查与消耗。凝念随实际可用读取念的技能同步上架。

## 十二、丹药在核心循环与局内入口（2026-10-24 讨论稿）

本节补充丹药在个人修仙循环中的职责和使用入口；它是待确认的接入方案，不把本文其余提案提升为现行规则，也不改当前运行数值。

### 12.1 在游戏循环中的职责

现行个人修仙循环为“落脚点修行 → 近域探索／交易 → 战斗或事件 → 返回整理 → 云息突破 → 选择更远地点”。丹药作为这条循环中的消耗品补给：探索与炼制提供持有来源，行旅、战斗和修行提供消耗场景，玩家在出发前或局内选择何时投入；丹药不能代替突破条件、秘籍学习或角色养成，也不应成为某条流派的必需入场券。

按使用时机分为三组：

1. **行囊即时药**：回春、通脉、静心等，在大世界行囊中按现有“使用”入口直接生效。当前三种药已有正式物品与使用处理；本次扩充不把静心丹改作战斗驱散。当前运行代码中行囊服用不推进历法，本节不借扩充暗改这一行为。
2. **战斗战术药**：凝罡、金肌、赤髓、引炁、砺锋等，只在即时战斗中作为队列行动使用。消耗一个行动位，让玩家用一次正常战斗行动换取治疗、防护或构筑铺垫；不额外占技能装配位，也不制造队列外的免费效果。
3. **修行与关口药**：纳灵、培灵、益思、返元、养伤服务世界修行、行旅和恢复；定脉丹、归元定息丹继续作为对应晋层关口的条件物品。带“剩余有效小时”的药效须存入正式存档，并只随对应的真实吐纳／研读结算递减。

### 12.2 战斗服丹流程（2026-10-26 首版接入）

战前准备阶段给每名参战角色配置 **3 个共用战备位**；丹药与消耗型符箓共用，不另设丹药栏、符箓栏或药带。每个位可放入最多 **5 件同一物品**，不同物品不能混堆；允许重复配置同一种丹药，但每个战备位仍分别计数。战备配置从该角色自己的真实行囊选取，开始战斗时预留对应数量；战斗结束后未用物品返还，成功使用的才从行囊扣除。战斗中只能使用已编入战备位的物品。

即时战斗规划阶段提供“战备”入口，列出本人战备位中的物品及剩余颗数。选择后将一项“服用·丹药名”加入本人第一个空行动位；同一战备位可排入多项服用，但不能超过该堆当前可用数量，每次各占一个普通行动位。按角色统一行动速度结算，与技能、休整使用同一队列。丹药行动不进入十个技能装配槽，不额外扣体力、法力或灵识。锁定队列前可取消或调整位置。

丹药只允许服用者本人使用，沿用各丹效果表中的“自身”目标；不提供跨角色递药或战斗中打开完整行囊。所有参战角色均可使用自己实际编入的战备物品，不只限主控角色；队友 AI 遵守同样的战备位、物品数量、行动位和效果前置规则，不生成免费库存。

行动到达结算时再核验战备物品、库存与效果前置。战斗提前结束，或药效已无任何收益时，不消耗物品；对应行动位仍按现有队列规则结算，不插入免费行动。有效使用时消耗一个战备位内的物品。可服用总数受已准备的颗数限制；不另加丹药通用的每回合或每场上限。

服丹不是主动技能或应对，不触发“施展剑技”“技能命中”等技能专属条件，也不能被技能复制。作为系统行动，它的定义可增列与催血、休整相同的弱点关键词**破绽**，供明确针对该词的应对技能匹配；该关键词说明技能／行动本身露出可乘之机，不表示角色获得持续状态或归入某种行动类别。是否中断仍由应对效果是否明确写有打断决定。服丹实际造成的生命／体力／法力变化、护盾增加、气血变化、炁获得或状态施加，仍按现有资源与公共事件规则结算。消耗型符箓是否增列“破绽”，由符箓专题逐项定义，不因共用战备位而自动套用。

### 12.6 基于“破绽”关键词的敌方应对（建议）

当前即时战斗的应对主要匹配角色遭受的来袭攻击，尚无依据技能关键词触发的匹配条件。这里提出为可被针对的技能／行动配置表示其露出可乘之机的“破绽”关键词：它们即将结算时，若敌方当前队首的应对技能明确写明匹配该关键词，且费用、次数、条件均满足，该技能先于原行动执行。首批对象为角色技能**催血**、系统行动**休整**与战斗行动**服丹**；例如催血自身携带“破绽”关键词，但只给予自身2层气血，不把“破绽”施加给角色。未来其他技能／行动是否添加该关键词，须逐项写明，不能只因效果加了 Buff 或改变资源而推断。该扩展不代表现有运行时已经支持。

首轮只给少量精英／首领配置应对条件明确匹配“破绽”关键词的技能，建议每场至多一名此类敌人；该敌人的相关应对合计每规划段最多触发一次、每场最多两次，触发即计数，不论技能实际打断与否。携带该关键词的技能／行动没有攻击命中判定，因此不经过攻击应对的闪避门槛。应对先按技能本身明写的目标、费用与效果结算，不自动变成攻击，也不额外产生伤害。只有效果明确写有**打断当前行动**才会取消当前行动：打断休整则不回复体力，打断催血则不获得气血，打断服丹则不产生药效；若未写打断，且行动者仍存活、服用前置仍成立，原行动接续结算。这样“被应对”与“被打断”是两层规则，不会让所有匹配应对都强制取消行动。

这不是敌人的免费额外行动：触发时消耗敌方当前队首应对槽、支付该技能的应对费用并扣其次数／冷却，且推进其队列；未触发时到正常队列时走显式配置的普通分支，没有普通分支则沿现行规则空放。被打断的带标记行动自身队列位仍算完成，不返还行动进度；休整没有体力回复，催血不获得气血，服丹不产生药效且不扣丹，物品留在战备堆供下一规划段安排。未被打断的原行动在应对结束后继续结算；若应对效果令行动者死亡或使服丹前置失效，则行动跳过且不扣物品。费用不足、应对技能不在队首、触发上限已用尽或条件不符，都不打断当前行动。

敌方不得读取玩家未公开的战备配置或行动队列。应对只在携带“破绽”关键词的技能／行动实际到达结算点时，依据公开发生的行动触发；预先排入相关应对技能的精英／首领须通过现有敌方意图展示让玩家看见对应技能。玩家可以调整休整／催血／服丹时机、先消耗敌方有限的应对机会，或安排其他行动让敌方队首先推进。应对窗口不新增等待条或玩家临时反应输入；它嵌套在当前技能／行动结算前，不启动第二项正常行动。

此设计参考《洛克王国：世界》的应对思路：应对技能按对方技能／行动上明示的关键词匹配并先结算，只有技能写明“打断”时才额外中断原行动。参考材料：[应对机制说明](https://www.taptap.cn/moment/655448340921582529)；[“阻断”技能条目](https://wiki.biligame.com/nrc/%E9%98%BB%E6%96%AD)。仅借鉴“按明示关键词匹配、先应对、由技能明文决定是否打断”的结构，不照搬其分类、数值与节奏。

仍需结合战斗队列验收“破绽”关键词的匹配字段与触发入口、被打断后行动位和物品的处理，以及每场最多两次的首轮参数。符箓的战备位共用规则不自动决定其是否添加“破绽”关键词，须由符箓专题定义。
