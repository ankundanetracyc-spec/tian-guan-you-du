袖形修订已取消：用户明确暂不处理宽袖细节，保留此前四套服装与快速迈步表现。外门宽袖v2只留候选文件，不接入当前入口，不继续生成／绑定／验收。

当前最终移动裁定：用户撤销轻功飞行与纯平移，恢复迈步前进、面朝敌人倒步回位。采用已验证的袍内短步；用户最新允许滑步，移动时长压缩至每段0.35～0.70秒，步态维持1.8周期／秒，不再按锁足要求拖慢位移。视觉速度限制在原短步范围，避免高速度导致袍摆或腿部夸张。取消腾空、蹬地停留及飞行前后倾。保留层级修复和原攻击、受击、架招、闪避。下文飞行与地面短掠均为历史过程，以本段为准。

最终轻功动作裁定（覆盖下文地面短掠）：用户明确要蹬地后前飞／倒飞。上前为沉身蓄力→蹬地腾空前掠→落地接攻击；后退保持朝敌，蹬地倒飞→落地缓冲回待机。人物必须实际离地，影子留在地面；躯干前后倾、袍内收腿和衣摆拖动共同呈现，不以整张图平移或只转躯干代替。水平行进与离地高度由同一演出进度驱动，蓄力与落地阶段有停留；暂停冻结并正确恢复。保持队列规则与攻击起手后接触时序，允许按完整动作调整接近／回位演出耗时。

最新移动表现裁定：用户不要求一步一步行走，改为有轻功感的短掠；上前适当前倾、回位适当后倾，袖袍跟随并收势即可。保留袍内腿部遮挡与正常头颈衔接，不再以慢步频、锁足或38单位移动速度作为验收目标。下文逐步行走方案保留为过程记录，本段优先；仍只改演出，不改队列结算。

追加验收要求：试演背景改为与小比例人物相适配的实际战斗地面，优先复用原玉虚试玩对应场景；重点展示攻击、受击、闪避。修正腿部穿出袍面的层级与遮挡，须检查左右朝向及动作中间相位，不能仅验收站立截图。此项只调整表现，不改变行动队列规则。

上前与回位追加要求：复用原小人的前进与倒步步态，位移驱动腿、躯干倾斜及袍摆，禁止站姿平移或瞬移。原队列的0.18秒急冲与0.22秒腾空回位不适合该表现，已制作小人可按距离调整纯演出时长并沿地面运动；攻击起手后的0.30秒接触与原结算顺序保持，普通角色不受此次展示修改影响。

步态验收须同时检查轮廓：层级正确仍可能因原全速步幅、抬脚与骨盆下沉把膝盖推出窄袍。允许队列专用适配缩短步幅、降低抬脚及相应移动速度，保留完整腿骨链与鞋底接地，不通过删除大腿来伪装遮挡。

用户明确选定原即时试玩 `tools/action_battle_test/yuxu_approved_skin.gd`、`art/yuxu_fullbody_v15` 的小比例玉虚人物，不继续采用本轮v2/v3完整大立绘变形或v7整张攻击姿势切换。原素材、骨骼和动态待机复用，接到原回合/行动队列事件上；不恢复即时操作、不新增距离或碰撞命中玩法。

首套展示为呼吸待机、蓄势攻击、受击回稳、架招及闪避。腿部受连续长袍约束，主要显露鞋部，不采用夸张分叉或大幅迈腿。攻击与受击需体现发力、停顿和回稳，闪避由已有规则判定后触发表现，不以动画碰撞再次判伤。攻击接触、应对冻结及动作收尾沿用原事件时序。

外观仍须对应实际衣服与前后发；旧小人目前只有玉虚内门常服与烘在头网格内的发髻，不能将它强行替换给所有发型。本轮先按真实目录精确匹配已制作的一套组合；其他组合保留旧显示。独立前后发与其余服装资产是后续必须补齐的映射，不把固定发髻描述成可换发已完成。

先在隔离的远景队列试演中展示，三对三只改变显示尺寸与错落位置，实际逻辑仍为原队列。本轮完整动作展示还应提供同角色近景，便于检查肩袖、腰袍和鞋底衔接。下方大立绘/关键姿势阶段记录为历史方案，遇到冲突以本节为准。

### 画风与一衣一姿（用户最新确认）

2026-11-03追加授权：先以玉虚内门常服制作完整「待机 → 起手 → 出掌 → 收手 → 原待机」动作，并在原行动队列中验收。攻击动作由招式类型决定，服装提供自己的待机姿势、过渡和袖袍适配；不要求每套服装重做全部招式，但也不能跳过每件服装的遮挡与权重适配。当前只制作首套出掌示例，不扩展卡牌效果。

本轮动作验收：肩部固定连接躯干，肘部有明确屈伸，掌形与出掌方向一致，衣袖随手臂运动并有收势滞后；头颈与腰部不能随整张贴图被扯歪。大幅抬臂若超出原待机连续网格的适用范围，应补充动作需要的素材与结构。使用既有攻击接触点、暂停、应对冻结和收尾时序，不从动画另行触发伤害。必须同时查看完整过渡、接触姿态、回待机及左右朝向，不能只凭静态终点验收。

整体绘制语言向项目原有静态局内图靠拢：明确的墨线、概括的大块明暗、简洁衣褶和成组发束，减少写实织物、细碎绣线与发丝。保持真实衣服的颜色与身份，不把不同衣服统一画成旧图的绿色袍子。

每一套衣服设计一个专属基础待机姿势，让袖形、袍身和人物气质形成完整轮廓；不是所有衣服共用同一张站姿换色。基础姿势也要绑定骨骼，具有呼吸、轻微重心变化及袖摆跟随。第一套玉虚内门常服使用当前从容垂手姿态。后续衣服逐套确定姿态、蒙皮和衔接遮挡；可以共用骨骼命名与动作接口，不要求不同袖形、不同姿态使用完全相同的权重。

发型独立对应真实角色选项，不由衣服强制指定。各套专属待机保持脸朝敌人、躯干略朝屏幕及无五官要求。出招、受击等仍是该人物在原行动队列事件下的动作扩展，“一衣一姿”不意味着战斗过程中只能使用一张静态图。当前只完成首套试作，不据此宣称其他服装已经生产。

用户已明确要求在实际行动队列战斗查看这一套的效果，因而本轮允许该组合先接入共用战斗显示及首页验收入口，不再等待全部衣服完成。仅当真实目录解析出的男修衣服、前发、后发三项均与认可组合吻合时启用；其他组合保留原显示，不将其他人物强制换成玉虚常服。

第一套使用认可完整图建立连续加权网格，绑定 Godot `Skeleton2D` / `Bone2D`，避免颈部、肩袖和腰部独立裁片产生裂缝。胸肩呼吸、头颈轻动、袖摆与下摆错相跟随，鞋底固定于地面骨。保持设计图等比例缩放，不宣称该图为严格七头身。此阶段是单套造型的骨骼待机，尚不是衣服与前后发可独立替换的完整资产系统。

本轮动作期间保持同款骨骼人物并沿用既有整身演出，不能切回其他衣服的攻击图；专用肢体出招动作仍待后续制作。完成情况及实机材料见配套美术记录。

## 2. 首张可审阅造型

见[预览与生成记录](../美术规范/行动队列局内形象_20261103/README.md)。样例是男修玉虚内门常服、守真拢发与守真束髻，取真实已启用选项，不代表所有人物的默认组合。

脸朝向右侧敌人，躯干为朝右的正面三分之四角度，保留可见胸前交领、腰带和近远肩的宽度。脸面留白，眉眼鼻口均不绘制；通过头型、耳部轮廓与头颈转向表达方向。敌方成对反向制作或镜像验证后使用，不能仅让头转向而躯干背对镜头。

服装保留象牙白袍、灰蓝云纹、青灰交领宽边、外层肩片、宽袖、同色腰带结与小坠饰。现有服装源图为腰上立绘，因此全身下摆和鞋属于本次待审阅的延展设计，不能声称是已有全身资产。云纹以大组块概括，减少碎线，适合原队列中190～320设计像素的显示高度。守真发型保持露额梳拢、小束髻、收整后颈，不变成长披发，不增加发冠。

静站以双脚稳定落地、双手低放为基准，不预置行走或持续出招姿势。身体具有近远肩、肘腕、腰胯和双足的明确关系，便于后续小幅呼吸、抬手出击与受击回稳。先审完整人物，再决定分件和动画；此轮不批量生产全部服装。

## 4. 映射清单与缺件处理

配套[已解析源目录清单](../美术规范/行动队列局内形象_20261103/appearance_mapping_audit.json)列出活动包全部14个男女衣服款、14个前发和16个后发，对每项保存：性别、部位、保存序号、部件ID、名称、实际源图路径与SHA-256。十种外观衣物中，四种玉虚物品各有男女款。此清单是可复核的来源盘点，不是已经做完44项局内资产。

局内映射键建议使用 `package_id + gender + part + variant_index`，同时记录已解析的 `component id` 与源图路径；不要仅用汉字显示名或图片序号作唯一键。局内资产清单另存 `rig_version`、本体/近远袖/前后摆/头颈/前后发资产、动作集合、镜像规则、脚点及胸部/握持/受击锚点。美术文件升级时通过清单版本失效缓存，不改人物身份。

分层建议：后发 → 远臂袖与远腿 → 后摆 → 躯干服装 → 近腿/前摆 → 头颈 → 近臂袖与手 → 前发。具体遮挡由本件姿势验证后决定，长发允许从头锚点挂接并进入衣服后方。每套衣服需要自己的袖与袍摆轮廓，不靠同一袍身改色来表示所有衣装。短发、长发、髻与发尾分别保持真实外轮廓。头颈、手和脚属于本体，不能把某款衣服的领口或饰品烘进通用皮肤层。

缺某个动作时保留当前同款组装待机，通过既有整体位移/短停收尾，禁止换成另一套衣装姿势。缺整套衣服或某款头发时，预览工具明确列出缺项；正式入口继续旧实现，直到其实际可出现的外观覆盖完成。不能用固定玉虚服或长披发悄悄补缺，再声称换装已支持。本轮仅新增审阅图和数据盘点，不启用新渲染器。

## 5. 动作与站位接入约束

待机仅胸肩轻微呼吸、袖摆与发尾小幅延迟；脚底不循环上下漂浮。攻击按原系统动作事件进入起势、命中姿势、收手/回位，受击由真实受击事件驱动；无伤害事件不得因为图像接触再触发一次伤害。原近身接近与倒身回位、远程原地出手继续沿用，只替换人物内部动画。

新人物先建立自己的局内脚点、可见高度和动作锚点，再适配旧 `BattlePaperDoll` 表现接口；旧2048画布、1375参考高度和各手部坐标不能不经测量硬套。动画期间使用稳定脚点和统一尺度，不能每一姿态按透明外框重新居中。脸与身体按同一朝向控制，攻击受击不翻错面。

沿用半场可见外包框居中；双方较多人决定共同高度320/280/240/210/190，多人各自错排，单对单中心Y=495；不新增站位玩法。布局只读取待机轮廓，手/袍运动不能引起全队重新排位。选择框、生命/状态条、受击点按新锚点核验。

非循环动作结束纳入既有行动收尾等待；待机循环不阻塞。暂停冻结人物与特效，倍速仅影响行动进度，镜头特写使用既有流程。任何新美术时长只是表现参数，不形成技能前摇、后摇、距离或速度属性。

## 6. 实施顺序与验收门槛

1. 本轮：完整造型预览、真实数据映射与缺口清单，交用户看造型。只制作这一个组合。
2. 造型通过后：为同一组合制作局内专用分件与待机/通用出手/受击，验证左右朝向、无五官、领口肩袖连续、脚点稳定及袍摆遮挡。仍先在独立队列美术审阅页，不修改即时试玩。
3. 对同款扩展原队列必需姿势，并以另一套真实衣装和短发验证可替换性；每种源部件明确对应，不做整人物组合的指数式重复绘制。
4. 覆盖正式入口会出现的全部衣服/前后发与装备显示后，再接 `portrait_data` 和动作路由。若外露装备的优先级/层次仍未定义，先报告具体冲突请求确认，不猜测装备覆盖规则。

后续运行验收必须包括：换衣进战斗；仅换前发；仅换后发；同种衣服男女款；混搭发型；进出战斗存档前后身份不变；同角色待机/攻击/受击/持剑/施法/休整不换装；缺姿势不换装；左右朝向；1对1与1对5/5对5；暂停恢复、真实应对插入、最后一击收尾。检查时记录实际源部件ID，不能只观察“都是青色衣服”。

本轮验证范围：源清单读取、衣服物品索引匹配、44项源图存在与哈希、样例索引、生成图格式/透明度与人工外观检查。未改运行代码，未运行编译或宣称场景冒烟通过；没有新增卡牌、资源、关键词、射程、位移机制或存档规则。
