# 炼丹中心丹炉测试界面（2026-10-16）

状态：当前测试界面方案。配伍仍以《炼丹主药辅药拖拽试演》为准；本页覆盖其双投药区、常驻调试指标和五味同息入炉的界面实现。用户本轮要求中心丹炉、图标药材、悬停信息与直接拖入丹炉。

## 概念与指标整理

- 独立“丹核”目前没有额外可玩操作，不再作为玩家要理解的对象。已有成形过程统一称“成丹进度”，保留原型内部计算，未增加新资源或新步骤。
- 原来的“主体完整17%”是释放比例×剩余完好度，容易被误解成药材坏了83%。界面拆成“主药已炼出17%”与“主药完好100%”。内部乘积只用于工艺评分，不用作完好率显示。
- 原来的“有效3.1、5.5”是品阶换算强度×释放比例×完好率，移出主界面。悬停改为“已炼出多少”“当前可发挥约多少”“等待哪个阶段”。
- 混合、阴阳、成丹内部阈值、留存与长日志收进“详细炉记”；前景只显示当前过程进度、实际/目标炉温、主药完好、阴阳是否合格及资源负担。

## 布局

- 左：药材图标网格，悬停显示质地、五行、阴阳、适温/耐温与功用。每次拖一份，不展示长属性卡。
- 中：直接绘制的简洁丹炉图形作为唯一投药目标，无需生成美术素材。炉上显示温度，炉下显示当前过程进度与炉内材料图标。
- 右：本人/副手法力，副手切换、回气和服药；下一息灵识占用及风险；本息最多五条可读变化。
- 下：炼药/混药/成丹/收丹选择，目标火候滑条与温火/强火/收火快捷按钮，推进一息。
- 顶部丹方区域预选一种主药。拖入选定材料自动视为主药，其他材料自动视为辅药；已有材料待投或入炉后锁定选择，重新开炉可改。单炉主药仍只有一种，可多份。
- 左下待投图标可点击撤回。所有安排在下一息结算时真正入炉，查看、悬停和拖拽不推进时间。
- 炉内同种同类材料合并成图标和数量，悬停查看平均释放与完好度、各功用当前状态；点击可以固定打开信息窗口。

## 分批演示

不再先拖完所有药再统一结算。新演示选择兽骨主药：

1. 只投兽骨，实际推进强火炼化，草木材料留在药架。
2. 主药至少炼出95%后收小火；实际炉温降到55以下才投青木芯。
3. 青木芯炼出一部分后投入苦苔根；演示它的阴性调整阳偏，藏减少散失。
4. 苦苔根开始发挥后，把松脂和雾铃花作为一批安排，下一息入炉，兼顾阴阳并为成丹准备固、引。
5. 混药达到要求后成丹，再降温收丹。

这套顺序只演示一种有理由的路线，不宣称是最优配方。实际选择仍取决于质地、火候、功用、数量与能力。副手按本人法力不足时接管，接管前检查自身灵识占用；不够则使用回灵散。

不擅自加入上一轮仍在讨论的“聚、固提前发挥会妨碍混合”规则；当前只改善操作与解释，相关工艺取舍仍需继续讨论。
