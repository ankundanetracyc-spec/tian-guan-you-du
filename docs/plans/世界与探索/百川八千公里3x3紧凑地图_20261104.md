## 保持拓扑的重烘焙

同一画面缩放重烘焙时，浮点栅格边界会产生17格舍入差。为使旧连续路线保持可恢复，本版使用经过母图SHA、来源布局SHA、8000公里尺度和网格尺寸校验的旧通行格，重写新画布元数据。重建命令应保留：

```powershell
python tools/world_map/build_bai_chuan_free_navigation_20261104.py --preserve-topology-from E:/stacklands/resources/world/bai_chuan/free_navigation_20261104.json --review-dir E:/stacklands/output/bai_chuan_free_world_3x3_20261104
```
