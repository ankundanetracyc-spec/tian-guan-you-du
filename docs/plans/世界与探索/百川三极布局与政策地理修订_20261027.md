# 百川三极布局与政策地理修订

后续细化：[地貌与主通路规划](百川地貌与主通路规划_20261027.md)，新增自然地貌与道路用途示意，保持本轮疏密、亲疏与城约关系。地貌色块不表示行政边界。

> 最新疏密修订：玄都右移至43／19；西南城市拉开，中部由承天、春水、通济及野外联系带承接。仙盟只是一处图外独立节点，不占中心空地。123个具名地点＋313空节点，169条候选路线。位置以结构化规划数据与[三极布局主案](百川三极布局与政策地理修订_20261027.md)本轮补充为准。

> 本轮最新空间关系主案。用户指出：太微不再是一级势力，旧四角分布不应继续；远近可以反映归属与政策。按此修订地图和关系。具体位置、政策表达与城约调整为工作方案，尚未实施运行时。
>
> 覆盖旧稿“地方宗门刻意远离同阵营、由地理决定邻居而不由站队决定”的排布理由；继续保持三个一级、十个独立二级，站队不等于行政隶属，以及二级山门不紧贴一级山门的要求。

## 一、三极明确，太微回到地方层次

玉虚仙宗仍在西南22／74，玄都天府仍在北部偏西43／19，无相圣宗仍在东部偏南83／61。本轮玄都由32／19右移至43／19，玉虚与无相位置保持；同步疏解西南城市，补充中央联系带。

太微道宫从东北81／18移至35／50，处在玉虚北侧的内陆联系带，邻近承天城、赤水城与通往西南的道路。它仍是有历史分量的地方强宗，但不独占一个与三大对举的远角，也不另配一组区域核心城市来制造第四极。

东北由镇海城、湖港、沧溟水府及野外承接，沧溟水府位于72／17，作为玄都倾向的地方水府参与往来；北海岸不是另一套与三大平级的号召中心。

## 二、亲疏通过地理与实际往来表达

| 联系方向 | 地方宗门位置 | 空间关系 |
|---|---|---|
| 玉虚 | 太微35／50、镇岳12／47、抱朴43／65、百药36／91 | 从西部山地经内陆联系带延伸到南部林谷，形状不规则，不围山门排圆环 |
| 玄都 | 丹鼎61／8、归藏62／37、沧溟72／17 | 北部高地、盆地与东北水路相连，矿产及城港贸易形成合作基础 |
| 无相 | 枯骨83／36、血河65／82、蚀日88／88 | 从东部古寺丘陵到南部深谷，围绕东部道路及产地形成联系 |

这一版十宗与各自倾向大宗的直线距离总体小于与另外两家的距离；这只是检查亲疏表达是否自洽，不是世界内判定阵营的规则。各二级距最近一级仍约为图幅短边21—29个百分点，有完整城镇和野外间隔。

山河屏障、实际通路和经营往来比单纯直线更重要。正式地貌落位后，应校准实际行程，不能只凭最近距离推断归属，更不能靠挪动坐标自动修改城约、人物立场与产权。

## 三、城镇和产地随关系一起调整

| 片区 | 城镇与道路联系 | 主要调整 |
|---|---|---|
| 玉虚近侧 | 太和、白石、溪云、春水、青萝及外围镇坊 | 春水府与其湖岸聚落移入西部内陆联系带；青萝城与百药林谷南移，连接抱朴河谷与玉虚生活圈 |
| 玄都近侧 | 金阙、望岫、绛阙和东北镇海城 | 归藏书院北移，沧溟水府北移；镇海城与澜浦渡移到东北海岸，通过北部水路连接 |
| 无相近侧 | 永夜关、暮烟、东部归寂城 | 枯骨寺及归寂城、古寺丘陵遗迹一同东移，避免寺在南西而附属城市与产地横跨半图 |

资源不是只改地图上的宗门图标：太微的天籁长峡、玄霜坞移到其北侧；百药谷的万毒谷、盘龙涧、不老林随林谷南移；归藏相关砺青崖、含章窟靠向北部盆地；鸣玉溪靠向沧溟水府与临渊城；藏蜕林靠向枯骨寺。只调整规划位置，不改变材料池、储量、品阶和产权方案。

少量远方合作保留：紫泥湾仍由溪云城公有、归藏书院签约经营；蕴辉岩仍为血河教与枯骨寺共有。前者是跨圈经营，后者是同一联系圈内跨距离合营，不能因离得远就当作数据错误或直接收归最近宗门。

### 3.1 城市疏密与中部补充

用户指出西南城市过密、中心过空。本轮不增加城市数量，重新安排现有十六城，使大部分城市之间有完整城镇、野外或空节点路段，保留少数联系紧密的局部。原最邻近两城约相距图幅6.4个百分点，本版约16.5个百分点；这是布局复核结果，不是游戏内最小间距规则。

| 地点 | 本轮位置 | 布局作用 |
|---|---|---|
| 太和城 | 11／68 | 移至玉虚西侧，拉开与白石城的距离 |
| 白石城 | 28／65 | 玉虚东北生活节点，与西侧太和城分开 |
| 溪云城 | 49／74 | 东移，衔接南部河谷与中部通路 |
| 青萝城 | 30／87 | 南移，避免紧贴溪云城；百药谷仍在其东南 |
| 承天城 | 43／37 | 北部向中部过渡，接归藏与太微方向 |
| 春水府 | 49／55 | 中部偏西湖谷，周围有镇与野外 |
| 通济城 | 65／51 | 中部偏东联系点，承接归藏、无相与南部道路 |
| 金阙城／绛阙城 | 34／10、54／19 | 配合玄都右移，分别承接北侧与东侧往来 |

中部不只补城市：天碑原59／44、东林地58／55、镜月泽72／58、雷泽75／44、碎星滩61／63、灵草谷56／67与落星墟68／69构成可经过、可探索的联系带，空节点仍负责地点之间的过渡。这些普通野外不因位于中心就统一归仙盟或某一宗门。

仙盟仅是一个普通尺度的独立节点，暂不与外界相接；既不需要大型城池占地，也不预留中心领地、隔离环或大片背景空白。本轮中心空白按正常世界内容重新使用，仙盟依然不赋世界坐标，未增进入方式。

## 四、政策需要可见的落点

下列为各联系片区的内容方向，具体城约高于片区概括，不把所有宗门政策写成完全相同的阵营模板。

| 联系片区 | 主要政策表达 | 在地点内体现 |
|---|---|---|
| 玉虚近侧 | 重师承与驻地护持，常用产地兼顾开放与封育 | 本门成员可询问已知路况、参加维护采办、进入约定区域；城镇保持自身日常机构 |
| 玄都近侧 | 重契约、经营与贸易往来 | 产地许可、合营与城港采购关系更明确；按具体约定接待，不默认封锁异阵营来客 |
| 无相近侧 | 强调本门庇护和资源边界 | 本门成员与来客的通行范围区分清楚，争端按当地产地约与事件处理；不把所有外人自动当敌人 |

附近城市更容易采用相近的驻守、许可和往来安排，较远地方则通过常驻人员、采购与明确协议维持关系。尚未设计的服务不显示伪可用入口；不在本轮追加税率、通行费、掉落倍率、自动仇恨或战斗收益。

归属与政策分开：一座城靠近玉虚可以与玉虚往来频繁，却仍由城约三方轮值；一个产地归沧溟所有，也不因临近无相就变成无相资产。政策变化要有城约修订、经营协议或具体事件作为依据。

## 五、保留接触带，避免三块封闭地盘

承天城在玉虚与玄都接触带，保留归藏书院、太微道宫、玄都天府共同城约；赤水城在玉虚近侧，仍自治；通济城在三方往来地带，仍由本地机构治理。

临渊城由倾向玄都的沧溟水府护持，却临近无相北侧，是少量跨圈通商接口。其实际规则由沧溟与城约决定；邻近无相意味着交涉和护路需求，不意味着自动敌对或自动转属。

三座轮值城的工作轮序随位置与联系修订：

- 镇海城：沧溟水府 → 玄都天府 → 归藏书院，替代此前远方太微参与的排表。
- 春水府：太微道宫 → 抱朴山 → 百药谷，承接西部内陆湖谷联系。
- 溪云城：抱朴山 → 百药谷 → 太微道宫，形成西南至南部的地方协作。

其余城约、轮值任期方案和库存交接边界不变。这些是初始世界的城约工作排表，不是游戏里因为地点移动而发生了一次无事件的政权更换。

## 六、路线与验收

按新位置重排为123个具名地点、313个空节点、169条地点间候选路线，世界路线图共436个节点；仙盟仍独立不相接。数量因真实分布调整而改变，不维持旧287个空节点的凑数目标。

已检查具名地点唯一、资源归属与供给引用有效、十地方宗门的亲疏方向、436个路线节点全部互通，以及仙盟没有外部连接。图中交叉线仍不自动互通，最终山川地貌与路口形态需要后续勘定；不把本次比例距离当旅行耗时。
