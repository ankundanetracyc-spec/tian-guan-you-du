# 地图节点表现与地点粒度规划（固定路网旧案）

> 状态：历史资料，固定路网旅行规则已由[《百川固定方格世界地图设计》](百川固定方格世界地图设计.md)取代。
>
> 本文只保留真实地理地点的粒度原则，供地点目录与旧数据迁移参考；本文中的固定地图交互、双击道路旅行、节点信息面板、底图坐标和固定路网验收不再是现行规则。

## 一、地点不是功能入口

世界地图上的地点要表达角色实际能够抵达的地理位置，而不是交易、委托或采集按钮的集合。

功能集合：郊外集市、任务大厅、资源采集点、宗门商店  
实际地点：白石镇、青溪里、东林地、青岚观、玄水渡

“交易”“打听”“接委托”“采集”“拜访”等功能，在抵达对应地点后作为地点内部行动出现。

一个常驻地点至少有稳定名称与地理含义、独立空间或可抵达边界，并且不因某项功能关闭而从地图上消失。

## 二、地点与地图要素

| 要素 | 含义 | 例子 |
|---|---|---|
| 实体地点 | 有建筑、入口或稳定地貌锚点的场所 | 白石镇、青溪里、玄水渡、遗迹入口 |
| 野外区域 | 有边界和内部体验的地貌区域 | 东林地、灵草谷、镜月泽 |
| 道路/航路 | 影响格网通行和移动代价的地图内容，不是城镇或独立经营地点 | 山谷古道、渡河航路、大光道 |
| 临时异象 | 依附地形、存在期限的动态机会 | 洞府现世、妖潮、蜃门、短期秘市 |

水系、山口、森林、道路等地貌可以作为方格地图上的通行条件、视觉拼块或辖域边界，不因此成为新的地点节点。

## 三、地点内部功能

实体地点和野外区域抵达后进入统一的地点场景结构：

地点环境与已知状态  
→ 场景标签 / 在场人物 / 地貌热点  
→ 对应功能界面或探索副本

交易、人物、任务、采集和探索留在真实地点内部，不增加纯功能地图节点。地点模板决定共用的交互与结算结构，静态地点数据决定具体内容；动态状态、资源数量和事件状态不得写回静态地图场景。

地点内场景、标签和行动数量继续遵守《地点模板与节点互动框架》与《UI视觉规范》。地图侧的格网移动与地点锚格规则见《百川固定方格世界地图设计》。

## 四、已有目录迁移参考

| 旧地图内容 | 处理原则 |
|---|---|
| 白石镇、青溪里、青岚观、玄水渡 | 保留稳定地点 ID 与真实地点身份 |
| 东林地、灵草谷、镜月泽、十万大山 | 作为有内部场景或探索内容的野外区域 |
| 坊市、客栈、公告栏、宗门商店 | 作为地点内部场所或行动，不独立占格 |
| 大光道、山谷折线、渡河航路 | 作为格网地貌、通行条件或移动代价 |
| 相柳毒雨、蜃门回航、残碑微光 | 作为依附固定地貌的临时状态，不进入常驻地点目录 |
| 旧地图坐标与节点道路 | 固定地图的迁移参考；新格网数据以现行地图场景/数据为准 |

固定地图的拼块组合、格子通行、旅行耗时、战争迷雾、路径预览与存档规则，以《百川固定方格世界地图设计》为准。
