# 云息期动态野外历练：雾隐幽谷首期实施记录

**状态：现行实施记录（2026-10-15）**。本页细化并记录《副本生态、材料来源、刷新与多层地图提案》第十节的首期实现；规则以用户确认的“180日检查、360日开放、两处上限”为准。东林地仍是原有常驻副本，原布局、任务、采集及存档进度不并入动态实例。

## 目标与边界

从白石镇自由世界开局后，玩家可自行发现并反复游玩“雾隐幽谷”。这是可选历练地点，不是宗门任务链，也不影响云息阶段的修炼、入宗、突破或12–15年目标。本期不生成真人NPC，不增加物品、配方、属性、Buff、掉落池、额外灵感倍率或新制作规则。

## 机遇出现与地点

- 动态历练首次在自由世界地图就绪时立即进行一次生成尝试；后续每180个游戏日检查一次。读档恢复既有调度游标，不重复首次生成。
- 每处幽谷从生成时起开放360日；每次检查先关闭到期入口，再按当前开放实例计数尝试生成。开放入口最多两处。达到上限、候选地点为空或世界地图不可用时，本期直接跳过，不累计补发次数。
- 候选格由玉虚仙宗核心锚点出发，在可通行世界格上做正交寻路，距离不超过10格；只选林地或山麓，排除地点占地、玩家所在格、当前有行旅者的格和已占用的幽谷入口。
- 入口标记只在玩家已探索的世界格显示，不揭开迷雾。找到入口后，须在入口格使用地图的“进入·雾隐幽谷”。
- 同时存在的入口分别持有稳定实例ID、模板ID、种子、世界格、生成／到期时刻、入口状态和完整地图快照。每期抽取确定性候选，读档不重抽位置和种子。

## 雾隐幽谷地图与内容

- 每个实例生成一张单层16×8地图，共128个唯一节点。节点以正交边相连，完整地图连通并可回到出口；实例种子决定地貌变化，地图节点、边、资源、事件和路线发现均写入实例快照。
- 入口位于竹林边缘。竹林资源点偏向苦苔根、月露苔和线索；中段以湿地及回涌泉眼为视觉与路线连接点；岩隙配置灵石矿点、岔路发现和林地凶狼遭遇。
- 竹影、泉声、爪痕各有两个调查选择。每次选择消耗1小时、1点精力，并记录唯一事件结果，只揭示所选方向的一段路线；重复回调不重复结算。调查不给物品或额外奖励，妖兽是否应战由玩家选择。
- 采集沿用现有苦苔根、月露苔、雾铃花、灵石物品及现有背包、精力、行动时间、采集灵感强化和战斗奖励结算。凶狼使用现有“林地凶狼”战斗模板和兽骨／兽皮奖励。每个妖兽记录有独立身份。

## 生态与到期

- 入口开放期间，资源按分类恢复：常见植物7日、雾铃花等慢生植物30日、矿产90日。恢复游标按实例和资源点独立存档；首次采集开始新的恢复周期，不因实例已经存在很久而立即补满。
- 普通凶狼每14日检查一次补充。被击败的个体身份和结果记录保留；补充时创建新身份，不复活旧个体。
- 入口到期后停止新进入，并停止该实例后续资源及妖兽恢复。若玩家仍在副本内，可继续行动并通过原出口离开；到期不强制撤离、不重置地图或事件。离开后入口不可重入。
- 世界地图入口状态与内部实例状态分开保存；到期实例不会被新一期覆盖。实例内部读档恢复原格位、已知路线、资源、事件与遭遇。

## 存档与迁移

- 正式存档格式提升到v8，新增独立的 `dynamic_dungeon_state`。动态实例不写入东林地既有状态字段。
- v7及更早存档迁移为空的动态副本表，以存档日历建立周期游标；不追补历史机遇或资源。东林地状态和任务进度保持原值。
- 进入、行动、战斗往返、离场、到期与自动保存均通过实例ID定位状态。存读档恢复活动中的副本；如果保存时玩家仍在已过期实例内，仍以内部状态恢复。

- **构建：**`dotnet build Stacklands.csproj --no-restore -nologo`通过；变更后最终构建为0警告、0错误。
- **Godot场景冒烟：**`tools/DynamicDungeonExpeditionSmoke.tscn`通过。覆盖首次生成、防重复、180日调度、360日到期、两处上限、失败不欠发、同种子一致、实例隔离、128格正交连通、调查选择单次结算、采集后7日周期、30／90日参数、14日新妖兽身份、到期仍可在内部、v7→v8迁移保留东林地状态，以及正式Resource存读档。
- **脚本与场景解析：**Godot .NET 4.7无头编辑器完成脚本类注册与场景扫描；发现一条既有 `MainScene.tscn` 节点父路径警告，没有动态副本脚本解析错误。未做人工试玩。
- **后续边界：**本期未接多层地图、真人NPC或其他动态副本模板。世界地图位置选择与正式游戏中的点击、视觉表现未做人工试玩；后续可在明确允许的游戏验收中继续检查。

## 主要实现位置

- `csharp/world/DynamicDungeonExpedition.cs`：调度、候选入口快照结构、种子地图、路线事件、资源和妖兽生态。
- `csharp/MainScene.DynamicDungeon.cs`：世界入口筛选、场景进入／离场、行动、时间与战斗往返。
- `csharp/panel/EastWoodsDungeonPanel*.cs`：复用既有节点地图展示和行动UI，按实例动态提供地图、出口和行动。
- `gdscripts/world/TileWorldMapPresentation.gd`：尊重世界迷雾显示入口并提供进入信号。
- `csharp/resources/PersistentGameSave.cs`、`csharp/autoload/GameSaveManager.cs`：v8字段、迁移和载入校验。
- `csharp/debug/DynamicDungeonExpeditionSmoke.cs`、`tools/DynamicDungeonExpeditionSmoke.tscn`：自动化场景冒烟。
