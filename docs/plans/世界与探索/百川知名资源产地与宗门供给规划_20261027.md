## 一、地图放产地，采集发生在产地里

大世界只标识有独立地理身份、主要产物和势力关系的知名药谷、矿山、灵木林、泉泽。普通野外也可按生态拥有采集内容，不再把每丛药、每段矿脉单列为世界节点，不新增一层“大小采集点地图”。

抵达知名产地后，进入该地的探索空间，沿用地点总览、主动进入探索和已发现内容保存的框架。内部可以有采集、考察、维护、遭遇与深入路线；抵达不直接领取产物，也不把整片产地的库存一次性装进行囊。

“大型／小型”若保留，是产地规模差别：大型可有数个经营分区和探索区域，小型可以是一条完整矿脉或一处泉谷。规模、材料品阶、危险程度、开放权限分别配置，小产地也可出少量珍材，大产地也可主要供常用材料。本轮不按名称擅定规模、产量或难度。

## 二、每处产地的归属要具体

每处分别登记：产地归属、经营方、日常驻守方、对成员开放范围、对外开放范围、宗门供给去向。共同经营必须列清签约方，不用“属于某阵营”代替归属。

一级与二级只是站队。抱朴山的药地及所得不会因为倾向玉虚，就自动归玉虚或向玉虚纳贡；玉虚若采购，须另有贸易或供给契约。城市轮值也不转移产地产权和库存。

成员身份提供进入本门开放区的依据，不能让所有人无限取用。封育区、正在开采区、危险深处与宗门保留区分别注明；受限材料可通过已有事务领取资格，不另造一套资源积分。外人可按具体契约获准访问、购买或参与事务，不能只看站队一律放行。

## 三、两条取得路径

| 路径 | 谁行动 | 收获去向 | 宗门关系 |
|---|---|---|---|
| 成员个人探索 | 玩家或有真实行程的成员 | 默认进入该行动者个人行囊 | 自留、主动交易或接受交付事务后上缴；不自动没收 |
| 宗门经营 | 产地已有驻守与经营人员 | 实际经营所得记入归属宗门物资账 | 供宗内需求与批准的对外交易，不额外发给每名弟子一份 |
| 宗门采办／交付事务 | 接取事务的成员 | 核验并从个人行囊扣除后入宗门账 | 按该事务结算报酬；同一交付不重复核发 |

个人自由探索与宗门经营应使用不同经营区，或共用同一可扣减的资源池，逐地产明确选择。不能个人采走一批，宗门又把同一批记成经营所得。尚未定义共享状态前，先用不重叠区域表达，不能凭空复制资源。

宗门经营是组织持续活动，不要求玩家每天代采。实际演算可接现有月度世界结算，但必须依据已登记的经营人员、开放状态、资源余量和运输结果；尚未配置这些条件时只展示供给关系，不生成数字库存。自然恢复仍沿现行生态主案，不因宗门经营而自动加快。

## 四、产地如何供给善功堂

供给链为：产地取得 → 经营方保管 → 登记交运 → 宗门验收入库 → 分配可售份额 → 善功堂或对应场所出售／兑换 → 进入购买者行囊。

宗门总物资不等于善功堂全部货架。留用、事务预留、待交运与可售份额须分清；这只是库存用途划分，不新增玩家货币。矿山资源不能在未交运时同时出现在多个城镇商店，运输受阻时先影响后续补货，不能把已卖出的物品追回。

善功堂继续使用现有宗门贡献兑换框架，不新建“资源贡献”“产地声望”等货币。哪些材料允许灵石买卖、哪些支持以物易物，按各地交易目录单独配置；交易方向不是默认所有物品、所有结算方式全部开放。物价、贡献价、兑换权限、收购价和数量均留待经济配置，不套用任意倍数。

宗门自有产物可成为稳定货源；没有该产地的宗门仍能通过明确的采购契获得，但不能因同阵营免费拿货。普通材料与稀缺材料的货量差别由实际供给决定，不以进入界面、离开重进或换城主刷新。

成员自留物可以卖给收购目录允许的商家；交付宗门事务则沿事务报酬结算。一次扣物对应一种已确认的结算，不把出售、上缴贡献和委托报酬叠发。买回再上交不能在无损循环中制造贡献，具体价目和事务资格需要经济验算后才能实施。

## 五、现有产地如何调整

二十一处先作为候选产地保留，其地貌与现有材料池沿用[宗门城镇主稿](百川宗门站队与城镇轮值及资源节点规划_20261027.md)第五节。原表“经营／护持契”只是初拟关系，不自动等于产权；其中城市采购、护路与登记职责不能误写成城市拥有产地。

| 经营联系 | 候选产地 | 主要作用 |
|---|---|---|
| 玉虚仙宗近域 | 太素原 | 宗门常用药材供给，兼容成员探索与封育维护 |
| 玄都天府近域及合作经营 | 断岳山、含章窟 | 矿晶与灵石来源；共管部分须单列双方权益 |
| 无相圣宗近域 | 黑瘴大泽 | 阴湿材料来源；危险不直接等于强制战斗 |
| 丹鼎宗 | 沉锋谷、丹穴山 | 金石来源与城市采购联系 |
| 太微道宫 | 天籁长峡、玄霜坞 | 晶岩与霜寒植物来源 |
| 归藏书院合作经营 | 砺青崖、含章窟、紫泥湾 | 岩土与矿产合作，不自动拥有表中每处 |
| 抱朴山 | 长生坞、濯缨泉 | 药材培育与泉泽供给 |
| 百药谷 | 万毒谷、盘龙涧、不老林 | 林谷药材、藤木与灵木来源 |
| 镇岳观 | 采露坪、松露台 | 林缘材料和松脂来源 |
| 沧溟水府 | 鸣玉溪 | 溪岸矿砂来源 |
| 血河教与枯骨寺合作 | 蕴辉岩 | 按合契分配，不各记整份产量 |

这不是每宗必须分到相同数量产地的配额表。可有专长、多方合营、贸易依赖与偏远产地；大宗的强大也不简单等于拥有更多矿点。先把这些地点做出区别，再据区域空缺扩充，暂不增加几十个无内容的小资源标记。

## 六、仙盟与青溪里

取消青溪里及其旧地记忆锚点在本轮大世界规划中的独立节点，不再为其单列类别、数量或开局落点；这项地图修改不等于删除序章剧情与既有人物经历。西南玉虚附近仍为首期生活圈，具体起步落点另按入口流程落实。

原盟府／盟府议场统一改称“仙盟”。仙盟作为独立节点保留，暂不赋予大世界地理坐标，不连接外部道路、城镇、资源运输和站队连线，也不擅设传送或菜单进入方式。它不是第四个一级宗门，不经营公共资源总库。

当前统计：百川大世界规划一百二十三处（取消青溪里、仙盟移出地理图），另有一个暂不相接的仙盟独立节点；合计一百二十四项。二十一处产地包含在世界地点内，不再额外叠加小资源点数量。

## 七、实施顺序与边界

1. 先审查产地名单、材料来源与实际经营关系；重名和规模按整体地图统一调整。
2. 为首期产地制定探索内容，明确个人可采区与宗门经营区；逐项落实人员、持有者及有限储量。
3. 再接宗门真实入库、可售库存与善功堂补货；配齐价格、权限和防重复结算后才开放交易。
4. 最后扩展跨宗采购、运送与世界演算，不为地图首版提前铺完整经济仿真。

现行[玉虚宗门生态](../剧情与宗门/玉虚仙宗宗门生态规划.md)将真实跨峰生产供给延期；本稿是用户新授权的供给规划，不声称已经开放公库支用或替换现有商店库存。生态恢复数值、已实装贡献规则和现有物品定义继续以各专题为准。本轮仅改策划与规划展示，不动运行时、存档或既有库存。
