# 百川模板随机地物生成

> 最新用户方向：学习鬼谷八荒的地物类型和摆放，按模板随机生成。此方向覆盖原地图主案中“地物只能手工落位、禁止生成器”的旧约束。当前先采用编辑器生成并保存的方式，游戏打开地图时不重排。

## 保持的边界

- 地图仍为 200×200 格、每格 256 像素，所有基础格均为普通陆地，不恢复已删除的旧水域地块。
- 现有一级/二级势力、地点 ID 与锚位固定；生成地物避开锚位及外围安全空间。
- 一格一树，直立树干，大小林地不规则；单个普通山体为一至四格的小型地物。
- 点景水面仅作装饰；林地和山地仍通过生成结果的占地元数据对接既有行旅规则。
- 此轮默认百川自然地物，不新增草丛，不把雪地、沙漠、火山等生态类型直接混入百川。

## 原作研究的证据与限度

最新补充：本轮找到游戏随附 Mod 教程中的大地图区域表与格子表，可直接读取中心装饰、包围装饰、外圈过渡、占格与权重，以及局部随机铺填/清理的命令说明。详见[鬼谷地图区域配置研究](../../美术规范/鬼谷地图区域配置研究_20261009.md)。这些教程表未逐项核对当前运行版本；原生随机数与种子映射仍未还原。

已只读查看本机 IL2CPP 元数据及模组导出的程序集，定位到 `MapCreate`，其可见接口包括 `GetDecorateItems`、`RandomOverTerr`、`GetRanomAreaPoint`、`FillDecorate`、`CreateDecorate`、`ClearPointEmptyRate`、`IsEmptyPoint`、`SaveToDataGrid`。`ConfWorldTerrainDecorateItem` 具有 `type`、`className`、`point`、`openBuildPoint`、`condition`、`weight` 字段。

这些证据支持原作存在权重、占格、重叠/空格和数据保存相关机制。读取到的模组程序集正文是原生调用包装；Cpp2IL 导出是空方法桩，不能据此确定原作实际概率、模板构图或生成步骤。本项目以下规则为结合素材与截图设计的原创规则，不是复刻原作脚本。

## 素材族

先补齐十八个百川自然地物族，每族两至三款，共四十张：高峰、小山低脊、阔叶树、松树、柳树、竹丛、枯木、散石、岩台、树石组合、低灌木、岸景、浅溪、荷叶、泉石、小潭、短崖、洞口。配套纸纹地表沿用上一批。原游戏提取图不进入正式素材。

## 生成方式

当前算法为 `regional_center_surround_edge_v2`，覆盖上一版六矩形区域与孤立小团的布置方法。

1. 固定地图尺寸和地点锚位，建立安全区与轻微弯曲的留白通道。
2. 六处山地走势、七处林地走势形成地理骨架，种子改变控制点和连续密度场的边界起伏。
3. 山群按中心、周围低峰、外圈过渡组织，较大的普通峰优先作为中心；连接坡地与低脊沿同一山势延续。单张素材仍保持小型占格。
4. 林地有密处、疏处和内部空白；主树种之中混入少量低坡、树石、灌木、散石、枯木；另补三至六格相邻的小林子。
5. 局部水景出现在林缘附近，配柳、竹和岸石；洞口在山群附近预留位置。地物占格互斥，避开地点。
6. 平原点景受区域环境和低频密度场控制，保留连续空地。
7. 同算法、模板、种子、密度可复现布局；结果为可编辑场景节点，运行中使用保存结果。算法升级后同种子会改变布局，不与鬼谷原作种子对应。

模板坐标、密度、权重与随机范围属于可调美术参数，不是剧情或资源数值。配置存放在 `resources/world/bai_chuan/map_layout_templates.json`，素材目录见相应素材清单。

## 当前保存结果

原地图场景已保存 v2 种子 `20261009`、密度 `1.0` 的示例：40 个中心山群及连接山坡、7 处林地区域、28 个小林子、20 组水岸点景。实际 Sprite 为 929 件山体/短崖、3,027 个树或竹丛格、1,337 件坡石/枯木/灌木等、46 件局部水景，四十款素材全部选用。固定遗迹另计，所有基础格仍为普通陆地。树形有适度大小与格内偏移变化，保持直立与占地留边。

布局数据为 `resources/world/bai_chuan/generated_nature_layout.json`。素材族总览与全图/西北/林地合成预览均在 `textures/world_map/bai_chuan/natural_families_20261009/`；预览只合成此次地物、纸纹及格线，省略固定遗迹、地点、绿染、玩家与迷雾，不是引擎截图。

## 编辑器操作

打开原 `BaiChuanDualGridTerrainPrototype_v1.tscn`，选中 `NatureDecorations`，在检查器设置 `Layout Seed`（布局种子）与 `Layout Density`（密度），点击“按种子生成地物”，满意后保存场景。地点锚位和原有遗迹保留；这次操作会重新安排山、林和自然点景。

同一个种子与密度、同一份模板和素材清单会得到相同结果。修改模板或素材清单会改变结果，因此运行中的游戏只使用已保存场景，不重新执行生成器。首版不改新存档格式，也不按存档保存独立地图种子。

生成后仍可在场景中逐件调整。再次生成时，这些地物调整会被新布局替换。生成器只在编辑器按钮中调用；没有在 `_ready`、打开地图、读档或运行时自动布置。

工具后端为 `tools/world_map/generate_bai_chuan_layout.py`，只使用 Python 标准库。`Python Executable` 可显式指定本机 Python；为空时优先找当前机器已有的 Python 3.11，再用系统命令。补全素材清单和排版预览使用独立美术工具，依赖 Pillow，不属于游戏运行依赖。

编辑器未保存标记的使用参考 [Godot EditorInterface 官方说明](https://docs.godotengine.org/en/4.5/classes/class_editorinterface.html#class-editorinterface-method-mark-scene-as-unsaved)。本轮未运行游戏或测试；工具实际按钮操作与运行表现不作为已通过验收报告。
