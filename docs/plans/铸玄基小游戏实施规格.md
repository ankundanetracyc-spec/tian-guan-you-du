# 铸玄基小游戏实施规格

> 状态：现行专题工作版。本文把旧十回合凝核牌局改作玄基入境小游戏，并把“云满而雨”收为同一小游戏中的一个阶段。本文数值为首轮可调方案。
> 关联：[云息十三层与秘籍成长规划](../云息十三层与秘籍成长规划.md)、[云息八回合凝核小游戏实施规格](云息凝核小游戏实施规格.md)、[高境界体系与天人设定确认稿](高境界体系与天人设定确认稿.md)。

## 一、定位与边界

小游戏名暂定“云满而雨·铸玄基”。它发生在云息十三层之后、进入玄基之时。修士调用此前真实积累的云气，在同一场牌局中引云、降雨、收雨入黄庭，完成玄基初基。

“云满而雨”是铸玄基过程的一段，不单独开第二场牌局，也不计作另一款小游戏。玄基后期的“三田返复”仍是玄基境另一款奠基小游戏，符合一个大境界至多两款玩家操作小游戏的约束。

玄基小游戏只决定玄基初始承载底蕴，不提前选择或锁定天人果位。五行、灵根、功法与相性影响铸基过程；五太—二十权—二十果位仍按神胎阶段的求果规则处理。

## 二、开始条件与输入

开始牌局须满足：

- 已达到云息十三层，累计云气储量 `Y ≥ 60` 缕。
- 当前主修仍满足修炼条件。
- 选择一件适合本次铸基的灵材。读取物品已有的五行、材性、相性和品阶，不添加新的“玄基材料类型”词缀。

本局最多调用 `C = min(Y, 80)` 缕真实云气。开局后云气输入量 C 固定；结算后 `Y′ = Y − C`。云气经牌局实际沉降的部分记为 `D`；被调用但未沉降的部分散入天地，不生成“云品”或“降雨评级”。

## 三、十回合牌局与云雨流程

旧牌局的十回合调度、六席手牌和每回合一次换位保留，牌局语义改为引云、布雨与铸基：

| 回合 | 流程 | 玩家操作重点 |
|---|---|---|
| 1～2 | 云起 | 从云海引出可用云气，摆定灵材与灵根的引导关系。 |
| 3～8 | 云满而雨 | 根据当轮云势调牌，使云气成雨；五行相生、相合可提高沉降，逆势强引会散失。 |
| 9～10 | 雨归黄庭 | 将已经降下的雨导入内景黄庭并收束，形成玄基初始承量。 |

每回合流程：补足六张手牌 → 公开本轮云势 → 玩家拖动一张牌与另一席对调一次 → 按优先、普通、滞后队列结算 → 计算本轮沉雨并清理手牌。上一轮明确保留的牌先占位；对调成功后立即结算。

牌库仍为 60 张：36 张本命灵根牌、12 张四维机制牌、6 张当前主修牌、6 张灵材反应牌。牌库读取现有角色和物品数据，不创建凝核专用书籍，也不改写日常战斗技能库。

## 四、沉雨结算

十回合云势固定为 `0、1、1、2、2、3、3、4、4、5`。每轮沉雨量：

`dⱼ = clamp(4 + 五行关系ⱼ + 牌面修正ⱼ − 云势ⱼ, 0, 8)`

- 五行关系：同根或同属一行 +1；前项生后项 +2；前项克后项 −1；单轮合计限制为 −2～+4。
- 牌面修正只读取卡牌明示效果，单轮限制为 −2～+2。
- `D0 = Σdⱼ`，范围 0～80 缕。

天赋、主修、灵材品阶和相性修正沿用旧牌局的明确值，不新增额外属性：

- 天赋 T：五灵根 +0、四灵根 +1、三灵根 +2、双灵根 +3、异灵根 +4、天灵根 +5 缕。
- 主修修正 F：`round(10 × (m − 1))`，限制为 −4～+4 缕；m 为现有功法五行匹配倍率。
- 灵材品阶修正：`floor(G ÷ 9)` 缕。
- 五行相性 E：同属一行 +2；灵根生灵材 +3；灵材生灵根 +1；相克 −2，按项目既有五行关系表判断。

最终实际沉雨量：

`D = min(C, clamp(D0 + T + F + floor(G ÷ 9) + E, 0, 80))`

## 五、玄基初始结果

牌局完成后进入玄基初期黄庭。`D` 缕实际沉雨直接成为黄庭初始承量，不折算为 S/A/B 或抽象玄基品质。后续灵力投入黄庭、绛宫、泥丸与三田返复的成长规则，仍按玄基专题细化。

沉雨量不足表现为黄庭起步底蕴较浅，而不是失去进入玄基或后续求果的永久资格。天赋、主修、灵材与玩家调牌共同决定最终沉雨量；任何单一灵根或五行都不直接锁定玄基路线或未来果位。

## 六、界面与存档边界

- 单场牌局显示十回合进度、六席手牌、当轮云势、累计沉雨 D、云气输入 C 与实际投入灵材详情。
- 云满而雨在第 3～8 回合中完成，不另开小游戏界面、不另结算小游戏结果。
- 存档保留 `D` 作为黄庭初始承量；`D0`、T、F、E 和逐轮 dⱼ 只用于本局结算，不变成永久指标。
- 牌局独立于即时战斗，不消耗战斗精力、法力、灵识，不读取三套基础战斗技能库。
- 玩家在第一回合结算前可以退出，不消耗云气或灵材；首回合结算后视为正式开局，结算完成时扣除 C 并消耗灵材。
