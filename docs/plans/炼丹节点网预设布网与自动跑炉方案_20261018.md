# 炼丹节点网预设布网与自动跑炉方案（2026-10-18）

状态：**历史节点网自动跑炉方案，已被用户2026-10-19关于槽位式即时配伍界面的明确要求取代。** 本案记录先前的节点线、火候和自动运行设计，不再定义当前炼丹试演入口；其构建记录仅对应旧节点网实现。

本案覆盖玩家操作节奏、十二功用在节点网上的职责、灵识调度、法力控火、结果与教程。它沿用[炼丹系统逻辑主案](炼丹系统逻辑主案_20261017.md)的材料来源、五行阴阳、加工与成丹判定，并以[节点网初始数值表](炼丹节点网初始数值表_20261018.md)为数值来源；不改材料分类。本文覆盖旧主案、首版接入记录和数值表中“逐息手动操作／灵识超载”的玩家流程描述，旧描述只解释历史原型。

## 一、玩家只需先搭炉局，再开炉

### 布置阶段

1. 拖入主药和任意辅材。药材从原料状态就在节点网上成为可布置的节点，不必先手动炼出药性。
2. 选择丹药与主材；主药须符合丹种候选与核心功用要求。辅材可替换、增减，不要求照抄丹方。
3. 左键节点查看详情并签功用线：**药材起点 → 功用 → 目标节点／炉口**。连线显示功用名称；玩家不填写流量、负荷、次数、间隔、优先权重。
4. 拖动节点整理布局。节点网是画面主体，丹炉口是汇合中心；节点只显图标与名称，点击才显示信息卡，悬停不弹卡，右键收网。
5. 查看简短预览：目标丹药、主辅材、实际路线、灵识并行／排队、适宜火候提示与可见的开炉阻塞。明显缺主药、核心功用或主药到炉口的“通”路线时说明具体原因。

### 自动运行

点击一次【开炉炼丹】后，炉务自行安排逐档添焰、守炉、敛焰，继续炼化、建路、流转、执行有实际缺口的功用、自动汇集和收束。过程中可看运行息数、当前火候、法力和灵识排队。开始后布网锁定；结算时可查看逐颗丹效、实际药效、材料去向、总息数、法力消耗、停车原因与仍未解决的瓶颈。

自动炉务不以“第一颗达到20分”作为停止条件。它继续处理仍能改善产量或成品的药流；当已无有效进展、资源无法支付下一步、达到安全上限或网络没有可执行工作时，才收束并保留真实成品与余料。动画可略过，动画快慢不改变息数和法力账。

### 简单与复杂炼法

- **简单炼法**：药材经炼化后沿有向路线各处理一次，最后汇入炉口；可以有分支和中继，不要求闭环。
- **复杂炼法**：至少一份真实药性必须从某节点流出后，沿有向“通”路线返回先前处理过的材料节点，再经历一项不同且可观察的加工变化；必须写明回流目的、变化和停止条件。仅仅画成环、重复经过节点或增加多味材料都不算复杂炼法。
- 复杂炼法满足真实回流条件后，才允许由中心“聚”形成丹胚。闭环是工序，不生成药性，也不自动提高品级。当前预览主流程以简单九品丹为目标；复杂丹种仍待单独设计与验收。

## 二、灵识与法力各管一件事

### 灵识：决定有多少条功用线能同时工作

灵识是修士分出的“手”和并行控制能力。自动跑炉中，每条正在执行的功用线占1点灵识；一条线上连带的处理、输送或调护不重复加临时负担。签线数量多于灵识时，超出的线进入轮候，调度器每息轮换，优先保留能推动主药与有效到货的路线。

灵识不是逐息扣除的消耗品，不按百分比惩罚，也不会因线太多自动炸炉。放药、拖节点和签线是修士伸手布置，准备阶段不推进游戏时间、不扣灵识；开炉时，每条未暂停的功用线需要1点灵识才能同时照看。并行数不超过灵识上限，其余线路自动轮候，不累计成超载；灵识越少，轮候越多，整炉通常越慢。暂停或撤回线路只在开炉前进行，减少需要维持的并行手数。灵识为0时不能维持任何功用线，预检会说明原因。

### 法力：支付自动火候

法力只为炉火和自动炉务中的炉令支付。全炉保持整数火候，0档为无火。内部每次添焰、守炉、敛焰推进一息，并严格沿用既定支付口径：

|内部炉令|火候变化|支付法力|
|---|---|---|
|添焰|升1档|支付新档维持费|
|守炉|保持当前档|支付当前档维持费|
|敛焰|降1档|支付降火前档位维持费|

自动控制优先照顾主药的适宜窗口；没有主药待炼时，按尚未处理材料的需求安排火候。法力越多，可维持的高档火候与运行息数越充裕；不足以支付下一步时安全收炉并报告停在何处，不偷降到小数火候。品级越高材料通常要求越高火候，同品材料依现行六类加工表现使用不同窗口。自动过程不把火候展示成连续温度，也不要求玩家逐档点击。

息仍是实际游戏时间：10息＝1时辰＝2游戏小时。每息火费按现有档位表结算，不因播放动画而额外收费。首轮自动加工倍率为3、自动路线容量为既有路线容量的2倍，用来落实减少点击后的合理用时；这是试算参数，需在用户验收后按材料组合与成丹结果调整。

## 三、十二功用在节点网上各有岗位

原料节点一出现即可预签线；药性必须在真实炼化后才可作为线的有效来源。每条线仍能显示名字、起点投入和目标变化；缺少真实对象时不扣来源药性。

|功用|节点网上的接法|自动运行中的实际职责|不能替代什么|
|---|---|---|---|
|破|有外壳材料 → 破 → 待开结构|打开真实结构，让后续炼化可以开始|打开不等于炼出药性|
|化|化药材 → 化 → 未炼开材料或黏滞药性|补充低火处理、解除黏胶滞留|不替代“破”的结构开启|
|通|有通能力的药材 → 通 → 药材／炉口|建立持续联系并提供基础导流|不增加药性总量|
|行|行药材 → 行 → 一条已建成的通路|给该路段供力、提高可输送量|不能创建通路，也受路线容量限制|
|引|引药材 → 引 → 有多出口的节点|按各出口真实下游需求分配有限药流，无需填比例|不增加总药量或路线容量|
|聚|聚药材 → 聚 → 已经到货的药团／符合条件的丹胚中心|收拢实际汇入的药性；复杂丹方满足回流后可成丹胚|不隔空吸药，不单独保证配伍正确|
|固|固药材 → 固 → 已有药团／丹体|稳住已形成结构与形状|不修复错误配伍，也不重复维持已成结构|
|镇|镇药材 → 镇 → 发生躁动的局部节点|压低真实接触造成的局部阴阳躁动|无躁动时不消耗；不修复热伤|
|护|护药材 → 护 → 可能受损的材料／药团|在伤害结算前抵挡真实热伤或冲撞|没有威胁不预扣；不替代降火|
|生|生药材 → 生 → 有可恢复能力损伤的对象|修复仍存药性上的能力损伤|不能恢复已成残渣、逸散或消耗的质量|
|明|明药材 → 明 → 待辨材料节点|显露材料状态，并提升之后实际分离度，减少排渣夹带|不自动分离或排渣，不追回已经散失的药性|
|藏|藏药材 → 藏 → 容易逸散的现存药性|覆盖药性并降低后续逸散|不追回已逸散部分；被封存部分不能同时流出|

行、通、引的界面区别应一眼可懂：**通造路并缓流，行给既有路段增流，引替分支选择有需求的去处**。引不再开放比例输入；支路分配由路线容量、下游目标与炉口缺口自动决定。功用不折成一个隐藏总产能值，四类自动调度只是内部执行次序，不合并十二项效果。

## 四、五行阴阳与材料状态

五行、阴阳、质地互相独立：五行只参与真实药性路线上的相生、受克与偏盛；阴阳在局部接触、流速、火候等条件成立时形成躁动；质地控制开炼、得率、滞留、耐热或逸散。木／液是否可以成为丹药精华由材料定义决定，不由本案推断或重分类。

当前节点连线保留方向性五行流转修正，局部阴阳接触会形成可供“镇”处理的躁动；五行回生、制克及完整的多来源关系展示尚未接全。五行生克不直接改火候或法力，也不替代丹种的五行、阴阳标准。药材彻底耗尽且无实际进料才从节点网退场；未炼完、有供料或尚有残余的节点保留实际状态和来源账。

## 五、十二个独立教程与进阶教学

十二功用有十二个独立课，顺序为破、化、通、行、引、聚、固、镇、护、生、明、藏。每课用同一组初始炉况跑“无该功用”与“接入该功用”两次，观察时长相同；玩家也可以亲自完成一条线，再点一次开炉，在一至两息内看见指标差异。课程展示实际来源投入、目标变化和不能解决的问题，不只讲定义。

|课|重点观察|
|---|---|
|破|同一材料在一息内自然开壳与受“破”后的开启进度|
|化|黏胶原料的滞留量与化后可流动药性|
|通|路线是否建成，以及第二息是否实际到货|
|行|同一段通路不加力／加力时的实际流量|
|引|直达炉口与无后续出口的分支之间，药流是否转向有效需求|
|聚|已经到货的药性被聚合的比例|
|固|汇合药团的结构稳定度|
|镇|相反阴阳接触后产生的局部躁动变化|
|护|自动升到3档时，藤丝实际损伤是否在护下减少|
|生|已有可恢复损伤修复前后的能力保存率|
|明|诊断显露与节点分离度，进而影响后续夹带|
|藏|同样逸散观察期内的封存覆盖和药性损失|

入门课程与专项课程都使用真实材料和真实结算。教学不会替玩家签线；会明确指出起点、功用、目标和需要观察的数值。无论课内还是普通炼丹，准备时布网，运行后不再要求点炉令、设权重或掌握书籍技巧。当前教程模式是定息数的对照，不冒充完整丹药炼成；普通炉局才按有效进展、法力与真实丹药条件自动收束。

### 五课进阶

十二项功用各有独立课，此外提供五项进阶教学：

|课|教学场景|要看懂的规则|
|---|---|---|
|灵识并行与轮候|预设三条功用线，教学炉局暂设1点灵识|灵识不被扣空；当前并行最多一线，其余轮候，路线轮换带来时间成本|
|法力、火候与安全收炉|教学炉局暂设18点法力，留有不同火候需求的材料|自动升温仍按整档支付；付不起下一步时停止并结算真实余料，不偷改档位|
|多味配伍与品质缺口|溪纹藻丝主药配凝露松脂、乌羽片、霜叶枝、回泉珠|通、行、固、护、聚各司其职；辅材补成丹要求，少一味会留下相应的品质缺口|
|五行与阴阳|进入“镇”课观察真实接触后的躁动|五行作用沿真实药性路线，阴阳躁动由实际接触产生；镇只处理已有躁动|
|简单与复杂炉网|用当前节点网说明路线判定|复杂必须有真实回流、不同的加工变化和明确停止条件；闭环丹胚未接入时不假称可运行|

受限灵识与18点法力只用于隔离观察瓶颈，不代表角色的常规初始属性。多味配伍炉局按现有丹种要求自动收束并显示逐颗结果；结果可能未达高品，课程重点是看缺口来自哪项真实能力。复杂炉网课程是边界讲解，直到回流加工和丹胚实装后才会开放实际操作。

## 六、当前实现与待验收边界

- 已接入：原料态节点预布网；单击开炉；自动整数火候与法力支付；灵识并行与轮候；主药／辅药自动角色刷新；自动收拢、结束说明与来源记录；节点网点击信息卡与无悬停弹卡；十二项手把手课程及五项进阶教学。
- 首轮参数：自动原料处理倍率3、自动通路容量倍率2；每条并行功用线占1灵识；引按真实下游需求分配；法力严格按新增火候支付表逐息结算。
- 仍待用户验收：自动收束是否保留合适余料、丹炉口汇合动画与节点大小、十二项教学内容及每课数字、灵识排队速度、法力消耗与整炉时间。
- 尚未接入：正式行囊扣料、角色持续法力／灵识、存档、完整五行制化、经过验收的复杂回流丹方。材料分类由其他规划处理，本案不改。
