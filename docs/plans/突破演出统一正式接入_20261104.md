# 突破演出统一正式接入

2026-11-04。用户已确认采用[此前实机效果](../美术规范/突破演出聚焦预览_20261104/README.md)，凝核成功、普通突破和归元九息圆满统一接入正式游戏。本文为现行接入规格，覆盖此前“实机候选”状态。

## 统一呈现

正式入口共用 `RealmPanel` 的聚焦流程：

1. 收起前一个操作页面，隐藏境界列表、属性、题字及常规说明。
2. 中央气息平滑放大至1.65倍，提高辨识度；保留阶段提示、跳过和关闭。
3. 变化完成后稳定0.45秒，淡入新境界结果并停留1秒，再用0.4秒恢复正常尺寸和其余信息。

上述参数仅为呈现参数。普通积云晋层、六→七凝核、七→十续环及归元九息圆满均使用这一流程；凝核失败保留原失败结果与休养说明。前八息仍在养息页面连续完成，不新增逐息弹窗。

## 正式场景的交接

### 凝核

八回合完成后，沿用唯一正式结算入口写入境界、最终分数和既有派生收益。成功后不再先播放牌局页的旧成核动画，再播放另一遍境界动画。

牌局成功结果暂时收起，避免其高层弹窗覆盖聚焦演出。演出完成或跳过后，先展示正常境界页；关闭境界页，恢复原凝核分数、收益和完整记录入口。恢复结果不重复通知结算；玩家已经返回修炼后，后续普通突破也不会重新唤起旧凝核结果。

### 普通突破

收到已经成功晋层的事件后，先排队等待行动过渡、跨月人物结算和平滑历法推进结束，并等待游戏解除暂停，再开始聚焦演出。

因此不会把三环贯通或积云变化提前播在“正在结算”页面下面。药物选择、成功后扣药、丹效与丹毒的原结算顺序保持。

### 归元九息圆满

只在已有八息实际养成第九息后，进入同一聚焦流程；仍先等待当前世界结算完成，再播放新息形成和圆满结果。终点为“云息十层圆满／准备铸玄基”，不继续养成第十息，不自动进入玄基。

## 结束、关闭与读档

- 自然结束与跳过均恢复说明、列表和正常主体尺寸。
- 关闭会取消本次界面动画和恢复计时，不在稍后弹回；再打开为正常总览。
- 只有真实晋层或息数增加的事件启动演出；绑定读回的人物仅记录当前境界与息数，读档不补播成功动画。
- 演出与等待期间不推进游戏历法，不修改灵力、凝核分数、息数、属性、丹药或存档格式。
- 测试窗口隔离外部桌面输入，避免地图收到额外点击而开始行旅；真实游戏的操作规则保持。
