## 一、目标与两个指标

前六层灵力整体压聚，从无核形成高密度气团；八回合末统一定形。无倒计时，抽牌顺序随机，牌效与所有结算确定并可预览。

1. **凝核程度：初始0，最低0，上不封顶。**八回合全部结算后达到100才能成核；100是成核标准，不是满分。中途达到100不会提前结束，也不会锁定成功。不另掷成功骰。
2. **气息紊乱：初始0。**每回合回弹结算后，按当时紊乱查表扣除凝核，再自然下降1，最低0。0—1点不扣凝核，2点起产生损失。紊乱恰为10不立即失败；任何一次增加使其超过10，立即判定凝核失败，不等待后续理气或回合末下降。包括牌效、蓄劲追加与操作顺序触发的增加。取消旧“预计超10便禁止施展”的规则；确认前必须清楚预警，取消不消耗。

紊乱与回弹分别承担持续失控和延迟反冲。理气不会抹去回弹，引回不会自动降低紊乱。只显示这两个指标；回弹用到达回合和强度标记，不再另做评分。

### 紊乱惩罚曲线（修订建议值）

| 结算时紊乱 | 凝核损失 |
|---:|---:|
| 0 | 0 |
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |
| 4 | 4 |
| 5 | 6 |
| 6 | 9 |
| 7 | 12 |
| 8 | 16 |
| 9 | 20 |
| 10 | 25 |

用户确认1点扣0、2点扣1；3—10点采用本轮放缓后的建议值。计算方式为“紊乱的平方÷4，向下取整”。平均每点紊乱的损失仍随紊乱升高而增加，但最高扣分由65降低到25，允许低紊乱下继续推进。不能用旧固定每点2或上一版递增表计算。

例如紊乱3结束回合，先扣2再降至2；此后不处理会再扣1、0，累计3。紊乱8本轮扣16，若先降到5则只扣6。界面显示本轮实际损失和操作后预测损失，不要求玩家心算。扣分后自然下降1、超过10立即失败的规则保持不变。本表尚未验证整局平衡。

### 同回合反复涨降

用户已明确：判断凝核程度的涨降，不判断紊乱自身的涨降。同回合出现“涨—降—涨”或“降—涨—降”，立即额外增加1点紊乱。

落实细则建议：

- 每次玩家主动操作（出牌、调息、道具）完成主体效果后，按实际凝核净变化记录一个方向。一张牌内部多个增减只计最终净变化，不重复触发。
- 净变化为0不计方向，也不清除已有方向；连续同向合并。例如涨、涨、降、涨仍形成一次涨降涨。
- 每次形成新的连续三个交替方向，触发一次；涨降涨降触发两次，涨降涨降涨触发三次。回合开始清空方向记录，不跨回合。
- 回合末自动回弹、紊乱扣分与最终余波不纳入主动操作序列；该额外紊乱本身不作为新方向事件，不递归触发。
- 道具虽不占施展次数，但如实际改变凝核，也计入方向。不能用道具绕过顺序代价。
- 额外紊乱在本次主体效果完成后立即增加，并检查是否超过10；失败立即终止，不能靠下一操作挽救。确认前预览须包含此额外1点。

例如轻压→理气→重压，凝核依次涨10、降3、涨18，第三次操作额外紊乱1；轻压→重压→理气则仅涨、降，不触发。新增顺序规则不新增玩家指标。

**牌效配套仍为待审建议：**旧牌池中大多数操作只增加凝核，下降主要来自自动结算；仅加入方向判定会很少触发。建议理气改为“凝核降低3；紊乱降低4加灵慧补正”，以主动放松压聚、整理错流解释代价；回旋仍是需要当前回弹目标的兼顾接应方案。其他牌不强行添加降分。凝核不足3时理气最低降至0，按实际变化判断；当前为0时不产生下降方向。这项牌效修改须与整局达标难度一起审阅。

## 二、牌组与八回合循环

- 牌组36张、同名最多4张；牌池18种；手牌上限6张。每回合3次施展，未用次数不累积。
- 第一回合抽6张，可换0—2张；换出的实体牌暂放，先抽替代，再洗回剩余牌库。
- 第二至八回合补足6张；首次施展或使用道具前可普通换1张一次（弃1抽1，不占施展次数）。主动进入行功后关闭换牌。
- 未打手牌跨回合保留。出牌不自动补牌；即时牌进入弃牌，持续牌留在桌面。额外抽牌先完成指定弃牌，再弃至6张；没有抽到任何牌时免去匀气的指定弃牌。
- 本局不回洗；牌库不足能抽多少抽多少，牌库空不禁止调息、出牌或道具。有合法目标才允许确认施展；选中和取消不扣次数。
- 无额外抽牌且每回合打满时，一共需要27张补牌；七次普通换牌共34张，36张保留2张余量。悟性追加换牌与抽牌手法仍可能提前抽空，须由玩家权衡。
- 调息不入牌组、占一次施展：紊乱降低2加灵慧补正，本轮未引回回弹损失减少1。多次可叠加，最低损失0。

回合末顺序固定：当前回弹结算 → 按结算时紊乱查递增表扣除 → 结算事件与本轮持续效果移除 → 紊乱下降1。未触发蓄劲保留。第八回合完成正常流程后，将第九回合及以后的回弹按总强度扣除；本轮引回/护气/丹药不能保护余波。最后才读取最终凝核程度，判断是否达到100并计算底蕴。中途数值不能用于最终结果。

## 三、人物差异

本局开始时对人物属性及主修功法取快照，局内不能靠换装备、换功法反复刷新收益。读取现行悟性与灵慧，不添加凝核专用天赋；属性修正始终显示在牌面预览中。

### 悟性：整局追加换牌额度

| 悟性 | 追加换牌次数 |
|---|---:|
| 低于40 | 0 |
| 40—69 | 1 |
| 70—89 | 2 |
| 90及以上 | 3 |

追加额度可在第二至八回合的换牌阶段使用，一次弃1抽1；与普通一次可连续使用，额度用尽不能重复。没有牌可抽不能消耗额度。起手不使用追加额度，不公开未知牌序。高悟性更容易找到接应/调度，但换牌仍消耗有限牌库。

### 灵慧：理气效率

按凝核时约10—20的尺度重调，只对调息、理气、回旋明确写出的紊乱降低量追加补正：

| 入局灵慧 | 额外降低紊乱 |
|---|---:|
| 低于10 | 0 |
| 10—14 | 1 |
| 15—19 | 2 |
| 20—24 | 3 |
| 25及以上 | 4 |

这是修订建议，不改变人物属性公式。灵慧10时调息降低3、理气降低5、回旋降低3；灵慧20时分别降低5、7、5。即便高灵慧，整理仍要占一次施展，不能自动免除损失。悟性经用户澄清仍用现有尺度，不改为10—20档。

### 灵根权重：压聚收益

只取主修功法要求且角色确实具备的有效灵根权重。OR取满足条件的最大值，AND取要求属性平均值，保留现有资格校验；非有效灵根的余权不能提供收益。功法没有五行要求时取有效灵根最大权重。本局只用原始百分比权重，不叠加修炼速率中的灵根类型倍率。

权重低于34、34—66、67—99、100，分别使每张“压聚”牌的凝核收益增加0、1、2、3。不增加回弹强度、紊乱或其他牌收益。比如匹配权重40的角色，轻压10变11、重压18变19；权重100时分别变13、21。它会鼓励更多压聚，因此仍需配合控制紊乱和安排引回。

牌不分五行属性，不为火/水/土另造牌组。无灵根或不满足主修功法资格者不能进入正式凝核；网页角色样例只供选档预览。权重为空的旧数据必须走现有有效权重读取接口，不将五项总和100当成匹配权重。

## 四、十八种手法

表中凝核数值为未加灵根补正的基础值；回弹按施展所在回合计时，除“压聚”牌外不吃灵根加成。紊乱减值仅三种明确理气操作吃灵慧补正。

| 手法 | 类别 | 基础效果 | 紊乱变化 |
|---|---|---|---:|
| 轻压 | 压聚 | 凝核+10；隔两回合回弹2 | +1 |
| 重压 | 压聚 | 凝核+18；下一回合回弹4 | +3 |
| 叠压 | 压聚 | 上一出手须为压聚；凝核+15，下一回合回弹3，可接续叠压 | +2 |
| 徐压（新） | 压聚 | 凝核+8；隔两回合回弹1 | 0 |
| 息压（新） | 压聚 | 施展前紊乱不高于2才可用；凝核+15，隔两回合回弹2 | +1 |
| 引回 | 引回 | 本回合末引回全部当前回弹；接住两股以上额外凝核+4，每回合最多一张 | 0 |
| 缓行 | 调度 | 一股未结算回弹延后一回合，可选当前回弹 | 0 |
| 催回 | 调度 | 一股未来回弹提前一回合，不能早于当前 | 0 |
| 并流 | 调度 | 选择到达回合不同的两股，较早者移至较晚者；仍为两股 | 0 |
| 蓄劲 | 蓄势 | 留桌，下一张压聚额外凝核+8、回弹强度+1、紊乱+1；用后移除，最多一张 | 触发时+1 |
| 随势 | 蓄势 | 本轮已施展引回才能用，回合末每引回一股额外凝核+2，最多+6；本轮最多一张 | 0 |
| 匀气 | 整理 | 凝核+1；抽2弃1，牌效后检查手牌上限 | 0 |
| 护气 | 护持 | 凝核+1；本轮未引回回弹损失减少3，可叠加 | 0 |
| 归拢 | 护持 | 消解一股当前或未来回弹，凝核+1；不计引回股数 | 0 |
| 理气（新） | 理气 | 凝核降低3（最低0）；降低紊乱4加灵慧补正，不处理回弹 | -4及补正 |
| 回旋（新） | 理气 | 选一股当前回弹，立即引回获得其强度的凝核，然后移除；不计回合末引回股数 | -2及补正 |
| 分引（新） | 调度 | 一股强度至少2的回弹分成两股，分别为原强度向下/向上取半，到达回合不变 | 0 |
| 观气（新） | 整理 | 公开牌库顶至多3张，选1入手，其余按原顺序置底；再检查6张上限 | 0 |

回旋在紊乱高但只有一股当前回弹时，可以一张牌兼顾接应和理气；引回在多股到来时更节省施展。分引增加独立股数，改变引回/随势收益，但占一次施展，并不增加回弹总强度。息压要求维持低紊乱，徐压适合减少整理需求，两者不替代重压的瞬时推进。

观气不能在确认前公开未知牌；空牌库不能使用。灵慧补正不影响护气减损，不给引回额外降紊乱。未使用回旋目标、并流目标等操作不会扣牌。蓄劲触发时若会使紊乱超过10，确认并结算该操作即立即失败；蓄劲施展本身不增加紊乱。

首轮默认牌组36张：轻压4、重压3、叠压3、徐压2、息压1、引回4、缓行2、催回2、并流1、蓄劲2、随势2、匀气2、护气2、归拢2、理气2、回旋1、分引0、观气1。分引可在构筑中换入。同名不超过4，不强制每种都带。

## 五、道具

沿用道具按钮与独立列表，最多两件、同名一件、各一次、每回合至多一件且不占施展。不能通过切换道具补充已用次数。

- 定息丹：本轮未引回回弹损失减少4，不降低紊乱。
- 聚气丹：凝核+10，无回弹，不吃灵根压聚补正。
- 导气符：一股未结算回弹提前或延后一回合，不能早于当前。
- 观息符：顶至多3张中选1入手，其余原顺序置底；确认后才公开。
- 清息丹（新工作名）：紊乱降低5，不增加凝核、不吃灵慧补正。

道具名称与数值为局内工作值；品阶、局外获得方式仍待丹药/物品专题确认，不能据此生成正式商店物品。

## 六、成核结果与后续境界建议

### 已确认的最终结算

第八回合必须按以下顺序完成：

1. 处理本轮回弹：被引回的增加凝核，未被接住的扣除凝核（先应用合法护持）。
2. 按此时紊乱查递增表扣除凝核。
3. 清理本轮效果，紊乱自然下降1。
4. 所有尚在未来回合的回弹立即作为余波扣除，本轮引回与护持不保护这些余波。
5. 此时的凝核程度才是最终值：不足100未成核，达到100成核，再以该值计算底蕴。

例如最后一轮结算前132，本轮引回+8，紊乱3扣2并降至2，未来余波扣9，最终为129。结果是129，不是132，也不是140。结算前105、结算后99仍未成核。

只保存最终程度，不将紊乱留下作为永久负担。每次扣减最低0；不设凝核上限，不截断溢出收益。

### 最后一回合不会免除回弹

第八回合打出的牌产生的第九、第十回合回弹同样纳入未来余波，按全部强度扣除。延后、并流只改到达时间，不消灭这项负担。结算预览同时列出“本轮回弹”“紊乱损失”“未结回弹”，最后显示预计最终值。

例如末轮重压的即时收益18，留下回弹4，若未提前处理，最终净贡献最多14，再计入其增加的紊乱损失。它仍能产生净收益，因为压聚本来有收益；不存在免费的延迟负担。引回只处理本轮到达的回弹，不把第九、第十回合回弹自动转成收益。归拢消解或催回后接应仍需正常施展机会及合法目标。

### 后续收益（2026-10-11 用户确认）

只读取第八回合全部结算后的最终凝核程度。100为成核底线，上不封顶；200不是奖励截止线。不恢复法力上限奖励，不奖励修炼速率，不增加属性成长倍率。

- 超过100后每满5分计一档，不足5分不计档。
- 七→八、八→九、九→十的本层基准灵力门槛倍率：1＋档数×0.0125。
- 铸玄基同等归元息投入的云气转化补正：档数×0.025。云气只在铸玄基过程中出现，当前保存最终凝核程度供未来转换读取；不自动增加息数、不缩短养息、不直接保证玄基品质。
- 超过100每满25分，凝核定额收益按三项战斗基础属性分配：体魄、神魂各获得＋1.5，灵慧获得＋1；相当于将旧敏捷的＋1平均分入体魄与神魂。成核后生效，悟性与福缘不变。该奖励独立于境界奖励，只由最终值计算，不反复写入基础属性，读档、重算与打开面板均不重复领取。
- 超过200按同样规则继续，不衰减、不封顶。

| 最终程度 | 后续本层灵力门槛倍率 | 铸基云气较基准增加 | 四项属性各定额增加 |
|---:|---:|---:|---:|
| 100 | 1.00 | 0% | 0 |
| 120 | 1.05 | 10% | 0 |
| 150 | 1.125 | 25% | 2 |
| 200 | 1.25 | 50% | 4 |
| 225 | 1.3125 | 62.5% | 5 |

### 牌值修订的意图与边界

成核线从旧建议60改100，且紊乱没有安全区，不能只改合格线而保留旧牌值。压聚基础收益改为轻压10、重压18、叠压15、徐压8、息压15；回弹强度仍为2、4、3、1、2。保留低风险推进与高收益高负荷的差别，避免所有牌同比膨胀后紊乱惩罚失去作用。
