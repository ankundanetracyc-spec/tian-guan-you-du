# 炼丹十二功用独立实操教程（2026-10-18）

状态：**当前教程规则，已接入预览场景，待用户验收。** 本课针对节点网自动跑炉；先读[预设布网与自动跑炉方案](炼丹节点网预设布网与自动跑炉方案_20261018.md)。本教程不要求书籍技巧、逐息炉令或线路数值；不授予角色能力。

## 一、课程怎么上

右上【教程】→【十二功用】，可从第一课顺修，也可任选一课。每课使用独立炉局：材料、火候、可用药性和目标节点已经准备好，画面仍以节点网为主体。课程先让玩家看“未接本功用”的结果，再重载相同初始炉局，亲手接一条真实功用线并点一次【开炉炼丹】。普通课程观察一息；通与护需要两息才能看到建路后到货、升温后热伤。

操作始终只有三步：

1. 点击指定药材节点，在节点信息卡点本课功用。
2. 点击指定目标节点或已建通路，完成“药材 → 功用 → 目标”连线。
3. 点击【开炉炼丹】，等待一至两息自动运行，然后对比指标。

节点只显示图标和名称；详情在点击卡中显示。线条直接显示“破／化／通……”等功用名。悬停不弹信息栏。签线不推进时间；运行后节点网锁定，课程结果保留实际药性投入与目标变化。每课会解释本项能做什么、不能替代什么；没满足作用条件时会说明不扣药性的原因。

课程是同初态、同观察时长的局部对照，不宣称已经炼出完整丹药，也不替普通丹方做成丹判定。课程目的在于让玩家看清“接这条线后，炉中哪项真实状态发生改变”。

## 二、十二课的接线与观察

|课次|接线|课程初态与观察指标|边界|
|---|---|---|---|
|1 破|赤纹燧石 → **破** → 青木芯|青木芯为致密材料，自动火候受操作者上限约束；一息比较开壳进度|破开结构不等于炼出药性；后续仍需合适火候或化|
|2 化|月露菌汁 → **化** → 凝露松脂|松脂已炼化但仍有黏胶滞留；比较滞留量和可流动药性|化可解滞或辅助处理；不能替代破开结构|
|3 通|风络藤丝 → **通** → 丹炉口|两息内观察路线建成和实际到货|通建立联系并缓流；路线建成不等于药性瞬间抵达|
|4 行|乌羽片 → **行** → 藤丝至藻丝的既有通路|在已有通路上，比较同段基础流量与供力增流|行必须作用于真实存在的通路，不能自己造路|
|5 引|雾铃花 → **引** → 风络藤丝分流节点|直达炉口与无后续出口的支路并存；对比有限药流是否转向有需求的路线|引不填比例；自动依据下游需求分配，不增加总量或容量|
|6 聚|回泉珠 → **聚** → 丹炉口药团|先有实际到货药性；比较药团聚合量|聚不隔空吸药，也不保证药材组合正确|
|7 固|凝露松脂 → **固** → 丹炉口药团|已有药团；比较结构稳定度|固稳住已形成的结构，不修复错误配伍|
|8 镇|泥脉石团 → **镇** → 丹炉口药团|两种相反偏性的药性已实际接触并造成局部躁动；比较躁动变化|没有真实躁动时不消耗，不修复热伤|
|9 护|霜叶枝 → **护** → 风络藤丝|风纹石英的较高适宜火候推动自动升温；藤丝安全上限较低；两息观察实际热伤|护抵挡已经出现的威胁；无威胁时不预扣，仍需法力维持高火|
|10 生|青髓芽 → **生** → 曾受热损伤的风络藤丝|相同炉局先产生可恢复能力损伤；比较修复前后的能力保存率|生修复仍存药性，不增加质量，不能复原已转渣或散失部分|
|11 明|清音玉片 → **明** → 青髓芽节点|比较诊断显露与实际分离度|明改善之后的辨析和分离，不会自动排渣或追回逸散药性|
|12 藏|凝霜叶 → **藏** → 青髓芽节点|同一观察期比较封存覆盖量与实际逸散|藏减少未来散失；封存部分不能同时流出|

“通”“行”“引”都画成真实功用线，但岗位不同：**通建路并提供基础缓流，行给某条已建路段增流，引把分支药流送往有实际需求的出口**。不再要求玩家在引线上编辑比例或优先值。

## 三、教学对照规则

- 无功用组与有功用组重新载入相同材料与节点初态，运行相同息数；教学数据只由当前炉次模型计算，不手填成功结果。
- 每条课程线都验证来源材料具备相应功用，且目标／路线存在；课程结果显示实际来源投入、去向与指标变化。
- 护与生分别教事前抵挡和事后修复；镇只作用真实接触产生的局部躁动；明提升真实分离能力；藏只影响后续逸散。
- 五行相生相克与阴阳局部接触仍按炉内真实材料关系结算；教程不把“火行材料”误当炉火，也不把五行生克当成十二功用。
- 普通自动跑炉按完整网络处理并自动收束；课程运行固定一至两息用于同条件教学对照，不继承旧的逐息手动按钮节奏。

## 四、与基础炼丹的关系

九品基础丹可以通过少量材料与一条必要的“通”路线完成；不要求初学者一次签满十二种功用。加入更多材料和合适功用线，可以弥补主药发挥、配伍协调、丹体稳定等不同缺口，提高成品上限；错误五行、失衡阴阳、过火损伤、药性逸散和线路瓶颈仍会真实影响结果。

点击【开炉炼丹】后，普通炉局由火候控制器自动添焰、守炉和敛焰，灵识调度器并行执行或轮候功用线。课程不让玩家逐息点炉令，普通炉局也不需要设流量、分支比例、执行次数或时间间隔。法力按每一道实际自动炉令支付；灵识决定并行线路数，不作逐息扣除的消耗值。

## 五、进阶教程

十二功用课之外，教程目录提供五项进阶内容。它们沿用布网后单击开炉的节奏；灵识与法力限制仅用于教学对照，不作为角色常规初值。

|进阶课|布置与观察|要学会的判断|
|---|---|---|
|灵识并行与轮候|预设两条通路和一条引线，将教学炉局灵识上限暂设为1；运行六息观察线路状态|灵识代表同时照看的“手数”，不逐息消耗；超过上限自动轮换，所以布太多线会拖长炉期|
|法力、火候与安全收炉|使用护课的材料组合，将教学炉局可用法力暂设为18；观察自动升档及资源不足后的收束|添焰付新档，守炉付当前档，敛焰付原档；无力支付时停止结算，不偷改火候档，也不凭空烧掉余料|
|多味配伍与品质缺口|以溪纹藻丝为通脉丹主药，配凝露松脂、乌羽片、霜叶枝和回泉珠，自动跑完一炉|固、行、护分别补充不同品质轴；聚只收拢真实到货药性。缺一种辅材未必不能成丹，但相应的高品缺口不会凭空补上|
|五行与阴阳|从“镇”课进入有真实相反偏性的接触炉局，比较镇线前后的局部躁动|五行关系沿真实药性路线结算；阴阳躁动由实际接触与炉况产生；镇只处理已经出现的躁动，不直接把整炉刻度拉回目标|
|简单与复杂炉网|阅读当前材料节点和炉口汇流规则|复杂炼法必须真实回到已处理节点、发生不同且可观察的加工变化，并有明确目的与停止条件。当前测试版尚未接入闭环丹胚，因此此课只教判定边界|

多味配伍课展示自动结算的逐颗结果与实际缺项，不保证本轮初始参数已能让这组材料达到最高分；它用于检查每项互补能力是否真实参与。低法力和低灵识是教学用试值，普通炉局仍读取当前操作者的真实资源输入。
