# 炼器取消燃料与五行展示修订 v3

> 2026-10-24最新：[投料与灵识界面修订](炼器投料配伍与灵识界面修订_20261024.md)取消全炉32份上限，改用灵识需求校验；每岗每材1—8份仍保留。以下32份及旧界面描述为历史规则，重演旧参数除外。

> 最新决定：用户暂定不给器物设置五行字段；主/副五行、复合摘要及自动功用定性均不实施，也不补无属性标签。[此前方案](器物五行与无属性功用定性设计_20261022.md)暂缓留档。材料五行继续参与炼制配伍，来源记录和阴阳七档保留。

> 2026-10-22，当前独立试炼实施规则。用户要求去掉燃料，并质疑器物五行占比的实际用途。本篇覆盖[v2实施](凡器法器公式试炼实施_20261022.md)中的燃料、供热及五行百分比展示；其余公式不变。数值仍为候选，不写正式存档或改战斗卡。

## 一、取消燃料

一级材料组改为**身、质、性、和**。身材仍内含主体、承接、辅体；必填主体、承接，其余按需。移除燃料位置、选材资格、燃料库存、供热参数、供热成本、供热判定及失败提示。造诣、工时及试炼精力保留原计算，不以替代耗材或新失败概率填补移除的内容。

运行参数切换为 `resources/crafting/process_forging_candidate_v3.json`、版本 `sword-process-trial-3`。从炼器加工档案移除松心炭、地脉焰炭，剩余11种已有材料；不删除它们的公共物品资源，不改炼丹或其他系统。所有档案不再含 Heat/FuelHeat，配置不再含 HeatPerUnit。

四套参考投料都移除燃料；旧“少量燃料投料”改名“单性材投料”，现在正常成器，不再人为保留缺热失败。每种当前加工材料在本页有30份；每岗同材1—8份、全炉32份不变。省下的燃料不再计入上限。凡器/法器、锋锐、效果共同预算与加工保留保持原公式，因此相同非燃料投料的属性不会因去掉燃料突然增长。

缺主体、缺承接、非法岗位、份数/库存超限仍拒绝开炼且不扣料。保留结算与尝试记录接口，不增加新成器失败规则。旧“供热不足失败会扣料”的测试不再适用，改为验证旧燃料投料被拒绝、无燃料即可成器、非法输入不扣料及重复提交幂等。

## 二、五行占比的真实含义

v2成品展示的“金95%、木5%”来自各源的保留量 `Q×η×配伍送达` 按五行相加归一化。它只是材料来源统计；未参与伤害属性分配、成器主五行、战斗克制、技能资格或器蕴判定，甚至不等同于角色收益的贡献占比。

例如用金行材料造剑身、木行材料作承接，来源里出现木，不代表剑有木属性伤害，更不能解读为95%金伤、5%木伤。把该统计标为“器性”容易将来源说明误读为正式成品属性。

因此本轮撤下本体页的“器性”和百分比。在炼制记录中只列**材料五行来源：金、木……**，不判主次、不显示占比、不附加战斗或套系含义。没有有行材料时显示无行。内部字段更名为 `MaterialElementContributions`，明确它只用于来源追溯；未来不能直接复用为战斗元素权重。

材料的五行、阴阳、生克送达和真实和材通关仍参与炼制，计算保持不变。取消的是没有实际用途的成器百分比展示，不取消材料五行系统。

当前暂定不给器物增加五行字段，不显示主五行、复合五行或无属性标签；不按实际功用另算整器五行摘要。后续若重新设计，需明确新的规则来源；不能擅自选占比最高者、规定主次阈值，或新增百分比混伤、克制倍率、器蕴层数。

## 三、版本与验证

试炼档案升级为schema3，不再保存 RequiredHeat/OfferedHeat。只允许新参数/新快照复算；schema2明确拒绝自动套用无燃料规则，不改变旧档案。此处是离开页面即清空的试炼，不涉及正式存档迁移。

保留旧v2参数和[截图/运行记录](../美术规范/凡器法器公式试炼_20261022/README.md)作为历史证据。现行画面与验证见[无燃料试炼验收](../美术规范/无燃料炼器试炼_20261022/README.md)。首页与百工入口仍使用同一炼器场景，无需新增入口。
