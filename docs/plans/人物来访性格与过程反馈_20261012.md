# 人物来访、性格与过程反馈

状态：现行首轮实施，用户确认方向及切磋后续规则。覆盖《人物交往与判定展示初版》中双立绘、日常逐句对白和固定自报身份的展示。切磋尚未接入，本期只做结识与闲谈。

## 一、行动权与来访

NPC 依自身目的、实际认知、在场条件、既有往来与性格选择来访；是否接受友好接触由玩家决定，接受后结果由行为规则确定。不同来意独立处理，不把求购、求助、寻衅混成索要物品。

本期保留入宗次月起、同地真实同门、每月最多一位来访的既有测试限流。候选先按最近与玩家接触月份轮转，再考虑外向倾向、重情者的熟人联系，最后用稳定人物 ID 排序；不新增随机率或关系加分。内敛者在尚无往来、也未听闻玩家的情况下不主动陌生结识；已有往来或宗内真传名号可提供接触理由。敌对者不进入友好来访池。

真传的身份名声沿用宗门生态既有规则，宗内主动来访可记录公开传闻姓名及身份；听闻与实际相识分开，不得自动获知境界、灵根细节或行囊。不得由此推定宗外人物人人认识玩家。

接受沿用当前交谈体力费用（现为 1）；婉拒免费，不因一次拒绝扣好感、声望或制造全宗印象。输入确认时实际结算一次，随后的动画只是可略过的展示，不二次收费或额外推进游戏日历。

## 二、过程浮层

参考用户提供的“人物考量逐条出现”节奏，不照搬配色、文案、构图或固定判断列表。

采用紧凑居中浮层：现有组装立绘的头部小像、人物姓名、来意／当前行为、一道墨色展开进度、实际生效的过程描述、结果与真实消耗。不使用两幅巨大立绘，不放底部剧情栏，不播放日常逐句台词。

- 来访：陈砚听闻你拜入真传，趁宗内相遇，希望与你结识。提供“接受／婉拒”。
- 进行：正在与陈砚结识……逐条显现对方停步、认出旧识、愿意互通姓名等实际分支。
- 结束：你与陈砚互通姓名，闲谈了几句。若实际发生费用则显示体力消耗；没有关系数值变化不伪报增加。

不显示隐藏性格数值，不虚构对背包、实力或利益的全知判断。界面可先略过展示，再确定关闭；Esc 在来访确认阶段婉拒，在过程阶段展开结果，随后关闭。正常剧情对白仍走原底栏。

## 三、四倾向性格

| 轴 | 方向 | 首轮接入情况 |
| --- | --- | --- |
| 交往 | 外向／内敛 | 影响主动陌生结识与候选优先顺序 |
| 情利 | 重情／务实 | 重情者优先联系既识人物；利益请求尚未实现 |
| 秩序 | 守序／随性 | 已有保存字段；承诺、门规、失约行为尚未接入判断 |

连续倾向是后续方向，概率、权重及数值分布未定，首轮仅保存定性方向或均衡，不宣称连续数值版已经完成。为兼容现有人口：旧“寡言”补为内敛，“爽直／圆融／随和”补为外向，“温厚”补为重情，“谨慎／多疑”补为谨慎；无法明确对应的轴保持均衡。每个轴独立补缺，不覆盖已有值，不把一个旧标签推成完整道德人格。新生成及旧人物首次参与本系统时补齐，随真实 NPC 资源存档。

性格不等于业力、心境、势力态度或私人关系。玩家的选择不被性格自动代选；“守信、冷淡”等他人印象需由具体经历形成，本期只保存实际回应记录，尚未实现印象传播、朋友生成或全宗评判。
