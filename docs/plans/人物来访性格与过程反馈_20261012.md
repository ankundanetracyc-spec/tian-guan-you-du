## 一、行动权与来访

NPC 依自身目的、实际认知、在场条件、既有往来与性格选择来访；是否接受友好接触由玩家决定，接受后结果由行为规则确定。不同来意独立处理，不把求购、求助、寻衅混成索要物品。

本期保留入宗次月起、同地真实同门、每月最多一位来访的既有测试限流。候选先按最近与玩家接触月份轮转，再考虑外向倾向、重情者的熟人联系，最后用稳定人物 ID 排序；不新增随机率或关系加分。内敛者在尚无往来、也未听闻玩家的情况下不主动陌生结识；已有往来或宗内真传名号可提供接触理由。敌对者不进入友好来访池。

真传的身份名声沿用宗门生态既有规则，宗内主动来访可记录公开传闻姓名及身份；听闻与实际相识分开，不得自动获知境界、灵根细节或行囊。不得由此推定宗外人物人人认识玩家。

接受沿用当前交谈体力费用（现为 1）；婉拒免费，不因一次拒绝扣好感、声望或制造全宗印象。输入确认时实际结算一次，随后的动画只是可略过的展示，不二次收费或额外推进游戏日历。

2026-10-13 用户最新确认：每行先从左往右逐字写出与该分支相符的可见表现（如“对方略一沉吟……”），句尾点号试探性伸出、退回两轮，再撤去等待文字，显出本行反应，然后继续下一行。已完成行保留；未轮到的行不显示内容，布局预留位置，最终结果等待所有行结束才显示。允许略过并立即展开全部实际结果，不重复执行结算。等待语仅是该行的展示前奏，不计为新的判定或追加因素。

文案按已执行分支、实际正负方向选取，每类准备六组等待语与相符反应；同一次展示选定后不再重抽，每次新交互可换措辞。2026-10-13 用户最终收敛：每行只表现一个实际判定点，采用短句，如“你接话得体，对方愿意多谈几句”“谈及同门身份，对方少了几分生疏”；不在一行堆叠几层动作或另讲一段经历，也不缩成没有对应含义的泛泛动作。可提及实际参与的同门、真传、公开事迹等内容，不列出属性值、加成分数、算法门槛或对方内心。真传入门来访与百川公开事迹使用不同措辞组。

相邻且互相独立的判定表现每次变换展示顺序；接受、阻断、交换姓名、实际交割等步骤作为边界保留原有先后。只重排可见表现，不改变内部规则执行顺序、不增加或省掉判定点。正式费用、记忆、月度来访与试算权重沿用原规则。

- 个人所重：修行、财利、声名、宗门、亲友、传承。当前测试生成一项主要所重；额外次要项可保存，随机分布与权重不是正式平衡结论。
- 测试补缺：固定人物 ID 与轴键生成稳定结果，三个定性档（两端／均衡）用于测试覆盖，不随读档、查看或交际重抽，不消耗世界随机序列；已有值保留。旧寡言、爽直等明确标签仍优先对应迁移。旧“务实”原值另存迁移痕迹，情分归均衡，不推成冷漠或财利；旧随性改称不羁。

### 玩家行径与 NPC 侧写（2026-10-13 最新确认）

用户已确认个人印象首轮测试配置：两个不同月份实际聊成，下一次过月后才形成“愿意往来”的个人观感；实际切磋／药材成交一次，次月才可成为再次相邀／有真实需求时求购的依据。暂不设衰减或传播，不增加好感数值；NPC 自身性格、需要、支付能力、在场限制及已知修为差距仍生效。覆盖下方历史“门槛另行确认”的首轮未定状态，其他人格／守信／援助／传播规则仍未定。

玩家与 NPC 不采用完全对称的性格系统：NPC 有稳定的自身性情；玩家的性格由玩家自主行径表现，不在开局随机分配六轴人格，不自动代选行动，也不在面板公布一个客观人格分数。魅力、交际、心境仍是各自已有属性，不将它们换算成“仁厚／冷酷”等性格结论。

玩家了解自身形象的途径是 NPC 的外在反馈：明确说出的评价、称呼变化和实际应对。不显示 NPC 未说出口的真实想法。评价归属于说话的具体人物，不等于系统宣判；同一行为在不同 NPC 看来可以不同，但必须有其知晓的事实作依据。

实施按以下阶段推进，不把后续项描述为已完成：

1. **已有基础**：NPC 六轴、所重及稳定存档已接入；交往／切磋／求购各有实际经历记录。部分性情影响行动，其余轴先保存，不凭文案冒充已运行的行为逻辑。当前只有具体回应／交手记录，尚无完整玩家形象归纳。
2. **亲历侧写首版已接入**：先接 NPC 自己亲历的交往，记录行为、对象、时间地点、结果与来源；展示前核验记录仍存在。优先用“前次你愿意停步聊上几句”这类具体回顾，而不是一次接受就判为热情、一次婉拒就判为冷淡。若没有可靠依据，不补侧写台词；试演不生成正式证据。范围与验收见文末“亲历回顾首版”。
3. **个人印象首版已接入**：首期仅按已确认门槛形成愿意往来／交过手／药材交易联系，过月归纳、通过外在评价及现有来访行动体现，详见文末月度闭环记录。更复杂的观感改变仍待后续；守信须有真实承诺与履行／违背，仁厚须有实际援助，不能把普通交易或拒绝邀请当作道德依据。承诺、救援等相关流程未落地前不生成相应评价。
4. **后续阶段：有限传播与行为联动**：传闻要有真实见证者和传播路径，不能全世界同步知晓。即时动作只登记证据；印象归纳、衰减及传闻传播沿用过月批处理，只处理有新记录的对象，不每次移动扫描全人口。亲历事实可以在当场回应中引用，但不为此提前执行月度归纳。

NPC 真实性情、NPC 对玩家的印象、玩家对 NPC 的认知三者分开；印象不直接变成业力、全宗声望或私人好感。正式游玩不直接揭示 NPC 完整性格，当前测试查阅仍可用。印象存储结构、归纳门槛、有效期、传播范围与影响权重在对应阶段另行确认，不在本次擅定数值。

前轮实现边界为三类交互试演与具体亲历回顾；本轮进一步接入下述个人印象月度闭环首版，不宣称传播、道德人格归纳或全六轴行为均已实现。
