## 一、行动权与来访

NPC 依自身目的、实际认知、在场条件、既有往来与性格选择来访；是否接受友好接触由玩家决定，接受后结果由行为规则确定。不同来意独立处理，不把求购、求助、寻衅混成索要物品。

本期保留入宗次月起、同地真实同门、每月最多一位来访的既有测试限流。候选先按最近与玩家接触月份轮转，再考虑外向倾向、重情者的熟人联系，最后用稳定人物 ID 排序；不新增随机率或关系加分。内敛者在尚无往来、也未听闻玩家的情况下不主动陌生结识；已有往来或宗内真传名号可提供接触理由。敌对者不进入友好来访池。

真传的身份名声沿用宗门生态既有规则，宗内主动来访可记录公开传闻姓名及身份；听闻与实际相识分开，不得自动获知境界、灵根细节或行囊。不得由此推定宗外人物人人认识玩家。

接受沿用当前交谈体力费用（现为 1）；婉拒免费，不因一次拒绝扣好感、声望或制造全宗印象。输入确认时实际结算一次，随后的动画只是可略过的展示，不二次收费或额外推进游戏日历。

## 二、过程浮层

参考用户提供的“人物考量逐条出现”节奏，不照搬配色、文案、构图或固定判断列表。

采用紧凑居中浮层：现有组装立绘的头部小像、人物姓名、来意／当前行为、一道墨色展开进度、实际生效的过程描述、结果与真实消耗。不使用两幅巨大立绘，不放底部剧情栏，不播放日常逐句台词。

- 来访：陈砚听闻你拜入真传，趁宗内相遇，希望与你结识。提供“接受／婉拒”。
- 进行：正在与陈砚结识……逐条显示真正参与决策的条件及其作用，不显示停步、打量、注意到接近等纯动作填充。
- 结束：你与陈砚互通姓名，闲谈了几句。若实际发生费用则显示体力消耗；没有关系数值变化不伪报增加。

不显示隐藏性格数值，不虚构对背包、实力或利益的全知判断。界面可先略过展示，再确定关闭；Esc 在来访确认阶段婉拒，在过程阶段展开结果，随后关闭。正常剧情对白仍走原底栏。

最新文案修订：玩家看到的是人物的反应与取舍，不是程序条件解说。例如同门联系写“谈及同门身份，对方少了几分生疏”；谨慎拒绝写“谈到姓名时，对方有所保留，只拱手告辞”。内部保留稳定判定标识；“没有敌对关系”等默认放行检查只记内部，不强行插入每次展示。没有对应判定不补纯动作，不透露“某轴／某门槛／优先权”等机制词，也不由一次反应确认完整人格。以下此前“写清因素→作用”的要求指逻辑可回溯，不要求玩家文案直白列出算法。

2026-10-12 最新确认：不规定两行，也不硬凑四至六行。每行须来自实际执行的判断，写清“因素→对决定的作用”；不把文案中的性格或环境当作已经生效的算法。首版交谈记录玩家接受／拒绝、敌对关系阻断、已相识转为闲谈、同门／已听闻身份提供接触依据、谨慎门槛允许／拒绝姓名交换。界面文案与规则标识在同一分支生成，便于逐项验证。已相识不重复结识；同门或闻名可使谨慎者不因陌生接触而拒绝；无这些依据的谨慎者拒绝交换姓名。其他性格轴、环境、实力、财物、劫道未实际参与本期结识判定，不追加展示。结果与实际消耗另列，不算作判定行。

## 三、六轴性情、个人所重与交际认知（最新，覆盖四倾向初版）

用户确认采用“底层性情＋个人所重＋实际经历”，测试期可查真实性格，正式游玩逐步通过交际了解信息。下文旧四倾向仅作迁移记录。

- 六轴：外向／内敛、仁厚／冷酷、谨慎／冒进、守序／不羁、重情／淡情、宽和／记怨。每轴独立，首版保存定性值，不设连续分值及行为概率。
- 个人所重：修行、财利、声名、宗门、亲友、传承。当前测试生成一项主要所重；额外次要项可保存，随机分布与权重不是正式平衡结论。
- 测试补缺：固定人物 ID 与轴键生成稳定结果，三个定性档（两端／均衡）用于测试覆盖，不随读档、查看或交际重抽，不消耗世界随机序列；已有值保留。旧寡言、爽直等明确标签仍优先对应迁移。旧“务实”原值另存迁移痕迹，情分归均衡，不推成冷漠或财利；旧随性改称不羁。
- 已开放的主动来访继续先轮转，再按外向、重情联系熟人及相关个人所重择人。看重声名／宗门者更优先结识当前宗内真传；看重亲友者更优先联系已明确为朋友者，不把相识视为朋友。这些实际生效的排序因素只在主动来访过程展示，不套到玩家主动搭话。
- 风险倾向继续参与陌生结识门槛；仁厚、守序、宽和等暂不伪用于普通交谈，也不宣称救援、劫掠或复仇已经实装。求购、切磋等独立流程按第四节后续接入。
- `social_personality`、`social_priorities` 保存真实数据；`player_social_memory` 保存 NPC 对玩家的认知；新增 `player_known_npc_info` 保存玩家对 NPC 的交际所得，记录内容、来源和月份。三者不可互相复制。姓名只在真正交换后登记；主动接触和谨慎拒绝只形成具体行为经历／暂时印象，不直接揭示真实六轴或所重，不凭一次交际确认完整人格。
- 交互浮层标题提供悬停查阅，`gameplay/npc_test_inspection` 当前默认 true，明确标注“测试查阅”；关闭后该入口只读交际所得，未知显示尚无了解。测试查阅绝不改变玩家知识。此开关只控制本轮新增性情查阅，不代表旧人物面板的所有基础属性已经全面隐藏；正式人物全页信息门控另接统一认知层。

## 四、宗内切磋与其他范围

用户确认接入真实同门对练，复用现有演法／训练的非性命之争路径，不走野外杀人结算。

- 首轮限玉虚宗内同峰真实在场、双方云息的同门。玩家从人物菜单发出邀约；NPC 在既有每月一次来访限流内，已相识且看重修行、愿意对练时可主动邀请。不是额外增加一套每月弹窗。
- NPC 敌对时不接受友好对练。谨慎者对尚不熟悉、也没有已知修为的玩家暂不应邀；若此前实际获知玩家修为且高于自身，则暂缓对练。不读取玩家真实隐藏修为来替代已知信息。内敛且不看重修行者面对未相识人物可以婉拒；其他符合条件者约定点到为止。只用定性条件，不新增成功率／奖励权重。
- 玩家可以接受、婉拒／取消。取消免费；确认商议沿用交谈体力 1，只结算一次，NPC 拒绝也属于已进行的商议，不额外收战斗体力、贡献或物品。过程展示可略过，确认结果后才进入既有战前界面，并可在战前取消。
- 玩家参战包直接来自当前角色的正式快照；对手复用世界 NPC 战斗转换，不用凶狼或随机新人物替身。当前随机 NPC 未配置个人秘籍卷章，沿用其既有公共基础战斗池；不在本轮凭空发秘籍或生成新卡牌。
- 战后复用训练快照恢复：不写回模拟生命损失、不杀死 NPC、不施加正式战败重伤，不掉落物品、不发贡献、不推进额外游戏时间。返回发起时的峰，不跳青溪里或固定天问峰。
- 用战斗 ID 防重复登记，双方往来记忆与玩家交际所得保存本次实际胜负／提前结束经历。不自动建立朋友、仇敌，不自动增减好感或公开完整境界属性。旧伤仍保留，不借切磋治疗原有世界伤势。

求助、同行、求购、寻衅、劫掠、复杂权重、长期来访消息队列均为后续。长行动期间目前不强制打断，也不会为每个错过月份补弹一次；不宣称已实现留信或紧急事件调度。NPC 自主互斗仍不属于本次完成项。
