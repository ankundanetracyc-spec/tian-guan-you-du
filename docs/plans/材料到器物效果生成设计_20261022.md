# 材料到器物效果生成设计

> 最新实现约束：用户要求通用公式而非穷举材料效果。统一数学模型见[炼器效果通用计算公式](炼器效果通用计算公式_20261022.md)。本篇逐材料表仅解释已存在的材性，不是材料→效果白名单；实际生成必须只读取数值与公共算子，不读取材料名匹配配方。

> 2026-10-22，设计提案。回答“投入什么材料，为什么得到这些装备属性”。以[器物属性规划](器物属性与装备收益规划_20261022.md)的最新修订为准：成器不设功用字段，常驻包含数值、条件修正与条件触发。本篇提出下一版生成规则，不代表旧试炼已支持这些新效果；不新建战斗卡或直接修改材料资源。

## 一、成器生成的因果顺序

```text
材料在实际岗位中的贡献
 → 成材与共同承载、可用效果潜力、工艺通路
 → 匹配能成立的具体效果模板
 → 分配真实潜力与通路，淘汰过弱或无法实现的效果
 → 成器直接保存常驻效果、化法、获授技能、器蕴及自身信息
```

不通过器名抽取效果，不把材料标签直接粘贴到器物，也不先指定想要的成品属性。相同材料、岗位、份数与加工条件得到相同结果；添加一味材料可能改变分配，不保证所有既有效果只增不减。

## 二、各岗位究竟提供什么

| 岗位 | 本次实际贡献 | 以剑为例 |
| --- | --- | --- |
| 身材／主体 | 成形与结构，建立大类载体和结构承载 | 玄铁或铜髓矿经加工成为剑体；不会把身材中的固再完整复制成物防 |
| 身材／承接 | 连接完整性，使器内效果能可靠作用到使用者或外部通路 | 青木芯只有明确的承接加工档案生效，生潜力不自动附送回血 |
| 身材／辅体 | 补充并改变真实结构，影响体量、宽厚与可承载复杂程度 | 加铜髓矿可改变结构；不是必定厚脊或直接附加攻击 |
| 质材 | 整件器物共用的根性与效果送达支撑 | 铜髓矿、玄铁或灵石依档案建立共同预算；换根性也会改变配伍损耗 |
| 性材 | 提供具体收益的来源潜力 | 裂甲石的破可支持攻伐效果；另投玄铁的固可支持防护效果 |
| 和材 | 处理生克、局部冲突，并支付导通、聚集、留存等工艺配额 | 风纹石英支持通，褐铜砂支持聚，灵石的通/聚/藏需要分配，不能三份全额使用 |
| 燃料 | 支付实际加工供热 | 松心炭或地脉焰炭；多烧不免费增加伤害，也不直接给器物染火行 |

同种材料放在不同岗位会承担不同职责。身材玄铁与性材玄铁必须是不同实物份数；质材灵石与和材灵石同样合计扣库存。

## 三、首批材料与效果潜力

以下材性来自现有资源；“支持的成品效果”是待评审加工映射，必须经过通路、强度与预算条件才会生成。

| 性材来源 | 材料真实功用 | 可支持的首批具体效果方向 | 不自动附送 |
| --- | --- | --- | --- |
| 裂甲石 | 破九品 | 物理伤害加成；剑关键词技能的物理伤害修正；本次物理防御忽略；物理攻伐能力 | 全部方向各一份满额效果 |
| 玄铁 | 固八品 | 物理防御；合格守御技能的化解修正；护盾能力 | 只因器型坚固就给角色免伤 |
| 铜髓矿 | 固九品 | 与玄铁同属防护候选，具体潜力与保留不同 | 改材料名字就变另一种随机词条 |
| 青木芯 | 通八品、生七品 | 首批主要使用其承接/工艺档案；作为性材时生方向需后续单独模板 | 现阶段没有模板的回复技能 |

材料功用品级影响来源潜力；岗位、加工保留、共同预算和配伍决定最终能实现多少。不能直接把八品材料标为八品器物，也不能把某种材料固定绑定唯一成品。

## 四、同一来源为什么能变成不同装备效果

需要同时匹配“效果内容”和“如何发挥”。建议新增以下工艺模板方向；它们是结算规则，玩家仍只配材料，不勾选成品效果。

| 成品表达 | 实际需要的工艺条件 | 例子 |
| --- | --- | --- |
| 基础属性常驻 | 来源能稳定留存，并与器体/使用者耦合，达到对应属性最低强度 | 分配破来源潜力形成物理伤害加成；固形成物防 |
| 剑关键词持续修正 | 有剑类载体、足够连续导通及稳定留存，可将效果覆盖到使用者的同类技能 | 所有带剑关键词且含物理伤害的技能，提高其物理伤害 |
| 条件触发附带效果 | 有合格事件响应、导通与一次收益所需的聚集配额，且具体触发模板已定义 | 剑关键词攻击在指定命中事件后，附带一段合法效果 |
| 定向化法 | 可把来源稳定附着到一个合格技能的集中通路 | 给玩家选定的合格物理技能追加穿防；给应对技能追加化解 |
| 直接主动技能 | 有足够聚集与释放能力，且有审核后的技能模板 | 直接攻伐或护持 |
| 召出御使 | 有足够外放结构、留存及导通，并达到御器模板要求 | 召出剑体后御使；器体与在场灵识另记 |

连续覆盖多个合格技能与集中附着一个技能是不同工艺，不能把“通”一律解释成化法。新增的跨技能覆盖及事件响应必须在加工档案中声明条件、配额与门槛；不能只见到一份风纹石英便保证出关键词增伤。

剑大类只提供“剑范围效果”的载体资格，不免费增加剑技能伤害。具体数值仍须由性材有效潜力支付。实际筛选读取技能正式关键词，不用装备名字或近身出手方式代替。

## 五、自动生成与分配规则

### 5.1 先解决必要加工

先支付成形、连接、供热及生克通关等必要投入。已用于通关的和材单位不能再生成覆盖、化法或御器配额。局部阴阳冲突单独处理，整体平均为和不能抹掉冲突；至阴至阳也不会因为偏极被统一降级。

### 5.2 枚举实际能成立的效果

从性材有效来源与已形成的工艺逐项列出候选。模板声明来源要求、载体/关键词范围、通路种类和数量、结构与根性占用、最低有效值及转换曲线。缺任一必需条件就不生成该效果，未知材料功用不临时映射成新状态。

形态参与真实结构约束，不通过“修长剑”名称再次提高增伤或降低费用。造诣改善保留和组织能力，不能代替缺少的导通、聚集或性材来源。

### 5.3 共同分配，不按候选数量复制潜力

对相互争用来源、承载或和材的候选联合求可行分配。内部约束为：

```text
每个材料来源分给所有效果的潜力之和 ≤ 该来源实际送达潜力
所有效果占用的共同支撑 ≤ 质材实际支撑
所有效果占用的结构 ≤ 实际成材承载
每个和材单位实际支付的工艺用途 ≤ 一次
```

在满足最低有效值后比较实际可实现收益；评分考虑实际数值、适用范围及触发频率，不能按条目越多得分越高。分配目标、覆盖/触发成本、门槛和同值的稳定顺序需统一成参数表，再进入新一轮试算；当前旧模型只有固定通→化法等分配，不拿它冒充新求解器。

同属性、同条件、同结算时点的贡献合并为一条实际效果，并保留各来源记录。不同条件分别保留。低于可用门槛的碎片不显示为“+0”或无效技能；未利用量留在记录中，不重新复制给其他效果。

成器没有“最多两项功用”字段，也不按材料种数一味一属性。实际效果数量由可行分配决定；需要用测试覆盖合理复杂度，再确定必要的条数上限，不能先把旧两项改名为新两条。

## 六、三种实际材料组合应怎样解释

以下是下一版目标方向，用于评审材料与效果的因果关系；不是已算出的新配方或保证产出。新通路门槛未标定，不填写伪精确份数或最终数值。燃料均按真实供热需求另配。

### A：侧重直接战斗属性

身材采用可成形铜髓矿及青木芯承接，质材铜髓矿，性材裂甲石，和材只处理必要配伍。来源潜力能稳定留存但没有形成复杂覆盖/事件通路时，主要生成物理伤害加成。

现有旧模型相应基础样方实际产出物理伤害+6%，这只能证明基础常驻已经试算；后续换用新求解器时要重新校验，不把6%强行锁为新配方答案。

### B：侧重剑关键词持续效果

沿用可成形身材、铜髓矿质材及裂甲石性材，另投足够风纹石英和必要的留存加工投入，使剑类载体与使用者技能之间形成持续覆盖通路。

目标成品直接显示：“带剑关键词的技能，其物理伤害提高一定比例。”若还分得足够稳定留存潜力，可以同时保留较小的通用物伤加成。两项分用同一裂甲石来源，不能各自获得完整一份强度，也不要求绑定某个技能槽。

增加风纹石英主要改变能形成什么通路，不直接增加破来源潜力；如果质材不足，只补导通未必提高效果。若最终形成的是集中附着而非持续覆盖，则可能只产生定向化法，不能保证任意通材料都出全剑增伤。

### C：攻伐条件效果与防护收益并存

身材按实际结构需求配置，质材承担共同支撑；性材用独立份数的裂甲石和玄铁，同时提供攻伐与防护潜力；和材再用风纹石英、褐铜砂等建立导通与聚集，或用灵石的不同实物配额补足所需工艺。

目标可以是剑关键词伤害修正，加上物防；也可以在有审核后的事件模板且工艺足够时，将部分防护潜力转成“合格剑攻击的指定命中事件后获得护盾”。若同时请求化法或御器，必须进一步分配已有通路与潜力，不能因加入聚材料便自动又赠送一项主动技能。

固来源分给物防越多，可供护盾、化解等其他表达的潜力越少。裂甲石与玄铁也共同竞争质材和结构，不是分别享有一整件器物的承载。

## 七、物品上最终保存什么

只保存已经实现的：

- 常驻效果：例如物理防御固定值、剑关键词物伤修正规则、带明确事件条件的附带效果。
- 化法：具体修正和合格绑定条件。
- 获授技能：审核后的技能模板、实际参数与装配引用。
- 器蕴贡献，以及形态、性相、器体等本体信息。
- 制作来源引用和版本快照；原料功用与效力分配在这里追溯，不再列成器物功用字段。

器蕴来自实际保留下来的能力和器性，不因投料中有破、固便自动显示破蕴/固蕴。现有候选这两个蕴名与层数尚未随新生成模型重审，本篇不定新的套系奖励或蕴种映射。

## 八、下一轮需要落实的数据

优先为破、固两类现有材料来源补齐：基础常驻、剑范围持续修正、条件触发、定向化法四种表达的匹配和转换表。主动技能继续走战斗卡审核流程，不由本篇直接生成可用卡。

用受控试算比较：同成本、同造诣下的基础属性与关键词修正；只加导通而没有增加来源时的分散；有/无聚集时的事件效果；生克处理占用和材后的路线变化；多段/群攻/追加下的触发预算。通过这些样本校准数量和强度，而不是给每份材料拍一个最终伤害值。
