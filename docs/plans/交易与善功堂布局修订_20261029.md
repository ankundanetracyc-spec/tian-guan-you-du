# 交易与善功堂布局修订

2026-10-29阶段设计。交易部分已被[行囊索引与空间联动](行囊索引与空间联动方案_20261029.md)取代：先优化行囊，交易后续可用统一列表；不再把完整我方行囊嵌入交易作为现行要求。下方善功堂每列一类、纯文字基础字段的方向保留。v2概念图不是正式界面，未完成Godot集成验收。

## 交易：我方完整行囊＋对方可交易目录

页面分为两块：我方行囊约占三分之二，对方目录约占三分之一。成交态度、双方交出摘要与交易按钮集中到底栏，不再占用中间整列。

我方行囊保留全部五区、原有相对位置与分类／搜索。等比缩小整体，保证胸前、左袖、右袖、腰间、背囊全部可见，不裁掉区域或用滚动隐藏半个背囊。五区仍是6×4、3×4、3×4、6×4、6×8，共120细格；所有小格显示尺度相同，区标题仅有名称，不标长宽，不画人体。示意图约34～36屏幕像素／格，仅为1920宽布局建议，未改128源像素／格的素材规格。

点选我方物品时，物品留在原位置，仅用克制选中边线表示拟交出；不能为了交易展示自动重排背包。我方完整物品可见不等于全部可交易，是否可选仍读取现有交易资格，不新增装备出售等规则。

对方只列愿意交换的物品。现有NPC的`trade_inventory`就是独立的可交易库存，展示它，不把NPC实际随身物品全部公开，也不新建对方身体分区。每行显示小图标、名称、可交易数量，选中时提供既有数量选择；可显示多件同名货物的报价数量，不因此改变我方物品堆叠规则。列表可滚动，空时显示无可交易物品，不填空格卡片。

底栏并列显示我方拟交出摘要、对方拟交出摘要、对方态度及交易按钮。估值、精力消费、关系记录和交易校验继续用原流程，不在页面公开内部估值分数。真正按空间入包的事务仍需随正式空间库存迁移完成，不能把120格效果图当成已实现。

## 善功堂：每列一类的文字目录

先按当前实际开放的大类展示三列：材料、秘籍、器物。各列有固定分类标题和自己的竖向目录，不沿用左侧分类栏切换同一个大列表。以后确有新类别时再扩展，不在图中擅自增加丹药、衣物、符箓等未开放兑换品类。

每行只显示名称、库存、所需贡献。名称占主要宽度，库存和贡献固定靠右对齐；长名称自然保留可读空间。不给每件物品放大图标、全文简介、重复兑换按钮或一套独立卡片。品阶、用途、学习门槛、效果与占格等通过同一悬停查看。每列内容超出后独立滚动；无溢出的短列不强行显示滚动条。

选中一行后，底栏显示所选物品、既有兑换数量与贡献总额，单一兑换按钮进入原确认流程。仍按现有单件兑换，不新增批量购物车或折扣。当前器物0贡献属于现行原型值，效果图照读不代表本轮调整价格。

**库存数据边界：** 当前善功堂实现有可兑换目录与贡献价格，没有每件商品的库存数、售罄／补货或刷新规则；宗门公库流水也不能直接当善功堂零售库存。概念图的库存统一用“—”占位，既不表示0也不表示无限。本轮仅设计字段位置；引入真实库存前须另行确认规则，不能填随机数或擅定每日／每月补货。

## 共用悬停与状态

物品悬停继续使用原深墨底、浅纸字、96图标及类别字段。标题附近另画真实占格小图：例如灵石1×1、秘籍／瓷瓶2×3、修长剑2×6、宽剑3×6、折衣3×4。每格约16设计单位，读取占地配置，不按图像尺寸猜；非物品不出现占格图。
