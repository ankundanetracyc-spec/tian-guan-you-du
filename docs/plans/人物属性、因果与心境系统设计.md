# 人物属性、因果与心境系统设计

> 状态：人物资料结构与业力单值方向已确认。心境首版分类与圆盘表现已确认：以修士个人长期心绪为圆盘主体，八风作为外缘诱因；圆周八种为狂喜、渴求、焦灼、惊惧、悲恸、暴怒、怨恨、绝望。扇区表示心绪种类，半径只表示当下强度；事件推移、心魔条件和修炼效果均未定数值。本文是主角与百川 NPC 共用的人物数据及人物页规则。

## 一、设计目标

- 主角与世界 NPC 使用同一套人物基础信息与人物状态字段，避免人物页只能展示主角、NPC 另造一套不完整数据。
- 功德与罪孽合并为一个名为“业力”的可正可负综合属性，不保存两套独立余额。
- 新心境使用一个位于圆盘上的落点；首版为八种共通的长期心绪，按常见过渡关系相邻排列，不要求圆心两侧成对相反。同一套心绪适用于所有人物，个人经历塑成各自的当前状态。不再使用七档横轴，也不恢复旧的 `current_mind/max_mind` 资源逻辑。
- 人物面板第一页统一命名为“概览”，展示立绘与身份基础信息；数值属性独立放在“属性”页，立绘不在属性页重复显示。
- 百川区域声望、势力态度、NPC 私人关系和因果各自独立，不相互替代或自动换算。

## 二、人物数据

主角 `HumanData` 与百川 NPC `WorldNpcData` 均需具备以下资料：

1. **八项基础属性**：体魄、灵慧、神魂、福缘、悟性、魅力、交际、治事。前三项是战斗基础属性；其余属性按各自已有用途使用。NPC 不再只保存三项核心属性。
2. **修行与身份**：年龄、性别、种族、灵根及五行权重、境界、灵力、正式身份、所属势力和当前位置等。
3. **业力**：唯一的有符号综合值。正向代表善业偏重，负向代表恶业偏重；同一事件只修改这一项，不另存“功德余额”和“罪孽余额”。业力不是可消费资源，也不等于区域声望；人物页可以按该值显示解释性称谓，但称谓不是额外属性。由于正负值会形成净值，重大行为造成的具体后果仍由事件记录或既成事实保存，不能因数值相抵而抹去。
4. **心境**：独立于战斗资源的长期心绪状态，以单一圆盘落点表示修士当前持续的主导情绪及其深浅；不等同善恶、性格标签或一时情绪。
5. **声望与关系**：记录人物在区域中的公开名声；势力对人物的态度、人物与主角的私交继续分开保存。

### 战斗属性结算（2026-10-18）

战斗基础属性为体魄、灵慧、神魂。身心协调值是派生值 `min(体魄, 神魂)`，不单独成长、存档或作为人物基础属性显示。旧公式中体现身法协调、闪避与行动协调的敏捷作用改用身心协调值；洞察与反应读取神魂；精准中的敏捷作用并入灵慧；物理技能伤害中的敏捷系数并入体魄。

- 生命上限：`60 + 9×体魄 + 2×基础体魄 + 3×神魂 + 1.5×灵慧`。
- 行动速度：`80 + 0.5×体魄 + 0.75×灵慧 + 1.5×身心协调值 + 0.75×神魂`。
- 精准：`7×灵慧 + 神魂 + 0.5×体魄`。
- 身法：`4×身心协调值 + 2×神魂 + 灵慧 + 0.5×体魄`。
- 会心：`0.5×体魄 + 2×神魂 + 0.3×灵慧`；护心：`3×体魄 + 2×灵慧 + 2×身心协调值 + 1.5×神魂`。
- 体力恢复读取体魄；战斗意图洞见读取神魂。物理技能旧敏捷伤害系数并入体魄，同一属性的重复系数合并显示。

旧存档中的敏捷成长按一半迁入体魄、一半迁入神魂；旧版导出字段仅用于一次性存档迁移，不作为运行时属性。境界、研读和凝核奖励中的旧敏捷收益也依相同原则分配；派生公式按上述结算映射。

因果变化应由可追溯的行为、事件或裁决产生。因果不等于百川区域声望：行善或作恶不自动成为公开事迹，也不自动改变势力态度或 NPC 私交。功法可各自声明因果条件；例如雷法可以针对罪孽深重者获得额外效果，魔修功法也可自行规定因果门槛或作用，但不将其推广成所有同类功法的统一规则。罪孽阈值、功法效果与事件记账规则待专题逐项确定。

### 观因察果（2026-10-13 设定补充）

- 部分修为深厚的金丹修士，以及神胎及以上修士，能够察看修士一路经历留下的因果脉络。此能力读取的是已发生的行为及其因由，不等于读心、全知或窥见行囊。
- 业力是正负相抵后的综合值，不能替代具体因果履历；重大行为事实不得因数值抵消而消失。需要“观跟脚”的剧情应依据可追溯事件，而不是只看业力、区域声望、势力态度或 NPC 私交。若历史事件尚无记录，不得凭空补造。
- 主角为穿越之人，其异世来历及相关因果受天道遮掩。具备观因察果能力者看不穿穿越身份，也不会单因遮掩而察觉异常；其在此世真实经历留下的因果仍可被察看。
- 玉虚仙宗山门迎真沿用此规则：具备观因能力的金丹接引长老可察看玩家此世真实经历，并另行察看资质；迎真具体流程以[真传入门与师承培养主案](玉虚仙宗真传入门与师承培养流程.md)为准。此设定不表示迎真已接入运行时。
- 这是世界观与场景判定规则，不代表所有金丹 NPC 已获得观因能力，也不代表人物事件履历及通用因果读取接口已完整实装。事件记账细则仍须按相关专题定义。

NPC 的区域名声使用可追溯的公开事迹记录；现有 `faction_reputations` 仍表达 NPC 与各势力之间的立场/声望关系，不能当作区域名声或个人关系。百川以外的区域扩展沿用区域 ID，不把百川数值冒充全世界声望。

## 三、心境圆盘：个人长期心绪（分类已确认，玩法待细化）

### 定义与分类

心境记录修士在一段时期内持续占主导的个人情绪，不是一次事件发生时的即时喜怒，也不是善恶、性格、业力、灵识或可消耗资源。同一套情绪名称适用于所有人物；每个人落在哪个扇区、情绪有多深，由其本人经历、牵挂、选择与持续修行塑成。

《礼记·礼运》列出喜、怒、哀、惧、爱、恶、欲七种人情；《灵枢·本神》也讨论忧、愁、悲、恐等情志对神与身的影响。[《礼记·礼运》原文](https://ctext.org/wiki.pl?chapter=188568&if=gb)；[《灵枢·本神》原文](https://ctext.org/huangdi-neijing/ben-shen/zh)。本案借用古典情志观念来校准语义，但下列八种是游戏为表现长期修行心绪所作的分类，不宣称古籍定有一套固定的“八种心境”。

2026-10-10 用户修正：**安宁撤出扇区**，平稳状态由圆心“无心绪”表达。圆周均应是强烈情绪；同一扇区从内到外是同种情绪逐渐加深，不额外增加情绪资源或独立指标。随后用户确认以下分类作为首版；事件与玩法数值另行细化。

| 内侧心绪 | 圆周强烈形态 | 长期含义 |
|---|---|---|
| 欣喜 | 狂喜 | 因所得、成就或重逢持续喜悦，向外情绪愈发高涨 |
| 渴望 | 渴求 | 对目标或所求持续牵挂，向外愈难放下 |
| 焦虑 | 焦灼 | 对未发生的风险持续不安，向外愈难安定 |
| 恐惧 | 惊惧 | 面对明确威胁或创伤持续害怕、警觉 |
| 悲伤 | 悲恸 | 对失去、离别持续难过，向外愈发深重 |
| 愤怒 | 暴怒 | 对不公、阻碍或背弃持续恼怒 |
| 怨恨 | 怨恨 | 对伤害持续怨愤，强弱由半径表达 |
| 消沉 | 绝望 | 对前路持续低落，向外逐渐失去盼望 |

首版圆周顺时针为“**狂喜—渴求—焦灼—惊惧—悲恸—暴怒—怨恨—绝望**”。分类与界面顺序已确认，不据此自动推导事件转移规则。扇区之间不强制对立，也不强制按圆周顺序发生；首尾及各相邻关系仍须结合事件验证。内外两套称呼描述同一情绪，未设更名数值阈值。

八风“利、衰、毁、誉、称、讥、苦、乐”改作**外缘诱因标签**，不再作为圆盘的情绪扇区。相同的得利、失利、称赞、毁谤或苦乐境遇，因修士牵挂与经历不同，可以推向不同心绪；这使心境确实属于人物本人，而非将外部处境误当成情绪。[《思益梵天所问经》八风经文](https://dlbs.liberal.ntu.edu.tw/BDLM/sutra/html/T15/T15n0586.htm)

### 单一落点与变化规则

- 盘内只保存一个落点。所在方向表示当前主导的长期心绪；离圆心的距离只表示这份心绪当前有多强：越靠圆心越轻，越靠外沿越强。半径不表示持续了多久，也不表示心绪更难消除。圆心标为“**无心绪**”，表示没有持续占主导的情绪、心境稳定；人物仍会有一时喜怒，只是不会因此离开圆心。不再另设安宁扇区。
- 落点可处于相邻扇区交界，表示两种相近心绪正在交替或混合；不新增第二个心境栏、情绪条或独立“心魔值”。
- 普通事件先作短暂情绪演出，不必然改写长期落点。关键经历、重复而未解决的事件、人物自己的选择与持续修行，才推动落点迁移。事件强度及迁移数值待专题平衡；不先添加每日随机摆动。
- 同一事件不必让所有人产生同样变化。事件与人物的关系、在意之事、先前经历和当时的心绪决定其反应；宗门或流派通过长期教化、实践和关键事件塑造心绪倾向，不因加入宗门或装备功法即时改写心境。
- 心绪消退需要有意义的安歇、释怀、关系变化、目标转向或修行体悟等内容支持；单纯经过若干日历日不自动清空，也不能靠反复中断修炼刷回圆心。

### 水墨界面与动态表现

心绪盘沿用角色页暖宣纸、旧墨边与细金线，但把“外缘吹动落点”的表现改成个人心景：

1. **八个心绪扇区：**用相互渗化的低饱和矿物颜料铺出八片心绪色域，不画成硬切饼图。颜色只帮助辨认心绪，不代表善恶、修为高低或正负属性。
2. **唯一落点：**一枚带温润亮芯的墨珠位于当前扇区；靠近圆心表示心绪较轻，靠近外缘表示心绪较强。半径不兼任持续时间或“执着程度”指标；交界位置显示两种相邻心绪正在过渡。
3. **平时状态：**背景墨色保留层次与留白，扇区色彩繁而不艳；圆心“无心绪”是稳定基点，不画成第九种心绪。
4. **事件状态：**普通事件在相关色域处泛起一次淡涟漪后消散；真正改变长期状态时，墨珠沿合理的邻接路径缓慢移动，相关色域随之浓淡变化。重大事件允许跨区迁移，但需有明确叙事原因。
5. **人物页信息：**概览页显示圆盘、当前心绪名称和简短缘由；展开详情后再查看最近一次持久变化及其事件来源。不常驻八条数值。

### 与修炼、心魔、事件和流派的关系

心境需要影响玩法，但先用同一落点产生情境化倾向，不另造一组复杂副指标，也不先写固定百分比：

| 心绪（作用待审） | 修行与行动倾向 | 情绪固着时可能生出的心魔执念 |
|---|---|---|
| 欣喜 | 愿意继续投入带来成就感的事 | 不肯接受顺境结束 |
| 渴望 | 围绕目标长期用功 | 为达目标不肯放手 |
| 焦虑 | 反复准备、推演风险 | 无法接受不确定 |
| 恐惧 | 谨慎准备、避险 | 回避一切风险，困住自己 |
| 悲伤 | 回望经历、珍视关系 | 不肯接受失去 |
| 愤怒 | 面对阻碍更愿正面解决 | 让一时愤怒代替判断 |
| 怨恨 | 追索旧事与责任 | 被报复牵住修行方向 |
| 消沉 | 更需要重新确认修行理由 | 放弃仍在意的事 |

这些是各心绪对事件与修行的叙事倾向，不是八种固定的优劣职业，也不代表角色一定按该方式行动。玩法效果应落在具体行动和事件选择上；不能把“静定”做成永远最优，也不能把愤懑、悲恸等状态一律做成惩罚。

| 系统 | 建议作用 | 边界 |
|---|---|---|
| 修炼 | 当前心绪改变修士维持某类修行的顺手程度，并影响相应修炼事件与叙事。例如渴望推动目标导向的修行，焦虑可能让人反复准备，消沉则更难主动投入 | 不把每个扇区做成永久属性加成；具体行动对应与数值另行核定，归元息、瓶颈与突破规则不自动读取心境修正 |
| 心魔 | 心绪很深且长期僵固，在相关旧事、诱惑或冲突再次出现时，可触发与该人物经历相符的心魔征兆或事件 | 不能只因落点靠近外缘就随机判心魔；不另设心魔累积数值。触发和化解条件须有因果可追溯 |
| 极端状态 | 心绪长期压过人物的自我调节时，可临时影响相关行为、修炼选择，极端情况下影响属性或状态 | 具体阈值、属性项目与持续时间待定；不把短暂情绪当作长期减益 |
| 事件与流派 | 八风可作为外缘事件标签；人物关系、过往、目标和流派实践决定事件如何触动心绪 | 八风不是八种情绪，也不强制一类外缘只对应一种心绪 |

心境与普通吐纳瓶颈是两套规则：瓶颈记录持续吐纳带来的效率抑制，心境记录人物长期心绪。是否允许特定心绪影响普通吐纳，须另外定规则，不能叠加出未审定的隐藏惩罚。

旧的 -50～+50 心境横轴、七档称谓及旧的 `current_mind/max_mind` 资源逻辑整体退役。心境不代表品性或业力；任何长期变化都应能追溯到人物经历、选择、修行或关系变化。

### 主角

- 第一页标题为“概览”，进入角色面板时默认显示此页；导航顺序为“概览、属性、战斗、功法、装备、侧重、关系”。
- 新建旅程的主角初始年龄固定为 16 岁；最大寿元沿用本次角色生成得到的寿元增量，后续随游戏时间正常增长；载入已有存档时不得重置年龄。
- 2026-11-02 实施：以游戏历法一年 360 日计，主角累计经历每满一年增加 1 岁；部分年度进度随角色存档保存。旧存档第一次载入时从当时历法时刻开始累计，不追补过去年龄。人物档案在年度年龄变化后的时间结算中同步刷新年龄和立绘。
- 概览页充分使用可用画幅：左侧独立立绘区使用明确的大尺寸画框，立绘在框内完整展示；姓名、性别、年龄、境界、灵根、正式身份、所属势力、当前位置、百川声望、业力与心境全部排在立绘右侧，禁止把资料或状态栏堆在立绘下方。性别和年龄各占一行，不合并为“性别年龄”一行。身份或所属势力确实为空时显示“无”，其他尚未取得的资料显示“未详”。当前位置显示地点名及大世界格位坐标，不只显示笼统地点。
- 百川声望独立显示为“声望：百川 N”，并在同一区域简要列出构成：玉虚基础声名 × 身份倍率 + 百川公开事迹；不显示旧的声望档名或冗长解释句，不与业力、心境、势力态度合并。
- 业力展示单一有符号数值；未定义解释称谓前不自行增加数值阈值或称号。心境以个人心绪盘显示长期落点；圆周名称为狂喜、渴求、焦灼、惊惧、悲恸、暴怒、怨恨、绝望，八风只作外缘诱因。扇区按常见过渡安排，不强制圆盘两端情绪相反；圆心“无心绪”表示无持续主导情绪且心境稳定，越靠圆心情绪越轻。采用暖宣纸、层叠水墨与低饱和矿物颜料，不以颜色暗示善恶。
- 立绘只在概览页展示；“属性”页专注八项基础属性、战斗属性、修行属性和造诣，不重复放置立绘。
- 概览不出现捏脸入口、立绘组装说明或素材缺失调试提示；角色外观仍通过既有创建/服饰流程管理。
- 业力、心境、区域声望、势力态度和 NPC 私交保持独立。
- 贡献流水等长账目仍留在现有个人档案/贡献区域；概览只显示身份与区域声望摘要，不把贡献、灵石或关系合成一个分数。

### NPC

- NPC 复用同一“概览”页的结构与术语；当前阶段只开放这一页，不显示主角专属的属性管理、功法管理、装备管理、侧重配置等页面。
- 展示 NPC 已保存的立绘、基础身份与所在地、八项基础属性、业力、个人心绪盘落点、区域声望、所属势力态度，以及与主角的关系。现有交谈、交易入口仍可保留在该页。
- 人物资料尚未确认/未生成时显示“未详”，不得用假数值填充。后续若引入情报遮蔽，再按已知资料规则收敛显示；首期数据完整性不等同于主角自动全知 NPC 的秘密。

“概览”作为主角和 NPC 共用的第一页名称；旧个人档案入口继续承载贡献明细，但不能再是唯一能查看人物身份和区域声望的入口。

## 五、存档、演算与实施边界

- 正式存档保存主角心境落点、业力和区域公开事迹；NPC 快照保存相同的八项基础属性、心境落点、业力、区域公开事迹及现有行动历史。心境只保存个人心绪圆盘上的一个位置，不再写入旧横轴值或八项独立分数。
- NPC 新属性必须在人物生成时取得稳定值，并与稳定 `npc_id` 一同写入正式存档；读档不得重抽属性。生成分布与个体配置按 NPC 生成专题另行确定。
- 旧心境数值退役后，不保留双轨显示或“心神”兼容别名。项目现行存档案指出目前没有旧版正式进度槽；若未来导入外部旧数据，再按明确版本迁移规则处理。
- 圆心“无心绪”、半径表示强度、八种首版情绪及当前界面排列已确认；事件移动量、心魔条件及修炼数值效果仍待细化，定案前不接入最终效果。

## 六、验收

- 主角“概览”页与 NPC“概览”页使用相同字段命名和基础布局；NPC 暂时只有该页，且不显示主角专属管理页。
- 主角和 NPC 均能在概览页查看单一业力值、个人心绪圆盘与区域声望；不存在功德/罪孽两项余额，也不存在旧数值心境/“心神”替代字段。
- 心境只保存一个圆盘落点；方向表现长期个人心绪，离圆心距离只表现当前强度（越近越轻）；八风作为外缘诱因。扇区相邻关系基于常见情绪过渡，不要求所有对径扇区互为反面。事件、持续修行与长期教化造成的持久移动可追溯；短暂触动只作演出。
- 心境与修炼、心魔、事件相连，但具体数值须由专题明确；不得擅自改变已确认突破的固定门槛或加入随机成败。
- 区域声望、势力态度、NPC 私人关系、因果彼此独立。
- 读档后人物与 NPC 的状态和属性不重抽、不丢失。

### 2026-10-10 界面检查后的实施状态

已补心境详情、统一悬停、切页清理及落点视觉过渡；主角与 NPC 共用概览结构，NPC 显示真实灵根、区域声望、业力、地点与单独性别年龄行。详情无历史数据时明确显示“暂无记录”。正式心境落点、默认初始状态、事件来源与存档迁移尚未接入，不能将预览落点当作真实人物状态。NPC 仍缺福缘、悟性、魅力、交际、治事五项存储和生成规则，界面显示“未详”，等待专题明确，不随机补值。见[界面检查与待定事项](../美术规范/人物概览与心境圆盘_20261010/界面检查与待定事项_20261010.md)。
