# 炼器过程量与成器推导细案

> 2026-10-22；结算结构候选v0.2。主入口：[材料与过程量驱动炼器设计](材料与过程量驱动炼器设计_20261022.md)。用户已确认材料与过程量决定功用、属性、器型；本篇提出实现这一方向的具体规则，新增取舍尚待评审，不冒充已批准数值。
> 原细案提出时只设计结算；随后用户要求成熟设计并接入测试，已补齐独立候选参数并实装，见[新模型试炼与器物信息](炼器新模型试炼与器物信息设计_20261022.md)。本篇是结构依据，具体试炼数值以配套篇和参数文件为准；正式材料、存档、战斗技能及旧计算器未改动。

## 一、玩家操作：配材料，一次结算

建议首版玩家只选法宝大类、材料岗位与整数份数，再点击开炼。沿用当前炼丹“材料优先、结果后揭晓”的交互思路；不引入火候滑条、实时锻打、点击时机或成品方向开关。

提炼、成形、相合、导通与固化是计算阶段。玩家通过材料和分配影响这些阶段，不需要逐阶段重复点击。炼器造诣、器具能力是加工条件，不能替代缺失的材料能力。

首期仍只研究剑。其他大类的岗位、可加工材料及效果须分别配置，不照搬剑的规则。

## 二、岗位决定材料本次承担什么

五个分组保留，具体槽数由大类的工艺复杂度及能力确定，不再先选细分器型。新增位置的精确上限及造诣门槛待定。

| 岗位 | 首期职责提案 | 不自动产生的收益 |
| --- | --- | --- |
| 身材 | 提供实体成形原料、结构强度及形态倾向；剑需成形主体与承接，复合身材按已开放位置投入 | 不把其中全部固、破等功用再次复制为成品功用 |
| 质材 | 建立器内根性与共同支撑通路，形成整件器的可用承载 | 不为每项功用分别复制一份满额承载 |
| 性材 | 提供最终功用候选；同一材料的多个功用共同分摊该份材料的供给 | 不由玩家指定成品一定具备哪一项功用 |
| 和材 | 处理配伍、加工与导通问题，帮助形成收益表达所需的实际通路 | 通、聚、藏等加工投入不自动附送独立战斗技能 |
| 燃料 | 支付提炼及加工的供热需求，影响本轮能完成哪些加工 | 不当作额外性材，不靠多烧燃料直接加攻击 |

“主体、承接”是剑类的基础加工职责，不是“阔刃、厚脊”预选器型。身材复合后形成的具体形态在结算时确定。

同一种材料可用不同实物份数分投岗位；每份只归一个岗位。同一岗位同种材料先合并数量，再折算效果，不能拆成多槽绕开递减或上限。换位置会改变职责，不只是换界面显示。

### 现有材料如何理解

以现有资源为事实：玄铁为金行、致密、固八品；裂甲石为金行、致密、破九品；青木芯有通八品、生七品；铜髓矿有固九品；灵石有聚、藏、通九品且未设置五行。

其中“玄铁适合成剑身”“青木芯适合作承接”仍需炼器加工档案明确支持。功用或材评不能替代这份加工依据。灵石无五行不是缺省金行，也不能默认用它支付任一五行通关。

玄铁投入身材时，本次主要用于结构；另投在性材位的玄铁才提供固结的成品功用候选。青木芯用于承接时，其生不自动变为回复生命。灵石的聚、藏、通可以支持工艺，但同一份不能按三个全额独立份数支付三项要求。

## 三、需要记录的过程量

采用分账的计算记录，不新增材料公共词缀或角色资源。

| 过程记录 | 内容 | 用途 |
| --- | --- | --- |
| 成材记录 | 有效身材体量、成形适用、延展与紧实倾向、连接与稳定情况 | 能否成器、实体结构、器型与载体约束 |
| 根性与通路记录 | 各根性来源的支撑量、五行送达路径、可支付的导通／聚集／留存投入 | 共同承载、配伍损耗、收益表达条件 |
| 功用记录 | 各性材来源实际保留的功用向量、损耗、未能利用量 | 最多两项功用及其效力来源 |
| 性相记录 | 输入及加工后的五行构成、阴阳倾向与局部冲突 | 加工适配及最终性相，不强迫归和 |
| 用度记录 | 真实物品需求、供热、工时、精力与工艺资格 | 开炼条件和一次性消耗 |

所有记录保留来源材料、岗位、份数和阶段。不要只保存一个总分，使得高攻击、坚固与御器都无法追溯。

### 加工数据缺口

现有MaterialCraftData只有五行、质地、阴阳及功用品级，不能据此推断完整物理加工表现。需要独立的炼器加工档案，至少声明：允许岗位及工艺、单份可成形体量、基础成材情况、延展／紧实倾向、加工难度及供热要求。

这份档案属于工艺规则，不是物品随机词缀。同一物品定义的所有副本继续同质。缺少档案的材料应显示“尚未配置此岗位的加工规则”，不能默认为全部可用或自动以零值参与。

## 四、一次结算的顺序

### 4.1 核验并冻结投入

核验岗位、整数份数、材料加工适用、已开放位置、造诣及器具资格。按物品定义合并总库存需求，冻结同一份草稿；校验中不扣料，不自动补材料，不因重新排槽改变结果。

材料选择合法不等于保证成器。需要区分“不能提交的非法操作”与“允许尝试但加工失败的配伍”；两者的扣料差异须随正式失败规则定案，当前不擅自开放真实扣料。

### 4.2 提炼与成材

建议记录每份原料如何分为可用部分与加工损耗：

```text
可用成材[i] = 投入份数[i] × 单份可成材体量[i] × 加工保留率[i]
加工损耗[i] = 原始可成材体量[i] − 可用成材[i]
```

保留率受工艺适配、供热和造诣掌握影响，位于合法范围内。辅助投入可以改善原有可用部分的保留，不能凭空生成额外原料。并非所有投入都有实体成材体量：液体和气体的通路用途不能自动当成金属剑身体量。

### 4.3 先形成结构，再命名器型

由实际成材及连接情况确定实体结构，输出有效体量、延展／紧实倾向、连接稳定及结构承载。之后才解释或绘制其形态；不先查询“阔刃剑”的固定承载。

形态建议采用连续参数。作为后续美术形态解算的候选表达：

```text
V = 有效剑体体量（不包括未成为剑体的性材、液体及燃料）
λ = 工艺和成材倾向决定的长宽比
τ = 工艺和成材倾向决定的厚宽比
宽 = 立方根[V / (λ × τ)]
长 = λ × 宽
厚 = τ × 宽
```

此处是规范化形态体量，不宣称等于现实米制体积。λ、τ须受剑类成形范围限制，其生成曲线与范围待加工数据校准。宽厚可同时较高，不强制落入三个互斥模板。

“宽刃”“厚脊”等可作为最终形态说明，不能再按名称额外乘一套属性倍率。承载和效果读取已形成的实际结构，避免同一结构贡献先加承载、再因命名免费重复加成。

### 4.4 结算五行与阴阳

先以岗位实际参与情况形成输入性相，用于本轮加工和配伍；再根据各来源实际保留量得到成器性相。分清“投入状态”与“最终状态”，不重复回算到收敛。

五行按来源建立送达路径：同行、相生、相克与经中间五行通关分别处理。通关材料实际占用份数及容量；无五行材料可以承担其定义的通用辅助作用，但不能代替任意具体五行。相生也只改善已存在供给的送达，不能把同一根性支撑复制给多个功用。

阴阳保留至阴、阴、偏阴、和、偏阳、阳、至阳七档。整体偏极不自动判失败；相互冲突的局部材料不能因为总平均接近和就被视为已调和。需要分别检查局部适配和整器倾向。

现有炼丹实现按MaterialCraftData.polarity的正、负、零读取“阳、阴、和”，其旧字段中的1不能直接解释为七档里的“偏阳”。进入新模型时必须统一解码与显示口径；现有物品的文字相性标签及旧三向读数要先校核，再确定七档标定，不能混用同一整数的两种语义。本轮未修改材料字段或炼丹规则。

### 4.5 性材生成候选功用池

同一份性材的多个功用共用一份来源供给。建议采用以下参数化框架：

```text
来源总潜力 B[i] = 同岗合并份数的有效量 × 该来源的供给刻度
来源分配权重 a[i,u] = W(功用品级[i,u]) / Σv W(功用品级[i,v])
功用有效量 E[i,u] = B[i] × a[i,u] × 加工保留 × 配伍送达
```

W与供给刻度需定义为非线性配置，不能直接把九品到一品序号当线性倍率；本篇不借用旧模型24点基数。单功用材料自然集中，多功用材料保留多方向潜力但不免费复制供给。

每一根性来源有一个共同送达预算，按来源记账：所有被采用支路消耗之和不超过该来源预算；结构也有一个共同承载上限。辅助材料的同一份可以具备多种适配资格，但本次只能支付一次实际配额。

### 4.6 最多留下两项成品功用

建议按以下步骤筛选，而不是机械取材料标签的前两项：

1. 列出性材实际提供且已有成品效果定义的候选功用。
2. 检查每项候选能否形成至少一种有效表达，低于最低有效要求者不成为成品功用。
3. 枚举单功用与双功用组合，在共同根性预算、结构及辅助投入约束下计算可实现量。
4. 以达到本功用门槛后的实际实现程度比较，候选比较口径须统一配置；同值用稳定ID打破平局，不由槽位顺序或随机决定。
5. 留下一项或两项，明确记录未被采用功用的原因。落选投入不偷偷转成另一项额外强度，未利用量单独记账。

本篇确定筛选步骤的提案，不先填入跨功用比较权重或阈值。新功用尚无战斗／成品效果定义时，应标为未适配，不临时编造效果；未知功用如何失败或形成无效器胚需随失败规则一起裁定。

### 4.7 收益表达也从实际通路形成

建议进一步取消“常驻、化法、直施、御使”的成品开关：材料在岗位中形成何种可用通路，成品才具备对应表达。这是本轮新增设计提案，尚非用户已确认的具体门槛。

| 表达 | 建议要求的实际条件 | 不足时 |
| --- | --- | --- |
| 常驻属性 | 功用能稳定保留并耦合器体，有有效承载与属性模板 | 不生成该属性，不能凭“装备了剑”自动附送 |
| 附加化法 | 有可附着并贯通使用者技能的通路，功用具有已定义技能修正 | 不生成化法；没有合格技能时也不转成其他收益 |
| 直接施展 | 有聚集与瞬时导出的通路，功用具有直接技能模板 | 不生成独立施展技能 |
| 召出御使 | 有承受外放的稳定结构、留存／导通通路及可用器体模板 | 不生成御器技能，不能默认所有法宝都可召唤 |

通、聚、藏等材料功用可以参与这些加工通路，但“有通”不等于必出化法，“有聚＋藏”不等于必出御器；还要满足有效量、结构和已定义模板。

每项最终功用有一份实际效力池。先由通路形成非负的路由份额，再按份额分配；达不到最低有效强度的表达不产出，其未利用量保留在结算记录中，不自动赠给另一条路线。这样添加辅助材料可能改变路线分配，需要解释这种变化，不能承诺所有旧效果只增不减。

```text
每项功用分给常驻、化法、直施、御使的效力之和 ≤ 该功用实际效力
整件器所有表达的结构占用之和 ≤ 实际结构承载
每份辅助投入只支付一次已分配配额
```

多种表达可同时成立，均不成立的情形须按成器有效性规则处理，不为展示方便硬补技能。具体技能费用、次数、冷却及化法条件均由正式模板决定，不从材料品级临时猜数值。

### 4.8 生成成器说明与记录

成器后显示：最终器型与形态图、至多两项功用、属性、化法条件、主动技能、器蕴，以及材料／工艺来源说明。

器蕴建议从最终保留下来的有效功用与器性产生，不按投料标签累计；一份未成为成品能力的残留材料不能贡献一层器蕴。层数及门槛另表定义，不复用旧模型的具体奖励作为已定新参数。

正式产物须保存本次计算版本与快照。其后材料表调整不能无声重算已有法宝；存档迁移与平衡修订单独处理。当前阶段不实施正式写档。

## 五、炼器造诣如何接入

建议造诣同时控制工艺掌握及复杂配伍能力：能否处理该材料、加工保留、能否稳定处理多来源／复合连接。具体资格与位置扩展门槛单独定表。

造诣不提供无来源的功用，不替代供热、连接或必要的通路投入；也不直接解锁“阔刃剑配方”。高造诣的价值是把投入中真实存在的潜力更好地成材、送达和组织。

过量原料仍受器具处理量和结构约束；可以用较低品材料增加投入补足部分量需求，但不能无限堆量代替明确的加工资格。所有精确上限待定，不沿用旧三器型容量。

## 六、剑类样例的正确演示方式

以下是新方案的定性例子，不声称已获得成器数值，也不宣布这些份数为新合法配方。

1. 选择大类“剑”；把可成形玄铁投入身材，用有明确连接适用的青木芯承担承接，质材建立可用根性。
2. 性材投入裂甲石，让破成为候选。此时大量身材玄铁的固仍主要服务成形，不自动压过性材产生固结成品功用。
3. 再分配独立玄铁份数到性材，才为固提供成品候选。两项候选需共同竞争实际可用的根性与承载，不获得两份免费满额供给。
4. 和材若形成较强贯通而缺少留存通路，可能支持化法而不满足御器；换成有足够聚集、留存且结构承受得住的投入，才可能出现召出御使。
5. 调整身材及加工后，若有效成材与延展改变，剑的宽厚等形态随之变化；具体宽刃或厚脊是在结算后描述，不是提前选好的图谱。
6. 炼后同时展示最后留下哪些功用、哪些表达、各自效力分配及具体形态。只有加工档案、阈值和属性转换齐全后，才给出伤害、穿防、护盾等数字。

### 仅用于解释守恒的算术例子

假设某次加工后得到一项功用的有效效力60个内部演算单位；已形成的化法与御器通路分别分到36与24，则两者合计仍为60。增加第三条表达必须从这60中再分配，或通过额外有效投入增加该池，不能再复制一个60。

这里的60、36、24只是算术说明，不是玄铁、裂甲石或任何实际投料的标定，也不对应60伤害、36%穿防或24护盾。

## 七、界面展示与结算验证

炼前展示按最新意见收紧：大类、岗位材料、整数份数、客观材性、五行阴阳及用度。撤回“已贯通／留存不足”等本炉工艺结论提示；不预测成品、达标状态或补料方向。通用教程与岗位说明可以解释原理，具体结果与原因在炼后揭晓。

炼后展示：结果及来源对照，例如“性材中的固形成固结；身材中的固用于结构；导通投入已被某路线消耗”；避免一段只有“炼制成功”的文本。

后续模拟器必须覆盖：岗位换置改变职责、同材拆槽不增效、来源和公共预算不重复、辅助配额不复用、最多两功用、器型命名不二次加成、五行无属性不冒充通关、阴阳平均不掩盖局部冲突、造诣不创造材料能力、相同快照可复算，以及开炼前后信息边界。

## 八、进入新样例实现前的数据清单

需补齐首批材料的岗位加工档案、功用品级及来源供给刻度、五行／阴阳处理表、通路份额与有效门槛、结构／形态曲线，以及首批效果模板的属性转换。这些均需明确标为候选并完成试算，再提交评审；不能从旧样例倒推一组刚好产出旧答案的数值。

本篇补完了结算顺序、来源记账、连续器型和收益分配的设计提案。后续独立候选试炼已运行新模型，并形成器物说明；不宣称新战斗卡、正式装备或新耐久规则已接入。
