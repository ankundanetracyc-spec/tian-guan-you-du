# 百川测试人口与过月性能

状态：现行。2026-10-11 用户确认人口建议并要求优化过月、保留演算效果和复用现有加载界面。配套《百川区域地点旅行与 NPC 月度演算规划》《个人修仙正式存档设计》。

## 人口规则

| 地点 | 首次生成／旧档补齐的普通可互动人口 |
| --- | ---: |
| 一级势力 | 60 |
| 二级势力 | 30 |
| 普通城池 | 50 |
| 小型聚居地 | 12 |
| 普通资源点 | 6 |
| 东林地 | 10 |

等级读取当前格网锚点，东林地独立覆盖为10；一级、二级势力按势力规模优先，不因兼容资源中的旧城镇类型重复追加人口。只为当前具有真实锚点、可进入的地点补齐；无内景的势力占位图不生成虚假人口。当前地图可生成580名普通人物，职能师承人物另计。不是全地区居民总数。

- 新生成且非职能常驻的人物，按来源地点分组取约20%作为在途初态，整数向下取整。执事、长老、掌门、护山、供奉和师承常驻不被抽走。
- 优先选择附近最多三个已开放、可通行地点，沿真实正交路线在普通野外格中落位，保存路径、下一格索引、格内进度及行动记录，不推进主角游戏时间。
- 月度主行动概率不变；在途人物仍随玩家主动时间按遁速逐格行进，不新增自然时间。
- 旧档仅一次补齐缺额，原人物含死亡／在途者计入来源地点名额；不覆盖原ID、外观、关系、死亡记录、行程。新增人物使用唯一ID。
- `npc_population_version=1` 随正式存档保存；重进、读档或人口死亡后不重新补齐。新旅程清零版本，避免自动补人成为无限刷新。

## 性能与加载复用

- 不跳月份、不抽样人物、不删除历史；按原人物顺序、稳定随机种子与逐月旅行／行动时序执行。
- 月度访人使用地点候选索引和单次最小种子选择，等价于原全表过滤后稳定排序取首项。死亡／离场仍即时过滤；数据工具无格网时保留全表候选以兼容旧旅行结算。
- 同一结算内缓存实际格／遁速的精确旅行费用及同起终点路径，不改变代价公式或路线。结算结束清缓存，避免后续地形变化使用旧数据。
- 保留每条行动记录与逐条记录信号；将整次过月期间的人物列表／地图刷新合并为最后一次，避免界面反复重建。
- 休息、修炼等既有长行动通过原 `ActionTransitionPanel.play` 分帧结算；大世界跨月行旅通过同一面板的实际工作模式等待演算，无需另外一套加载素材，也不附加固定数秒等待。
- 分帧预算约4毫秒后交还主线程；单个人物／寻路操作为原子步骤，4毫秒不是硬上限。时间总量、遁速、资源费用和动作结算结果不变，分帧只分散现实计算时间。
- 结算期间暂停场景输入、阻止Esc及手动／自动存档；完整结算后恢复之前的暂停状态再继续行动，避免保存“日期已更新但NPC只结算一半”的快照。
- 普通不跨月的格移动继续轻量同步结算；副本采集和遭遇保留原同步时序，不绕过原有中断规则。

## 验证与测量口径

### 多人入格与副本站位修订

2026-10-11 用户反馈进入多人格卡顿、东林地人物堆在入口，以及格内排列过于整齐，现行修订如下：

- 共用角色名单保留全部人员和完整滚动长度，但初次只建立轻量行占位；可见的完整行与原立绘裁出的头像按帧加载，每帧最多一个构建步骤。屏幕外、收起或隐藏时不加载；相同地点、人员及展示字段未变化时不重建名单。不是抽样人口，也不改头像身份。
- 角色名单滑条仅在内容超过可用高度时显示，空名单或一页容得下时隐藏。鼠标位于展开名单内（含人物行、头像、标题和留白）时，上下滚轮归名单所有；到顶／到底或无需滚动时也不穿透缩放底图。大世界输入在GUI派发前按事件坐标避让名单，副本沿用GUI滚动阻断，收起／隐藏时不占用底图滚轮。
- 东林地首次纳入的真实驻留人物，按地图种子和人物ID分散至既有可达节点，不再统一入口。旧档只迁移未行动的入口初态（步数、边内进度为零且无上一节点），版本字段 `dungeon_placement_version=1` 随NPC资源存档；已有行程、时间与资源不重置。
- 格内使用确定性随机矩形装箱，棋子图像范围不重叠、不越界，不按整齐行列排列。拥挤时适度缩小；相同地图／节点／人员及窗口尺寸下刷新和读档站位一致，人员变动时允许重新让位。玩家与NPC继续沿原正交通路播放摆动移动动画，不改遁速与演算。
- `NpcPresentationSmoke` 覆盖60人完整名单、首屏7头像及滚动补载、同名单不重建、收起不被移动展开；500组不同数量／种子的站位均不重叠、不越界且重复生成一致，检查新人物／旧入口分散和真实行程保留。60人首次名单占位在本机无窗口样本约3.5ms，非完整游戏单帧指标。地图／行动回归也通过。
- `RosterScrollSmoke` 通过真实输入派发验证0／1／7人无滑条、25人可滚动、人物行与标题滚动、到底不缩放、大世界及副本隔离、底图区域正常缩放、人数减少自动隐藏与归零。C#编译通过；加载完整世界场景时另发现天气叠层 `scripts/world/WorldMapWeatherOverlay.gd:332` 的 `draw_polygon` 参数数量解析错误，本次未修改该无关模块，不能将本项滚轮测试通过视为完整世界场景无报错。

人口测试覆盖规模、真实野外坐标、职能留守、初始化零游戏耗时、旧档补缺、ID唯一、死亡／原行程保留、真实Resource存读与不重复补人。

580人无窗口测试的优化前样本：单月约109ms，一次十二个月约1428ms、人物刷新24次。优化后样本：单月约77～97ms，一次十二个月约743～753ms、人物刷新1次。这是本机不同随机人口的样本，不是严格固定种子的性能提升比例，也不含完整游戏UI／绘制成本。

分帧与同步使用同一份初始快照推进十二个月，逐字段比较所有NPC导出字段及完整行动历史；结果一致。分帧检查包括复用加载面板、期间仍有渲染帧、最终一次刷新、恢复暂停、世界行旅等待桥及旧长行动入口。分帧可能增加总现实等待时间，以换取持续渲染响应；不能把总等待时间当单帧卡顿。

最终回归样本：单月66ms、十二个月790ms；分帧十二个月跨124个渲染帧、现实耗时2605ms，最大演算切片16.53ms（含不能拆开的单人物／寻路步骤）。因此不宣称所有帧均小于4ms或已经覆盖完整游戏场景的帧率。编译0警告0错误；人口、地图／迷雾、行动、同步／分帧完整字段一致性、真实加载入口和GDScript输入脚本检查通过。未修改另一任务的人物／道基接口。

扩大人口时修复兽皮／灵石材性资源的非法中文子资源ID，并缓存携带物定义，避免批量加载时释放托管包装；不改材性数值、掉落或库存规则。既有《卸力》UID回退警告不在本次扩大处理。
