# 百川区域仙盟大势力与二级辖域规划

> 状态：现行专题（2026-09-18 用户确认修订）
>
> 适用范围：百川区域的仙盟、一级势力、二级势力与固定管理范围。
>
> 上位来源：《当前项目：个人修仙改造路线》《大陆格局与百川区域设计》。本案按现行设定将当前首期区域称为“百川”。
>
> 2026-09-23 空间裁定：百川是当前制作区域，不是州或州域。大陆只负责自然地理和远行分组；本文的一、二级势力是百川内部的政治层。

## 一、总裁定

### 0. 百川的空间身份

- 百川是当前唯一完整制作、可进入和可持续扩展的内容区域。
- 百川不挂接旧州级名称，也不与其他旧行政单元并列；它是大陆内部由河湖、山口、古道、荒域与近海构成的旅行单元。
- 四个一级势力和十二个二级辖域只描述百川内部的政治与内容组织，不改变大陆、区域、地点的空间层级。
- 其他大陆和其他区域只保留远行、航路、传闻与后续制作接口，不在本期冒充可探索地图。

### 1. 仙盟只负责对外

仙盟是百川各大势力为了应对区域外敌而组成的松散共同体。它负责外敌入侵、跨区域妖潮、天灾级异变、界外通道和共同防线，不负责日常治理，也不负责强行调停盟内争端。

平时各势力可以争夺资源、争抢弟子、封锁道路、竞争商路，甚至互相敌对。仙盟没有统一税制、统一门规或常设的内部仲裁机构；内部冲突由相关势力自行处理，或通过临时谈判、雇佣见证人和地方协议解决。

外敌出现时，天人修士临时召开盟议，确定共同防线和战时主事者。敌情结束后，战时权限自动解除，仙盟回到松散状态。

### 2. 仙盟不是第五个一级势力

仙盟不拥有一块独立的“仙盟领地”，也不把百川所有土地收归中央。中央只设置一个用于议战、传令和会面的盟府，不从四个一级势力的管理范围中切出新的政治区域。

盟府的作用类似共同议场和外敌警戒点。它不收普通弟子、不经营市场、不替各势力发放日常任务，也不拥有凌驾于四个一级势力之上的常规行政权。

### 3. 二级辖域是实际的地图管理单元

每个二级势力都必须拥有一块固定、连续、可在地图上定位的地方管理区。它可以是一处山谷、一个河段、一片林地、一座城镇周边、一处海湾、一个矿区，或一块由家族、商会、宗门、军府、部落实际控制的区域。

一级势力的正式范围，严格等于其下属二级势力范围的总和。二级辖域内部可以再放置山门、城镇、洞府、矿区、渡口和野外事件点，但这些是地点，不再另立政治层级。

山脉主脊、无人荒地、禁地、深海和暂未开发的异变区可以作为无主地存在，不纳入任何势力的正式范围。它们是旅行风险和探索内容，不是边界漏洞。

## 二、两层势力结构

### 1. 一级势力：完整的区域强权

一级势力不是单一功能组织。每个一级势力都必须拥有：

- 完整的修炼传承与高阶修士体系；
- 能自给的资源、炼制、交易和补给网络；
- 直属弟子、附属组织、城镇或家族；
- 独立处理战争、旅行、治安和灾害的能力；
- 至少一名由本势力神胎突破而来的天人盟籍。

一级势力可以有偏好的文化和道路，但不能只靠“掌管某一种资源”成立。四个一级势力之间实力接近但不完全相等，任何一个都不能轻易吞并其他三个。

首期四个一级势力为：

| 一级势力 | 组织形态 | 主要气质 | 范围方向 |
|---|---|---|---|
| **玉虚仙宗** | 正统大宗 | 重师承、传法与秩序；最愿意把仙盟规则写成明文 | 百川中部偏西的河谷、山地和旧道 |
| **太微道宫** | 古老道宫 | 传承完整，兼有城镇、道场、商路和隐修地；重视长期布局 | 中北部河源、台地和雪线过渡区 |
| **玄都天府** | 府院与世家共同体 | 以府院、家族、工坊和城镇组成复合势力，重现实资源与人事网络 | 西部群山、古驿和内陆盆地 |
| **无相圣宗** | 魔道圣宗 | 以“无相”为道统，自称圣宗；拥有完整的魔道修炼、生产、交易与军力体系 | 东南内陆台地、下游支流、旧盐泽与通海暗线 |

“无相圣宗”是正式名称。正道势力可能称其为魔宗或邪宗，但仙盟是否承认其盟籍，只看它是否参与百川对外防卫并遵守战时约定，不以单一称呼决定其政治资格。

### 1.1 首期一级势力生成锚点

现行地图由策划手工拼接固定方格地貌，旧版 3200×1800 场景坐标用于对齐固定地图格网。四个一级势力继续保留方位意象与地貌倾向；锚格由策划固定落位，并给中央河谷盟府及公共内容留出空间。

| 一级势力 | 方位与生成约束 | 节点表现 |
|---|---|---|
| 玉虚仙宗 | 西南河谷平原与支流旧道；落在可通行平地，不压峰顶 | 河谷山门印记，暖灰纸色 |
| 太微道宫 | 东北雪线下的河源台地；贴近雪地并避开山脊 | 冷灰道宫印记 |
| 玄都天府 | 西北古驿盆地与山前缓坡；落在盆地开阔处 | 厚重府院印记 |
| 无相圣宗 | 东南内陆台地、下游支流与旧盐泽上游；不贴海岸 | 深灰圣宗印记 |

世界地图上的一级、二级势力节点插画统一输出为 **2048×2048 像素、带透明通道的 PNG**；一级节点按 3×3 逻辑格、二级节点按 2×2 逻辑格缩放安置。当前逻辑格为 256×256 像素，一级节点的 3×3 占格足迹为 768×768 像素。插画画布外保持透明；只有与地图纯白陆地相接的地面区域使用纯白（#FFFFFF），不得将整张画布铺白。该规格只用于世界地图势力节点插画，不替代宗门/地点内景背景的 1672×941 规格，也不改变地块素材规格。

百川格网、辖域蒙版、势力锚格、地点锚格和战争迷雾统一按《百川固定方格世界地图设计》手工对齐；编辑器场景与运行时读取同一份固定地图数据。

### 2. 二级势力：一级势力的直属中坚

二级势力可以依附某个一级势力，也可以保留较大的自主权。它们通常拥有一名神胎修士、多个玄基修士和稳定的地方资源，能够影响数个地点，但无法单独承担整片百川的外敌压力。

首期配置十二个二级势力，每个一级势力下三个；后续可按地图和内容需要扩展到每个四个。二级势力的类型不固定，可以是：

- 中型宗门、道观、寺院和府院；
- 家族、山庄、部族和地方世家；
- 城邦、河港、商会、工坊院和镖局；
- 猎会、散修网络、海上会盟和军镇；
- 服从无相圣宗的魔道教派、魔修家族和黑市组织。

以下是首期工作名与类型分布；工作名、上级归属、地点挂接、格位、辖域边界和可通行路径均由策划固定：

| 所属一级 | 二级势力工作名 | 类型 | 主要特点 |
|---|---|---|---|
| 玉虚仙宗 | 青岚观 | 道观 | 山间修行、符箓、镇邪与地方传承 |
| 玉虚仙宗 | 白石城 | 城邦 | 交易、消息、落脚和低阶修士聚集 |
| 玉虚仙宗 | 东林镇妖会 | 镇妖组织 | 镇妖、采集灵材、守护山林与散修互助 |
| 太微道宫 | 海川会 | 商贸会盟 | 河运、近海贸易、船队和航图 |
| 太微道宫 | 长风护道会 | 护道组织 | 修士护行、灵材商路保全和远行消息 |
| 太微道宫 | 春水府 | 水府与城镇 | 湖泽、灌渠、水产和水患处理 |
| 玄都天府 | 关山府 | 山口军府 | 关隘、古驿、护路和妖兽迁徙 |
| 玄都天府 | 赤炉堂 | 炼器堂口 | 炉火、矿材、兵器和修缮 |

| 无相圣宗 | 灰骨寺 | 魔道寺院 | 尸傀、葬地和旧战场资源 |

二级势力之间并不天然友好。即使同属一个一级势力，也可能在河权、矿脉、弟子、商路和辖域归属上发生冲突。

#### 2.1 固定管理辖域与地方形态

二级势力就是玩家最常接触的实际地方势力。它们拥有明确的管理范围、固定入口和地方关系，但不一定拥有完整独立的高阶传承；一级势力直接对它们进行册封、保护、征调和问责。

首期配置十二个二级势力，每个一级势力下三个；后续可扩展至每个四个。二级势力可以采用以下形态：

| 形态 | 固定管理范围 | 常见内容 |
|---|---|---|
| 小宗门 | 山谷、灵脉、数个村镇 | 收徒、传法、试炼、山门禁制 |
| 家族庄园 | 河段、田地、矿区、山林 | 家族客卿、采集、生产和护卫 |
| 城镇与行会 | 城镇及周边道路 | 交易、住宿、传闻和低阶委托 |
| 军镇与关卡 | 山口、古驿、边界道路 | 通行、护送、战斗和封锁 |
| 商会与船队 | 港口、河段、海湾 | 航运、贸易、航图和水上风险 |
| 猎会与部落 | 森林、草地、荒原 | 猎妖、采集、部族关系和野外生存 |
| 小型魔道组织 | 废矿、密林、旧战场、暗港 | 黑市、邪法、劫修和隐藏委托 |

二级辖域的范围不只是地图上的装饰色块。它决定内部地点的初始关系、通行条件、资源恢复、敌对人物、地方事件和玩家能否在此安全落脚。辖域内的山门、城镇、渡口、矿区和野外区域属于地点配置，不再拥有独立的上级势力关系。

## 三、归属链与地图数据规则

### 1. 唯一归属链

每个有主地块只允许一条正式归属链：

```text
二级势力 → 一级势力
```

一个二级势力不能同时被两个一级势力正式计入辖域。临时驻军、租借、商路合作和短期封锁记录为状态，不改变正式归属。

### 2. 一级范围由二级辖域合成

地图数据不再给一级势力单独画一块与下级不一致的多边形。正确流程是：

1. 先制作二级势力的固定辖域；
2. 将同一一级势力的二级辖域合并，得到一级范围；
3. 在二级辖域内部布置地点，不再生成新的政治边界；
4. 对边界进行自然地貌修整，但不能改变归属面积和邻接关系。

这样可以避免上级边界穿过下属地点，也能保证地图、节点、声望和旅行数据使用同一套范围。

### 3. 边界形态

二级边界优先贴合河流、山脊、湖岸、林线、道路和旧渠，不使用规则网格。边界可以有自然弯曲，但应避免无意义的锯齿和细碎飞地。

一级边界只作为逻辑汇总，不在正常地图上画粗重外框；二级辖域在需要查看归属时以淡色纸纹和细边显示。

### 4. 地图显示层级

- **编辑器预览**：可以打开完整势力层，检查所有二级辖域、归属关系和邻接错误；
- **远景总览**：只显示四个一级势力的印记和大致影响范围；
- **中等缩放**：显示当前镜头附近的二级势力；
- **近景探索**：显示二级辖域内的地点、淡色范围和地点归属；
- **点击面板**：显示完整归属链、管理者、声望、通行条件和当前冲突。

运行时不使用大面积纯色覆盖水墨底图。二级辖域采用低饱和纸色、地貌纹理差和细边缘；未探索区域只显示模糊的势力印记或地形，不提前公开全部名称。

## 四、天人与仙盟盟籍

### 1. 天人来源

仙盟内的天人必须来自百川原有势力的神胎突破。天人不是凭空从仙盟中诞生，也不是所有突破者都自动成为仙盟的行政官。

突破后，原势力为其确认出身和传承，盟府只登记其外敌防卫盟籍。该天人仍然代表原势力的利益，并可以继续庇护本门、家族、城邦或魔道组织。

### 2. 平时状态

- 天人各自回到本势力或自己的洞府，不接受仙盟日常调度；
- 仙盟只维持外敌预警、信使、边境观测和共同防线；
- 一级、二级势力之间的争端不自动上交仙盟；
- 任何势力都不能以仙盟名义取得其他势力的资源、弟子或领地。

### 3. 战时状态

当外敌进入百川、界外裂隙扩大或出现区域级灾害时，天人临时盟议启动：

1. 确认威胁是否达到共同防卫标准；
2. 按各势力的实力、位置和资源分配防区；
3. 推举一名或数名战时主事者，期限只持续到本次危机结束；
4. 各一级势力向下调动二级势力，但不得借战事永久吞并他人领地；
5. 威胁消退后，战时权限、临时征调和统一命令自动结束。

无相圣宗及其盟属魔道势力可以参与共同防卫。它们是否被信任，取决于实际出兵、协防和战场行为，不取决于仙盟是否认可其道德理念。

## 五、势力关系与玩家归属

### 1. 一级势力之间

四个一级势力没有固定的正邪阵营，也没有永久盟友。玉虚仙宗可能与太微道宫争夺传承解释权，玄都天府可能与两者争夺山口和矿脉，无相圣宗则会利用三方矛盾扩大自己的二级辖域。

仙盟只在外敌出现时把它们拉到同一条防线上，危机结束后原有竞争继续存在。

### 2. 一级与二级势力之间

二级势力可以通过赐予、租借、联姻、收徒、保护、兼并或临时协议获得和调整辖域。一级势力可以册封、撤换、分割或合并二级势力，但不能把二级辖域继续拆成新的政治层级。

玩家的正式身份与势力声望分开记录。玩家可以成为某个宗门弟子、某个家族客卿、某个商会护卫，也可以维持散修身份；不同身份的兼任限制由具体势力决定。

本文的七阶声望表达“具体势力对玩家的态度”，逐势力独立记录；它不同于“百川区域声望”（玩家在百川的名声/可识别度），也不同于某位 NPC 与玩家的个人关系。百川区域声望可由所属知名势力的基础声名与玩家当前身份倍率、以及公开个人事迹共同构成；它影响当地人是否听闻/认出玩家和初见反馈，但不会自动改变任何势力的七阶态度、通行权限或 NPC 私人关系。玉虚仙宗的公式与原型参数见《玉虚仙宗宗门生态规划》。

### 3. 玩家早期入口

百川早期不直接让玩家选择一级势力。玩家先从二级辖域内的地点接触地方势力，再通过委托、交易、护送、探索、拜师、投靠或背离逐步接触二级和一级势力。

玩家看到的不是“加入一级势力按钮”，而是：

- 二级辖域内地点的管理者和地方需求；
- 二级势力对下属地点的保护、征调和资源分配；
- 一级势力对整个辖域的传承、战争和长期路线；
- 无主地、魔道据点和外敌事件带来的越级机会。

## 六、首期落地范围

本案先完成结构和首期十二个二级辖域的地图挂接，再逐步补齐各辖域的全部地点。首期按以下顺序推进：

1. 确定四个一级势力的自然辖域和中央盟府位置；
2. 为每个一级势力放置三个二级势力，校验类型、地点挂接与地貌匹配；后续需要扩容时再增加第四个；
3. 先制作每个二级势力的固定格网辖域和首批地点，形成完整归属图；
4. 将二级辖域与地图节点、旅行限制、声望和归属面板接通；
5. 再逐步补齐辖域内地点、无主地、海域缓冲和魔道暗线；
6. 最后增加天人相关人物、战时防区和外敌事件。

当前实现骨架位于 `resources/world/bai_chuan/bai_chuan_second_level_catalog.json` 与 `tscn/world/NodeWorldMap.tscn`：目录负责唯一归属链和辖域类型，地图场景负责固定底图、固定格网、辖域与地点锚点。现行场景中的固定道路折线可迁为地图地貌/通行代价，不再是唯一寻路图；新寻路按固定格网和地形通行条件计算。运行时地图与编辑器中的格子、地点、辖域必须读取同一份固定数据。

正式名称、二级势力的全部地点、各级天人数量和战时主事者暂作为下一轮细化内容；当前先锁定两级关系、范围合成规则、仙盟边界和魔道可入盟原则。

### 入门起始身份与晋升

玉虚仙宗按灵根确定新入门弟子的起始身份；真传是天灵根在入门时直接获得的身份，不属于任何晋升路线。其他弟子的后续晋升不以起始身份作为上限：

| 灵根 | 入门起始身份 |
| --- | --- |
| 无灵根 | 不予接收 |
| 四灵根、五灵根（杂灵根） | 杂役 |
| 三灵根 | 外门弟子 |
| 双灵根 | 内门弟子 |
| 天灵根 | 真传弟子 |

起始身份由灵根档位确定。杂役、外门与内门之间的晋升只依据修行境界与宗门贡献；真传只能由天灵根入门取得。泛势力态度和百川区域声望均不能替代境界与贡献，也不能用于晋升真传。

本表是玉虚仙宗现行规则，不外推为其他宗门的通用录取规则。旧稿中关于玉虚仙宗灵根破格、拒收或试炼改变起始身份的说法均由本节取代。

玉虚仙宗完整宗门生态、真传师承培养、身份兼任门规、八峰玩法职责与待定规则分别见现行专题[《玉虚仙宗宗门生态规划》](玉虚仙宗宗门生态规划.md)与[《玉虚仙宗真传入门与师承培养流程》](玉虚仙宗真传入门与师承培养流程.md)。专题不得改写本表的灵根分档和晋升依据。

### 新入门者入口与身份登记（策划现行；运行时已有首版）

未入宗者第一次从大世界点击玉虚仙宗“进入”，直接开始山门迎真：由具观因察果之能的金丹接引长老查看玩家在此世的真实经历因果，并另行察看资质；长老只问“可有宗门？”，“有”则礼貌结束且不继续办理加入，“无”则安排弟子领入后续流程。天灵根真传按《玉虚仙宗真传入门与师承培养流程》正式拜金丹师父，由师父委派云息十层同门日常带教，收徒录籍后直接安置紫府峰；首卷沿用现有三本候选与规则。玩家穿越来历受天道遮掩，不会被看穿。具体因果评语必须有真实经历记录支撑，业力净值、区域声望、势力态度与 NPC 私人关系均不能替代跟脚。

已属玉虚者再次进入世界节点时，直接打开八峰总览；进入后点击峰位标签，前往对应峰的独立内景。观复峰提供杂役、外门、内门弟子的基础居所、静室、休息、授业与月例；紫府峰提供真传居所、静室与休息。其余峰内功能、月例以灵石累积、贡献与灵石分立、个人档案位置以及声望/势力态度/个人关系互不自动换算等规则维持不变。无灵根者不予接收；玉虚允许弟子和长老兼任家族客卿，家族身份与宗门身份分开记录，不阻挡拜入。峰内不放通用事务总板或贡献兑换商店，生态与玩法范围以《玉虚仙宗宗门生态规划》为准。

实现边界：山门迎真入口、因果事实读取、宗门问答分支、接引弟子、真传正式会面、录籍存档及峰内直达已有首版实现。玩家经历事实当前接入青溪里序章三项事件；其他系统尚未普遍记录。玉虚硬性门规的机器可核验目录与事件证据映射仍待定义，因此首版不凭业力、声望、关键词或未核实线索拒收。

杂役、外门与内门之间的晋升仍以境界与宗门贡献为据；真传不能由晋升获得。贡献由各峰派发并可追溯的事务产生，兑换地点按峰职能后续确定，不塞入观复峰。角色数据字段目前由运行时角色资源承载；在项目建立正式存档流程前，不应宣称这些字段已支持跨进程存档。
