六层至七层凝核小游戏以[云息六回合凝核构筑设计](云息六回合凝核构筑设计.md)为当前玩法入口：六回合、24张牌、手牌6张、每回合3次出手，外物不占出手；牌效与成核底线为首轮平衡草案。旧[八回合规格](云息凝核小游戏实施规格.md)及[旧网页](../prototypes/eight-breath-condensation.html)仅留作追溯，K/Q、旧核媒及旧回合数不带入新牌局。境界其他资料见[云息十三层旧工作稿](../云息十三层与秘籍成长规划.md)，永久品质、后续倍率和复试消耗待统一接入；玄基入境牌局见[铸玄基小游戏实施规格](铸玄基小游戏实施规格.md)，云满而雨仍属于铸玄基过程。

境界视觉以[云息境界界面表现](云息境界界面表现_20261009.md)为本轮实施入口：保留现有纸面与境界签，先完成一至六层灵气积聚、六至七层收缩成核，再接牌局。最新修订复用原旋涡气流并缩小范围，右上题字淡墨、拉开间距，按右起一/三句高、二/四句低逐字顶对齐。旧凝核牌局概念图已否定。当前代码与网页为待审版本，尚未编译或游戏运行验收，不改动突破数值与旧结算。

修行风格与阶段区分先读[高境界体系与天人设定确认稿](高境界体系与天人设定确认稿.md)。现行果位结构为五太各四权、共二十个唯一果位；旧“五太 × 五行”果位分类与干支命签不再生效。灵根、五行性材、相性、原有道途、阴阳、定干、天干合化、命辰、功法、太痕与纪时等作为求果输入，具体算法仍待细化。神胎（元婴）修行包括雷、风、火三劫；天人持果后可能面对天人五衰。高层结构为现世、太虚、钧纪、上界；太虚是所见，钧纪是规则所以然，神胎认知进阶为见痕、通理、触纪。养成结构为“修命（锻体）＋修性”；修性以三景心相图为主体，作为所有修士共通的观变、察势、应物之学。当前细案保留一重至五十重的温观／观法循环与图景配置接口，本轮只定义日象·烈日的全场气血周期效果和 35 重净化节点；寒月、远山、孤灯等图景不指定属性或效果，修性不新增状态资源、Buff 或被动槽。统一修行入口与修命／修性总览也纳入调整。日象触发条件和数值待体验审阅、未接入运行时，详见[性命双修养成重构提案](性命双修养成重构提案.md)。锻体细则见[锻躯淬体养成规划](锻躯淬体养成规划.md)；[蕴神观想养成规划](蕴神观想养成规划.md)只记录三景的旧运行时实现，五行参悟继续作为兼容／迁移资料。五行悬基与升维旧讨论稿仅供追溯，果位旧分类和命签已标明废止。
