## 查询顺序

1. 本系统的分类 README：先看主入口与覆盖关系，再看“全部文档”。
2. 原案全文及同体系词典：确认具体效果、参数与实现边界。
3. 有跨系统联动时，按分类入口中的链接读另一系统，不凭当前目录名截断检索。
4. 需要截图或实施证据时查[美术与验收目录](../美术规范/README.md)；追溯旧裁定再查[整理前索引](../归档/目录整理_20261109/README.md)。

## 状态与维护

- “现行规则”“候选参数”“已接入”“独立样稿”是不同维度；以原文明确说明为准，不按文件日期或分类位置推断。
- 历史方案和旧验算保留在本系统清单，可供追溯；已经被覆盖的内容不得重新拼入现行规则。
- 新增正式策划只放本分类，更新该分类入口并刷新目录；不要把工作进度堆回总索引或快速摘要。
- `python tools/design_docs.py --refresh --check` 刷新完整目录并检查漏项、残留路径和新增失效链接。
- `python tools/design_docs.py --find 关键词` 搜索策划正文、词典和数据；加 `--evidence` 扩展到美术证据、原型与日志。
