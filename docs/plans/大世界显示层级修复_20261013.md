# 大世界显示层级修复

> 2026-10-13，现行显示约定。用户反馈大世界角色、脚印与节点插画不可见；本次只修显示结构，不改行走、时间、寻路、视野或存档规则。

## 根因与修复

`TileWorldMapPresentation.tscn` 在实例化地形之后插入了一行 `#` 注释。该位置的注释使后续 WeatherLayer 节点头没有正确建立，天气层的 `z_index=125`、可见性等属性被应用到前一个地形实例。运行时观察到地形根层级为 125，而角色有效层级仅为 17，因此不透明地表覆盖了角色、路线、迷雾和节点。加载同时报告 CloudCover 与 PrecipitationAndLightning 的父节点 WeatherLayer 不存在。

删除该注释，说明移入 WeatherLayer 的 `editor_description`。场景地形实例显式设为 z=0，运行时也统一地形根的相对层级与 z=0。天气视觉仍为隐藏且停止处理，天气业务状态保持原样。嵌入正式地图时停用地形预览脚本的独立输入处理，保留正式地图统一的行走、缩放与拖动入口。

## 绘制约定

CanvasLayer 与同画布中的 z 值分别管理，不把它们混为一个数字序列。

| 主场景 CanvasLayer | layer |
| --- | ---: |
| 地点场景 SceneLayer | 10 |
| 世界地图 MapLayer | 15 |
| 常驻 HUDLayer | 20 |
| 功能面板 CanvasLayer | 30 |
| 对话 DialogueLayer | 40 |

打开世界地图时使用 MapLayer 15；进入地点隐藏世界地图。常驻 HUD 始终高于地图。本表将旧 UI 规范中 MapLayer=0 的记录校正为现行场景的 15。

| 正式地图内部 | 有效 z（MapCanvas=0） | 规则 |
| --- | ---: | --- |
| 纸底 | -100 | 仅背衬 |
| 地形根、地表、底染与自然地物 | 0–6 | 地形根必须为 0；子层保留自身排序 |
| 探索迷雾 | 10 | 覆盖自然地物，不覆盖已知战略节点和行走提示 |
| 已知节点图示与名称 | 13 | 沿用战略节点始终显示规则 |
| 路线鞋印 | 15 | 随地图缩放，按实际路线绘制 |
| 目标旗标 | 16 | 当前格不显示 |
| 玩家角色 | 17 | 衣摆底端锚定当前格中心，128 地图像素高 |
| 普通格人数／节点人数 | 14／33 | 保留现有徽标规则 |
| 天气视觉（暂关闭） | 125 | 独立屏幕覆盖，不得写入地形实例 |
| 地图操作、目标说明与进入按钮 | 130 | 屏幕控件；常驻 HUD 由更高 CanvasLayer 保证 |

WorldMapOverlay 继承地图变换，基准 z=10，其子节点使用相对 z；禁止用抬高整个地形来修个别素材的遮挡。

## 实际运行观察

使用项目 Godot 引擎实例化正式 `TileWorldMapPresentation.tscn`，没有加载或写入正式进度存档；观察初始位置、两格路线预览、点击启程抵达 (40,166)，以及 25% 缩放画面。

- 修复前可复现仅有地表与自然地物，角色、鞋印、地点及迷雾被覆盖。
- 修复后角色、鞋印、旗标、玉虚仙宗插画与名称均可见。
- 路线行走后输出 `player_cell=(40,166), moving=false`。
- 25% 视野可见当前明区、已探索暗区、未知迷雾，以及迷雾上方已知节点。
- WeatherLayer 父节点丢失警告已消失。
- 未跑全流程主场景／真实存档回归。退出仍有既有 ImageTexture／RenderingServer 资源释放诊断，不属于本次遮挡根因。
