# 角色单向关系与好感系统

> 状态：现行首版，2026-10-14。人物之间的私交使用单向记录；不读取旧的综合关系分推算新关系。

## 一、目标与边界

系统统一描述玩家与 NPC、NPC 与 NPC 的私人关系。关系由实际交往和可核验经历形成，每条记录只表达一个人物对另一个人物的感受。双方可有不同数值、不同阶段，也可以只存在一方的记录。

以下信息继续独立保存和判定：姓名与境界认知、交往印象、性情、势力态度、区域声望、业力、心境、案卷事实。关系不能充当执中峰裁断罪责或处分的证据；记录关系事件不改心境值。

玩家没有修改关系数值或阶段的操作。关系不因时间流逝自动衰减，也不合成综合好感分。

## 二、数据与阶段

关系以稳定人物 ID 稀疏保存。只有实际事件发生时才建立人物对记录；玩家固定使用 `player` 作为存档内稳定人物 ID，NPC 使用 `npc_id`。每条关系有四个相互独立的 0–100 数值：

| 维度 | 玩家可见阶段名称 | 影响范围 |
| --- | --- | --- |
| 亲近 | 尚无私交、略有往来、渐渐相熟、彼此亲近、深厚情谊 | NPC 主动来往与亲近称呼 |
| 信任 | 尚无托付、尚可往来、有所信赖、可托实事、深度信赖 | 仅在已有托付型行为中使用；当前没有相应行为时不生效 |
| 敬重 | 未见敬意、略有认可、颇为敬重、深深敬重、由衷钦佩 | NPC 是否愿意发起切磋，以及谨慎性情对切磋的判断 |
| 怨结 | 未结怨、微有芥蒂、心存不满、怨意深重、结怨难解 | 避免来往、拒绝切磋与副本敌意 |

阶段由数值确定，不另存可能与数值脱节的阶段字段：0–9、10–29、30–54、55–79、80–100。界面只显示阶段，不显示原始数值；原始值留给调试和规则检查。

## 三、事件归纳与原型参数

每条证据保存唯一事件 ID、事件类别、受影响维度、发生月份、基础影响和事实说明。录入时按事件 ID 防重。严重伤害、背弃和重大救助即时结算；一般交往先保存证据，经过月度归纳后才改变关系。

一般重复事件按同一人物对、同一事件类别柔性递减：第 `n` 次实际结算的影响为 `max(1, ceil(基础影响 × 2 / (n + 2)))`。结算次数保存在关系记录中；影响下限为 1，不会因重复而归零。成功交谈每月最多留一条有效证据，并至少在两个不同月份聊成后才开始增加亲近。

首版可调基础影响如下：

- 不同月份聊成：亲近 +3；同一月重复交谈不增加证据。单次交谈不加亲近。
- 双方按接近公允价值完成交易：双方分别获得信任证据，基础影响 3。公平区间按玩家交出物品总估值／NPC 交出物品总估值判断，比例为 0.90–1.10；双方估值均为零时视为相等。关系不抵价；普通或不公允成交不自动增加信任。
- 完成一次非性命之争切磋：双方分别获得敬重证据，基础影响 4。切磋落败不会自动增加怨结；切磋提前中止不算完成。
- 明确伤害或背弃：受害者只增加对行为人的怨结，基础影响 18，即时结算。
- 重大救助：受助者只增加对施助者的信任，基础影响 12，即时结算。另一方感受需要单独的事件证据，不自动镜像。

NPC 彼此过月实际访人时，双方分别记录一次交谈证据。NPC 与玩家的日常交谈、交易及切磋也分别写入双方记录；每个方向独立去重、归纳和变化。

## 四、行为影响范围

- NPC 对玩家的亲近达到 30 后，可作为主动来访的一个充分理由；达到 80 且对方姓名已获知时，可自然直呼其名。
- NPC 对玩家的敬重达到 30 后，可提高其主动切磋意愿；对谨慎性情者，敬重可解除因尚不熟悉造成的推辞。
- 怨结达到 30 后会回避主动接触及求购；达到 55 后可形成明确敌意、拒绝切磋，并提高副本出手倾向。
- 信任目前只积累，不影响交易价格或未配置的行为。
- 行为判断只读取对应人物、对应方向、对应维度；势力态度、区域声望与关系不混算。切磋之外的胜负不因旧综合关系分自动生成关系变化。

## 五、玩家可见信息

玩家角色关系页显示玩家对人物的四个阶段、待月结记事与玩家亲历的往来纪事。关系改变的交互结束时，展示玩家这一方向的关系维度、记入的影响量及“待月结”状态；同月重复而未登记时说明本次未新增记事。即时结算的明确伤害／重大救助展示实际增量。月结后，往来纪事记录实际增量及阶段前后；重复经历的月结增量可以小于交互时登记的基础影响量。

NPC 对玩家、NPC 彼此的内在关系不直接展示；玩家只能根据实际言行、交往回应和社交所得形成认识。不会展示内部当前数值，也不把交往印象当作关系阶段。交互反馈只显示“玩家对 NPC”这一方向；对方的方向不显示数值或阶段。

人物离世时，已有关系记录会收到一条带唯一 ID、月份和死因的离世事实，供后续悲恸设计使用。本期不根据它修改心境或自动触发额外效果。

## 六、存档迁移

正式存档从 v6 升级至 v7。玩家与每个 NPC 分别保存指向其他人物的稀疏关系表、待归纳证据、已处理事件 ID、同类结算次数、交谈月份和离世事实。

v6 的 `player_relationship` 与 `personal_relationships` 数字只保留作读取兼容，不拆成四项、不参与新判定。`player_social_memory.relationship`、`relation_tags` 与 `personal_relationships` 中精确写明的 `friend`／`enemy` 迁入旧关系标记；其他数值不推断为感情。四项数值仍从中性开始。明确行动历史原样保留作为可核验经历，但不从模糊结果文案推断感情或补造新事件。

## 七、验收

- 同一遭遇可只改变受害者对施害者的怨结；反向记录不存在时不自动创建，四维之间不互相换算。
- 交谈需要跨月重复才增加亲近；公平成交只积累信任；完成切磋只积累敬重；伤害／重大救助即时改变对应单向维度。
- 事件 ID 重放不重复结算，同类影响递减且至少为 1；关系没有日历衰减。
- 拒绝、普通不公允交易、切磋落败及未完成切磋不造成错误关系变化；普通交易价格不受关系影响。
- 来往、切磋和怨结分别读取亲近、敬重和怨结；信任没有已配置行为时不施加效果。
- v6 迁移不拆旧分，保留明确朋友／仇敌标记和结构化旧经历；关系证据、结算状态与离世事实可存读档。
- 玩家界面不泄露 NPC 内在关系或原始数值；NPC 关系离世事实不改心境，也不进入案卷裁断证据。
- 交谈、切磋、公平交易等关系互动结束时，玩家可看到自己这一方向的维度、登记影响量及待月结状态；没有新增关系证据时明确说明不变。
- 月结处理后，玩家关系页显示待归纳证据已清理，并在往来纪事记录实际增量和阶段变化；NPC 对玩家的阶段与数值不显示。
