# 成套剑器与独立飞剑完整提案

> 最新模型：[单槽变换与成套同化方向](器物单槽变换与成套同化方向_20261023.md)。用户明确成套剑器可直接看作一个器，御用技能占一个槽，召出后同槽变为在场技能；无需为成套表现先实现多件独立剑联合指挥。相同器合并同化为一套是后续方向。分体受击方式、费用公式与同化细则仍待定。

2026-10-23，设计提案，尚未实施。用户允许成套与独立多剑两种玩法，并明确成套剑器御用通常灵识要求极高。以下成本函数、分体处理和执行细则供评审，不是已定数值或正式技能卡。

## 一、已确认底座

- 装备是局外配置，不收长期维系灵识；御用是器体召出在场，持续占用D；御使是执行一次指令。
- 主动器物技能/借器施法临时占用T，释放结束归还；器体仍在时D不退。化法随原技能生效不另占，常驻修正也不自动视为主动借器。
- 身材主要提供器体等本体属性，性材主要提供角色加成，其他岗位可有真实贡献。器体不等于人物生命或长期耐久，本体锋锐不默认供未召出的普通攻击使用。
- 成套剑器与独立飞剑都可设计，成套不会因一件实例而低灵识控制任意多分体。装备上限、同类装备和全部多器叠加细节尚未批准。
- 多段伤害逐段获得完整固定增伤；惊鸿、抱朴为现有两种器蕴方向，采用百分比激活奖励，数量与比例待标定。

主依据：[本体与施法灵识](器物本体与施法灵识占用修订_20261023.md)、[术语与剑群](装备御用术语与环绕剑群设计_20261023.md)。本案不改变两者已经确认的部分。

## 二、两条路线

| 项目 | 成套剑器 | 独立飞剑组合 |
| --- | --- | --- |
| 物品 | 一个成器实例，内部多个分体 | 多个不同实例 |
| 装备 | 按整套一个实例，具体总装备容量仍待定 | 每件分别占据装备额度 |
| 常驻与器蕴 | 整套一份，不按柄数复制 | 各实例分别提供实际收益与贡献 |
| 召唤与御使 | 有完整模板时可整套召出、整组指挥 | 底座按逐器使用；群体指挥须另有模板 |
| 灵识 | 很高的整组在场控制负担，施法另需T | 各件D求和，联合指令另算T |
| 管理特点 | 参数集中、同源协同 | 来源多、不同效果互补、可分别处置 |

不预设哪条路线绝对强。成套节省实例管理与指令入口，付出高在场控制成本；独立多剑承担装备与装配压力，具有逐件选择的灵活性。独立剑不能因站位环绕便自动获得整组免费齐射。

## 三、器体与材料来源

### 3.1 一体型剑群

多个小剑表现为同一套器物，共享整组器体B。目标入口一项，选中时整组高亮，整组B归零同时崩解。同一群攻对整组只结算一次，不能显示六柄就重复扣六次同一生命池。

适合首个原型，数据和目标交互清楚。它不支持逐柄击落；不得用剑图减少假装已经实现真实分体损失。

### 3.2 分体型成套剑器

仍是一个物品实例，但每柄有独立器体Bᵢ与本场状态。目标列表可先选整组再选具体分体；群攻对每个合法在场分体分别结算，不能再对父组额外扣一次。

各分体的结构与生命来自真实分配：总有效结构按实际体量/连接分给各柄，经公共本体公式形成Bᵢ。不能把整套B完整复制给每柄。材料不增加、结构相同的情况下，增加分体需要分散结构，并支付额外连接/分体加工损耗；新加材料若改善结构，则可以同时增加总生命，不能把“分散”写成所有情况下总生命恒定的硬规则。

分体损失减少可参与指令的剑，不能剩一柄仍打出完整六柄攻击。本场被击落分体不通过收回/重召免费恢复，补剑、修复或重召如以后开放必须有独立规则。剩余状态与来源仍归这一套器物，不拆成可随意转让的六件完整法器。

### 3.3 独立飞剑

每件自己的B、锋锐与能力直接来自各自成器快照，不从一个父组分配。聚合显示只能减少界面噪声，不合并实例或生命。共同攻击时每段仍引用具体出剑实例，不能读取所有剑的锋锐总和或自动取最高值。

一体型、分体型是运行模型候选，不增加玩家预选的细器形或固定配方按钮。当前只选剑大类、通过材料形成结果的方向保留；何种过程量生成分体结构仍需公式标定。

## 四、成套高灵识需求的公式方向

需要把维持多分体与协同控制的成本明确计入D，不能只按总伤害或一个物品实例收费。

同质分体的简化候选：

```text
D套(n) = ceil(n × d + k × n(n−1)/2)
```

d表示一个分体的基础维持负担，k表示分体协同控制成本，二者为公共模板参数且为正。同等单体负担下，数量增长带来额外协同成本，使大型成套剑器具有明显更高的灵识需求；式中成对项是控制复杂度代理，不表示场景真实计算两两距离。

异质分体可推广为各分体控制负担求和，再加按相异性/协同模板计算的成本。真实体量、能力复杂性与控制模式须纳入公开可标定参数；稳定/导通工艺可改善实现效率，但效率要有界，不得通过造诣把大型剑群D压到0。法器具体数值要结合现有低容量角色测试，不提高角色上限来掩盖费用过高，也不承诺普通云息即能完整御用大型剑群。

施法T独立计算：

```text
T指令 = ceil(本次指令基础负担
             + 参与分体的操作负担
             + 本次目标/协同模式的附加负担)
```

T不等于再次收整份D，也不是按场上所有无关剑计费；只对本次实际参与的来源与技能模式结算。同一套普通御使、复杂联合攻击可以有不同T，但完整费用和目标需在技能模板中确定。

因此，“能召出来”与“召出后还能施法”是两次不同容量检查。界面同时展示D、各指令T与组合峰值；不要求所有配置必留某一固定比例空余灵识，由玩家决定是否有空间发动所需招式。

## 五、在场数量变化与容量释放

一体型整组D持续保留，整组离场再释放；剩余器体降低不逐点退灵识。

分体型建议按当前实际在场分体集合重算D；击落一柄释放新旧D的差额，余下协同负担保留。不能每掉一柄都退还完整原始整套D。最后一柄离场时归零。当前能力是否仍可执行由剩余分体与模板资格判断，不将已损失的潜力转移给剩余剑来免费增强单柄。

独立剑离场释放它自身的D，其他实例保持原样。若联合指令使用了不稳定的在场组合，不隐式合并出一份新的低D预算。

实际开始施法时记录本次参与者和T。释放过程中参与者损失，不把当次T反复缩小再重新借用；释放结束按实际提交量统一退还一次。器体持续占用释放与施法临时占用退还采用不同来源记录，避免一柄剑击落时退错别的容量。

## 六、指令、队列与行动

剑不获得独立角色行动条。环绕是待命，不自动攻击或挡伤；伤害、护持、拦截必须来自明确审核的主动/应对/触发模板。此案只规划能力接口，不创建费用未定的卡。

建议首个成套原型只做召出→御使攻击闭环：

1. 御器技能由玩家主动装入技能栏；一个同源剑群指令入口占一个技能位置，其他独立获授技能仍各自占位。
2. 首次排队锁定召唤分支；成功建立运行态和D，召唤本身不默认攻击。召唤施法T若有，按模板另外检查，不能只校验最终D而漏掉释放期间峰值。
3. 在场后的御使锁定对应意图，执行前检查来源、在场者、目标、临时容量与原有体力/法力、次数/冷却。
4. 分体损失后，根据模板要求验证参与数量；仍符合则按实际参与者形成费用与效果，不符合则沿失败规则跳过，不扣尚未提交费用，不补行动，不自动改成召唤。
5. 效果结束归还本次T；D继续保留到相应器体离场。

初版不做任意选择少召一部分来绕开整套高需求；子集召出须以后通过明确模板另行设计。御使可以按模板使用部分在场剑，但其他剑仍在场，D不会因为本次未出手就自动降低。

多段次数来自明确技能模板与实际参与者，不来自剑图数量。整体基础效力先分配到合法段，每段再加完整固定增伤。护盾等触发按自身事件计数，不能把“逐段增伤”扩展成所有收益逐段重复领取。

借器直施若不要求器体在场，可以只收T；没有在场本体则不自动借用本体锋锐或器体承伤。化法无需T，但若原技能本身就是主动借器能力，仍照收原技能的T，不因它同时绑定化法而免除。

## 七、一次完整例子

纯算术展示：人物上限12，六分体成套剑器D=8，御使T=3；这些数字不是成本函数的定案结果。

装备后：不占灵识，合法角色属性与器蕴贡献生效。召出成功后占8、余4。御使期间占11、余1；释放结束归还3，恢复占8。此时使用无需额外灵识的普通化法技能不新增占用；使用临时需要5的主动借器技能则因余量不足不能开始。

若采用分体型，损失一柄后仅按公共D函数释放差额，后续御使由剩余参与者决定；不能提前写成固定“退还8/6”，也不自动给剩余五柄复制第六柄的基础伤害。整套完全离场后释放全部D。

无论六柄全在还是损失一柄，装备来源仍是一件器物，不能因此多算或逐柄扣掉器蕴贡献。崩解是否撤销独立装备收益仍属于完整装备方案的待确认项，不能由分体掉落偷定。

## 八、炼制与器物信息

身材形成的总结构、体量与有效连接，需在整组或各分体之间真实分配，主要决定器体与本体强度。质材提供共同根性与支撑；性材主要提供角色加成和能力潜力；和材的导通/聚集/留存等按现有公共矩阵形成工艺条件。不能把某一种材料名写成六剑配方。

后续分体公式需共同求出：实际可形成数量、每柄结构与器体、协同连接是否实现、整组在场控制负担、合法技能表达。数量不能只按总材料份数向上取整；也不能把剩余根性直接转换成额外小剑。若要新增分体工艺字段，应先修订材料档案规范，不装作已有数据。

材料到器体的变化与D/T系数均待离线测试；先评估“少柄坚固、高单段”与“多柄较薄、多段”的相同预算结果。不得预设数量越多总输出、总生命和器蕴必定全部增加。

详情建议分别显示：

- 本体：一体/分体运行模型、分体数、整组或逐柄器体、锋锐，标明在场适用。
- 角色收益：基础固定属性、常驻效能、集中化法、获授技能与本件器蕴贡献。
- 灵识：整组D、每项主动指令T、释放期间需求；分体型可展开各存活状态。

画面上小剑环绕、出击、返回不引入方位格子或背击机制。共享器体一个目标入口；独立或分体型允许折叠列表再选具体来源，隐藏列表不改变真实候选数。

## 九、后续实施与未决项

先统一物品入包与本体/角色收益数据，建立D/T独立账本，再用单件单体测试生命周期；随后一体型剑群、真实分体、独立多器与联合指令逐步验证。每个正式技能新增或改动前执行项目卡牌流程，不能以此稿绕过费用/目标确认。

重点验收：D/T同时存在、化法不新增T、施法完只退T、失败/中断/死亡正确清理；分体数量不复制生命和器蕴；群攻不重复扣父组；丢失参与者不免费补段或转召唤；多段固定增伤一致；实例持有、存档与装备上限不因画面分体绕过。

当前待确认或标定：一体/分体的首轮范围、具体N/B/D/T公式系数、正式技能费用与目标、群攻固定增伤口径、零灵识凡器本体使用、崩解后独立装备收益范围。本文未修改代码或发放样本。
