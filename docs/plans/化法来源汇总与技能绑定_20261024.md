# 化法来源汇总与技能绑定

> 2026-10-24 用户确认实施。覆盖旧的“学会后自动替换技能库中所有匹配招式”方式；各来源原有的效果、数值、费用、触发及兼容限制继续有效。

## 入口与展示

角色面板的技能页保留“技能库／造诣图谱”两个标签，不单开化法子页。技能库、十个术法槽和右侧化法栏同屏显示；右栏汇集真实来源，每项显示化法名、来源及绑定状态。已绑定项前显示勾；点击条目查看适用范围、化法追加、目标术法槽与生效／暂停状态。

化法来源详情只展示“适用范围”和“化法追加”。适用范围直接列技能名；多个技能以顿号列名，不写绑定资格或装配状态解释。只有运行时确实支持关键词匹配的来源，才可写“带闪避关键词的技能”等范围。其他技能字段与基础效果不在来源详情重复；目标技能自身的信息栏仍完整显示这些字段与结算效果。追加部分确需计算公式时才列公式。

长按右栏化法项约 0.34 秒后拖向术法槽。拖拽期间，符合该化法现有适用条件的已装配技能槽高亮，其余技能槽变暗；只有高亮槽接受放置，放下即保存绑定，不再要求二次确认。拖动化法前的小幅移动会取消长按识别，以免与滚动操作冲突。已绑定化法可从详情中的“解除绑定”解除；再次拖向其他高亮槽会改绑。

仅展示真实数据，不因策划历史表写每卷一项就补造缺失配置。秘籍读取已学卷章和现有化法配置；当前主修可用，辅修须启用该卷化法分支；其他已学来源显示未启用原因。器物读取玩家持有的实例，只有已装备且可用的来源可绑定；未装备来源可查阅但不能绑定生效。不可用来源及暂无合法槽位的原因写在右栏，不能拖拽。

受化法的技能库条目和术法槽显示“化”标记；同一技能承接多项化法时显示数量。技能详情明确列出化法来源与各自生效状态，实际效果仍按同一份解析后技能副本展示。来源、条件和绑定状态常驻可见；长文在右栏正文滚动，不给悬停信息卡加滚动条。

## 绑定与结算

- 每项秘籍化法选择一个技能。稳定来源标识由秘籍路径、卷章标识和配置序号组成，目标记录原招式身份，不记录槽位序号。
- 候选必须已装配在十个技能位置中，且满足来源原有匹配条件；秘籍的公共基础／本经技能范围不扩大。技能库内已学但未装配的招式不可选。
- 同一件新成器的化法集中选择一个对象，候选须满足各项共同适用条件；不拆成多个不同目标。原有器物效果算子仍负责追加内容，不新增炼制或收益规则。
- 技能调整位置后绑定跟随技能。卸下技能、切换秘籍或辅修分支、卸下器物及来源失效时暂停生效；保留原选择供重新满足条件时恢复，不自动寻找替代对象。
- 多项已有兼容化法仍按原合并顺序作用；旧内炼器物沿用同一技能不得绑定第二件内炼器物的限制。不新增费用、资源或灵识占用。
- 技能库保留原始招式，运行时只在解析已装配技能时创建化法副本；不修改共享资源。战斗快照使用确认后生成的完整副本，悬停及实际结算读取同一版本。

## 来源接入范围

共用来源项提供稳定标识、来源名称、适用范围、可用原因、候选判定及副本应用方法。

1. 当前启用的秘籍及真实卷章化法配置。
2. 已有器物实例的内炼化法；沿用其已明确保存的手动绑定字段。
3. 新成器固定快照中的化法效果组；可以读取持有快照。正式装备资格仍沿用器物系统，本页不补开尚未接入的装备／御用链路。单器独立对练继续使用自己的配置页。

无实际数据的其他来源不生成占位化法。后续来源使用同一来源项协议接入，不从名字或文案猜测效果。

## 存档与旧档

`HumanData.skill_rewrite_bindings` 保存秘籍／新成器来源到原技能标识的稀疏字典，旧内炼实例保存字段继续兼容。该字段为可选的追加导出字段，旧档缺失时为空，不提升存档版本、不自动推断玩家选择。

旧技能槽中若保存化法资源路径，解析回原招式身份，保留技能装配；此前自动匹配不迁移成已确认化法。停用秘籍及停用技能仍遵守原开放范围，不重新授予归档招式。
