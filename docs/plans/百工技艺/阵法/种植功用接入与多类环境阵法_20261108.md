## 一 功用由基质材料发挥

基质是向原有田地加入其他实际材料，由材料的性质与功用参与培育。不是单纯的筛选标签，也不是改成预设土壤套餐。

作用关系为：

    实际材料 → 加入田地形成基质 → 材料功用按培育规则发挥
        → 影响对应条件或培护结果 → 对照灵草需求与持续长势

沿用[物品词缀主案](../../物品与装备/物品词缀系统设计.md)和 MaterialCraftData.utilities／MaterialUtilityGrade 的十二项：固、聚、通、化、引、破、护、镇、生、明、藏、行。材料最多四种功用，不另建保水、催生等基础词典。

单项数据 1 为九品，9 为一品，不分下中上；与物品总品阶 grade_value 分开。不修改现有材料的功用或品级以适配种植，不把件数、品级或功用数量相加为培育总分。

具体材料的培育表现仍需结合五行、质地、相性、加入与处理方式、作用条件及灵草定义。尚未定义的效果不提前改变温度、供水、灵力、成长速度或采收时间。

## 二 材料功用的培育用途候选

以下仅说明基质可以如何使用现有功用，不是已配置的效果或阵法设计。

| 功用 | 现有语义 | 基质培育用途候选 |
| --- | --- | --- |
| 固 | 稳定、承载 | 保持田层或附着载体结构 |
| 聚 | 汇集、蓄积 | 汇集地块所需的环境灵力，来源另定 |
| 通 | 连通、导流 | 疏导已有水路或连通灵路 |
| 化 | 转换、炼化 | 处理与转化实际投入的培育材料 |
| 引 | 牵引、导向 | 将已有供给导向目标区域或根系 |
| 破 | 穿透、瓦解 | 处理明确的结壳、阻塞等对象 |
| 护 | 保护、隔绝 | 隔绝已定义的外界扰动 |
| 镇 | 压制、固定 | 抑制已定义的不稳定因素 |
| 生 | 生长、修复 | 在适生约束下养根与修复 |
| 明 | 显化、辨识 | 观测与辨识灵草状态 |
| 藏 | 封存、收敛 | 封存或缓释已有供给 |
| 行 | 运行、位移 | 维持已定义的循环与输送 |

每项实际作用还需明确适用材料、加入方法、适用物种／阶段、条件、用量、周期、消耗、叠加与结束方式；上述语义不能替代缺水、必要岩面或其他独立需求。

## 三 阵法只留独立入口

田地概况正文保留“田地阵法”一行，与基质操作并列，通过“查看阵法”打开当前田地的独立入口，顶栏不再放阵法。未接入时只提示“阵法系统待接入”，不列具体阵式、不画阵位、不提供布阵、购买、费用或阵法功用配置。

浏览器原型仅提供一个打开入口，向外部阵法系统传递当前田地身份。没有自行设计阵法的数据结构、效果换算、供能、维持、返回协议或成长加成。

[阵法底层主案](阵法系统设计.md)与[阵盘接入专题](阵盘制作与招式盘接入规划_20261107.md)继续各自负责阵法。种植的基质功用清单中没有阵法条目。后续确需读取阵法影响时，由独立系统及正式培育规则提供已经生效的地块结果，不把材料功用映射搬过去，不直接套用战斗信号或阵源数值。

## 五 真实资料与实现范围

| 材料 | 真实功用与单项品级 | 范围 |
| --- | --- | --- |
| 紫砂灵土 | 藏九品 | 名称不自动定义培育效果 |
| 泥脉石团 | 镇九品 | 镇不直接等于万能稳土 |
| 兽骨 | 固九品、生九品 | 不等同完整遗骸 |
| 地脉焰炭 | 聚八品、通九品 | 保留炼器燃料分类；可选不代表已定入田资格 |

原型从行囊演示输入中先过滤“可作为基质且剩余持有量大于零”，再显示列表。资格不由材料名称、分类或带有功用直接推导；正式白名单及判定规则仍待定，样稿使用单独的演示资格字段验证筛选，不能当成已批准物品规则。

默认一次加入一件，可在底部调整数量；拖拽选中项使用该数量，拖拽其他材料默认一件。拖入接收区或点击“加入”立即更新本田加入记录与演示剩余量，同材合并，不再保存方案或二次确认；真实拖拽取消、无效来源、超量和重复投递均不能添加。耗尽物品退出可用列表，切田共享同一演示行囊剩余量，各田已加记录独立。详情与来源按需打开，没有常驻大详情区。

库存、三块田、定性需求及一号田的改造后环境／阶段／植株状况均为隔离界面示例；共同初始条件保持。加入记录只在浏览器内存中保存，不真实扣料或写角色／存档，也不自动改变情境环境与长势。具体培育作用、费用、周期、耐受与损伤参数未定，不计算虚构增益或成熟时间；未接正式游戏的连续生长。

同批地块同起点，持续不适先长慢、停长，持续严重不适才受损或枯死的方向保持。查看、切页、切田、预览不推进游戏时间、不消耗真实资源、不清空不适或损伤历史。
