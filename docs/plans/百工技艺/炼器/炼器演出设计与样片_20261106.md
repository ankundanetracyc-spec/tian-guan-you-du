# 炼器演出设计与样片

2026-11-06。当前为可运行的独立样片，供评画风和节奏，尚未接入正式开炼。炼丹的新瓶及演出时隐藏界面已经实际接入，见[炼丹当前画面](../../../美术规范/炼丹演出节奏优化_20261106/README.md)。

当前修订：按用户继续询问炼器的语境，同步柔化材料融入。材料轻抬、缓起牵入，在器坯不同位置化开；器坯以灰褐薄洗渐聚并延展，实际器形从中段向两端凝出，与坯影交叠后收色定住。仍为独立样片，不改正式事务。

成器本色修正：此前成形材质将纹理颜色重复相乘，造成成器近黑。现修正渲染乘色，冷却完成后恢复物品图本色，保留节点着色与透明度；不修改现用素材。三种剑形的原图／最终材质GPU对照共6组，RGBA最大差均为0；跳过与重播7项继续通过。[最新动图与对比](../../../美术规范/炼器演出样片_20261106/README.md)。

## 依据与边界

沿用[器物系统现行主案](../../物品与装备/器物系统现行主案_20261023.md)、[炼器地点与正式事务](炼器炼丹游戏内接入_20261025.md)、[投料界面](../../界面与美术/炼器投料配伍与灵识界面修订_20261024.md)。现阶段炼器选择器类及身／质／性／和材，不预选最终细器形，无燃料；实际成器、属性和器阶由既有结果决定。

本方案只增加结算后的揭晓表现。下面的“炼合、显形、冷却”是画面阶段，不是新增工艺选项、材料费用、属性、成功率或输入判定。暂不增加锤击小游戏、手动控火、额外淬火剂或固定符文。正式炼器仍是一次预检与提交，成功成器按原事务入包；不改成炼丹的待领取流程。

## 构图与节奏

沿用当前工坊背景和案台。进入演出后收起投料页、阴阳轴、用度与顶部操作栏，视觉集中在案台中央，保留跳过。右侧背景中的炉火保留，不复制炼丹的旋涡和出丹。台面附近少量暖褐碎点、灰墨与材色流痕说明材料正在聚合，不铺屏幕光效。全段约6.8秒。

| 时间 | 动作 | 画面要点 |
| --- | --- | --- |
| 0—0.4秒 | 留出案台 | 材料图像短暂停留，给玩家一个辨认投入的起点；不显示成品、评分或预测。 |
| 0.4—2.4秒 | 投料聚拢 | 材料轻抬后沿缓起弧线牵入器坯的不同位置，稍有先后；轮廓逐渐化为原素材颜色的细痕与碎屑。小幅牵引，保留金属炼合观感。 |
| 1.15—4.6秒 | 材料炼合 | 灰褐薄洗渐聚成坯影，再沿器身方向延展，与材料化开及显形交叠；轮廓有柔和干湿边。没有具体温度或锤击次数。 |
| 2.6—4.65秒 | 器形渐显 | 使用本次真实成器的现用物品图，从中段向剑尖、剑柄两侧凝出，柔边逐渐稳定并与坯影衔接；剑形不硬编码为某一结果。 |
| 4.65—5.8秒 | 收敛冷却 | 暖褐色退回素材本色，流痕与碎点消散，完整轮廓稳定；不用光柱、雷电或品质色爆闪。 |
| 5.7—6.8秒 | 抬起定器 | 成品缓缓离开台面、轻微转正，在视线中心停住；完全定住后才显示真实名称和器阶。 |

正式接入时，定器结束后打开既有成器详情，原本体、装备效果、技能与器蕴说明继续复用统一物品信息。极短的中途跳过应直接打开同一已提交实例的详情，不重新求解或发放。实际失败只显示既有失败结果，不制造假成品或新增炸炉概率。
