# 炼器成器物品展示

2026-10-22，当前界面实施范围。用户澄清：先保证炼成物品能正常显示信息栏、图标，器物槽尚未设计。本篇覆盖此前单器试炼方案的工坊入口安排，不改变已确认的锋锐规则或炼制公式。

## 当前交付

- 器物册按实例列出成器，提供图标、名称、品阶、锋锐和七档阴阳；相同形态仍保留不同实例各自的数据。
- 悬停条目显示现有共用纸墨信息栏，包含实际图标、名称、大类、品阶、阴阳、本体属性、基础加成，以及法器已有的其他能力、御器信息和器蕴贡献。未配置的内容如实标明，不凭展示补发能力。
- 成器详情增加器物图示与身份栏；详情和悬停共用展示适配器，读取已成器快照，不重新结算、不扣料、不改变属性。能力详情、炼制记录保留分页。
- 使用已有水墨剑素材，按生成形态选修长、宽展或厚脊外观。外观不赋予属性，不参与材料配方或评阶。未另加器物五行字段。
- 正常成器页撤下“装备此器/进入独立对练”。没有新增器物槽、装备操作、技能绑定或正式行囊/存档写入。此前对练后端仅保留开发测试场景，不再作为工坊流程的一环。

## 信息边界

展示修订：锋锐只列数值，撤下逐器重复的物防忽略解释。“其他能力”更名为“器物效能”。同一件器的所有化法条目集中为“化法”区块，每项直接写适用范围与化法追加，不重复目标技能的其他字段或绑定说明。器物信息、能力详情和悬停共用该分组。此次只调整展示，正式绑定与器物槽规则不在本次实现范围。

只在成器后展示实际属性，炼前不显示预测。效果描述表示器物形成的能力，不宣称当前角色已获得装备收益；界面明确标注“试炼成器 · 仅供查看，装备功能暂未开放”。凡器不展示法器专属能力。耐久、器蕴规则、法器小档和正式装备布局未补设数值。

## 验收

验收入口为炼器场景的 `--audit-process-forging`。在原公式/库存/场景检查之外，覆盖凡器和法器图标、实例信息一致、共用悬停显示与切换、关闭清理、反复查看不重复扣料，以及正常界面无装备/对练入口。截图和运行结果见[物品展示验收](../../../美术规范/炼器物品展示_20261022/README.md)。
