# 炼成剑通用装备与战斗适配

> **2026-11-04战斗修复，当前覆盖**：正式装备物伤比例不再被空试器快照清零；按2026-10-27器物主案，普通手持、借器及御使的物理剑招均须匹配实际已装备剑的实例来源，锋锐由预览和实算共用入口追加一次。旧比例及条件词条保持快照原值，不在本轮迁移或平衡。完整流程、空间行囊回归及资源生命周期处理见[本轮验收](炼器至战斗接入修复与验收_20261104.md)。

用户要求适配所有炼出的剑，而非清和剑专用代码；化法由另一个对话适配。本篇覆盖此前“新器物装备/御用尚未开放”的对应状态说明。

## 适用和来源

所有合法schema3、Category=剑的成器快照均可作为武器装备，不按名称、投料或器形白名单。正式持有实例可从行囊和装备页武器槽装配。正式常规武器与生成剑共享一个武器位，互相替换；按实例ID保存，重复名称通过ID尾号区分。换剑/卸下撤销原实例的御用与直施技能来源，空技能位置不前移，不自动挤掉其他技能。

独立炼器试炼的成器继续只在该会话内存在，进入对练时使用同一适配器；不会把试炼免费材料产物注入正式旅程。宗门兑换是正式来源；正式炼制扣料入包事务仍是另一项工作。

装备不占灵识，凡器也能装备；没有直施/御器效果的器物不凭空获得主动技能。器蕴没有在本轮激活。化法绑定、选择及与秘籍叠加不在本轮改写。

## 当前效果适配

| 快照来源 | 执行 |
| --- | --- |
| base/physical_defense | 角色固定物防，重算后追加，卸下撤销 |
| base/physical_damage_percent | 原有快照的物伤比例，保持原值，不伪装固定增伤 |
| keyword/physical_damage_percent | 仅带有“剑”关键词的技能物理伤害应用原比例 |
| trigger/shield_flat | 剑关键词原始物理攻击对生灵实际造成伤害后，自身获得护盾；同次执行首次触发，不对器体/衍生段触发 |
| direct/physical_damage_base、shield_flat | 一项直施技能，读取本器分得的伤害与自身护盾值 |
| summon/physical_damage_base、shield_flat | 一个御用/御使同槽入口，读取本器分得的伤害与自身护盾值 |
| binding | 保留快照与外部化法接口，由专门对话继续适配 |

比例快照仍是旧公式，不把百分号直接改成固定点数。后续公式产生新AtomId时应增加一次通用处理，不穷举材料或逐剑特判。

直施与御用均存在时可分别装槽，来源仍指向同一器物；直施来源键后缀`#direct`区别同实例的御用入口，卸下同时撤销两者。御用本身仍只占一个技能位，成功后同槽预览切换御使。没有正数伤害/护盾则不生成空主动能力。

## 费用、目标及生命周期

- 御用体力1、法力0，仅召出器体；持续灵识直接取本剑SpiritRequired，器体取BodyMaximum。无额外召出临时费用。
- 直施/御使体力1、法力1，施法期间临时灵识1，无额外次数或冷却。伤害/护盾直接取对应carrier实际Value的合计，不统一强加10伤害。
- 有伤害则单个敌方合法目标；只有护盾则自身；兼有时伤害作用敌方，护盾作用自身。采用现有物理伤害、会心、应对、目标与队列规则。
- 剑关键词已存在，生成的剑器主动技能标注剑；不把近身当关键词，不增加新五行。没有返费、抽牌、额外行动或资源生成。
- 手持、直施及御使的物理剑招，在实际引用已装备本剑时忽略本剑锋锐对应的物防点数；不要求普通手持或直施先召出。拳脚、无用器来源、其他器物来源、非物理及衍生伤害不享受，不能仅凭剑关键词借用锋锐。
- 在场D与临时T共用真实占用池；初始化保留快照中的其他占用。实际施法前检查峰值，成功支付时登记T，执行完成释放T；主人倒下及结束/重建战斗也清理，重复释放不扣其他来源。
- 沿用现有队列预演、确认锁意图、失败不转召出、器体受击/崩解/离场与战后报告，不改长期耐久。

运行传输复用既有外祭在场标志，但只在战斗副本设置；永久快照没有恢复内炼/外祭互斥，也不把化法和召出做成二选一。
