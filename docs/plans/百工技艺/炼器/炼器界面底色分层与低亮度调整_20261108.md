# 炼器界面底色分层与低亮度调整

2026-11-08。用户反馈当前炼器界面大量白／乳白背景难以区分且晃眼，附投料区截图。本篇覆盖此页此前“颜色也完全不变”的展示约定，调整范围仅为背景明暗和控件层次，继续沿用原字体、字号、纹理、边框、布局与交互。

## 当前实现

| 用途 | 表现 | 保留项 |
| --- | --- | --- |
| 页眉、投料、用度、阴阳等主面板 | 压低亮度的灰米色纸面 | 原山纹、纸纹、九宫格、角线及占屏比例 |
| 已投入的材料块 | 克制灰青底，区别于主面板 | 原图标、材名、库存和份数位置 |
| 普通按钮、未选中页签 | 灰褐纸底，悬停略向灰青偏移，按下略沉 | 原尺寸、命中、启用／禁用与文字 |
| 数量输入框 | 灰棕底，沿用原内凹与边距 | 原数字、字号、增减与确认规则 |
| 已选中页签、开炼主按钮 | 保留原深绿材质 | 选中语义及可执行条件 |
| 滚动滑块 | 深灰绿，提高与主面板的区分 | 原宽度、范围和拖动操作 |

通过本页专用`ForgingSurfacePalette`设置背景StyleBox乘色，并复制当前页面Theme中的输入框、弹窗与滑块样式。不修改控件整体Modulate，避免字和物品跟着变暗；不覆盖共享字体或原PNG，也不把本次颜色变化扩散到静室、行囊、善功堂等系统。

参数是原材质的乘色，最终像素仍受原纹理、透明度影响：主面板`#D0D1C5`，材料块`#B8CBBD`，普通控件`#C3C4B7`，数量框`#C2C9DD`。数量框原底偏暖，偏冷乘色用于中和，不表示最终显示蓝色。

## 范围与验收

已用于当前`ProcessForgingScene`的原生页面及其弹窗；中央炉火仍沿上轮独立只读演出，不借换色接入人物事务、火源类型或新费用。成器公式、材料、灵识和用度保持。

[实际效果、取样与检查](../../../美术规范/炼器底色分层_20261108/README.md)。编译0警告0错误，原炼器工作区15项和原生演出6项通过。原字体与共用样式文件哈希保持，三个标题共637个实心墨色像素在原位置保持；不再以整块背景RGB与白底一致作为本轮验收条件。

## 同日后续：收减常驻说明

用户指出“每岗每材1—8份 · 全炉由灵识限制”这类文字多余。已删除该底栏、重复的剑类／岗位提示、四组材料的常驻解释、默认“先配材料”及载入样方提醒、无缺项时的“投料齐备”提示。份数范围放入数量框悬停，现有“炼器说明”继续解释完整规则；资源不足、岗位未开放、缺少必需材料及真实结算通知保留。

左侧页签上移至原副标题位置，材料列表从192起改为112起，底部保持700，增加80设计单位的可用高度；其他控件、底色、字体和开炼条件保持。
