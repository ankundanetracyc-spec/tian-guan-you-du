# 炼器装备对练接入

用户授权自行设计测试数值。以器物系统现行主案为准，不恢复旧内炼/外祭互斥。

## 本轮已接入

工坊成器详情增加“装备试用 · 进入对练”，使用该成器的唯一实例建立隔离对练。现有试用装配支持装备/卸下后重开，以未装备人物为基线重新计算，不向正式角色写入。

化法界面统一一个技能选择器，只有该技能满足条件的修正生效。撤下普通攻击勾选借用本体锋锐的旧选项。基础物防及旧快照物伤百分比沿现存公式读取，并在状态栏明确标为旧公式；尚未完成固定值生成，不把旧值直接改单位。条件词条、器蕴、御用未启用。

不改普通技能资源、费用、目标与关键词；不增加额外行动或资源生成。返回保留当前工坊会话与成器详情。退出工坊不会将测试物品转换成正式产出。

## 御用数值设计（待实现）

首个剑器测试模板：召出体力1、法力0，在场持续占灵识2；御使体力1、法力1、临时占灵识1。召出仅建立器体，不造成伤害；召出不另收临时占用。御使峰值为其他占用＋2＋1，临时部分在执行结束或中止时归还。在场容量不足不能召出，施法峰值不足不能御使，失败不自动改成召出。

器体上限取成器快照已有本体量，不覆盖为统一生命值。首个接口验证的御使基础物理伤害取10；剑自身锋锐按1点忽略1点物防，仅用于明确来自在场剑器的攻击，不能附加到普通技能。无御使限次与冷却。此模板仅用于独立测试，不把所有成器强加同样主动技能，不作为正式材料到主动技能的生成公式。

后续依次补齐御用模板、同槽状态变换、D/T生命周期、真实材料对应的能力生成，以及固定值词条与器蕴。此处待实现数值不代表当前对练已有对应效果。
