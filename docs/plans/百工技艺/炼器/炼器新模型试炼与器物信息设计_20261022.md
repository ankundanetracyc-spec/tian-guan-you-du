## 一、操作闭环与范围

剑类只选大类，不选剑形、方向、功用或收益开关。选择岗位材料与整数份数，检查工艺条件，开炼后才显示成品。首页试演和百工法宝页进入新模型；旧模型场景保留归档。

每次进入有独立材料库存，每种30份。非法操作不扣料；合法试炼即使供热或有效功用不足也会消耗本页投入，记录失败及试炼用时。不会扣人物精力、推进历法、授予真实装备或写入正式存档。重复提交同一草稿版本只结算一次，改料或重新载入才建立新提交。

投料一级分组仍为身、质、性、和、燃。用户确认身材内可以设置小岗位；主体、承接、辅体都属于身材内部，不与身材并列。界面使用身材组标题和内嵌区域，选材与炼制记录以“身材／主体”等完整路径说明归属。

辅体表示补充器体结构的材料位。内部工艺键暂保留旧名“复合身材”以兼容已有候选参数和器物快照，所有玩家可见名称统一为“辅体”；本次只改名称，不改变材料适用或数值。

剑类身材内部候选位置：主体1、承接1、辅体1；其余分组为质材1、性材最多2、和材最多3、燃料1。各位每种1—8份，同岗同材合并后最多8份，全炉最多32份。造诣8开放基础制作；20开放第二和材及地脉焰炭；32开放第二性材和辅体；50开放第三和材。开放的是复杂加工位置，不是指定器型。该表只适用剑，甲、鼎须独立设计。本次确认的是分组层级；具体加工职责、数量及材料门槛继续作为现有候选，不因调整层级而改动结算。

## 二、可追溯的候选计算

加工档案逐物品声明岗位、难度、供热、保留、成材体量、延展、厚度和根性。没有档案不能加工，不由“金、致密”直接推断。首批13种已有材料，不新增材料资源。赤纹燧石与灵泉露分别配置火、水的和材加工档案，使首批五行通关能实际试验；这不是对材料公共词缀的改写。

实际份数用于库存与供热。有效量表（0—8份）：0、1、1.8、2.4、2.9、3.3、3.6、3.8、4。同岗同材先合并；重复槽不能规避递减。掌握率=0.8+0.2×clamp((造诣−材料难度)/40,0,1)。有效保留=档案保留率×掌握率。

只有主体及辅体产生剑身体量；承接不复制成剑刃。各身体量=有效量×档案体量×有效保留。体量加权得到长宽比λ和厚宽比τ，再按宽=cbrt(V/(λτ))、长=λ宽、厚=τ宽输出规范化尺寸；不是厘米。名称仅描述实际形态，不追加倍率。结构共同容量=体量×6。

性材的供给=有效量×8×最高功用品级权重×有效保留。权重从九品到一品为1、1.6、2.5、4、6.4、10.2、16.3、26.1、41.8。每个来源按自身各功用的权重比例分摊总供给，不复制。当前只有破、固有候选成品表达模板；其他来源有记账但不临时编造战斗效果。

质材提供一份共用根性预算=有效量×档案Root×有效保留。性材送达受五行和局部阴阳影响，再与根性预算、结构共同容量取小值，按各候选供给比例分配。按可实现量排序，达到3点者最多留两项，等值按稳定功用ID；落选量不赠给另一项。

五行以质材→性材为方向：同行1、根生性1、性生根0.9、相克0.6。克关系若能沿木火土金水生序逐个支付中间元素和材单位，则送达0.9。通关单位从和材真实单位中移除，不能再支付收益通路；无行材料不能替代中间五行。相克不简单判全炉失败。局部阴阳差≥4时该来源再乘0.75，不被整炉平均掩盖。

阴阳解码优先读相性文字标签（完整七档），无标签则按旧字段正负解码为阳/阴/和（±2/0），避免把旧1误读成偏阳。燃料排除；输入与成品分别计算，成品按成材、根性、已采用性材、实际消耗和材的保留权重形成七档。极阴极阳有效，不强制归和。

和材先支付通关，余下每个真实单位按其通/聚/藏功用权重的累计欠额分配唯一工艺身份；不按三个全额重复使用。每对藏+通形成一条御器通路（体量至少7）；余通支持化法，余聚支持直施，基础留存支持常驻。路线权重为实际分配的单位/对数，常驻固定1。每项功用按这些权重分配自己的效力池，低于1.5的表达不产出，废弃份额不再转移；器体不达标时已支付的御器配额仍记录未利用。每项功用的路线占用总和不超过自身有效池，全器不超过结构/根性预算。

造诣只改善实际保留并开放复杂位置；供热不足不由造诣免除。供热需求=各非燃料实际份数×(档案Heat+1)，燃料按实际份数×FuelHeat支付，多烧不加属性。工时=max(1,ceil(非燃料份数/3))时辰，试炼精力=工时×2；均为候选试炼用度。

## 三、器本身应包含的信息

更完整的属性目录、品质/耐久提案、装备收益与展示顺序见[器物属性与装备收益规划](../../物品与装备/器物属性与装备收益规划_20261022.md)。本节仍记录当前试炼字段，不以规划中的预留能力冒充已实现。

| 信息层 | 字段与规则 | 当前落地 |
| --- | --- | --- |
| 身份 | 实例ID、显示名、大类、结构版本、规则版本、参数及材料快照摘要 | 独立试炼实例，不复用旧单功用内炼/外祭Resource |
| 形态 | 连续体量、长宽厚、长宽比、厚宽比；派生形态描述 | 同材料结果可复算；名称不参与结算 |
| 性相 | 五行保留量分布、主行/并行、七档阴阳及连续值 | 无行保留为空，不冒充金行 |
| 效果清单 | 直接保存具体收益与效果ID，不设成器功用列表 | 现有试炼仍按破/固分组，待重构；来源供给与损耗转入炼制记录 |
| 常驻属性 | 真实属性键、单位、数值、来源；装备后自动汇总 | 破→physical_damage_percent；固→physical_defense；仅说明，不给角色加值 |
| 化法 | 来源实例、功用、有效量、修正类型、合格技能条件、绑定槽 | 破：攻伐、气血、含单体物理伤害；固：守御、含应对化解。近身只作出手方式。绑定不额外占主动技能槽；当前描述不创建卡 |
| 主动技能 | 稳定效果ID、实际效果、目标/费用/冷却模板引用、来源实例 | 先记录直施/御器的效力；战斗模板的费用、目标等未完成新案统一，明确未装配，不编造可用卡 |
| 召出状态 | 器体上限、在场灵识需求；战斗实际剩余器体另存运行态 | 仅有御器表达时生成候选：器体ceil(V×2)、灵识ceil(V/6)，不假装其他法宝都可召出 |
| 器蕴 | 有效功用对应蕴种、层数、来源；套系奖励单独版本化 | 每项有效功用≥3贡献1层，≥12贡献2层；只显示器蕴层，不编造未统一的套系奖励 |
| 炼制记录 | 投入岗位/份数、材料静态快照、造诣、热量、损耗、通关/通路分配、落选原因 | 可复核、序列化往返，不反查未来已改变的材料资源 |
| 生命周期 | 获得/装备/绑定/耐久/修复/归属/交易/销毁 | 本阶段未启用，不能用器体充当耐久，也不能给“凡器”假默认品阶 |

候选效果转换：常驻破=floor(分配效力×0.5)%物理伤害加成，固=floor(效力×0.5)物防；化法破=效力×1%本次物防忽略（上限35%），固=floor(效力×0.5)实际应对追加化解；直施破=floor(效力×1.2)基础物伤，固=floor(效力×1.2)自身护盾；御使破/固分别floor(效力)基础物伤/自身护盾。四种表达都使用同一功用池，不能把每种都写成满额。只生成值大于0的说明，截断损失保留记录。

主动技能记录仍是设计数据，不是可释放的战斗卡。正式接入前需按卡牌流程统一费用、目标、次数、冷却、化法绑定与秘籍叠加，再以新实例ID适配队列/器体。当前不声称原双剑战斗样本已覆盖新模型。

### 装备与战斗数据如何分层

建议后续采用三份记录，不把战斗中的状态写回器物本体：

- 器物实例：已经炼出的固定值、效果ID、规则/材料快照。改名只改显示名，不能更改来源或重新计算效果；器型也不允许通过改名获取倍率。
- 人物装备配置：引用器物ID、化法所绑定的合格技能位置、所装配的获授技能ID。常驻与器蕴在装备汇总阶段读取，化法在生成技能副本时追加；不能改共享技能资源。具体装备数量与绑定冲突上限待评审。
- 单场运行态：来源实例ID、召出/在场/崩解/离场、剩余器体、灵识占用、次数/冷却。只有器物实际具有御器表达才创建这类状态；召出成功在场占灵识，化法本身不另行施放。场结束后释放并记录报告，不把器体状态当耐久扣除。

直施与御器是不同表达模板；一件器物可以同时有两者。每项功用当前分别记录其可用表达，不在试炼阶段暗自合并成一张多效果战斗卡，也不自动塞入技能栏。后续需逐个模板完成费用/目标审核，再决定合成一个授予技能还是多个；此选择不回头复制功用效力。

器蕴层数属于器物静态贡献；套系的当前累计、激活门槛和奖励属于人物装备汇总。不能把全身累计写成单件器物属性，也不能在卸装后保留已失去的套系奖励。当前只演示单件层数，套系奖励未生效。

## 四、界面信息分工

左：实际岗位、材料图标、份数、槽数解锁，直接点材料换选。中：水墨锻造台、五阶段职责、局部五行配伍、七档输入阴阳；不出现预选细剑/阔剑或成品答案。右：投料总数、供热、造诣资格、时辰与精力、当前已知问题、开炼、试炼器物册。结果独立详情页，页签为器物、功用与表达、炼制记录；长文可滚动，重看不再扣料。

## 五、后续定案边界

需要评审：岗位上限及造诣门槛、材料档案与所有候选曲线、成器有效门槛、器蕴套系表、正式品阶/名称、装备数量与占用、主动技能模板、绑定冲突、耐久与修复、交易和正式消耗事务。它们有清晰字段和边界，未定项不悄悄生效。

## 六、当前实际样例与验收入口

三套参考投料分别为基础成材、复合配伍、不足供热；均只有材料与造诣，没有预写的结果ID。运行产出、候选数值及全部检查见[自动生成的运行记录](../../../美术规范/材料过程炼器试炼_20261022/运行记录.md)，实际页面见[实机图](../../../美术规范/材料过程炼器试炼_20261022/README.md)。

样例用于验证单项专精、多收益分散、材料换岗和失败消耗。基础成材的破常驻达到6%物理伤害加成；复合配伍分摊后常驻破只有1%，但另有化法、直施和御器。这是候选参数下的实际结果，用来展示取舍，不能据此宣布已完成正式平衡。
