# 剑类图谱与方法配置评审表

> 日期：2026-10-21。
> 状态：**配套评审草案**。主入口为[剑器形与炼制配置设计](剑器形与炼制配置设计_20261021.md)。本表细化用户已确认方向，供逐项评审和后续校准，不是可执行配方、正式方法库或已实现界面。
> 范围：三份图谱的输入结构、材料工艺适用候选、七类候选方法、配置样方与界面状态。后续已在[首轮试算方案](剑类炼器首轮试算方案_20261021.md)补齐份数、加工适用、效果、费用与造诣候选，并生成[离线结果](剑类炼器首轮试算结果_20261021.md)；本表下文保留的“待定”均指正式规则尚未批准，不代表没有数值候选。

## 一、三份图谱的槽位表

槽位数量表示工艺位置，材料份数表示消耗量；二者独立。完成一个槽位必须同时满足材料适用与规定份数，不能只放一个图标就算完成。

| 岗位 | 细身剑 | 阔刃剑 | 厚脊剑 |
| --- | --- | --- | --- |
| 身材必填 | 剑身、承接 | 主体、刃面、承接 | 剑身、剑脊、承接 |
| 部件重点 | 剑身一体承担主体与刃部 | 主体和刃面分别满足条件 | 剑身与剑脊分别满足条件 |
| 根材位置 | 一个，支撑整器 | 一个，支撑整器 | 一个，支撑整器 |
| 功用来源位置 | 最多两个，分别选定功用 | 最多两个，分别选定功用 | 最多两个，分别选定功用 |
| 调和及方法辅材 | 按图谱预留位置与所选方法启用 | 按图谱预留位置与所选方法启用 | 按图谱预留位置与所选方法启用 |
| 燃料 | 根据组合列出需求 | 根据组合列出需求 | 根据组合列出需求 |
| 不允许省略 | 必填剑身或承接 | 主体、刃面或承接 | 剑身、剑脊或承接 |
| 首要比较方向 | 简单结构的专精成本 | 攻伐方法的转化与刃面成本 | 复合配置的承载与剑脊成本 |

和材、方法辅材和燃料尚无完整参数，不能在图谱中默认填一个槽、两份材料或零消耗。厚脊剑支持复合的优势应通过结构参数体现，不能默认无限增加辅助槽。

每个图谱实际还须补齐以下字段：部件材料条件、部件份数范围、允许的辅助位置及其启用条件、形制转化参数、结构承载、学习资格。未填写的必要字段会阻止正式开炼。

## 二、材料工艺适用评审

### 2.1 为什么需要单列

当前材料资源的五行、质地与功用并不直接描述能否加工成刃面或剑脊。公开质地继续使用现行六类；建议在炼器工艺资料中单列材料适用说明，供图谱准入查询，不新增玩家战斗属性，也不恢复旧金／木／晶等质地枚举。

适用说明至少回答：可以承担哪些部件、需要哪种已掌握的加工、能否独立承担或只能辅助投入。它需要明确配置，不从物品名字、五行或旧兼容字段生成。

### 2.2 已有材料的候选用途

本表根据现有物品和材性资源列出候选；“候选”不代表已满足加工资格，不作为制作白名单。

| 材料 | 已确认的资源性质 | 待评审的工艺适用 | 不自动授予 |
| --- | --- | --- | --- |
| 玄铁 | 金、致密、阳、固结 | 剑身、主体、剑脊；刃面加工另核对 | 常驻物防、额外固结功用或所有部件通用资格。 |
| 铜髓矿 | 金、致密、和、固结 | 提炼成形后承担结构；质材与固结性材候选 | 未经过规定工艺即可把原矿当成刃面。 |
| 青木芯 | 木、致密、和、疏通／生发 | 承接；另用份数时作功用来源候选 | 木行剑身资格、同时激活疏通和生发。 |
| 裂甲石 | 金、致密、阳、破障 | 破障性材；是否存在结构加工另核对 | 因为金行、致密或名称含裂甲而获得刃面资格。 |
| 风纹石英 | 金、致密、和、疏通 | 质材、疏通性材及具体调和工艺候选 | 因为旧晶类字段而获得公开晶质或剑身资格。 |
| 灵泉露 | 水、液体、和、凝聚／化生 | 质材、选定功用来源或已定义辅助工艺候选 | 独立承担实体剑身、自动同时发挥两项功用。 |
| 凝露松脂 | 木、黏胶、阳、固结 | 固结性材或具体辅助工艺候选 | 自动作燃料、独立剑柄或免费附着效果。 |

相性文字按物品已配置标签核对，不将旧 polarity 数字直接解释为七档权值。材料功用品级需要从统一材性规则读取，不能以资源中的单个 grade_value 默认值代替。

## 三、七类方法的评审范围

下列名称是工艺条目标题，不是战斗技能名。各条的数值、正式目标、费用、冷却、限次及化法关键词尚待补齐；本表不生成卡牌或技能资源。

| 工艺条目 | 来源功用 | 研究的表达方向 | 必须单独补齐的条件 |
| --- | --- | --- | --- |
| 破障·附加化法 | 破障 | 对合规攻伐的指定物理结算追加穿防 | 真实关键词、技能类别、必要出手方式、适用伤害段与穿透上限。 |
| 破障·直接施展 | 破障 | 一项直接攻伐能力 | 完整技能、伤害结构、目标、费用、冷却与限次。 |
| 破障·召出御使 | 破障 | 召出器体后通过御使进行攻伐 | 器体、召唤和御使两组规则、灵识、目标及伤害结构。 |
| 固结·常驻发挥 | 固结 | 装备期间的明确防护属性强化 | 对应现有战斗属性、收益上限与生效范围。 |
| 固结·附加化法 | 固结 | 在符合条件的实际应对中增加化解 | 真实关键词、应对条件、追加时点；空放不追加。 |
| 固结·直接施展 | 固结 | 一项直接护持能力 | 使用何种现有效果、目标、费用、冷却与限次。 |
| 固结·召出御使 | 固结 | 召出器体后通过御使进行护持 | 器体、两组费用、灵识、具体效果与离场规则。 |

七类条目都允许在三种形制上进入评审，不能把破障分给阔刃、固结分给厚脊后锁死其用途。具体方法可以有形制适用条件，但必须逐条说明。

候选范围不等于立即全部开放：没有完整规则或条件未定的条目只供查看，不授予能力。尤其固结常驻所用的物防、化法化解和主动护盾不能用同一份数值线性兑换。

破障常驻暂不进入这七类，原因是作用范围尚不明确；这不是宣布剑器不能具有常驻收益。其他功用及其方法在战斗语义定案后再扩充。

## 四、同一份配置怎样计算与修改

### 4.1 从来源到方法

顺序为：核对结构与部件 → 核对根材 → 选择功用来源 → 选择方法 → 启用明确的辅助位置 → 处理配伍与七档阴阳 → 检查承载和最低效力 → 分配主次 → 核对库存、燃料与用度。

主次可以在选材阶段修改，用于查看需求变化；实际效力分配规则与系数未定，不能据此先生成结果值。最终方案在成器时保存。

### 4.2 重复来源与重复方法

- 同一功用的补充材料只增加该功用的有效供给，不形成第三项功用，也不复制已有方法。
- 一份多功用材料选中一项时，其他功用不自动继承；若图谱允许另用一份承担第二功用，须独立分配与扣料。
- 同一个方法条目只能加入一次；额外化法目标或额外独立技能必须有另外的明确工艺，不能重复勾选。
- 不装某项主动技能、未绑定某项化法或战中御器失败，不触发效力再分配。

### 4.3 材料的实际扣除范围

草稿选择、正在浏览的候选与实际投入三者分开。只有当前图谱、当前方法组合所需且已确认分配的材料进入扣料表；其他图谱草稿、已删除方法的备用材料不扣除。

移除方法后若某份材料仍被其他已选方法或调和关系需要，保留这份有效投入；若不再被需要，解除投入并留为可重新选择的草稿。不要按一个按钮机械清空所有相关材料。

## 五、首轮六套配置样方

这些是需要校准的配置结构，不是固定配方。根材、各槽份数、辅助材料和燃料暂缺，因此不能按材料名称拼出正式成品。

| 样方 | 器形与配置 | 要回答的问题 |
| --- | --- | --- |
| A：细身专精 | 细身剑，破障单功用，附加化法单方法 | 较简单结构能否让有限投入集中到一项追加？ |
| B：阔刃攻伐 | 阔刃剑，破障单功用，直接施展单方法 | 刃面成本计入后，攻伐方向优势是否仍有价值？ |
| C：同功两用 | 任选合规形制，破障化法主用、御器兼用 | 两项方法是否共同分走破障效力，并增加相应材料与结构需求？ |
| D：厚脊复合 | 厚脊剑，破障与固结双功用，各采用一项方法 | 复合承载是否有价值，两个来源和共同根材是否正确计入？ |
| E：无主动技能 | 任选合规形制，固结常驻单方法 | 无技能、无化法是否仍能通过装备属性与器蕴参与构筑？ |
| F：同功三用 | 任选合规形制，固结常驻、化法与主动护持并存 | 三项最低投入与承载是否形成真实要求，单项强度是否合理分散？ |

同一配置还应替换三种形制比较；不能只做各形制最擅长的样方，便宣布平衡成立。比较成本包含部件、根材、性材、辅助与燃料，不只统计性材份数。

## 六、界面状态与操作验收

| 状态或操作 | 界面应显示／执行 | 不得发生 |
| --- | --- | --- |
| 切换形制 | 对应部件、位置与结构图一起变化；恢复该形制自己的草稿 | 刃面静默变成剑脊；所有图谱共同占用库存。 |
| 一个部件缺材料 | 左侧槽、中央部位和右侧待补项指向同一位置 | 仅显示泛化的材料不足。 |
| 材料适用尚未定 | 可查看候选与待定原因，正式开炼不可用 | 因为致密或金行就标记加工合格。 |
| 第二功用未选 | 可选位置不计入必填缺项 | 强迫玩家做双功用。 |
| 添加已学方法 | 列明新增材料／结构要求，更新有效投入 | 自动换材料、免费复制效力。 |
| 技术未掌握 | 可查看方法条件与学习缺项 | 自动授予技能，或消失到无法了解。 |
| 辅助槽未需要 | 收起或明确标可选，空位不报错 | 为凑齐整页而强制放料。 |
| 方法最低效力不足 | 指出受影响功用与方法，提示改善来源或减少配置 | 改主次就伪造合格；静默丢掉一个方法。 |
| 结构承载不足 | 指出结构问题与需要调整的位置／配置 | 用任意燃料数量放行。 |
| 删除方法 | 重新计算共用需求和实际扣料，保留选择草稿 | 清空仍被其他分支需要的材料。 |
| 有多个草稿 | 只核对当前有效投入与实际库存 | 把其他草稿里的物品重复预占。 |
| 看阴阳 | 七档文字完整，提示是已选材料倾向 | 把极端标为普遍错误；展示成器结果。 |
| 开炼资格未齐 | 右侧列具体缺项与定位入口 | 用零耗时、零费用代替缺失规则后开放正式制作。 |

右侧待补清单是一组导航，不是另一份材料表；实际用度按物品汇总同种投料，不重复显示每个部件的详细属性。

## 七、校准与实施前检查

本轮只完成图谱与方法的评审框架。下一步应逐项填完，而不是一次性给所有候选方法套通用默认数值。

| 表 | 必须补齐的内容 | 对应验收 |
| --- | --- | --- |
| 材料工艺适用表 | 材料与部件的加工条件、技术要求 | 同为致密的材料不会无条件互换。 |
| 三份槽位参数表 | 各槽份数、辅助位置与启用条件、燃料 | 无无限加料、无隐藏扣料、无必填部件缺省。 |
| 方法全文表 | 正式效果、费用、目标、条件、上限、冷却与次数 | 按卡牌总规则补齐词典与实现后才授予能力。 |
| 承载与分配表 | 结构负担、最低效力、主次规则、形制转化 | 专精有效、多功能有代价、同投入无全面优势。 |
| 学习与成长表 | 造诣门槛、具体技术来源、实践奖励 | 不强迫四类方法走单一升级顺序。 |
| 相性与器蕴表 | 七档贡献、五行路径、整器器蕴判定与贡献 | 不默认中和唯一正确，不按部件重复累计。 |

正式制作和战斗生成仍处于关闭边界；本篇不改旧样本、存档或材料配置。文档与资源核对只能证明引用和描述有效，不能替代数值模拟、编译或实际战斗验收。

## 八、首批投料建议

### 8.1 收敛目标与状态

首轮先使用现有物品建立容易追溯的材料组合，逐步研究结构与方法的差异。以下“推荐”均是本轮新增的工艺适用建议，尚未批准、未写入材料资源，不能据此把正式界面标为加工合格。

先采用相同金行根材与金行功用来源，减少首轮比较中的五行调和差异。这是校准样方的控制条件，不是宣布剑只能金行、其他根性不合法或最终阴阳必须中和。

### 8.2 三种剑的推荐部件用材

| 部件 | 细身剑首轮建议 | 阔刃剑首轮建议 | 厚脊剑首轮建议 |
| --- | --- | --- | --- |
| 剑身／主体 | 玄铁 | 玄铁 | 玄铁 |
| 独立刃面 | 无独立槽，剑身按一体成形工艺处理 | 玄铁，另占刃面投入 | 无独立槽，剑身包含刃部 |
| 独立剑脊 | 无独立槽 | 无独立槽 | 玄铁，另占剑脊投入 |
| 承接 | 青木芯 | 青木芯 | 青木芯 |

建议先评审玄铁是否支持这组基本结构工艺、青木芯是否支持承接工艺。正式准入需由对应加工条件规定，不以本表永久锁定两种材料；以后其他材料满足条件即可扩展。

本表不把原矿直接等同于成品部件。初步建议在一次炼制行动中完成规定的加工，不额外生成中间锭、剑胚等背包物品；是否需要独立提炼生产链另议，不隐式增加前置生产系统。

阔刃的刃面与厚脊的剑脊即使用同一种玄铁，也按不同工艺和独立份数核对。不能把两个部件都指向同一份实物；具体份数尚待校准。

### 8.3 共用的根材与功用来源建议

| 作用 | 首轮建议材料 | 核对理由 | 限制 |
| --- | --- | --- | --- |
| 金行根材 | 铜髓矿 | 资源已配置金行、致密、相性和，可作为根性候选 | 根材承载与支撑参数未定；自带固结不自动成为额外功用。 |
| 破障来源 | 裂甲石 | 资源已配置破障功用 | 不因破障而获得剑身或刃面资格。 |
| 固结来源 | 玄铁 | 资源已配置固结功用 | 作为性材必须使用结构投入以外的独立份数。 |
| 第二功用 | 仅在对应样方需要时加入另一项来源 | 可以研究破障＋固结组合 | 同一图谱最多两项功用，第二项未选不属于缺料。 |
| 和材／方法辅材 | 由具体方法提出要求后配入 | 不为把所有槽位填满而添加 | 相同行只能减少五行问题，不能代替方法本身的辅助需求。 |
| 燃料 | 松心炭底火、地脉焰炭催火候选 | 材料对话已补明确用途、资源与图标，供热和份数见试算方案 | 来源点未接入正式采集；凝露松脂与赤纹燧石不因此自动成为燃料。 |

青木芯在承接中的疏通、生发功用、玄铁在剑身中的固结功用，都不自动转成战斗效果。若要把它们作为性材使用，需要另设有效功用来源并扣除独立投入。

### 8.4 首先研究的三份投料草方

| 草方 | 部件与根材 | 功用来源 | 方法意向 | 首轮研究目的 |
| --- | --- | --- | --- | --- |
| 细身单用 | 玄铁剑身＋青木芯承接，铜髓矿根材 | 裂甲石提供破障 | 仅附加化法 | 以简单结构建立单功用、单方法的比较基线。 |
| 阔刃单用 | 玄铁主体＋独立玄铁刃面＋青木芯承接，铜髓矿根材 | 裂甲石提供破障 | 仅直接施展 | 把独立刃面成本计入，研究攻伐方向的效力转化。 |
| 厚脊复合 | 玄铁剑身＋独立玄铁剑脊＋青木芯承接，铜髓矿根材 | 裂甲石提供破障，另投玄铁提供固结 | 破障化法＋固结御器的组合意向 | 核对两个来源、共同支撑、方法要求和复合承载。 |

三份草方的份数、辅助、燃料、方法与造诣已在首轮试算候选中展开并重算；仍未生成正式游戏配方，不能称为游戏内已可炼。离线结果中的相性与强度属于候选模型结果，不是正式角色所得物品。

研究时还要做互换比较：同一份破障方法意向分别放进三种形制，再把同一份复合意向分别放进三种形制。不能只比较本表不同配置，然后把差异全部归因于剑形。

### 8.5 从草方进入试算的必要决策

1. 审定上述基本加工适用，明确加工是否包含在一次炼制行动中。
2. 为各槽给出最低、标准与最高有效份数；按同等总成本建立比较档，不以每槽默认一份填补。
3. 选定真实燃料及用途，明确消耗；若需要新增物品，另走材料创建流程，不在草方中虚构。
4. 为首个化法与首个直接方法补齐完整规则，再给复合方法确定独立条件。
5. 给部件、根材、功用来源及方法分别建立参数，完成后才运行数值试算。

这些步骤是进入数值校准的条件，不是要求先实装所有器蕴、修复或材料加工生产链。器蕴正式表尚未确定时，可以验证投料与方法组织，但不向正式角色写入虚构器蕴。
