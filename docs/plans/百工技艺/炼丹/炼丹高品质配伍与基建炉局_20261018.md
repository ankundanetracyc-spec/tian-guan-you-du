# 炼丹高品质配伍与基建炉局（2026-10-18）

状态：用户要求“巧妙设计数值，让丹药需要多味药材才能成高品质丹”后的首轮接入。已替换单味青髓芽可达85分的旧判定。数值仍是初始平衡基线，尚未全面跑遍材料组合和各阶丹药。

规则入口：[逻辑主案](炼丹系统逻辑主案_20261017.md)、[初始数值表](炼丹节点网初始数值表_20261018.md)、[节点网分工修订](炼丹通行引节点网分工修订_20261018.md)。本稿补充炼丹专用的高品质成品配伍要求；不改材料原表功用归属，不改其他制作系统。

## 一、用实际互补能力支撑高品质

继续采用主药发挥、配伍协调、丹体稳定三轴分别评分、取最低项的判定。主药提供核心能力，辅药补充高品质要求的药性；配伍轴新增下表检查：

|丹种|超过50分逐步要求|超过65分逐步要求|超过75分逐步要求|
|---|---|---|---|
|回春丹|固：稳住丹体与生机药力|化：药力化合、便于承接|藏：药性收敛、持效|
|通脉丹|固：通脉药力稳定|行：药力运行|护：避免强通伤脉|
|静心丹|固：丹体与药力稳定|藏：镇摄药力收敛|明：安神兼具清明|

主药候选和核心功用要求保持原丹种定义。这是成品保留药性的要求，不能将普通搅和、塑形等操作当成凭空生成材料能力。材料用于炉内工艺和最终提供丹效分别计算。

不按材料名称数、投料批次数或线数加分。当前材料中，可以通过选择兼具两项所需能力的辅材缩短配方；也可以分别选用不同辅材。增加同一主药数量、换高品主药、拆成多批或大量加入无关材料，均不能补上缺少的能力。

## 二、初始数值

设目标品质为q，某项开始要求的分数为q0，100分的基础需要量为N：

```text
q≤q0：该项需要量为0
q>q0：需要量 = N × ((q-q0)/(100-q0))^1.15 × S(目标丹药品级)
```

三列的(q0,N)分别为(50,3)、(65,4)、(75,3)。S沿用已有九品至一品非线性强度表，固定按目标丹阶取值，不按选用主材强度抬高门槛。

以九品回春丹为例：

|目标品质|所需固能力|所需化能力|所需藏能力|
|---|---:|---:|---:|
|80|1.667|1.510|0.471|
|90|2.321|2.717|1.667|
|100|3.000|4.000|3.000|

这些量与现有“质量×功用品级强度×实际保存与损伤”统一。高品辅材可以少量高效发挥；低品材料可以增加合理用量、调整加工精度及来源去向，仍须服从实际控制规模。

当前三种丹的主药候选不具备所需固能力，因此单味路线即使其余条件全部理想，也只能到50分；补足第一项后仍须逐步满足后两项，才能进入更高品质。三列不是额外的品质乘数，而是三轴共同标准中的实际缺口。

## 三、哪些来源可以计入

1. 实际留在该颗丹体中的有效药性，按其保留的功用、数量和损伤计算。不在该颗丹中、已经逸散、变渣或用于其他工序的来源不计入。
2. 固在中心／丹体上实际投入并保留的结构，可以提供其原来源的固支持；记录在结构来源中，不恢复为自由药性，不重复提供已经消耗的核心能力。普通塑形提高形状稳定，但不会凭空生成固药性。
3. 通路、外部行供力、引调度和留在炉外圈的辅助来源不因“本炉使用过”就计入丹体。回泉珠若要同时做化配伍和聚工艺，必须预留不同实际份额，分别进入丹体和绑定结构。
4. 同一结构的能力与其来源能力按同一实际份额核算，不把一份材料复制成两份。多功用材料可以表达多个不同能力，但需要消耗的工序仍从共同来源预留投入。
5. 混匀、阴阳、主药量、夹渣、损伤与形状标准继续独立成立。配伍互补齐全不自动变成100分。

新药性流入汇合位时，已有稳定按实际新旧药性量稀释，必须继续稳形；不能先稳住一小团，随后无限加入未经稳形的药性并继承100%稳定。

## 四、基建测试炉局

测试页默认载入可接手的八味炉局；“重载基建炉局”重新准备，更多菜单的“重新开炉”仍可从空炉自由搭建。预备状态通过实际投料、火候加工、建线和牵药生成，保留准备阶段息数、法力和来源账，不直接填写可用药性或修改材料能力。

|材料|实际岗位|
|---|---|
|青髓芽0.8份|主药，提供生机药性，由基本牵药送入主干|
|风络藤丝0.4份|通路起点，分出直汇和中继两支|
|溪纹藻丝0.4份|中继通路，把流入药性继续送向中心|
|乌羽片0.4份|行作用于主干至中继的那一段路线，实际增流|
|雾铃花0.3份|引作用于主干分流节点，以3∶1权重分支；实际仍受路线能力和下游空间限制|
|回泉珠0.4份|一部分药性入丹提供化；另一部分留作聚的工艺来源|
|凝露松脂0.3份|在中心实际施固形成稳定结构，结构来源进入丹体|
|凝霜叶0.3份|药性沿主干流入，提供成品藏能力|

默认显示节点网，可守炉逐息观察、点运输线调累计目标／开闭、点行或其他功用线设置持续作用、暂停或撤线，点引线修改各出口权重。基本牵药作为本息安排另行标注，点击可撤回，不伪装为材料拥有通。

持续功用仍按每息实际执行计入操作负担，线路占用另计；没有目标缺口不消耗药性。来源筛选、自动识别复杂配伍缺口、完整五行制化和复杂丹种仍未完成，不能把这一炉局称为全部系统验收。

## 五、实际验证

- 构建通过，0警告、0错误；46项模型检查与7项场景检查通过。
- 成品配伍条件对照：单味青髓芽理想状态50分；青髓芽＋回泉珠＋山蚕长丝可到100分；青髓芽＋月露菌汁＋凝露松脂＋凝霜叶也可到100分。这两套是成品来源条件的构造检查，不冒充真实跑炉结果。
- 缺化能力不超过65分，缺藏能力不超过75分；象征性掺入极少辅材不能完成高品质条件；高品主药不能独自补齐配伍。
- 引的9∶1权重在来源不足、路线未满载的构造炉况中，实际分支流量比为9∶1并保持来源守恒。
- 八味真实材料炉局从投料准备至最终成丹共29息，产出1颗100分回春丹，剩余法力460。真实经历分支、中继、行供力、引分配、聚药、混匀、分离排渣与稳形。
- 已修正大量分流时药渣记录碎片膨胀，按来源与位置合并残余记录，保留实际质量；药材资源目录改为共享静态读取，避免重复加载脚本资源导致测试运行期间原生资源析构崩溃。

本轮验证说明多味互补路径可运行，不说明100分成本已达到最终难度。后续需比较更多替代材料、操作精度、法力、灵识和目标品质的成本，继续收敛平衡。
