# 炼丹节点退场与五行阴阳接入边界（2026-10-18）

## 节点耗尽的用户裁定与执行

用户确认：药性完全耗尽后节点消失；仍有未炼原料、或仍在进料的中继节点保留。

1. 保留有未炼原料或当前自由药性的节点，以其为真实供料起点，沿未暂停、开阀且未达目标量的已建／本息安排通路，以及基本牵药安排，求可达进料节点；暂停或封阀不视为正在进料。外来药性同样计入接收节点库存。
2. 原料和可用药性均不超过1e-6且没有真实可达进料时，该药材节点从图面退场；无供给的空环不能互相声称“后续有料”。炉口汇合位独立保留。
3. 息末自动停止该节点及相应路线供力的控制线，下一息不再占其持续灵识；失去来源的持续基本操作一并停止。此前本息已付资源不返还。
4. 退场不删除材料来源账，不抹掉炉内残渣或既有工艺绑定。自动停止控制等同暂停线；区别于玩家主动撤线，不将已完成的绑定自动拆回残余。后续若实际重新进料，节点可重新显示，旧线保持停止状态，需玩家重新恢复。
5. 同一炉局其他节点的位置不因某个节点消失而重排；刷新、推进一息与关闭重开保留布局。

## 五行：当前确实生效的部分

- 顺生对实际“化”处理、通路上实际“行”增流生效，倍率1+0.20R；来源受目标克制时为1−0.15R。多行按原材五行的配对份额计算，合成倍率截断0.70—1.25。
- 代码当前按来源／目标节点原材五行计算，不是按所有外来药性的实时混合贡献逐份制化。通本身的基础缓流不额外获得行的增益。
- 回生的下一息损伤增长修正、过盛五行的制克活跃度压制，以及完整的外来药性五行贡献追踪尚未接入。三种现有测试丹没有额外五行比例门槛。不能将当前实现称为完整五行制化。

## 阴阳：当前确实生效的部分

实际流入与目标已有药性接触，按来源阴阳和目标药团偏向、接触量、流量、火候等产生局部躁动；镇可压躁动，躁动参与损伤。护、生分别防伤、修复；成丹配伍按实际保留药性加权的阴阳偏向与丹种目标比较。

点击信息卡同时显示原材五行／阴阳和当前药团的加权阴阳偏向、局部躁动，不将原材标签冒充当前药团组成。偏向显示为“偏阴／偏阳 XX%”，接近零显示平衡。
