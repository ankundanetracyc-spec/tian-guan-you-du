# 炼丹造诣成长规划（2026-11-10）

> 状态：首轮已接入，待局内试玩（2026-11-10）。本案记录当前运行规则；数值是首轮观察参数，后续可按进度和资源压力调整。人物的基础丹道造诣代表天赋，研习和实践只增加单独保存的固定造诣加成。
>
> 权威边界：当前结算以[炼丹完整结算与正式接入](炼丹完整结算与正式接入_20261023.md)及[首批八种丹药扩充与接入](首批八种丹药扩充与接入_20261104.md)为准。旧[槽位式自动配伍案](炼丹槽位式自动配伍新案_20261019.md)中的成长公式与首炼奖励没有随现行一次性结算流程保留；本案只重做成长闭环，不恢复旧炼制方式或旧数值。

## 一、问题与目标

角色创建时九项造诣可在 0～10 之间设置，默认 5。九品丹准入为丹道造诣 8，原先没有从初始值到首次开炉的成长桥梁。本轮在正式丹房加入入门研习，并让真实成丹的丹效进步提供后续实践成长。

成长应让玩家能靠研习与炼制逐步成为更好的丹师，同时避免大量重复小炉胜过学习与有挑战的炼制。造诣仍沿用人物现有丹道造诣字段，不新增丹药经验条、丹种熟练度或兑换货币。

## 二、当前成长来源

| 来源 | 规划作用 | 发放边界 |
| --- | --- | --- |
| 丹诀入门 | 正式炼丹房顶部的“入门研习”按钮；角色可在尚未达到九品丹门槛时学习。 | 每名角色一次。每补足1点至造诣8，消耗8点精力和1时辰；默认5升至8，消耗24精力、3时辰。已经达到8时不再授课或扣费。 |
| 炉上实践 | 正式炼制产出至少一颗合格丹药后，比较该丹种此前的最高丹效档。 | 每次事务最多+2；新高档按丹种分别记录。同一丹种重复制作已达档位不再成长；一炉多颗或一次跨过多个档仍只发一次。 |
| 专题研习 | 后续可由新丹理内容提供稳定成长。 | 本轮尚未接入，不影响当前规则。 |

## 三、炉上实践规则

### 可计入的结果

- 必须来自正式人物成功提交的实际开炉事务，且至少产出一颗丹效分数不低于20的丹药。配伍预览、首页试演、查看丹方、切换材料、预检失败、炸炉及没有合格产物均不成长。
- 本炉必须实际产出至少一颗符合现行成丹条件的丹药；只检查事务是否提交成功不够，因为正式炼制可能合法结算但没有合格成丹。
- 以本炉开始时的丹道造诣完成本炉所有结算。造诣奖励在结果和材料事务提交后发放，只影响后续开炉，不回算本炉药效、数量、品质、灵识或精力。
- 以该炉最高成丹档与该丹种历史最高档比较。高于历史记录时，登记新档并增加2点；无论一炉多颗、档位跳升或产量多少，本事务最多增加2点。

### 里程碑候选

复用现行结果字段：丹种身份与丹效档。每种丹药独立保存其最高档位；第一次产出任一有效档、以及以后首次超过该丹种旧纪录，均为一次新里程碑。档位为薄效（20—50）、良效（51—75）、优效（76—90）、极效（91—99）、满效（100）。若一炉从未产出跃至更高多个档位，只按一个里程碑奖励2点，并把已达最高档写入记录，不补发中间档奖励。

档位沿用现行丹效判定，不引入新的丹效门槛。研习和实践增加人物的丹道固定成长加成，不改写代表天赋的基础造诣；有效丹道造诣按基础造诣×适用成长倍率＋境界定额加成＋研习实践固定加成＋其他固定修正计算。成长只影响之后的开炉，不回算本炉的产量、丹效或资源消耗。当前有效造诣上限1196与最高一品丹的准入档一致。

### 失败与复盘

现阶段倾向于失败、炸炉和无合格丹产出不直接增加数值。失败结果继续写入炼丹记录，供玩家查明材料与配伍问题；待有真实的复盘／师授交互后，可另评估是否把首次诊断成果作为独立学习来源。不能因失败扣料便自动发造诣，避免把损耗转成可重复刷取的成长。

## 四、事务与存档边界

- 实践成长以实际提交的炼制事务为准，不以领取页是否打开、物品是否放进行囊或演出是否播放为准；领取只是处理已经提交的成品。
- 一炉事务的成长发放必须与投料、精力、时间和炼制记录保持同一提交边界。重复点击、重进页面或读档不得重复授予。
- 现有炼丹记录是面向玩家的可读文本，不作为防重的唯一依据。建议为成长来源保存稳定的事件 ID、来源类型、奖励版本及已发数值；避免解析文案判断是否领过。
- 入门研习 ID 写入人物 `alchemy_proficiency_growth_sources`；各丹种最高档写入 `alchemy_growth_highest_tier_by_pill`；已获固定成长累计写入 `alchemy_proficiency_training_bonus`。这些字段随人物存档保存，旧角色缺少字段时沿默认空值开始记录，不从旧文本记录补发。有效造诣重算后显示在人物当前丹道造诣中，不增加丹药制作的即时增伤、灵识折扣或额外丹效。

## 五、首轮平衡判断与验收

定数值前至少需要：

1. 默认5点角色研习一次即达九品丹门槛8；费用24精力、3时辰。造诣不足8的角色成本随差值变化，精力不足时不能开课。
2. 当前开放的11种丹药最多提供55个“首次达到某丹效档”里程碑，理论实践上限为110点；加上入门课后，默认角色的理论上限为118。实战必须逐步炼成新档，不能靠同一低档重复生产获得成长。当前已开放最高丹阶为七品，其准入68在这条理论路径内可达；更高阶丹种开放后再观察长线节奏。
3. 预览、预检失败、炸炉、无合格产物、同档重复、多颗同炉及档位跳升均按上述事务边界处理；首次有效档或超过旧纪录时只增加2点。
4. 存档字段为稳定去重记录。领取页打开、关闭、重复进入结果页不会二次授予；旧存档不按旧文本追溯补发。
5. 已完成 `dotnet build Stacklands.csproj --no-restore`，0警告、0错误。当前本机 Godot Mono 运行器在.NET模块初始化阶段未进入场景，故尚未完成人工鼠标试玩；需在可运行的 Mono 编辑器／游戏窗口进一步观察课程入口、反馈与中后期节奏。

后续观察重点：24精力是否让新手仍有余力完成首炉；薄效到良效的提升速度是否足够可感；每种丹药各自记档是否鼓励多方探索；新丹种与更高丹阶开放后，理论成长上限和现有1196上限是否仍合适。本轮不沿用旧槽位案成长公式或首炼奖励。
