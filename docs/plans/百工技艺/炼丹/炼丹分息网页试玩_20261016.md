## 已确认方向

- 一次炼制由多次推进组成，暂称“一息”，界面不使用回合；安排后手动结算，不要求实时反应。
- 君药只能一种，可多份、分批；臣佐使可多味。君药全部功用实际参与过程。
- 法力有总量，驱火持续消耗；副手接管后本人可回气，也可当息服药。
- 灵识按当息占用计算。超过80%不支，超过100%通常炸炉，本原型确定性炸炉以便体验边界。
- 丹阶九品至一品，九品造诣门槛8。丹效0—19失败，20—50、51—75、76—90、91—100为四档；暂称薄效、良效、优效、极效。
- 所有材料处理在炉内进行；不设外部研磨等前置小游戏。

## 结算顺序

合法检查 → 灵识超载检查 → 服药 → 法力驱火 → 副手顶炉回气 → 投料 → 化药与热损伤 → 合药或凝丹 → 药力散失 → 收丹判定。

投料、变火和操作在按下推进前均可修改。凝丹后停止加入新药，收丹前仍可控火或继续稳丹。

## 原型人物与资源

|角色|造诣|法力上限|灵识容量|火候输出上限|
|---|---:|---:|---:|---:|
|本人|24|90|60|100|
|副手|12|54|44|70|

本人回气须副手主炉，每息回复18法力；两份回灵散，每份回复本人28法力、当息增加6灵识占用。资源不超过各自上限。副手有独立法力，不能无限顶炉。

每息法力费用=ceil(1+受主炉者上限约束的目标火候×0.065+药量×0.45+操作附加)。合药附加1、凝丹2、其余0。法力供给不足引起衰火、留存降低和稳定度下降，不自动换人。

灵识占用=8+药量×4×[24/(造诣+24)]^0.3+本息投料量×4+目标火候与实际炉温差×0.18+操作占用+技巧占用+服药占用。

操作占用：化药4、合药10、收丹8、凝丹每丹核2。技巧：护药8、引流10、细分14，要求造诣12/16/24。原型人物预先学会符合要求的技巧，正式版另设学习。

占用比例r>0.8时，效率=1−(r−0.8)×1.5，同时产生可见的交替控温偏差、增加散失；r>1直接炸炉。当前人物数值仅用于体验，造诣模型不设100上限。

## 药材与过程

功用强度=10×1.8^(品阶序号−1)，序号1为九品。有效贡献乘数量、释放率、保全率、角色系数（君1、臣1.1、佐0.9、使1）。这些系数仅为首版占位平衡，不代表正式角色已经定案。

君材生提供主效药力，君材其他功用与辅药功用共同入池：通/化/行促进融合，固/聚/引稳定丹核，藏/护减少损伤散失，引/行改善分丹，破帮助释放。没有按材料ID编写加药力的特殊效果。辅助材料的生不额外生成主效药力。

质地起炼/适温/耐温/基础每息释放率：木25/45/65/0.44；骨45/80/95/0.28；液15/35/60/0.8；晶55/85/98/0.25。实际释放还受温度、造诣、化、破和灵识控制影响。超过耐温减少保全率，包括已经释放的药力。损伤不可通过降温逆转。

实际炉温渐近目标，受总药量影响；不瞬间升降。木君配已释放的水辅，在本炼丹子系统显式赋予合药×1.08；不改全局五行规则。阴阳偏性=30×有效释放材料阴阳加权和÷总药量（阴−1、和0、阳1）。不改全局相性判定。

## 成丹

君药释放≥90%、融合≥90、偏性在−10～10才可凝丹；稳定≥80才可收丹；实际炉温≤35时结算。

每份君材计划3丹。平均丹效=100×有效主效药力×留存率÷计划丹数÷满效参考12。各丹按灵识、造诣、引、行和细分技巧形成确定性对称分配。逐丹整数评分、各自评级，低于20废丹，不抽随机成功率。
