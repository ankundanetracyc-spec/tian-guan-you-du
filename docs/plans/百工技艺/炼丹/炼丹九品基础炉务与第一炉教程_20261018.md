# 炼丹九品基础炉务与第一炉教程（2026-10-18）

状态：已接入当前测试入口。用户要求先撤去技法菜单与所有书籍技巧，九品入门不依赖高级操作；确认保留排渣、凝丹、出炉等无需学习的基础炉务。本记录覆盖此前“默认载入八味15息炉局”和“第一屏先学十二功用／五课进阶”的入口安排。

## 1. 基础流程与入口

- 测试入口从第0息、0档、空炉开始，默认九品通脉丹、主材溪纹藻丝、计划1颗。首屏直接提供“第一炉教程”“看一炉演示”“自己开炉”；顶部另有教程与演示／暂停。
- 教程页默认“第一炉”，提供单味简炼和辅药稳形两课；另页保留十二功用专项。旧高品质八味自动炉局和五课进阶暂不作为面向玩家的入口，旧内部回归样例仍保留。
- 撤去技法菜单、快捷收藏与书籍技巧学习入口。当前普通玩家流程使用投药、真实功用接线、添焰／敛焰／守炉与炉口的排渣／凝丹／出炉；不需要手动照料、基本牵药、搅和、精细分离、回流照管等操作。
- 点击炉口信息卡即可安排排渣或凝丹，再用炉令推进一息；安全档位点出炉结束，不额外推进。教程既可亲手执行，也可用“演示本步”逐息观察；连续演示随时可暂停接手，不暗推息数。

## 2. 牵线不做参数表

点击药材→选择其真实功用→点击目标；行仍点击已有通路。选功用后显示跟随鼠标的临时虚线，接成即显示实际功用名。

签成的非通功用线默认随炉令按需施用，无需再次勾选持续、逐息安排；来源消耗仍按实际工作量，灵识仍按现有维持与操作负担预览。通保持建路后缓流，未附加行时也能运行。没有改材料功用、品级、容量、火候费用或药性来源。

点线只看用途、当前状态、停用／恢复、拆除。删除普通操作里的累计目标量、容量修改、权重输入和反复安排开关。引提供“各支路均分”／“优先送往某支”按钮，使用原有1∶1与3∶1偏向，不要求手填权重；实际流量仍受容量与来源限制。

## 3. 两课真实简炼

|课程|材料与火候|运输／稳形|必要炉务|实测结果|
|---|---|---|---|---|
|第一炉：单味通脉丹|溪纹藻丝0.4份，逐档至2档炼完|藻丝以自身“通”直达炉口，不借用隐藏搬运|输药完成后排渣一次、降到1档；反复凝丹直到达到最基本成丹条件，再出炉|19息，1颗45分薄效通脉丹，余法力549|
|再试一炉：辅药稳形|溪纹藻丝0.4份＋凝露松脂0.3份，以两者可共处的2档加工|藻丝“通”至炉口；松脂“固”至炉口，随实际缺口稳形|同样排渣、敛焰、凝丹、出炉|16息，1颗53分良效通脉丹，余法力555|

两课模型均使用普通测试角色初始资源和造诣，不填满药性、精度、混匀或丹效，不授予技巧，不加入隐藏牵药／高级分离／搅和，也不降低当前成丹标准。教程按真实原料、流入、药渣、稳定及预计丹效检查当前步骤；品质由共同判定产生，不是教学固定奖励。修改材料、份数、火候、接线或时机仍可能降质甚至失败。
