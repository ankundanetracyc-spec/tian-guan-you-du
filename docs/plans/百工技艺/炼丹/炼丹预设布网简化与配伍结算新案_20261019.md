# 炼丹预设布网简化与配伍结算新案（2026-10-19）

> **状态：已由[槽位式自动配伍新案](炼丹槽位式自动配伍新案_20261019.md)替代，不再作为候选方案。** 本稿保留节点网方向的早期方案供追溯，不应据此实现。验收前，现有测试入口仍按[预设布网与自动跑炉方案](炼丹节点网预设布网与自动跑炉方案_20261018.md)运行。
>
> 本案不重做材料分类。材料的品阶、五行、阴阳、加工表现和原有功用从当前材料数据读取；本案只规定这些数据如何组成丹方、节点网、资源负荷和成丹结果。

## 一、设计目标与玩家流程

炼丹采用一次布置、一次开炉、自动结算的流程。节点网是玩家规划药性去向和工序的主要界面，灵识与法力分别约束“能否同时驾驭这张网”和“能否承担这次炉程”。

1. 选择丹种与一味主药。主药须符合该丹种的候选条件，并提供丹种要求的核心功用。
2. 加入辅药。辅药可以自由选择、替换和增减；没有独立药引槽。
3. 在材料节点之间布置十二功用线。每条线显示功用名和起点、目标；无实际作用的线不算有效线路。
4. 预览灵识占用、火候安排、法力总额、成丹瓶颈和预计用时。
5. 点击【开炉炼丹】。资源足够时一次确认并扣除本炉法力，炉火、材料加工、药性流转、汇合、凝丹和出炉自动完成。
6. 查看结果：主药发挥、配伍协调、丹体稳定三项分数，五行与阴阳适配、药性损失、消耗及实际成丹数。

一息仍是内部运行单位，十息为一时辰、即两游戏小时。玩家不再逐息点击添焰、守炉或敛焰，也不在运行中反复安排小操作。

### 本案的取舍

- 保留主药与辅药、十二功用、非线性功用品级、材料加工窗口、来源守恒、五行生克、阴阳目标和三轴最低分判定。
- 把灵识改为整张布网的同时维持负荷，开炉前一次核验；不再按“每条线1点、超额线路轮候”计算。
- 把法力改为整炉自动火候计划的总支出，开炉前预览并一次扣除；火候档位只供后台自动排程使用，不作为玩家操作步骤。
- 九品入门以开放式汇流即可完成。闭环丹胚只供明确需要回炼的复杂炼法使用，不强迫每张网都绕圈。
- 当前基础流程没有书籍技巧菜单，也不要求先学高级操作。造诣负责丹阶资格与火候可达范围；将来若重开书籍技巧，另立专题，不计入本案基础数值。

## 二、主药、辅药与丹种职责

### 主药

- 每炉恰有一味主药。它必须是丹种列出的合格候选，并承担该丹药的核心功用和主要药效来源。
- 主药的功用品级决定实际核心能力；高品级不会把成丹门槛同比抬高或压低。
- 只有主药而没有辅药时，主药发挥轴最高为50分。它仍能炼成20—50分的薄效丹，但不能单味冲出高品质。

### 辅药

- 辅药没有固定必选清单，可为核心药力补强、补足丹种指定的辅助功用、调整五行比例与阴阳、稳住丹体或减少加工损失。
- 一味辅药可承担多项不同贡献，但实际留在成品中的来源只能计一次；用于工艺绑定、排出、逸散或其他丹体后，不能复制计算。
- 加入材料本身不加分。材料只有在真实提供核心能力、丹种要求的辅功、五行／阴阳适配，或实际改善保存与稳定时才有价值。
- 同一物种拆成多批可以增加加工节点与灵识负荷，但在“不同药材数”门槛中只算一种。

每颗丹都读取同一丹种的固定成品标准。丹方是可保存的配伍建议，不把某味辅药变成强制配方，也不改变成丹资格。

## 三、灵识：整张网的维持负荷

灵识在本案中是修士同时伸出的“手”：牵住药材节点、维持功用线、照料多批投料和协调复杂交汇都会占用。它不被消耗，炉次结束或撤掉布置后释放。

### 3.1 计量单位

- `M`：布网中实际参加本炉的材料来源节点数，主药也计入。
- `N`：投料总份数。一份为当前数据口径的100炉内质量单位。每个材料节点至少一份，因此 `N ≥ M`。
- `F`：实际承担工序的有向功用线数。不同目标的线分别计；一条线经过多个视觉弯折仍只计一条。没有实际目标、已失效或暂停的线不计。

```text
灵识需求 L需
= M
  + floor((N - M) / 3)
  + 2 × F
  + floor(max(0, M + F - 4) / 3)
```

这四项分别表示：每个药材节点占一只手；每增加三份同炉余量再占一只手；每条功用线需要一手牵持、一手调度；当材料节点与功用线合计超过四项后，每多三项增加一手统筹负荷。所有数值均向下取整，结果为整数灵识点。

|布网示例|M|N|F|灵识需求|说明|
|---|---:|---:|---:|---:|---|
|两味入门网|2|2|3|8|两味材料，以通、行、聚完成一次汇流|
|三味配伍网|3|4|5|14|增加一份投料及两条配伍／稳定工序|
|五味高品网|5|7|8|24|基线角色的灵识全部投入，支持复杂配伍|

当前测试角色沿用24点灵识上限。布网阶段允许继续添加材料和线，但超出上限时，资源栏显示红色 `L需 / L上限`，且【开炉炼丹】不可用；玩家可删线、减料或换更省灵识的布网。系统不自动排队、削弱功用或偷删线路。灵识负荷与材料质量分开：高品功用效果更强，但不会仅因材料品级高就额外多占一只手。

### 3.2 负荷计算边界

- `M`按来源节点数算；`N`按总份数算。多份同物种材料放在同一节点，不增加物种数，但每三份超出首份的数量增加1点灵识负荷。
- `F`按有实际工作的功用线算，而不是按画面线段或全十二功用的目录数量算。未布置的功用不占灵识。
- 质量被分成多个批次独立加工时，各批是不同节点；如果这些批没有不同目标或时序需要，合并节点可省去灵识。
- 造诣不直接加灵识或降低本公式；灵识上限仍读取修士已有属性。避免同一造诣既提高丹阶、又重复抵消布网成本。

## 四、法力与自动火候

玩家只在开炉前看到并支付本炉法力总额。系统依材料数据中的品阶、加工表现、开炼档、适宜档和安全档，自动安排火候；玩家不需要逐息调火。

### 4.1 自动排程

1. 读取每批材料的开炼、适宜与安全窗口，以及结构是否需要先开。
2. 适宜窗口有交集的材料并炉处理；交集为空时，按适宜档由低到高拆成连续加工段，完成各段后再汇入炉口。每段只把当前材料组送入受火工位；未轮到的节点留在丹炉冷候区，已完成的药性送入炉口缓释区，因此后续升温不会反烧前一组。冷候区与缓释区是炉内固定工位，不额外占一个功用槽。相同条件采用相同分组与顺序，保证可复现。
3. 每段选交集内最低适宜火候，以保证适宜加工并控制法力支出。若只能在开炼区加工，则使用该区规则；超过安全上限的排程不作为“赶工”选项。
4. 需要破壳的材料可由达到条件的“破”线开启；这可以省去单纯为开壳而升温的步骤，但不取消后续材料本身的化炼温度要求。
5. 造诣、丹炉与火种共同限制后台可达火候。任何批次没有可达的安全加工路径时，预检点明材料及所需条件，不消耗原料和法力。

### 4.2 总法力算法

后台仍使用当前整数火候曲线，保留“升火按新档、守火按当前档、降火按降前档”这条已定规则。令上一息火候为 `H前`、本息为 `H今`：

```text
C(0) = 0
C(h) = ceil(h + h² / 4), h > 0

若 H今 > H前：本息耗法力 = ceil(C(H今) × η火)
若 H今 = H前：本息耗法力 = ceil(C(H今) × η火)
若 H今 < H前：本息耗法力 = ceil(C(H前) × η火)

整炉法力 = 所有自动排程息的本息耗法力之和
```

`η火`读取丹火数据；当前平火为1，柔火为0.85。后台升降仍按原规则每息一档，十息计一时辰。系统在开炉前算完整炉法力；法力不足时显示差额并禁用开炉，不能先扣原料再中途因缺法力停炉。基础流程不加入额外随机耗法力。

## 五、五行与阴阳进入同一张配伍账

材料现有五行与阴阳标签直接参与计算，不把它们当成丹方装饰。实际落入成品的药性用来算最终适配；功用线之间的方向关系影响工艺效率。

### 5.1 丹种目标五行

每个丹种配置固定目标五行向量，五项合计100%。本案给现有三种测试丹一组首轮目标，供测试与校准：

|丹种|木|火|土|金|水|设计意图|
|---|---:|---:|---:|---:|---:|---|
|九品回春丹|55%|5%|10%|5%|25%|木为主，水助木，余行少量调和|
|九品通脉丹|35%|20%|10%|5%|30%|木水为主，火推动，土金少量约束|
|九品静心丹|10%|5%|30%|20%|35%|水土金偏重，配合其偏阴目标|

实际五行比例按成品内仍有效的药性来源计算；渣、逸散和只用于炉内工艺的绑定药性不计入成品向量。令实际向量为 `A`、丹种目标为 `T`：

```text
五行差异 D = 0.5 × Σ|A元素 - T元素|，范围0—1
五行适配分 E = floor(100 × (1 - D))
```

如每项差10个百分点，`D=0.10`，五行适配为90分。五行适配计入“配伍协调”轴；投错某行不能靠额外总质量补回。

### 5.2 五行生克怎样改变生产线

沿用当前炼丹节点网的方向判定，只在实际功用作用或药性输送时结算；不改写来源材料本身的五行属性。

|实际关系|首轮数值与用途|
|---|---|
|顺生|相应“化／行”工作量 × `(1 + 0.20R)`；推动药性顺势转化或流通|
|回生|仅限真实闭环回流；来源节点后续可恢复损伤增长 × `(1 - 0.10R)`，不倒运质量、不抹旧伤|
|制克|目标五行活跃贡献超过60%时，压低超额部分的活跃强度；单次最多压低超额的`25%R`|
|受克|相应来源的功用作用／流量 × `(1 - 0.15R)`|
|同气或无五行|不加减倍率；仍按实际流入改变成品配比|

`R`为本次接触双方真实五行贡献中该关系的比例，所有关系比例合计不超过1。复合倍率总截断在0.70—1.25，避免多个相生关系连乘成指数收益。五行的生克用来优化工序、校正过盛，不凭空生成或删除药性质量。

### 5.3 阴阳偏向与相激

阴、和、阳分别记为`-1、0、+1`。成品阴阳值按实际药性加权：

```text
Y = (阳性有效药性 - 阴性有效药性) / 全部有效药性
```

三种测试丹沿用既有目标和容差：

|丹种|目标Y|丹效20容差δ20|丹效100容差δ100|
|---|---:|---:|---:|
|回春丹|0|0.72|0.20|
|通脉丹|0|0.68|0.16|
|静心丹|-0.50|0.68|0.16|

容差随丹效目标 `q` 从20到100线性收紧。令 `d=|Y−Y目标|`：

```text
Y轴允许的最高丹效 Q阴阳
= clamp(100 - 80 × (d - δ100) / (δ20 - δ100), 0, 100)
```

偏差不超过丹效100容差时，这一轴可到100；偏差达到丹效20容差时，这一轴最多20；超过丹效20容差则不成可用丹。这样目标容差与最终品质有唯一、可复算的换算。

相反阴阳药性只有在真实汇合时才相激。设进入丹炉口同一汇流节点的阴、阳有效药性分别为`m阴、m阳`，总有效药性为`m总`：

```text
初始躁动 Z0 = min(100, 200 × min(m阴, m阳) / m总)
镇摄后 Z = max(0, Z0 - min(60, 10 × 镇的有效工作量))
```

`Z≤60`不造成额外损伤；`Z>60`时，失稳损伤为`(Z−60)/4%`，最高10%。`护`先抵挡实际损伤，`生`只修复仍可恢复的能力损伤，不恢复已逸散、化渣或离炉的质量。阴阳接近丹种目标仍是成品要求；“镇”解决的是相激风险，两者不是同一个指标。

## 六、十二功用在自动炉程中的岗位

十二功用仍是节点网上的实际操作线，线名就是玩家布置的工序。玩家可以只选本丹需要的功用；十二项目录不常驻挤占画面。功用品级沿用现有非线性强度表：九品至一品依次为`1、1.65、2.9、5.4、10.7、22.6、50.9、121、304`。原有功用工作量、来源消耗、上限和保存规则继续从[初始数值表第5—7节](炼丹节点网初始数值表_20261018.md)读取。

|功用|节点网岗位|自动运行中的可观察结果|
|---|---|---|
|破|开启数据明确标记的壳层或结构|节点外壳裂开；减少为开壳而额外升温的需要|
|化|把已处理原料转成可用药性，或解除真实附着|可用药性增加、附着减少；不凭空增加质量|
|通|在两节点间建立稳定的药性通路|线保持接通，提供可用通路容量；本身不冒充实际输送量|
|行|沿已有通路搬运药性|来源减少、目标等量增加；受通路、行力和目标空间限制|
|引|按丹方缺口决定多条可用去向|分支药流自动偏向尚缺的核心／辅功，不需玩家填百分比|
|聚|把到达炉口的有效药性归并为丹团|所有成丹都要有一条有效“聚”线；炉口只收集，不会自动替玩家凝成丹。复杂丹种可在此形成丹胚|
|固|维持丹团与药力结构|真实结构稳定上升；达到需求后该线停止投入|
|镇|压低阴阳相激产生的躁动|炉口躁动下降；没有躁动时不消耗来源药性|
|护|抵挡热伤、冲撞或相激的实际损害|损伤结算前显示吸收量；没有威胁时不预扣药性|
|生|修复可恢复的功用能力损伤|受损保存能力恢复；不增加材料质量或恢复已经失去的药性|
|明|辨出有效药性与渣滓、杂性之间的差别|分离度和可入丹的有效部分提高；已知信息本身不收费|
|藏|覆盖易逸散的有效药性|覆盖部分逸散率降至原值的10%；覆盖本身占用真实来源与灵识|

`通`负责让路线存在，`行`负责把药性送过去；二者不互相替代。基础炼丹可以使用自动炉口汇流完成，不要求每名玩家先做闭环。功用线在目标达到、来源不足、路线失效或材料耗尽时自动停止；无目标就不扣料。

## 七、成丹质量与“多味药才能出高品”

最终仍分三轴计算，每轴0—100，成丹分为三轴最低值：

```text
丹效 Q = floor(min(主药发挥, 配伍协调, 丹体稳定))
```

|丹效|结果|
|---|---|
|0—19|未成可用丹|
|20—50|薄效|
|51—75|良效|
|76—90|优效|
|91—100|极效|

### 7.1 高品质的配伍门槛

三种测试丹保留已有的丹种专属辅助功用要求。需求只在超过对应起点后逐步增加：

```text
需求(q) = N × ((q - q0) / (100 - q0))^1.15 × S目标丹阶
仅当 q > q0 时计算；q≤q0时需求为0。
```

|丹种|超过50分开始|超过65分开始|超过75分开始|
|---|---|---|---|
|回春丹|固：100分需3|化：100分需4|藏：100分需3|
|通脉丹|固：100分需3|行：100分需4|护：100分需3|
|静心丹|固：100分需3|藏：100分需4|明：100分需3|

九品丹的`S目标丹阶=1`；更高丹阶沿用目标丹阶非线性表。实际辅功只读取被保留在该颗丹中的真实有效药性；同一部分不能既用于工艺、又满额提供丹效。材料功用品级使用上一节的非线性强度，不把材料品阶和功用品级混为一项。

### 7.2 有效药材种数门槛

高分必须由不同药材共同支撑，不允许拆同一味药、重复多投或堆无关材料绕过：

|目标丹效|至少需要的不同药材种数|若主药占一味，至少需要的不同辅药|
|---|---:|---:|
|20—50|1|0|
|51—75|2|1|
|76—90|3|2|
|91—99|4|3|
|100|5|4|

一味药只有在其有效来源实际进入该颗丹，并至少满足下列一项时才计入种数：提供该丹种的核心／辅助能力需求，或使最终五行、阴阳适配分至少提高1分。重复同种材料不增加种数；进入炉中但没有贡献的药材不计数。每一项高分仍须满足相应辅助功用需求，种数不能替代功用。

此规则让不同阶段自然需要更多搭配：入门丹可以只靠主药做到薄效；良效至少要一味有用辅药；优效、极效逐步需要三至五味真实互补。扩大投料量只能提高有效供给或延长加工，不会自动提高种数或分数。

## 八、复杂炼法的边界

**简单炼法**：材料经功用线加工后汇入丹炉口，由有效“聚”线聚成丹团并自动凝丹；缺少“聚”时本炉没有成丹，药性按结果账留作未成丹去向。网络为有向无环图，不要求闭环。三种九品入门丹、十二功用基础教程都按简单炼法设计。

**复杂炼法**：丹种或后续正式丹方明确标记“需回炼”；网中必须有至少两个实际材料节点参与的有向闭环，回流后必须产生可观察的能力保存、杂质分离、结构变化或五行制化结果，并有明确停止条件。节点环本身不产生质量，不自动加分；不得用无限绕圈替代真实工序。

复杂炉程首轮最多回炼3轮，或在目标提前完成时停止。`聚`将炉口丹团凝成丹胚，闭环只让丹胚接受有来源的后续处理；`固`负责最终稳形，`引`只对实际缺口调度。基础九品丹不需要这些额外复杂条件。

## 九、造诣、九品入门与上手节奏

- 丹道造诣决定可炼丹阶门槛，继续沿用当前非线性门槛：九品8、八品18、七品36、六品65、五品110、四品180、三品300、二品520、一品900。
- 造诣也限制后台可达火候：`A≥8`时上限为`1+floor(A/20)`，再受丹炉与火种上限限制。A36可达0—2档。
- 灵识上限独立读取；法力是每炉支出；造诣是资格与可控范围。三者不互相折算。
- 九品入门教程从空网或预置两味网开始，先教“通—行—聚”的一次汇流，再分别讲十二功用对实际结果的改变。教程不要求玩家逐息盯火，不保证每次都是高品质丹。
- 当前版本不开放书籍技巧。高级功用的效力来自材料原有功用、功用品级与造诣资格，不需要额外技能树。

### 教程顺序

十二个单项教程各自从可复现的初态开始，只改变一条目标功用线，并让玩家对照节点状态或成品分数。进阶课再把多条线、资源预算与相性合起来：

|教程|演示重点|
|---|---|
|破|同一带壳材料，用线开壳与自动高温开壳的差别|
|化|同一批原料，可用药性与附着减少量的变化|
|通|建立真实路线，但节点药性尚未移动|
|行|沿已建立路线输送等量药性，核对起点与终点|
|引|在两个真实缺口间按丹方需求分配药流|
|聚|多股来料在炉口归并，形成同一丹团|
|固|同一丹团在稳形前后的稳定分数|
|镇|让阴阳相激确实发生，再比较镇摄前后的躁动|
|护|在实际热伤或冲撞发生时抵挡损失|
|生|修复可恢复的能力损伤，确认质量不增加|
|明|分辨有效药性和渣滓，观察分离度与成丹含杂|
|藏|比较易逸散药性被覆盖前后的保留量|

进阶课依次为：①同一布网的灵识拆账与超限改线；②不同材料窗口如何自动拆段、整炉法力如何预览；③五行顺生与制克如何改变有效工作；④阴阳目标、躁动和镇摄的区别；⑤两味至五味如何跨越薄效、良效、优效、极效门槛，以及闭环丹胚何时才有必要。教程不加入逐息按钮、书籍技巧或纯数值猜谜。

## 十、界面需要直接回答的问题

节点网仍是画面主体：保留丹炉与炉口汇合的视觉关系，不加暗框背景。材料节点上只显示图标与名称；功用名显示在线上。点击节点显示可常驻／再次点击取消的详情栏，悬停不弹信息。玩家可自由拖动节点，右键关闭网面。

开炉前常驻资源栏只显示灵识与法力：`灵识 本网需求 / 当前上限`、`法力 整炉需求 / 当前可用`。点击节点或开炉预览后，再查看材料数、额外投料、功用线、统筹负荷、预计用时、配伍预估、五行／阴阳偏差和具体阻塞原因。不能开炉时按钮禁用，并在预览信息栏指出超限项或不可加工的材料。

十二功用名只在线上以及节点的点击详情中出现，不占用常驻总览区。运行结束后显示实际分数和药性去向，不把预测值伪装成已发生结果。

## 十一、验收例与计算

### 九品回春丹，目标91分

至少要四种不同药材，即主药加三味有效辅药；还要实际满足`固、化、藏`三项对应需求，并使三轴、五行与阴阳都支持91分。假如布网有4个材料节点、4份投料、6条有效功用线：

```text
L需 = 4 + floor((4-4)/3) + 2×6 + floor((4+6-4)/3)
    = 4 + 0 + 12 + 2
    = 18
```

基线24点灵识可以运行，保留6点余量。换成单味主药或加入不贡献的辅药，不能达到91分；加一条确有作用的功用线后，灵识需求增加2点。

### 九品回春丹，目标100分

至少五种不同药材，即主药加四味有效辅药；固、化、藏分别达到3、4、3个九品有效能力单位；五行向量完全匹配首轮目标、阴阳偏差不超过±0.20，丹体稳定和核心发挥也须满分。若5个材料节点、7份投料、8条功用线：

```text
L需 = 5 + floor((7-5)/3) + 2×8 + floor((5+8-4)/3)
    = 5 + 0 + 16 + 3
    = 24
```

基线角色刚好能维持整张网。想再多加一条线，必须先减少其他负荷或提升角色灵识上限；多放一味无关药不会绕过种数、功用和五行要求。

## 十三、实现验收条件

1. 两名玩家使用相同材料、角色、丹炉和布网，得到相同的灵识需求、火候计划、法力需求和结果。
2. 增加一味不同来源材料会增加材料节点负荷；增加投料份数会按每三份额外投料增加负荷；增加实际功用线会增加2点并加统筹负荷。
3. 灵识超限或法力不足时，开炉前明确阻止且不扣料；资源足够时开炉一次后自动完成。
4. 简单九品丹不要求闭环；复杂炼法需有真实回流目标、变化和停止条件。
5. 主药单独最多薄效；51、76、91、100分分别要求2、3、4、5种有效药材；重复物种、拆批、无效投料不能绕过门槛。
6. 十二功用分别有不同对象和可观察效果；无目标、不足来源或目标已完成时不扣药性。
7. 五行关系只改实际操作效率与制化效果，不改材料身份；五行最终比例与阴阳目标真实影响配伍轴／稳定轴。
8. 药性、绑定结构、损伤、渣滓、逸散和成品之间来源守恒；同一份能力不能重复支付或重复计分。
9. 火候计划始终处于造诣、丹炉和火种允许的安全范围；整炉法力计算与后台实际计划逐息一致。

本案现在是可供验收的规则版本，尚无代码实现、运行模拟或平衡测试结果。通过验收后再以此替换当前自动跑炉主案，并进行实现与九品教学炉次校准。
