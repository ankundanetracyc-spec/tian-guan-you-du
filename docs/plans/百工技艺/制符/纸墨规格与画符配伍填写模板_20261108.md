# 纸墨生成字段与画符配伍填写模板

2026-11-08，配套用户已认可的[三工艺整体方案](符箓三工艺深度整合与画符配伍方案_20261108.md)。本页统一后续填写口径，避免纸墨生产、购买品、画符与界面分别定义不同能力。它是策划资料模板，不表示已有运行接口或正式成品。

本轮字段与阶段因果已在[三工艺完整规则方案](符箓三工艺完整规则方案_20261108.md)形成细案。此模板用于统一字段结构、生成口径与每批实际结果；已明确的规则不再当作空白问题重新推倒，未标定数值也不以示例填满。

用户最新限定主墨源为致密、颗粒、液体，黏胶仅作可选辅料，纤维退出研墨；液体可直接制墨，不要求固体配料。填写实际墨基、标准份量与来源时应覆盖液墨路线，不再另外填写浓度属性。

空缺写“待定”，不能用零、无限或任意示例代替；尚未填写完整的规则可供策划讨论，不参与正式生产与结算。原料继续只读现有质地、功用及品级、五行和实际份数，不因本页模板新增原料字段。

## 一 纸墨生成结果的共同资料

本模板对应每张纸／每份墨的结果结构，不要求预先建立有限纸种、墨种。原料和方法生成字段；同批均质时可以共享一份结果，数量分别消费。

| 项目 | 填写内容 |
| --- | --- |
| 身份与版本 | 基础类别、显示名、结果字段结构与生成规则版本；名称不决定能力。 |
| 普通物品资料 | 图标、占地及说明等沿用物品资料；实际五行与保留功用来自真实结果，不凭名称补值。 |
| 标准单位 | 本张纸／本份墨的实际数量口径。具体单位待统一，不由各页自定。 |
| 保留功用 | 最多四项实际功用，各自品级、标准单位可调用支持及真实来源。不可只填一个万能总量。 |
| 结构与调用边界 | 哪部分形成自身能力，哪部分还可供画符调用，哪些已用于加工或损失；同份来源不重复计满额。 |
| 生成规则与本批结果 | 真实成形条件、工法、分张／分份及字段计算口径；本批实际字段、数量与残余，不查预设产物降规表。 |
| 显示 | 简要说明和完整字段详情，比较实际能力；程度描述不变成固定品种。 |
| 现成来源 | 购买、委托或其他途径提供同结构的已生成纸墨；具体供给与价格另配。 |
| 保存与合并 | 冻结结果快照；影响画符的字段与版本一致才可合并数量，不仅按定义或名称合并。 |

自制品、购买品按实际数据同等使用。画符读取这张纸／这份墨的字段，不回查制造者、旧原料或制作历史补加能力；生成字段与库存适配尚未接游戏。

## 二 每张符纸的玩家字段

| 项目 | 生成与展示需要明确什么 |
| --- | --- |
| 灵性 | 灵力层次的单项表达，怎样与现行品阶显示统一并软性适配；不独立再乘万能倍率。 |
| 承墨量 | 每张实际纸基与组织能承接多少墨，采用何种统一结果单位。 |
| 渗墨性 | 更偏表面还是容易渗开，怎样与墨的流动、附着及技法配合；不以高为一律更好。 |
| 韧性 | 结构保持、损伤与工法怎样形成抗受损和断纹的能力。 |

均匀、连接、损伤、封存支持等后台资料另记；纸面精细不回到主栏。字段数量不代表后台只有四项，完整数据仍按真实来源与实际工序生成。

## 三 每份符墨的玩家字段

| 项目 | 生成与展示需要明确什么 |
| --- | --- |
| 功用 | 最多四项真实保留作用；来源品级与支持分层另存，可详细查阅。 |
| 灵性 | 作用来源层次的单项概览及归纳口径，不平均实际品级，不以少量高品覆盖全份。 |
| 浓淡 | 实际墨基相对配液的集中程度，来源分配与墨量同步记录；不由功用品级直接计算，也不单独乘威力。 |
| 流动性 | 铺展与接续的倾向，怎样与纸和笔配合；不以高为一律更好。 |

每份墨量与库存份数另记；附着、凝定、均匀与实际损失可以保留后台，真正影响本次搭配时给出简短原因提示。主栏不展示整张换算表，也不暗中抹掉这些差异。

## 四 一份画符配伍的填写内容

玩家必需项为符谱、实际纸墨笔、投入上限与一种写法，可沿常法。以下辅纹、分配和自动应变是可选进阶配置，后台展开为同一份执行方案，不是每次必填的多个控制栏。字段形成及真实材料例子见[完整细案](符箓三工艺完整规则方案_20261108.md#十五-用现有材料说明原料是真的产物数值不虚填)。

| 项目 | 需要记录与核对什么 |
| --- | --- |
| 符谱 | 已学符谱、固定主纹、必要作用来源与允许完整成品；不要求先采用有限符式。 |
| 符纸 | 所选纸的实际字段与投入上限。 |
| 成品墨清单 | 各份实际生成字段与预留数量，可单墨或多墨；不是三个必填墨岗位。 |
| 工艺辅纹 | 从符谱允许项中选择，逐项注明解决的问题、需要的来源、占用与工作代价。 |
| 实际符笔 | 承墨、出墨均匀、聚锋精细、运锋、收锋等能力及实际快照，不把造笔原料再当符墨。 |
| 主技法 | 已学方法、当前适用条件、改变的执行方式、实际代价；不与其他方法重复叠算。 |
| 分配策略 | 主纹、连接、护纹、封符的高层取舍与真实预留；不提供逐笔配墨或任意百分比滑杆。 |
| 应变策略 | 真实工况出现时允许的处置及实际资格、余量、用度；无有效策略时等待玩家。 |
| 冻结条件 | 纸墨结果及公共参数版本、本次符道造诣、已学资格及工具条件。执行时仍重核人物与真实资源合法性。 |

主辅纹和方法配置改变的是制作过程。若需要改变战斗目标、费用、持续或其他效果，须回到对应符谱和卡牌规则另行定义，不能塞入配伍资料暗改。

## 五 画符阶段的共同记录

| 阶段 | 输入与实际去向 | 需要给出的结果 |
| --- | --- | --- |
| 准备核验 | 库存、资格、纸墨笔与用度，明确本批预留。 | 合法工作单或真实缺项；失败零消耗。 |
| 取用与配墨 | 已启用标准份的墨量及各来源；混用只形成这批状态。 | 本批可用量、接触与处理损失，不生成库存新墨。 |
| 主辅纹成形 | 实际送达、连接、结构支持与主效分配。 | 已成纹部分、实际损伤、已用与尚余来源。 |
| 识势处置 | 当前真实问题、已学方法、实际剩余支持。 | 继续、处理或收束的本次变化与代价，不倒算已完成纸张。 |
| 收口封符 | 已有主纹、纸的实际留持条件、实际剩余固、藏等支持及笔的收锋条件。 | 真正留下的术式、损失与未成符原因。 |
| 逐张验收 | 该张实际得到的完整支持与符谱条件。 | 固定成品及已有符效档，或未成符；不附随机词条。 |
| 批次结束 | 实际已用、未启用预留、明确残余、精力工时等。 | 一次提交的结果与制作记录，不重复扣料或发物。 |

这些是共同结算口径，不是要求玩家逐阶段点击的页面流程。各阶段数值与真实消费边界在实现前统一标定；跳过演出不能代选未决抉择，也不能跳过必要结算。

## 六 继续细化的顺序

1. 明确字段与预算的单位、纸墨生成规则和允许工法，校验新材料自动匹配及相同字段的自制／购买品同质。
2. 定义符谱工艺、可选辅纹、混用成品墨与主技法的共同分配，避免每项各叠一次增益。
3. 补实际笔的能力映射、造诣驾驭、真实识势和封符要求。
4. 用真实材料与完整配伍标定阶段损失、效档、数量和用度，检查不同方案各有适用。
5. 根据同一资料修订界面、接正式库存与领取，再验证完整制作闭环。

整体方向已确认，以上待填内容不重新打开已认可的三工艺分工，也不以某个未定数字阻止其他不依赖它的资料整理。本轮完成模板及文档衔接，尚未运行新的工艺或游戏测试。
