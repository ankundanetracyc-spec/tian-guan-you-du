## 布局与现有界面的关系

沿用炼器当前灰米主面板、灰青材料卡、深绿选中和主按钮，以及实际字体、纸纹和数量控件阅读方式；参考炼丹的规格／材料选择与自动工序，不照搬丹方材料名单或制造数值。顶部在“制符纸／研墨”之间切换，右上角使用全局“返回＋实心右三角”。

左栏是本批材料，每张卡含实际图标、名称、五行、质地、可用演示库存、功用及品级、份数增减和移除。中央展示凝纸／融墨意象、目标名称，以及本批用途摘要和五行关系；右栏集中目标规格、灵力品阶、五项工艺字段、工法、用度和开始按钮。规格、字段含义和完整配伍解释通过点击查看，准备页不铺开内部预算。

## 两页各自的重点

| 内容 | 制符纸 | 研墨 |
| --- | --- | --- |
| 接收质地 | 纤维、液体、黏胶；不接致密／颗粒／气体。 | 致密、颗粒、纤维、液体、黏胶；不接气体。 |
| 中央意象 | 悬纸、纸脉渐生与灵丝交织。 | 墨气回旋、诸蕴相融。 |
| 用途摘要 | 纸基、调和、固形。 | 墨质、取蕴、调和、定性。 |
| 灵力字段 | 承灵品阶：承受灵纹负担的能力。 | 灵蕴品阶：实际留存灵性的层次。 |
| 五字段 | 承墨量、渗墨性、纹面精细度、承纹稳定、封存适用。 | 每份墨量、浓度、流展性、附着性、凝定性。 |
| 额外展示 | 工法围绕养脉、凝纹和叠脉。 | 目标功用留存与“有来源／缺来源”独列，和书写墨性分开；工法围绕融灵、澄灵和聚蕴。 |
| 自动过程 | 化材、蕴养、凝纸。 | 化材、融灵、凝墨。 |

五字段始终标作“目标纸性／目标墨性”；不能把选定规格显示成当前材料必然产出的结果。渗墨、流展与凝定采用有方向的定性文案，不做五条越满越好的评分条。纸有封存适用，也不因此再赠送一份藏；墨的留存来源独立呈现。

灵力字段位于五项工艺字段之前，点击解释软适配；纸墨品阶不会与境界作固定换算。正式软适配模型待标定，当前不计算或显示“适合某境界”的结果，不增加境界或最低纸墨品阶的开始条件。

## 选材和交互

选材弹窗支持搜索、质地、五行和十二功用筛选；功用可多选，按任一命中浏览。默认仅展示适用材料，可切换查看不适用材料和原因。重复选择同种材料合并数量，点击材料本身打开物品资料；没有人工指定原料岗位。

目录从当前资源提取50项，制纸适用23项、研墨适用50项。这里只把现有三组材性和份数用于匹配；相性、品阶、描述、身份与图标不参与制造资格或收益。当前独立样稿为离线目录快照，正式接入时应从物品资源统一发现材料，不能维护名字特例。

更换规格会更新五字段、目标功用和兼容工法；不兼容方法可见但禁用。配伍册分工艺保存目标、工法和份数，载入重核本页演示库存；浏览器保存与人物存档隔离。准备完成后自动展示工序，无手描、手磨、节奏条或时机点击；跳过与正常结束到达同一鉴看示意，返回后保留本批选择。
