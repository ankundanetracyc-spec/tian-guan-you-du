## 一 原来三个墨的区别及调整

| 旧名称 | 原本想承担的工作 | 本轮调整 |
| --- | --- | --- |
| 主墨 | 给主纹提供术式来源。 | 每砚实际写到哪一笔，就给那一笔供墨；不设固定主墨栏。 |
| 辅墨 | 调墨、导通、隔离及修补。 | 加工材料直接进入具体墨砚；用墨的位置和时机由笔序决定。 |
| 封墨 | 收口、保存已经形成的术式。 | 封符是最后的笔法与工序，可以继续用原砚；不强制第三套材料。 |

旧分法按“主效、辅助、保存”分岗位，容易成为丹器投料模板。**新准备对象为符纸、符笔和自由配制的墨砚；独立玩法放在笔段、补墨点、干湿接续与叠写顺序。**

一砚可以完成整张符。另开一砚用于实际有差别的墨性或局部配伍，不限定为辅助或封口专用。砚多会增加调配、换砚、笔上残墨处理和操控工作，不普遍更优。

## 二 一张符的操作

1. 选择符谱、纸与笔，往第一砚放入材料和份数。
2. 查看符谱的笔段、必需接点、相隔位置和先后约束。
3. 在允许的位置安排提笔补墨；有多砚时，指定每段蘸哪一砚。
4. 安排趁湿行笔或候底纹定形后行笔，按符谱允许的依赖调整部分笔段先后。
5. 提交后自动研墨、蘸墨、行笔、候干和收口；完成后鉴看实际成符与过程原因。

玩家做准备决策，不要求描线准确度、抢时间、按节拍或逐笔重复点击。等待和补墨由同一工序自动执行；跳过演出只揭晓同一结果。

## 三 制符独有的三个取舍

### 连写与提笔补墨

笔能承接的真实墨量约束连续笔段。连写可减少提笔接缝，但长段可能到末端供墨不足；在允许接点提笔补墨，可以恢复笔上实际可用墨量，同时增加接笔、工时与墨的支出。

补墨来自对应墨砚。笔上原有余墨、回砚部分及无法回收的残余分别记账，不能“补满”而不扣墨，也不能把整笔余墨无条件全额退回。换另一砚还要处理残墨夹带；具体可回收规则及系数待材料、笔档案标定。

长锋在长贯纹上可能减少回蘸；硬毫利于细接点；柔毫利于回环；兼毫用于较均衡的路线。它们改变能够怎样写，以及接缝和用度，成品不另加一层笔的战斗倍率。

### 趁湿接续与候干叠写

每处接点的“须相接／须相隔”由符谱规定，玩家不能为追求数值任意改成另一术式。干湿是墨迹在本次工序中的暂态，不新增全局材料词缀、人物属性、成品耐久或保质期。

| 场景 | 趁湿行笔 | 底纹定形后行笔 |
| --- | --- | --- |
| 要相接的接点 | 可借尚可接续的底纹搭接，但墨性冲突或铺展过量会串染。 | 需符谱允许的润接／搭接工艺，另用真实墨处理接头；等干本身不建立连接。 |
| 要相隔的交叉 | 需支持湿态隔纹的材料与笔法；湿线接触并不天然安全。 | 利于稳定底纹边界，但仍需相应定纹、辨线和隔纹能力；等干本身不保证隔离。 |
| 收锋封符 | 根据符谱处理尚未稳定的收口。 | 根据符谱处理已经定形的收口；不要求每张符一律湿封或干封。 |

候干增加真实工时，且可能让别处原本可湿接的窗口关闭。只等待需要的纹域，不能把整张纸统一设为干后获得全部好处。定形完成后继续等待不无限提高质量；等待不补墨、不消除配伍冲突、不代替缺失功用。

### 排笔序与换砚

符谱保留主干和依赖，部分独立支纹允许换序。玩家可以先完成需要湿接的部分，再处理必须稳定底纹的隔交；也可以利用允许的搭接笔法分段完成。两条路承担不同的墨、纸面、接点与工时要求，不能事先指定某条永远产量更高。

同一砚可以先写主纹、再写辅助笔段、最后收口。两砚也可以按墨性分别服务不同笔段。墨砚是实际配制批次，不是把同一材料的能力复制到多个槽位。

## 四 材料真正改变什么

沿用五行、质地、相性、功用及品阶，不新增一套共用材料标签。制符加工档案从这些已定义性质和真实份数，确定能否成墨、可用墨量、铺展与附着、定形过程及接续适用；缺档案不能默认为可用。

“浓、润、容易铺开、较易定纹”等是本工艺计算结果的描述，不是从名字猜出的材料特效，也不先写成未经标定的通用属性分数。样稿不伪算这些值。

以下是要落地的定性取舍，具体曲线尚未标定。它们描述一砚墨在不同方面的表现，例如偏润与定形较快可以组合；不是三种必选墨或新的材料词缀：

| 实际墨性表现 | 适合解决什么 | 随之需要处理什么 |
| --- | --- | --- |
| 偏润、铺展较快 | 长贯纹与回环中的连续铺开。 | 窄线和交叉处更要控制边界，兼顾纸的渗化与笔锋。 |
| 偏凝、铺展较缓 | 细接头、急折与局部落点的控制。 | 长段送达及断续接笔，需要相应承墨、行与润接安排。 |
| 底纹较快定形 | 较早进入后续叠写工序。 | 可趁湿接续的窗口较短，需要先完成接头或另做搭接。 |

没有“攻符永远用凝墨、护符永远用润墨”的固定归类。同一符谱可以依据笔、纸、接点与允许笔序，研究不同的墨性路线。

- 只有更多有效来源、能被纸与笔承接并实际送到正确纹域，才可能提高成符档位或数量。
- 用液体或化来帮助分散，需要真实加工规则；加液体不无条件延长全部湿接窗口。
- 胶质和固的作用取决于实际附着、铺展与定纹，不能普遍理解成胶越多越好。
- 五行、相性在真实同砚、接笔及相邻纹域发生关系，不用整批平均把局部冲突抹去。
- 墨砚是本次制作的中间数据，首版不因此新增可交易的随机墨液物品。

## 五 十二功用落到笔纸工序

十二功用继续全部保留。下列为制符中的职责细化，实际强度和适用由加工档案及来源分账决定；不是要求每张符凑齐十二项。

| 功用 | 在新玩法中的具体落点 |
| --- | --- |
| 破 | 研取允许打开的致密原料；已用于研取的份额不再次全额进入主纹。 |
| 化 | 将允许分散、炼化的实际原料调入墨中；与破共用真实残余账。 |
| 聚 | 在需要的主纹局部集中已有墨中来源，增加纸与笔的局部承接要求。 |
| 行 | 沿本次笔段铺展、送达已有墨量；笔内缺墨或断路时不凭空补足。 |
| 引 | 使落墨沿允许的走向和分岔进入指定纹域；与笔序及笔段去处相连。 |
| 通 | 使合法接头真正连通；湿接和干后搭接都需要实际条件。 |
| 固 | 支撑落墨结构与底纹定形；过早失去可接续状态也可能增加搭接工作。 |
| 明 | 澄墨、辨线及交叉边界，减少夹带和串染，不限制玩家查阅信息。 |
| 护 | 隔离相邻纹域和接点干扰；底纹干燥也不使护自动失去或免费替代其作用。 |
| 镇 | 处理相激与接笔会聚的真实不稳定，未发生问题时不额外产出。 |
| 生 | 从真实预留或未用墨中补接允许修复的细缺；失效整符不免费重画。 |
| 藏 | 在收锋封符时保留已经形成的术式，继续使用同一砚也可以发挥。 |

与丹器的区别在于：材料能力要在**纸上某处、某一笔、某种干湿与先后条件**下真正发挥，而非每个材料岗位各交一份功用总和。

## 六 两种符的设计例子

### 炎矢符：长贯纹与细折接头

长段用墨、转折落点和聚集处承载是主要取舍。可先完成需要湿接的折纹和接纹，再叠写需要隔离的旁纹；也可在允许接点分段补墨并处理搭接。长锋与硬毫分别解决不同问题，换笔不代替缺失原料或封存能力。

赤纹燧石、朱阳花籽、灵石、灵泉露、石蜂蜡仍仅为核过材性的参考投入，本轮不宣告该组合能成墨或必成某档。它们可以放进同一实际墨砚；有局部混配需要时才另开砚。

### 护身符：回环闭合与内外隔线

回环要求末端能接回预留接头，内外纹又要保持规定关系。可以利用柔毫组织较长回环，或用硬毫分段接环并承担更多搭接工作。先完成要相接的部分，再处理需要底纹稳定的隔交，是一种可研究路线。

玄甲薄片、石蜂蜡、青木芯、清音玉片、雾心菌核继续只作材性参考。护用于主纹作用的份额，与用于工艺隔离的份额分开；不会附送第二层战斗护盾。

两个符种的固定战斗用途不变。新的笔序不会自动生成灼烧、治疗、破甲、反伤或其他未定义战斗词条。

## 七 界面修订

沿用丹器的材料阅读、中央工作场景、右侧用度和统一素材风格。

- 左侧由四个固定岗位改为“符纸／墨砚”。墨砚可新增，分别配料；材料可在砚间按真实份数移入，不能一键复制完整投入。
- 中央案面保留符纸与笔砚，底部显示真实笔序。选择笔段后在放大的符纸上定位，设置墨砚、补墨、干湿安排，并在允许范围内前移／后移。
- 每笔明示符谱所需的相接、相隔或收口关系；不显示预计成品档位、成功率或补料答案。
- 右侧核对整批真实选材及本次用度，墨砚数量、补墨与候干次数为客观输入；未定用度继续显示“—”。
- 演出依当前笔序显示蘸墨、候干与运笔。演出时长只作演示节奏，不能当作正式游戏工时。

准备草稿支持即时调整及本次会话保存。正式开始仍需冻结输入，核对符谱、纸笔、加工适用、库存、接点几何、笔序依赖及已定义用度；合法尝试的过程成败由完整结算器决定。

## 八 本轮范围与验证

本轮修改正式策划文档和隔离界面样稿，不改丹器结算、材料资源、符箓战斗卡、人物或存档。新提出的干湿、搭接、笔上残墨及等待工序是制作规则候选，须补齐加工档案与参数后才能接入真实结算。

样稿验证限于：自由配砚、跨砚移料守恒、笔序依赖、每笔墨砚／补墨／干湿安排、会话保存与恢复、演出状态、两档窗口布局及素材加载。实际墨量、定形曲线、成符档位和数值平衡不以浏览器交互通过来替代。
