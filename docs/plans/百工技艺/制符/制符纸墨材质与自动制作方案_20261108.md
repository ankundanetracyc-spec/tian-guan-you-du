## 一 三个对象各有职责

| 对象 | 负责什么 | 玩家选择什么 |
| --- | --- | --- |
| 符墨 | 将实际材料中的术式来源调入可书写的墨，形成铺展、附着与封存适用。 | 同一批墨的材料和份数，可保存配伍。 |
| 符纸 | 作为有自身材质与功用的载体，吸附、承纹、导通并留存墨中来源。 | 已加工好的纸种与张数。 |
| 符笔 | 在选定纸墨之间承担承墨、落墨、细纹及回环工艺。 | 具有不同工艺适用的实际工具。 |

主墨、辅墨、封墨不再设为三个必填岗位。研墨、调墨、成纹和封存是同一次制作的自动工序，不需要玩家逐步确认。首版一批配墨完成一批同符谱的制作，不提供多砚分段分配操作。

符谱只确定要做哪一种符及其工艺要求。主辅纹、接点、蘸墨、等待和行笔路径交给既定符谱及制作结算；不存在玩家笔序、接点或湿接窗口的输入字段。

## 二 墨的区别在材料形成的墨性

沿用五行、质地、功用、相性、品阶。配制时通过各材料的制符加工档案，确定研取、分散、可用墨量、铺展、附着及相容；不是把功用品级相加直接当成符箓威力。

| 墨的加工方向举例 | 配伍特点 | 需要纸笔共同处理的问题 |
| --- | --- | --- |
| 矿粉入墨 | 致密来源先经过研取和分散，可能形成较凝的配制路线。 | 能否均匀铺开、附在有效纹层，细纹末端是否送达。 |
| 灵植入墨 | 可研取的植物来源与胶、露等材料共同形成配制路线。 | 纤维残余与夹带、纸面渗化、实际墨量与附着。 |
| 复合配墨 | 不同来源共同服务同一术式和成符工艺。 | 局部配伍、比例及处理负担，增加材料不必然提高产出。 |

这些是材料加工方向，不是新增的固定效果墨种；不因材料属矿、植或某五行就自动生成伤害、治疗或其他成品附效。每一种材料仍须按自身加工档案参与，缺档案不默认为可用。

偏润、偏凝、易铺展、较易附着等是制符过程的结果描述，不增加全局词缀，也不产生同定义随机纯度。定形快慢等过程可以参与自动结算，不显示为玩家时机选择。

首版调成的墨是本次制作的中间数据，不另外生成可交易的随机墨液。是否开放独立制墨物品另案处理。

## 三 符纸是参与配伍的载体

符纸自身具备实际材质和制符加工档案。它不只是统一的品质上限，也不单按颜色或价格分成必胜的高低档。

本轮建议先研究三类加工纸材，名称与性质均为候选，不代表已有物品：

| 候选纸材 | 想形成的材质差异 | 主要取舍 |
| --- | --- | --- |
| 草纤符纸 | 纤维较疏，容易吸入流动的墨。 | 用墨能进入有效纤维通路；渗入无效区域时则削弱清晰成纹。 |
| 韧皮符纸 | 组织较紧密，侧重表层承纹与结构保持。 | 较凝的墨仍需有足够附着与铺展能力，致密不等于自动接住全部墨。 |
| 蚕丝符纸 | 加工成长纤维细织载体，研究连续导通与细纹表达。 | 要处理墨在织面上的附着、渗开与局部聚集；不天然兼容所有墨。 |

上述纸种需要先补齐加工后的正式定义、图标和档案。原草、树皮或山蚕长丝不能直接当成已经制好的符纸。纸的功用及品级须按加工后的定义明确，不能从原料完整继承一份未扣减的全部能力。

纸可以提供已有的固、通、藏等工艺来源；具体哪张纸具备哪项，由自身定义确定。纸的墨承载与功用协同分别核算，不把“纸厚、纸贵、纸有灵性”直接当作全项增益。

## 四 纸与墨怎样互相影响

| 搭配情形 | 自动结算要回答的问题 | 玩家怎样调整 |
| --- | --- | --- |
| 润墨与疏松纸 | 墨进入了可用纤维通路，还是散到无效区域？ | 换纸、改变墨的配制与份数、换适合控墨的笔。 |
| 凝墨与致密纸 | 墨能否附着并均匀送到细纹，而非停留堆积？ | 改善实际分散和附着，或选更适用的纸笔。 |
| 局部会聚较强 | 纸的承纹、笔的供墨和墨的稳定能否共同承接？ | 适配纸笔，调整聚集来源与辅助材料的投入。 |
| 纸与墨均有通、藏等功用 | 各来源在导通、结构与封存中实际用了多少？ | 依据实际加工与成符记录调整材料，保留来源分账。 |

吸墨不是统一损失：只有进入本纸可用纹层、并实际参与导通和成纹的部分才发挥；渗入无效区域、脱附或未送达的部分记录为对应损失。低渗也不是统一优点，仍要完成附着与导通。

纸与墨中的五行、相性在真实接触与工序中作用，不平均抹去局部冲突。不规定某种符只能用某一种纸或固定一家墨料；同一固定符种允许研究多种材料路线。

## 五 符笔服务纸墨适配

| 笔型方向 | 自动制作中的职责 |
| --- | --- |
| 兼毫 | 常规纸墨与纹路的均衡承接。 |
| 硬毫 | 侧重凝墨落点、细纹与转折的控制；实际是否适用仍看纸墨。 |
| 柔毫 | 侧重较润墨的连续铺展和回环；细密边界仍需纸墨配合。 |
| 长锋 | 较长段的承墨与送达；是否减少回蘸由系统根据实际工艺处理。 |

玩家只选择笔，不指定笔段、回蘸次数或收锋时机。符笔影响实际送达、处理工作和用度，不提供额外主效果来源，不在同定义成品上再乘一次笔的伤害倍率。

## 六 十二功用继续使用

| 功用 | 自动制作中的作用 |
| --- | --- |
| 破 | 研取本材料允许打开的致密部分，已用于研取的份额不重复计入主效。 |
| 化 | 将允许分散、炼化的真实原料调入墨中，与破共用原料残余账。 |
| 明 | 澄清夹带并保持纹域边界，不作为玩家查阅信息的门槛。 |
| 镇 | 处理实际混配与局部会聚的不稳定，不无条件增加产出。 |
| 固 | 帮助墨附着、纸承纹及成纹保持，按真实来源与去处分账。 |
| 行 | 在本纸可用纹域内铺展、送达已有墨量。 |
| 引 | 按既定符谱与载体通路引向所需纹域，系统自动组织。 |
| 通 | 使纸墨形成符谱需要的有效连接。 |
| 聚 | 在允许的主纹局部集中已有来源，仍受纸笔承接约束。 |
| 护 | 隔离真实相邻干扰，减少扩散，不自动给成品增加护盾。 |
| 生 | 调用真实余墨或允许的预留材料修补微缺，不凭空修复整符。 |
| 藏 | 留存已经形成的术式，封符并映射到允许的固定成品。 |

同一材料或纸中来源用于结构、工艺和主效的分配之和，不超过实际可用预算。笔只是工具，不复制来源；增加纸张也不复制墨池，整批逐张支出。

十二功用不必集齐。材料、纸和笔是否解决本次真实问题，决定辅助投入是否有用；不是所有符都套四个固定投料岗位。

## 七 制作流程与成品

选符谱、纸、墨材与笔后开始，系统自动研取调墨、检查纸墨适配、落纸成纹、处理必要的接续和修补、收锋封存，最后揭晓实际成品和过程原因。人物造诣、资格与用度沿既有制作边界；具体曲线独立标定。

准备零扣料，开始前重核真实资格、库存及全部已定义用度。一次合法提交冻结同一批材料和纸笔；批次逐张使用有限墨，投入张数不保证全部成符。失败消费与领取仍须按既有候选一起定稿，跳过不重算、不重扣、不补发。

同符种同品阶的有限符效档仍对应固定定义；材料不随机拼战斗词条。无新定义时不自行生成更高伤害、额外触发或新的成品状态。

## 八 当前界面

- 左侧只有符墨和符纸两类选材。符墨选择实际材料与份数，符纸选择已加工纸材及张数，符笔在案面旁选择。
- 中央显示场景和只读纸墨笔摘要，替换逐笔编辑、蘸墨点、候干开关与笔序图。工艺知识通过详情查阅。
- 右侧显示本次客观投入与已定义用度；未定值为“—”，不预测成功率、符效档或合格张数。
- 顶部可切符谱、保存材料配伍；保存内容不含笔序、接点、干湿或分砚安排。
- 点开始后自动演示制作，期间只保留跳过，完成后鉴看。

样稿内三类纸材与纸面描述是候选夹具，不模拟已拥有的正式库存，不从当前墨材虚算出真实墨性。素材复用此前案面和纸笔，不改正式丹器页面。
