# 符箓三工艺候选参数与实装

2026-11-09，首轮规则版本 `20261109`。承接[完整规则主案](符箓三工艺完整规则方案_20261108.md)，用户已明确授权“同时拟定候选参数，接通完整制作”，并追加“让造诣参与这之中”。本页将原先未标定的单位、曲线、用度、初始知识及备置价格补成可调整的实装候选；不把这些首轮参数追记为此前已经批准的平衡数值。测试状态与原生图集由[接入说明](符箓三工艺原生接入_20261109.md)登记。

玩家仍只看材料、用量、已学技艺、相关配伍问题及用度。纸墨制作前不显示生成字段、品级或数量预测；实际制成入包后鉴看。纸为灵性／承墨量／渗墨性／韧性，墨为功用／灵性／浓淡／流动性。复杂计算留在后台，符谱最终效果固定。

## 一 实物、生成结果与保存

- 原料继续只有已有质地、十二功用及各自品级、五行集合、实际份数。目录递归自动发现；名字、描述、图标、总材评、相性和炼器档案不参与匹配或能力计算。
- 制纸只接纤维、液体、可选黏胶；纤维与液体均须有真实投料。研墨只接致密、颗粒、液体、可选黏胶；液体可单独调墨，固体墨须有液体，纯胶不能成墨，纤维不入墨。
- 同材性签名先合并份数。同字段异名、换添加顺序或将同一份数拆成多行，结果一致。每批投料最多64份，不自动补料。
- 制成纸墨均为同一共享字段结构下的生成物，不查“厚承纸”等纸种表。输出同批均质，冻结完整能力与版本；不逐张掷随机词条。
- 生成物保存为 `TalismanProductItemData`，能力快照在 `snapshot_json`。全部影响画符的数值、分品级调用来源、结构来源及真实五行份额共同形成能力签名。能力相同共用路径，制造者、批次和原料名称不入签名；加工履历写人物批次记录。
- 产品定义存于人物资料目录的 `talisman/products`。人物另保存“路径→冻结快照”副本；定义文件缺失时从保存结果恢复，不用当前造诣重新计算。纸墨类别为器具，不能退回裸原料目录补满来源再加工。
- 本轮采用原子直接入包：提交时重新检查用料、精力、灵识和真实空间；材料扣除、成品入包同时提交。空间不足时不扣料、不扣精力、不记成功、不推进时间。鉴看是已入包成品的查看，没有未领取物会因关页而丢失。

## 二 统一单位与来源账

一份带功用的原料提供一份来源预算。若原料有多个功用，这一份预算在它的真实功用品级层之间等分，不给每项各复制一整份。无功用原料仍提供真实纸基或墨基，但没有凭空的功用来源。

品级内部1为九品、9为一品；不按品级乘以数量，不平均品级，不把少量高品改记为全批高品。来源始终保存为“功用、品级、实际量”。同功用同品级才合并；分张后逐份均分，不复制整批能力。

工具先取得允许的基础部分：致密0.62、颗粒0.75、液体0.90、其余合法质地0.82。已取得部分的10%先支付处理；这部分不能继续调用。已取得的破、化、明、行所占处理量可帮助后段取得，上限0.06；未取得的功用不提前帮助自身。

后段取得率为：基础取得率＋`0.13×造诣系数`＋已付处理的有限帮助＋本次接触的相生帮助－相克损伤－复杂负担，限制在0.35至0.97。从取得量再扣已付处理，方法舍弃也照实扣掉携带来源的部分。

制纸将余量43%用于结构、其余保留调用；研墨将余量12%用于结构、其余在玩家选择的最多四项功用中保留，未选择部分记损失。结构来源不能在画符时再当作满额主效来源。物质纸基与这份法性预算分别记录，普通无功用纤维也不凭空消失。

每次报价和结算保留数值批次账：`原料来源总预算＝加工支出＋产物真实结余＋损失`。产物结余为全部张／份的调用来源与结构来源总和。产品自身只保存结余边界，批次加工与损失保存在本次记录，避免无关履历拆散同能力堆叠。先守恒再允许提交；不是只检查不超过预算。

## 三 符道造诣实际参与

直接读取人物现有 `talisman_proficiency`，本轮不新增人物资源。令 `p＝造诣／（造诣＋40）`，合法造诣下范围为0至1，不随造诣无限增长。

| 参与位置 | 首轮作用 | 边界 |
| --- | --- | --- |
| 纸墨取得 | 对既有来源的取得率最多增加0.13。 | 不增加新功用、不改来源品级，不能超过真实输入。 |
| 复杂配伍 | 可驾驭负担为 `1＋造诣／12`；超出的复杂度按每点0.025增加取得损失。 | 更多原料不是稳定全正收益。 |
| 加工效率 | 工时最多减少28%，精力最多减少24%。 | 仍须支付实际用度，不能刷零工时、零精力。 |
| 画符送达 | 有限改善已得来源的实际运送，最多贡献0.16。 | 只减少真实送达损失，不补缺少的主纹或收口来源。 |
| 行纹驾驭 | 对连接、收口、韧性负担作有限驾驭。 | 所有必要条件分别验收，不求平均掩盖缺项。 |
| 技艺学习 | 进阶工法有造诣门槛；人物仍须主动研习。 | 不因属性到了就自动学会全部技艺。 |

符道造诣不直接乘同档符箓伤害或护盾。换主人、打开详情或读档不再次计算纸墨。三工艺本轮不额外自动增长造诣，避免在尚未定义成长收益时靠反复制作刷数值。

## 四 五行接触

相生木→火→土→金→水→木，相克木→土→水→火→金→木。无五行合法但不参加生克，同行无额外奖励。

原料阶段，同签名材料组之间只处理本批一次接触。接触份额按双方真实量占全批比例共同限制；多行子对等分这一份接触预算。相生帮助对应接收对象取得，相克损伤对应接收对象取得；不把全部元素对子各算一份全额增益。介质、胶料实际流失部分不会把五行标签完整复制给成品。

产品保存实际留下的元素份额。画符用这份冻结资料，在新的一份墨真正入纸时结算：

- 每张纸有一次接触预算，随实际入墨负载占承墨容量的份额扣减；多行及两个方向共同分享。
- 纸生墨帮助该份的送达、纸克墨增加该份的送达损失；墨克纸形成真实纸伤。墨生纸只缓和这张纸已经存在的损伤，不给完好纸追加一层免费韧性。
- 新墨与尚未封持的既有墨分配有限调合接触；旧墨克新墨影响新加入来源，新墨克旧墨只损伤在场旧墨调用余量，不回头扣纸调用来源。每次新接触只处理新加入部分，旧接触不因回看再算。
- 多行按双方产品实际元素份额归一，不按元素数量复制加成。五行不会造出材料没有的功用或改写功用品级。

这些影响落到来源送达或实际纸伤，不给纸墨四栏统一乘一轮五行倍率。

## 五 制符纸：字段与方法

普通方法成纸数取真实纤维份数向下取整，最少1张。叠脉按0.65倍分张；减少张数后，每张实际分到的纤维与全部来源均重新计算。

| 字段／后台结果 | 实际依据 |
| --- | --- |
| 灵性 | 每张实际结余来源中，累计至少0.20份支持的最高真实层次；不足为无品，不另乘威力。 |
| 承墨量 | 每张真正保住的纤维量、结构聚与通；过多胶结占用可开放的承接部分。受损失的纤维不能还按原始投料算承墨。 |
| 渗墨性 | 真实液胶关系与结构固、通、行；胶和凝纹偏封闭，连接开放偏易渗。不是越高越好。 |
| 韧性 | 实际保住的纤维、结合料、结构固／护／生及未驾驭负担。 |
| 连接／留持 | 结构通／引／行与结构固／藏／护分别形成后续行纹和收口条件，结构部分不会再次记入调用池。 |

| 方法 | 初始知识／门槛 | 实际取舍 |
| --- | --- | --- |
| 养脉 | 初始掌握。 | 分张与纸性均衡。 |
| 凝纹 | 主动研习，造诣8。 | 工时／精力倍率1.20，承墨×0.88、渗墨×0.72，韧性得到有限改善。 |
| 叠脉 | 主动研习，造诣18。 | 工时／精力倍率1.35，张数×0.65向下取整；每张真实纸料和来源更多。 |

## 六 研墨：字段与方法

基础可分墨份数取真实主墨源（液体＋致密＋颗粒）份数，胶不单独扩大主墨基。液体本份只有一次实体计数，可以满足液墨与液态调和条件，不记成两份。澄灵按0.80倍分份，聚蕴按0.65倍分份，向下取整最少1份。

| 字段／后台结果 | 实际依据 |
| --- | --- |
| 功用 | 玩家在实际已有功用中保留至多四项；取得、处理、结构支付后只保存剩余量。 |
| 灵性 | 沿纸的真实支持阈值归纳；实际仍保存各功用逐品级来源。 |
| 浓淡 | 主墨基相对液体的真实集中程度；聚蕴减少可分份数并提高集中。浓度不由功用品级求和，也不另乘战斗伤害。 |
| 流动性 | 实际液胶比、已支出的化／行／通调匀支持；与纸渗墨一起决定洇散条件。 |
| 附纸／凝定 | 真实胶结、结构固与镇等形成；附纸只处理送达损失，凝定只处理收口问题，不反复乘成万能品质系数。 |

| 方法 | 初始知识／门槛 | 实际取舍 |
| --- | --- | --- |
| 均研 | 初始掌握。 | 正常取得、匀调与分份。 |
| 澄灵 | 主动研习，造诣8。 | 用度×1.30，弃去14%已得来源，可分份数×0.80；流动与附纸改善。 |
| 聚蕴 | 主动研习，造诣18。 | 用度×1.25，收配损失10%已得来源，可分份数×0.65；留下来源向更少份数集中，承墨负载也增加。 |

## 七 画符、写法与封符

操作为选谱→选真实纸、墨、笔及一种已学写法→查看相关问题和用度→自动行符与封符→成品鉴看。基础两谱护身符、炎矢符作为本轮入门知识初始掌握，后续新增谱使用持久知识列表；不从旧雷击／爆炎资源复制旧数值。

准备数量是符纸投入上限。每种符墨选的是最多预留份数，提交只扣实际开启的整份墨；未开启部分仍在原库存。开启的一份墨可为本张主纹、连接与收口提供其真实来源，未用于升档的余蕴在本张收束中消耗，不退回原瓶、不跨张复制。本轮暂不开放残墨再调配。

必须先为本批每张逐一组成完整基础包，锁定主纹、必要连接与基础收口，才确认该张落笔。下一张不足则停止，未启用纸墨保留。凝毫聚势另走第二遍，只有全部基础包锁定后的真实余墨才能加势；不能为了第一张升档耗掉第二张基础用墨。试配余墨不能升既有档时不实际启墨。

| 基础谱 | 主纹／基础收口 | 额外条件 |
| --- | --- | --- |
| 护身符 | 护0.085份、固0.025份。 | 必要连接、韧性与收口同时成立。 |
| 炎矢符 | 破0.085份、藏0.025份。 | 实际火行支持不少于0.08份，及必要连接、韧性与收口。 |

五档需求倍率依次1／1.45／2／2.8／3.7；需要的真实来源最低品级依次九／九／八／八／七品。连接门槛为0.35＋0.055×档序，收口0.40＋0.045×档序，韧性0.38＋0.055×档序，档序从0开始。所有条件分别达到才取最高合格档，不将主效超额与缺失收口求平均。

常法不额外加负担。束墨留痕降低洇散限制但调用保留×0.90、用度×1.15；透纸行墨允许更多纸脉承接但损耗纸的韧性，并须从本张可调用来源实付通或行合计0.02份；匀铺长行改善连接但用度×1.25；凝毫聚势须实付本张可调用聚0.02份，调用保留×0.83、用度×1.30，且增加纸笔负担。技法支出从已经取得的实际余量扣除后，再验收主纹与收口，不凭固定工具底值补出缺失功用。进阶写法均须主动研习，造诣门槛依次8／12／15／25。

当前为确定式候选结算，不额外随机生成意外。因此已知配伍问题在准备时就可通过纸墨笔及写法处理，过程不强制弹三次问题。将来加入实际未决工况时再停在该节点，不能用动画或“跳过”按钮代选。本轮也不把尚未开放的辅纹、应变按钮写成已经可用。

封符是在既有主纹、真实来源、有效连接和收口同时成立后才生成固定成符，不用造诣或好笔凭空补齐缺失法性。最终效果统一读 `TalismanCombatCatalog` 与十份固定技能资源，固定伤害／护盾、体力费用、目标及使用条件见[符箓首轮战斗接入候选](符箓首轮战斗接入候选_20261109.md)，制作不保存隐藏战斗倍率。

## 八 符笔、学习与用度

符笔的制作仍归器物工艺，本页不新增造笔第四系统。本轮天工峰提供已制好的真实符笔备置，支付现有灵石实体并检查行囊空间，没有免费试用品或笔材功用每张白送。

| 成品符笔 | 灵石候选价 | 承墨／控墨／运锋／收锋 |
| --- | --- | --- |
| 青竹符笔 | 2 | 1.50／0.55／0.55／0.58，取向均衡。 |
| 静毫符笔 | 5 | 1.30／0.82／0.58／0.80，控墨、收锋较好，承墨略少。 |
| 藏锋符笔 | 5 | 2.20／0.48／0.76／0.54，承墨与运送较好，精控较弱。 |

笔承墨限制本张可启墨负载；控墨影响洇散及纸伤驾驭；运锋影响已有来源送达与连接；收锋影响实际收口。它们都不直接提供主纹功用，也不改变同档成符效果。更高价笔是不同取向，不是四项全高。

每项进阶技艺研习固定精力8、1时辰，需满足门槛并主动点击，学成记录随人物保存；已学重复点不再收费。基础养脉、均研、常法初始掌握。

材料工艺基本时辰为 `(0.22＋0.11×材料总份数＋0.08×复杂度)×方法倍率×(1－0.28p)`，精力为 `(2＋0.55×总份数＋0.8×复杂度)×方法倍率×(1－0.24p)` 向上取整。复杂度按额外材性组、额外功用构成，不能靠改名拆组获益。灵识为本次操作可用量要求，不作永久占用，也不另扣画符法力。

画符用度随真实完成张数、实际启墨份数、混墨复杂度及写法计算。所有时间统一沿现有世界历法推进，一时辰折两个游戏小时；用度成功提交后只扣一次。记录保存真实入料、实际生成、来源去向、已学方法与本次造诣，供后续平衡回看。
