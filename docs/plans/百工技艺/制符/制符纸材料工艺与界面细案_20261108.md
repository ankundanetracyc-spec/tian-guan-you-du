# 制符纸材料工艺与界面细案

> 纸墨制备的当前联合入口为[纸墨双工艺与字段自动匹配主案](纸墨双工艺与字段自动匹配主案_20261108.md)。本页保留制纸流程与界面；两工艺质地分工、十二功用用途／保留、墨字段形成及生克预算以联合案为准，不另建逐材料配方或原料字段。

2026-11-08，当前制符纸专题规划，承接[三工艺主案](符箓三工艺与画符技艺主案_20261108.md)和[纸墨笔字段规范](符箓纸墨笔字段与技法规范_20261108.md)。用户最新裁定：不增加原料字段，只用现有质地、十二功用及其品级、五行生克自动匹配材料；不逐材料编写用途或配方。

本版撤回结构模板、天然长短纤、完整膜片、原料粒度等接入要求。用户进一步明确制纸与研墨应各有用料侧重，单个小系统不必覆盖全部质地；制纸收束为纤维、液体和可选黏胶，致密／颗粒的研磨交给研墨。原料份数沿用实际库存；工法、工具和符道造诣属于本次制作条件，不成为新增材料属性。以下为公共规则候选，转换系数、规格值、用度与门槛待标定，未改正式资源或运行。

## 一 原料输入与统一抽象

制纸计算仅读取三组原料信息：质地、功用及其等级、五行。相性和材料品阶继续作为物品资料展示，但不参与本版制纸资格、损耗、费用或产物选择；材料品阶不再乘一遍供给。

份数是本系统归一化的投入单位，不解释成材料实际克重、纤维长度、天然孔隙或膜面积。每种质地怎样兑现一份投入，由同一份公共工序参数表定义，不为单个材料填体量、得率或难度。

所有纤维采用相同的基础成浆和成页规则。兽皮、长丝、枝叶等名称不产生额外膜基、细长纤维或其他例外；相同质地、功用等级、五行及份数，在同样制作条件下得到相同表现。

制纸过程可以计算可用纤维量、成页均匀、未解团块、胶层负担、连接与损伤等中间状态。这些状态由本批输入和操作推导，不储存为原料新字段，也不从名字、描述、旧材类、图标或炼器专用加工属性中读取。

符纸仍保留承墨量、渗墨性、纹面精细度、承纹稳定、封存适用五个产物字段；相同成品定义完全同质，不增加隐藏制作者倍率。

## 二 制纸与研墨的质地分工

本版制纸只接收纤维、液体、黏胶三类。研墨负责致密和颗粒的研磨成墨，也可使用液体和黏胶。两道工艺的原料可以重叠，各自采用自己的公共用途规则；不存在每道工艺都必须用齐六种质地的要求。

| 原料质地 | 本版制纸用途 | 研墨规划中的侧重 |
| --- | --- | --- |
| 纤维 | 主要纸基，提供实际纤维及其本有功用。 | 可选统一研取路线，提取真实功用来源入墨，不把纤维本体当成品墨。 |
| 液体 | 制浆、调胶和分散介质，本有功用参与相应处理。 | 调墨、分散和浓度配制，具体规则由研墨细化。 |
| 黏胶 | 可选胶结、施面和边界保持。 | 墨的结合、附着和定纹处理，不能因此替代墨料。 |
| 致密 | 本版不进入制纸候选。 | 墨料候选，先研碎再研细、分散与调墨。 |
| 颗粒 | 本版不进入制纸候选，不设置矿物填面路线。 | 墨料候选，从研细、分散和调墨开始。 |
| 气体 | 本版不接收。 | 暂无本轮确定用途；不为覆盖六类硬设捕获或凝液。 |

最基础的制纸输入为足量纤维和液体介质，加上相应工具与制作资格。黏胶是否需要、用于内部结合还是表面处理，由目标规格及工法决定；不强制每批加胶。

用途是计算结果，不是材料上保存的岗位。纤维可以同时带来纸基和实际通来源；胶料用于结合或施面时须统一记账，同一份实物不能在多个步骤各算一份完整投入。

基础工具可以解料、打浆、筛整和抄压，不要求每个动作都额外投入一味同名功用材料。制纸的打浆属于成页处理，不另设研碎矿物、研细墨料等研墨工序。

同类材料跨纸墨分别消耗。制纸保留纤维作载体，研墨的纤维研取只取本批实际来源；同一份不能既做满额纸基又做满额符墨。研磨完成程度是研墨过程量，影响研取、分散、后续墨性及工作，不是新增原料字段。

## 三 自动发现与分配顺序

1. 从人物真实库存发现普通材料，读取现有合法质地、功用等级和五行；无需加入制纸名单或推荐样方。
2. 按这三组输入归并同性质材料，并累计实际份数；名称、资源路径、相性及材评不影响分组和效果。
3. 按质地确定纸基、介质或胶料候选，结合当前目标、工法与工具检查可执行工序。
4. 先满足目标每张所需的纸基、介质及必要加工，再按公共优先级分配胶结、施面和实际功用；分配顺序由工法与规格统一规定，不让材料名决定先后。
5. 对每次真实接触处理生克，更新保留、损伤和剩余来源；再完成成页与定纸。
6. 用实际结构和保留来源验收固定纸规格，逐张分配，得到真实产量与残余。

身份只用于扣除正确库存、显示图标及记录来源。把同性质投入拆成多个异名材料，不能提高效果或绕过批量负担。原料仅有现成字段即可接入；字段非法须报明原因，不补一份制纸档案作为资格。

## 四 十二功用按实际工序发挥

十二功用在整个符工体系复用，各小系统按真实工序取用，不要求制纸把十二项逐一配齐。固、生、通、藏等更直接支撑成页与留存，破、化、明等也可在研墨的研磨、分散和去杂中发挥；不能为了某项功用而把不接收的质地塞进制纸。

| 功用 | 本版制纸中的公共作用 | 限制与取舍 |
| --- | --- | --- |
| 破 | 打散实际未解开的纤维结团。 | 不设置矿物研开；过度处理损伤已有纸料。 |
| 化 | 分散纤维、调匀浆料和胶料。 | 只处理已接收材料，过度处理会损失可用料。 |
| 明 | 辨识过程中的结团、缺口与分布不均，辅助筛整。 | 仍需实际筛整，不读取天然含杂率，也不自动增加细腻度。 |
| 固 | 支持纤维结合、胶结和定纸。 | 不创造纸基或胶量，纸面封闭负担来自实际施胶与工法。 |
| 聚 | 归集已有浆料与有效来源，减少散失。 | 不增加投入，集中超过铺布能力会团聚。 |
| 通 | 形成纸内有效连接。 | 不保证所有渗入有用，也不替代纸面平整。 |
| 引 | 引导纤维和胶料按工法排布。 | 不增加总量，局部集中可能留下缺口。 |
| 行 | 运送和铺匀浆料。 | 不替代通建路、引定向，超出承接会带走可用料。 |
| 护 | 减少真实接触损伤、限制干扰扩散。 | 不凭空生成膜层或取消全部相克。 |
| 镇 | 压制合浆与成页中的实际波动。 | 无对应问题时不发稳定加成，不新增阴阳相激。 |
| 生 | 使用真实剩余纤维填补缺口。 | 消耗补料，填补过厚也影响纸面均匀。 |
| 藏 | 帮助有效来源在定纸时留存。 | 不补回已流失来源，不给每张纸额外生成一份藏。 |

功用品级影响公共模型中的可处理强度，份数影响供给，换算统一标定。没有对应问题或可施展来源，就没有该项额外收益；高品级也不强制全额施展。

现有可接收的纤维、液体和黏胶尚无破、明、镇来源时，不为补齐表格借用致密矿料。基础工具仍能完成普通成页，新增同类原料若实际拥有这些功用，再按同一公共规则参与。

## 五 五行生克的公共接触规则

相生为木→火→土→金→水→木，相克为木→土→水→火→金→木。五行只修正当前加工关系，不决定一种材料属于哪个用途，也不独立生成纸字段或功用。

本版只在实际制浆、合浆、施胶中处理：液体与纤维／胶料、纤维与实际投入的胶料、纸基与实际面胶。同一来源和同一对象的同一次接触只记一次；压平、演出和重复查看不再发奖励。

| 接触方向 | 公共作用 | 对字段的传递 |
| --- | --- | --- |
| 水行介质生木行纤维 | 改善当前适用分散与保留，减少对应实际损失。 | 保住可用纸基与连接，间接帮助承墨、面整或稳定；不生成更多纤维。 |
| 金行处理来源克木行纤维 | 对木方的处理与保留增加负担；若同时有破，解料帮助与受克损伤一起结算。 | 按剩余可用料影响承载与稳定，同一次损伤只扣一次。 |
| 木行纸基克土行胶料 | 土方来源在当前结合或施面中的兑现受抑制。 | 胶结与边界保持按真实剩余支持判断，有固或藏也不保证全额兑现。 |
| 支持来源生被处理对象 | 改善对象处理或保留；若确有来源分流，登记支持方的实际支出。 | 不同时给双方同一份来源的满额收益，也不只凭相生关系扣掉支持方实体。 |
| 任何实际相克 | 对被克对象增加相应处理负担、兑现损失或结构损伤。 | 可通过当前真实护、镇及工法减少具体问题，但不能免除必要用料。 |

多行材料不补元素占比字段。本轮候选统一算法为：有多少个合法五行标签，该份接触的关系权重就在这些标签间等分；双方标签配对只分配同一个接触预算，各对子权重合计不能超过一次接触。它是制纸公共算法，不声称实际物质被拆成等份。无五行的部分不参与生克，仍有质地和功用作用。

先按现行词典校验并去重五行标签；每个元素对子只查一次有方向的关系，不把反向查表算作第二次接触。相生、相克分别作用于各自实际对象，不先正负平均抵消。同一来源跨多个对象或工序仍从实际剩余中分配，不能每次恢复满额；已排出的料和来源不再参与后续处理。

相生改善已有处理与保留，相克影响实际对象，均不制造新的材料或功用。生克后只把实际保留带入下一阶段，不重新恢复为原始满额供给。具体强度系数待标定。

## 六 五个符纸字段的直白含义

纸负责提供可书写的载体，墨负责携带实际术式来源和书写墨性。纸本身不必承担墨的研磨、分散与配制工作，画符时再检查两者是否适配。

| 符纸字段 | 玩家可以怎样理解 | 制纸中的形成依据 | 主要取舍 |
| --- | --- | --- | --- |
| 承墨量 | 这张纸能接住多少墨。 | 本张纤维投入、结合支持和成页完整。 | 胶多或压得过密可能限制可用承墨；没有纸料不能靠固、聚堆容量。 |
| 渗墨性 | 墨有多容易渗进纸里。 | 成页疏密、实际施胶量和抄压方式；通等帮助利用已存在的连接。 | 太易渗可能洇开，太难渗则挑墨性；高低各有适用。 |
| 纹面精细度 | 细小笔画能否分清、会不会糊在一起。 | 打浆、筛整、铺匀和压面的完成程度；不靠矿物填面。 | 更细处理增加工作与纸料损失，密压也会影响渗入。 |
| 承纹稳定 | 画符时是否容易断纹、散纹。 | 纤维结合、胶结、均匀度及剩余损伤；固、生、护、镇处理实际问题。 | 缺料或已有损伤不能靠稳定功用无代价补齐。 |
| 封存适用 | 封符时能否稳住已经写入的效果。 | 成页完整、边界保持及实际固／藏支持。 | 只提供封符条件，画符仍要有实际来源；过度施胶封护也会影响落墨。 |

同一张纸遇到不同符墨仍会有不同加工表现。纸的五字段约束载体，墨的墨量、浓度、流展、附着和凝定约束墨性，最终在画符工序共同结算。

这些是工序产生的成纸状态，不是新增原料字段。纸的尺寸、规定层次和有效纹层属于产物规格；不读取原料天然长度、膜面积或孔隙。一个字段的富余不能抵消另一个字段的缺项。

## 七 来源分账与固定规格

投入至少分清：留入纸基、胶结与纸面等实际结构，留入规格的功用支持，加工已耗用，损失与残余。结构化保留不等于全部烧没；同一份固若已经体现在纸的承载支持中，不能再作为另一份完整固额外加成。规格如另有可供后续调用的来源，须在同一预算内划分。

不同原料可以共同提供十二功用，成纸定义仍最多四项。目标规格明确保留哪些功用及品级，其他能力按实际工序去向处理，不把全部原料功用抄进成纸。

| 通用规格候选 | 统一验收的重点 | 主要取舍 |
| --- | --- | --- |
| 素纹符纸 | 足量纤维、基本成页与可用纸面。 | 基础平衡，不自动具备复杂细纹或强封存。 |
| 通络符纸 | 足量纸基、连续有效连接及相应真实来源。 | 侧重利用内层连接，仍要处理过渗和串染。 |
| 细纹符纸 | 充分打浆筛整、均匀纸面、足够稳定。 | 处理更细，承担更多工作及可用料损失。 |
| 厚承符纸 | 每张足量纸基与真实结合支持。 | 承载偏强，量多不能抵消面整不足。 |
| 封藏符纸 | 完整成页、实际留存来源与边界条件。 | 封存偏强，过度封护影响落墨。 |
| 复层符纸 | 各层真实用料、结合与有效连接。 | 分层用料和处理更多，不免费增加张数或全项性能。 |

结算先完成工序，再逐张满足目标规格的结构、五字段形成要求、保留功用和固定五行要求；缺任何必要支持就不能再生成一张目标纸。剩余只能进入预先声明的降规规格或加工残余，无定义不临时造物。

固定产物的质地、五行、功用与纸字段由正式规格登记，必须有本批实际来源支持。产物相性仍属于固定物品资料，但本版不做原料相性匹配、继承或转化结算，不反查阴阳来改变产物。

相同规格的每张纸完全一致；原料差别体现在能否达到、实际产量和用度，不产生库存实例隐藏值。纸的品阶沿用共用材评，不用五字段另造品阶公式。

## 八 工法与自动流程

工法为一套整体执行方式，首版保留三个候选，不依赖新增原料物性：

| 工法 | 实际重点 | 代价 |
| --- | --- | --- |
| 保纤疏抄 | 减少已有纤维支持的处理损失，保持适当开放连接。 | 面整和细纹处理有限，过开放仍有渗散。 |
| 精浆密抄 | 更充分打浆、筛整、铺平并压面。 | 工时和实际可用料损失增加，开放纹层减少。 |
| 分层复抄 | 把真实纸基、胶结与连接来源分别用于规定层次。 | 每层分走实际用料，层间处理更复杂，不能重复使用同份材料。 |

最低规格配置基础常法。已学方法及符道造诣决定能否驾驭相应过程，但不能制造缺失纸料、功用或工具。配伍保存目标、工法与份数，载入后重核真实条件，不保存保证产量。

自动顺序为：预检与分配 → 纤维解料打浆 → 调浆与筛整 → 合浆匀布 → 抄页或分层复抄 → 压平、施面与定纸 → 分规领取。没有天然膜基分支，也没有逐笔、逐帘、干湿或压实时机操作。

制作一次提交后自动结算，演出读取同一结果；跳过不重扣、不改结果。首版不插随机事故或中途抉择，画符仍可采用主案中的关键技艺选择。

## 九 用度 库存与记录

工具采用制浆、筛帘和抄压的公共条件，不把符笔当制纸必需工具，也不读取材料的炼器专用档案。

灵识、精力和工时从实际处理类别、份数、工序、功用强度及制作条件统一核算，不按材料名字或不同名称数量收费，不额外乘材料品阶或相性。曲线独立标定；同步制作只核容量，不新增长期灵识预约。

预检失败零消耗。合法提交后一次扣本批实际投入、精力并推进工时，成败均不撤销；没有选入本批的候选不扣除。实际纸进入通用领取页，确认后才入包，取消或未选沿通用放弃规则，不承诺跨进程待领取恢复。

记录保存本次三组原料输入与份数、身份来源、目标、工法、人物与工具条件、公共参数版本、阶段分配／保留／损失、产物与用度。更新公共参数不回改历史结果；无定义的筛渣和残余只进记录。

## 十 界面安排

符工仍为制符纸、研墨、画符三个入口。制纸页采用左原料、中纸槽场景、右目标与用度的布局，复用现有字体和低亮度纸面。

| 区域 | 显示内容 |
| --- | --- |
| 左侧 | 真实库存、按质地／功用／五行筛选、份数增减与移除；本批用途由规则自动说明。 |
| 中央 | 解料、调浆、抄压场景；按已选材料显示实际配伍接触。 |
| 右侧 | 明确标注的目标规格五字段、兼容工法、缺项和实际用度、开始制纸。 |
| 自动过程 | 收起准备控件，展示统一加工与成页，只保留跳过演出。 |
| 结果 | 按实际固定纸规格分组显示张数与五字段，进入领取；主要损失原因可在记录查看。 |

新增合法材料自动参与同一筛选和计算，不设结构模板、天然膜、粒级或亲水性筛选。没有纤维、缺介质、缺工具，以及颗粒／致密应在研墨使用等原因直接说明；不以额外档案或白名单阻挡。

目标字段不伪装成本批预测结果，不填虚构成功率或精确预告产量。纸的专属字段放工坊纸材详情，材料通用悬停仍沿现行规范，不添加数量、分类或材料 F1 规则入口。内部预算、版本号和资源路径不进入玩家主界面。

## 十一 三个自动匹配情境

新增一种木行、纤维、通的材料，直接作为纸基和通来源候选，与现有同类材料共用解料、成页与水生木等关系；无需补字段或配方。

新增一种金行、颗粒、固的材料，本版不会把它列入制纸候选。它可由研墨的公共规则评估墨料和固来源，经研细、分散及调墨兑现；不因带固就倒灌为造纸填料，也不需要新增逐材料配方。

两个材料只有相性、名称或图标不同，本版三组输入和份数相同，在同样工法、人物和工具下制纸表现一致。若业务希望区分其天然细长、皮膜或粒度，本版明确不表达该差异，也不能偷偷按名字分支。

## 十二 参数与验收

公共参数只需维护：两工艺的质地分工、制纸三类用料的共同工序与份数转换、功用等级兑现曲线、工法处理与分配、生克强度及多行权重算法、固定纸规格与每张要求、降规结果、用度与工具条件。参数表不出现材料名、定义 ID、结构模板引用或逐材料覆写。

后续实施至少验收：

- 新增普通材料仅填现有字段，即能自动发现、匹配和参与允许的工序。
- 同三组输入、同份数与同制作条件结果一致；异名拆分不改变用度。
- 相性、材评、名称、旧材类和炼器加工数据不参与本版制纸效果。
- 制纸只接收纤维、液体、黏胶；致密／颗粒的研磨归研墨，不因其功用强便加入制纸，不强迫两边各覆盖六质地。
- 十二功用只处理真实对象；基础工具不免费生成同名功用。
- 每张纸有自己的纸基与保留来源，同一投入不被多个阶段或产物满额复用。
- 生克有方向与份额，同次接触不重复奖励，同次损伤不重复扣除。
- 纸面精细度由打浆铺布抄压形成，不依赖矿物填面；高渗非全局更好，封存字段不再赠一份藏。
- 同定义纸同质，原料历史不改变其画符效果；跳过与反复查看不重结算。

本轮为规则修订与资料核对，未实施制纸或运行游戏测试。所有新增数值和门槛仍待标定。
