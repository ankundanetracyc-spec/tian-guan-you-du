# 纸墨灵力软适配与意象修订

2026-11-08，当前修订，承接[纸墨联合主案](纸墨双工艺与字段自动匹配主案_20261108.md)。用户否定中央写实造纸、研磨器具与工序，要求修仙意象；先选择纸的“承灵品阶”、墨的“灵蕴品阶”，随后明确采用软区分。以下记录这两项裁定及本轮设计边界，具体数值和转换仍未标定。

**后续完整入口：**[三工艺完整细案](符箓三工艺完整规则方案_20261108.md)现保留有用旧字段并串起全链。用户最新限定主墨源为致密、颗粒、液体，黏胶仅辅料、纤维退出；本页用途组合只作早期方向示意，不能以其中破引组合或旧样稿推定当前墨源已有引，实际输入和调用以完整细案为准。

**本轮后续候选：**用户认为原有工艺字段不够贴近最终符箓效果，要求重新发挥并汇报。推荐的新分工及有限符式见[结果导向重设计提案](符箓纸墨法性符势与成符结果重设计提案_20261108.md)。本页软适配和墨方向意图继续作为约束，新字段及成品结构不在此提前定稿。

**用户最新方向：**符墨优先以不同作用方向区分，适合的墨配合对应符谱自然发挥更好。墨的主区别是擅长什么，灵蕴层次辅助描述同方向墨的差别；不能把全部墨归为一条通用灵力高低轴。下面关于负担与品阶的说明保留，但不替代方向匹配。界面已有的五项墨性、目标留存和灵蕴说明仍为样稿，方向分类尚未正式配置。

## 当前主线 墨的方向与符谱相合

方向来自成品墨实际保留的十二功用及其品级，是对用途的概括，不新增原料属性或一套与功用重复结算的方向加成。以下仅举推荐方向，名称、完整规格和对应符谱待进一步设计：

| 推荐墨方向 | 典型功用组合示意 | 适合发挥的符纹作用 |
| --- | --- | --- |
| 攻伐 | 破、引 | 引发、攻伐。 |
| 护持 | 护、固 | 防护与维持结构。 |
| 生养 | 生、通 | 生机与调养。 |
| 封藏 | 藏、固 | 收束、封存。 |
| 行运 | 通、行 | 传递与流转。 |

这些组合不是逐材料配方、固定必备的两项门槛，也不代表添加对应功用就自动学会或产生一类战斗符。正式墨规格仍保存有限、明确的留存功用与五项墨性；五行另外影响真实配伍，不把某一行永久绑定到某种用途。

同样层次的攻伐墨和护持墨各有适合的符谱。相合时，已有来源更能用于该符所需的符纹作用，表现为更好地完成目标、保留有效来源，并影响本符已有的符效档与合格张数；不能只贴方向标签就在真实模型之外再乘一遍威力。

方向不合本身不直接禁用，也不保证任意墨都能完成任意符谱；必要的实际来源和成纹条件仍须满足。墨不凭方向给成品符拼接新效果，例如护持方向不意味着攻伐符自动附带护盾。

灵蕴描述同方向墨的实际来源层次，不决定墨的方向；较高灵蕴不保证在所有符谱上优于更合适的另一种墨。纸负责承托，墨负责其擅长的作用，符谱确定最终符种与完整效果。

## 一 纸墨按实际负担软性适配

纸墨不按云息、蕴脏等境界划分使用许可，也不因低于某个纸墨品阶就直接拒绝某张符谱。境界不与九品到一品建立固定换算，不增加“仅限某境界符”的材料标签。

符谱描述本术式的实际负担，纸、墨、笔与技艺共同决定怎样承托、供给和完成它。纸墨品阶偏低时，负担较轻仍可能充分发挥；负担提高后，更容易发生实际失稳、灵意散逸和保留损失，影响可达到的符效档及合格张数。较高品阶能承受更重负担，也可能只是让轻负担制作更从容，不自动改变符种或抬升符效。

这里不承诺任意低品材料一定能制成高负担符。仍须具备真实材料、对应功用与完整成纹条件；没有足够实际支持可导致失败，但不能用境界标签代替过程判断。额外投入可补充用量，数量不直接升级灵性；造诣改善实际驾驭与损失，也不生成来源或消除所有材料差别。

本修订只处理纸墨的制作适配。符谱学习、人物制作资格与成品符本身的使用条件继续由相应专题分别定义，不借纸墨软适配改动战斗规则。

## 二 一项灵力字段与五项工艺字段并列

| 成品字段 | 含义 | 与现有字段的区别 |
| --- | --- | --- |
| 符纸：承灵品阶 | 承受灵力冲击、维持复杂纹势的能力层次。 | 承墨量描述可接墨量，承纹稳定描述纸内结构保持；承灵描述面对术式灵力负担的适应。不能用更能吸墨直接证明更能承灵。 |
| 符墨：灵蕴品阶 | 本份墨实际保留灵性的层次及对术式供给的适应。 | 墨量和浓度描述实际用量与配制负载，各功用及其品级说明来源方向和层次；灵蕴不另发一份主效供给或整体威力乘数。 |

两项都是成品纸墨的专属能力表达，不是新的角色资源、原料字段或第二套物品品质。通用物品品阶仍按[共用材评规则](../../物品与装备/物品词缀系统设计.md)维护；不能把通用品阶、承灵／灵蕴品阶、保留功用品级和符效档视为同一数值，也不固定互换。

纸墨仍只通过现有质地、十二功用及其品级、五行和真实份数自动匹配材料。承灵形成须有实际成纸、结合、连接与留存支持；灵蕴须有实际留入墨中的来源。工法和造诣改变本批分配、处理与损失。具体转换、品阶表达及实际负担曲线属于公共规则，待与完整规格一同标定，不逐原料增加“灵力值”。

灵蕴与各项功用品级必须在同一实际来源预算中兑现，避免“按功用品级计算过一次，又按灵蕴整包再加一次”。承灵也不能同时作为独立万能减损，与承纹稳定对同一损伤重复处理。正式模型须区分实际对象再结算一次。

同一完整纸墨定义的字段固定。各批材料决定是否达到已定义规格、实际产量及损失，不给同名纸墨生成隐藏灵力值；低品原料堆数量不能自行改写库存成品定义。

当前规格未标定，品阶值显示“—”；不为演示补写九品、八品等任意结果。未来可解释当前符谱是承托从容、负担偏重或容易散逸，具体预测须来自真实模型；本轮不伪造匹配分数、成功率或境界推荐。

中央改为稀疏的悬纸、灵丝交织与墨气回旋；不再放纸槽、竹帘、研钵或配液器具。制纸自动展示“化材→蕴养→凝纸”，研墨展示“化材→融灵→凝墨”，表现材料凝合的意会，不要求玩家处理现实工序或手动操作。内部仍需真实分配与损失，展示抽象不意味着凭空生料。
