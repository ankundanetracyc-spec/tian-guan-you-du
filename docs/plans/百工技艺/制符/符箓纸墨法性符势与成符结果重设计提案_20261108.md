# 符箓纸墨法性、符势与成符结果重设计提案

2026-11-08，结果导向的重设计候选，供本轮汇报与审阅。用户认为现有纸墨字段虽细致，却过于偏向现实工艺，要求围绕最后得到的符箓效果重新发挥。此前已明确的原料不加字段、十二功用、五行生克、自动操作及境界软区分继续作为约束。

**后续整合覆盖：**用户随后明确旧字段中有用部分应保留，复杂度应放在三环合计，购买纸墨后画符也要完整。当前整体设计见[三工艺深度整合与画符配伍](符箓三工艺深度整合与画符配伍方案_20261108.md)。本页将纸墨收至少量核心字段的取舍不再作为当前要求；有限符式保留为可选研究，不是继续设计或实现三工艺的前置确认。

用户现已认可上述三工艺整合方向；本页旧候选不再构成待确认阻碍。具体资料按[纸墨规格与画符配伍填写模板](纸墨规格与画符配伍填写模板_20261108.md)继续细化，整体确认不等于采用本页全部新字段或有限符式。

本案推荐缩减纸墨核心字段，并提出“符谱内有限符式”。字段语义、符式扩展及具体映射均为新候选；不把当前炎矢符、护身符改成持续、群体或其他效果，不修改运行、战斗卡、费用或数值。旧规则来源为[三工艺主案](符箓三工艺与画符技艺主案_20261108.md)、[纸墨联合主案](纸墨双工艺与字段自动匹配主案_20261108.md)、[软适配与墨方向](纸墨灵力软适配与意象修订_20261108.md)。

## 一 先让纸墨回答成符结果

原字段主要回答墨能否铺开、纸能否分清细线、怎样稳定制作。这些细节即使改成修仙名称，也容易让玩家只是在提高加工评分。新版先回答：这份墨能帮助什么术式，这张纸适合怎样发挥，合在一起能支持哪种已经设计好的成品。

推荐分工如下：

| 对象 | 负责的内容 | 玩家理解 |
| --- | --- | --- |
| 符谱 | 符种、完整用途、允许的符式、费用、目标与使用条件。 | 我在制什么符。 |
| 符墨 | 实际所蕴功用、五行与对应灵蕴。 | 用什么性质的力量完成它。 |
| 符纸 | 承托能力及适合组织的纹势。 | 怎样容下并发挥这道术式。 |
| 符笔 | 把实际来源送入对应符纹的能力。 | 这些力量能否按本意写到位。 |
| 技艺与造诣 | 本批如何分配、驾驭和取舍。 | 在现有条件下，更偏重哪种发挥。 |

纸不再重复墨的攻伐、护持分类；墨也不再只作为纸面书写介质。材料不创造玩家未学会的符种，符谱仍提供完整规则边界。

## 二 纸保留两项核心表达

| 字段候选 | 含义 | 最终体现 |
| --- | --- | --- |
| 承灵 | 对本符实际术式负担的承托能力。可用“容得下多少法意”解释。 | 负担升高时是否仍能完整发挥和留存，影响达成目标符式、符效档及合格张数。采用软适配，不按人物境界或纸品阶直接禁用。 |
| 符势 | 这类纸适合怎样组织已有术式。是有方向的特性，不是另一条越高越好的总分。 | 支持符谱已设计的集中、流转或凝驻形式，使纸的选择关联成符风格。 |

承灵沿用前轮希望表现灵力承载的意图，不与通用品阶直接互换；具体分档或量纲待标定。符势初步推荐以下三类，名称与完整纸规格仍为候选：

| 符势 | 擅长的组织 | 需要面对的取舍 |
| --- | --- | --- |
| 聚发 | 将已有作用集中到主要落点或一次发挥。 | 集中给主效后，可用于其他已定义部分及维持的来源减少；不能同时获得完整集中与延续收益。 |
| 流转 | 连贯传递、承接已定义的连续作用。 | 连接与维持占用实际支持，不自动获得与聚发相同的单次强度。 |
| 凝驻 | 稳住已经成立的术式结构。 | 支持分配偏向保持，不能同时把全部来源用于主效集中。 |

三种符势不分别等同攻击、治疗、防御。聚发可以支持攻伐谱，也可以支持已有瞬时护持或生养形式；流转与凝驻同样可服务不同用途。具体意义必须由该符谱的允许符式解释。

不再叠加固真、灵契等近义评分。实际留存由纸的能力、真实功用分配和执行共同处理；纸墨与符式的相合是当前搭配的结果说明，不另发一条适配加成。

## 三 墨围绕法性与灵蕴

| 信息候选 | 含义 | 最终体现 |
| --- | --- | --- |
| 法性 | 实际保留的少量主辅功用及其五行性质，概括这份墨擅长的作用。 | 破、引方向可帮助适用攻伐；护、固方向可帮助适用护持；生、通、明、镇等各有对应作用来源。既可有常见用途名称，也可直接显示引通、明通、生藏、镇固等组合。 |
| 灵蕴 | 上述各项实际来源的层次与可调用支持。 | 说明所选术式能得到怎样的实际支持，影响已有主效、辅效及留存的达成。不是一条对所有符通用的额外威力乘数。 |

五行仍是已有共用字段，继续参与实际配伍；不因火性自动给符加灼烧，也不因金性自动给符加破甲或改变伤害类型。法性只概括实际来源，不另造一套与十二功用平行的增益。

灵蕴的底层须保留各功用及品级、标准份数与对应预算。不能把它压成一条万能总量，再让破、护、生等各用一次满额。相同品阶的墨可以各有所长，层次更高而方向不合的墨，也不保证优于实际适用的墨。

墨可命名为破引墨、固护墨等已定义规格，但这些是固定成品的方向描述，不是给每种原材料手写配方。单个成品仍最多保留四项功用，不把所有输入叠成万能墨。

## 四 推荐补入有限符式，保持成品完整固定

[原成品候选](符箓成品分类与画符界面方案_20261108.md)主要让同符种在固定五档之间改变效果量。若完整保留这一限制，纸墨便主要影响符效档、张数和用度，不能宣称同一符会产生新的战术形式。

为让用户真正感到“换纸墨，得到的符有所不同”，本案推荐：每张符谱可以预先设计少量完整符式，玩家开工前选择其中一种，纸墨和技艺支持其达成。不同符式有各自完整成品定义，式内仍可保留有限符效档；相同定义的全部副本同质。

不是每张符谱都必须多式，也不是将三种纸势与所有墨任意相乘。每个符谱只开放值得选择的少量分支；采用不同触发、时限、范围或规则的分支，须逐一完整设计并通过相应战斗规则流程。

以下仅说明新结构能够承载的玩法差别，不是新增卡牌或已批准的效果：

| 抽象情境 | 纸墨如何选择 | 希望得到的差别 |
| --- | --- | --- |
| 某攻伐谱已设计集中发挥的符式。 | 聚发纸，搭配实际具有所需攻伐来源的墨。 | 有限来源优先投入主要攻伐，风格偏集中。 |
| 某护持谱分别设计一次强化与维持两种符式。 | 相同护持方向墨，分别用聚发或凝驻方向纸支持。 | 比较一次护持强度与已经设计好的维持能力；不能两边收益全拿。 |
| 某生养谱已有连续发挥形式。 | 流转纸与实际具有相应生、通来源的墨。 | 支持既定的连续生养形式，不自动附加额外次数或通用回血。 |
| 攻伐谱搭配较高灵蕴、但主要保留护持来源的墨。 | 先检查真实所需来源。 | 高层次不替代方向相合，不据高品阶保证更强攻伐，也不因此附送护盾。 |

已有炎矢符仍按现案的一次单体物理伤害理解，已有护身符仍读取公共护盾规则。新提案不为它们暗加持续、反伤、群体、追踪或重复触发。若以后为其设计新符式，必须另行完整评审，而不是用材料标签绕过。

材料方向不合本身不直接禁用，实际负担与来源支持按过程处理；真正缺少必要作用来源也不承诺可成符。造诣可以改善驾驭和分配，不能把缺失的护变出来，也不能凭数量直接升格灵性。

## 五 十二功用怎样接到结果

以下是纸墨分工的推荐语义，具体分配与强度仍需公共模型标定。同一功用在同一批中只按实际去向结算，不能作为结构支持后再完整加回一次。

| 功用 | 形成符纸时的用途 | 留入符墨后的意义 |
| --- | --- | --- |
| 固 | 帮助保持可承托的纹势结构。 | 支持适用术式的定形、维持等作用。 |
| 聚 | 把已有支持组织到主要纹势。 | 将有限作用来源集中到符谱允许的位置。 |
| 通 | 形成可用的纹势连接。 | 支持术式中实际存在的贯连与传递。 |
| 化 | 调和实际纸源，帮助其凝合。 | 调和多源法性，保留可用来源；不开放任意转换。 |
| 引 | 帮助本批支持按意图归位。 | 为符谱规定的引发、导向提供真实来源。 |
| 破 | 帮助化开本版允许处理的结滞。 | 保留可用于既定攻伐或解破作用的来源。 |
| 护 | 保护已有纸势支持，限制实际干扰。 | 为符谱规定的护持作用提供来源。 |
| 镇 | 稳定实际波动，帮助凝驻组织。 | 为符谱规定的镇定、抑制等作用提供来源。 |
| 生 | 在有实际余料时弥补纸源缺失。 | 为符谱规定的生养作用提供来源。 |
| 明 | 辨清本批真实混杂和缺失，辅助取舍。 | 为已定义的辨明、显明等符术提供来源，也可用于本次处理。 |
| 藏 | 支持把已形成的法意留下。 | 封持已有术式或保留可调用来源，具体由符式规定。 |
| 行 | 组织支持在可用连接中流转。 | 为符谱实际规定的运送、流转提供来源。 |

破、护、生等不是拿到标签就给任意符加一条对应效果，镇不自动附加控制，引不自动附加追踪，行不自动附加位移。它们供给的是符谱已经解释清楚的作用，材料与符式之间须有明确映射。

## 六 原料继续自动匹配，工艺规则围绕这些结果组织

仍不增加原料字段，不按名称、描述或图标特判。制纸继续接纤维、液体、可选黏胶；研墨继续接致密、颗粒、纤维、液体、可选黏胶，不为气体硬设用途。真实份数决定实际投入。

推荐处理顺序为：

1. 从现有库存按质地自动发现本工艺适用材料。
2. 读取各项十二功用及其品级、五行和份数，按共同规则组织实际支持。
3. 制纸让部分功用形成承灵与符势，研墨处理并保留目标法性来源。所用、保留和流失各记实际去向。
4. 五行按实际接触处理调和、分流和损失，辅助达到目标；相生不生出新功用，相克不按标签直接判败。
5. 核对有限、完整的纸墨规格。不同合法材料组合可得到同种半成品，区别在达成、数量、损失和用度。
6. 画符仅读成品纸墨定义、实际笔和已学技艺，支持玩家所选的符谱／符式，不回查原料历史加成。

例如现有山蚕长丝与兽皮同为木、纤维，前者有固、藏，后者有固、护。候选模型可让它们分别倾向留持与稳护支持，差别依据实际功用，不给山蚕或兽皮专写规则。墨也同理：没有实际破来源，就不能靠墨的名字或高灵蕴生成破。新材料只要现有字段合法，便沿公共规则自动进入。

承灵、符势和法性转换、单份来源、灵蕴表达、生克强度、目标规格和符式达成曲线仍需统一标定。本案不猜测转换数值，也不保证任意输入都能做出某张纸或某份墨。

## 七 玩家作抉择时看什么

制纸主要选择希望得到的承灵层次与符势，再配材料和整体工法；研墨主要选择希望保留的法性组合，再配材料和取舍方法。过程只展示凝纸、融墨意象，自动完成，不操作现实工序。

画符先选符谱及其已开放符式，再选适合的纸墨笔和已学技艺。让玩家能理解为何某种搭配偏重主效、为何另一种更适合连贯维持，以及为了该方向放弃了什么。复杂度放在这些有结果的取舍中，不靠两套五条工艺评分堆出深度。

选材前可查固定纸墨能力、符式用途与真实缺项。未有精确模型时仅显示适用倾向，不把倾向写成保证效果、虚构成功率或保证产量；完成后显示实际得到的符式、符效档、效果正文和张数。

## 八 旧字段和本轮范围

承墨量、渗墨性、纹面精细度、承纹稳定、封存适用，以及浓度、流展、附着、凝定，不再作为推荐新版的两组核心玩家字段。必要的每份实际数量与来源预算继续保留；其他物性是否仍需内部模拟应逐项检查，不能为了沿用旧表就保留全部计算。

不能把原五字段简单改名后继续叠加全部新字段，也不在底层又重复乘两遍同一能力。正式实现前应重整共同模型，而非在原十条参数外再加四条增益。

本轮只完成重设计候选和来源核对，未改现有HTML样稿、游戏场景、正式物品、战斗卡或存档；现有样稿56项检查仅证明旧版界面功能，不证明本提案已验证。具体战斗规则、固定成品和数值仍待逐项设计。

需要集中确认的结构选择是：是否允许符谱带少量预先设计的完整符式。若保留原先同符种主要只改效果量的限制，本提案仍可用于精简纸墨字段和改善跨符种适配，但应收回同一符种内的横向呈现承诺。
