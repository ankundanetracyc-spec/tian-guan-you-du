## 行动与费用

进入或经过地格不自动战斗、不自动采集。每格首次可主动“探查”：0.5 游戏小时、1 体力，显示环境和本格内容；完成后永久记为已探明，重复查看免费。普通格探查可以没有异常或奖励。巡查仍只按既有路线核验，不要求探查、采集或杀怪。

| 地格 ID | 探明后的行动 | 耗时／体力 | 结果 |
| --- | --- | --- | --- |
| `fern_lowland` | 采集苦苔根 | 1 小时／2 | 每次 2 份，总量 4 份 |
| `dry_pool` | 采集月露苔 | 1 小时／2 | 每次 1 份，总量 2 份 |
| `north_turn` | 调查废弃陷坑 | 0.5 小时／1 | 一次性记下危险、留下标记，无物品奖励 |
| `moss_bridge` | 辨认兽迹 | 0.5 小时／1 | 一次性提示盘根深处的妖兽，不强制改路线 |
| `root_hollow` | 应战林地凶狼 | 地图费用为 0 | 一头现有通智初期凶狼，正式战斗与结算；胜利后此格清除妖兽 |

所有数值为首轮短测，可后续统一调整。资源不随重进、读档恢复，首轮不自动再生；恢复周期另议。凶狼本场遁速暂为 100，仅配置本次遭遇快照，不改全局兽种。胜利额外固定奖励兽骨、兽皮各一份，通过共用战后结算领取，支持行囊满时待领；若未来兽种自身也配置掉落，需复核是否重复配置。战败、平局、撤退均不清除此格妖兽、不发胜利奖励；主角沿用现行非永久死亡规则。可以在应战前取消，也可以按现行战斗撤退规则尝试撤退。

探索和调查时长不随遁速变化；移动仍按每边基础一小时乘 100／遁速，不额外扣体力。行动耗时同步推进 NPC 行程：驻足行动按下一位 NPC 到达节点的时间切片，最长每片 0.25 小时；停在菜单、查看、悬停、取消不推进时间。若中途遇袭，已投入体力和已过去时间不退；不发尚未完成的采集奖励、不扣资源余量、不记调查完成，战后可重新行动。此原型尚未做分段采集进度。

采集前检查物品、图标、体力和行囊容量；无效操作不消耗。探明、事件完成、累计采集量和妖兽清除状态作为 `east_woods_dungeon_state.actions` 保存，使用稳定地格 ID＋行动 ID。旧存档无该字段时按未探明恢复。普通环境事件不生成固定剧情 NPC，不增设声望、业力或额外属性奖励。

## UI 与复用

保留全屏林地背景、正交地图、共享棋子及常驻 HUD。现已扩至 128 格并保留原节点，新增行动点与镜头参数见[外围扩图与镜头实施](东林地外围扩图与镜头实施.md)。当前格下方中央安全区使用紧凑纸墨行动条，显示地格名或“林间驻足”、当前可执行行动与“此地见闻”；路径预览／行进时隐藏行动条，避免叠放。已耗尽、已完成的行动不继续提供入口。

点击行动后打开中央暖宣纸详情卡，细墨分隔、深墨文字、低饱和朱色强调；用既有 `WorldHudStyle` 字体、纸纹、按钮，不增加副本专属装饰素材。详情集中显示叙述、风险判断、耗时、体力、采集余量，底部“返回／确认行动”；查看见闻与结果只保留返回。背景保留可辨识地图并轻压暗，地图操作暂时阻断。结果仍用同一详情卡，不另开系统弹窗。实际战斗前情报和战后奖励复用共用战斗界面，不重复制作。

2026-10-11 出口改造：林缘 `forest_edge` 是当前 21 格地图的实体出口。到达后点击“离开林地”，复用详情卡确认才返回东林地入口内景，再按既有入口流程回世界；其他格不提供离场行动，底层关闭方法同样检查出口位置。Esc 先关详情，否则中断自动路线并打开“暂歇”，再按 Esc 只关暂歇；查看期间游戏时间不推进。右上“查看出口”及副本内点击“世界”只预览通往林缘的路径，再次点击目标地格才行进，不瞬移、不直接离场。遇到战斗立即取消路径，战后不会继续先前的自动行进。

路线状态新增 `inside` 标记。副本内保存后读档恢复当前格，不回世界绕过出口；正常离开后再次进入从林缘出发。旧存档无标记时保留旧的世界落点，但采集、事件及探明记录不清空。NPC 仍使用原稳定 ID 与副本位置，不随重进重抽。128 格已接入；机遇实例寿命、资源周期恢复与多层尚未接入。
