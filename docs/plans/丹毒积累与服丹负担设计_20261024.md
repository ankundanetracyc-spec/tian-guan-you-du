# 丹毒积累与服丹负担设计（2026-10-24）

> **2026-10-25最新实施：**用户暂定采用并要求实装，随后明确不同丹药丹毒不同。本轮按前版建议分支A接入“吐纳＋服丹吸收”，改用丹种独立基值，不再统一按丹阶计毒。现有回春／通脉／静心与两种旧无档突破丹已接增毒；自然／静养排解、保存、分段吐纳和人物／行囊说明已接。其他20种只预置毒值，不表示药物或战斗服丹已经实装。编译情况见末节。

原有药效见[25种丹药提案](云息丹药扩充与旧丹完善提案_20261024.md)，批量与计时见[最新修订](炼丹耗时与批量掌控修订_20261024.md)。参数仍可调；本轮不新增正式战斗技能或其他丹药物品。

## 一、只增加一个玩家要理解的数值

丹毒是反复服丹后，身体尚未排解的药性残留与负担；不是炉内药渣，也不是敌人攻击施加的通用中毒。

首版只增加角色的“丹毒”值D，不同时引入药抗、药瘾、每丹耐药计数或永久经脉损伤。不同丹药共用这一个值，换一种丹吃不会把它清零。它是可保存、跨战斗的身体状态，不是每场结束自动清除的战斗Buff。

同一种、同丹阶、同丹效档的药物继续使用同一物品定义、同一基础药效、同一新增丹毒值并堆叠。不能从每炉原始丹效分、残余百分比或不同丹方派生出隐藏毒性，重新拆成很多背包格。

### 2.2 只在真实使用时增加一次

- 世界行囊有效使用、战斗服丹成功生效时，消耗一颗并增加一次丹毒。配置战备、加入队列、炼制、领取和持有均不增毒。
- 持续丹只在服用时计一次，不在每次恢复或触发时反复加毒。
- 被明确打断、角色死亡、物品不足或前置失效而未生效时，不扣丹也不增毒；行动位仍按现有战备规则处理。
- 定脉、归元定息沿原规则在成功晋层时消耗，在同一成功事务里增加丹毒；不在持有检查时先加一次，也不让失败重试重复扣毒。突破折时等五档收益若获采纳，再按实际消费时的状态计算。
- 丹毒只记在服用／消费该丹的角色身上。主控、队友和其他参战角色遵守同样规则，不记成队伍共享负担。
- 消耗型符箓不是服丹，不因为共用战备位而产生丹毒。

## 三、丹毒的影响：采用分支A，分支B留作历史备选

### 3.1 当前接入分支A：长期吐纳＋服丹吸收

保持一种连续系数，减少阈值附近突然失效的感觉：

```
Q(D) = max(0.50, 1 − 0.005 × max(0,D−20))
```

|当前丹毒|效果系数|说明|
|---|---:|---|
|0—20|100%|少量服丹不立即处罚|
|40|90%|负担开始明显|
|80|70%|连续用药需要取舍|
|120及以上|50%|收益降低，继续用药会延长排解时间|

Q不是新资源或第二个积累条，仅是丹毒的派生说明。D在20之后连续变化，表中不是四个硬档位。

效果范围：

1. 自然吐纳的实际灵力产出按Q修正一次，不修改灵根、基础修炼资质或晋层所需灵力，不凭空减少已有灵力。
2. 丹药的主要正向数值按服用前的Q修正。生命、法力、护盾、体力、气血、剑意、念、直接补入灵力、精力、折时及研读增益等都须在各自明确效果上接入，不能只削回血而让其他丹无限绕过。
3. 正整数效果取floor(基础值×Q)，原基础值>0时最少1；百分比效果保留内部精度，到最终实际量才按既有口径取整。资源和状态上限仍然截断。丹毒提高后，较小离散药效可能被取整成相同实际收益，这来自人物状态，不改五档基础值。
4. 药效持续时间、触发次数、作用对象、使用资格和突破门票身份不缩减；突破丹不会因高丹毒突然失去对应关口资格。
5. 持续型、次数型药效原则上在服用时保存本次实际数值，之后每跳不重新吸收、不重新加毒。较低毒时已获得的持续收益不因下一颗丹改变D而追溯重算。
6. **同一产出不能重复乘丹毒。** 培灵等直接加成吐纳产出的药，不在加成百分比上先削一次、又在最终吐纳乘一次；此类药保留名义加成，在吐纳最终产出统一按当时Q作用一次。它是持续快照规则的明确例外。其他不经过丹毒活动倍率的增益按服用时Q计算。
7. 不把丹毒扩展成所有技能治疗、所有伤害、全部研读和所有精力恢复的通用减益。药物效果及自然吐纳以外的收益不自动受影响。

举例：若采纳回春丹优效基础恢复80，角色丹毒40时本次恢复72，随后新增8丹毒至48。先按服前状态生效，再承担本颗负担，不在本颗药效内先加毒又自我削一次。

这个分支改变的是人物状态下的实际收益，不生成“优效回春72”和“优效回春80”两种物品。悬停应同时表达基础效果与本人当前实际值，不能把基础档位改名或重新判级。

### 3.2 历史备选分支B：只影响长期修炼（本轮未采用）

若用户选择只影响长期修炼，保留相同Q和自然吐纳修正，取消所有服丹吸收修正；药效完全沿五档基础值与正常上限结算。

取舍也应说清：此时丹毒不会在当场限制回血、回体力或直接补入灵力；连续服丹主要以之后的吐纳负担付代价，不能宣称它已解决战斗内连续用药。战备数量、队列行动与物品消耗仍提供原有约束。

用户已要求暂定实装，本轮采用建议分支A；此段仅留作历史比较，不能在运行时混用。

## 四、消退：自然排解，静养更快

首轮建议以真实推进的游戏时间计算：

- 正常每24游戏小时减少4丹毒，等价每小时1/6；行旅、吐纳、研读等正常推进时间均可计入。
- 明确休息／静养时额外每24小时减少8，合计每24小时减少12，等价每小时0.5。
- 不足1点的消退精度保留，不能每小时floor成0。D最低0，不积累未来可抵扣的“负丹毒”。
- 战斗回合、现实等待、挂机停在界面、打开关闭背包或读档不视为排毒时间。战后若正式推进历法，只按那段实际游戏时间计一次。
- 闭关等推进大量时间时不能直接用结束时D覆盖整段吐纳效率。若采用分支A或B，按D下降过程分段或积分计算Q，再与当前修炼分段规则合并。
- 同一段休息可分别满足重伤的真实休息要求和丹毒的加速排解，但不把行旅自动变成重伤休息。两套状态保留各自恢复规则。

例：丹毒36自然排解至20需96游戏小时；专门静养则需32小时。丹毒12自然清零需72小时，专门静养需24小时。时间只是可调首轮基准，不是现实等待时长。

D不在100封顶：丹毒越积越多，排解时间继续增长，避免“已经满毒，后面服丹不再承担代价”。首版不因D高直接掉永久属性、随机死亡或禁止突破；急救仍有收益，代价可预知并可恢复。

## 五、排毒手段与后续扩展

首版先用自然排解和已有休息行动闭环，不立刻增加一串清毒丹、药浴材料和专用面板。

- 普通回春、静心、接骨、和中等只执行各自定义的效果，不清除丹毒。
- 敌方中毒、内伤、外伤和丹毒分别有来源；通用驱散或普通解毒不能在没有明文规则时清空丹毒。
- 后续可设计医馆调理、药浴或专门排毒法，但应消耗真实材料与游戏时间，明确是否另带丹毒；不能靠廉价连吃清毒丹让所有服丹负担归零。
- 材料“明、化”仍按炼制岗位改善夹带、得率等；通过炼出更高档丹减少固定丹毒，不能让同档物品因某方用了明而额外变成无毒版。
- 满效丹少毒、修炼前预留排解、出行时保留低毒空间是首轮已有策略。新增抗毒天赋、体质、境界免疫和解毒药配方须另行定义，不写成既有属性。

## 六、人物与物品显示

人物状态区在D>0时显示“丹毒 N”，悬停解释当前影响、正常排解速度与静养速度。D很低时可写“少量残留，暂不影响”，不铺新的常驻顶部长条。数值内部保留精度，界面保留一位小数或向上显示整数时应统一；首轮建议一位小数。

物品悬停：

- 保留丹名、丹阶、丹效档和原有效果。
- 加一行简明“服用后：丹毒＋N”。不写炉内杂质百分比或晦涩词。
- 若采用吸收分支且实际受影响，显示例如“恢复72生命（基础80，受丹毒影响）”；没有影响时不重复两行相同数字。
- 持有相同药物的不同角色可看到各自当前实际值，基础物品仍相同，不拆堆。

规划阶段多项服丹不保证都按当前D得到相同收益。行动结算前重新读D，显示与实际使用同一算法；被打断或取消不增加丹毒。不要向敌方AI泄露玩家未公开战备或队列，丹毒也不成为读取私有队列的理由。

## 七、结算与存档边界

- 角色持久记录D和排解结算进度；存档重载、战斗切换与人物页刷新不得重置。旧档无该字段时为0，不追溯历史服丹补毒。
- 有效使用的药效、物品消耗与本次丹毒更新作为同一服用事务处理，不能药效成功而漏毒，也不能被打断仍加毒。
- 世界与战斗共享该角色真实状态，战斗中重复建立快照不得重复加毒；退出战斗只提交实际使用变化，不把队列预排的丹毒全部落账。
- 确认领取、取消领取、炼丹失败和未成丹都不改变角色丹毒；毒性只随服用，不随批量生产累积。
- 若同名持续效果按当前规则不能覆盖、且本次无任何实际收益，保留药物不增毒。吸收分支下尤其需要比较实际效果，不能因为名义档位高就用更弱实际值覆盖旧有效果。
- 非丹药的突破条件、重伤恢复、药位解锁、材料功用、五档物品合并与通用领取保持各自规则，丹毒不承担额外资源费用身份。
