> 状态：首发“游骸行遁”规则已确认；另有两项候选术法细案待试玩调整。功法卷章数据与功法详情页已支持展示来源术法及方形图标；地图施放入口与结算仍未接入运行时。入口位置与悬浮信息栏已有 v6 概念图及交互原型，待审。

## 一、目标与边界

大世界术法是修士学会功法后获得的世界行动能力，可改变行旅方式、处理探索情境或作用于地点。它有独立的习得记录与使用入口，不进入即时战斗技能栏，也不占主修、辅修或战斗队列槽位。

术法施展必须接入现有的大世界时间、持久精力、地图位置和存档流程。普通行旅本身仍只消耗游戏时间；术法带来的特殊移动、交互或结算按术法自身配置产生代价。预览、选中、取消和无效目标不扣资源、不推进时间。

首期建议只落地一个持续遁行术，用来验证“功法学习—世界术法解锁—地图路线预览—精力结算—时间与 NPC 同步推进”的闭环。大挪移作为一次结算式遁术的规则样例，暂不配置具体数值或解锁来源。

## 二、分类：用途与施展方式分开

每个术法同时标注“用途”和“施展方式”，避免把持续、瞬发等结算形式误当成门类。

| 用途 | 解决的问题 | 例子 |
|---|---|---|
| 遁行 | 加快赶路、改变通行条件、脱离行旅危险 | 持续遁行、短距穿越、远距挪移 |
| 攻伐 | 在大世界遭遇或探索事件中主动攻击 | 远程击破阻碍、先手伤敌；若进入战斗则交由战斗规则结算 |
| 护持 | 降低旅途危险或保护角色、同行者与物品 | 护身、隔绝环境影响、抵御一次事件伤害 |
| 探察 | 获取当前区域、路线、人物或异象的线索 | 感知附近危险、辨认灵机痕迹、查明已发现地点 |
| 役物与应物 | 操作环境、器物或地点机关 | 移动物件、开闭机关、处理明确配置的环境阻碍 |

| 施展方式 | 规则 |
|---|---|
| 一次施展 | 施法后立即结算一次结果；可作用于自身、目标、路线或地点。 |
| 持续施展 | 角色在移动或执行指定行动期间维持效果；按持续时间、实际移动距离或结算次数支付配置的代价。停止、遭遇中断、效果条件失效时按该术法写明的规则结束。 |
| 一次位移 | 选择合法落点后，直接改变角色位置，不逐格经过中间路径。必须单独写明落点范围、可选地点、时间推进、资源费用、迷雾与事件处理。 |

“大挪移”属于遁行用途下的一次位移；其效果一次结算，不代表它必然不消耗游戏时间。

## 三、统一数据与结算规则

每个大世界术法至少明确以下字段：

1. 名称、稳定 ID、用途、施展方式。
2. 来源功法与解锁卷章；学习门槛沿用该卷现有规则。
3. 使用场景、施法目标与合法目标条件。
4. 资源消耗：大世界精力、实际消耗物品及其他已存在资源；未配置的资源不得隐式扣除。
5. 游戏时间：施法耗时、持续时长或移动造成的实际耗时。
6. 效果：对遁速、路径、位置、事件或地点状态的具体改变。
7. 次数限制：不限次或明确按一次行程、一次地点行动、游戏日等口径重置；大世界不使用战斗“每轮”口径。
8. 中止、失败、资源不足和存档恢复规则。

大世界及地点活动共用已存在的持久精力，与即时战斗体力分开；不新设另一条大世界法力池。首发遁术只消耗大世界精力。战斗中的法力不会因本提案自动转成大世界费用；其他术法若需要法力或物品，须在对应术法案中写明其具体来源、恢复和消耗口径。

所有术法按一个统一行动入口完成：先检查是否已学会、场景是否允许、目标是否合法、资源是否足够，再扣除对应代价并结算。检查失败时不扣费、不推进时间。时间变化必须调用现有统一时间推进流程，使日期、NPC 行旅与月度结算保持一致。

## 四、学习、收纳与使用

- 研读并学会配置了大世界术法的卷章时，解锁对应术法并加入角色的“已掌握术法”列表。
- 首轮采用“学会即永久解锁”：术法由学习记录获得，不要求来源功法当前装配在主修或辅修槽；装配槽继续决定既有心法与其他明确注明的装配效果。
- 已掌握的大世界术法与战斗技能库、战斗技能栏分开。世界地图只展示当前场景可施展的已掌握术法；战斗开始后不把大世界术法自动塞入队列。
- 同一功法可以同时提供战斗技能、心法和大世界术法，三者分别说明解锁条件与适用场景，不共用未定义的效果、资源或次数。

## 五、首发样例：《乘物游骸真经》·游骸行遁

以下首发规则已由用户确认，后续可按试玩反馈调整。

| 项目 | 已确认规则 |
|---|---|
| 术法名 | **游骸行遁** |
| 用途／方式 | 遁行／持续施展 |
| 解锁 | 学会《乘物游骸真经》第一卷“游骸”时解锁；不需要装配该功法。 |
| 使用场景 | 世界地图行旅；开始一段路线前启用。 |
| 效果 | 行旅期间有效遁速提高 50%，即 `本段有效遁速 = 角色遁速 × 1.5`。用该有效遁速重新计算路径预览和逐格耗时；现有地形耗时修正照常应用。 |
| 费用 | 每实际跨入一个地图格消耗 1 点大世界精力；施展本身不另收费。未移动、预览、取消不扣精力。 |
| 结束 | 到达所选目的格、玩家中止行程、行旅被事件打断或进入战斗时结束。之后若继续行旅，重新选择是否启用。 |
| 资源不足 | 无法支付下一格费用时，遁术结束并停在当前格；界面重新显示普通行旅的路线耗时，玩家可继续普通行旅或停下休息。 |
| 世界结算 | 按启用遁术后的实际行旅耗时推进游戏时间；NPC 按相同时间轴移动。每格仍逐格判定迷雾、地点发现和现有事件，不因提速跳过中途格。 |
| 限制 | 不赋予飞行能力，不改变地形通行，不提高战斗速度或战斗身法，不影响战斗伤害。无冷却；精力按实际跨格数限制使用。 |

这使乘物游骸真经的世界侧收益围绕“轻身而行”展开，且与战斗侧的游骸整招规避、身法和攻伐效果各自独立。地图上的路线预览直接显示启用前后的预计时间与精力花费，实际路径和逐格事件规则不变。

## 六、一次位移：以“大挪移”为后续范式

一次位移需要区别于持续遁行：它不沿普通格路线逐格移动，因此不能沿用普通行旅的地形耗时和中途事件处理。每一种一次位移都必须单独指定：

- 能到达的区域、地点或坐标；是否只允许已发现/已到访的落点；
- 施法及位移总共推进多少游戏时间；
- 精力、物品或其他既有资源的明确费用；是否有按游戏日或单次行程的使用次数限制；
- 是否绕开中间格的地形、迷雾、地点发现与事件；落点是否可能触发当地事件；
- 施法失败、落点失效及存档中断时如何结算。

首轮建议的共通底线是：不允许选择角色尚未掌握的精确未知落点；位移不揭开中间区域迷雾；目标有效性在扣费前检查；施法时间照常推进世界时钟。一次位移术仍需逐项确定距离、精力、时间及中间格处理规则，目前不纳入候选清单。

## 八、地图施法入口与交互界面

### 8.1 入口位置

- “术法”作为独立 UI 按钮，放在世界地图右下常驻导航按钮行的上方，与导航行右边缘对齐。按钮复用 `MainHUD.tscn` 导航项的 `104×98` 图标按钮、`21` 像素名称标签和悬停反馈，不另造按钮底框；固定在屏幕坐标，不随地图缩放，也不参与格子点击。
- 现有实机布局中，左上时间牌位于 `(18,16)`，大小约 `354×112`；地图自身的“返回”按钮位于 `(24,22)`，操作提示从 `(24,76)` 开始，两者被常驻时间牌遮住。接入术法入口时一并修正：将地图返回按钮与操作提示移到时间牌下方同一行，确保返回、移动说明和时间信息都可见。
- 左下角色状态牌约 `330×176`，右下为常驻图标导航。术法小窗从入口附近向地图内侧弹出，不遮挡导航与左下状态牌；选中地图格后出现的当前格信息牌也应保持可读。地图格子、路线和地点标记仍铺在控件下方。
- 点击“术法”后，在入口侧上方打开小窗；再次点击同一按钮、点关闭按钮“×”或按 Esc 可收起。未掌握当前场景可用术法时，小窗显示简短空状态。小窗开关不暂停或推进游戏时间，正在行旅时仍遵循现有地图移动锁定规则。
- 持续术法生效时，入口仍叫“术法”，另以小标记提示“行遁中”；不要把入口名称改成术法名。

### 8.2 已掌握术法与悬停信息

以 `1672×941` 画布为基准，术法小窗宽约 `380–420` 像素、高度不超过 `460` 像素，靠右并在“术法”按钮上方展开；小窗右边缘与入口及导航行右边缘对齐，底部须高于导航行。窄屏时宽度改为屏幕的约 `90%`，内容较多时只滚动小窗内部，并保持关闭按钮可见。

浮层与详情按以下方式交互：

- 点击入口只列出当前场景可用且角色已经掌握的术法；不列出未学术法，也不提供用途分类页。术法图标和名字按多列网格横向排列，每行可容纳多个项目，空间不足时再换行；不能为填满网格显示未掌握或尚未设计的术法。需要时以小标记显示持续术法当前是否生效。
- 鼠标悬停某个术法格时，在其旁显示独立的信息栏；移出术法格和信息栏后收起。信息栏样式参考现有物品详情栏与战斗技能悬停栏：深色半透明底、细金褐边线、圆角、`58×58` 图标与标题在上、说明正文在下；内容包括用途、施展方式、来源功法/卷章、目标条件、效果、费用、次数限制，以及当前不可用原因。选中地图目的地后，路线型术法的信息栏同时显示同一路线的普通/施术耗时和预计费用。
- 点击术法项本身就是施展操作，不再增加单独的“施术”“施术并启程”按钮。一次性术法点击后立即使用；持续术法第一次点击开启，再次点击关闭。需要目标而目标无效时，提示具体原因且不扣资源、不扣次数、不推进时间。
- 点击“术法”入口、详情关闭按钮“×”或按 Esc 可收起列表；查看、悬停、开关列表和取消都不收费。

术法小窗复用当前地图按钮与格子信息牌的暖米纸视觉；其中悬浮信息栏复用物品/技能详情栏的深色半透明底、细金褐边线、圆角及浅色正文。信息栏不提供独立施展按钮；术法格本身承担施展或切换操作。“术法”入口沿用底栏导航的圆形炭墨外框、纸面中心构图与相同图标显示尺寸（`104×98`）；列表中的具体术法及其悬浮信息栏使用方形、无外框的战斗技能图标风格，以暖色纸面、炭墨主体、灰墨晕染和少量克制色彩表现技能本身。图案只表达对应术法已定义的用途，不补入额外世界观元素；地图保持可见。

### 8.3 游骸行遁的施法流程

1. 玩家在地图上单击已发现且可通行的目标格，沿用现有流程显示路线、距离、普通行旅耗时。
2. 玩家点击右下导航行上方的“术法”入口打开已掌握列表，悬停“游骸行遁”图标格时，在旁侧显示详情栏并读取当前已选路线。
3. 详情栏显示路线格数与距离、普通预计耗时、施术后预计耗时、预计消耗精力、当前/预计剩余精力。地形修正后的结果直接使用同一条预览路线计算。
4. 玩家点击“游骸行遁”这一术法项后，立即按当前路线开始逐格移动、扣精力和推进时间。若路线尚未选定、目标未知/不可通行或当前精力不足以支付首格，点击只提示具体原因，不扣资源、不扣次数、不推进时间。若精力不足以走完整段，术法仍可启程，并在无法支付下一格时于当前格结束。
5. 行遁开始后，小窗收起；入口仍显示“术法”并带“行遁中”标记。地图上显示窄状态条，列出当前术法、已走/总格数、已耗精力和剩余路线预计时间。重新打开小窗并再次点击“游骸行遁”图标格，即关闭术法并请求在当前格结算后中止。
6. 中止只在当前格结算完成后生效，结束术法并清空剩余路线；当格时间、精力与地图事件照常结算。到达终点或遭遇事件/战斗打断时，自动结束并更新状态标记。

若完整路线的预计精力高于当前精力，详情栏显示可支持的行旅格数；玩家仍可点击“游骸行遁”启程，行遁在精力不足以支付下一格时于当前格结束，不扣除无法支付的那一格费用。精力为 0 时点击不会启程并提示原因。

### 8.4 一次位移的地图操作

一次位移也从已掌握列表中选择，目标选择方式由术法决定。若只可抵达已知地点，地图点击地点后，悬停术法项时在信息栏显示落点、施法时间、费用与事件规则；点击术法项后立即施展。一次位移不复用普通路线的双击起程操作，以免把选点误当成已经施法。
