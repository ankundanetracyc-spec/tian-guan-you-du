# 白石城基础内容与内景接入

2026-11-05，用户要求在已生成内景的基础上先粗填内容。本轮先形成可游览、可交谈、可查看告示，并能承接已有交易与序章研习的首版。

## 场所与进入

白石总览进入南街、东市、府前街、西城旧巷，各街区加载本次独立内景。南街连接客栈，东市连接坊市与书坊，府前街连接告示所与城守府；城守府前厅再进入讲法前院和研习处。可见返回与公共返回均按这一层级逐层退回，HUD及原人物列表保持。

保留原 `market`、`bookshop`、`inn`、`notice_hall`、`lecture`、`lecture_study` 六个空间 ID，补充四街区与 `city_office` 五个空间定义。原人物位置不迁移、不重抽。现行世界人口和到达空间选择继续读取真实空间数据，不为场景捏造独立人物名单。

## 首版内容

- 每处补一两句简短环境文案，标签继续使用大世界纸签与深墨字。
- 与在场 NPC 交谈仍从公共角色列表进入。追加与当前位置相关的问路、买卖、初学功法、城约轮值等问答；使用现有交谈精力规则，不编造关系、声望或任务收益。
- 坊市等处的交易继续复用原 NPC 交易菜单，读取该人的实际库存和双方交换清单；不新增店铺无限供货、补货周期、价格表或虚假货源。
- 书坊提供只读入门书目，目录动态读取已开放功法，不提供新的学习来源、不发书、不绕过首卷门槛。首卷选读仍在本期主持修士的既有交互中。
- 告示所先放讲法告示、城中去处、问道须知三项信息；讲法告示读取本期主持与剧情实际状态。公告查询不推进时间，不生成新任务或奖励。
- 城守府前厅呈现轮值职责和侧院去处，沿用三方城约；不把城务与宗门收徒合并，不新增玩家主持任务的费用或收益。
- 研习处接已有研读、吐纳与暂歇。仍要求先验灵、选定首卷及方远道别，沿用入云息前的既有支持边界；达到云息后收起本期支持入口。长时间行动仍按既有真实结算。
- 客栈和旧巷先承接人物交谈、问路及场景游览。本轮不创设客房费用、免费住宿权益或经营系统。

主持人与来使保留原稳定人物及职责快照；人在前院时不复制到研习侧屋名单。首次同行剧情仍直接承接讲法前院；玩家之后可按城内正常入口行走。
