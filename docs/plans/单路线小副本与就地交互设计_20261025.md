# 单路线小副本与就地交互设计

日期：2026-10-25。状态：本轮设计稿，未接入运行时。

> 同日最新确认：用户随后选择“行走途中会触发遭遇，先显示战前信息”，当前地图已据此调整到格遭遇；覆盖本稿原先狼格必须先点挑战的建议。下列三条短路线及其点位仍未实装，不能将当前地图遭遇交互接入等同短副本已制作。详见[当前途中遭遇规则](副本四格视野与直接行动_20261011.md)。

用户方向：副本内到格子后还要找按钮，操作绕；希望有专门的小副本，通常沿一条路线，沿途安排资源和小怪；首批只使用现有狼。

本稿的路线长度、点位数量、位置和新增操作方式均为候选配置，不能作为已经确认的平衡数值。现行资源费用、敌人强度、存档、出入口和视野规则继续有效；不直接改写东林地、雾隐幽谷或旧旅程。

## 一、当前问题与改造目标

当前东林地与雾隐幽谷都是128格量级；静态狼遭遇各只有3处，其余由各自生态与完成状态决定。大片走路区域、四格视野和已清除点位，会让玩家长时间只看到通路。当前行动还要经过“到格子→找下方行动条→选行动→中央详情→确认”，空间焦点反复转移。

首批小副本用9～13格的手工主线代替大片空格，保证新鲜实例沿途有明确资源点和狼遭遇点；敌人点位由模板编排，不依赖随机NPC路过或随机兽群补充。重复进入同一实例不能凭此保证再出现已经击败的狼。

小副本为独立内容模板，东林地原任务路线、巡查与人口生态保留。雾隐幽谷不在本稿中自动缩图或更换生命周期。

## 二、操作：到了哪里，就在哪里行动

### 资源格

1. 移动仍沿现行规则：点远格先预览，再次点击启程；方向键可走相邻格。点资源不会远程采集。
2. 抵达且棋子落稳后，资源格旁自动出现小纸签，例如“采集苦苔根”，同时直接显示本次耗时、精力、产量和剩余储量。打开纸签本身不消耗时间。
3. 点“采集苦苔根”即发起这次明确行动，不再先打开说明页、再找第二个确认按钮。开始前仍检查位置、余量、精力和行囊；不能满足时留在原处，说明原因。
4. 完成后原地显示本次结果和新余量；还有余量便保留同一按钮。耗尽改为不可操作的“已采尽”，不能靠重复点击再领取。物品领取沿用已经存在的通用流程，不在此重做领取界面。

纸签是明确执行入口，自动出现不等于自动采集。详细说明用悬停或独立“详情”入口查看，不作为每次采集的必经步骤。

### 狼所在格

- 当前视野内直接显示真实狼立绘小标记、名称及“未交战”，不再只靠抽象“兽踪”让玩家猜此处有没有怪。标记与实际遭遇绑定；不制造装饰假狼，不显示视野外狼的实时情况。
- 抵达后在狼旁显示“挑战林地凶狼”。点击即进入已有战前情报页，在那里查看真实敌方及开始战斗；不再先经过副本自己的应战说明卡。
- 进入格子不自动开战，走路点击也不等于挑战。取消战前页原地返回，不推进时间。战败或撤离不清除狼；只有真实胜利回调将该遭遇记为已击败。
- 首版沿用“不强制应战”的规则，玩家可忽略狼继续移动，也可原路撤离；本稿不增加狼封路、强制清图或追击规则。路线的目标是方便连续历练，而不是要求每只狼必杀。
- 狼仍用当前林地凶狼模板和真实强度，不能因被称为“小怪”就默默降低属性。三张地图只增加连续遭遇次数，不暗增敌人境界、精英词缀或狼王。

### 多行动、移动与中断

- 一个格子优先只放一种主要内容。确有两项独立行动时，就地并列显示具名按钮，不折叠成泛称“交互”；不能一次点击同时采集和战斗。
- 当前格纸签固定在该格外侧，遇屏幕边缘或HUD遮挡时自动换侧。按钮位置在同一次停驻期间保持，不能因棋子摇摆、列表刷新或数量文本改变而跳动。
- 资源与敌人提示不覆盖棋子或通路；点纸签消费本次鼠标事件，不能穿透成移动指令。移动、行动或战斗过渡中禁用重复执行。
- 连续路线遇到第一个尚未处理的资源／狼内容格时先停下，让玩家看见并决定；停下不自动执行，也不额外扣费。玩家再明确点击后续目标即可略过该点，不能反复被同一格拦住。
- Esc先收起详情等最内层界面，否则沿用暂停／暂歇；不传送出副本。鼠标滚轮缩放、右拖镜头及方向键沿用现行逻辑。

## 三、首批三条路线

以下都为单层、无岔路、无隐藏传送的正交路线。视觉可弯折，拓扑是单链；内部节点只有前后两个邻居，两端各一个邻居。下列箭头表示唯一前进方向，不代表自动沿路执行。

每个“狼”为一场独立的单只现有林地凶狼遭遇，首批不靠多人围攻制造难度。每个“资源”为一个独立有限储量点，余量按点保存。同名资源分布于不同格不共用计数。

| 模板／候选格数 | 完整路线顺序 | 体验重心 |
| --- | --- | --- |
| 蕨林采径／9格 | 入口 → 苦苔根 → 狼 → 林间路 → 月露苔 → 狼 → 苦苔根 → 狼 → 出口 | 3资源点、3场狼；先学会就地采集，再交替推进。优先制作 |
| 湿溪花径／11格 | 入口 → 月露苔 → 狼 → 苦苔根 → 溪边干地 → 狼 → 雾铃花 → 月露苔 → 狼 → 雾铃花 → 出口 | 5资源点、3场狼；偏采集，湿润植被与花材形成主题 |
| 林缘旧采道／13格 | 入口 → 狼 → 苦苔根 → 岩地小径 → 狼 → 灵石脉 → 月露苔 → 狼 → 岩地小径 → 灵石脉 → 狼 → 苦苔根 → 出口 | 5资源点、4场狼；偏连续消耗与采矿，采道周围仍属林缘狼活动地 |

空地只用于短暂换景和拉开战斗间隔，不弹无内容调查页，不赠送治疗、法力或奖励。出口不再额外放一个换名的强狼或凭空宝箱。

每张地图入口说明直接告知主题、当前实际资源状态和“沿路可选择应战现有林地凶狼”；不写“新手轻松”“必得某宝物”或固定现实通关分钟数。狼的真实强度与玩家构筑决定能否连续挑战。

## 四、入口、出口与实例

候选接入方式：作为世界地点中的独立小副本入口配置，不给普通地点凭空增加地图级格子。现有东林地和限时幽谷入口不自动重定向到本稿。首图的具体世界位置与出现条件留待接入前确认，不擅自占用任务地标。

建议为每条路线两端明确配置实体出口，均回到入场世界锚点；入口端允许走回撤离，末端用于完成路线后离开。到出口仍须玩家明确选择离开，不到格就自动切场景。两端出口属于新模板候选配置，不改老副本只有既有出口的规则。

实例生命周期必须在实施前选定，不能把常驻恢复和限时机遇刷新混用：

- 若作为常驻小副本，同一旅程固定同一实例，沿用植物7日、雾铃花30日、矿产90日、普通狼14日检查的既定生态规则；不承诺每次重新进门满资源满狼。
- 若作为限时机遇，则沿用该机遇的开放与关闭规则、进出和保存边界，不能因为复用本图就额外创建一套寿命。本稿不新定出现概率、开放天数或数量上限。
- 初次创建实例按编排生成真实内容；存读档或重进只恢复同一个实例。每只狼、每处资源有稳定节点ID与行动／遭遇ID，不重抽、不免费重置。
- 副本内保存恢复原位置；通路、已发现格、储量、击败状态及待领战利品分别保存。满包和取消不能丢失或重复结算。

## 五、落地顺序与验收

先实现一个可配置的就地行动控件，再做“蕨林采径”完整样板；验证操作确实减少后，湿溪花径与林缘旧采道只换路线配置。旧地图可复用就地行动控件，不复制三套近似副本脚本。

实施前需收敛：首图世界入口、生命周期、两端实体出口，以及本稿候选格数／点位；未确认前本稿不替换运行时配置。用户已明确的主要目标是到格后不用到别处找按钮，并不是提高狼强度。

验收要点：

1. 到达资源格后，在该格旁直接看见具名采集按钮与费用；普通采集只需一次明确执行点击，不再经过双重确认页。
2. 狼格显示真实遭遇，点挑战只进既有战前页；路过不自动采集或开战，点击纸签不穿透移动。长路线在首个内容点停下后允许主动略过。
3. 三条路线分别为9／11／13格单链，含3／3／4场单狼及3／5／5个资源点；具体数字只在最终确认后成为验收配置。
4. 验证未发现内容不泄露、视野边界不随缩放改变；就地纸签在边缘、HUD附近及两种画布下不遮挡、不抖动。
5. 重进、读档、重复点击、胜利回调重入不刷新资源或复制奖励；战败和撤离保留未击败狼，满包不提前扣余量。
6. 往返、出口取消、途中战斗、行进中存读档均保留正确位置和进度；时间与NPC同步沿用原系统，不新增免费治疗点。
7. 沿用已经完成的地图对象复用和历史索引优化，行动提示只按状态变化更新；不得恢复每帧重建地图或全扫历史的实现。
