# 百川旅途随机遭遇

2026-11-01 用户确认首版：在大世界行旅途中随机遭遇，主要为野兽，也可能遇劫匪。按有效行程平均约 60 公里一次，随机分布；约八成为野兽、两成为劫匪，优先单个敌人。城镇、宗门节点不触发。遭遇时暂停行旅，复用副本事件窗口并提供选项。

按路线实际里程累计，不按节点个数抽签。旅途在到达节点后暂停，事件与剩余路线随存档保留；处理后再继续行旅。战斗沿用现行战前确认、战斗撤退、失败及已配置战利品规则，不采用副本专属的固定掉落。野兽使用已有林地凶狼，劫匪使用既有人物生成与基础战斗配置。押送任务已有独立拦截，临时同行期间不叠加普通旅途遭遇，避免两套事件同时接管行程。

已接入正式游戏。检查覆盖抽样分布与路线分段、真实节点暂停、窗口选择、临时存档写盘读回及重建主场景、两种敌人的战前确认与取消；野兽遭遇另验证进入正式战场和结算返回，测试以直接设置敌方生命结束战斗，没有自动操作技能，也未跨进程重启读档。无窗口测试退出时仍报告项目现有的资源清理告警。
