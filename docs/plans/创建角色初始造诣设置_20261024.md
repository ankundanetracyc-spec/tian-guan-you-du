# 创建角色初始造诣设置

> 2026-10-24，现行。用户确认：创建角色时九项造诣可免费独立调节，每项 0～10，默认 5。

## 规则

- 九项为剑道、刀道、枪道、体道、术法、炼器、符箓、阵法、炼丹，使用既有 `*_proficiency` 字段，不新增每本功法独立的熟练度。
- 不消耗资质点，不设九项总和预算；0～10 只限制创建角色时的设定，不改入世后的成长上限或功法研读奖励。
- 创建流程增加第三页「初始造诣」，每项提供滑条和数字输入，可保留一位小数；支持全部恢复为 5。前两页「下一页」继续前进，第三页点击「入世」。
- 单独重抽灵根、重抽资质和更换初始功法不重置造诣。
- 九项写入开局方案，载入旧方案缺失字段按 5；非有限数拒绝，越界设定限制在 0～10。
- 新角色生成时，同时写入对应的基础造诣 `base_*_proficiency` 与当前造诣，后续派生属性重算仍从基础值继承。正式存档使用现有 HumanData 字段，不新增存档版本，不修改已有旅程。
- 提高造诣不直接发放秘籍、完成卷章、推进修炼或给予永久研读奖励。

## 实施

- 开局模板及预设：`GameStartProfile.Proficiencies.cs`、`GameStartProfile.cs`。
- 创建页：`StartMenu.CreationProficiencies.cs`，复用现行纸墨字体、输入框与按钮。
- 新角色继续走 `apply_to_youngest` 原入口，不覆盖正式读档角色。
