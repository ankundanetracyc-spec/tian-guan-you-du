## 一、用户最新裁定

本节覆盖首版及修订2／3／4中相冲突的展示：

- 角色侧栏顺序为概览、属性、战斗、功法、造诣、装备、关系。造诣独立，不归战斗。
- 角色最外层取消框边与其装饰角，引用原木纹区域铺满；顶部题签及人物字级缩小、同一行统一46高，右上行囊与返回对齐。此项不改变静室的既有外框和场景。

- 灵感、修命、修性暂不接。静室仅保留吐纳修行、功法研读、闭关突破；同时撤下灵感清册、自动／手动炼化、研读灵感和相关修行总览入口，不保留灰色占位入口。
- 灵力值、目标缕数与单位使用淡青色，灵力条同族处理。其他资源按各自语义，不混成同一数值。
- 只删除“因果”标题及被指出的侧栏题句、页脚题句和圆盘说明；恢复声望、业力、所在。声望保留百川区域及简要构成；未绑定真实值时留“—”，地点留“未详”，不编造名望或业力。
- 删除重复的“人物卷宗／玉虚仙宗·弟子”侧栏题头，侧栏直接进入分页。
- 基本资料集中在立绘下方：姓名、宗门、身份、境界、灵根、性别、年龄、族属。取消中间资料卡，概览页眉不再重复这些值。所在与所属宗门分别表达地点和归属；所在保留独立字段，未绑定时不拿宗门名填充。基本资料位置按本会话用户明确的立绘下方指示执行，不据此改动人物主案中的正式页布局。
- “当前状态”专指局外 Buff，移除生命／体力／法力数值。生命等资源继续在属性页。状态支持名称、效果、恢复／到期信息、来源、换行与滚动。

- 心境收成右上角小面板，保留圆盘、当前心绪及说明入口；恢复的信息放在旁边，不再让心境独占右侧整行。
- 数字／日期的增减只保留上下两个三角，不使用装饰底图；输入框仍有素材。静室日期仅显示年月日，不显示时辰。
- 静室撤下“瓶颈减速”和主修摘要，角色功法页的实际主辅修装配保留。当前瓶颈有旧代码，但开关关闭，见下文核实。
- 不再把同一个按钮取样用于全部尺寸。按用途分别生成侧栏分页、短页签、普通操作、主操作、小图标与输入槽六种同风格底图；本轮替换修订3的旧取样裁角方案。真实透明底保留，边缘在浅纸、深墨和静室场景三种底色复核。
- 侧栏只在选中时向右滑出纸签，露出左侧灰蓝装订边；未选中时纸签收回、装订边不显示。角色和静室同时应用，纸面与文字一起移动，切换时旧项收回、新项滑出。

以1672×941为设计基准，验证1920×1080和1280×720窗口；角色画布的逻辑宽度按实际窗口扩展，文字与按钮继续等比缩放，不再由固定1672宽居中留下两侧余白。当前角色页眉顶部12、行高46；题签字级26、姓名23、境界与灵根18；侧栏左16、宽200，正文左232、右16、上76、下20。正文可用高度由777增为845，约增加8.8%；木纹覆盖整个查看区域。概览仍为立绘与基本资料、声望／所在、紧凑心境和大区局外状态，细分面板随正文伸展。这些均为视觉尺寸，不是容量或游戏数值。

## 三、素材与实施

本轮通过内置图像生成工具分别制作六张RGBA底图，每类独立生成，使用善功堂和藏经阁现有截图作材质参考，不复制页面构图。所有底图、完整提示词、源文件位置及哈希见[分型素材说明](../../美术规范/角色与静室纸墨木石样稿_20261108/assets/按钮分型_v4/README.md)，可查看[三种底色对照](../../美术规范/角色与静室纸墨木石样稿_20261108/按钮分型.html)。

| 类型 | 视觉分工 | 样稿中的适配 |
| --- | --- | --- |
| 侧栏分页 | 浅纸签；选中右移并露出灰蓝装订边，未选中收回 | 角色与静室侧栏，约69高 |
| 短页签 | 叠纸、微折角、薄布底 | 模式／筛选、小型操作与目录行，约40–46高；内容行保留自身高度 |
| 普通操作 | 薄木边、浅纸面、轻微厚度 | 查看、返回、离开等，约44–48高 |
| 主操作 | 同族纸面、松灰绿下压边、稍明确的木边厚度 | 开始修炼、研读、突破及确认，约50–52高 |
| 小图标 | 灰青石薄底座、空白浅纸中心 | 帮助、清除、重置等小图标，36／46高；装备槽按自己的尺寸适配 |
| 输入槽 | 内凹浅纸、直边木槽 | 数字、日期、搜索等，约48高 |

上述均为视觉尺寸，不引入游戏数值。文字、图标和命中区独立，数字增减继续只用两个三角。导航和主次操作不再由同一素材缩放冒充。各底图九区伸缩，保留对应角部和边沿；原生透明通道承担轮廓，不再描轮廓使用`clip-path`裁角。

生成原图按字节保存，不以脚本抠图或重绘。原图低Alpha背景噪点在显示时通过连续透明度映射清除（Alpha≤8归零，其余连续变化），保留抗锯齿，不以背景色矩形遮盖。三种底色和三倍边缘图分别检查；见[透明分析](../../美术规范/角色与静室纸墨木石样稿_20261108/assets/按钮分型_v4/透明通道分析.json)。

其余主框、纸页、题签、图标、勾选／单选、进度、滚动、节点、提示、弹窗与通知继续引用既有素材。原20区补充图集、善功堂和藏经阁源图保持，字体仍为原项目字体。深墨悬停完整展开，不设内滚动。素材册为控件示范，不引入延后系统。

### 侧栏选中动效（修订5）

纸面及文字在选中时同步向右18设计单位，装订边在其下层显露；未选中位移0、装订边透明度0。纸签位移使用220毫秒缓出，装订边140毫秒渐显／隐，无弹跳。只是悬停不会露出装订边。切换分页时保留原侧栏节点，只更新选中状态和正文，以保证旧项收回和新项滑出的连续性；同页重复点击保持选中，快速切换从当前进度平滑转向。

键盘激活与点击一致；减少动态效果模式直接切到终态。按钮命中区、列宽和相邻正文位置稳定，选中纸面仍在侧栏内。复用v4侧栏原PNG，通过原生区域引用分成纸面和装订边，未改写或生成位图。参数见[侧栏动效参数](../../美术规范/角色与静室纸墨木石样稿_20261108/侧栏动效参数.json)，实测见[专项验收](../../美术规范/角色与静室纸墨木石样稿_20261108/侧栏动效验收.json)。

## 四、规则与范围边界

### 战斗页：局外预装配独立样稿

以下为早期现状核查，已由[本次独立样稿](角色战斗页新版招式盘样稿_20261108.md)补齐可操作演示。局外入口、命名方案管理与局内载入副本已可在样稿中查看；正式运行接口及存档并未因此完成。

用户要求在局外预先装配新版招式盘、准备多套搭配，局内可以直接使用并继续调整，减少逐件拖拽。现有`BattleBoardHud.ShowPlans()`已经有局内保存草稿及载入方案的基础；目前人物战斗页仍为兽战装配，尚无对应的局外新盘编辑与方案管理入口。

后续样稿以现行人类新盘规则和专用逐格材质为基础，保留真实格形、转向、化法目标与唯一外围手持。方案只保存配置，不携带可恢复体力、法力、灵识、次数、冷却或库存的运行状态；装配资格和实物来源仍需实际核对。方案数量、命名／覆盖交互和待审器物能力不在本轮审计中自行补定。本条记录新增方向，不代表预装配或正式战斗皮肤已经接入。

核实现状补充：现有方案窗口仍是通用弹窗，保存只是自动编号追加；当前`CombatBoardLayout`仅有矩形尺寸与摆放列表，尚无新版完整非矩形可用格及外围手持字段。局外入口不能假借启动真实战斗；后续配置表达及管理沿[配招方案与一键摆盘设计](../战斗与构筑/布阵方案与一键摆盘设计_20261107.md)衔接。人类新盘规则已接入，与新版专用皮肤未接入是两件事。

本轮只修订预览，不新增、重做或平衡卡牌。秘籍、卷章、招式名和图标只读现有资源；数值为排版夹具，未绑定字段留“—”。不推定费用、资格、成长、奖励或结算。

- 人物与心境继续参考[人物主案](../人物与修炼/人物属性、因果与心境系统设计.md)。因果标题撤下，声望与单值业力仍分别展示；不改变正式数据或因果机制，不自创心绪变化和收益。
- 状态遵循[大世界角色状态系统设计](../世界与探索/大世界角色状态系统设计.md)：局外持续状态与资源、战斗临时Buff分开；恢复、来源及移除条件来自实际记录，不从文案推导效果。
- 战斗沿[现行招式盘规则](../战斗与构筑/人类招式盘实施与验收_20261107.md)，不把人类对战退回十槽。
- 装备按[已确认双护具分类](../物品与装备/外围手持槽与护具分工设计_20261107.md)作视觉示意；旧运行接口尚未迁移，待审收益继承与器蕴方案不视为已实施。
- 主辅修、书目、卷章、研读、日期与突破只供查看；[信息分层规范](信息展示与规则详解分层规范_20261026.md)保持。确认只展示样式，不推进时间、不扣资源、不生成物品、不写存档。

当前运行核实：[瓶颈开关](../../../csharp/system/CultivationBottleneckRules.cs)为`Enabled => false`；旧计算与存档字段仅为兼容保留，角色读取时在关闭分支返回0。即已有旧实现、目前未启用，本轮只撤下样稿中的占位行，没有修改运行开关。
