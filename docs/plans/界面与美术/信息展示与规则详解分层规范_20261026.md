## 游戏内两档显示

游戏设置新增“信息显示：简略／详细”，开始菜单与游戏内暂停菜单共用，切换立即生效并保存到通用游戏设置，不写入角色存档。未设置过该选项时默认详细；恢复默认也选详细。

- **简略版**：只显示效果结果，以及费用、目标、关键词、独有触发条件、次数、冷却和真实代价；不带公式或属性代入。
- **详细版**：效果正文与简略版相同；正文全部结束后留出段间距，再独立显示“计算来源”。伤害、护盾、层数、概率或属性数值的来源分别起一行，统一“名称：最终结果 = 具体代入式”；有名称保留名称，无名称只写“最终结果 = 具体代入式”。结果必须在算式前，使用半角` = `，不使用约等号或逗号计算格式。保留真实代入与运算顺序，例如“伤害：12 = 7＋体魄[10]×0.25＋体魄[10]×0.20”。不同来源不能挤在同一行，不把整条来源再用外括号包住；长公式在该项内部自然折行，不与效果句混排。
- 显示精度沿用2026-11-08裁定：系数、属性代入和倍率最多显示2位小数，去掉尾零；2026-11-09确认采用“结果 = 算式”，不使用约等号。真实系数仍保留来源精度（本轮剑器为四位），运算精度、实际取整及伤害／稳定结果不变，不将缩略文字重新用于计算。策划精确公式与来源表继续保留完整数值。
- 固定数值没有依赖计算时不凑公式；动态数值使用当前施术者的真实代入值。玩家正文直接写“造成12点物理伤害”等结果，取消“预估”字样。计算口径仍为原角色自身修正后的数值；命中、会心与目标防护等在实际攻击时结算，其边界继续放在规则详解，不因改文案而改成目标最终承伤。
- 2026-10-28确认的完整代入要求继续有效：所有人物属性的详细版展示基础值、倍率、固定加值及实际生效修正，派生属性也保留运算顺序和真实结果。悬停不显示四舍五入、向上／向下取整等底层用语；采用最新格式“18 = 基础值[8]×倍率[2]＋固定加值[2]”，这只是排版示例。只有基础值的样例不能代替有加成场景的验证；简略版只显示最终结果。
- 结果依赖未来攻击、目标或状态时，说明何时确定，并在详细版保留其计算方式，不编造结果。
- 两档使用同一份详细源说明；切换不会把详细源覆盖成简略文字。已打开的悬停和已经创建的正文即时刷新，之后新开的信息栏同样遵守设置。
- 同一信息栏有多个效果或栏目时，全部正文先显示完，计算来源只在最后集中列一次；不能各栏目分别追加一块，也不能切换、刷新后重复追加。没有动态计算来源时，两档不增加空标题或占位行。简略版不显示计算来源标题、公式、属性代入或计算用字母。
- 计算来源中，每两项计算之间固定空一行。单项长算式的自然折行保持连续，不在其内部插空行；最后一项之后不额外追加空白项。此间距仅适用于逐项计算，不扩大为全部信息字段统一空行；结果前置、`min(...)`／`max(...)`写法及隐藏取整名称的规则保持。
- 所有悬停中，效果、化法追加等本身可能长段的字段采用标题独立一行、正文从下一行开始并自然折行，不紧接标题冒号。消耗、目标、次数、冷却等短字段保持“标题：内容”同行；不对全部字段机械增加空行。两档共同遵守该段落规则，计算来源仍只在详细档末尾出现。
- 长内容按需适当加宽信息栏，优先保留正常字号、完整正文、计算项之间的空行和底部格图。局内招式仍保持单栏；内容较长时提前加宽，不必等整栏接近窗口高度才调整。宽度受当前视口限制，位置避让窗口边缘；不截断或省略内容，不增加内部滚动。短内容维持常规窄栏。
- 函数写法：取最小值／取较小值统一显示为`min(...)`，取较大值保持`max(...)`，不再以中文函数名显示这两类运算。四舍五入、向上／向下取整属于底层规则，玩家计算来源不显示这些用语，也不显示`round`／`ceil`／`floor`名称；保留原算术项、必要分组与实际结果。其余函数沿用现行可读中文。本条覆盖旧“所有函数都翻成中文”的表述；实际精度、取整和结算完全保持，正式策划仍保留精确算法。

2026-11-08招式标注裁定：名称后“*N”为可摆份数，“限N”为整场共享生效次数，回合次数仍明确写“每回合N次”。首次扫到检查、整份变暗、失败不重试与下轮重新点亮属于公共流程，集中在规则详解／策划说明，不逐招重复到玩家正文。见[当前平衡与标注案](../战斗与构筑/人类招式首轮平衡与名称标注_20261108.md)。
