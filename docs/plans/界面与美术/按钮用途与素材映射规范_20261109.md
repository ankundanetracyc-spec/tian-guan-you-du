# 按钮用途与素材映射规范

2026-11-10，当前。用户要求按钮可以多样，但类型必须对应固定用途；不得按当时想法、文字长短或按钮宽度临时换素材。用户同时允许个别页面保留独特按钮。可操作控件统一暖纸色，禁用／不可互动允许统一冷色；选中保留原纸色相并压暗，不额外染绿。本案补充[全局纸墨木石风格](全局界面统一风格规范_20261108.md)，统一用途与状态语言，不要求所有页面同框、同布局或同一PNG。

## 固定用途表

| 用途 | 默认素材族 | 使用位置 | 约束 |
| --- | --- | --- | --- |
| 普通操作 | Regular齐边纸面 | 返回、取消、关闭文字按钮、添加、移除、清空、重置、保存维护 | 同排同类操作使用同族，尺寸可变；不因字少改成折角签 |
| 核心提交 | Primary主操作纸面 | 炼丹、开炼、开始修炼、成交；当前弹层的主要确认／载入 | 每个独立操作区有明确的主提交组；同一任务的并列执行方式可同族，如养成一息／连续养息；不能把选中状态临时提升成主操作 |
| 页内选择 | Regular选择态 | 功用、五行、材料筛选、互斥模式、普通子页切换、选中目录行 | 选中只改变整纸明暗和既定反馈，不换轮廓、不换成Primary、不加中央色块或额外底线侧线 |
| 跨页导航 | Navigation装订纸签 | 人物七页、静室分区等真正跨页导航 | 同一导航组一致，保留已批准右移／装订边动效；不是所有横排按钮都叫导航 |
| 纯图标操作 | Icon方形图标底材 | 问号、无文字关闭、重置等图标操作 | 图符居中，命中区明确；不能因按钮窄就自动归为Icon |
| 数量／输入 | Input纸面输入槽 | 数量、剂量、天数、名字、检索输入 | 数值增减采用裸三角的既有例外；槽、文字和上下限反馈一致 |
| 器物化入口 | 已登记的入口卡或专用资产 | 丹方册、实体书册、特定场景吊牌等 | 图标可独特，文字仍是真实控件；必须登记用途和适用页面，不能把专用底材借给普通筛选 |

`ButtonKind.Tab`仅作为历史视觉资产和明确登记的实体册页签兼容存在，不再是“短按钮”的默认选择。新代码不得按宽度、字数、CSS的small类或选中布尔值自动在Regular、Tab、Primary之间切换。

## 状态与尺寸

正常、悬停、按下、禁用、选中属于同一用途的状态，不是不同用途。普通状态保持同族底材，按下整纸轻暗并下沉1设计单位，释放复位；命中区不跟随移动。选中保持原纸色相与纹理，只把整张纸面压暗并保留深墨字；不额外染绿、不在文字后另铺矩形、不附加选中短线。选中不等于核心提交。

同一排按钮共享字号、行高和文本垂直居中；标准普通操作22字／46高，按内容可登记紧凑或大号尺寸。数字三角不套纸按钮；问号等图符水平与垂直居中。返回统一右上“返回 ▸”，日期如存在应同一行同字号同高。素材采用九宫格／固定端帽，不将完整图像强拉成长条。

## 允许保留的专用表现

| 范围 | 专用用途 | 边界 |
| --- | --- | --- |
| 凝核牌局 | 牌面、轨道、起手、原笔触操作 | 用户已认可整体，完整保留，不套普通表单 |
| 善功堂、藏经阁 | 原目录、书架书脊、抽书与兑换 | 本轮继续保留；独特资产不是问题，玩法与布局不改 |
| 世界地图与场景挂牌 | 轻量HUD、地点行动、可点击场景物件 | 保留场景身份；弹层内普通确认仍按普通操作／核心提交分工 |
| 正式战斗 | 逐格盘、战斗HUD、来源与资源专用控件 | 可保留批准暗幕和专用边框；状态不应误当提交用途 |
| 人物战斗当前清册 | 五类按钮与配招同款边框 | 11月9日已明确的局部视觉例外保留，语义仍区分分类和进入配招，不直接撤掉已批准同款边框 |
| 炼丹丹方册入口 | 具象册本图标＋入口卡 | 本轮重做透明图标，保留独特入口构图；功用筛选不借用册页折角签 |

新增独特按钮时，在对应页面主案登记用途、适用位置、素材、各状态及与普通控件的关系；不要求再次确认每个常规实现选择。例外不得扩散成同用途多套随意样式。

## 本轮实施与检查边界

先修用户指出的炼丹：删除炼成展示模式控件、去掉丹方册副标题、生成新图标、统一功用筛选及册内同级选择、修复滚动条拉伸。普通交易仍为独立样稿。所有其他正式页、当前样稿和保留实现分别审计，不能将历史废稿混作当前问题，也不能把源码检查说成所有页面均已重新实机查看。

多线程结果与逐页差异统一归档到[全页检查报告](../../美术规范/按钮用途全页审计_20261109/README.md)。其他页面继续按用户要求逐页验收；未获接入的样稿不因本规范发布自动实装。
