# 人物战斗与配招正式接入

> 同日最新人物与战场外观：用户明确确认恢复[林间石地与小人物](../战斗与构筑/招式盘战场固定为林间石地小人物_20261109.md)。正式人类招式盘和查看入口已固定同一套表现；旧远山／大纸偶截图为前轮状态，见[当前原生图集](../../美术规范/人物战斗正式实装_20261109/林间石地小人物/README.md)。

2026-11-09 · 用户在确认人物页尚为样稿、局内仅部分接入后明确要求“实装”。本案据此授权正式人物战斗页、人物配置与存档、战斗开局快照及局内列表接入；覆盖此前只做独立样稿的范围限制。布局以[最终人物战斗与方案流程](人物战斗总览与局内配招统一_20261109.md)为准，不改变其他人物分页。

- 人物战斗首页仅展示真实已学招式、化法及实际持有的丹药、符箓、法宝；不从资源全库或当前盘反推学习与拥有，不填入网页示例。未定义的法宝上盘能力保持关闭，持有目录仍可如实查看。
- 功法页并列展示每卷“修持、化法、习得”三项内容。已研读且已装配的卷章两项战斗效果都显示“已生效”；未装配时显示预览，未研读时显示条件，不提供辅修逐卷切换入口。主修与辅修的战斗差异只显示在心法的主修额外效果；大世界境界与突破要求继续按主修规则检查。
- 配招保留原人物页并压暗、全屏显示紧凑主盘与右侧来源／组合／方案。复用原生占格、物品图、整物材质框、拖放、R／右键转向与校验；图谱继续独立。
- 人物默认开局与当前战斗运行盘分别保存。应用只更新独立的局外默认配置；开始战斗复制默认配置，局内调整、消耗、胜负回传不覆盖默认配置或命名模板，不恢复库存、资源、次数或冷却。
- 命名方案与组合归属于人物，随正式人物存档序列化；使用显式导出名称和稳定编号，避免后台资源快照漏掉名称。现有全局方案库保留只读兼容：人物尚无内嵌库时读取，第一次人物管理操作复制到本人库，不改写或删除旧文件。
- 方案盘下“保存为方案”命名确认，右侧每项竖排“应用、改名”；同名先提示覆盖。保存与应用分开，取消／无效输入／缺来源不部分改配置。组合保存相对布局，支持命名、覆盖、改名、删除和整组拖入，空隙不预留。
- 局内继续只载入，不提供保存或改名；读取出战人物的冻结方案库，列表每项显式“应用”，仅替换当前整理草稿，开始／继续战斗才提交。返回与未确认拖放不产生管理写入。
- 空瓶、符痕不自动还原消耗品。局外默认与模板不保存已消耗对象；旧运行盘仍可查看并手动修正。主辅修变化后的必需指示沿现有校验处理，不自动补发招式、物品或未定器物能力。
