## 页面与入口

百工“阵法”资料页点击“绘制阵图”，展开独立全屏操作内页。旧资料框不承担大盘编辑，也不在本次批量改动百工其他分类。

操作页采用1672×941设计画布等比适配窗口，正文边距24／10／24／20。三栏按功能组织：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 阵法、守攻试运行、保存草图、读取草图、说明、返回 |
| 左侧纸册 | 原有七类可构筑部件、紧凑操作菜单及接线示例 |
| 中央案面 | 常显细格的最大盘面、占格与连通摘要；不再保留底部工具条 |
| 右侧纸页 | 部件设置与信号试运行；选中件、条件、计数与结果 |

草图的读取、保存、部件参数和试线继续调用原接口。部件按原操作选取后放入，盘内已有部件可按住拖动；Q切“信号线”、E切“供能线”，按住左键铺线；Esc回移动，R或操作菜单的“转向”旋转，右键仍取下或擦除。快捷键只作用于当前可交互工作台，不吞掉输入框内的文字或弹页操作。

长操作说明收在独立纸页，常驻只保留必要用途与当前结果。返回释放本次操作页，回到百工资料；操作页退出时一并清理自己打开的守攻试演与说明，避免残留输入或试验人物。
