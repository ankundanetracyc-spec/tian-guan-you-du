# 俯视角色衣服骨骼与换装

日期：2026-11-04。状态：独立试玩已接入，待用户评价动态和美术。现行入口为[俯视角四招与凶狼试玩](../战斗与构筑/俯视角四招凶狼试玩_20261104.md)，正式行动队列不切换。

用户要求美化俯视人物、绑定骨骼，使衣服能反馈人物动作，并为后续手持武器保留能力；随后明确「发型先别管，先把衣服做了」。本轮只扩展衣服与身体骨架，保留原固定发髻，不制作可换发型。

## 骨骼与蒙皮

- 使用Godot原生 `Skeleton2D`、26根 `Bone2D`，包括骨盆、躯干、头部、两侧上臂/前臂/手/袖缘、腿链、左右衣摆三段链及腰带三段链。
- 五件衣料为躯干、左右衣袖、连贯袍摆、腰带飘带。头部、双手、双足分别为身体网格；共10件 `Polygon2D`，每件99顶点、160三角面。衣料使用实际骨骼路径及混合权重，袖口跟随手腕，肩部与躯干相接，衣摆在腰部锚定。
- 待机有轻微身体起伏；移动按真实局部速度反馈，手臂通过两段IK屈伸。出掌、架招、错步与受击读取原试玩的视觉状态，动画不自行产生伤害。
- 转身与启动/停止驱动衣摆、袖缘和腰带的阻尼惯性；暂停、失焦和配置时不推进场上衣料模拟。衣着面板有独立的待机、行走、出掌、架招演示时钟，不推进真实战斗。
- 当前为受限骨骼及蒙皮形变，没有布料自碰撞、真实三维遮挡、衣料破损或全身物理求解。

## 试装与数据连接

试玩新增V键或左下「衣着」按钮。面板可在七套男装之间试装，并放大查看四类动作；关闭后，场上人物保留试装衣服，重开战斗也保留该次衣着选择。

从主项目打开时，读取 `GameStartProfile.create_player_appearance_preview()` 的独立副本，经 `PortraitCatalog` 选择真实衣服身份。已适配的男修衣服会显示；女性或未适配目录保持明确标注的男修样例，不将其描述成该人物的真实衣服。此连接是建角外观预览，不是读取正式存档角色或接入正式装备系统。

当前不提供女修俯视衣服、不提供可换发型；不修改原男/女立绘PNG、人物外观目录或正式衣着资格规则。

## 后续手持物接口

主攻手和副手的手骨各有 `Marker2D` 挂点，名称为 `WeaponSocket` / `OffhandSocket`；挂点前向与前臂握持方向对齐。`mount_visual(Node2D, offhand)` 可接入武器、法器或其他手持显示节点，切换衣服时保留同一骨架与挂点。

本次只验证显示节点随手骨移动，没有新增武器物品、剑类关键词、攻击招式、射程、伤害、判定或装备收益。武器的握持姿态、不同攻击动作及正式装备读取留待具体武器任务确定。

## 实现与验证

`tools/action_battle_test/topdown_clothing_rig.gd` 为骨骼蒙皮及挂点；`topdown_clothing_library.gd` 为衣着身份和俯视材质。原 `topdown_battle_trial.gd` 只新增外观读取、试装暂停和视觉驱动；`topdown_hud.gd` 新增衣着面板。原四招与凶狼的费用、伤害、范围、冷却和资源循环保持。

检查包含权重归一化、混合蒙皮、七套身份与目录匹配、64朝向/动作相位顶点检查、衣摆惯性及冻结、换装保留挂点、挂点方向、实际鼠标试装、建角数据隔离、原战斗回归，以及实际窗口和连续演示。结果、画面和限制见[本轮实装记录](../../美术规范/俯视衣服骨骼化_20261104/README.md)。
