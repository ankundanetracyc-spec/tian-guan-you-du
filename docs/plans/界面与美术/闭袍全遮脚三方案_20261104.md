# 闭袍全遮脚三方案（候选）

2026-11-04。用户澄清：要鞋和脚完全藏在袍内的那种表现，而非允许露鞋尖，并允许先展示几个方案。先用同一玉虚内门常服制作三个动态候选，不改当前正式／试玩默认。

## 共同要求

- 鞋、脚、裤腿均不可露出；连续闭合袍面，无腰断口、无运动中裂叉。保留完整腿骨与原腿数据，负责动作支撑和地面脚点；闭袍可以采用独立的鞋脚渲染遮挡策略，但不得把它描述为未测过的真实布料碰撞。
- 衣摆接近地面，阴影留地面；上身、头发、手、原服装配色与纹样一致。只比较下摆轮廓和惯性，不混入新画风或大袖修改。
- 速度与技能不变，沿用允许滑步的既有表演限制；前进、倒退、转向、急停、出掌和错步中间相位都要验收全遮脚。

## 三个方向

| 方案 | 下摆轮廓 | 动态取向 |
| --- | --- | --- |
| A 直垂收口 | 较窄、自然垂下，贴地收整 | 摆幅小、反应利落，作为稳妥基础 |
| B 小幅钟形 | 膝下略宽，末摆舒展 | 柔软拖动和停步回落更明显，避免过度蓬起 |
| C 厚重叠摆 | 裹合感与前后层次更厚实，外表始终闭合 | 启动迟一些、回落慢一些，表现衣料重量 |

三个方案都不等于开衩劲装。劲装以后按衣服原设计单独配置，不能为了展示脚步强行给闭袍开叉。
