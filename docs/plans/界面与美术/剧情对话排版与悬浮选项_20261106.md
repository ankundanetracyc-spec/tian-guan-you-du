# 剧情对话排版与悬浮选项

2026-11-07，用户要求回应选项的最下边动态贴合对话栏上沿；横向仍位于右侧，不因立绘或其他界面元素避让。窗口尺寸和对话栏高度变化时随之调整，重叠时选项显示在立绘前方。此修订覆盖此前“纵向固定锚点”及“中间偏右并避让立绘”的旧布局；探查公式、费用、反应、禁斗、存档和战斗结算不变。

- 底部对话改为水平居中的有限宽度浅纸卡，两侧与底部留空；名单确实延伸至对话高度时对称收窄，不将整框推向右边。复用大世界纸墨边框，加实纸面以隔开下层HUD；不叠全屏暗幕、不加金饰或光效。
- 姓名统一在阅读区左上，正文紧接其下，底部只保留轻量继续／选择提示。正文过长可滚动，不靠扩大通栏挤占整个画面。
- 说话者与事项分开：叙述或无具体发言人的说明显示“旁白”；如需事项标题，在正文开头写“事项：内容”，例如“真传考核：……”，不把事项写成说话者。人物发言使用实际人物姓名，玩家发言及心声使用玩家姓名；不为普通旁白强加标题。
- 选项从正文框移出，在对话栏右上方独立竖排；深墨文字、灰绿悬停。选项区底边贴合对话栏实际顶部，对话栏因正文长短或窗口变化而改变高度时随之移动；横向只按窗口确定，不因立绘和名单避让。数量多时选择区内部滚动，不把选项塞回正文；选项放在立绘各部件之上，保证重叠时可读。
- 对话栏和立绘继续沿用现有比例：立绘按纸卡宽高缩放，显示高至多为卡宽30%及卡高2.1倍，不再独立按屏高放大。NPC靠卡右侧站立，玩家发言靠左侧，底沿贴住卡片上缘；切换与窗口变化后重新布局，保持图像比例。
- 使用同一 `StoryDialoguePanel` 与原选择回调；取消、旧回调防重、强制反击和读档续接保持原规则。
