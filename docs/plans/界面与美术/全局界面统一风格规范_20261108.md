## 一、定调

**纸墨作面，木石为骨，布绢盛物。**

面板像同一世界里制作的卷宗、木架、器具和收纳衬面：有连贯的支撑、清楚的边沿、克制的厚度和柔和接触影。信息落在干净的浅纸上，深墨文字清晰；灰青负责布面与石材，灰褐负责木作，松灰绿负责选中反馈。

统一对象是材质、字级、控件、边沿做工与交互反馈。具体布局按功能组织：人物适合卷宗，静室适合修行案面，行囊使用布绢收纳，藏经阁保留书架，善功堂保留原四列目录。各页不统一成屋檐、四列或三排架子。

本轮以以下两张**现有实机图**为完成度锚点，既有页面保持：

- [善功堂：当前分类与滑轨](../../美术规范/行囊交易善功堂实装_20261031/07_善功堂去装备与滑轨_20261107.png)：完整木作外框、浅纸目录、深墨字、淡山纹与克制选中色。
- [藏经阁：当前书脊与封面侧面](../../美术规范/玄览峰拓印接入_20261107/封面侧面_1920.png)：木架与石材相接、灰蓝布面书册、纸面详情、明确的前后厚度。

## 三、材质与层次

### 1. 木石承托

- 外框、横梁、书架和器具支撑采用去饱和灰褐木、灰青石；有连接关系、窄亮边与暗侧面。
- 结构强调角部、接缝和承重边；大面积木纹保持连贯，细节密度低于可读文字。
- 普通面板采用简洁角件、木压条或薄框；善功堂的屋檐、吊牌属于该场所的身份，其他页面不直接套用。

### 2. 纸面阅读

- 主信息面为偏中性的暖米白，避免大面积亮黄、纯白和油亮金边。
- 纸纹低对比，山纹放在边角或留白处；文字所在区域平静。列表、说明、条件和费用的底纹强度一致。
- 主纸面有一层薄边与接触影；内部信息块主要通过间距、分隔线、题签组织，避免层层厚框。

### 3. 布绢收纳

- 行囊与领取沿用已经认可的浅暖灰绢布 v5、淡灰褐格线和薄折边；不改成纸面。
- 书册和部分装订边采用灰蓝布面，与石材同属低饱和灰青家族。
- 质感不能遮盖物品轮廓、占格和命中区域；格子尺寸与容量继续由各系统主案决定。

### 4. 明暗与装饰

共同的空间顺序为：背景 → 承托 → 阅读面／收纳面 → 物品与文字 → 悬停／确认弹窗。边缘亮度和接触影表达厚度；不靠发光表达层级。

不使用霓虹描边、泛光、碎金点、密集污渍和漂浮厚框。场景插画用于场所身份与氛围，其面积服从实际信息和操作，不挤压功能区。正常表单不整张烘焙成图片，文字与状态保持真实控件。

| 选中纸面 | `selected` | 常态纸面亮度×`0.84` | 保持原纸色相与纹理，只压暗整张纸面；不额外染绿 |
| 深绿强调 | `accent` | `#526D60` | 主操作边沿、纸框明暗与文字强调，不追加选中细线 |
| 边沿 | `edge` | `#9A8A71` | 细边和分隔线，避免亮金 |
| 风险／不足 | `danger` | `#985344` | 与叉号、原因等文字同时出现 |
| 深墨悬停底 | `tooltip` | `#20251E` | 既有悬停深色变体 |
| 深墨面文字 | `inverseInk` | `#EFE6CD` | 深墨提示与紧凑暗底 |

## 五、文字、间距和缩放

字体统一为 `resources/font/LXGWZhenKaiSlabGB-Regular.ttf`。界面文字用实际字体排版，不把整段文字画进底图。

新通用组件以 **1672×941 设计单位**为参考；藏经阁已有 1664×936 样板和正式已确认控件继续按自己的基准，不为凑画布改动架位或物品尺度。下表是设计单位，不是要求在所有屏幕固定为同样像素。

| 层级 | 建议字号 | 用法 |
| --- | --- | --- |
| 页面标题 | 38–42 | 一页一个主要标题，承托于题签或页眉 |
| 区域标题 | 27–28 | 概况、目录、用度等区块 |
| 正文／行项目 | 21–22 | 主要阅读与操作信息 |
| 按钮 | 21–22 | 清晰短词，基线与正文一致 |
| 辅助说明 | 18–19 | 次要信息；必要条件不挤成小注 |

- 新组件间距以 8 为基本节奏，常用 8／16／24；阅读面内边距建议 24。
- 常规按钮建议高度 44–48，主要确认 50–52；窄图标按钮保持足够命中范围。
- 特定已经确认的规则保留：物品操作菜单 27 号／52 高；书脊 42×170 槽位与上限 18 的动态题签字号；36 格距和 200 格行囊。这些均不得由全局默认值覆盖。
- 在 1920×1080 和 1280×720 实看。小窗口优先调整留白与分栏，不把主要文字压到难读，不让字与装饰重叠；详情可随内容增长，专门阅读页可滚动。
- 同一标题不在导航、页眉和正文连续重复；数值列对齐，费用与确认操作在阅读顺序上相邻。

## 六、共用组件与交互状态

下表规定同族材料与反馈的示例，不是唯一控件模板。外框数量、页签形状、按钮轮廓、导航方向和信息布局均可按页面用途变化；复用材质、字级和状态语义，不要求外观逐像素相同。

| 组件 | 共用做法 | 功能边界 |
| --- | --- | --- |
| 页框／题签 | 灰褐承托、浅纸题签、克制角件、深墨标题 | 各页轮廓按功能；不统一套用善功堂屋檐 |
| 页签／导航 | 未选中米白纸，选中整纸压暗并保留原纸色相、深墨文字；保留原纸框与导航滑出，不加细线 | 保留各页当前切换、筛选与权限含义 |
| 列表 | 行间距稳定、浅分隔线、选中淡绿 | 不挪动固定架位，不把筛选当权限 |
| 普通按钮 | 纸面、薄木边、清楚文字 | 只使用实际可执行操作名称 |
| 主要按钮 | 同一纸面，深松绿压边或短签突出 | 颜色不冒充足够资源或可执行判定 |
| 输入／搜索 | 内凹浅纸、细边；空白提示与实际输入区分 | 搜索、数量与费用仍读真实数据 |
| 深墨悬停 | 深墨底、米白文字、窄角标；字级与全局同族 | 保留既有暗底批准；正文完整展开，无内滚动条 |
| 确认弹窗 | 窄木框浅纸面，标题／代价／确认取消清楚 | 遮罩关闭与 Esc 按各系统主案，不自行增加扣款 |
| 图标与物品 | 沿用已认可手绘物品，完整轮廓在格线上方 | 不用整块高亮遮挡真实占格 |

按钮状态统一：

1. **常态**：可读纸面、薄暗边、轻接触影。
2. **悬停**：边沿与纸面轻微提亮；文字和组件尺寸不变，无光晕。
3. **按下**：纸面略深、接触影收短，可做轻微压入反馈。
4. **选中**：整纸适度压暗，与未选中纸面形成明暗差，保持原纸色相、纸纹、纸框和深墨字；不额外染绿、不添加底部或侧边细线，与普通悬停区分。
5. **键盘焦点**：清楚的实线轮廓，进入当前可见内容；不以颜色变化代替焦点。
6. **不可用**：降低材质对比但文字仍能读，必要时给出实际原因；不能只降低整个控件透明度。

通用悬停／页签反馈建议 100–160 毫秒；尊重减少动画设置。专用演出沿其主案，例如藏经阁抽书 240 毫秒，不能用通用过渡覆盖。

## 八、信息与功能不得随换肤改变

## 九、后续落地顺序

1. **当前只做百工资料**：按展开工艺簿册、册页签与薄纸目录制作独立样稿，减少重复厚框；不接入正式游戏。
2. **交付这一面板的完整画面与可操作样稿**：检查实际内容、字级、材料、状态与两档窗口可读性，不能只给零散控件代替整页验收。
3. **等待用户验收后再继续**：未通过时只修当前面板，不自动开始下一面板；通过后依用户指定顺序推进。
4. **接入游戏另行按已确认范围实施**：不把样稿通过等同于授权批量迁移。善功堂、藏经阁和凝核保持，角色／静室继续保留现有独立样稿。

运行时组件未来应共用主题参数，避免 `WorldHudStyle`、`QuietRoomStyle`、人物页和各独立面板继续分别定义同一用途的颜色与控件。本轮结构化参数用于交付和比对，**尚未成为运行时依赖**。
