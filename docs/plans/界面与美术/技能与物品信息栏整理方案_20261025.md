## 三、共用视觉层次

1. **名称与身份**：图标、名称；下方简短显示类别、品阶。关键词独立成行。
2. **关键内容**：直接说明做什么、获得什么；数值与单位作为完整短语，效果正文使用主要文字色。
3. **条件与限制**：目标、费用、触发、使用条件、次数及冷却使用明确标签。代价和受限状态用克制的颜色提示，同时保留文字。
4. **两档公式与规则详解**：简略版只显示结果；详细版在正文末尾集中列计算来源，逐项写“名称：结果 = 具体代入式”，无名称时只写“结果 = 具体代入式”，项间空一行，函数为`min(...)`／`max(...)`。通用结算说明继续通过独立入口主动查阅。

所有悬停的长段字段采用“效果：”“化法追加：”等标题独立一行、正文从下一行开始，长段内自然折行。消耗、目标、次数、冷却等短字段保持“标题：内容”同行；不因本轮排版机械增加全部字段之间的空行。两档效果正文都不夹公式，只有详细档在末尾增加计算来源。

沿用深墨底、浅纸字、灰金边线。名称、正文、说明形成三级字级，具体字号与宽度通过实际窗口验证后确定。栏目仅通过间距、细线分组，不为每行加框或铺底色；相同字段不在副标题和正文重复。

空栏目不占位；未知且影响决策的信息明确为未知，不用0冒充。零费用、无限次等有规则意义的值仍需显示，不能当成空内容删除。

## 四、技能信息栏

| 位置 | 内容 |
|---|---|
| 标题区 | 图标、名称、关键词；撤下旧三分类 |
| 第一组短字段 | 费用、目标；长字段自然换行 |
| 效果区 | 标题后换行，正文按发动条件与结算顺序自然折行，动态效果显示最终结果；详细来源集中在正文末尾逐项写“名称：结果 = 算式”，项间空一行 |
| 限制区 | 剩余次数、冷却、队列补充；不限次数也明确展示，无冷却时不设空栏目 |

特殊技能不能硬塞进普通模板：

- 应对技能分“触发应对时／未触发应对时”两组，各自展示条件、费用和效果。条件作为句子的一部分，用“时，”“后，”“若……则……”衔接，不在消耗、目标或效果字段内部再写“触发应对：”等嵌套标签。例如“触发应对时，消耗体力1、法力0”“未触发应对时，空放”。

同一分支的触发条件和结果连续写成一段，不在两句之间手动换行；只有不同分支之间留空行，行宽不足时由界面自然折行。
- 复命等依赖另一技能的情况，展示当前复制对象、本技能费用、复制费用、合计及双方必要限制；没有可复制对象时明确说明。
- 2026-10-29用户确认：复命有复制对象时，技能槽、悬停和行动队列使用被复制技能的图标，名称显示“被复制技能名（复命）”，关键词随复制对象展示。复制对象变化时自动刷新；没有对象时保留复命自身图标名称并说明尚无可复制技能。复命消耗、复制技能消耗、合计消耗各占一行，目标、效果和使用限制继续分组。目标随机规则保持，用户已明确此前对目标的疑问为看错；不据此改成手动选目标。显示身份变化不修改复命原资源、队列技能身份、费用、次数或冷却，也不提前锁定将来真正执行时的复制对象。
- 多段伤害保留段数和每段数值；目标防御未知时继续标为当前预估。
- 化法追加按来源分组并紧接被追加效果，不重复整份基础技能。
- 技能栏和行动队列共用格式化内容；动态刷新保留现有角色、状态、费用和次数来源。

在现有格式化阶段生成结构化段落，不用正则从成品文案猜测触发条件和公式。保留旧正文接口，逐项迁移。

2026-10-27关键词纠正：现行技能没有“重击”关键词，痛击的关键词显示为无。撤下资源中残留标签、词条解释及依该标签触发的旧拳架增伤／消耗分支，不将这套旧规则改名或隐藏到伤害中。痛击及其既有化法的基础伤害、属性系数、费用与目标保持；普通叙述、技能名称或美术动作名中的“重击”二字不等同于关键词，不作全词删除。

## 五、物品信息栏

| 类别 | 栏目与顺序 |
|---|---|
| 材料 | 图标、名称 → 品阶 → 五行 → 质地 → 相性 → 功用及各自品级 → 简介；一个字段一行，不显示分类、数量、价格、所需贡献与领取来源；简介为空也保留“简介：” |
| 丹药 | 图标、名称 → 丹阶 → 丹效 → 药效 → 丹毒 → 简介；每项一行，不单列使用条件；少数必要条件写入简介，空简介保留标签，不显示数量／价格／炉次评分／容器说明／规则详解 |
| 装备／器物 | 图标、名称 → 品阶 → 器类 → 器蕴 → 本体专属属性（剑为独立锋锐行） → 装备效果 → 化法 → 技能 → 简介；凡器／法器同一模板，固定顺序，缺项显示“无”，简介始终留位置 |
| 秘籍 | 图标、名称 → 修习境界 → 修习要求 → 关键词 → 简介；要求字段固定保留，无要求显示“无”；不重复境界条件，不展示研读值 |
| 衣着 | 图标、名称 → 适用人物（男修／女修／通用） → 简介；简介为空也保留位置，不套用品阶、器蕴、装备效果、化法等器物字段 |
| 其他 | 读取真实用途与效果；配置缺失时诚实说明，不推测效果 |

器物的“本件贡献”和“角色已激活收益”必须区分；化法、在场占用和施法临时占用遵循现行规则，分别标注，不合并成一个含义不清的灵识数字。
