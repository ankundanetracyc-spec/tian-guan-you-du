# 全局只读悬停：鼠标穿透与拖拽隐藏

> 2026-11-08，用户最新交互裁定。用户指出配招拖放被信息栏遮挡、截住操作，并明确允许相关规则适用于全局。本案统一只读悬停的输入边界；深色单栏、正文顺序、公式、占格底栏及各系统真实操作继续按各自当前主案执行。

## 全局规则

1. **拖起即收起信息栏。** 不等待原悬停消失延迟；拖拽期间，指针经过招式、物品、空格、列表及落点都不重新显示信息栏。旧的延时任务、动态数据更新和“立即显示”请求也不得重新打开。
2. **只读信息栏全部穿透鼠标。** 框体、文字、图标、分隔线、占格图、底栏提示、隐藏的内部滚动条及后来加入的内容都不接收点击、右键、滚轮或拖放。鼠标在其视觉范围内时，底下真实控件仍按原规则响应；不手工再转发一次输入而产生重复操作。
3. **信息栏不为自己维持显示。** 仅指针仍在真实来源上时维持。离开来源后按既有短延迟收起；移入信息栏自身不会停止、重启或延长该计时。当前共用组件的消失延迟仍为0.10秒，正常显示延迟仍为0.10秒。
4. **拖拽结束后重新认来源。** 取消、放入、拖出或拖拽控件离树后，重新检查指针下的有效来源，按正常延迟读取当下信息；不恢复拖起前的旧对象或旧数值，不因拖拽完成直接弹回旧卡片。
5. **滚轮归真实操作区域。** 只读悬停正文完整展开、没有内部滚动条。悬停挡在列表上时，滚轮滚动列表；挡在允许缩放的世界空白上时，仍按世界规则处理。列表与地图之间的原有输入隔离保持。
6. **明确打开的阅读页另论。** “规则详解 [F1]”在悬停内只作键盘提示，不是可截鼠标的按钮。非拖拽时F1仍可打开独立规则阅读页；该专门页面继续接受正文滚动、关闭按钮与Esc，不将只读悬停的穿透要求套到它上面。

本规则适用于配招、战斗、行囊、领取、储物、交易、人物属性与其他采用共用只读信息栏的入口。已有操作菜单、确认对话框、方案选择页及明确打开的档案／规则阅读页不是只读悬停，不据本案撤去它们必要的交互。

## 拖拽与右键路由

拖拽已经由控件接管时，世界级“右键返回／关闭菜单”不抢先消费同一次右键。右键按下与抬起交给拖拽控件；具体是否用于旋转由该系统自身已定义操作决定。非拖拽时继续原来的世界返回、菜单关闭等行为。

拖拽结束只结束显示抑制，不修改物品、招式、放置合法性、资源、次数或任何战斗结算。信息栏不以“自己隐藏了”为由取消实际拖拽。

## 实现契约

共用入口为`HoverInfoManager`：

- 原生拖拽由`NotificationDragBegin/End`及`Viewport.GuiIsDragging()`自动识别，开始时立即关闭当前卡片并取消待显示任务。
- 自定义拖拽可调用`HoverInfoManager.SetDragInProgress(Node? owner, bool dragging)`；开始传`true`，结束／取消传`false`。每个存活所有者独立持有状态，不能由一个拖拽结束误解除其他来源；所有者离树自动释放。
- `HoverInfoManager.IsDragInProgress()`供输入路由与交互组件查询原生或显式拖拽。`GameplayInputRouter`在此期间将右键让给拖拽控件，清除旧的世界右键按压状态。
- 所有内容入口与延时展示入口都检查拖拽状态。卡片所有子控件递归设为`MouseFilter.Ignore`、不接焦点；动态新增内容也立即遵守。
- 正常显示恢复时，从真实GUI命中来源重新读取提供器，而非复用已移动、已消耗或已卸下对象的旧说明。

本次不改变[局内招式悬停当前单栏布局](局内招式悬停统一与伤害显示_20261108.md)、[物品悬停占格与预估](物品悬停底部占格与范围展示_20261108.md)、[简略／详细信息规则](信息展示与规则详解分层规范_20261026.md)中的正文、公式或数值口径。

## 验证范围

专项场景为[HoverDragPassthroughSmoke](../../../tools/HoverDragPassthroughSmoke.tscn)：覆盖真实点击与滚轮穿透、所有内外子控件、动态新增内容、离开来源后不续命、原生与多所有者自定义拖拽、结束恢复以及F1独立阅读页。旧滚轮导航专项删除“悬停卡接收滚轮并内部滚动”的历史断言，改验底下真实列表响应；地图滚轮隔离、裁切及右键返回等其余断言保留。

主任务已统一运行上述专项，28项通过，覆盖共用组件的实际点击、滚轮、原生／显式拖拽及F1阅读页边界。结果见[全局悬停交互验收](../../美术规范/招式盘拖放与遍历反馈_20261108/全局悬停交互验收.json)；该专项结果不等同于整个游戏全部旧控件已经逐一人工验收。
