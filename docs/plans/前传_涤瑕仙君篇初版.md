# 前传：涤瑕仙君篇初版

> 状态：早期单人前传草案，当前不进入制作
> 定位：独立的单主角修仙故事构想。玩家在第二世与玄镜一同降临此界，从普通起点成长为“涤瑕仙君”，最终尝试开天；本案不定义当前主线的主角关系与系统承接。
> 本案不是现行主线依据。若未来重启，须重新确认叙事设定、玩法范围与当前世界观的关系。

## 一、叙事前提与边界

### 已确认

```text
第一世：玩家是地球人，未到此界。
第二世：玩家与玄镜一同降临此界；意识在自身肉身中，玄镜是无意识的随身器物与金手指。
第二世后期：玩家成长为涤瑕仙君，并尝试开天、打通飞升之路。
```

### 与现行主线的关系

本案只是独立的历史时代构想，不是现行主线前置，不定义当前主角的来历、血缘、继承关系或系统迁移。未来若重启，须由当时的主线专题重新确认是否衔接。

### 本案不决定

- 第二世的降临地点、降临形态、起始身份、姓名与初始同伴；
- 涤瑕道号何时获得、由谁授予；
- 开天的具体方法、所需器物与天道如何逐步阻拦；
- 玩家是否可改变历史结局，以及改变的边界。

这些内容必须另立剧情专题确认；玩法框架不以未定细节为前提。

## 二、前传的体验定位

前传构想聚焦**单主角成长、积累资源、最终挑战天地规则**，不承担验证或导入其他规模的组织经营系统。

| 支柱 | 个人修仙中的含义 |
|---|---|
| 培养 | 主角的功法、道途、装备、战斗构筑与决断 |
| 交易 | 跑商、交换稀缺物、建立信誉与供给网络 |
| 经营 | 管理洞府/据点、委托往来、维持个人修行所需供给 |
| 战斗 | 历练、护送、夺取资源与破局 |
| 人物 | 通过交谈与具体事件了解人物 |

玄镜的金手指不能是无成本的“显示答案”。它的可玩价值应限定为已设定的三类能力：

- **推演**：展示有限的趋势、风险或候选结果；
- **映照**：看见隐藏线索、法则痕迹或物品/地点的异常；
- **记忆**：记录重要人物、地图与功法线索。

具体消耗资源、冷却、失败代价待定；初版只要求每次使用都需要玩家仍自行承担行动与后果。

## 三、核心循环

```text
修行与构筑
   ↓
接取线索 / 商机 / 委托
   ↓
旅行、交易、据点经营或战斗历练
   ↓
获得物资、信誉、人物信息与法则线索
   ↓
强化主角、积累资源、推进开天调查
```

每轮至少产生一个不能靠单纯刷怪解决的选择：

- 资源自用还是用于交易、修行或补给；
- 走安全但利润低的路线，还是承担战斗风险去获取稀缺机会；
- 使用玄镜提前看见风险，还是保留其能力应对未知事件；
- 将时间用于继续修行，还是投入交易、探索与资源获取。

## 四、章节结构

章节以“功能和故事逐步升级”为目标，不预设未定角色、地点或具体事件。

### 第一章：降临与立足

**主题：一个地球人在陌生天地中活下来，并第一次学会使用玄镜。**

- 主角从普通起点开始，获得基础行动、旅行、采集/委托与最小战斗构筑。
- 玄镜首次提供有限推演或映照，帮助玩家理解其不是普通器物。
- 交易以生存调剂为主：补给、出售低阶收获、取得基础修行资源。
- 经营只需一个可恢复和存放物资的落脚点，不引入势力管理。

**章节结束状态：**主角获得稳定修行路径、第一批可靠物资来源，以及至少一条可重复往返的安全路线。

### 第二章：修行与立业

**主题：个人变强不足以穿过乱世，必须拥有资源与信誉。**

- 主角从单次历练转向可重复的交易、制作或资源获取链。
- 开放小型据点经营：提供补给、制作、信息或雇佣/委托中的一种功能即可；不要同时做全套。
- 交易开始引入价格差、限量货物、信誉或期限，使信息和路线具有价值。
- 战斗从单体遭遇扩展为护送、资源争夺或据点防守。

**章节结束状态：**主角建立了可持续支持个人修行的资源来源，并首次意识到灾变不是个人可独自解决的问题。

### 第三章：镜照与开天调查

**主题：玩家发现飞升受阻不是个人修为不足，而是天地规则的拦截。**

- 玄镜的映照逐渐从地点线索升级为法则线索；它仍展示有限信息，不直接给出终局答案。
- 高阶交易与经营转为筹措难以替代的资源、通行权、盟友和信息。
- 战斗转为应对阻挠者、争取关键地点或完成高风险试炼。
- 玩家明确开天不是“再打一场更大的战斗”，而是同时具备力量、资源与对规则的理解。

**章节结束状态：**主角确认开天目标与代价，决定以玄镜参与破除飞升拦截。

### 第四章：开天、失败与封镜

**主题：个人天人与世界秩序的冲突。**

- 前传以开天行动收束，不能把它设计成普通副本结算。
- 商路、据点和此前积累应在终局中提供不同支援或代价。
- 历史结局构想：天道阻止开天，涤瑕仙君陨落；其他后续因果留待重启本案时确认。
- 玩家选择的作用是决定留下些什么：可被本传发现的遗物、地点状态、人物因果或记忆碎片；具体继承规则待定。

## 五、最小可玩前传（Vertical Slice）

不要先制作完整天人传记。先做能证明方向的 45～60 分钟纵切片：

1. **降临后的落脚点**：主角、玄镜、最小仓库、基础修行与一条安全路线。
2. **一趟交易/委托**：在两个地点之间取得、出售或交付少量物资；让报价和时间产生取舍。
3. **一次玄镜推演**：给出有限风险或收益趋势，玩家仍需自己选择。
4. **一次可撤离的战斗**：高价值奖励受敌人把守；胜、败、撤离都改变后续资源与关系。
5. **一次留痕**：完成后写入“前传遗产”记录，证明未来可被本传作为记忆/遗物读取。

纵切片验收不是剧情长度，而是玩家是否感到：玄镜能帮助我看见机会，但我仍需靠修行、经营、交易和战斗去兑现它。

## 六、开发顺序

### P0：先确认叙事底稿

- 若未来重启本案，先重新核对第一世、第二世和涤瑕仙君身份关系；不以本草案改写现行主线。
- 确定第二世降临的起点、第一章危机、第一份修行机缘与第一段商路；只需这些，不一次定完数千年历史。
- 确定历史固定点：开天失败、涤瑕陨落、玄镜封镜。

### P1：实现单主角通用底座

- 从现有角色、功法、技能库、物品、地图旅行、统一奖励事务中抽取可复用接口。
- 增加“前传编年状态”与“遗产标记”，不直接改写本传存档。
- 做最小市场流程，验证交易不是静态买卖。

### P2：完成纵切片

- 实现本案第六节的连续节点。
- 为每个节点加入明确的资源、时间、战斗和关系反馈。
- 在本传中只提供一个只读的“前传遗产”展示入口，验证两个篇章的连接方式。

### P3：按章节扩展

- 先扩展第一、二章，验证单主角的修行—交易—据点—战斗循环。
- 开天调查与终局最后制作，且必须在完整主线专题确认后开工。

## 七、风险与控制

| 风险 | 控制办法 |
|---|---|
| 前传规模吞没本传开发 | 先做纵切片和可插入的记忆章节；底层系统必须复用 |
| 玄镜金手指破坏决策 | 只提供不完整信息，使用有机会成本，行动后果由玩家承担 |
| 前传结局已知导致缺乏张力 | 把悬念放在“为何失败、留下什么、谁继承了什么”，而非是否陨落 |
| 历史与本传互相矛盾 | 建立固定历史点与遗产标记；未确认剧情不写死 |
| 单主角缺少经营感 | 通过据点、商路与委托表达个人积累与取舍，保持玩法聚焦于修行 |
