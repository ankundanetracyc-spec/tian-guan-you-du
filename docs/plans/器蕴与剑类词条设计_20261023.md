# 器蕴与剑类词条设计

> 2026-10-24：[运行与生成主案](器蕴运行与生成接入_20261024.md)已实施，2/4点总10%/20%为测试参数，高档不叠低档完整比例。下文保留历史讨论，实际状态与算法由新主案覆盖。

状态：2026-10-23，讨论提案，尚未实施。用户最新确认方向：暂只设计两种器蕴，名称含蓄，器蕴奖励采用百分比；普通单件词条仍优先固定值。用户要求构思器蕴与剑的常见词条。候选点数、激活门槛、奖励和生成系数均须标定，不替代正式装备规则，不修改现有战斗卡。

## 一、承接规则与旧稿差异

承接[剑关键词与固定值收益](剑关键词与器物固定值收益设计_20261023.md)、[器物属性来源](器物属性与装备收益规划_20261022.md)、[现有剑修四招](公共技能节点网与首批节点实施.md)。

- 器物本体主要来自身材，角色收益主要来自性材；各岗位并非独占来源，统一效力分配守恒。
- 普通单件收益优先固定值，器蕴激活奖励采用百分比。符合条件的多段物理伤害逐段获得完整增伤，群攻目标口径仍待确认。
- 凡器只有本体性能与基础属性，不形成特殊效能、化法、主动技能或器蕴。
- 器物不增加五行字段；阴阳七档独立保留。器蕴不默认要求中和，不把材料五行种类当成可累计贡献。
- 正式器物槽与多器配置尚未确定。本篇设计累计协议，不增加装备位置、不承诺当前能凑齐任何档位。

[旧首轮方案](剑类炼器首轮试算方案_20261021.md)的“每件仅一种器蕴、固定1层、锋锐器蕴奖励百分比增伤”仍为历史候选。本篇建议改用实际成器贡献点，器蕴名与本体属性分开，不把旧候选当作已确认规则。

## 二、器蕴是什么

器蕴是器物炼成后留下的、可与其他已装备器物累计的构筑倾向。单件词条立刻描述该件能提供什么；器蕴贡献只描述它为某类组合提供多少点，达到门槛才激活公共奖励。

例如一件剑记录“惊鸿 +3”，表示本件贡献3点，不代表已激活4点奖励。人物汇总才能显示“惊鸿 3/4”。不得把人物当前累计保存进单件器物，也不在只有行囊持有时计算激活。

器蕴不是技能关键词、战斗状态或额外资源，不随攻击次数涨层，不通过战斗临时叠加来替代装备累计。

## 三、单件贡献与组合激活

### 3.1 推荐贡献规则

1. 同件器物可以没有器蕴，也可有一种或多种；没有免费的主蕴、副蕴槽。每种贡献都来自实际分配的有效材料潜力。
2. 初版候选：每件对同一蕴种贡献1—3点。低于1点不生成，超过上限的候选不继续吞掉无效预算。上限是待校准的效果模板参数，不对应原料身份或固定器物小档。
3. 同件相同蕴种先合并再计点，材料部位、材料种数和相同词条数量不分别多算。数量更多、造诣更高只通过加工结果间接影响贡献。
4. 同件若形成多种器蕴，需要分配更多潜力与通路，单项贡献通常更分散；不另设“最多两项功用”或随机副词条数量来替代预算。
5. 器蕴随成器快照固定。换装不重新炼算，改名也不改变贡献。

### 3.2 推荐累计规则

```text
某器蕴累计点数 = Σ 当前有效装备实例对此器蕴的贡献
某档激活 = 累计点数 ≥ 该档门槛
```

初版先讨论2点、4点两档，不急着扩展6/8点。达到4点时保留2点奖励，再获得4点奖励；每档只结算一次。超过最高门槛不循环发奖，也不把8点解释成两套4点奖励。

按实例ID去重；同一实例不能因多个技能引用、详情刷新或内外使用形式重复累计。若未来装备规则允许，两件同名不同实例可各自贡献。此处不放开多器装备。

不要求所有贡献者都是剑。剑、甲或其他器物只要实际形成相同器蕴即可协同；“惊鸿”提供的剑技收益仍要求玩家使用合格且带有“剑”关键词的技能。跨器类只共享器蕴含义，不共享材料位置数量或本体属性。

装备生效、卸下、换装重算，未达到门槛的档位不保留。战斗中换装、器体崩解、长期破损与套系失效的关系留给正式装备/维护规则；目前不按器体在场状态擅自开关所有器蕴。

## 四、首批器蕴候选

当前只保留两种器蕴，每种先表达一个核心效果，不加入剑意器蕴或混合触发奖励。建议名称为“惊鸿”“抱朴”；名称尚待用户认可，具体比例与激活门槛仍需标定。

| 器蕴拟名 | 核心效果 | 档位处理 |
| --- | --- | --- |
| 惊鸿 | 带有“剑”关键词的技能，造成的物理伤害提高X% | 高档提高同一百分比，不再追加固定伤害或其他触发 |
| 抱朴 | 装备者的物理防御提高Y% | 高档提高同一百分比，不再追加化解或剑意奖励 |

X、Y为待标定参数，不能当作已经实现的属性键或倍率。2/4点仍只是门槛候选；各档必须注明该档总加成，高档与低档不重复叠加同一个完整倍率。若沿用累计档位实现，只施加高低档差额，保证结果等于高档标示总值。

惊鸿只修正合格的原有物理伤害，不给养锋、格剑无伤害部分新增攻击；多段中各段符合条件的物理伤害均正常获得比例修正，不在多段间分摊一次比例。抱朴增加的是角色物防，不是物理减伤百分比、不减少最终扣血，也不作用于器体。它作用于哪些物防来源、与其他百分比来源如何汇总，以及惊鸿与既有增伤的合并顺序，均须在结算接入前按现行通道统一，不另造独立相乘区。

单件普通词条固定值与器蕴奖励百分比分工不同，不因这次修订把所有剑词条改成百分比。藏锋器蕴从当前候选中移除；剑意相关单件词条仍可作为后续讨论方向，但不因此自动生效。

## 五、器蕴怎样由材料形成

器蕴使用统一语义矩阵和工艺约束，不逐一列“某矿石等于某器蕴”的配方。初期候选语义：

| 器蕴 | 内容潜力 | 加工条件 | 不能使用的捷径 |
| --- | --- | --- | --- |
| 惊鸿 | 破所支持的实际攻伐潜力 | 连续传导、稳定留存及剑类构筑适配 | 名字中有剑、身材看起来锋利就免费给点 |
| 抱朴 | 固所支持的防护潜力 | 防护效力能稳定实现及必要通路 | 主体硬就同时免费增加物防、化解和器蕴 |

破/固的既有语义作为两种器蕴的内容依据；贡献点仍由实际分配效力和公共工艺条件计算，不是材料出现相应功用就必定获得器蕴。

与单件属性、常驻效能、化法、技能共享来源预算：

```text
对每个来源维度u：
分给基础属性的效力
+ 分给常驻效能的效力
+ 分给化法/技能的效力
+ 分给器蕴的效力 ≤ 实际有效供给Eᵤ

某蕴可实现效力Xᵣ = 经共同承载、根性和工艺约束分得的效力
贡献点pᵣ = min(单件上限cᵣ, floor(Xᵣ / 每点成本qᵣ))
```

q与c是公共模板参数，须用真实材料目录标定；不随材料名称改公式，也不直接使用材料品级当贡献点。器蕴分配同样占用共同承载/根性及适用的留存、导通，防止绕开工艺约束。超出计点上限的部分不分配；不足一整点的损失按统一规则记账，不送出保底1点。

器蕴点越集中，该项越容易帮助跨档，但留给单件直接属性、化法和其他蕴种的预算会变少。玩家既可追求单件实力，也可接受部分单件强度转入组合潜力，不是增加器蕴就白赚一份奖励。

造诣影响保留率、加工可行性、通路与位置，间接帮助保留器蕴效力；不按造诣等级免费发点。材料实际潜力不足，造诣不能凭空炼出3点器蕴。炼前仍只展示客观投料与过程量，炼后才揭晓蕴种和贡献。

## 六、剑的常见词条候选

词条是实际效果的展示单位，不再随机抽一个与材料无关的名字。以下简称可以供内容整理使用，玩家面板优先显示效果本身。没有固定“剑必带三条”的规则。

### 6.1 基础属性

| 方向 | 显示形式 | 条件与阶段 |
| --- | --- | --- |
| 本体锋锐 | 锋锐 N | 剑固有本体属性，不作为随机词条再次抽取 |
| 防护 | 物理防御 +N | 已有固定值方向，由有效防护来源支持 |
| 生存 | 最大生命 +N | 后续补材料到属性模板，不因装备自动恢复N点生命 |
| 命中 | 精准 +N | 真实数值，不直接写命中率 +N% |
| 回避 | 闪避 +N | 真实数值，不直接写闪避率 +N% |

首版优先物防；最大生命、精准、闪避仍为候选，不把所有预留字段一次性加入生成表。体魄、灵慧、神魂、剑道造诣、速度、体力/法力上限等牵动多个体系的属性另案，不作为普通剑词条普遍生成。

### 6.2 常驻效能

| 内容简称 | 玩家文案方向 | 识别与触发 |
| --- | --- | --- |
| 剑技增伤 | 带有“剑”关键词的技能，每段物理伤害 +N | 剑标签且确有适用原始物理伤害；不作用于养锋、格剑的无伤害部分 |
| 应对增幅 | 带有“剑”关键词的技能，实际应对时化解量 +N | 有真实应对和化解；每次实际生成化解时修正，不按敌方每段重复生成 |
| 护盾增幅 | 带有“剑”关键词的技能，给予自身的护盾 +N | 技能原本具有自身护盾效果；不让所有剑招凭空带护盾，当前四招没有此项接点 |
| 攻后护持 | 带有“剑”关键词的技能首次对生灵造成物理伤害后，自身护盾 +N；每次技能一次 | 进阶触发模板；群攻与多段不重复触发，同条护盾不递归触发自身 |
| 养意 | 带有“剑”关键词的技能实际获得剑意时，额外获得N层；每次技能一次 | 进阶模板，保留10层上限；只修正已有剑意获得事件，不创造额外事件循环 |
| 蓄意增伤 | 尽锋每消耗一层剑意，本次伤害额外 +N | 进阶模板，读取实际消费；不另行扣剑意，不改其他技能的剑意含义 |

伤害增量按已确认规则逐段加；护盾、化解和剑意的频率按各自效果事件判断，不拿伤害多段规则扩展成所有收益都多次生成。独立常驻词条的固定值与器蕴的百分比若共存，须分别记录单位并统一结算顺序，不新建隐蔽倍率；总强度需同时计入标定。

### 6.3 定向化法

| 化法方案 | 适用技能 | 可组合修正 |
| --- | --- | --- |
| 攻伐化法 | 剑标签，且含合法物理伤害 | 每段物理伤害 +N；本次额外忽略固定物防N，二者各分预算 |
| 应对化法 | 剑标签，且能实际应对并生成化解 | 实际化解量 +N；若附带额外护盾，必须明确新增触发模板，不默认赠送 |
| 养意化法 | 剑标签，且实际获得剑意 | 原获得量额外 +N，保留状态上限；需先完成剑意修正模板 |

同件器物所有化法只有一个绑定对象，条目必须有共同的适用技能。不能把攻伐、守御、养意三套互斥条件直接堆成一个必能使用的包；如何由候选自动选成最终方案沿用前案待决项。化法不占主动技能槽、不单独排队；获授主动技能另有完整资源、费用和目标审核。

## 七、一个组合例子

以下只是设计演示，不对应固定材料配方，也不承诺已有多个装备位置：

```text
甲剑：锋锐5、物防+4、剑技每段物伤+2、惊鸿贡献3点。
乙器：抱朴贡献1点、惊鸿贡献1点。
```

若未来装备配置允许两者共同生效：惊鸿累计4点，抱朴累计1点。惊鸿达到候选高档，提供该档标明的物理伤害百分比；抱朴未达到候选2点门槛，不发奖励。甲剑自身固定增伤仍按每段生效，不与惊鸿百分比合并写成固定点数。

例如带有“剑”关键词的技能原本三段各4点，先以单件固定增伤+2形成6/6/6。惊鸿的比例再按最终确认的伤害合并顺序处理，之后正常结算防御等效果；本例不提前锁定比例、乘区或取整。没有物理伤害的养锋不因此出现伤害。

移走乙器后惊鸿退为3点，按候选门槛回到低档比例，不保留4点档总比例。实例中的“惊鸿贡献3点”仍不变。当前不实现这次换装，也不创建乙器赠送给正式存档。

## 八、展示与实施边界

单件器物信息分为本体属性、基础加成、器物效能、化法、获授技能、器蕴贡献；没有的区块可隐藏。器蕴区只写本件蕴种与贡献，展开可查看公共档位奖励；不把未激活套系奖励混成单件固有属性。

人物未来装备页显示累计点数、已激活档位、下一档门槛及各实例来源。例：“惊鸿 3/4；2点档已激活，距4点档还差1点。”器物本身显示“本件贡献：惊鸿 +3”，不显示一个来源不明的3/4。

初期最小范围建议：固定物防、剑技逐段固定增伤、实际应对化解；惊鸿/抱朴两种器蕴。先通过独立聚合器验证门槛、实例去重、来源撤销、未达档不发奖，再接未来装备设计。剑意词条、攻后护持及获授技能后置，当前不设计第三种器蕴；未经确认不向现有样本补发器蕴或词条。

待确认：器蕴是否采用本文预算与1—3点上限；2/4点档与两种器蕴具体比例、比例合并口径；多蕴贡献是否按本文允许；群攻目标口径；互斥化法方案的生成；装备/崩解/破损的完整生效边界。本文不要求先定装备槽数才能讨论词条，也不因槽数未定自行增加位置。
