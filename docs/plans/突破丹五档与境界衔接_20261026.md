## 一、当前开放范围

- 回春丹保留炼制、五档物品、领取、世界使用和战斗战备。
- 通脉丹、静心丹的当前效果暂不采用，退出已知丹方、炼制识别、世界使用和战斗战备；兑换、交易及新奖励共用禁用检查。定义文件与毒值保留，方便后续重做及读取旧档。
- 旧库存物品保留可查阅，不自动删掉、替换或发补偿；原有通脉战备配置不能继续使用，不消耗旧物品。自拟配伍记录不删除，但不会绕过禁用目录炼出被下架丹药。
- 材料十二功用不撤销：通仍可在使位帮助混合，镇仍可在佐位处理相激；只是对应的两个成品暂不开。
- 定脉／归元定息只用于各自突破关口，不可提前直接服用或编入战备；炼制来源与其他新增丹种暂不推进。

## 二、突破丹怎样区分五档

两种丹分别保持原本关口：

|丹药|丹阶规划|对应关口|最基础职责|
|---|---|---|---|
|定脉丹|九品|云息三层→四层|满足这一关的丹药条件|
|归元定息丹|七品|云息九层→十层|满足这一关的丹药条件|

共同五档为薄效、良效、优效、极效、满效。任何成丹档都能作为该关口所需丹药；低于20未成丹没有物品，不能用于突破。不再另外设置“至少优效才可过关”的隐藏要求。

药效不用于缩短三→四或九→十的突破闭关。它们在成功突破后分别作用于下一段长期修行，并配合各档丹毒差异：

|丹药／效果|薄效|良效|优效|极效|满效|
|---|---:|---:|---:|---:|---:|
|定脉：晋入四层后补入吐纳进度|1缕|2缕|3缕|4缕|5缕|
|定脉：成功使用后丹毒|18|15|11|8|4|
|归元定息：归元九息所需时间缩短|2%|4%|6%|8%|10%|
|归元定息：成功使用后丹毒|30|24|18|12|6|

定脉补入的灵力直接计入云息四层的四→五进度；云息四层下一层需求以现有境界公式为准，奖励不溢出、不自动晋层，也不改变永久属性。五档基础补入量固定；若按丹毒规则折减直接灵力收益，先读取服用前丹毒并套用现有Q，之后再增加本颗丹毒。

归元定息的折时只作用于云息十层开始后的九息过程，不改变九息数目、每息三阶段、每息连续闭关要求，也不抵扣突破闭关、九息是否完成或之后境界要求。五档比例应用到九息各阶段的基础所需时长，现有环境效率仍按现行公式计算；默认环境效率为1时，9504小时的九息总时长约分别减少8、16、24、32、40日。实际显示由人物当前效率重新估算。服药时按既有丹毒规则对本次药效作一次折算，再增加本颗丹毒；不在每个阶段重复折减同一药效。

所有五档都满足对应突破门槛；档位改变的是突破后的日常修行收益，不改变突破成功率、属性奖励或两道关口。保持同种同阶同档的基础效果固定，不按每颗分数或炉次生成额外物品类别。

现行普通突破没有药物增加成功率的已定规则，本案不加随机突破失败、失败掉境或“满效必成功”等表述。境界成长、凝核品质、属性奖励由境界／凝核原案负责，不因为高档丹增加一套永久属性奖励。

定脉的灵力补入只在晋入四层成功时发生；归元定息只在晋入十层成功时启用九息折时。两种丹不代替凝核、灵力和主修条件。

## 三、突破时间与后续药效的结算边界

当前代码中，两道关口的闭关基准分别为5游戏日、18游戏日，再按现有范围随机确定时长；静室在原时间上乘80%。丹药不修改这两个闭关时长。

成功突破时，采用同一个事务顺序：

1. 复核并扣除满足该关口的实际物品。
2. 按成功晋层后的境界应用定脉进度，或记录归元九息的丹效快照。
3. 按该物品档位增加对应丹毒；丹毒不回头改变已结算的本次突破时间。
4. 同一事务内更新境界与药效，避免动画重入或读档重试重复发放收益。

归元九息的丹效快照随人物存档保留到九息圆满；开始、估算和逐段推进共用相同的阶段时长公式。九息中断仍按原规则清除当前未成一息的进度，但不撤销已经消耗丹药带来的九息整体药效。

## 四、境界页让玩家明确选本次丹药

满足普通突破前置后，在原有闭关确认区域增加“本次丹药”一行，沿用现有界面，不另开庞大炼丹面板。

- 只列本关口适用、本人真实持有且可用的档位，显示名称、丹效、数量。
- 默认选择最低可用档位，允许玩家主动换高档，避免默认吞掉满效丹。
- 选中后显示按当前丹毒折算的本次收益、档位基础值和成功使用增加的丹毒：定脉显示晋入四层后补入的吐纳进度；归元定息显示归元九息时长缩短比例。详细说明复用通用丹药悬停。
- 没有对应丹时说明缺少哪种丹，不把缺药误写成灵力不足；有药但其他条件不足时继续说明原来的条件。
- 丹药只在境界闭关流程选用，不在行囊点“服用”提前消耗，也不开放战斗战备。

## 五、预留、成功消耗和读档

应给闭关保存本次选中的丹种、档位／物品路径、数量1及后续收益快照，不能到结束时再遍历背包自动选最高档或另换一种。

- 开始闭关复核真实库存并保存所选一颗；闭关期间库存事务会保护这颗预选丹，不能出售、丢弃或被其他事务使用。预选本身不扣丹、不增毒。
- 成功晋层时，在同一事务里扣所选药、增加对应丹毒、完成境界变更并发放一次后续收益，避免信号重入产生重复消耗或重复灵力。
- 取消、条件变化导致闭关中止，释放预留，不消耗也不增毒；若未来境界案要改变失败代价，需另行明确，不在此自动引入。
- 保存／读取保留选择、预留和结束时刻；不能读档后换档再重新抽一份更短耗时。
- 当前普通闭关是一次推进时长并完成；即使短期内没有可操作的中途窗口，也应确定本次消费路径，避免以后改为分段时重做物品协议。

其他普通晋层没有新增丹药条件，六升七凝核仍走自己的入口，归元九息仍走原养息规则。

## 六、旧物品怎样过渡

当前两个旧物品没有丹效档，不能只把名称加上“优效”就冒充完成接入。建议的迁移方向为：

1. 五档各自有固定物品定义，按丹种／丹阶／丹效档区分，使用同样瓷瓶图和档位说明；首期只开放突破选择，不接炼制。
2. 两个旧无档资源路径与定义 ID 保留，物品改为对应丹种的薄效档；丹毒改按薄效值18／30结算。
3. 新旅程原有各发一枚的来源保持，发放薄效丹，不取消关口保底供给。
4. 其他档位使用明确的丹种／丹阶／丹效路径，不按名字模糊转换。
5. 更新前已开始且没有预选字段的闭关沿旧规则完成：使用旧路径与12／20基值丹毒，不追加新档药效。

两种丹的炼制获取、君药核心与配伍可沿既有成丹设计继续细化；本轮不把未验证草方宣布为已开放产线。先接境界识别与五档消费，再接炼制来源，避免炼出来却无法突破。
