# 突破丹五档与境界衔接（2026-10-26）

> 最新范围：用户要求除回春外先收敛现有丹药，通脉／静心暂时下架，定脉／归元定息补五档并与境界衔接。通脉／静心的开放入口本轮已关闭；突破丹以下内容为规划，未擅自改动现有境界、突破属性或旧存档。

依据：[云息境界与归元九息](云息十层归元九息修炼设计.md)、[既有突破丹与五档提案](云息丹药扩充与旧丹完善提案_20261024.md)、[丹毒](丹毒积累与服丹负担设计_20261024.md)。下架改动已编译通过；本轮不运行自动测试或实机场景，旧通脉可用的战备验收记录不代表本次下架已验收。

## 一、当前开放范围

- 回春丹保留炼制、五档物品、领取、世界使用和战斗战备。
- 通脉丹、静心丹的当前效果暂不采用，退出已知丹方、炼制识别、世界使用和战斗战备；兑换、交易及新奖励共用禁用检查。定义文件与毒值保留，方便后续重做及读取旧档。
- 旧库存物品保留可查阅，不自动删掉、替换或发补偿；原有通脉战备配置不能继续使用，不消耗旧物品。自拟配伍记录不删除，但不会绕过禁用目录炼出被下架丹药。
- 材料十二功用不撤销：通仍可在使位帮助混合，镇仍可在佐位处理相激；只是对应的两个成品暂不开。
- 定脉／归元定息旧门票用途继续有效，不与普通可服用丹混为一谈；其他新增丹种暂不推进。

## 二、突破丹怎样区分五档

两种丹分别保持原本关口：

|丹药|丹阶规划|对应关口|最基础职责|
|---|---|---|---|
|定脉丹|九品|云息三层→四层|满足这一关的丹药条件|
|归元定息丹|七品|云息九层→十层|满足这一关的丹药条件|

共同五档为薄效、良效、优效、极效、满效。任何成丹档都能作为该关口所需丹药；低于20未成丹没有物品，不能用于突破。不再另外设置“至少优效才可过关”的隐藏要求。

建议沿前期提案，把药效落实为**缩短本次闭关耗时**，并配合已定的各档丹毒差异：

|丹药／效果|薄效|良效|优效|极效|满效|
|---|---:|---:|---:|---:|---:|
|定脉：闭关耗时缩短|0%|5%|12%|20%|25%|
|定脉：成功使用后丹毒|18|15|11|8|4|
|归元定息：闭关耗时缩短|0%|8%|18%|30%|36%|
|归元定息：成功使用后丹毒|30|24|18|12|6|

毒值沿当前丹种独立基值12／20及五档系数取整，折时仍是候选值。薄效完成最基础的过关职责；高档省时且少积毒。保持同种同阶同档的基础效果固定，不按每颗分数或炉次生成额外物品类别。

现行普通突破没有药物增加成功率的已定规则，本案不加随机突破失败、失败掉境或“满效必成功”等表述。境界成长、凝核品质、属性奖励由境界／凝核原案负责，不因为高档丹增加一套永久奖励。

归元定息只作用于九升十的这次闭关，不抵扣之后归元九息的息数、阶段或9504小时要求，也不代替凝核、灵力和主修条件。

## 三、怎样与既有闭关时间相乘

当前代码中，两道关口的闭关基准分别为5游戏日、18游戏日，再按现有范围随机确定时长；静室在原时间上乘80%。这些是当前实现记录，不据此改变境界策划的其他门槛。

建议接入顺序：

1. 根据境界现有公式生成未用药的闭关时间范围，应用既有静室修正。
2. 取本次选中丹药档位的基础折时率S。
3. 读取开始闭关时的丹毒系数Q，实际折时率=S×Q。
4. 对原时长乘(1−实际折时率)，最后统一向上取整到游戏小时；现行12小时下限本轮保留，两道关口正常时长远高于此值。
5. 界面预估范围与真正抽取／结算调用同一计算，不显示折后范围却扣折前时间。

丹药折时与静室采用相乘，不把20%＋25%直接相加。丹毒只降低折时收益，不影响“这颗丹是否满足过关要求”；本颗新增丹毒在成功消费时才计入，不先给本颗折时自我加毒。

例如满效定脉的基础折时25%，开关时丹毒系数90%则实际折时22.5%。这是一颗药在当前人物状态下的实际收益，不改物品满效档位。闭关中丹毒自然下降不追溯改变已确定的本次时间。

## 四、境界页让玩家明确选本次丹药

满足普通突破前置后，在原有闭关确认区域增加“本次丹药”一行，沿用现有界面，不另开庞大炼丹面板。

- 只列本关口适用、本人真实持有且可用的档位，显示名称、丹效、数量。
- 建议默认选择最低可用档位，允许玩家主动换高档，避免默认吞掉满效丹。默认策略也是本方案建议，不提前改现有代码。
- 选中后显示两项结果：本次闭关预计时间范围、成功使用增加的丹毒。详细物品说明复用最新通用丹药悬停。
- 没有对应丹时说明缺少哪种丹，不把缺药误写成灵力不足；有药但其他条件不足时继续说明原来的条件。
- 丹药只在境界闭关流程选用，不在行囊点“服用”提前消耗，也不开放战斗战备。

## 五、预留、成功消耗和读档

应给闭关保存本次选中的丹种、档位／物品路径、数量1及时间收益快照，不能到结束时再遍历背包自动选最高档或另换一种。

- 开始闭关复核真实库存并预留所选一颗；预留期间不能出售、丢弃或被其他事务使用，显示预留提示。预留本身不扣丹、不增毒。
- 成功晋层时，在同一事务里扣所选药、增加对应丹毒并完成境界变更，避免信号重入产生重复消耗。
- 取消、条件变化导致闭关中止，释放预留，不消耗也不增毒；若未来境界案要改变失败代价，需另行明确，不在此自动引入。
- 保存／读取保留选择、预留和结束时刻；不能读档后换档再重新抽一份更短耗时。
- 当前普通闭关是一次推进时长并完成；即使短期内没有可操作的中途窗口，也应确定本次消费路径，避免以后改为分段时重做物品协议。

其他普通晋层没有新增丹药条件，六升七凝核仍走自己的入口，归元九息仍走原养息规则。

## 六、旧物品怎样过渡

当前两个旧物品没有丹效档，不能只把名称加上“优效”就冒充完成接入。建议的迁移方向为：

1. 新五档各自建立固定物品定义，按丹种／丹阶／丹效档堆叠，使用同样瓷瓶图和档位说明。
2. **建议旧无档物品迁为薄效**，保证仍可过关，不凭空发出高档省时收益；此迁移尚待确认，本轮不执行。若采用，丹毒也统一按薄效新定义，不保留“同档不同丹毒”。
3. 新旅程原有各发一枚的来源先保持，若采用薄效迁移，后续新旅程也发薄效；不能把五档扩充变成偷偷取消保底供给。
4. 旧资源路径保留兼容解析；真正迁移时按明确的两个旧物品ID映射，不按名字模糊转换。
5. 已开始的旧闭关保留原时长与原选药规则，不在更新中途追溯折时或要求补交丹药。旧无档成功消费当前仍按既有12／20丹毒，直到迁移真正实施。

两种丹的炼制获取、君药核心与配伍可沿既有成丹设计继续细化；本轮不把未验证草方宣布为已开放产线。先接境界识别与五档消费，再接炼制来源，避免炼出来却无法突破。
