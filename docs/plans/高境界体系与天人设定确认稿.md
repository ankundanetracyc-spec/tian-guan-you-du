## 一、五太与此界

五太不是生灵，也不是五位上界修士，而是上位世界规则在下位世界中的投影。此界由五太完成创界。

| 五太 | 已确认定义 |
| --- | --- |
| 太易 | 世界由“无”向“可有”的根本层。 |
| 太初 | 气始，天地运行之气开始成立。 |
| 太始 | 形始，世界中的形与结构开始成立。 |
| 太素 | 质始，万物性质获得稳定区分。 |
| 太极 | 阴阳、五行及诸关系归于可持续运转的平衡与秩序。 |

创界完成后，上下界原应接通，使此界生灵可以飞升；创界末期发生意外，通道未能建立，五太投影相继沉睡。太极在沉睡前维持五太与世界的平衡，并分出天道代管此界。天道最初没有私欲，后因既定背景中的意外产生私欲。

## 二、封闭之界与历史

此界自创界失败后一直封闭，不存在真正的上古飞升时代，也没有历代正常飞升记录。初代人皇留下过“飞升”之象，后世将其视为成功飞升；这实际是假象，不算真正的飞升记录。

第四纪元是此界最强盛的纪元之一。多位天人发现世界封闭、修行上路有根本缺失，遂欲伐天。天道以劫雷镇压，天人近乎全军覆没，仅余少数苟存。此战既令第四纪元由盛转衰，也撼动太极维持的沉眠平衡，成为后来某一太出现苏醒迹象的直接历史原因。

若一太单独苏醒，原有静态平衡便会改变，并推动其余五太相继苏醒。五太无序复苏威胁此界稳定，也与天道的底层维持逻辑及其私欲冲突。

玩家原为上界高位格之人，进入此界主要是历练、渡劫并积累功德。天道主动求取外来力量解决五太复苏问题；求援有现实必要，但目的并不纯粹。后期还会引入不属于原“上界—此界”秩序的域外势力，其组织与目标另行规划。

## 三、二十果位与飞升故障

现行结构为“五太各辖四种权柄，共二十权柄、二十果位”。每种权柄对应一个唯一果位；同一果位同一时刻只能由一人占据。果位按五太层级划分，不再由“五太 × 五行”排列成二十五个位点。神胎圆满者满足求果条件后占据果位，首先由神胎升为天人。按原设计，果位随后应继续托举修士脱离此界、升往上界；修士登籍受职后，下界果位重新空出。

五太仍限定权柄所触及的规则层级：太易关乎未定、未显与存泯；太初关乎无形之炁的交感和运行；太始关乎形与结构；太素关乎已成之物的性质；太极关乎关系、时序与秩序。每太下四种权柄各自有边界，不构成跨五太的横向同构表。

### 太虚与钧纪：由见痕到触纪

高层结构按认知与规则深度分为**现世—太虚—钧纪—上界**四层。它们不是彼此平行的地图，而是同一世界由表象到根本的不同观察与规则层次。**太虚是所见，钧纪是所以然。**

| 层级 | 定义 | 与修行的关系 |
| --- | --- | --- |
| 现世 | 物质与常规灵力活动层。 | 肉身、地形、法器、术法表现与可直接观测的灵机现象所在。 |
| 太虚 | 神识越过普通五感后能够感知的高层现象层。 | 可见灵力流向、魂魄残痕、术法痕迹、神识轨迹等；神胎能够稳定神游太虚。 |
| 钧纪 | 太虚诸现象背后的规则结构层。 | 果位映位、五太投影留下的规则结构及世界秩序的深层关联所在。 |
| 上界 | 本世界之上的合法高位世界与规则源头。 | 五太投影的源头，也是原定飞升接引、登籍任职之处；本界上行连接未能完成。 |

神胎的认知进阶按**见痕—通理—触纪**推进：在太虚观察真丹纹、神通与天地现象留下的太痕；通过比较多门神通，发现其背后的共同法理；神胎后期感知这些法理在钧纪中的归属、牵连与规则位置，为求果作准备。能观察或理解钧纪，不代表能自由改写其中的规则；只有占据果位成为天人后，修士才取得对所辖权柄的直接权限。

钧纪是规则层，不是另一片可自由探索的天域。旧讨论稿中的“升维之境”“悬基真影”以及五行材料补基方案均不作为现行层级名称或既定机制。

由于此界与上界的联系从创界起便未完成，果位如今只保留拔高位格的功能，托举飞升的功能失效。因此天人是被果位拔高、却未能继续升举而滞留下界的状态，不是原设计中应长期停留于下界的常规终境。位主未脱离或坠果前，同一果位不能由第二人占据。

## 四、金丹神通、神胎与天人性权

- 金丹真丹纹承载本命神通；假丹纹不能承载真正神通，也不能转化为真丹纹。真丹纹数量与战斗神通槽数量不是同一概念。
- 金丹神通来自五太创界后留在天地间的规则痕迹，称为“太痕”或“五太之痕”。真丹纹承太痕，太痕形成神通；神通仍属“术”的层级，不称性权。
- 金丹化神胎后，真丹纹所承太痕随神胎结构保留。神胎从多门神通之间看见共同法理，理解神通为何成立。神胎阶段连接“金丹得其用”与“天人执其权”；对法理的理解影响求果契合与难度，但早期神通选择不硬锁未来果位。
- 神胎亦称元婴；其修行劫难包括雷、风、火三劫。三劫的先后次序、触发条件、具体流程与失败后果尚未确认，本稿不补造机制。
- 天人占果后取得对该果位所辖一类规则的直接支配资格，称为“性权”。性权由果位对应的权柄界定，不再按“五太权域 × 五行权性”生成；它不占第十一普通技能槽。
- 金丹、神胎阶段保留的本命神通不会在天人阶段废弃。神通可视为性权固定、成熟的用法；性权运用更自由，但不替代既有神通体系。

五行、灵根与性材仍参与求果前的道基准备和结果计算，但不再作为天人性权的五种分类。二十权柄的具体运用边界、神通映射、消耗限制和五衰联动留待后续专题，不在本稿补造。

## 五、天人五衰

天人五衰是天人独有的五重劫难，不是自然衰老、寿元耗尽或周期性掉属性。它源于果位原本应在拔高位格后继续完成升举，但此界托举链路失效；天人长期滞留后，原本面向飞升的规则过程转为针对位主的劫难。

五衰必须可能导致坠果、道毁，并为果位更替提供自然窗口。神胎修士可以围绕现任位主的五衰谋划目标果位，使“候果、谋果”成为高境界长期战略。五衰、果位和飞升失效属于同一条逻辑链。五衰正式名称、各衰流程与天人阶段成长刻度尚未确认。

## 六、三途由硬路径改为软侧重

锻躯、行炁、蕴神不再是终身硬锁的三个职业，而是战斗与技法的软侧重，决定“如何用”，不决定能否接触某条天地法理。同一法理、同一果位都可以由不同侧重走到，差别表现为运用风格。三种软侧重可兼修，主修变化不应抹去已经学习的招式或历史记录；它们不再分别定义三套长期养成轴。

| 阶段 | 区分强度 | 定位 |
| --- | --- | --- |
| 凡人至云息 | 强 | 确立主要修行侧重与基础战斗循环。 |
| 云息 | 强 | 保留三途明显不同的技法与战斗体验；长期养成统一按性命双修组织。 |
| 玄基 | 中 | 保留本途倾向，允许更明显的兼修与交叉。 |
| 金丹 | 软 | 共同进入太痕—神通体系，不以路径限制神通本质。 |
| 神胎 | 更软 | 三途主要体现为理解同一法理的不同切入角度。 |
| 天人 | 不锁果位 | 任何三途都可证任何符合条件的果位；侧重体现于性权的运用习惯与擅长对象。 |

当前云息期按以下方向组织：

- 长期养成分为修命与修性。修命以锻体为主体，沿用皮、筋、骨、血、脏、心六部位；修性以所有修士共通的三景心相图为主体，建议借天象观变、地文察势、物华应物推进，并由装配图景提供属性倾向与常驻被动，不新增修性状态资源或被动槽。具体细案见[性命双修养成重构提案](性命双修养成重构提案.md)，图景被动与数值仍待体验审阅。
- 锻躯、行炁、蕴神仍可作为秘籍内容和战斗软侧重，主修影响当前技能准备；不会因此限制角色修性或修命。
- 五行参悟继续保留已有数据作迁移兼容；三景观想已有成长、装配和属性实现则直接承接为修性骨架，不按蕴神侧重锁定资格。运行时名称、入口与公共战斗接口待按提案逐步调整。
- 各软侧重的技法与主修秘籍特化仍可保留风格；主修变化不清除已学招式。未定义的跨体系增益、惩罚和数值门槛不在本稿补造。
- 后续境界依上表逐步放软；任何高境界果位都不能仅因早期侧重而被排除。

## 七、战斗框架边界

高境界仍使用十个普通技能槽、独立神通槽与物品栏，不恢复抽牌、手牌、弃牌逻辑。果位性权属于规则层权限，可以影响技能、读条、状态、结构与关系，但不另造一组占槽的普通技能栏。天人战斗资源以调用天地灵力为方向，而非完全依赖自身法力；高位天人能够明显影响区域天地灵力。
