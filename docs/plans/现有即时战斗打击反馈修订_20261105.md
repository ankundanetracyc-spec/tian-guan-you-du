## 当前增强：敌人受击反应

用户指出仍缺少打到人的感觉，要求敌人反应更明显。本轮将受击显示改为腰部以上后仰、短暂停留后平滑回正；普通与重击分别使用约7.45°／13.18°横向上身弯折，22／28毫秒快起、45／72毫秒峰值停留、总340／480毫秒。上下方向另加折身下压和小幅肩部侧倾，避免纵向反应缩到几乎看不见。下腿与脚底权重为0，保持原落脚。

原包络在正向反应只持续约74／108毫秒后便反向穿零，已改成单调回正。再次命中从当前显示姿态衔接新峰值；重受击优先于轻受击、纯化解及自身出拳的小回弹，避免边挨打边出拳时后仰被覆盖。纯化解仍只作小幅承力；部分化解有实际剩伤时使用70%的对应伤害反应，原伤害与化解结果不变。

实际命中后，主墨在25—85毫秒间逐渐退至原透明度的40%，让敌人受击姿态露出；空挥不沿用此命中消退。接触标记和攻击范围不受影响，声音继续关闭。

[10秒无声实战预览](../../output/combat_reaction_visible_20261105/combat_impact_preview_silent.mp4)使用当前真实人物与共同取景，展示拳掌、痛击及向上／向下命中。正常输入、原属性结算与自然闪避／会心保留；采集只关闭NPC自主决策，不伪造命中或改快照。录制控制器按现行范围来源安排落空和远距血浪案例，避免用旧长度冒称范围外。

本轮[反应包络专项](../../tools/action_battle_test/smoke_combat_reaction.gd)162项、原反馈163项、水墨97项，合计422项通过、0失败；分别见[反应专项日志](../../output/strong_hit_reaction_smoke_20261105.log)、[反馈日志](../../output/hitfeel_stronger_smoke_combat_impact.log)和[水墨日志](../../output/hitfeel_reaction_smoke_quiet_vfx.log)。覆盖八方向、回程强度、重入连续与转向、强弱优先级、化解区别、暂停重开、材质归零及CPU骨骼／脚点／物理／资源时钟不变。实际GPU画面和无音轨导出见本轮预览目录；观感仍待用户体验。

## 当前表现

[共用反馈调度](../../tools/action_battle_test/combat_impact_feedback.gd)接入人类陪练、百骸自选对练和旧狼演练的真实结算出口，玩家与NPC共享。不创建AudioStreamPlayer、不加载音频资产，攻击释放中的挥动声入口也已移除。

真实接触保留干净水墨、上身短促回弹与轻微镜头响应，区分普通、重击和实际化解。反馈没有战斗僵直、击退、无敌、额外判伤或动作中断，也不改变战斗模拟时间。

| 真实结果 | 纯视觉反馈 |
| --- | --- |
| damage > 0 | 产生对应轻重的接触水墨、局部回弹与有界镜头偏移。 |
| blocked > 0 | 使用化解表现；仅按下架招或存在防御窗口不算实际化解。 |
| 空挥、属性闪避或无敌 | 不产生伤害接触、受击回弹或命中镜头；不播放挥动声。 |
| 伤害与化解均为0 | 不补判伤害或化解。 |
| 同帧同一对攻受者的本体与血气 | 各自按原规则结算，主接触表现只合并一次；不合并伤害、取整、命中或联动。 |

[人物顶点显示](../../tools/action_battle_test/combat_impact_body.gdshader)以真实脚点和腰部为轴，上身响应更明显，下腿与脚点位移权重为0。只修改GPU显示，不修改CPU骨骼、网格坐标或物理解算。受击参数以本文顶部当前增强为准；此前26／42毫秒停留、170／240毫秒总长转为历史。显示峰值停留没有冻结动作采样或模拟时钟。

[接触水墨](../../tools/action_battle_test/combat_contact_mark.gd)用主笔与亮边组成一个短接触，重击／化解增加一道短回声；按目标脚点深度排序，在实际攻击高度显示。所有朝向使用同一纵深压缩，最多保留16个短标记，不再叠加旧接触碎墨。血浪读取释放时记录的高度，不随释放者后续手部动作漂移。

镜头只改Camera2D.offset，普通／重击／化解最大位移为0.70／1.65／0.55世界像素，不累加多人幅度，不回写共同取景的位置或缩放。暂停冻结显示时钟，重开清除标记、回弹与镜头偏移；既有战斗结束清场保留最后一次真实接触的短余波。以上数值均为表现参数，不是技能规则。
