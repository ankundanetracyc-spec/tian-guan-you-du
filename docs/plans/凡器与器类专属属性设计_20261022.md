## 一、完整等级序列

**凡器 → 法器 → 法宝 → 灵宝 → 道器。**

等级依实际成器水准评定，不增加原料几品、造诣几级才能评定的硬门槛。法器及以上沿用已确认的下/中/上/极品，凡器是否也细分暂不另行扩定。

凡器是完整可用的器物，不是制作失败的残胚。它可以有基础战斗属性加成及该大类固有本体性能；没有额外关键词常驻规则、条件触发、化法、获授技能、御器召出或器蕴贡献。

法器是首个允许形成上述特殊收益的大阶，不要求每件法器必定具有它们。是否形成仍取决于真实材料潜力与工艺；不能用是否有技能、效果条数或一个随机词条来直接判等级。

法器的具体标准提案见[法器阶段](法器阶段设计_20261022.md)：评估本体能否稳定承载、维持和传导足够灵性效力。锋锐等物理性能不直接替代该指标；身材与性材仍是主要来源，不排除其他岗位通过守恒分账参与。

## 二、专属本体属性属于哪一层

每个器物大类定义一项有明确作用的本体属性，所有该类器物按同一公式计算；材质与加工改变数值，不按材料名称指定效果。

这项属性由身材实际成材、材料自身层次、物理适用和加工结果形成；属于器物自身性能，不是性材给予角色的额外常驻条目。因此凡器也有。例如凡剑锋锐、凡甲自身的专属物性可正常存在，但不会因此拥有化法或关键词附加特效。

本轮只定义剑，不为甲、鼎等大类拍定名称和作用。其余大类应各自设计物性及结算，不能把剑锋锐通用于全部器物。

## 三、剑的专属属性：锋锐

建议名称为**锋锐**，显示为本体数值，不使用“锋锐层数”、额外战斗资源或可释放技能。

锋锐表达剑刃切入与破开实体防护的能力。建议按固定物防忽略量结算，数值X表示本次适用攻击计算物防时忽略X点，而不是忽略X%。

适用范围建议限于本次确实由这把剑参与的物理攻伐，不让剑的固有锋锐无条件强化拳脚、所有法术或神魂伤害。具体通过剑关键词、武器来源引用还是动作/技能器物引用识别，须结合正式用器规则统一；当前不能仅凭技能名字带剑字命中条件，也不直接定义多剑叠加。

### 3.1 本体计算的统一方向

对实际成为剑刃的材料i，令vᵢ为其有效成材体量，bᵢ为材料品级、质地及加工参数算出的本体保刃能力：

```text
剑刃本体水平 B = Σᵢ(vᵢ × bᵢ) / Σᵢvᵢ
锋锐 X = floor[k锋锐 × B × 开刃完成度 × 刃形系数]
```

b由全材料共用的品级增长函数及必要物理加工参数计算，不能读取材料名决定是否加穿防。开刃完成度反映真实加工保留与完成情况；刃形系数由实际成形结构计算，并与结构稳定性共同约束。新增的保刃/开刃加工参数需要定义后才能运行，缺项不能默认所有致密材料都能成剑。

增加同种材料数量主要改变剑体与承载，不通过简单加总无限提高锋锐。高品且适于成刃的材料、良好复合和加工可提升B与开刃结果。不能只把剑画得更薄就免费获得更高穿防，形态变化必须进入实际结构计算。

锋锐与结构等都是身材实际结果的不同表现，不再作为一条性材效果重复领取潜力。性材另外生成的穿防或增伤属于另一笔独立材料来源，应保留来源并统一结算，不能将锋锐复制到每条附带效果。

### 3.2 物防结算提案

没有其他穿防时：

```text
本次有效物防 = max(0, 目标本次物防 − 本剑锋锐)
```

示例：目标物防20、锋锐6，本次按14点物防进入现有伤害公式。这是忽略物防的算术说明，不代表造成额外6点伤害。

锋锐不降低目标常驻物防，不无视护盾、化解或物理百分比减伤，不额外增加伤害倍率；物防不足时最低按0计算，不能形成负防后额外增伤。

与其他百分比/固定穿防共存时必须统一顺序，只折算一次。当前已有百分比穿防接口，尚未统一本体固定穿防的新增位置，本篇不擅自修改伤害公式或通过重复结算模拟。附带攻击与召出御使是否使用本体锋锐也须逐来源明确，不默认一项剑属性覆盖所有衍生段。

## 四、凡剑与法器剑的展示

凡剑示意：

```text
某剑 · 凡器
本体属性：锋锐 X（本剑参与的合法物理攻伐忽略X点物防）
基础加成：仅列实际炼出的基础战斗属性
```

法器剑除本体锋锐及基础属性外，可以在实际形成时拥有关键词规则、条件触发、化法、获授技能与器蕴。锋锐不因器阶名称另乘一遍倍率，材料和加工提高已经体现在本体数值中。

## 五、生成与评阶顺序

先算本体结构、根性、稳定性及器类专属属性，再按真实水准判等级，最后在该等级允许的收益范围内结算性材表达。凡器不能通过给效果改名为“基础属性”绕过限制，器类固有性能则不应误判为获授技能。

凡器未能实现的特殊潜力进入未利用记录，不自动免费转为另一条基础属性，也不通过舍弃一条高级效果把材料消耗当作未发生。无可用本体或结构不完整才进入失败/残胚处理，不能把所有未达法器的完整器物统一判失败。

本轮未改运行数据。后续至少验证凡器只出现基础收益、凡剑锋锐正常、非用剑攻击不误用、固定/比例穿防不重复、器物物防状态不被永久修改、护盾/化解不被绕过，以及数量不无限抬高锋锐。
