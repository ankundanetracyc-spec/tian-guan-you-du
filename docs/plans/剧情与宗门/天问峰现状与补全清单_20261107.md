# 天问峰现状与补全清单

日期：2026-11-07。现状按当前文档与代码核对；补全顺序和新增活动属于提案，尚未接入游戏。

天问峰已有固定演法、预备真传考核，也能使用现有人物切磋。主要缺口是把这些能力组织成有日常安排的演武场，并补齐独立试炼与赛事。下一步应先做好日常对练，再发展小比、大比与会武。

## 三 具体还缺什么

| 缺口 | 玩家现在少了什么 | 补全内容与前置 |
| --- | --- | --- |
| 日常演武安排 | 到峰后主要是固定狼演法与身份考核，难以了解当天能和谁、练什么。 | 清楚展示现有演法和真实在场的可邀约同门；无可接触人物时给出自然空状态，不临时补人。 |
| 可反复参加的试炼 | 还没有独立于入门考核的试炼目标和挑战进程。 | 先定义考什么、用哪些已有对手、完成标准和重复规则，再设计试炼目录；不直接增设层数、战力评分或奖励。 |
| 小比 | 没有报名、分组、对阵、轮空、弃权与赛绩管理。 | 先定个人赛范围、分组和结算，再实现最小完整赛事。 |
| 大比与会武 | 没有届次荣誉、代表选拔、主办轮值与其他宗门的完整参赛数据。 | 共用小比赛程基础，再补稳定参赛者、资格、对外记录和主办场所。 |
| 观摩与交流 | 切磋有真实结果，但天问没有围绕演武安排的持续交流内容。 | 先做基于本人实际战果的反馈；观赛、NPC点评须有真实在场和获知记录，不自动加造诣或关系。 |
| 战斗模式衔接 | 人类切磋与兽类演法使用不同的当前战斗流程。 | 活动只选择现行支持的对战组合；旧赛事稿中的“即时队列”不能替代最新人类招式盘规则。 |
| 活动结算约定 | 赛事尚未明确实际药品消耗、伤势隔离、平局、退出和赛间恢复。 | 在接入前列成逐项结算表，不从普通演法推定赛事都免费、全恢复或不耗药。 |
| 长期记录与防重 | 普通战斗、考核与切磋各有记录，但没有赛事身份和届次管理。 | 独立保存活动、比赛、对阵和完成事实，不能把战后返回次数当参赛次数。 |
| 实际难度与体验 | 真传考核验证覆盖通路，战斗胜负曾由测试控制。 | 用真实合法角色与首本配置试玩，核对可读性、可完成性与战后返回；发现规则冲突先列问题，不自行降门槛。 |

## 四 峰内安排建议

主场景继续保留演法台。新增安排围绕“演法”“同门对练”“本期比试”组织；真传考核按实际身份和期限单独出现。只展示已经可用的活动，未定的比试不做伪可点击入口。

同门对练先用公共人物名单和既有切磋流程，不让天问变成全宗远程约战大厅。若以后支持预约、召集或跨峰邀约，须另行确认人物移动、应约意愿、时间与取消规则。切磋无须先接公事，也不因移到天问而多扣一笔费用。

演法页面展示对象、活动目的、当前构筑、已知消耗及结束方式。赛事页才展示届次、资格、对阵与赛绩。普通演法、真传考核和比试各自核验，互不替代成绩。

## 五 与执中峰的分工

天问组织演武、主持赛程并记录真实活动；[执中峰重设计提案](执中峰职责与玩法重设计提案_20261107.md)处理规则问询、争议与违例。

目前约定切磋已经采用训练通路，不应误写成现有同门切磋必被定罪。需要补的是未来统一的活动记录：能证明双方同意、活动类型、参与者、场所与是否结束；切磋约定不等于宗门对任意后续攻击的授权。执中不能仅凭同门之间发生过战斗就认定私斗，也不能只凭一个非空授权字段认定全部行为合法。

争议影响赛果时，先记录争议范围；胜负记录、违例认定与是否重赛分别处理。重赛、取消资格和更改名次的条件尚须单独定案。

## 六 推荐制作顺序

1. **日常演武整理**：复用现有演法、人物切磋和考核，完善入口、活动说明、回场与实际难度验证。
2. **最小个人小比**：先确定分组、人数不足、平局与退出、消耗隔离、赛绩和首届时点，再制作报名到结赛的一轮。
3. **独立试炼**：在已有对手与战斗能力范围内明确目标和重复规则，不绑定为修行硬性门槛。
4. **宗门大比与四宗会武**：在赛程可靠、其他宗门有稳定选手后扩展。
5. **观摩与赛后往来**：依真实在场、参与和知情补内容，不从旁白生成额外收益。

三年小比、十年大比、三十年会武仍是旧讨论稿的建议，不能直接写入运行时。当前也不新增报名费、演武资源、每日次数、熟练度、称号属性或赛事奖励。

## 七 接入验收清单

- 普通演法、同门切磋、真传考核与赛事的成绩、费用和奖励互不串用。
- 人物离开、闭关、死亡、拒绝邀约以及战前取消都能正确返回，不凭空补人。
- 人类与混合兽战按现行战斗范围运行，不修改招式、费用或兽招规则。
- 不写回模拟伤亡，不从训练生成战利品；药品与状态按各活动定案的结算表逐项验证。
- 平局、退出、重复回传、跨期、存读档与赛果恢复不重复结算。
- 合法演武记录不触发私斗认定；超出约定的真实冲突另行留存与处理。

本次交付为现状清单和补全顺序，未修改天问峰代码、考核标准或赛事参数。
