# 白石城分层与共用挂牌修订

> **2026-11-10 当前导航覆盖：**用户反馈街区分层难以辨认且主线目标要进入二级标签才能发现。白石总览现直接平铺已接入的主要场所，含客栈、坊市、书坊、告示所、城守府与讲法前院；讲法前院可一级直达，主线提示停留在城内总览并指向讲法地点。“南街、东市、府前街、西城旧巷”不再作为抵达这些地点的必经层级。讲法、研习等场景内部仍使用现有功能入口；已有内容、人物与结算保持。本条覆盖下文对白石总览保留四街区标签的当前表现。

2026-11-06，当前。用户明确：一级内景沿用，二级使用挂牌，后续再按具体功能决定是否深入；不能把每一层都做成总览式散落地标。并要求美化共用挂牌、让主绳具有物理反馈。本案覆盖[白石城首版](白石城基础内容与内景接入_20261105.md)中“所有层级均使用地标纸签”的表现，不改地点内容、人物和行动结算。

- 白石城总览保留当前背景和南街、东市、府前街、西城旧巷四处地标标签。进入街区后，设施及可用功能改用公共 `SceneActionButton` / `SceneActionRope` 悬绳竖牌；不再复用总览定位标签。
- 当前已经有内容的客栈、书坊、告示所、城守府及讲法、研习空间继续承接其已有背景、真实人物与功能。功能打开何种页面由原功能决定，不因进入挂牌层就自动再造新的总览、空场景或虚假行动。
- 沿用原空间ID、父子关系、NPC筛选、返回、存档、验灵、首卷、研习和灵舟接引；对话仍从公共人物名单进入。入口开关继续读取实际权限，不补新价格、奖励或住宿规则。
- 讲法旁听属于公共场景活动，按[入场引导修订](白石讲法会与序章入道流程_20261103.md#讲法入场引导与场景旁听2026-11-06当前)由中央“旁听讲法”挂牌打开；当面验灵、问功法等事务继续从人物名单进入。
- 共用牌面复用现有宣纸墨框纹理，增加克制的木质压条、穿绳孔和绳结；各状态为深墨字、灰绿反馈。文字按实际牌面留白自适应，避免长标题顶到悬挂孔或流苏。
- 主绳分段计算张力、回弹和阻尼，两端固定，静止为连续弯垂。鼠标掠过绳子／牌子产生局部扰动，可轻拉主绳再松手；波动沿绳传播，挂点带动牌子与邻牌，不用循环正弦冒充物理。
- 牌面绕穿绳点摆动；底部红绳穗独立滞后，并承接牌面运动。动作有幅度限制，低帧率分步、隐藏后停止，改变窗口或入口数量时重新安置；不改变游戏时间、扣费或交互对象。

本轮改动落实到同一个公共控件，玉虚峰内等既有使用处一并沿用；保留和光公事多绳行布局。原生截图与动效记录见[验收目录](../../美术规范/白石城分层与挂牌_20261106/README.md)。
