# 执中峰职责与玩法重设计提案

日期：2026-11-07。用户已明确要求整体职责和玩法重做；下文为新的完整候选方案，尚未定为运行规则，也未修改现有代码与存档。

执中峰建议重新定位为**守宗门规矩、为门人止争、受命巡察的所在**。普通弟子来到这里，可以弄清自己能做什么、为实际遭遇求一个说法，也可以参与有明确职责的当值与协查。案件只是其中一部分，峰内日常应能独立成立。

## 一 旧方案的问题

| 问题 | 当前依据 | 对体验的影响 |
| --- | --- | --- |
| 入口面向管理操作 | 峰内直接列“裁断与申诉复核”“执行终局裁断”；玩家点击后处理列表中首个符合条件的案件。 | 普通弟子像在替整个宗门运行裁判程序，难以判断自己与这件事有什么关系。 |
| 玩家自己的遭遇缺入口 | 现有裁断入口排除“玩家冲突待核”记录；规则主要面向东林地NPC之间的冲突。 | 看到陌生人的案子能处理，自己受袭或被指责却没有完整陈情路径。 |
| 核验过程缺少实际行动 | 来源主要是后台冲突记录，原核验多为查看事实后上呈。 | 后台知道经过，不等于玩家或执事已经知道；缺少报知、访查、说明与求证过程。 |
| 申诉缺少新的处理对象 | 现有复核重跑同一判定器，并强制等待申诉当事人押送交接。 | 通常没有新事实或具体争议要核对，申诉反而变成押送前置。 |
| 惩戒过度依赖累计次数 | 现有草案以先行斗法的已判次数递进为训诫、记过、除名。 | 行为性质、后果、授权范围、实际责任和裁断顺序不足以表达；“第三次”不能代替完整判断。 |
| 宗门职责过窄 | 案源几乎围绕野外自动冲突，缺少门规问询、门人求助、止争与峰内巡察。 | 没有案件时，玩家看不出此峰平时做什么。 |

## 二 新职责与其他峰的边界

| 新职责 | 执中峰平时做什么 | 玩家为什么来 |
| --- | --- | --- |
| 讲明门规 | 说明修行、交手、公物、传承和对外任职的已定规矩；解释适用范围。 | 准备做一件事前查清边界，或知道自己的遭遇应找谁处理。 |
| 受理陈情与止争 | 听取门人的实际遭遇，核对双方说法，处理能澄清的误会和可协商的纠纷。 | 为自己求助、说明经过、交付真实所见，或回应与自己有关的争议。 |
| 当值巡察与协查 | 安排场所巡看、访问相关人物、核对明确记录等有限职责。 | 选择承担一项峰内工作，亲自查明具体问题，再向执事回话。 |
| 门规处断与护持 | 对查明的违例依规处置；对门人在外受侵害的求助组织适当核查与护持。 | 查看与自己有关的结果、提出具体异议；经正式指派才参加相应外勤。 |

和光峰继续处理庶务、公事公告和贡献结算；执中负责问询、受理与办理案事。紫府处理宗门中枢和师承事务，按既定职权承接重事项；不因为某人是真传便授予执法或裁断权。天问负责演武和赛程，提供真实活动记录；执中处理其中的争议与违例。观复负责起居、修习与授业。

门规约束本宗成员。牵涉外宗时，先区分对本宗成员的处理、对受害门人的护持与对外交涉；不能因外宗人物出现在案卷里，就按玉虚门规修改其身份。涉及长老、执事或利益冲突时，须交不涉事的有权者办理，具体职权表另行定案。

## 三 三种主要游玩过程

### 平时来问规矩

玩家选择与实际问题有关的门规，如私斗与切磋、公物与个人所得、外聘报备、传承保密。页面先说明已定内容，再指出应去的峰或应办的手续。普通查询不消耗资源、不推进时间，也不产生贡献。

查询不检查未公开行囊或隐藏经历。只有玩家主动选择“就这件事说明”时，才进入陈情，并展示本次实际提供的材料。外聘登记涉及的多身份数据、审批和费用尚未定义，先列为后续功能，不凭问询授予客卿身份。

### 自己有事来陈情

流程为：**说明诉求 → 提交自己能够提供的经过 → 执事判断如何受理 → 澄清、协商或查办 → 听取回话与查看履行情况**。

玩家先说明想解决什么，例如厘清一批物品归属、说明一次交手、请求核查侵害。选择的对象和事实来自实际事件；对白可以表达意见，不能凭一句指控生成证据或处分。玩家也可能是被指责的一方，应有说明和回应入口。

执事分别处理以下情况：

- **问清即止**：规则和真实记录足以澄清误会，说明依据并结束问询。
- **可以协商**：事实与权利范围已清楚，双方自愿商议如何履行；一方不同意则不能记作和解。
- **仍需查明**：列出尚待核实的具体问题，安排实际查访；缺证不等于有罪，也不直接等于无事发生。
- **涉及门规**：依据已经明确的条款与事实办理；严重侵害不能靠私下讲和自动免除门规责任。
- **应由别处办理**：说清本峰能处理的部分和应转交的对象，不把所有求助一概结为“不适用”。

玩家可以不追问或不参加后续查访；已经获知的严重违例是否继续查办，由宗门职责与具体条款决定，不由玩家撤回一个界面按钮抹去事实。该分流须随正式条款确认后实现。

### 主动参加当值与协查

峰内当值体现日常秩序。玩家可以选一项具体工作，查看职责、范围、预计耗时和已定报酬，再决定是否参加。具体班次、耗时和奖励待定，不直接搬用旧核验的测试贡献。

| 工作形式 | 玩家实际做什么 | 能改变什么 |
| --- | --- | --- |
| 场所巡察 | 在已有宗内场所按明确范围巡看；正常时可平安结束，发现具体事件才展开。 | 形成真实巡察与发现记录，不保证每班都有案件或战斗。 |
| 受命访查 | 访问案事中可接触的相关人物、核对指定地点或已有记录；决定继续求证、提交现状或说明无法核实。 | 增加实际取得的材料，可能改变待查问题与处理分流，不直接选择罪名。 |
| 协助止争 | 在真实发生的纠纷中听清双方诉求，转达已核实内容或请执事处理。 | 双方可以接受或拒绝协商；玩家的私交不能替对方同意。 |

当值可从峰内参加；需要正式委派、追踪或贡献结算的具体事项才接入和光峰事务平台。不能要求求助者先接一张公事，宗门才肯听其陈情。同一项工作只保留一个委派和结算来源，两处入口不能重复承接或领报酬。

普通弟子可查访、回话、提交材料和请求回避。裁断者与处分执行者必须有实际职务和授权；玩家真传身份不自动赋予这些权力。若将来允许玩家任职，应另做官职玩法，不混入普通弟子的当值。

## 四 让调查和选择有实际作用

每件案事先写出一个具体的待查问题，如“这批物品来自个人培护还是公事交付”“这次交手是否为双方同意的演练”“双方对先后经过的说法哪里不一致”。玩家获得材料，是为解决这些问题，不是搜集无意义的凭据数量。

后台原始事实、人物能够知道的事、执中已经收到的材料、玩家可以查看的内容分别保存。真实事件用于防止矛盾与造假；只有被报告、亲历、查访或有权调取的部分，才能成为当事人与执事当前知道的内容。旁观者、神通与传闻都不能自动授予全宗共享记忆。

可用选择包括：补问一项具体矛盾、去核对已有来源、转达双方都允许公开的内容、说明自己无法继续核实、因本人或利益关系申请回避。不同选择可以改变证据范围、是否达成协商和后续应做事项；关系变化仍须来自实际发生且现行关系规则支持的行为，不新增“办案好感”或判案评分。

人物可能离开、闭关、拒绝说明或死亡。案事记录真实阻碍，由执事判断继续查、换可用来源或暂存；不把人瞬移回来、不以其缺席定责，也不要求玩家用战斗逼出证词。人物自由文本不是已核实事实。

## 五 处断 复核与履行

### 处断依据

处断必须说明已认定行为、所据材料、适用条款、由谁作出，以及应做什么。考虑行为性质、授权和约定范围、实际后果与有效既往记录；不再把“累计第三次”作为通用除名标准。具体条款和处分仍需逐项确定，不能由新界面补全。

旧有训诫、记过、除名与原物追还可作为待重定的后果类型，不直接沿用旧次数和参数。新增罚俸、罚款、禁足、赔偿或强制缉捕均须独立定义。公开威望、私交、性情、宗门身份与贡献仍分别记账，不因处断自动联动。

### 复核针对具体问题

当事人可针对事实遗漏、材料矛盾、授权与条款适用、处置程序提出具体异议。复核应逐项回答异议，由不涉事的有权者处理；如需补充则明确所需材料。相同异议和相同材料不反复生成新复核。

取消“提出申诉就必须押送当事人”的通用绑定。确需当面说明时先通知或约见；自愿同行护持与强制押解分开设计。强制押解须另有有效文书和独立事件链，不能用“对方申诉了”作为拘束依据。申诉限次、期限、是否暂停哪些措施、执行后的纠错与恢复，均随正式规则定案。

### 履行必须真正完成

提出追还要求、实际收回、交还原主与确认完结分别记录。物品不足时保留尚未履行部分，不生成替代物，不把“已发任务”记作“已经追回”。可堆叠物品应依真实转移和归属记录核对，不从同一种物品的当前持有量推断它必然就是涉案所得。

记录处断与执行记录分开保存。复核更正不覆盖原事实，也不能只改显示文字；已发生的身份或物资变化须有对应的纠正方案。旧处分何时算生效、哪些可作既往记录、适用哪个规则版本，须在接入前统一，避免办理顺序改变责任。

## 六 峰内界面

沿现有内景与公共人物名单进入，主要行动控制在四项：**门规、陈情、当值、案事**。这四项是功能分工，不新增世界地图地点，也不假设必须新建四座建筑。

| 页面 | 主要内容 | 玩家可做的事 |
| --- | --- | --- |
| 门规 | 按日常问题组织的简短规则、适用范围及相关手续。 | 阅读、切换问题；有实际经历时转入陈情。 |
| 陈情 | 本次诉求、涉事者、本人所述、可提供材料与受理回话。 | 说明、补充、回应；提交前核对内容。 |
| 当值 | 真实可参加的峰务、职责、地点、已定用度与回报。 | 参加、继续当前工作、提交结果或按已定规则交还。 |
| 案事 | 与本人有关或获准参与的事项、经过、待查问题、已核实内容和办理结果。 | 看回话、补充材料、提出具体异议、查看履行情况。 |

案事页建议左侧为可见事项，中部为经过与材料，右侧为当前待办和本人的可用操作。普通弟子看不到全宗涉密卷宗；结案公开部分和私密材料分开授权。没有案事时仍可问规矩、正常参加已开放当值。

沿当前室内功能页的木框、浅纸、深墨楷体组织内容。主页面只显示玩家能理解和使用的信息；来源字段、规则版本、适配说明和未定参数放策划说明，不放玩家正文。未制作的独立功能不显示为伪可用按钮。

玩家文案示例：“先把事情说清，再论是非。”；材料未齐：“尚有一处经过需要查明。”；回避：“此事与你有牵涉，另请一人核查。”。对白须对应真实状态，不用旁白假称已经见过人或取到物。

## 七 三个首期情境

以下为制作模板，须由真实人物、实际事件和可追溯材料承载，不是现成已实装案件。

### 灵植所得的归属误会

同门对玩家一批雾铃花是否应交宗门提出异议。实际来源可能是个人培护，也可能是公事交付。玩家可以出示对应收获与委派记录，执事依据真实归属说明；若还有未履行交付，按原公事处理。个人培护所得不能只因同属雾铃花就被收走，也不凭一段对白把公事物资改为私产。

这个情境先做“规则澄清”样板，体现不打官司也能使用执中峰。现有收获来源若没有逐批可追溯记录，应先补齐来源接口，不能用行囊总量冒充证据。

### 玩家在外与人交手后陈情

玩家带回实际冲突记录，请宗门核查。执事区分谁发起交手、是否有先前诱因、地点、后果与物品转移，不因玩家是门人就认定其无责。对方属于外宗时，宗内责任、门人护持与对外交涉分别处理。

现有玩家冲突待核记录可作为来源，不再永久排除在求助流程之外；旧事件缺少材料时仍按实际可知范围说明，不追造证人或授权。

### 天问切磋与私下出手的分界

对战双方对一次交手是否仍在约定演武范围内有争议。先核对天问的真实活动、同意范围、结束时点与之后另行发生的攻击。不能因败北认定受欺，也不能以曾参加过演练为后来私斗开脱。

玩家经指派时可以查访或核对活动记录，涉事时则以当事人身份说明。赛果、门规责任和是否重赛分别处理；不靠查一个非空“授权”字段放行全部行为。

## 八 旧实现如何处理

| 旧内容 | 新方案中的处理建议 |
| --- | --- |
| 原始冲突、伤亡、物品流水与稳定人物身份 | 保留来源；补报知、访问和可见范围，不转写为新罪名。 |
| 按钮处理首个待办案件 | 退下普通玩家入口，改为围绕与本人有关的案事交互；执事有实际身份与职责记录。 |
| 重跑同一判定器的申诉 | 改为针对具体异议、材料与程序的复核。 |
| 每逢申诉就生成押送 | 取消该自动绑定；已有行程按独立迁移方案收尾，不突然解队或丢弃任务。 |
| 按累计次数直接除名 | 停止作为新版通用规则；重新确认条款、处分与有效记录口径。 |
| 唯一任务、贡献流水和防重复结算 | 继续复用；新增峰务的耗时、费用和奖励单独定案。 |
| 已发生的旧身份处分与追还 | 作为旧规则历史保留；是否纠正及如何恢复另行确认，不自动回滚玩家存档。 |

用户要求重做已明确；上述替换涉及旧裁断、押送和处分规则，仍须在新版具体规则定案后切换。当前不删除旧代码，不清空案卷，不修改已执行结果，不停止既有存档中的在途行程。

## 九 首期范围与待定规则

推荐先制作“门规问询、本人陈情、可见案事”的界面与规则澄清情境，再接一项有真实访查过程的峰务。由此验证玩家是否知道自己来做什么、信息是否可查、选择是否改变处理过程，然后扩展处断和复核。完整缉捕、强制押解、高阶执法与跨宗争端留在后续。

进入正式结算前需要确认：

1. 首批受理哪些具体问题，以及各类问题的必要事实和可访问来源。
2. 当值资格、班次与耗时、报酬，以及与和光事务平台的单一承接方式。
3. 执事和复核者的实际职务、授权、回避与无人可办时的处理。
4. 分流和答复在什么游戏事件或时点推进；仅随玩家行动推进的游戏时间处理，不设现实时间后台。
5. 各条门规的责任条件、可用处分、复核范围、期限与执行后纠正。
6. 旧案件、在途押送、已生效处分和已结算贡献的迁移与核对。

以上参数与后果没有从旧测试值或峰名推定。问询、陈情和旁听不自动发贡献；协查报酬按具体峰务另定，不恢复成员之间善功交易，也不接入暂缓的私委或跨峰真实生产。

## 十 验收要求

- 没有案件时，玩家仍能理解并使用执中峰的日常职能。
- 本人受侵害、本人被指责、经指派协查三种身份有不同权限和操作，不能跨案访问。
- 后台真实记录不直接变成NPC知情；未在场、未报知和无权材料不能被引用。
- 未核实的说法、关系、身份、性格、输赢和死亡不单独决定责任。
- 约定演武与真实冲突分别记录，合法活动不误判，演武约定不无限延长。
