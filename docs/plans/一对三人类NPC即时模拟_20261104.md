# 一对三人类NPC即时模拟（当前：已接独立入口）

2026-11-04。用户要求开始制作一名玩家对三名人类NPC的即时模拟，并确认：NPC按项目现有凡人属性生成规则产生，均使用拳掌、痛击、错步、架招；玩家保留当前六招，双方使用相同费用与属性冷却，NPC没有额外加成。

## 规则来源与配置

本案补充[即时动作恢复主案](即时动作战斗恢复与共同取景_20261104.md)。资源身份按[三资源总案](design-plan.md)，动作按[基础四招](即时战斗基础四招规格_20261103.md)、[四段拳掌](拳掌四段连招与贴步_20261104.md)、[六招与运功](即时战斗首批六招与运功限制_20261104.md)及[独立属性冷却](即时战斗六招节奏调整_20261104.md)。本次不新增或重做技能。

- 玩家沿用独立样例的体魄／神魂／灵慧8、生命100、法力容量3和六招，命中、会心与防御通过现有人物属性流程结算。普通战斗移动采用人物已定235单位／秒；形象继续使用当前人物骨骼与衣料。
- 三名NPC由 `CharacterGenerator.generate("凡人", 2)` 产生独立 `HumanData`，经 `Character.get_snapshot_data` 读取实际派生属性。NPC身份、姓名和属性独立，开战满血；重开复用同批快照，不重新随机。仅作为陪练，不加入世界、存档或奖励。
- NPC使用公共基础技能池的拳掌、痛击、架招以及动作基础错步，不授予催血、聚炁或未迁移技能。玩家示例可使用催血、聚炁，不借此修改正式人物学习与装配。
- 四名角色体力各自上限6、每2秒恢复1。拳掌0体力，其余已定技能各1；六招不耗法力、不占灵识，法力不自动恢复。各角色各技能的动作、CD与硬下限相同，只按自身最终属性计算。

## 多单位判定

玩家拳掌各段及痛击在释放时遍历全部存活敌人，按实际位置、方向与半圆范围逐个判定。每段／次释放对同一目标最多结算一次；范围外和身后无伤害，没有自动锁敌或只取最近者。NPC攻击只针对玩家，无友军伤害。伤害经过现有精准／身法、会心、化解、物防及减伤，不让人类使用撕咬。

错步前0.15秒无敌先于属性命中判定，实际位移仍0.20秒／最多100单位。架招只消耗首次匹配且未被属性闪避的物理来袭；同一时刻其他攻击按实际顺序独立结算，不延长窗口、自动反击或重复使用化解余量。拳掌整套结束、续接超时或中断后只起算一次CD。

## NPC行为与场地

### 追加明确：地面位置与离地高度分开

用户反馈判定不直观，随后否定将半径16单位小圆直接用作人物整体受击与阻挡的提议，并明确“竖直距离”指离地高度，区别于画面上下对应的地面前后。本轮不启用该16单位方案，不擅自新增人物阻挡、错步遇人停止或跳跃／浮空动作。

脚下圈只定位人物的地面位置，属性射程继续按脚圈位置之间的地面相对距离与前方半圆计算；人物另有离地高度这一空间坐标，当前全部站地为0。拳掌／痛击先作为等高横向出手：攻击层取释放时实际手部高度，向鼠标所在的该高度平面瞄准；伤害接触还须与目标身体占据的高度区间重合。身体高度读取当前人物网格，手高读取实际手骨，缺少挂点时沿用既有表现基准，不凭空设新的人物属性或攻击高度数值。

气劲与接触反馈读取同一释放高度；源人物后续转身／移动不改变已释放的攻击层。F2只读对照同时显示地面距离投影、手高攻击层与人物身体高度，使用实际判定函数，不扩大技能半径、费用、伤害、CD或无敌。完整的身体占地形状、空中行动与纵向技能之后另行确定。

NPC各自观察玩家当前的位置、出手方向与可见准备，沿不同接近方向进入自身近身范围，按已就绪的痛击或拳掌出招。受威胁且可支付时可架招或错步，全部经过与玩家相同的施放入口。AI不读取未来命中随机结果，不跳过准备、费用、施放互斥或CD；不额外增加攻击间隔、无敌或伤害倍率。队友之间只使用移动目标与避让转向分散站位，不引入单位推挤、碰撞半径或障碍规则。

场地沿用石坪与现有边界。共同镜头只读取四名存活角色的位置和可见范围，地图边界仍为硬约束。当前人形用于模拟表现，显示NPC姓名、生命、体力与当前动作区分身份；不将人物替身误记为完整外观／装备映射。

## 操作、结束与范围

首页「试演与预览 → 战斗与特效 → 即时战斗 · 一对三人类NPC」进入。先显示准备画面，开始后玩家沿用WASD／方向键、左键四段、空格错步、右键痛击与Q／E／R／F自由槽；P开始／暂停／继续，T重开，Tab装配，F1帮助，F2切换判定对照，Esc关闭面板或返回首页。暂停与失焦清除按住／连招缓冲并冻结所有单位的移动、准备、资源和CD。

击倒三名NPC才获胜；玩家生命归零则失败。倒地NPC停止思考、移动和未完成招式，不阻断其余敌人；战斗结束清除所有未完成攻击、贴步、运功和资源收益。重开恢复同一批初始快照和各自资源／CD；离开释放四人场景资源，不回写世界数据。

此轮为独立一对三模拟，不替换正式世界遭遇或已有真实人物单狼演练，不实施心法、化法、器具、丹药与战后回传。

## 实现与逐项验收

场景为 `tscn/scene/ActionHumanSparringScene.tscn`。`ActionHumanSparringRuntime` 隔离并初始化四份人物快照，复用现有命中／会心／防御结算；保留强引用并缓存只读派生段伤害资源，避免多人连续施放反复加载／复制技能。`human_sparring_arena.gd` 负责多目标与结束条件，三名 `human_sparring_fighter.gd` 复用基础施放、四段、费用、互斥与CD时钟。`human_contact_space.gd` 读取实际手高／身体高度，HUD与特效使用同一释放高度。

1. **效果、数值、费用和目标**：三名NPC由现有凡人规则产生并保留独立身份；玩家六招、NPC四招按用户确认配置。前方半圆逐目标结算，圈外、身后和高度不重合时不命中；站地四段仍按4／4／6／8样例基础伤害及2.2秒执行。NPC架招、错步、费用、资源恢复和各自属性CD均实际生效。
2. **规则边界**：未新增技能、资源、关键词或RPG能力属性；离地高度是用户明确的空间坐标，当前开战均为0。人物手高和身体高度来自现有人物，不用16单位脚圈替代全身，不启用未确认的身体阻挡、推挤、错步撞停、跳跃或浮空动作。攻击半径、伤害、费用、CD与无敌时长保持原规则。
3. **零费与联动限制**：每名角色各自执行同技能施放互斥、整套CD和硬下限；范围内多个目标不重复支付或返还费用。NPC中断自己的准备也保留已扣费用与完整CD。倒地或结束清除剩余动作与资源收益；没有额外行动、抽牌、返费、自动产炁或未迁移心法触发。
4. **数据与展示**：[四招词典](../卡牌词典/即时战斗基础四招.md)、[词典入口](../卡牌词典/README.md)、专题及三处文档索引已同步；卡牌公式与图稿保持原值。界面显示三人姓名、生命、体力和动作，玩家六招及费用／CD沿用共用HUD；气劲与接触反馈读取相同攻击高度。F2只读对照地面投影、水平攻击层和身体高度，不改变战斗状态。
5. **运行与实际窗口**：下列均通过。已检查准备、战斗、结束、帮助与高度对照实际画面；10秒演示由同一场景逐帧渲染，脚本只操作玩家，不修改双方生命／伤害／冷却。模拟胜负仍按实际结果展示，不以自动脚本能否获胜代替平衡定稿。
