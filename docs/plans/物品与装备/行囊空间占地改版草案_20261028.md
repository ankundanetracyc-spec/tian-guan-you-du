# 行囊空间占地改版草案

日期：2026-10-28，更新于2026-10-29。状态：空间机制草案与独立布局样板；96物品的图标及占地字段已按全物品主表接入，正式空间库存、存档事务、戒指及上位灵石规则尚未实施。容量分区仍供用户审阅。

2026-10-29最新修订：用户随后要求恢复区域名称，去掉尺寸描述和人体示意图。当前独立样板为胸前6×4、左右袖各3×4、腰间6×4、背囊6×8，共120格，每格48设计单位；界面只显示胸前、左袖、右袖、腰间、背囊名称。保留原外壳、分类、顶栏和底部总占用。行囊本体固定，不设置容量切换；戒指仍作为包内物品单击打开内部空间。正式空间库存与戒指子页尚未迁移。全量物品形状、像素密度和共用图标以[全物品现行规划](行囊全物品图标与占地规划_20261029.md)为准，覆盖本草案旧裸丹药图及未定源像素方向。

## 已明确的方向

- 行囊改为物品有大小的空间管理，暂定不可堆叠。
- 储物戒指放在行囊内，单击进入该戒指的内部空间子页；行囊主页面不预留独立戒指区。戒指具体容量与本体占地未定。
- 保留原行囊整体布局，只替换网格；行囊本体空间固定，后续储物戒指承担额外空间，不设置行囊本体容量切换或升级入口。
- 单格是很小的空间单位；灵石属于特殊小物，单枚占1×1，不能据此把其他小件都定为1×1。普通小件一般从2×2起；秘籍每本占2×3。尺寸记法统一为宽×高。
- 素材须与占地比例一致，不能将所有物品继续塞进等大正方形图标。
- 其余物品尺寸由本稿提出建议；未来可以考虑灵石的上位替代，本轮不新增具体品阶、兑换比例或产出。

现行实现仍为30个等大格、可堆叠物品同类无限合并，见两级文档索引2026-10-24条目；本轮用户方向将替换该规则，但尚未迁移实现及存档。此前助手提出的灵石袋、药瓶有限收纳方案未获采用，不作为本案前提。

## 占地建议（待审）

首版建议仅矩形占地，允许90度旋转，不引入不规则形状。以下按单件或现有配方中的一份计量；不因改尺寸擅自改变配方用量或采集产量。

| 占地 | 建议物品 | 美术表达 |
| --- | --- | --- |
| 1×1 | 单枚灵石（用户已定） | 特殊小物，不作为普通小件的尺寸基准 |
| 2×2 | 回泉珠、种籽与晶屑的一份材料等 | 普通小件的基准，裸药丸仅供动画 |
| 2×3 | 所有秘籍、丹药共用瓷瓶；短根、材料小瓶、骨片等 | 秘籍共用朴素书册，丹药共用瓷瓶；其他按逐项表 |
| 2×4 | 苦苔根、雾铃花、青羽翎等较修长材料（建议） | 完整植株或长羽 |
| 3×3 | 玄铁、铜髓矿、裂甲石、斑甲壳片、砾地菌伞等（建议） | 一块矿石、壳片或完整菌伞 |
| 2×5 | 霜叶枝、青木芯、青岚藤心、长兽骨（建议） | 长枝、木芯或完整长骨 |
| 3×4 | 折叠兽皮、折叠衣物（建议） | 有宽度与厚度的折叠形态 |
| 2×6 | 普通长剑（建议） | 剑身竖直完整呈现，护手占宽，不斜塞方框 |
| 3×6 | 确有宽护手或宽刃的大型剑器（候选） | 按实际轮廓采用，不因品阶高自动变大 |

以上取代上一轮把普通小件定为1×1、1×2，长剑定为1×5的建议。仅灵石1×1、秘籍2×3及普通小件一般2×2的尺度方向已由用户明确，其余尺寸仍须通过实际摆放样板校准。

其他材料按实际外形逐项归档，不能仅按名称自动推断。丝、砂、汁、苔等现有“一份”材料，可用一小束、一小撮、一小瓶、一小片表达；这是既有剂量的外观，不是装入多份的堆叠容器。材料尺寸全部为待审建议，不新增未存在的物品。

用户已否定逐种裸药丸的行囊图：全部丹药共用瓷瓶（2×3），裸药丸仅用于动画。瓶图不定义容量、装药数量或新的堆叠／消耗规则。液体材料小瓶仅表达现有一份材料，不另建容器容量系统。

## 灵石空间与后续替代

不可堆叠下，20枚普通灵石占20格；整理只能利用形状空隙，无法减少总占地。因此上位替代有价值，但不能靠尚未推出的物品解决当前容量。

建议后续沿“同体积、更高价值或更高储灵量”的灵石方向讨论：仍占1×1，以晶体结构、色泽和轮廓区别，不能仅靠放大素材表现。具体名称、价值、储灵量、获取及兑换渠道均待另案，不默认等比兑换。

由于灵石目前兼具支付、修炼供给和加工材料用途，需要分别明确：高阶灵石是否可替代普通灵石支付、怎样找零；修炼如何消耗剩余储灵量；配方能否替代及其材性。不可只提高售价就让全部系统自动接受。找零或兑换产生大量普通灵石时，须先验空间再提交，不能丢失物品。

## 容量候选与操作边界（待审）

撤回上一轮10×8（80格）和12×8（96格）的优先容量建议：其依据是过大的单格尺度。应先按细网格和新物品尺寸制作实际显示样板，再拟定总宽高；旧30格不能直接沿用。

最新排版建议为胸前6×4、左右袖各3×4、腰间6×4、背囊6×8，总120格，单格48设计单位；以网格位置体现身体相对关系，保留名称，不画人体，不显示分区尺寸。旧无名称、带人体及96格布局只作历史。

当前混装例19件／65格：十二枚灵石、一把2×6剑、两本2×3秘籍、两瓶2×3丹药、一份2×4苦苔根和一块3×3玄铁。仅为展示，不是赠送清单，不限制物品类别。单件须完整位于一个区，不能跨边界拼占；总余量不能保证任意大件可放入。

面积示例：20枚灵石、两本2×3秘籍、一把2×6剑、四份2×4药材、两块3×3矿石、四瓶2×3丹药，合计118格。此为面积加总，未声明能在五区完整摆入；单区形状与碎片空间仍会限制放置，不据此推定容量或赠送物品。

筛选、搜索只弱化无关物品，不把其他物品占地变为空位；排序不能暗中搬动物品，自动整理才改变位置。上面两条为建议，需与现有浏览排序一起调整。

仍需确认最终宽高、旋转规则、装备后占地及旧存档超量处理。旧库存展开可能远超新容量，必须先制定无损迁移办法，不能截断、删除或擅自兑换成上位灵石。

## 素材与实施验收

- 当前样板每格48设计单位，制作统一每格128源像素；例如秘籍／瓷瓶256×384、修长剑256×768、折衣384×512。屏幕尺度与源分辨率分开，所有图等比缩小，禁止拉伸或放大补像素。
- 每件物品绘于对应宽高透明画布，统一边缘留白尺度，主体完整；旋转图像时同步旋转占地，禁止横纵分别拉伸。
- 行囊用占地原画；交易、悬停等紧凑入口可从同一原画等比缩略。战斗持剑素材与握点沿独立接口保持，不用行囊新图覆盖。
- 本轮96份已有物品定义对应65张行囊图，全部按同一风格重生，另有1张药丸仅供动画；制作、正式资源引用与实际显示验收状态见[全量记录](../../美术规范/行囊全物品图标与占地_20261029/README.md)。图标及占地字段的接入不代表玩家空间库存、堆叠和存档已迁移。
- 实施覆盖物品定义、实例位置与方向、摆放校验、拖放旋转、全部入包出口、领取整理、交易与制作事务、存档迁移。NPC当前库存模型与玩家不同，须逐入口核验，不默认一并施加玩家容量。
- 验收包括边界与重叠、旋转、空间不足时事务不部分提交、扣料后入包、装备卸下、保存重启、旧大量库存无损迁移，以及原尺寸素材的实机视觉检查。
