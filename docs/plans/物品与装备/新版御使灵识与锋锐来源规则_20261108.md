# 新版御使灵识与锋锐来源规则

> 2026-11-08，当前恢复入口。最新用户裁定：装备效果在手持或御使时均可生效；化法仍须手持。普通攻击与术法统一为器物技能，各自检查费用与条件；费用不足跳过当前项，**撤销此前资源不足自动回退普攻的规则**。公共生效规则集中说明界面，不在每张卡正文反复说明。

## 一、灵识只有持续占用

1. 启用与重新启用御使只检查可用灵识，不收体力、法力或其他启用费。
2. 启用后按真实器物实例持续占用，跨共同回合保持；收回或停用释放。出招不另登记一次施法灵识。
3. 同一实物不能同时手持和御使；多格、多个技能引用、成套分段不能复制该件灵识占用。
4. 技能自己的体力／法力、次数、冷却和触发另按明示定义；免费启用不等于技能免费，也不额外送一次攻击。
5. 容量下降后的停用优先级与新盘完整来源集合尚待定稿，不在本页猜值。

## 二、统一技能字段，不自动替换

普通攻击是一项明确技能，与术法、防护或其他能力同列。清和当前登记普通攻击；其他器物有什么技能须逐件登记，不因器类或名字免费补能力。技能资源、费用、目标、条件及实际用器身份必须明确。

| 情况 | 当前处理 |
| --- | --- |
| 本件未合法启用或持续灵识资格失效 | 不执行要求御使的技能 |
| 当前技能费用和其他条件合格 | 按该项实际定义尝试发动 |
| 当前技能费用不足 | 跳过该项，不支付失败费用、不扣成功次数或启动冷却，不自动改用另一项技能 |
| 当前技能因冷却／次数／目标／其他条件不合格 | 跳过该项，不据此生成替代普攻 |
| 已施放后落空或未造成伤害 | 依已施放技能正常结算，不补攻击、不返还机会 |

一件器物有多项真实技能时，共用本件持续占用，各自保持真实费用／限次／冷却账本。多技能扫描顺序、是否一轮各自尝试和是否有独立技能块仍待确定；不能用“费用不足跳过”推定下一项免费发动。根性、结构与效力分配是炼器预算，不是战斗付款资源。

阵盘与阵旗沿[当前完整阵法提案](../百工技艺/阵法/阵法系统完整策划提案_20261108.md)及[盘旗分工](../百工技艺/阵法/手持阵盘与招式盘阵旗协作规划_20261108.md)：盘手持、内部元件为子部件；旗御使并持续占灵识，按阵图工作，不附送普攻。统一字段不凭空给这些对象补剑攻。

## 三、锋锐按手持覆盖与真实本体分别读取

锋锐是剑器自身可忽略的物防点数，不是人物攻击力或伤害倍率：

- 手持来源：星标覆盖内、带剑关键词的人物招式获得该剑锋锐；范围外不获得。只影响真实物理攻击结果，不为格剑等无伤害招式生成攻击。
- 御使来源：由这把剑本体参与的合格物理段使用它自己的锋锐；不取得其他手持剑的星标锋锐。
- 一项能力包含独立术法、衍生段或多剑分段时，逐段记录实际本器来源；不能把全部在用剑的锋锐相加。

清和最新范围为从剑尖向前连续3格，随剑尖转向。标准本体坐标(0,0)、(1,0)，剑尖(1,0)，受益格(2,0)、(3,0)、(4,0)。三格范围不计本体占格，也不改技能攻击射程；本体2×1与行囊2×6分别保存。旧按本体同尺寸向内两格的候选撤回。

## 四、装备属性、化法与器蕴分别处理

- 装备效果在手持或御使本器且启用时提供；六项固定属性及剑形硬池沿现行白名单，不恢复普通剑招额外加伤。贡献按真实源实例去重，人物全局评分只登记一次，器物动作读取主人最终值，不再复制一份。
- 化法仍须手持其来源器物，整包绑定一份合格目标；格剑仅修正其实际物理应对化解。具体接口沿[化法契约](器物化法生成与招式改写接口_20261108.md)。
- 器蕴本件贡献与人物累计分开，公共档位不变。卡面写“惊鸿2、抱朴3”，数字前不加＋。完整新盘有效来源集合仍须独立接线。

## 五、每件参数与当前角色预估

每件稳定四系数和物伤三系数由实际炼器结果冻结，后续换主人只代入当前属性，不重炼、不按品质重复乘倍率。默认名称不决定数值，旧实例缺参保留缺失。

剑类普通攻击读取神魂和剑道，伤害仍为物理。悬停读取CardRules.Number当前有效属性；预估再走既有自身修正通道，不对未知敌方计算最终扣血。灵识读取本器占用及当前角色可用量；稳定只显示上限，不将长期耐久或缺失当前值伪造成满值。

详细模式在结果后紧接实际代入公式，简略模式只显示结果；不使用固定10／10替代当前角色。缺角色待选择，缺参数未记录。通用手持／御使资格、启停释放、费用继承和格图图例由独立说明界面解释。

## 六、运行边界与待定项

长期耐久与局内稳定分别保存；稳定受击、当前值、归零、恢复与同场重放仍须定稿。本轮不以旧BodyMaximum直接换名，也不为旧物补清和参数。

当前实现已有旧装备与器物技能适配，但新盘尚无完整器物本体kind、六项贡献账本与器物化法数值桥。悬停图示与动态预估不等于真实新版战斗已接通。后续执行验收需包括：人物星标内外、多剑真实来源、持续占用跨轮与去重、统一技能费用不足无替换、当前属性代入、化法一份目标、稳定与长期耐久分离及保存往返。
