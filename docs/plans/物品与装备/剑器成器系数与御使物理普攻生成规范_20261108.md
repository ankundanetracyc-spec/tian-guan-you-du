## 一、统一公式，各剑保存自己的参数

对真实剑器实例i，建议统一采用：

```text
稳定上限i = floor(S0i + k神魂i×御使者神魂 + k剑道i×御使者剑道造诣 + k占用i×本件灵识占用)
默认御使普攻原始物伤i = round(D0i + d神魂i×御使者神魂 + d剑道i×御使者剑道造诣)
伤害类型 = 物理
```

| 参数 | 归属与含义 |
| --- | --- |
| S0i | 本剑稳定基础项，是派生公式的一部分，不是独立固定局内生命 |
| k神魂i | 本剑将御使者神魂转成稳定的系数 |
| k剑道i | 本剑将御使者剑道熟练程度转成稳定的系数 |
| k占用i | 本件持续灵识占用对稳定的贡献系数 |
| D0i | 本剑默认御使普攻的基础物伤项 |
| d神魂i | 神魂对本剑默认物理攻击的贡献系数 |
| d剑道i | 剑道造诣对本剑默认物理攻击的贡献系数 |

七项均是本次成器固定结果，不是人物新属性、材料新功用、战斗资源或七条装备加成。它们可以逐件不同；不同剑恰好得到相同参数也合法，不为制造差异强加随机词条。

战斗读取当前御使者的有效神魂与剑道造诣，再代入本剑参数。炼制者的炼器造诣只影响当次加工、保留与生成结果；换主人不会以新主人的炼器造诣重炼。人物属性变化怎样即时重算当前稳定，仍须按生命结算方案定稿，不借重算回满。

本件灵识占用是该真实物件实际持续占用的量，不是总容量、剩余容量或多次攻击的累计。不因它出招再登记一份占用，也不以新滑条额外分配灵识。

## 二、品质体现在哪里

“品质”在此次要求中指实际成器水准对性能的影响。沿现行规则保留材料功用品级、器物大阶／小档和加工完成情况的区别，不把它们强行合成一个战力分。

```text
材料自身数值、实际岗位与份数、配伍、炼器造诣及加工
  → 实际成材、连接、根性、通路、稳定实现与可分配效力
  → 本剑两组参数、锋锐及其他实际结果
  → 按既定标准评价器阶
```

这是因果说明，不改变既有“先检验可用本体与灵性标准，再在允许范围结算特殊表达”的先后。参数和评阶读取同一批真实结果；评阶标签不再反过来免费放大已经算出的参数。

- 同阶剑可以有不同参数侧重，不规定所有法器使用同一组系数，也不承诺更高器阶的每个单项都高于另一件器。
- 不新增粗制／精良等第二套已开放品质前缀，不凭用户本次“品质”一词补出未标定的质量分或四小档。
- 不在生成后再叠乘一次器阶倍率、一次工艺品质倍率、一次形态名称倍率。已定义的高阶专属机制另按其专题，不能以本轮给未定高阶猜系数。
- 凡器的类别默认御使普攻是基础用法，不是额外获授的法术技能；足够灵识等用法资格仍须满足。它不因此获得化法、专属法效或器蕴。

## 三、接入炼器来源与预算

### 3.1 参数的形成方向

以下是公共映射的来源边界；具体候选权重与曲线已在页首完整换算中给出，不再仅为未定义方向，数值尚待采用及平衡：

| 输出 | 应追溯的实际依据 | 不采用的捷径 |
| --- | --- | --- |
| 稳定基础与稳定成长 | 本体结构、连接、根性／通路、加工稳定实现，以及分配给御使性能的实际贡献 | 复制旧固定生命，或给每把剑直接填同一套稳定系数 |
| 普攻基础物伤 | 本剑实际成材、物理加工表现及分配给默认攻击的贡献 | 把锋锐直接再当伤害加一遍，或只按长剑／阔刃名称乘倍率 |
| 神魂／剑道伤害成长 | 本剑传导与操控响应、剑类适用及攻伐方向的实际分配 | 因为用了神魂就自动生成神魂伤害；给每项成长各发一份满额来源 |

材料仍只配置自身性质及既有加工档案。同数值异名材料应得到同样性能，不按材料名、剑名或样方指定两组参数。其他器类的参数和造诣另列，不能把镜、铃一律套剑道。

### 3.2 先区分基础性能与额外强化

类别默认动作已由用户明确，不要求先生成一条专属御器技能才允许攻击。参数强弱仍须来自实际成器：本体加工结果提供本体性能依据；若使用额外来源提高稳定或攻击成长，必须登记真实分配，不在全部既有效果之外附送一套满强参数。

结构承载、根性与通路既可作为公共模型的输入，也限制能实现的性能；**容量上限不是另一份可发奖励的效力**。不同物性共同描述一个真实器物，不意味着为每项可分配强化复制整份来源。

对每个实际来源维度u，继续满足原分账，并将两组参数的真实强化占用纳入：

```text
本体实际使用u + 基础加成实际使用u + 法效／化法／专属技能实际使用u
  + 器蕴实际使用u + 两组参数强化实际使用u + 未利用u
  = 扣除已登记加工／配伍损失后的实际可分配供给u
```

同一笔贡献只能记一次：已经记入本体参数形成的使用，不再以“两组参数强化”名义重复扣一笔；已经分给锋锐、其他能力或器蕴的可分配份额，也不能再次全额用于新参数。两组参数若由一项共同分配生成，其整套成长收益须共同计价，不能给七个输出各套一次满额换算。

本轮完整候选将B按功用维度分成核心、稳定Bs、攻击Ba，各行权重和为1；它们分享一份本体供给，不是给每组复制一整份B。现行器蕴先预留及实际扣除顺序不变；其后Xs、Xa与普通效果使用各自合法来源，共同竞争R、C及相关工艺，不默用已经消费的器蕴份额。具体候选成本见完整换算，尚未改正式参数。

### 3.3 完整公共换算候选（已可复算）

以下保留总函数名作为接口摘要；F稳定／F普攻的具体内容已由[完整换算](剑器属性池与化法接口修订实算_20261108.md)和版本`sword-material-profile-trial-2-shape-pools`定义：

```text
(S0, k神魂, k剑道, k占用) = F稳定(实际本体与工艺, 稳定方向真实分配, 公共参数版本)
(D0, d神魂, d剑道) = F普攻(实际本体与工艺, 攻击方向真实分配, 公共参数版本)
```

完整候选按以下顺序计算：

1. 材料实际岗位、份数和加工档案经Q／η／P及配伍送达形成B／E／J。
2. B按公共矩阵分成核心、Bs与Ba，核心承担基本性能；器蕴按原顺序先扣真实E、R与通。
3. 由真实剑形先过滤硬属性池，再将六项中合格基础属性、注册化法、稳定Xs与普攻Xa进入共同求解；分别消耗来源并共用R／C／工艺，不生成通用关键词加伤。根性是炼器预算，不是战斗付款费用。
4. Xs、Xa通过平方根曲线形成整组价值Vs、Va，再按本体与工艺的真实比例形成组内偏向。
5. 以神魂20／剑道20／占用3的公开参照价归一化，七项分享整组价值，不把每项各换一整份效力。
6. 每个系数向下保留四位小数，损失记账不返奖；最终稳定向下取整，默认原始物伤按正数四舍五入。

公共矩阵、成本、最低有效值、曲线、参照价与精度均已明确为可执行的独立候选，仍待用户审阅、采用与实战平衡；未写入正式炼器生成器。系数应为有限非负值，缺失不当0；显示与计算读取本件当次保存的结果，不能用粗略显示值反算。清和实算七系数及来源以新结果为准，不用下节人工A／B／C代替。

## 四、神魂参与计算，伤害仍是物理

默认御使剑普攻的参数输入与伤害类型分别记录：

- 输入是御使者神魂、剑道造诣和本剑攻击参数。
- 输出是物理伤害，沿既有命中／闪避／应对、物防、锋锐、化解、护盾等物理规则，具体次序不在本页另改。
- 本剑本体攻击使用本剑自身锋锐，不领取手持剑星标锋锐。
- 神魂伤害专属增伤、抗性或克制不会仅因为公式出现神魂而自动加入；各修正仍检查实际伤害类型与原适用条件。
- 材料五行不把默认普攻变成元素混伤；炼器的工艺稳定比例也不当成战斗稳定当前值。

专属御使技能若明确另有法术或神魂伤害段，按它自己的定义处理。本页只固定默认剑类普通攻击为物理，不把所有器物技能都强改成物理，也不将普攻模板自动改写人物现有斩剑。

各项能力统一按技能字段记录，普通攻击也是其中一项；每项技能独立检查费用、目标及其他条件，不满足时跳过该项，不自动替换别的技能或额外补普通攻击。只有实际执行的技能结算自身效果；技能之间的扫描次序与编排仍待定，不能借本条默认同时全放。旧资源不足自动回退已撤销。

同一真实物件不因开页、换主人、改名字、移动、转向、切方案或重读档而重新生成系数。新物按当次生成规则冻结，旧物按自身材料／参数快照重演；无新字段的旧物保留缺失事实，不默补人工算例A，不把旧BodyMaximum或旧主动伤害直接换名。旧物进入新版的转换须在单独迁移规则定稿后进行，不删除原始快照。

无专名自动命名、简短有义的方向前缀及专名优先沿用户确认；[本轮候选](器物自动命名与成器特征前缀_20261108.md)每组两字、默认两组＋剑型，额外专属特色才考虑第三组，具体词表与顺序仍待采用。前缀只读最终正数效果，不跨量纲比较稳定与物伤；同投料候选自动名为“洞隙·明察·薄脊剑”，既有明确商品专名仍为清和剑。name_origin须有自动、商品／剧情专名、玩家自取或历史来源不明的真实依据，不能见旧Name非空就跳过自动命名；未知旧来源保留原显示名，不批量重命名。

简略模式显示实际稳定和预估物伤；详细模式代入**这把剑真实保存的系数**与当前人物值。以A为人工排版例：

```text
预估物理伤害14（4＋神魂[10]×0.45＋剑道造诣[10]×0.55＝14）。
稳定53／53（12＋神魂[10]×2＋剑道造诣[10]×0.5＋灵识占用[2]×8＝53）。
```

玩家正文不显示实例编号、参数键、来源预算和迁移注释；详细版也不显示取整术语，沿[展示规范](../界面与美术/信息展示与规则详解分层规范_20261026.md)。动态结果不能冒充器物固定基础属性，更不能把小数系数误称为人物百分比加成。

## 七、保留未定与后续平衡

普通攻击体力0暂定；法力、目标、近身／远程、扫描时机／次数、多专属技能编排、复制／周天兼容仍待定。当前稳定重算、受击与归零、恢复和耐久损耗也不因逐件系数获确认而一并定稿。

提高某剑占用会同时影响稳定；占用不是纯削弱项。参数逐件生成提供了调节空间，但没有自动解决多剑免费出手的效率问题。后续须比较同灵识、同盘格等不同约束下，多件低占用与单件高占用的完整能力。

成长系数需要在多个神魂／剑道水平核算，不能只按属性10的一个点计价；也不因高阶人物能把某系数放大，就凭空抬高成器时的剩余预算。未定义的新人物上限、件数上限、费用和额外攻击不用于补平差异。
