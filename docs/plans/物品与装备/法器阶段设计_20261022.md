## 一、法器的定位

法器是首个允许形成特殊常驻、化法、获授能力与器蕴的大阶，前有仅具基础性能与加成的凡器。下品至极品是本大阶内的器身与工艺成长；实际评阶按成器水准，不因数量、造诣或效果条数单独抬阶。

法器可以拥有基础属性常驻、关键词条件修正、条件触发、定向化法、直接技能或御器能力。这些不是按小档逐个解锁的职业功能；实际能否出现由材料贡献、工艺及共同预算计算。

这里的御器能力指实际形成的专属能力，不包括新版剑器的类别默认御使普攻。凡剑可有默认用法与逐件性能参数，并不因此获得上述法器特殊收益，也不能拿一次默认动作反推已达到法器水准。

法器阶段不预设额外的大阶专属加成。法宝以上应另有大阶基础跃升和专属加成的配置，不能只沿用法器的小档增长曲线，也不在这里擅自给它们设计具体规则。境界限制另案，不将四大阶直接等同四个修炼境界。

## 二、法器本体应记录哪些属性

### 2.1 岗位是主要贡献，不是独占来源

用户强调“主要”：身材主要提供剑自身属性，性材主要提供角色收益，不能把其他岗位贡献一律设为零。建议先计算每种材料自己的有效贡献，再由全材料共用的岗位矩阵分账；这是对旧试炼严格分岗归零的下一版修订，尚未实装。

统一形式为：

```text
材料有效向量 pᵢ = Q(同岗合并份数) × 品级向量贡献 × 加工保留 × 配伍适配
本体贡献 = Σᵢ α[岗位ᵢ,本体] × 本体加工映射(pᵢ)
角色收益潜力 = Σᵢ α[岗位ᵢ,角色] × 收益语义映射(pᵢ)
工艺供给 = Σᵢ α[岗位ᵢ,工艺] × 工艺映射(pᵢ)
```

首轮岗位权重候选：

| 岗位 | 本体 | 角色收益 | 工艺供给 |
| --- | --- | --- | --- |
| 身材 | 0.75 | 0.10 | 0.15 |
| 质材 | 0.30 | 0.20 | 0.50 |
| 性材 | 0.10 | 0.75 | 0.15 |
| 和材 | 0.10 | 0.10 | 0.80 |

各行总和为1，来源只分一份，不给三个账本各一份满额供给；表内既有试用权重被本轮完整实算沿用，正式平衡仍待标定。它表示岗位利用效率，不保证所有配伍最终恰有75%贡献来自某组。没有成形适用的液体不会因性材本体权重而变成剑刃体量，没有相应语义也不临时生出新效果。旧燃料供热方向已由v3取消，不加入本轮来源账本。

属性来源引用保留岗位及实际占用。身材中适合成刃的贡献主要形成锋锐、结构等本体表现，少量可参与真实匹配的角色收益；性材主要形成角色收益，但也可能帮助本体稳定或连接。所有材料只按数值与公共映射参与，不查材料名或配方组合。

### 2.2 结果字段

| 本体信息 | 来源与作用 |
| --- | --- |
| 大阶/小档 | 法器，及下/中/上/极品；由实际满足的本体与加工条件评定 |
| 大类/实际形态 | 玩家选剑等大类；最终宽厚等由身体成材决定，不额外按名称乘倍率 |
| 结构承载C | 身材成材、结构强度、整体品级与加工保留的结果，限制全部能力的共同负荷 |
| 根性支撑R | 质材与加工结果，限制实际能稳定实现的效果总量 |
| 御使稳定参数 | 新剑器固定保存S0、k神魂、k剑道、k占用；战斗代入御使者属性与本件占用，不再以生成专属御器表达为前置条件 |
| 默认御使物理普攻参数 | 新剑器固定保存D0、d神魂、d剑道；参数来自实际成器，神魂输入不改变其物理伤害类型 |
| 五行/七档阴阳 | 从实际保留来源形成；极阴极阳不因偏离和而扣档 |
| 长期完好程度 | 预留耐久及修复字段；扣损规则未定，不能用战斗器体归零代替 |
| 来源快照 | 材料、岗位、实际份数、规则版本、加工与未利用记录 |

结构承载与根性支撑是内部可追溯依据，普通物品详情以器阶、形态与实际效果为主，不把所有演算数字塞进基础面板。器物结构强度不直接增加角色物防；角色物防依性材实际收益生成。

## 三、按实际成器水准自然评阶

用户最新修订：删除按材料品阶和造诣硬分档的方案，不规定八品材料才能炼中品、达到某个造诣数才能评上品。先计算真实成器结果，达到相应水准就认可相应等级。

### 3.1 原料与工艺是输入，等级是结果

材料品级影响实际成材、结构表现、根性和来源潜力；造诣影响加工保留、连接与稳定实现。它们不作为成器评阶时额外的身份门槛。

同样的低品材料，如果配伍与加工后真的达到较高水准，就能得到较高评价；高品材料若组织不好，也可能只形成较低等级。不能计算结果已经达标后再因材料名字、品级或造诣数值拒绝评阶。

### 3.2 评阶依据是实际本体指标

**建议法器的核心标准为：具有稳定承载、维持并传导灵性效力的本体能力。**纯物理结构很强、锋锐很高并不足以直接认定为法器；达到灵性能力标准但未形成主动技能，也不因此降为凡器。

先定义三个共同量，统一换算为内部“效力承载单位”：

- C灵：实际结构可承受的灵性负荷。由本体成材、结构强度及配伍后的灵性承受能力计算，不直接拿剑重量或锋锐充当。
- R灵：器内根性能够维持的效力。接受各岗位真实贡献，质材通常最有效，不能用一份来源为多个效果复制维持量。
- T灵：器身与使用者/释放端之间实际可传导的效力。由连接、通路和相关材料贡献计算，基础传导能力与额外覆盖/触发通路的工艺成本分别记账。

再计算稳定系数S∈[0,1]。候选公式为：

```text
失稳负荷 L = 连接缺损负荷 + 局部配伍冲突负荷 + 本次加工残余失稳负荷
S = exp[−L / max(ε, 实际稳定支撑)]
实际稳定通灵水平 H = min(C灵, R灵, T灵) × S
```

ε是数值计算的正小量，不是额外资源；实际稳定支撑为零且失稳负荷不为零时S按0处理。各负荷和支撑由统一材料/工艺映射计算，不能给每种材料单独配置最终S。纯阴纯阳不因偏极而产生失稳；只计实际局部不适配。S是可稳定实现的比例，不是随机成器概率。

法器入门标准建议先用以下**明确但待标定的测试标尺**：

```text
H ≥ H法器基准
且 S ≥ S法器稳定基准
首轮参考：H法器基准=10个内部效力单位，S法器稳定基准=0.80
```

10是后续统一换算和试算的标定参考，不是体力、法力消耗或某种材料份数；80%是维持比例，不是80%几率炼成。它们约束成器结果，不附加原料几品、多少造诣、必须某种材料或必须有技能的限制。关键数量级须用真实目录校准，尚未作为正式平衡或试炼开关启用。

例如C灵=16、R灵=15、T灵=14、S=0.90，则H=12.6，按参考标准已到法器水准；即使没有主动技能也成立。若一把剑锋锐很高，但R灵=4、T灵=3，哪怕S=0.95，H至多2.85，仍未达法器通灵水准。高效力但S不足时也不能仅靠总量抬阶。

这三个容量和S不是人物属性，也不是成器功用字段，默认仅作炼制记录和评阶依据。它们从来源账本中计算，实际生成能力仍受同一组来源和共同预算限制；评阶测试只评价能力，不凭空另发一份潜力。法器下/中/上/极品及更高大阶的结果区间在入门标尺验证后再定，不在本轮重造一张材料等级对照表。

建议先使用器身结构表现、根性支撑、稳定性三类结果。其中结构要兼顾实际承载与连接完整性，不能只数材料份数；根性看真实送达与维持能力；稳定性看实际加工、连接和局部适配结果，不以阴阳是否为和评分。

等级判定的统一形式为：

```text
成器结果 v = (实际结构、实际根性、实际稳定性等)
器物等级 = v所达到的最高等级标准
```

等级标准只检测计算后的结果，不再额外检测“原料必须几品”“人物必须多少造诣”。具体结果指标及各级数值区间待试算标定；不把已撤回的材料表换名字恢复。

材料堆量受到Q递减、加工保留、连接和实际结构质量的自然约束。少量高级辅体若没有改善真实结果，不抬阶；如果复合确实形成更好结构，则按实际改善计入。此前“低品材料不能越级”应理解为通常更难达到高水准，不能保留为绝对禁令。

### 3.3 大阶同样依据达到的水准

法器→法宝→灵宝→道器均为成器结果的评价；大阶标准要体现明显更高的本体与根性水准，达到后才取得对应额外加成。既不把法器四小档简单继续线性外推，也不要求玩家预先选择“法宝配方”或手动解锁一个只按原料身份判定的资格。

更高大阶的具体指标和加成后续设计，本篇不通过法器专用评阶范围强制把真实高水准结果压回法器。本轮只取消评阶的材料/造诣硬门槛，不顺带修改尚在试炼的材料加工适用、投料位置与实际工艺规则。

## 四、角色收益怎么随法器成长

角色收益仍从性材有效潜力生成，按通用公式计算：

```text
某方向有效潜力 = Σ性材 [有效数量 × 对应功用品级贡献 × 加工保留 × 配伍送达]
最终效果 = 实际分配效力经范围/事件成本及效果曲线换算
全部效果共同受实际C、R、工艺供给约束
```

法器小档描述本体达标状态，不在最终效果后再乘一个下/中/上/极品倍率。材料层次和加工提升已经增加C/R及可实现量，避免同一改善算两遍。

所以：

- 低档器身与强性材组合，不会自动提升器阶；只能在当前本体的约束内发挥，超出潜力记为未利用。
- 高档器身与弱性材组合，不会自动送出高额角色加成；它有更好的本体与余量，但缺少效果来源。
- 单一表达可把潜力集中到一项较强收益；多种表达可以并存，但要支付对应通路并分配同一来源。
- 材料相关功用品级提高时，该方向的源潜力应不下降；不代表新增强方向后所有旧成品数值都只能提高。

## 五、法器阶段的效果范围

| 收益类型 | 法器阶段的设计范围 | 必须满足的条件 |
| --- | --- | --- |
| 基础属性 | 已有战斗属性的固定值或百分比加成 | 相应性材来源、常驻耦合与实际预算 |
| 关键词常驻 | 自动作用于所有合格关键词技能的修正 | 合法范围、实际覆盖通路、作用范围成本 |
| 条件触发 | 具体战斗事件下附带已有合法效果 | 明确事件、次数口径、目标及防递归规则 |
| 定向化法 | 玩家绑定一个合格技能的修正 | 对应来源、集中通路与技能适用条件 |
| 获授技能 | 经审核的直接主动或召出/御使能力 | 完整技能模板、工艺、体力/法力/灵识规则 |
| 器蕴贡献 | 成品实际形成的蕴种与层数 | 独立的来源与累计规则；不是额外功用字段 |

不因下品而禁止化法，不因极品而保证六类都有。下品的有限预算通常更适合集中，但这只是可行结果的倾向，不写成只能有一条效果。

效果范围优先覆盖已有物伤、物防、穿防、化解、护盾等结算。新增行动次数、返费、资源上限等高影响效果需要专项审核，不能由材料公式任意拼出。这里不新增战斗卡、费用或新关键词。

## 六、器体与御器负荷

以下为旧局内生命与灵识映射方向，仅作旧规则对照，不再作为新版剑器稳定上限的公式：

```text
器体基础 = floor(kB × 有效承受结构)
在场灵识需求 = max(1, ceil(kS × 外放结构 + kE × 御器实际效力))
```

kB/kS/kE需独立试算标定，不沿用旧样本作为正式系数。形态体量、结构强度与小档都不是同一变量，不能只看器阶给每件固定生命。

上述旧“只有御器能力成立才生成”不限制新版剑器的类别默认用法。逐件参数归属与默认普攻物理类型已确认，以下为统一公式的候选表达，具体换算已有完整数值候选、待采用与平衡：

```text
稳定上限 = floor(S0 + k神魂×神魂 + k剑道×剑道造诣 + k占用×本件灵识占用)
默认御使普攻原始伤害 = round(D0 + d神魂×神魂 + d剑道×剑道造诣)
```

神魂、剑道读取御使者；稳定参数反映本体、连接和稳定实现，普攻参数反映成刃、攻伐与相关通路。本轮完整候选先将B三分，器蕴先扣，Xs／Xa与普通效果共用R／C／工艺求解，再经平方根组价值及20／20／3参照价归一；七项各向下截断四位、损失不返奖。数值待采用和平衡，不从旧kB／kS／kE或材料名字直接换值。默认普攻固定物理，专属技能按自身定义。

基础用法不要求额外抽中获授技能，但强化仍需真实来源及分配。两组参数不能各自复制完整的本体／工艺供给，C／R等共同上限不是另一份潜力，根性不是战斗付款资源；其他效果和器蕴使用过的量不能再领。灵识占用映射已有新候选，仍待采用；启用只检查可用灵识、不另收费，资源不足回退普攻保持已确认边界。

局内稳定与长期耐久分开，名称、归零／恢复和长期损耗按最新方案定稿。新成器固定保存参数与来源版本，战斗只计算当场结果；旧物不因打开页面按新公式补齐。

## 七、法器小档与工艺品质

当前先显示下品/中品/上品/极品法器，不额外开放“粗制/精良/上乘”等第二套前缀。品质评价保留在规划中，待它有独立玩法价值再决定展示，避免出现“上乘极品法器”这类难读组合。

评阶仍严格检查加工达标，不能用一个高品质评价弥补关键身材或根性缺项。品质不直接赠送属性倍率。

本节的独立工艺品质仍未开放；现行未标定的试炼小档也不补默认值。用户本轮所说的品质关联通过实际成材、连接、稳定实现与真实分配影响逐件系数，不据此新增玩家质量分。器阶是同一结果的等级标识，不能在参数已体现结果后再无条件乘一轮器阶、品质或形态倍率。

新剑[自动命名](器物自动命名与成器特征前缀_20261108.md)的两字方向前缀不是第二套品质前缀：默认两组，第三组仅在确有额外专属特色时考虑；明确专名优先。具体词表仍为候选，方向只读最终正数效果，不跨物伤与稳定排强弱。auto_name、custom_name及name_origin分别保存，不能从旧Name非空判断专名；改名不重炼当次系数。

## 八、炼制流程与失败边界

玩家仍只选剑大类、材料岗位及整数份数。用户最新要求：炼前和炼制过程不提供成品提示，包括预测器阶、效果、成败、达标状态或据本炉结果给出补料建议。不显示“已具备法器条件”“灵性留存不足，补某材”等间接成品预告。可展示客观材料信息、投料、五行阴阳及用度；加工适用/数量等操作合法性与成品评估分开处理。

玩家学习法器原理通过通用教程、材料性质及岗位说明完成，不在每次投料中由系统代判是否达到标准。成器后再显示实际结果和已发生的来源记录。

炼后先确定实际本体达标的小档，再在其真实预算和工艺上限内生成收益；显示成器信息、实际效果与未利用原因。

未达法器水准但完整可用的器物，应继续按凡器标准评定，不统一判为失败或器胚；凡器仅基础属性及器类固有本体性能。结构不完整或尚未完成必要加工的载体才进入失败/器胚候选处理；器胚保存及后续用途尚未开放。本篇不新增正式失败扣料/炸炉规则，当前测试消耗仍以原试炼边界为准。

## 九、三组应验证的组合

1. 主体与质材只够下品层次，加入高品性材：应保持下品资格，受本体预算限制，不因高品性材升成法宝。
2. 主体、承接、质材达到较高小档，性材较弱：本体小档可以较高，但实际角色加成依然由性材决定，不补送满档强度。
3. 同一组达标身/质，分别投入集中攻伐、多方向性材或增加导通：小档不因效果条数变化；收益的方向、表达与分配按通用公式变化。

上述为验收方向，不声称已实际产出上品或极品法器。首轮应先用真实目录验证材料层次覆盖、C/R曲线和造诣成长，再补公共加工参数；不穷举每种材料的成品属性。

## 十、实施边界

已确认：四个大阶、各四小档；大阶差距大且高阶有额外加成；本体/角色收益的材料来源分开；使用通用公式。

本篇新增候选：按实际结构/根性/稳定性自然评阶、器体/灵识映射及先不展示额外品质前缀。材料/造诣硬分档表已依用户意见删除。结果指标、区间、法宝以上加成、本阶段技能模板、器蕴套系及维护规则尚未定正式数值。当前试炼不得直接补默认“下品法器”标签。
