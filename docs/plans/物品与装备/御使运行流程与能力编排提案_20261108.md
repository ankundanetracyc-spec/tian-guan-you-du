# 御使运行流程与能力编排提案

> **状态：旧编排候选，冲突部分已被覆盖。**最新入口为[星标锋锐、默认御使攻击与稳定度](剑器星标锋锐与御使稳定度方案_20261108.md)。用户已明确通常两用、无专属御使技能执行类别普攻、手持星标只强化人物剑招、基础属性固定点数；本文的独立器术块不是必需项，“只有法效就完全不攻击”及手持全盘实际用器口径不再作为现行规则。局内生命不再采用器体名称。下文保留原提案以追溯，不能据此直接实施。

> 默认普攻体力0为用户暂定；法力0、本体每轮首次扫描发动一次、御使稳定度名称与公式均为最新候选，未因归档或零启用费得到确认。本文其他容量下降、反制与兼容细则也没有整体获批。

> 2026-11-08。应用户要求详细设计御使怎样运行。**持续灵识、真实用器锋锐、手持收益与化法限定为已确认边界；本页的本体／器术编排、启用细则、降容停用等为完整推荐方案，待用户审阅，未实装。**不以记录方案代替用户确认。

> **用户后续裁定**：启用御使只检查灵识，不收体力、法力或其他费用。本文“器术”只是器物主动技能的简称；是否将主动技能做成独立占格块仍未确认。下文保留上一版“本体＋独立技能块”的编排候选，不能因用户确认零启用费就视为接受这套编排。

依据：[御使、灵识与锋锐来源规则](新版御使灵识与锋锐来源规则_20261108.md)、[外围手持与护具](外围手持槽与护具分工设计_20261107.md)、[人类招式盘当前规则](../战斗与构筑/人类招式盘实施与验收_20261107.md)、[三资源总案](../战斗与构筑/design-plan.md)。

## 一、推荐的统一编排

**器物本体负责启用与持续维持；主动能力由器物技能按盘序执行；常驻、范围及条件法效依本体御使状态生效。**不增加器物独立行动条。

| 内容 | 怎么放 | 做什么 | 成本 |
| --- | --- | --- | --- |
| 器物本体 | 真物品在主盘放一份，按其战斗格形占位 | 启用御使、维持来源与范围、提供明文法效及器蕴 | 本体占格、持续灵识占用；启用无体力／法力费用 |
| 器物主动技能 | 本器确有主动能力时，在来源列表出现对应招式，可另放入主盘 | 决定该能力本轮的出招时间；攻击、施法、主动防护等都可通过它执行 | 器物技能占格、该能力明示体力／法力、次数与冷却；不再占灵识 |
| 常驻或条件法效 | 属于本体能力，不额外生成没有动作的器物技能块 | 御使中持续生效，或真实事件满足条件时触发 | 计入本件本体成本及法效限制；每次另有收费须明写 |

器物技能不是第二件物品。一个真实器物实例可以供自己的多项合法器物技能使用，持续灵识只按这件实例登记一次。没有主动能力的器物不必再摆器物技能；有多个主动能力的器物可选择本轮要编排哪些，按各项明示占格和可摆份数执行。

角色已学的招式若明文支持御使，也可直接指定一个合格器物来源；仍使用这份招式参与扫描，不再额外摆一张重复执行同次动作的器物技能。物品自带器物技能与角色已学御使招式都须有明确的实际用器资格，不因普通剑招带剑关键词就自动开放御使用法。

这里的主动／法效区分只用于说明执行时机，不新增玩家技能分类或关键词。

## 二、战前怎么配置

1. 从真实库存选择明确支持御使的器物，把本体放入主盘。行囊占格与战斗占格分别定义，不把现有2×6剑器硬塞成同样大小的战斗对象。
2. 在该器的真实能力中选择需要的器物主动技能，作为招式放入盘。仅列出本器实际拥有的能力，不因剑、镜、铃等器形免费授予技能。
3. 器物技能引用确定的真实物件。两把同名剑也分别认实例，不能靠名字自动改用另一把。
4. 一件实物的本体只放一份，不能同时手持与御使。允许手持甲剑、御使乙剑及其他合法器物；数量受实际库存、盘格、灵识及各卡明示限制共同约束。
5. 提交时检查配置来源完整：依赖御使本体的器物技能必须在该方案中有对应本体。源对象在但尚未启用是合法的先后安排；方案根本没有相应来源则提示错误。战中后来失去来源时保留原格并提示失效，不变成空格。

摆盘时只是配置和预览，不预付费用，不提前占灵识，也不提前获得范围加成或器蕴。

## 三、扫到本体：启用御使

在真实物品及摆放配置合法的前提下，本体第一次被本轮扫描到时，只检查可用灵识是否足够。足够就登记本件持续占用、进入御使中；不足则本次不启用。启用不消耗体力、法力或其他费用。

推荐本体也沿首次检查规则：本轮首次检查后整份变暗，启用失败不在第二占格重试，下轮再检查。启用成功建立本件御使状态及明文法效；是否在同一节点执行主动能力仍须在发动方式中定稿，不能从零启用费推导额外攻击。确有启用事件效果时，须独立写明效果与限制，不额外收启用费。

已启用器物跨共同回合保持。下轮再扫到时不重复占灵识、不重复加入器蕴。

**暗淡只表示本轮已经检查过，不表示御使停止。**界面需要另有御使中状态及真实范围显示，避免暗物件仍在生效却无法辨认。

## 四、扫到器物技能：执行具体能力

器物技能执行前核对：其指定本器仍在合法御使中、当前目标与触发条件、体力／法力、该份机会、同源共享次数和冷却。通过后付款、执行真实效果；不再提交一份灵识。

- 普通主动器物技能沿一份首次检查后变暗，失败本轮也不重试。正常施放有原成功机会与共享限制，不因器物技能属于器物而免费多一次。
- 应对型器物技能扫到后建立待命，实际应对才支付费用。沿共同轮末待命结束、先判闪避、首份合格应对失败后不寻找下一份等已确认规则。常驻防护不冒充另一次自动应对。
- 释放后落空或未造成伤害不自动退款、不恢复次数；实际伤害与防御仍走原结算。
- 同一真实器物的同一项器物技能若允许多份，按该能力明示口径共享次数和冷却；不同实物来源分别记账，卡面另有同类共享限制时再按其定义合并，不能只按同名误合账本。
- 器物技能来源停用后，取消依赖它的待命及后续发动资格。已完成的伤害、护盾不倒算，已经消耗的本轮机会不归还；来源恢复不从背后补查已经走过的暗器物技能。

初轮将本体排在器物技能前，可以在同一共同回合先启用后出招，不强制隔一轮。初轮器物技能先被扫到而本体尚未启用，该份失败变暗；之后本体启用不会补放。第二轮本体仍处于御使中时，器物技能即使排在本体格之前也能照常发动。

## 五、法效怎么运行

| 法效表现 | 执行规则 |
| --- | --- |
| 常驻防护或属性修正 | 本器御使中且条件合法时生效，停用撤去后续修正；不把手持专属收益带过来 |
| 范围强化 | 从本体格位与当前方向计算范围，再检查目标招式资格；覆盖不是自动符合条件 |
| 条件触发 | 本器已启用，真实事件发生且费用、条件与限次满足时才结算；启用前事件不追溯 |
| 主动攻击或施法 | 通过对应器物技能安排出手，沿该能力明示费用和目标；不因物品在场自动调用所有主动技能 |
| 明文触发攻击 | 必须独立定义事件、伤害来源、目标、费用与每轮／每场限制，不从一张器物主动技能自行推导免费反击 |

一件器物可以同时具有上述多项真实能力，费用与限次分开明示，共用本器一份持续占用。纯范围强化可以只摆本体；兼有攻击的器物可以再编排其攻击器物技能。

范围法效建议沿当前候选：覆盖到一份招式任一实际占格即可对这一份检查资格，多格重合不重复计；两份同名招式分别判断。范围内空格依然是真正空格，不被范围标记占用。范围指的是盘面哪些招式受益，不替代能力在战场上的目标或出手距离。

法效只从启用之后向前结算，不倒补此前施放。已待命应对在真实应对时核对当前合法法效；尚有独立额外施放机会的招式，在之后实际施放时检查当前来源与范围，不因普通扫格已暗就回溯重放。

## 六、灵识及体力／法力各管什么

灵识限制同时维持多少御使来源，跨回合保持；启用本身不收体力、法力。器物主动技能是否收费、怎样发动及是否单独占格，按后续能力与编排方案定稿，不能将这些未定内容当成已确认的启用条件。

以现有清和待审候选为算术示例：人物灵识容量3，清和占2，启用后就是2／3；触发护持或某项合法能力结束后仍是2／3，下一共同回合仍是2／3。收回或停用清和才回到0／3。该例不增加另一种施法占用。

推荐区分两种不足：

- **新启用请求放不下：**本次启用失败，不自动挤掉已在御使的其他器物；原器物照常维持。
- **原容量实际下降：**建议按盘序从后往前停用御使器物，直到总占用合法。停用时撤去对应持续法效、取消依赖待命并释放该件占用。此停用顺序是本轮推荐，不视为既有用户确认。

容量恢复不自动补施法或重领启用收益；若本体本轮尚未检查，可以在之后正常扫描时重新检查，否则等下一共同回合。重新启用仍只检查灵识，不收费，保留真实物件的本场次数、冷却与其他已发生记录。

## 七、真实用器和锋锐

人物手持甲剑攻击，使用甲剑本体属性；以御使乙剑攻击，使用乙剑本体属性。两种攻击都由对应合法招式执行，不因乙剑属于御使就排除其锋锐，也不因人物手持甲剑就将甲剑锋锐套给乙剑。

每段物理攻击核验本体是否参与以及实际用器实例。范围增益与器物化法作为不同来源分别核对，不把提供强化的器物误当作造成伤害的剑。附加段不无条件继承主段用器；多剑分段分别取各自来源，不默认相加。

没有实体用器要求的普通技能仍按原定义使用，不因为剑关键词就新增装备门槛；器物技能本身有明确器物来源，必须满足它的真实使用资格。

## 八、轮末整理与退出御使

每共同回合结束自动打开配招页，才允许调整；临时暂停和单个人先走完不开放改盘。

- 同一器物仍维持御使，仅移动或转向：保留其启用状态，提交后重新计算范围，不再记一份灵识。
- 移走本体、改成手持或来源失效：停止本件御使、撤去后续持续收益并释放占用；依赖器物技能保留实际占格但无法发动。
- 重摆同一物、切方案或更改摆放ID：不得重置本场次数、冷却、本轮触发账本或已经发生的器体损失。
- 改用另一件真实器物：这是另一实例的来源切换，检查其明示能力与限制；不能将旧器物技能按同名静默转给它。
- 退出御使后已实际获得的护盾、治疗等按原效果规则处理，不能一概倒扣，也不能凭停用重新获取一次。

推荐器物主动技能作为正常招式参与周天和复命时，仍检查对应非应对要求、原份机会、原费用／限制与本器有效来源；本体启用不是招式，不被复制或当成一次普通施放。具体器物技能的特殊禁用条件必须明写。这一兼容基线属于本轮建议，定稿时需与现行实现核对。

## 九、器体与反制

御使卡必须明示是否存在可受击器体：有则保存本场剩余器体及相关反制；纯法效没有该受击定义时不显示虚构器体0。清和剑上轮的纯护持、无受击器体仍只是一个待审样卡，不代表所有御使法宝都如此。

有器体的推荐规则：普通攻击继续依原角色目标定义；只有明文允许攻击器物的能力才将合格器体加入目标池，避免默认用许多法宝分流所有随机攻击。器体是否能享受主人护盾、物防或应对须能力明示，不自动借用整套角色防护。

器体崩解则本件御使停止并释放占用，依赖器物技能停用，实际物品不因此永久消失。建议本场不靠收回再放免费修复或重启崩解分支；若有真实修复能力须另写。单纯转位不恢复器体。

## 十、整轮示意

某剑器确有主动攻击能力时，摆好本体与其攻击器物技能：

1. 第一行扫到本体：可用灵识足够即登记持续占用、开始御使，不扣体力／法力；主动能力的发动方式仍按待审编排方案区分。
2. 第二行扫到攻击器物技能：本器仍有效，目标与资源合法，支付本招体力／法力，执行该剑器攻击，用这把剑自身的锋锐。
3. 攻击完成：本器继续御使、灵识占用保持；其他真实事件法效依其各自条件和限制结算。
4. 共同轮末：自动配招，可以调整器物技能顺序及本体范围；保留实际状态与账本。
5. 下一轮：本器已在御使中，持续占用保持；主动技能按定稿的发动方式、新一轮机会与自身能力条件执行。

清和护持候选没有主动攻击器物技能，只需本体启用后等合格剑招造成伤害，其护盾法效按候选限制触发。攻击型、护持型及多能力器物均在同一流程中运行，逐件填写真实能力。

## 十一、本轮核对与实施边界

- 效果、目标与费用：启用只检查灵识，不收体力／法力；能力费用与原目标按各自明文设计，新增编排细则仍为待审方案，不擅自采用清和候选数字作所有法宝通用值。
- 属性与关键词：使用已有物理伤害、物防、锋锐、护盾、化解、器体及既有关键词；不新增资源、攻击射程或位移。
- 0费与额外行动：启用不默认送攻击；器物主动技能保留费用和原限制，事件法效须明确约束，整理不重置收益。
- 图文与结构：本轮只补全通用规划；清和已归档数值仍为候选，不新增运行卡图或修改成器快照。
- 验证：核对本体／器物技能先后、跨回合持续、来源与占用、链接；未修改运行代码，不宣称已通过实战、编译或平衡验收。
