# 器物自动命名与成器特征前缀

> 2026-11-08，用户确认：后续炼得的剑，无明确专名时按格式自动命名；前缀要简短、可以文雅，但含义必须对应真实方向。本轮候选每组两字、默认两组，真实额外专属特色才取第三组。现行普通属性先走[六项白名单与剑形硬池](器物战斗属性白名单与剑形属性池_20261108.md)，不因名字发新效果。

完整数值见[v2材料实算](剑器属性池与化法接口修订实算_20261108.md)，词表位于[v2参数](剑器材料换算候选参数_20261108_v2.json)的automatic_naming。v1清和“固身·卸劲”随其池外物防整卡撤回，不再作为当前示例；历史原值保留。

## 一、格式与专名

```text
自动名 = 两字方向前缀1 · 两字方向前缀2 · [两字专属特色前缀3] · 真实剑型
显示名 = 有明确专名时用专名，否则用自动名
```

默认两组，最多三组；前两组之外，确有已生成的主动或专属御使特色才追加第三组。实际不足两组如实少写，不补均衡、神异、清和等空泛方向。只读取最终正数效果，不取未利用潜力、未过门槛候选或原材料标签。

当前持有者是否学会技能、手持／御使、法力是否足够、是否冷却或如何转向，均不改变成器名称。名字概括确实拥有的能力，使用条件在卡面明确。

显式专名与自动名分别保存。商品／剧情明确命名、玩家命名优先；旧Name非空不自动代表专名，避免默认“修长薄脊剑”阻止自动名。旧来源不明保留原名，不批量改写。本次清和商品有明确entity_name来源，保留清和剑专名，另算自动名供对照。

## 二、当前前缀词表

| 排序 | 实际正数效果 | 两字前缀 | 对应含义 |
| --- | --- | --- | --- |
| 基础1 | 会心 | 洞隙 | 察见破绽，利于会心 |
| 基础2 | 精准 | 明察 | 辨明来势，提高命中评分 |
| 基础3 | 身法 | 轻身 | 动作轻灵，提高闪避评分 |
| 基础4 | 生命上限 | 养元 | 养护生元，提高生命容量 |
| 基础5 | 物防 | 固身 | 稳固自身防护 |
| 基础6 | 护心 | 守中 | 守护要害，抵抗会心 |
| 化法 | 指定格剑追加化解 | 卸劲 | 卸去来劲，强化实际化解 |

按组先基础后化法，组内按上表与稳定效果ID排序去重，通常取前两项。这只是读名顺序，不代表前项强于后项；不跨物防、评分、伤害、稳定等量纲比较强弱。剑形只允许自己的属性出现，因此不会从池外方向取前缀；池内没有实际产出也不取名。

独立主动／专属御使的破敌／自守／驭锋／护主等词仍为后续能力词表候选，只有真的生成并通过相应模板审核才可入名；本轮没有开放这些能力的自动生成。普通剑招增伤已撤回，其旧“摧锋”前缀不进入当前生成。默认类别普攻与基本稳定不是额外专属特色，不因此加第三组。

未校准同类参照与阈值前，不能比较稳定28与物伤9就叫“高稳定”，也不能把锋锐5冠以高锋。未注册方向省略，不从长描述猜词；器蕴与主材保留在详情，不为凑名堆满所有方向。

## 三、剑型后缀与清和试算

后缀按真实厚宽比τ：≥0.16为厚脊剑，否则薄脊剑。完整修长／宽展形态按λ保存在profile中；后缀只概括形态，不再乘伤害。不能从名字反推属性池。

清和v2最终为会心11、精准6、格剑化解3，厚宽比0.157188。前两项正数基础效果对应洞隙／明察；没有额外专属御使能力，不加第三组。同投料无专名的新炼器显示：

**洞隙·明察·薄脊剑**

格剑化解3仍完整写在卡面，不为把化法塞入名字改变排序。同一物件不随机切换词语；已有清和专名仍显示清和剑。

## 四、保存与验证

成器保存auto_name、可选custom_name、name_origin、前缀来源与命名规则版本。公共词表更新不在开页时重命名旧物；改名只改命名字段，不重炼、不改能力／预算／实例／数量。同名不同实例不合并，也不因此具有唯一性。

[v2数学验收](清和剑属性池修订验收_20261108.json)核对：最终正数前缀、六属性池外排除、默认两组两字、真实专属才有第三组、零效果不取名、专名覆盖、改名不改变七系数及同值材料异名性能一致。正式命名界面和重命名入口未接入。
