## 可以用于改卡的现有字段

| 部分 | 已有内容 | 改卡时如何理解 |
| --- | --- | --- |
| 身份 | 独立实例ID、名称、类别、器阶、形态、阴阳 | 同名器物仍是不同实物；整套器物按一个实例 |
| 图标与行囊 | 图标路径、行囊宽与高、旋转 | 已有行囊占格，不能直接当作已定的新战斗盘范围 |
| 外形结构 | 长、宽、厚、体积、结构承载 | 是真实炼制结构，不自动变成攻击射程或盘面尺寸 |
| 本体 | 器体上限、锋锐、灵识需求 | 器体用于召出在场；锋锐按实际用剑来源生效 |
| 装备收益 | 效果列表中的属性、数值、描述 | 对人物生效的收益；本体锋锐单列，不混为人物属性 |
| 常驻能力 | 效能、触发事件、触发条件、适用范围、数值 | 有明确形成的能力才显示，不从名字推断能力 |
| 化法 | 共同适用对象、每条修正、条件与数值 | 当前器物选择一个技能对象，不额外占施法灵识 |
| 主动／在场技能 | 技能名称、目标、体力与法力费用、伤害／护盾、状态、原回合／场次数、冷却 | 由实际已装配模板生成；描述存在不等于已接通战斗 |
| 召出／御使 | 在用状态、灵识占用、器体（有此定义时）；旧召出费用只作兼容记录 | 新版启用只检查灵识，不收体力／法力；御使期间持续占用，收回或停用释放；普通手持不占灵识 |
| 器蕴 | 本件的蕴种与贡献 | 单件固定贡献与全身累计分开；同一实例不重复计算 |
| 长期耐久 | 旧实例仍保留当前／最大耐久字段 | 当前主案尚未完成维护规则，不据此补造新的耐久消耗 |
| 行旅能力 | 载具能力、已充入的灵石时长、正在使用状态 | 独立世界能力，不自动成为战斗技能 |
| 来源与保存 | 炼制配方／投料、参数版本、输入指纹、效果来源分账、计算记录、成器快照版本 | 用于重演和存档兼容，放策划说明，不堆进玩家效果正文 |

每条生成效果还保存：效果身份、能力类型、承载方式、属性键、适用范围、事件、条件、玩家描述、实际数值和战斗模板装配状态。潜力分配与量化损失属于炼制记录，不直接当作战斗数值。

## 新盘还需要用户确定的部分

- 每种器物在主盘的实际占格与可旋转方向；外围手持的接点和读取时机。
- 御使器物如何启用、何时生效、在盘中是否保留召出／在场两态。
- 强化范围的形状、起点、朝向、适用招式与受益标；现有“效果适用范围”不等于已有几何范围。
- 原装备收益、化法、主动技能和器蕴分别由手持、穿戴或主盘哪一项承接；同一实例去重。
- 旧占用字段如何迁移成单一持续占用，器体与离场如何映射到新盘；原费用、次数和冷却是否调整。

建议改卡时先按“身份与占格 → 本体 → 手持效果 → 化法 → 各项能力与费用／目标／次数／冷却 → 御使灵识占用 → 器蕴”逐区核对。有哪类能力就保留哪类，无能力不补造数值。具体新规则仍由用户审阅后实施。
