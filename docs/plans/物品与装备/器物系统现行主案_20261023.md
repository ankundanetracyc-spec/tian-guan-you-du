## 一、确定的主干

1. 行囊保存器物，装备决定哪些合法收益生效；衣、剑、甲、珠等统一管理，不另建常规穿戴与法宝两套收益栏。装备本身不占灵识。
2. 新版御使启用后持续占用灵识；普通手持不占。手持剑锋锐只强化星标内携带剑关键词的人物招式，御使剑本体物理攻击用自身锋锐，不领取手持星标。
3. 身材主要贡献本体，性材主要贡献角色收益；各岗位有真实交叉贡献，同一潜力分账守恒。本剑稳定与默认物伤参数由真实成材、加工及分配形成，不以旧固定生命或全类系数代替。
4. 器物可有基础加成、化法、独立能力与器蕴，分开登记。普通加成仅用六项整数白名单，剑形硬池先于分配且池外绝不生成；本轮不自动生成关键词剑招加伤。特殊能力须独立批准模板，不设置成器功用字段、不强制最多两条。
5. 新版器物通常两用，御使本体按独立战斗格形放入主盘。能力统一登记为技能，普通攻击也是其中一项；每项各自判断费用与条件，不满足跳过且不自动替换其他项。多技能扫描次序与编排尚未定稿，不强制多摆一块。
6. 新版启用只检查灵识、无其他启用费；只有持续占用，跨轮保持，收回或停用释放，不再有按次施法T。具体技能费用按其明文，普攻体力0暂定，法力未定；化法仅在已启用手持本器时生效，不另占灵识。
7. 成套剑器是一个器物实例，多柄是其构成与表现。整套只提供实际形成的一份收益/器蕴；成套御用通常灵识要求极高。
8. 相同器物合并同化为一套是后续方向，兼容性、投入消耗与结果公式尚未定案。

## 四、从炼器到战斗的完整流程

1. 玩家选择剑等大类，投入身/质/性/和材料及份数。无燃料，不预选最终细器形；炼前只显示客观过程与用度，不提示成品或达标走向。
2. 公共材性与加工形成真实形态；先确定硬属性池、排除池外候选，再在器蕴先扣后共同分配本体、六项基础属性、工艺及注册化法。材料到七系数已有v2可复算候选，正式生成器尚未切换，不给所有剑补同一套数字。
3. 成器先成为人物行囊中的唯一实例；正式入包需要真实扣料/精力/时间的事务闭环，不能把试演材料变成正式产出。
4. 人物配置合法手持／御使用法及其他已定义来源。装备属性在本件已启用手持或御使时均生效，同一实例只计一次；化法仍限手持本器且启用。御使动作按主人最终属性读取，不额外复制角色加值；器蕴有效集合按后续统一来源规则定稿。
5. 整包化法只选一个已学已摆的合格placement，精确记录布局／份数／基础招式身份；或将御使本体放入主盘。同一实物不能两处并用，不复制来源。预配置与实战启用分开，失效暂停不重置技能账本。
6. 战斗中按待定稿的时机检查并建立本件持续灵识，启用无体力／法力费。读取本件参数与当前御使者属性，按统一列表逐项检查技能费用及条件，不满足跳过该项，不自动补放其他技能。具体扫描次序仍待定。
7. 收回／停用释放本件持续占用；战斗结束清理单场状态，保留物件与配置。同场剩余稳定、归零与恢复依生命规则定稿，不借整理重置次数或把派生生命写回固定快照。

旧直施模板保留自己的实际使用条件，不由本轮参数规划自动改造。新版普通手持不占灵识、不要求先御使召出，手持锋锐按本剑星标筛选人物剑招；御使本体物理攻击使用自身锋锐。凡器也遵守这两条路径，不能因人物灵识为零排除其手持用法。

各项能力统一按技能字段记录，普通攻击也是其中一项；每项技能独立检查费用、目标及其他条件，不满足时跳过该项，不自动替换别的技能或额外补普通攻击。只有实际执行的技能结算自身效果；技能之间的扫描次序与编排仍待定，不能借本条默认同时全放。旧资源不足自动回退已撤销。

## 五、技能槽变换与队列意图

> 以下保留旧十槽／同槽变换的实现依据。新版按页首招式盘、类别默认动作与逐件参数方案，不能从旧槽位编排推导必需器术块或覆盖新扫描规则。

槽位保存器物来源，显示随运行态变化；变换不新建永久技能，不刷新次数/冷却、不占第二个位置。

规划时可多次把同一入口排队。示意：

```text
行动1：该器物〔召出〕
行动2：普通技能
行动3：该器物〔在场施法〕
行动4：该器物〔在场施法〕
```

每项各占一次行动。预演考虑前序可能成功建立的在场状态，重排后重算分支、目标与费用。确认队列后锁定意图；实际召出失败，后续在场施法不会改成召唤，也不免费补行动。

悬停、槽位、队列要分别展示当前分支或该项锁定分支。例如槽位已经变为在场技能，前面已完成召出项的记录仍显示召出，不能被统一改名造成历史混淆。

限次与冷却按原模板和分支管理，不因图标变换重置。召出不默认消耗御使次数或启动其冷却；独立技能有无额外限制需模板明示。失去装备来源清空相应技能位置，其他位置不前移，秘籍化法保留。

## 六、灵识提交与释放

> 以下D／T公式为旧实现兼容记录；新版只有持续占用，启用仅检查灵识，无体力／法力费，不按次登记或释放T。新能力不得继续填旧T作为可调字段。

```text
已用 = Σ在场持续D + Σ当前尚未结束的施法T + 其他真实占用O
本次可用 = max(0, 上限S - 已用)
```

普通装备、纯化法没有新增占用。多个连续行动各自在开始时提交T、结束归还，不把一轮所有T永久加在一起。若有真实嵌套执行，外层尚未结束的T必须保留，不让同一份容量同时被使用两次。

执行前校验来源、在场要求、目标、容量、体力/法力、次数/冷却。全部通过再提交本次费用及T；未通过则沿当前失败规则处理，不先扣后漏退。

合法释放后被闪避或没有造成伤害，不等同于没有施放：原体力/法力、限次与冷却依原技能规则结算，不能因为T归还就自动退还其他费用。结束、中止、死亡和战斗终止都需清理对应临时占用，不能重复释放。中断机制本身不由本案新增。

施法完成后仅退本次T，仍在场的D保留；普通状态效果持续不等于T一直存在。生成持续实体则另建它的D，不混用旧T当作永久占用。

召出分支是否另有T，以及新D建立时是否与召出T发生重叠，须在完整召出模板中明确并展示峰值，不在本案凭空收费或默认免费。容量0不视为无限。

## 七、成套与同化

同源成套剑器按一器、一份装备收益、一份器蕴、一个御用入口处理。多柄出击可以是一项在场技能的多段，不能逐柄复制整套基础伤害、器体或锋锐总和；合法固定增伤仍按每段完整追加。

共享器体/逐柄器体为两种可设计模型，实际采用需明确。一体群攻不能按剑图数量重复扣同一生命池；逐柄模型不能对分体与父组双重扣血。数量变化如何影响攻击段与D需按公共模型实现，不用特效数量代替真实机制。

成套高灵识需求体现在D的分体维持和协同负担，并为复杂施法另保留T；不是额外装备维系费。数量、体量、连接/稳定及技能控制复杂度参与成本，系数未定，不提高角色上限掩盖不合理参数。

同化未来按兼容器物投入、共同结构重整、收益/技能/器蕴/占用重算形成成套结果。相同名称不足以判定相同器物；原件消耗、拆回、结果身份与绑定迁移均待专项方案。当前不实施同化，不把多件完整效果直接求和后压成一件一槽。

## 八、器蕴与固定词条

当前两种器蕴为惊鸿、抱朴：前者提高带有“剑”关键词的技能所造成的物理伤害百分比，后者提高角色物防百分比。激活不额外收灵识。贡献按装备实例去重累计，成套不按分体加点。

单件1—3点、2/4点门槛及具体比例仍是候选参数。各档显示最终总比例，高档不重复叠加低档完整比例；仅持有不贡献。材料潜力分给器蕴就不能同时全额用于单件属性。

装备词条直接增加角色战斗属性，不再沿用“带有剑关键词的技能每段固定增伤”作为新装备效果方向。旧成器已有条件效果的迁移另行核对；器蕴、化法与主动技能按各自规则处理。后续剑意和护盾触发须有完整模板，不因剑标签自动生成新效果。技能类别、关键词与出手方式分别判断，近身不视为关键词。

## 九、材料计算的统一约束

不新增材料名到成品效果的一对一配方表。沿用有效供给、份数递减、品级作用、加工保留、共同结构/根性/通路与效力分配；新增材料填写共享档案后参与同一公式。

### 新材料无专属配方接入（2026-10-27用户确认）

- 未来新增材料沿用与当前材料相同的公共炼器规则，不为每种材料、材料组合或炼成剑单独配置配方。
- 材料档案只定义材料自身性质：五行、质地、相性、功用及等级，以及既定计算所需的物理加工属性。加工属性是材料输入，不指定成品身份、固定词条或获授技能；无需为新材料编写独立效果适配代码。
- 岗位适用、有效供给、配伍、器形、本体性能、装备属性、化法、主动能力与器蕴，均通过共享规则及其已有公共效果定义结算。同类功用自动参与已有映射；新增一种公共效果时才扩展公共效果及执行接口，不按材料名字分支。
- 推荐样方与已保存投料只是填写和复用工具，不是成器资格表；未列入样方的合法组合仍可按同一模型结算。无专属配方不表示任意材料可用于任意岗位，仍遵守材料适用性、造诣、资源和容量限制。
- 接入验收必须包含：新增一个具有完整自身档案的材料，不新增配方、不修改效果与战斗适配代码，即可选择、投料、结算、入包、装备，并使用其实际形成的已有能力；来源快照可保存和重演。同性质异名材料的结算结果应一致，身份与来源记录正常区分。

**2026-10-27实施：材料自身档案与自动发现已接通。**炼器公共参数不再保存按材料名列出的加工名单；原十一种材料的岗位与加工数值原样迁入各自材性资源。正式炼器与独立工坊共用自动发现，新增具有完整自身档案的材料后，重新打开工坊即可进入合法岗位候选；不添加样方、不新增配方、不修改成器效果或战斗适配代码。

新增材料的资料接入顺序：

1. 在正式物品目录 `resources/entities/items/`（支持子目录）建立材料物品，填写唯一的定义身份和名称，并通过 `craft_data` 引用其 `MaterialCraftData`。材性文件无须与物品文件同名，也可以使用内嵌材性。
2. 材性仍填写五行、质地、相性和功用等级；在其可选 `forging` 字段挂接 `MaterialForgingData`，只描述本材料自身加工表现。
3. 加工档案沿用已有字段：合法岗位 `roles`、加工难度 `difficulty`、保留率 `retention`、体量 `volume`、延展 `extension`、厚薄 `thickness`、刃性 `edge`、强度 `strength`、连接 `connection`。这些数值须有材料设计依据；不能从名称、五行或质地猜测并填默认值。没有加工档案的材料暂不出现在炼器候选中；存在档案但数值非法时明确报错，不静默套用其他材料。
4. 正式选材、库存与扣料均读取实际物品路径。候选只按自身档案的合法岗位筛选，成器能力继续由公共预算与效果模型生成。仅新增材料不改变已有能力的费用、目标、关键词或触发规则。
5. 成器保存当次材性和加工参数快照；旧快照仍从其保存的 `Profiles` 与参数原文重演，不反查当前材料。当前参数文件移除名单，不删除历史快照字段；日后材料修改或下架也不影响已有器物的来源重演。

本轮验证：编译0警告、0错误；新材料接入专项32项（含迁移前参数对照）通过，正式炼制集成42项、通用剑器适配51项通过。专项实际创建一个不在样方和公共参数内的异名材料，使用任意文件名和子目录，验证发现、合法选材、真实扣料与精力、成器入包、装备、实际生成主动能力的装槽与解析、化法来源、器蕴累计、保存读取，以及移除当前材料文件后的快照重演。四套旧样方的锋锐、效果、预算和器蕴与迁移前一致，旧参数原文快照重演保持输入哈希。临时测试材料与存档已清理。

验证范围为独立场景和接口检查，未作完整人工实战验收；仍有既有《卸力》资源UID失效后按文本路径加载的警告。本轮未改战斗卡、炼器生成效果数值或运行中的手持锋锐规则；前文2026-10-27确认的装备词条迁移与手持锋锐接入仍是后续事项。

对每个来源维度u，分给本体、基础属性、效能、化法/技能及器蕴的量合计不能超过实际供给Eᵤ。同一来源不能全额复制到多个方向。主要岗位关系不是独占，身材强度也不能直接等同于角色物防强度。

### 剑器成器参数补充（2026-11-08）

新基础属性只生成六项白名单且须在实际剑形硬池内；先筛候选再归一与共同分配，无效来源记未利用，不溢出回填。本轮化法只走[注册整包接口](器物化法生成与招式改写接口_20261108.md)的格剑化解槽；普通关键词伤害、事件奖励及旧泛化改写均不进入v2。六项属性生产贡献账本和新盘器物化法数值桥尚未接入，旧运行记录不能证明新链已完成。

本剑稳定基础项及神魂／剑道／占用系数、默认物伤基础项及神魂／剑道系数，属于成器固定性能。公共公式共用，参数逐件生成；具体映射、平方根成长、20／20／3参照价归一及四位向下截断已有[完整候选](剑器属性池与化法接口修订实算_20261108.md)，待采用与实战平衡。旧12／2／0.5／8及4／0.45／0.55仅为人工算例，不是真实清和系数。

本体与加工结果提供性能依据，额外强化占用沿同一真实来源账本，不能给每个输出重复发放满额潜力。共同C／R及工艺是约束，不是另一份可领奖励；现行器蕴预留与扣除顺序不因新参数改变。普通类别攻击不必先抽中专属御器表达，凡器不因此获得专属技能、化法或器蕴。

当前御使者神魂与剑道只是战斗代入值，不写成器物自带人物属性；默认剑攻仍物理。品质及评阶概括真实加工与分配，不在最终参数后再乘同源品质倍率；新物冻结当次参数，旧物不默补、不重炼。完整边界见[逐件参数生成规范](剑器成器系数与御使物理普攻生成规范_20261108.md)。

固定值候选转换按分得效力、适用覆盖／事件成本和公共系数计算，整数取整并记录损失；百分比器蕴另按公共激活表，不把旧百分比值直接换单位。本轮B分核心／稳定／攻击后，器蕴先扣，Xs／Xa与普通效果共用R／C／工艺求解；根性是炼器预算，不是战斗付款资源。分体、一般化法兼容及正式采用仍需后续确认，旧D／T不作为新版新增费用。

## 十、最小交付与验收

先做单件法器、一个召出入口及一个在场技能，不要求首次交付就有四件装备、六柄分体、同化或全部器蕴。

| 阶段 | 必须证明的闭环 |
| --- | --- |
| 物品 | 新成器真实入包、图标/统一信息栏、同名实例区分、重启读档 |
| 装备 | 合法角色固定收益与来源撤销，普通装备不占灵识 |
| 化法 | 共同条件、单对象、秘籍兼容、化法不新增T |

| 清理 | 失败、死亡、离场、战斗结束不遗留占用，重复提交不重复结算 |
| 扩展 | 模型确认后再做成套、逐柄受击、多器、器蕴汇总与同化 |
