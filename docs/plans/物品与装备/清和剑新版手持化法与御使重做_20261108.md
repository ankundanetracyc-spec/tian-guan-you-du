## 一、本轮已确认

1. 用户要求剑器整卡重新设计：锋锐必须点明生效范围，装备效果需修订，化法须写明目标技能要求，御使须有完整方案。
2. 剑器装备加成只在**手持本器且已启用**时生效，新卡栏目使用“手持效果”。主盘御使不继承这组人物加成。
3. 用户明确选择：**化法只在手持本器时生效。**化法同时要求本器已启用、指定目标合法、实际触发条件满足；行囊收藏、主盘御使均不能启用它。
4. 保留单件真实器物的身份与来源边界，同一实例不同时手持、穿戴或御使，不复制效果与器蕴。护具的既定穿戴职责不被本轮剑器手持条件改写。
5. 化法先明确必需关键词，必要时直接指定基础技能，整套效果围绕同一目标设计。用户要求尽可能避免将适用于不同技能的条目混成一包，造成实际使用时部分条目浪费；撤回“选定一招后各条分别判断，只生效其中几项”的建议。
6. 新版灵识只在器物御使期间持续占用，单次出招不另登记施法占用。锋锐属于本体，不能把手持专属效果的限制套给御使剑器的真实攻击。
7. 启用及重新启用御使不收体力、法力或其他费用，只检查可用灵识。“器术”只是器物主动技能的称呼，是否单独占格尚未确认。

## 三、锋锐的完整表达

新卡必须同时说明：**当前用法、实际用器来源、适用攻击、盘面范围**。

- 手持基线：实际使用本剑的物理剑招，按本剑锋锐忽略物防。只具备剑关键词、使用另一件剑器、拳脚或无本剑来源的术法均不能借用。原规则不要求招式紧贴外围手持槽；若新版要增加几何限制，必须单独定稿并画出格位。
- 御使出招：实际使用本剑本体造成的合格物理攻击，使用本剑锋锐；不能加到人物手持的另一把剑上。主盘范围覆盖招式也不自动获得锋锐，需该法效另有明确授权。
- 多把剑分别认来源，不将锋锐相加给全部剑招。衍生伤害、公共状态伤害及群攻的适用边界依真实模板明写，不因图标或器名推断。

“锋锐的适用范围”与“御使法效覆盖哪些盘格”分别展示，避免将真实用器条件误写成全盘增益。

## 四、化法要求与当前冲突

旧正式入口要求整器化法的各项条件同时满足。当前清和剑的两项分别为：

| 项目 | 实际技能要求 | 当前20招中的对应对象 |
| --- | --- | --- |
| 应对化解+1 | 带应对关键词，实际施加化解 | 架招、格剑 |
| 忽略2.1%物防 | 气血关键词、单体物理攻击、非范围攻击，且技能原有比例穿防为0 | 血臂撼岳 |

**当前20招没有同时满足两组要求的招式。**前述是旧正式入口与当前技能定义之间的实际冲突；试器中的逐条判断不能直接当作正式入口已经允许。

用户已明确：**先确定化法目标，再围绕该目标形成整套有效修正。**不采用“选格剑只用化解、选血臂只用穿防”的部分条目生效方案，不为凑条件给技能添加气血或攻击。

| 定义方式 | 必须明确的内容 | 本轮示意 |
| --- | --- | --- |
| 关键词要求 | 所需既有关键词，以及必要的真实效果条件；所有条目共同适用 | 要求剑、应对、化解，并实际应对物理攻击、施加化解；所有修正围绕这类动作设计 |
| 指定基础技能 | 稳定基础技能身份及适用效果，不按玩家改名后的文字匹配 | 直接指定格剑；全部条目围绕格剑设计 |

“先定目标”是效果方案的生成顺序，不要求玩家在炼前预选成品，也不增加未定义关键词。基础技能经过兼容化法形成的变体，是否仍满足修正要求按真实效果核验；不凭名字放行。

清和剑建议先以**格剑专用化法**作为重做样例：原来互不兼容的两项投入重新参与这一方案的统一核算，不保留一条对格剑无效的气血攻击穿防。具体条目、数值与来源转换尚未定稿，不把旧2.1%直接改成若干点化解或免费增加一份收益。

生成和验收原则：

1. 先明确该器化法的共同目标与真实生效时机，再选择对该目标有效的修正模板。
2. 按同一来源预算分配给这些兼容修正，不先生成互斥条目再让玩家舍弃一半，也不重复使用已分给其他器物能力的潜力。
3. 合法目标应能使用整套效果；应对等条目仍等真实触发后结算，不因配上化法提前领取收益。
4. 一个目标方案没有完整可用模板时，先补全设计或不生成该方案，不以隐藏无效条目、自动切另一招或补新关键词凑合。
5. 人物未学对应基础技能时不免费授予该技能。选中的是一份实际摆放，不能使盘上同名所有份数一起强化；具体选择界面与几何要求仍需在外围手持接口中定稿。

玩家卡面集中写“要求”或“指定技能”，随后列整套效果；手持本器且已启用的来源限制明确保留。内部来源分配和转换记录放策划说明。

## 五、御使完整设计边界（待审）

御使单列本体、法效和器术，沿原逐行行动运行，不增加独立行动条。

| 环节 | 建议行为 | 必须在逐件方案中补齐的内容 |
| --- | --- | --- |
| 布置本体 | 真器物放入主盘，选择御使用法；不能同时手持同一实例 | 战斗格形、转向、同类／实例数量限制 |
| 首次启用 | 对合法摆放的真物件，只检查可用灵识；足够即建立御使状态，不收启用费用 | 本件持续灵识占用、是否可受击及失败后的再次检查规则 |
| 启用持续 | 建议跨共同回合保持，已启用后的其他占格不重复建器体、占D或加蕴 | 停用条件、容量下降与恢复的处理 |
| 范围法效 | 只强化明确覆盖且符合要求的招式；同一来源覆盖多格同份只算一次 | 原点、相对格位、朝向、目标资格、效果与叠加规则 |
| 器术 | 有明文主动能力才提供对应招式，引用本件真实实例；出招不另占灵识 | 格形、份数、目标、伤害／护盾／状态、体力／法力、次数与冷却；是否另占招式格逐件定义 |
| 实际出招 | 来源必须仍处于御使中；按招式首次检查后整份变暗及共同轮次规则执行 | 器术在本体之前检查时的失败提示，后续机会不回补 |
| 锋锐 | 仅按本剑实际参与的合格攻击结算 | 哪些原始段／衍生段适用；范围法效不默认授予锋锐 |
| 器体受击 | 明文允许的能力才纳入器体目标池，防护来源逐项定义 | 器体目标资格、物防／护盾／应对是否可保护它 |
| 停用与崩解 | 有器体的能力建议保留本场剩余器体，移位、收回、换方案不修复；停用释放本件持续占用 | 本场能否重启、修复资格与动作收尾；不因单次出招结束释放御使占用 |
| 回合整理 | 仅在共同轮末调整；本体和器术仍占真实格，不因失效变成空格 | 换用法事务、状态保留、方案检查与来源失效提示 |

御使不提供已确认仅限手持的装备加成和化法。御使范围法效必须单独设计、单独核算来源效力，不能给旧手持化法换名后继续运行。器术不因范围覆盖而免费施放，不重置同招限制；范围落在真正空格上不占格，也不额外制造回体事件。

清和剑当前没有御使能力。重做需完整定稿本表后，才能授予相应本体与器术；不能凭法器品阶直接开出一套未配置能力。
