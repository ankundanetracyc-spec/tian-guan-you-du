## 一、本体与角色收益分开

器物本身属性用于其御用召出在场后的本体。身材主要影响器体上限等本体属性，其他岗位可有实际贡献；“主要”不等于唯一。器体不是人物生命，也不是尚未定案的长期耐久。

本体锋锐等不能在器体未在场时，仅凭已装备或一个来源引用就默认参与普通攻击。御用在场后，仍要由实际参与的器物来源与技能规则判定，不把全部在场剑的锋锐相加。

装备后给予角色的基础加成、条件效能、化法、获授技能资格和器蕴贡献仍是另一层，按各自装备/效果条件处理，不混成器体本身属性；性材主要贡献该方向。角色物防+4不能解释为器体物防+4，器体也不追加到人物最大生命。

凡器本体怎样在普通持用/零灵识人物行为中使用，需与本次本体在场定义再统一；不因此前凡器可普通装备就默认放开未在场的本体修正，也不在此宣布凡人不能使用普通工具。

## 二、三种情况

| 情况 | 占用 |
| --- | --- |
| 持有或普通装备，尚未释放相关技能 | 不收维系灵识 |
| 器体召出并持续在场 | 持续占用在场灵识D |
| 释放器物自带技能或借器施法 | 本次施法临时占用灵识T；释放结束返还 |

器体在场期间再次施法，占用D与T同时存在。释放完毕只释放T，器体仍在则D继续保留。普通装备没有重新引入此前撤回的长期维系费用。

允许不召出直接施放的器物技能，只需按该模板提交T；技能明确要求在场的，必须已有合法在场状态。不能为成功施法把失败的御使意图自动转成召唤，也不能以直施名义偷用未在场本体属性。

用户进一步确认：化法不属于主动借器施法，不额外占用灵识。普通技能绑定器物化法后，化法随原技能生效，不为该修正新增临时占用；原技能自身明确需要的资源仍正常检查。只有主动使用器物技能或主动借器施法才按模板临时占用。常驻的条件增伤也不自动当作一次主动借器施法。

## 三、同一份灵识账本

```text
当前占用 = 在场持续占用D + 正在进行的施法临时占用T + 其他真实占用O
剩余可用 = max(0, 当前上限S - D - T - O)
本次施法可开始：剩余可用 ≥ 本次临时需求
```

连续队列行动的临时需求依实际重叠阶段判断，不将整轮所有技能需求相加后永久占住。若出现嵌套应对等真实重叠，外层尚未释放的占用仍应计入，不能提前退还后让同一份容量同时使用两次。此为账本设计要求，具体提交与释放时点需在战斗流程接入时核对。

临时占用是容量的占住/归还，不是法力扣除或每回合恢复。即使实际体力/法力费用为0，只要模板需要T，也必须有足够容量。零容量不视为无限。

## 四、施法生命周期

建议实现阶段以“通过全部执行前校验→提交本次临时占用→释放效果→完整释放结束归还”为统一过程。未开始即失败不占住；中断、失败退出、主人倒下或战斗终止必须清理本次尚未释放占用，不能重复退还或遗留。

瞬时技能完成后留下的普通状态效果，不因此自动长期保留T。如果技能生成了持续实体，该实体应按自己的D生命周期登记，不能混用施法临时占用。召出技能本身是否另需T、与新D同时存在时的峰值需求，由完整召唤模板明确，当前不凭推测填写费用。

跨回合持续施法若以后存在，应按真实释放结束时间保留T，不按回合结束机械清零。当前不新增蓄力、引导等战斗机制。

## 五、纯算术例子

以下不对应正式角色容量或器物平衡：上限10，剑群在场占6。

- 待命环绕：占6，可用4。
- 御使剑群，本次临时需求3：释放期间占9，可用1。
- 释放结束：返还3，回到占6、可用4。
- 剑群离场：释放剩余6；没有其他占用时回到可用10。

若另一项技能临时需求5，在剑群保持在场时不能开始，因为剩余只有4。不能仅以“用完会释放”为由允许释放期间超过容量，也不能宣称自动收剑或替玩家取消别的占用。

## 六、成套与多剑的后续方向

用户允许继续构思成套剑器与多件独立飞剑，并强调成套剑器御用通常对灵识要求极高。成套装备按一个来源实例，不代表其在场控制成本低；分体数、协同与控制范围应参与公共成本公式。强度、器体和临时施法需求分别计算，不把高D当作可以省掉T的理由。

成套剑群共享器体或逐分体受击都可继续评审，不提前把共享器体确定为唯一规则。多件独立剑维持各自器体/来源，若共用一次群体指令，必须定义本次施法需求、参与集合和总效果；不因所有剑在场就免费各施放一项技能。

具体数量、费用系数、群攻目标口径、凡器普通使用与本体在场的关系仍待定。化法不另占灵识已确认。当前只修订策划定义，不改技能资源或补发正式器物。
