# 百川固定方格世界地图设计

> 状态：现行地图主案（2026-09-28，按用户修正采用手工拼接的固定方格地图；格长 40 公里、遁速为无单位评分）
>
> 目标：以《鬼谷八荒》的逐格大地图、移动揭雾和旅途探索为交互参考；地图地貌、格位和地点由策划手工设计多个地形方格/拼块，再拼接为固定的百川地图。
>
> 上位来源：《当前项目：个人修仙改造路线》《大陆格局与百川区域设计》《百川区域仙盟大势力与天人议盟规划》《地点模板与节点互动框架》《百川区域地点旅行与 NPC 月度演算规划》。地图交互与旧固定道路方案不一致时，以本案为准。
>
> 当前地貌首版覆盖百川 200×200 方形逻辑格，山地边界也包含在这 40,000 格内，不向外扩格。基础地貌仍为陆地和水域两类：陆地 Tile 本身使用暖宣纸色纸纹，水域 Tile 使用水墨蓝；陆地表面再叠加 2×2、2×3、3×3 格三种规格、每种三款的淡青绿水墨斑驳素材。斑驳是纯视觉装饰，不增加逻辑地貌类别、不改变通行。水域以噪波驱动动态流动；分布式弯曲河网与多个错落湖盆在地图右侧汇入小海湾。地形与绿染摆放静态保存在同一 TileMap 场景中，不由运行时脚本生成。该地图场景接入主入口。移动、格选路径预览、战争迷雾与正式存读档已接入；山体美术、树木和部分地点表现仍待后续。旧地图实装与草案都不作为新地图底稿。

## 一、设计裁定

本案采用《鬼谷八荒》大地图层面的格子移动、逐格行旅、移动时揭开战争迷雾、点击目的地预览耗时、旅行途中发现地点和事件等体验。地图不按存档随机生成：策划设计地形格与拼块，再按固定坐标拼成同一张地图，所有存档看到相同的百川地理与地点布局。

本项目继续使用既有世界内容：大陆、区域、百川四个一级势力、十二个二级辖域、稳定地点 ID、地点内部场景、NPC 归属和现有事件配置均保留。地点的身份、所属势力、上下级关系和剧情用途不随机改变。

| 保留 | 替换 |
|---|---|
| 大陆 → 区域 → 势力辖域 → 地点四层语义 | 当前节点之间固定道路图作为唯一旅行方式 |
| 四个一级势力、十二个二级辖域及唯一归属链 | 点选地点后直接沿节点路网自动旅行 |
| 稳定地点 ID、地点模板、地点内景与行动 | 只在两个地点锚点间显示抽象旅行 |
| 世界时间只由玩家主动行为推进；跨月时逐月演算 NPC | 无格坐标的节点位置状态 |
| 水墨淡彩、纸本地图的视觉规范 | 固定大底图单独承载全部地貌信息、格网不可交互 |

## 二、固定地图的拼接方式

### 2.1 设计单元

- 地图以正方形逻辑格作为移动、寻路、迷雾和地点落位的最小单元；地图中可重复使用由多个格子组成的地貌拼块。
- 基础逻辑地貌仍只有陆地与水域两类。PlainGround 中的陆地 Tile 本身使用暖宣纸色纸纹，WaterDualGrid 使用水墨蓝水域 Tile，不增加整图垫底层；其上静态摆放多格淡青绿水墨斑驳。绿染素材分为 2×2、2×3、3×3 格三种占地规格，每种三款，节点按占地规格缩放并保持素材生成方向，不旋转或翻转；它们是景物装饰，不是第三种逻辑地貌。水域格由水域材质中的噪波驱动缓慢明暗流动。地貌类型保留在正方形逻辑格；陆水边缘继续使用双网格绘制：显示网格相对逻辑网格偏移半格，每个显示格读取周围四个逻辑格，并按角块遮罩绘制陆地或水域，不改变格坐标、地貌属性或格子主体归属。
- 基础地貌类别与通行由 TileMap 表达；PlainGround 显示宣纸色陆地 Tile，WaterDualGrid 显示水墨蓝水域 Tile；PlainDualGrid 与水域遮罩负责陆水边界过渡。绿染层由静态多格 Sprite2D 组成，素材为 2×2、2×3、3×3 格三种规格、每种三款，淡边可相邻衔接，不影响逻辑格和通行。地图内水系由静态逻辑水格构成：弯曲主河与多条走向各异的支流在百川各处错落分布，并配有分散湖盆，最终汇入右侧小海湾。水格与双网格遮罩保持一致，不留被水包围的孤立陆格。水域遮罩绘制于地表与绿染之上。地图地形由场景内固定 TileMap 与 Sprite2D 数据保存，不使用运行时铺图脚本。双网格需覆盖陆水交界和转角，检查纸纹无格缝断层、绿染不出现矩形边界、水域主体被蓝色水面覆盖、无底层外露、无重复覆盖和硬直缝。动态噪波只作用于水域遮罩内部，不改变水域边界、接边或逻辑地貌。
- 地表 Tile、山体与树木景物、迷雾/标记、格线分层绘制；装饰层不负责通行判定。树木使用同一套透明单树 Sprite 多次静态摆放成林，位置与逻辑格对应，但不改变地貌或通行数据；地点锚格、移动数据与 TileMapLayer 的格位严格对应。
- 角色可通行、阻断与碰撞读取格数据或专用碰撞层，不由底色或草木贴图推断；草点缀默认不阻挡角色。
- 地貌格至少配置固定坐标、地貌类别、通行状态、旅行代价、辖域归属和显示资源。编辑器中看到的格位、运行时点击的格位与角色落脚格必须共用同一坐标体系。
- 拼块边缘标明可衔接的地貌和通行出口。拼接后河流、道路、山脉、林缘与辖域边界须连续，不能出现视觉接缝、断路或无法解释的孤立水域。
- 地图布置由策划固定，不使用运行时随机数、存档种子、程序随机地形、随机辖域或随机地点坐标。新增区域也先设计地貌拼块，再将拼块固定排布到区域地图。
- 地图数据与地貌画面一起编辑；不能只移动底图却漏改碰撞、可行走格、辖域蒙版或地点锚格。

### 2.2 首期百川布局

- 百川为当前唯一完整制作区域；保留现行世界设定中的区域范围、河湖、山口、古道和近海等地理要求，地图画面与方格排布从零重画。
- 百川首期固定为 200 列×200 行，共 40,000 个方形逻辑格；河流、海湾和未来山地边界都必须布置在这 200×200 格内，不增加外围逻辑格。左上角为坐标原点、列向右递增、行向下递增，每格为 256×256 像素，现实尺度固定为 40 公里边长。运行时初始以 1:1 比例将玩家当前位置置于视口中央；新角色默认落在青溪里记忆锚格 (38,166)，紧邻玉虚仙宗以便在世界入口附近识别这一处序章旧地。镜头只显示周边少量地格。滚轮和按钮可从 250% 放大到适配窗口的全域视图（目标下限 2%，若屏幕比例需要则略低于 2% 以完整显示全图），右键拖动浏览。不得把 200×200 全图自动缩小塞满初始视口。
- 四个一级势力各占 3×3 格，大致分居四方但不做镜像对称：玄都天府西北 (29,31)、太微道宫东北 (168,27)、玉虚仙宗西南 (34,166)、无相圣宗东南 (165,164)。十二个二级势力各占 2×2 格，初步围绕所属一级势力疏密不一地落位：玄都辖域为关山府 (18,47)、赤炉堂 (53,55)、赤水城 (52,23)；太微辖域为海川会 (145,16)、长风护道会 (181,45)、春水府 (151,57)；玉虚辖域为青岚观 (48,162)、白石城 (16,141)、东林镇妖会 (56,132)；无相辖域为幽泉教 (144,180)、夜行会 (181,142)、灰骨寺 (147,130)。坐标是各占地区域左上角，后续可按河谷、山脉和道路微调，但不得挤成屏幕总览。
- 首批具体地点仍为青溪里记忆锚点 (38,166)、白石镇 (83,87)、澜浦渡 (122,82)、东林地 (70,113)、伏岚观 (116,129)、灵草谷 (131,101)，各占 1 格并分散于中央行旅区域；青溪里为方便开局定位而靠近西南方玉虚仙宗，其他地点仍服务中央行旅区域；不引入泛化野外占位点。
- 东林地使用稳定地点 ID `east_woods`，以单格占位标记落在林地格 (69,113) 旁的边格 (70,113)，既靠近森林又不覆盖林地装饰；它与东林镇妖会 2×2 势力节点 (56,132) 是两个不同节点。势力节点不得借用 `east_woods` 作为自身的进入地点 ID；在其独立场景/稳定地点数据补齐前仅显示势力标记，进入按钮只属于东林地地点。
- 所有已编排的势力节点/地点锚点直接显示对应素材与名称，不受战争迷雾遮挡；一级、二级势力节点插画按各自 3×3 / 2×2 格足迹居中显示，当前素材名录见 `textures/ui/world/faction_nodes/CURRENT_NODE_ASSETS.md`，尚无专属素材的普通地点使用占位标记。迷雾仍遮挡未知地貌和未发现的动态事件，不负责隐藏已编排节点。
- 多格占地是一个完整地点节点，不把组成格拆成独立地点：占地内任一格均映射到同一稳定 `node_id`，共享同一份角色列表和进入目标。到达占地内任一格时，在节点图示上方显示“进入”按钮；节点人数徽标仍锚定完整占地右上角。
- NPC 人数按当前实际驻留地点统计（死亡与行旅中的 NPC 不计入任何格）；普通单格地点把人数徽标放在该格右上角，多格势力节点放在完整占地范围的右上角，徽标随占地大小适当放大。只显示非零人数，不在地图提前展示人物姓名或身份。
- 打开世界地图时，地图纸底必须位于常驻世界 HUD 下方；角色、时间等常驻 UI 继续可见，不得被不透明地图背景遮挡。
- 河流水网由固定水域逻辑格构成：多条弯曲河流与方向各异的支流、分散湖盆共同铺开百川，水系彼此汇流并接入右侧小海湾。山体边界若加入，必须占用当前 200×200 格内的位置，不扩大地图；山体与树木待后续加入，主体需避开格线和地点锚格。绿染装饰按九款多格素材静态铺设，保持素材生成方向，不旋转或翻转。
- 左侧、上侧等地图边界以高山组成连续、实心但轮廓参差的阻挡山带，参考《鬼谷八荒》冥山作为区域屏障的组织方式；不可通行区域在逻辑格数据中同样连续封闭，只在明确设计的山口或剧情关口开出通道，避免画面有山墙但逻辑可穿越、或画面出现空洞却逻辑阻断。
- 十二个二级辖域仍按四个一级势力各三个固定划分。辖域边界贴合河流、山脊、湖岸、林线、道路与旧渠，不用运行时生成的领地分界。
- 百川首批地点锚格仅落位于已确认的具体地点（青溪里记忆锚点、白石镇、澜浦渡、东林地、伏岚观、灵草谷等），保持固定坐标与唯一归属；势力节点按对应势力规格落位。每个地点的稳定 ID、所属辖域和地点内景均沿用现行策划，不设置泛化“野外入口”或“云岚荒径”一类占位地点。
- 其他大陆和区域不因为地图改成格子就提前出现在首期地图上。

### 2.3 旧版素材处理

此前制作的百川底图拼块和世界地图方格素材均属于废案，不作为新地图的底稿、风格参照或裁切来源。旧文件可留作历史备份，但不得挂入新地图场景、策划预览或后续素材提示词。

新方格地貌素材从零设计；参考《鬼谷八荒》清楚、干净的方格地貌阅读方式，颜色与笔触遵守项目现行《UI视觉规范》。百川固定地图也从头按方格数据编排，不能把旧底图缩放、切片或加格线后当作新地图交付。

长期画布和资源分块方案不覆盖当前首期 200×200 固定 TileMap；地貌格位以本节确认的百川布局为准。

### 2.4 新方格素材规格

- 当前地貌首版直接覆盖 200×200 个逻辑格，逻辑地貌仍为陆地与水域两类；PlainGround 以宣纸色陆地 Tile 铺设陆地，并叠加 9 款跨 2×2、2×3、3×3 格的水墨绿染素材。陆地纸纹、绿染均为视觉层，不改变通行。森林、山体美术、节点和其他地物另行验收。
- 逻辑地块为横竖对齐的正方形，不使用菱形格；地图观看感参考《鬼谷八荒》，通过景物层次和遮挡表现空间，不把地块旋成菱形。地貌纹理与比例保持一致，适合重复铺排。
- 普通陆地 Tile 使用暖宣纸色纸纹，直接作为陆地格本身显示，不在全图下方另铺底图。陆地绿染使用淡灰青绿水墨斑驳 Sprite2D，共 2×2、2×3、3×3 格三种占地规格，每种三款；每个图案跨多个逻辑格，留有柔和透明边缘以便相邻拼接，分布疏密与参考图相符，不在每个小格重复贴满。绿染只作装饰，不改变逻辑地貌或通行。水域 Tile 用统一水墨蓝底色，动态流动由材质内噪波产生，不烘焙密集浪纹。水域逻辑格完整表示水域，水域主体占据对应格子；陆地与水域使用双网格遮罩拼接，遮罩边缘不得露出细缝，噪波不能越过水域遮罩。水系需通过主河、支流和湖盆自然散布在区域各处，避免全部集中于地图中央；右侧保留小海湾。道路等线性内容暂不纳入本轮样张。
- 森林由一张透明底、适合缩放复用的单棵水墨树 Sprite 构成；在单格内及相邻多格上静态重复摆放多棵，组合成疏密有变化的林地。单棵树保持适中尺寸，不让孤立大树盖满一格；树冠允许自然跨越格线，树干根部落在林地格内。山地上的树进一步缩小，避免削弱山体主体。林地属性来自逻辑格，不通过树的数量反推。
- 山地可由多个相邻地块共同组成连续山脉，不要求压在单格内；山体主体应落在单格或多格覆盖区域的中心，避开格线和地块边缘。边界山墙不采用整齐的单格直线排布，而以宽窄不一、前后错落、相邻山形相互遮叠的高山群形成实心轮廓；山脊有起伏，山脚以墨雾和低峰衔接，只有明确的关口保留可通行缺口。山脉主体和支脉使用多格组合并锚定在其占地中心，不把主峰压在格线或拼块接缝上。水域主体同样落在一格或多格区域的中心，以连续水面明确区分水地貌。
- 逻辑地貌、显示地表、树木/山体景物、迷雾/标记与格线分层绘制。PlainGround TileMapLayer 直接显示宣纸色陆地 Tile 并保存陆水逻辑与通行数据；绿染层以多格 Sprite2D 静态摆放，分 2×2、2×3、3×3 格三种规格，每种三款；水域由双网格遮罩衔接并绘制在装饰层上方。各层共用同一格坐标，地点锚格、移动数据与 TileMapLayer 的格位严格对应。
- 格线作为独立显示层，初始显示细黑线，玩家可在游戏内开关；格线不烘焙进地表素材，隐藏时不影响地貌画面。地图方格素材不绘制文字、地名、边框、坐标、UI、人物或水印；标记和信息由独立地图层绘制。
- 两类逻辑地貌首版直接固化在同一张 200×200 静态 TileMap 场景里。验收宣纸色陆地 Tile 与相邻格的接边、九款多格绿染的尺寸与衔接、分布式河网与湖盆、双网格水域边界、水墨蓝水域的噪波流动、交界处无漏底及格线显隐。绿染不能变成逐格重复的小斑点，也不能遮住水域或地形主体。边界地貌不得使逻辑地图超过 200×200。用户确认这一版后，再加入山体、树木和势力地点等内容。既有概念样张与旧地图素材均为废案，不作为新图底稿或审美验收依据；不使用运行时脚本生成地貌或装饰。

## 三、方格地图数据

每个逻辑格至少有以下信息：

| 字段 | 用途 |
|---|---|
| 区域坐标 | 固定的列、行坐标；用于移动、寻路、存档和交互 |
| 地貌类别 | 水系、山地、林地、道路、平原等已定义类别 |
| 通行状态 | 可通行、受限或阻断，并记录适用条件 |
| 移动代价 | 依据地貌/道路影响旅行耗时；数值须由原型校准 |
| 辖域归属 | 属于既有二级辖域、无主地或其他已定义范围 |
| 地点锚点 | 关联一个稳定 node_id；无锚点的普通格不伪造地点 |
| 发现状态 | 未发现、曾发现、当前可见 |
| 动态事件 | 引用现有事件/临时地点配置，不在静态地貌格里存奖励 |

地图由“固定格网 → 地貌/通行 → 辖域 → 地点锚点 → 动态事件状态”组成。道路、河流和关口是格子上的地貌与通行条件，不另做可取代格网的独立节点路网。

## 四、玩家行旅与发现

### 4.1 移动

- 玩家当前位置记录为区域 ID + 格坐标；进入正式地点锚格时，同时记录地点 node_id，供地点内景、角色名单、档案和剧情接口使用。
- WASD 输入逐格移动；鼠标单击已知目的格显示最短耗时路径、预计时间和路径地貌，再次单击同一目的格确认起程并沿路线逐格行进。移动按格插值，视角跟随玩家。进入世界地图及重置视角时以玩家当前位置为视野中心；鼠标滚轮、缩放按钮和中键上下拖动均以视野中心为锚点缩放，不随鼠标指针位置改变；按住右键拖动画布，右键单击将视角重新居中到玩家当前位置且保留当前缩放倍率。
- 到达具有稳定地点 node_id 的锚格后，地图提供显式“进入”入口并沿用既有节点内景；势力/地点无专属节点图时复用共用水墨占位标记，待正式美术完成后只替换标记资源，不另建交互体系。
- 自动行进按相邻格以“总用时最短”为目标寻路。无飞行能力时，水域、山地、森林均可通行但会增加耗时；仅明确标记为阻隔/绝壁的格子、关口规则与势力封锁限制通行。移动途中遇到需要玩家处理的已配置事件时停在当前格，不跳过事件直达终点。
- 道路与河谷古道可降低通行代价或提供明确通道；不再要求玩家只能在固定节点间的折线道路上移动。
- 每次逐格移动都走现有统一时间推进接口。路径预计耗时与实际扣时必须一致；跨月沿用逐月结算 NPC 行动，没有移动时世界不自然流逝。
- 大世界遁速是独立于战斗身法的无单位评分，基础值暂定为 100；前期预定由体魄、敏捷等属性影响，具体权重与公式留待后续设计，功法等后续来源也不在本轮定案。每格边长按 40 公里，遁速100时平地每格内部基准耗时为24游戏小时；当前换算公式为 `2400 ÷ 遁速` 小时/格。无飞行能力时，进入水域、森林、山地格分别乘以 2.0、1.5、2.5 的地形耗时系数；具备飞行能力时忽略这三类地形耗时系数。预览以加权总耗时选择路线，预计时间和逐格实际推进使用同一系数；距离仍按路径格数×40公里计算。当前不额外虚构旅行货币花费。
- 地形耗时首版复用地图中已经摆好的静态地物数据：森林按 ForestPatches 子节点明确标记的 `map_cell` 识别，山地按 MountainRanges 子节点的 `footprint_dimensions` 与实际格位覆盖识别，水域仍读取 TerrainLogic。树木数量和纯装饰绿染不参与反推地形；后续地形编辑应维护明确的逻辑格数据。

### 4.2 战争迷雾与地图知识

- 地图有“未发现、曾发现、当前可见”三态。玩家逐格移动时揭开周围地貌；当前原型视野为以玩家格为中心、半径 5 格的圆形范围（边界按地图裁切），离开后的已发现地块保留地形认知。正式存档保存玩家格坐标、已发现状态和未完成行程；人物、临时事件与动态威胁按各自情报规则更新。
- 未发现区域遮蔽普通地貌与未发现的动态事件；预先编排的势力节点和具名地点则按本案地图识别规则常驻显示名称与节点素材，不隐藏在战争迷雾下。
- 已发现地点使用现有实体地点/野外区域/路线/临时异象的视觉区分。单击已知地点用于选中和查看情报；地点锚格抵达后由“进入”进入地点场景。动态事件与未编排的临时内容仍遵守迷雾发现规则。
- 任务追踪只在玩家已掌握足够情报时提供方向、区域或目标格提示。未知目标可以给线索，不直接透视完整迷雾。
- 本案只定义逐格探索与信息显露。路标、寻灵、堪舆、坐骑、传送符等《鬼谷八荒》专属工具不自动新增；若未来需要，分别由对应物品/旅行专题明确设计。

### 4.3 旅途遭遇

- 逐格移动可触发遭遇、地形障碍和已有临时事件；事件来源必须是项目已经定义的事件、NPC、兽类、资源或地点配置。
- 进入地点、处理事件或采集资源时调用对应系统的既有结算；本案不新设资源 ID、掉落、妖兽、战斗属性、势力规则或贡献来源。
- 事件在地图上未被发现前不显示精确图标。发现后显示目前掌握的名称、风险和剩余期限；结束或过期后从动态地图移除或更新状态。
- 固定地图提供可复访的地貌与路线；动态事件只按其既有系统配置变化，不改变静态地图拼接结果。
- 不要求玩家清空全部迷雾。地图推进围绕当前目标、可行路线、聚集地、探索地和重要线索组织。

## 五、现有系统迁移边界

| 现有系统 | 改革后的职责 |
|---|---|
| WorldNodeData | 继续保存稳定地点内容；固定 map_position 继续表示新地图中的正式地点锚格位置 |
| WorldRouteData、connected_nodes | 从唯一寻路图降为路线名、道路/关口内容、旧存档兼容或地点关系数据 |
| WorldMapRoads.gd | 不再负责玩家移动的唯一路径；道路可作为地图地貌层或通行代价数据 |
| WorldMapViewport.gd | 作为 TileMapLayer 的镜头与输入控制层，负责迷雾、格选择、路径预览与逐格移动；格坐标转换直接基于地图层的格网 |
| NodeWorldMap.cs | 将当前位置接口扩展为区域 ID + 格坐标，并保留当前正式地点 ID 供旧系统查询 |
| NPC 世界管理与月度演算 | 人物归属和行动目标仍用稳定地点 ID；旅行跨月结算不变。NPC 地图行程使用格网寻路，不可穿过阻断地形 |
| 地点场景与行动配置 | 保持原交互，不因地图换成格子而把交易、任务、采集改为地图常驻节点 |
| BaiChuanWorldMap.tscn 与旧底图块 | 仅作历史备份；新地图另建固定格网场景和全新方格地貌素材，不复用旧图的构图或贴图 |

### 存档兼容

- v1 正式存档保存当前格坐标、稳定地点 `node_id`、迷雾和剩余路线；加载后使用同一份固定地图数据恢复。
- 当前没有历史正式进度槽需要迁移；未来若引入旧版存档，旧 `current_node_id` 应映射到其固定锚格，旧旅行起终点则映射为新格网可行路线。
- 旧地图道路进度不能直接视作全部格子已探索；迁移时只恢复能由旧存档明确证明的已知地点/区域。

## 六、视觉与输入

- 沿用《UI视觉规范》的水墨淡彩纸本和横屏安全区。地貌拼块无缝衔接，不能像开发调试棋盘；海陆边界、山脊、河谷和道路仍由连续画面表达。
- 战争迷雾采用低饱和灰墨遮层；当前视野、已发现区域和未探索区须明显区分，但地图标题、任务提示和角色标记不遮挡格子点击。
- 世界地图保留左侧三块常驻信息：左上时间签需有清晰层级且比旧版更易读；左侧人物名单必须随主角当前格/地点刷新，人物行展示头像、姓名及身份/境界，名单为空时明确显示空状态；左下玩家状态签展示境界、生命与体力，并保留点击打开个人面板的行为。名单按内容伸缩，过长时在自身区域滚动，不覆盖时间签与玩家状态签；视觉统一采用低饱和墨色、暖纸色与克制的金色细节。
- 人物名单仅展示当前运行时数据确实归属于当前位置的人物，不得拿上一个地点名单冒充当前名单，也不得伪造普通格 NPC。当前 NPC 若尚无格坐标，只能在普通格显示空状态；是否扩展 NPC 格坐标与自由行旅另行决策。
- 主角棋子锚定当前格中心并采用固定地图尺寸，随地图缩放同比放大或缩小，使棋子相对格子和地貌的比例始终一致；移动表现按格间插值。停留时允许点击当前格或相邻已发现格查看环境/行动。
- 鼠标滚轮必须可直接缩放地图，并与界面缩放按钮及中键上下拖动共用同一缩放范围；所有缩放都以视野中心为锚点，不能以鼠标指针为锚点。进入地图、重置视角及右键单击归位时，以玩家当前位置为视野中心；归位不改变倍率。路线线宽和选中格轮廓保持固定屏幕尺寸；玩家棋子随地图同比缩放；按住右键拖动画布；WASD 负责逐格行走。单击格子预览最短路线、距离与预计时间，再次单击同一目的格确认起程。
- 远景突出大陆/区域轮廓与已知势力印记；中景显示地貌、已知地点和辖域边界；近景显示格位、地形、道路细节和事件。

## 七、数据与实现顺序

1. **格网对齐**：确定首期地图逻辑格尺寸与新地图边界；按现行百川地理要求和稳定地点 ID，把地点锚格重新固定到新格网，并统一编辑器和运行时的坐标映射。旧地图画面不参与新画布裁切或坐标推导。
2. **双网格地形接边**：逻辑 TileMapLayer 手工标定每格陆地或水域及通行数据，PlainGround 直接显示宣纸色陆地 Tile；显示网格偏移半格，以四个相邻逻辑格的地貌组合绘制陆水遮罩。绿染用多格静态贴花跨 2×2、2×3、3×3 格放置。检查直边、转角、窄河道、地块拼接和陆水交汇，并核对显示遮罩与逻辑格一致。
3. **格网渲染与迷雾**：用多层 TileMapLayer 分离地表、山体/树木景物和迷雾/标记，再接入未发现/曾发现/当前可见状态和现有缩放拖拽；森林通过同一单树素材多次静态摆放，不用随机脚本排布；旧底图不作为渲染底层。
4. **移动与时间**：接入逐格移动、路径预览、路径确认、移动中断、旅行耗时和跨月结算；让行程预览与结算共用同一求值函数。
5. **内容互动**：地点锚格抵达后复用现有地点场景；事件只读取现有配置，不把事件目录与静态地点混为一谈。
6. **NPC 与存档**：已接入统一正式存档，保存主角时间/完整角色、格坐标、路线进度、迷雾、随机 NPC 快照与月结算游标；NPC 继续按当前月度规则结算，显示旅行时使用格网寻路。
7. **分区扩展**：先打磨百川首期，再按相同拼块规则设计后续区域；不为尚未开放的大陆预制或展示完整地图。

## 八、首期验收

- 所有新旧存档使用相同的百川地貌拼接和地点布局，不存在地图种子或每局随机换位。
- 格子、拼块、辖域、地点锚格和画面坐标互相对齐；同一地貌拼块在不同连接处没有断河、断路、地形穿插或错误辖属。
- 双网格显示格始终与逻辑格错开半格；陆地和水域两种地貌均正确显示。双网格拼接不改变逻辑地貌、格坐标、可通行状态与寻路代价；水域主体清晰覆盖水格，陆水交界自然，无白缝、漏底或明显接缝。
- 陆地格本身显示暖宣纸色纸纹，使用 PlainGround 的陆地 Tile，不在地图底部额外铺整图背景；相邻陆地格接边自然。淡灰青绿斑驳由 2×2、2×3、3×3 格共九款静态素材组合，尺度跨格、透明柔边可衔接，不出现单格重复或硬方框。绿染不改变通行，也不覆盖水域。水域保持统一水墨蓝基调，由噪波产生轻缓动态且不越过水域遮罩；河网与多个湖盆自然铺展、彼此汇流并连接右侧小海湾，水中不留孤立陆格，显示遮罩与逻辑地形一致；地图边界仍严格处于 200×200 逻辑格内。
- 森林由多棵同款单树素材静态成组摆放，尺度和疏密适合格子地图；树冠不妨碍识别地表类型，山上树木小于山体主体。
- 地点 ID、正式名称、所属势力、辖域层级与地点内景没有因地图改革而改变；一个地点只绑定一个有效锚格。
- 不可通行地形和封锁规则会阻止寻路；玩家不会走穿海域、山体或未开放关口。
- 地图移动按格推进，迷雾随探索更新；未发现地点和事件不泄漏坐标。
- 地图初次显示及重置视角时，玩家棋子位于视野中心；地图区域内滚动鼠标滚轮、点击缩放按钮或中键上下拖动均以视野中心为锚点稳定缩放，不受鼠标指针位置影响，并遵守缩放上下限。棋子在各倍率下始终锚定于当前格，且与地图、格子的尺寸按同一倍率同比缩放。
- 点击目的格时显示的路径与耗时，和确认行程后的实际格序及扣时相同；事件中断不会把主角传送到原终点。
- 世界时间仍只由玩家主动行动推进；跨月时旧 NPC 规则按每个月逐月结算。
- 地点锚格抵达后仍先进入对应的全屏地点内景；地图改革没有把地点功能挪回世界地图。
- 所有地图数值，包括逻辑格密度、视野范围和地貌旅行代价，须在原型中校准后再冻结，不以本案文字臆造平衡数字。

## 九、与《鬼谷八荒》的借鉴范围

借鉴的是大地图层面的玩法结构：方格移动、点击目的地预览行程、移动消耗游戏时间、行走揭开普通迷雾、旅行中发现地点和事件。《鬼谷八荒》攻略所述的双击确认移动和 WASD 格间移动可作为交互参考；其地点随机坐标不采用，路标、寻灵符、堪舆、坐骑等专属系统也不视为本案默认新增内容。[游民星空：大地图界面](https://www.gamersky.com/handbook/202101/1359482_5.shtml)、[游民星空：地图活动](https://www.gamersky.com/handbook/202102/1359792_9.shtml)、[Tale of Immortal Map Guide](https://tale-of-immortal.com/guides/map-exploration)
