# 炼器、炼丹游戏内接入（2026-10-25，当前）

> **2026-10-26入口修订，当前覆盖**：用户明确百工用于查阅丹方和过往记录，实际炼丹／炼器须在玉虚仙宗等实际地点进行。本轮将正式入口移至玉虚仙宗·天工峰的丹房／器作；百工撤掉炼制入口。暂只保证现有炼制可在游戏内使用，后续设施拓展另行设计。

用户要求查看项目并将炼器、炼丹接入游戏内，随后明确选择“按当前参数接入，后续再平衡”。本篇覆盖此前炼器文档中“百工仅使用独立试炼库存、不消费人物资源、不推进时间、不生成正式物品”的接入边界；不修改成器公式、装备收益或战斗技能。

## 入口与资源

- 人物百工→法宝／丹药：只查阅炼器记录、持有器物炼制存录、内置样方、我的丹方与炼丹记录。查看不扣资源，不提供炼制或瞬移按钮。
- 玉虚仙宗→天工峰→器作·炼器：读取当前人物行囊、炼器造诣、总灵识与其他真实占用。每岗每材1—8份，不设全炉32份上限；参考投料只填写材料，不发材料、不修改人物造诣。
- 玉虚仙宗→天工峰→丹房·炼丹：沿用真实人物炼丹与领取流程，数量由配伍推导。现阶段复用天工峰既有宗门成员身份限制，无须接取公事；后端同时核对当前峰与峰内页面可见性，不能在别处调用入口。暂不增加租炉费用、设施等级、额外配料、公库供给或新材料。
- 首页独立炼器、炼丹试演保持隔离，不把旧会话产物补发给正式人物。

## 本轮确认的炼器事务

1. 工时为投入总份数除以3向上取整，单位时辰；精力为工时×2。一时辰换算两游戏小时。
2. 非法配置、人物不可行动、材料不足、灵识不足、精力不足均拒绝，零扣料、零扣精力、不推进时间。
3. 合法开炼无论成败均消耗整炉材料及精力，并同步推进历法。不增加失败概率或人为制造失败结果；当前模型的合法配置通常直接成器，未来失败模板需另行定义。
4. 成功成器直接收入人物行囊；预检在副本数组中扣料，允许使用该炉腾出的格位。扣料后仍无空位则拒绝开炼，不吞料、不丢成器。不使用仅支持普通物品的丹药领取队列承载器物实例。
5. 通过全部预检后统一发布材料、精力和器物变化；通知期间防重入。成器使用新唯一实例ID及完整参数／材料快照，沿既有器物正式存档字段保存，不自动装备。
6. 工坊器物册读取人物当前持有的炼成器物，重新进入仍可查看。当前页面记录本次会话的炼制记录；已入包器物的来源与用度保存在各自快照中。2026-10-26起，正式炼器与炼丹各将投入、结果和用度追加到人物持久记录，百工可跨地点查阅并随正式角色数据保存；旧档默认空记录，不从历史库存推造过去炉次。旧器物仍可查阅自带来源快照。

正式入口用当前资源定义重建计算器，不接受调用方伪造的材料档案或造诣。材料、灵识、精力在开炼时重检。开炼为同步一次完成，不登记持续灵识预约，不清空其他事务占用。

## 返回与炼丹领取

全局返回优先返回当前工艺页面，再回原地点。炼器先关详情／选材弹层，再退器作回天工峰；携器对练打开时不从底层关闭工坊。炼丹开炼、演出、鉴看与待领取期间阻止底层返回隐藏页面，完成领取后可退回天工峰。炼丹演出异常时尽可能直接打开已结算成果的通用领取页，避免继续使用“成品已在行囊”的过时提示。百工资料页独立关闭，不作为设施页面的宿主。

炼丹继续沿用[完整主案](炼丹完整结算与正式接入_20261023.md)的当前运行闭环：回春、通脉、静心三种丹，开炼扣投料／精力／时间，通用领取页确认后才入包。本轮没有扩充战斗服丹或战斗卡。
