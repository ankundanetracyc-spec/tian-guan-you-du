# 炼器、炼丹游戏内接入（2026-10-25，当前）

用户要求查看项目并将炼器、炼丹接入游戏内，随后明确选择“按当前参数接入，后续再平衡”。本篇覆盖此前炼器文档中“百工仅使用独立试炼库存、不消费人物资源、不推进时间、不生成正式物品”的接入边界；不修改成器公式、装备收益或战斗技能。

## 入口与资源

- 人物百工→法宝→进入炼器工坊：读取当前人物行囊、炼器造诣、总灵识与其他真实占用。每岗每材1—8份，不设全炉32份上限；参考投料只填写材料，不发材料、不修改人物造诣。
- 人物百工→丹药→进入炼丹房：沿用现有真实人物炼丹入口。数量由配伍推导，撤掉百工说明中已经失效的“选择本炉颗数”。
- 首页独立炼器、炼丹试演保持隔离，不把旧会话产物补发给正式人物。

## 本轮确认的炼器事务

1. 工时为投入总份数除以3向上取整，单位时辰；精力为工时×2。一时辰换算两游戏小时。
2. 非法配置、人物不可行动、材料不足、灵识不足、精力不足均拒绝，零扣料、零扣精力、不推进时间。
3. 合法开炼无论成败均消耗整炉材料及精力，并同步推进历法。不增加失败概率或人为制造失败结果；当前模型的合法配置通常直接成器，未来失败模板需另行定义。
4. 成功成器直接收入人物行囊；预检在副本数组中扣料，允许使用该炉腾出的格位。扣料后仍无空位则拒绝开炼，不吞料、不丢成器。不使用仅支持普通物品的丹药领取队列承载器物实例。
5. 通过全部预检后统一发布材料、精力和器物变化；通知期间防重入。成器使用新唯一实例ID及完整参数／材料快照，沿既有器物正式存档字段保存，不自动装备。
6. 工坊器物册读取人物当前持有的炼成器物，重新进入仍可查看。当前页面记录本次会话的炼制记录；已入包器物的来源与用度保存在各自快照中。

正式入口用当前资源定义重建计算器，不接受调用方伪造的材料档案或造诣。材料、灵识、精力在开炼时重检。开炼为同步一次完成，不登记持续灵识预约，不清空其他事务占用。

## 返回与炼丹领取

全局返回优先返回当前工艺页面，再关闭百工。炼器先关详情／选材弹层，再退工坊；携器对练打开时不从底层关闭工坊。炼丹开炼、演出、鉴看与待领取期间阻止底层返回隐藏页面，完成领取后可退回百工。炼丹演出异常时尽可能直接打开已结算成果的通用领取页，避免继续使用“成品已在行囊”的过时提示。

炼丹继续沿用[完整主案](炼丹完整结算与正式接入_20261023.md)的当前运行闭环：回春、通脉、静心三种丹，开炼扣投料／精力／时间，通用领取页确认后才入包。本轮没有扩充战斗服丹或战斗卡。
