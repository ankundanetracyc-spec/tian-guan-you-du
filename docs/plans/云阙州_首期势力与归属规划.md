## 一、阶段定位

- 主角离开青溪里时通常已达**云息三层左右**，已具备独立修行、基础战斗和远行能力。
- 青溪里只用于证明主角是被天道接引的界外之人；镇长地图与无名山是第一次异常证据。它不指向兽患源头、地气外泄或阶段二的强制调查任务，真相在后续由玩家主动发现。
- 序章后没有强制章节、招募提示或按日期自动推进的主线。玩家的长期目标是延续寿元、不断突破境界；寿元本身构成压力，不另设“千年问道”倒计时任务。
- 云阙州为第一块完整制作的州域。首期地图只显示云阙州；其余八州不显示为地图区域、节点或势力，待云阙州循环稳定后逐州展开。

## 二、玩家推动原则

世界提供地点、人物、传闻、交易、委托、试炼与异象，但不把“加入某势力”显示成阶段任务。玩家自行决定是否拜山、递帖、接近某家族、接受委托或继续作为散修。

境界、灵根、声望、物资和已知地点只决定玩家**能否尝试**某件事；真正开始一个事件、加入一个势力或进入一条修行路线，始终需要玩家主动选择。

每次行动的收益至少属于以下之一：修为与突破材料、功法与构筑、灵石与物资、地点知识、势力声望。玩家无需清空全部内容，只须以自己的方式获得下一次突破所需条件。

## 三、势力声望与归属

### 3.1 七阶势力声望

势力对玩家的态度只用一项**声望**表达，不另设重复的“关系值”。数值范围与各阶阈值留待实现数据确定，展示与效果遵守以下顺序。

| 声望状态 | 势力态度与权限 |
|---|---|
| 仇视 | 通缉、追杀、拒绝往来；可能主动阻碍玩家。 |
| 敌视 | 拒绝服务和委托，可能驱逐玩家。 |
| 不满 | 仅保留有限往来；价格、情报与事务均受限。 |
| 冷淡 | 默认状态；可正常交易、接普通委托、打听基础消息。 |
| 友善 | 折扣、额外消息、特殊委托与引荐。 |
| 亲近 | 可接触核心人物、内部事务与更深层机会。 |
| 尊敬 | 可申请或维持正式弟子、客卿、供奉、骨干等身份。 |

### 3.2 正式身份、兼任与退出

- 声望代表势力态度；**正式身份**代表弟子、客卿、供奉等组织身份。两者分开保存。
- 玩家可同时拥有多个正式身份。是否允许兼任、允许兼任哪些身份，由每个势力的宗旨与门规单独规定；不再使用全局“只能有一个主要归属”的限制。
- 主动退出某势力时，该势力声望清零为冷淡，已经获得的个人物品与已学功法保留，势力场所、折扣、内部委托和身份权限关闭。
- 若玩家违反排他规定、泄露禁忌、伤害成员或毁约，势力须先驱逐玩家，再按该势力规则将声望降至不满、敌视或仇视。不得把所有违约都机械地处理为同一结果。
- 普通交易、临时雇佣、购买情报和一次性结伴不改变正式身份。

## 四、灵根与入门层级（早期草案，玉虚规则已迁移）

本节只保留旧稿曾经讨论过的通用方向，不作为任何现行宗门的录取规则。早期“灵根仅提供常见起点”“变异灵根可破格”“四、五灵根可被大宗拒收”等表述，均不得用于实现玉虚仙宗。

玉虚仙宗的现行入门身份与晋升依据，以[百川区域仙盟大势力与天人议盟规划](百川区域仙盟大势力与天人议盟规划.md)“玉虚仙宗内景（首期）”中的“入门起始身份与晋升”为准：无灵根不收；四、五灵根为杂役；三灵根为外门；双灵根为内门；天灵根为真传。入门后晋升只依据境界与宗门贡献，具体门槛待后续细化。

其他宗门的灵根标准尚未统一定义，不得从本迁移资料的旧表推导通用录取机制。

## 五、云阙州首批地点与势力

### 5.1 白石镇

白石镇是云阙州东南近域的普通聚集地与首个长期枢纽，提供交易、住宿、见闻、散修往来与通往周边的道路、水路。它不是玩家必须效忠的组织，也不把势力招募直接摆在镇口。

### 5.2 玉虚仙宗

- **定位与实力：**云阙州大宗，传承深厚，天人级掌门与多位高阶修士坐镇；山门与核心传承对云息期玩家是远处的高峰。
- **宗旨：**维护正统传法与宗门秩序，严禁魔修；门规、师承和贡献高于个人任性。
- **首期接触：**通过云阙州见闻、外门人物、外围事务与主动拜山逐步接触，不在白石镇提供自动招募。
- **兼任：**正式弟子不得加入其他宗门；可在不冲突的前提下担任家族客卿或加入中立组织。
- **灵根：**旧稿设想已废止。玉虚仙宗现行起始身份与晋升规则见百川区域仙盟大势力与天人议盟规划；不得沿用变异灵根破格、试炼改变起始身份或低资质拒收的旧说法。

### 5.3 伏岚观

- **定位与实力：**云阙州东南山间小宗门，玄基修士坐镇，规模有限。
- **宗旨：**清修、护山、镇邪；不以扩张地盘为务，也不轻易卷入地方争斗。
- **内容：**基础道法、符箓、静修处、山间委托与地方异闻。它隐藏在旅行、交谈和地点发现中，不作明示招募点。
- **兼任：**正式弟子不可再入其他宗门；可兼任不冲突的家族客卿，也可参与碑会或行猎会的非正式事务。
- **灵根：**较玉虚仙宗宽松，重视道心与术法适性；三灵根可正常入门，部分四、五灵根可从杂役或记名弟子开始。

### 5.4 澜浦陆氏

- **定位与实力：**云阙州东南的县豪家族，玄基修士坐镇，经营渡口、灵鱼与水路商货。
- **宗旨：**守水路、护族人；看重实际行动，不尚空泛名声。
- **内容：**客卿、护送、采买渠道、临时住处、水路消息与地方委托。
- **兼任：**客卿可兼任非敌对势力；不得同时成为竞争家族的客卿或损害陆氏水路利益。
- **灵根：**更看当前战力、可信度与解决问题的能力；资质影响培养资源，不是客卿的唯一门槛。

### 5.5 东林行猎会

- **定位与实力：**散修、猎户与低阶修士构成的松散互助网络，不是宗门、家族或正式归属。
- **宗旨：**以猎妖、采集、互保换取生计；按约分配，不替成员担保全部风险。
- **内容：**组队探索、悬赏、兽材交易、野外消息与低阶合作。
- **兼任：**无排他规则，不授予正式身份；适合散修早期作为生存网络。

### 5.6 天机阁分支

- **天机阁分支：**以书坊、茶楼或拍卖行面目出现，提供情报、功法与交易。首期作为信息渠道，不设常规入会入口。

白鹿书院与青云观保留为其他州的顶尖势力，不在云阙州地图、人物或首批归属中出现。

## 六、首期不做

- 不制作九州全图、其他州的完整势力网或十余个可加入宗门。
- 不以倒计时、强制招募任务或自动弹窗推动玩家选择归属。
- 不恢复家族经营、民力调度、辖地项目或多人派遣。
- 不把青溪里、兽患或无名山异常改写为云阙州的强制调查线。
