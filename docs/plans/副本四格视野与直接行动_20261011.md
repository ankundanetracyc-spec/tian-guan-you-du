# 副本四格视野与直接行动

状态：现行用户修订，2026-10-11。覆盖旧案“付费探查后才可采集、调查或应战”的前置，不改已有行动费用、产物、储量与战败规则。

## 行动与视野

- 取消探查按钮及结算。抵达资源、异状或妖兽地格即可选择采集、调查、辨迹或应战；不自动扣费、采集或发动妖兽战斗。
- 当前视野内显示简洁的“可采集／异状／兽踪”提示，悬停可看现场信息；实际行动须抵达。
- 采集与调查仍推进时间和 NPC 行程；途中遇袭中断，未完成行动不发产物、不扣储量。NPC 攻击继续按既有性格、关系、声望与立场规则判定。
- 四格范围沿用大世界既有圆形半径算法，半径改为 4 个逻辑格，不随缩放改变。若用户后续选择横纵距离，只替换距离判定。
- 未发现地格隐藏地形、连线、名称与棋子；曾发现但当前不可见的地格保留暗色地形记忆。
- NPC 棋子、现场行动提示、悬停详情与札记实时信息只在当前视野内显示；视野外人物仍正常演算，不因隐藏停止行动。
- 路线仅使用已经发现的节点和通路，任务指引不直接揭开迷雾；未知目标先给文字线索。
- `east_woods_dungeon_state.discovered` 保存已发现地格。旧存档从实际到访、旧探查记录及当前位置视野迁移，不全图解锁、不重置储量、不补扣探查费。
- 出口、Esc 和镜头仍遵守《副本入口与镜头交互修复_20261011》；必须走出口离场。

## 人口核查与后续确认

当前每个宗门／城池只随机生成 2～4 名普通人口，东林地属于野外节点，为 0～2 名；普通人物开局全部驻留地点，月度主要行动仅有 12% 概率选择旅行。普通野外格只统计真实行旅者，没有临时假人，因此常无人，东林地也可能恰好生成为零人。

上述是扩充前的核查。后续用户已确认固定测试规模、约20%新增普通人物在途及旧档一次补缺，已实施，见[百川人口规模与过月性能](百川人口规模与过月性能_20261011.md)。月度主行动概率未改。
