# 器物单槽变换与成套同化方向

> 范围确认：同化当前不做，等器物基础构建完成后再讨论。下文同化章节仅保留方向，不纳入当前交付或前置依赖；成套剑器本身可按一件器物设计，无需先做同化。

2026-10-23，用户最新明确的交互与器物模型。单槽变换、成套视作一器为当前方向；同化属于后续构思，尚未定义材料消耗、兼容要求、具体公式或实施。

## 一、一件可御用器物，一个变换入口

装备器物后取得该器物御用技能的装配资格；玩家选择装进现有十个技能位置之一，不自动挤掉已有技能。只有玩家要将器物御用在场，才需要装配这个入口，不要求仅提供常驻/化法/器蕴的所有器物都占技能位。

| 本场状态 | 同一个技能位置显示 | 本次执行 |
| --- | --- | --- |
| 未召出 | 御用该器物的技能 | 召出器体，成功后建立在场状态 |
| 已在场 | 该器物在场时可释放的技能 | 支付该次费用与临时灵识需求，发挥在场效果 |
| 崩解/离场 | 对应失效或未在场提示 | 是否可再次召出遵守运行态规则，不由按钮变换自动放开 |

召出后不用额外装一张御使技能，也不新增第二个位置。变换改变显示与执行分支，不复制技能、不移动其他位置、不重置限次/冷却。槽位始终引用同一器物实例，运行态决定当前展示。若器物未来具有多个在场技能，其共槽选择方式需另行设计；首个闭环先按一个召出入口对应一个在场技能设计，不默认为多技能全部免费塞进一个位置。

无需在场的直施型器物技能、化法和常驻收益按此前独立表达规则处理；本次单槽变换不强迫所有法器先召出。

## 二、与行动队列及灵识对接

同一个技能可按现有规则多次排队：第一个行动召出，后续行动御使。规划阶段根据前序行动预演分支、目标与费用，队列移动后重算；确认后锁定意图。实际召出失败，后续已锁定御使不能自动改成召唤，不扣尚未成功提交的费用、不补行动。

召出成功持续占D；在场技能主动施放临时占T；结束只释放T，器体继续占D。召出分支若另有T，按完整模板明确；化法不新增T。技能槽当前展示的分支与队列项已锁定意图可能不同，应在队列项上明确显示“召出/在场施法”，不能只看变换后的槽位名称猜执行。

战斗结束重建未在场状态，不把按钮变换后的运行时副本保存成新的永久技能。器物卸下/失去后清理来源槽位，其他位置不前移；所有变化仍需正式入包和装配接口支持，目前未实施。

## 三、成套剑器就是一个器

一件器物可以表现为一柄剑，也可以是一套小剑。成套不是先装备六个独立实例再临时归组；无需为实现此表现先开放多器联合指挥。

- 行囊保存一个实例，装备按这一器计算；具体装备总量仍未定。
- 一套只提供其实际形成的一份角色收益、化法与器蕴贡献，不按显示剑数复制。
- 御用入口占一个技能位置，召出后该位置变为整套在场技能。
- 多柄各自出击可以形成一项技能的多段，仍按正常行动与临时灵识规则结算。
- 整套御用通常有很高在场灵识需求，数量和协同复杂度参与公共控制成本；不能用一个实例逃避负担。
- 共享器体或逐柄器体仍属于器体运行模型选择；“视作一个器物”不自动等于必须共享一条生命，也不自动确认逐柄受击。

独立多剑仍可作为后续另一类玩法，但当前成套剑器的成立不依赖独立多剑联合模板。身材主要形成器体生命等本体，性材主要形成角色收益，预算守恒与材料决定结果的方向保持不变。

## 四、后续同化为成套的方向

用户提出后续可让相同的器合并同化，作为一整套使用。建议按一种制作/改造过程评审，完成后成为一个成套器物，而不是继续由多件完整装备暗中重复提供收益。

推荐评审原则：

1. 兼容性按真实原型/结构与效果规则判断，不以玩家改成同名就满足“相同”。“相同”需要同到哪一层仍待定。
2. 同化形成的分体数量、器体与锋锐、常驻/化法/技能、器蕴贡献、D/T都重新按公共过程计算，不能简单把多件常驻、器蕴完整相加后再享受一器一槽。
3. 保留投入来源记录、规则版本及新结果的稳定身份，防止同一原件同时留在行囊和成套结果里重复使用。原件是否消耗、保留或可拆回需另定，未获授权不实施消耗。
4. 同化可以换取集中管理和协同能力，但通常增加御用灵识要求；不保证所有单件能力原样无损保留。
5. 原件技能槽、化法绑定及预设引用如何迁移，必须在过程确认前展示；不能让旧引用继续调用已不存在的独立器物。

同化不在当前阶段实施，不提前新增正式配方、材料门槛、锻造费用、拆分或修复规则。先做一件器物的召出→同槽变换→在场施法→灵识释放闭环，再扩展成套生成与同化。
