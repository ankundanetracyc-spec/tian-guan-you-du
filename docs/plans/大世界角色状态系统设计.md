# 大世界角色状态系统设计

> 状态：持久记录、到期处理、首批“重伤”规则与人物界面展示已接入；更高境界的恢复时长待定。

## 一、系统边界

- 本系统记录角色在大世界、地点与副本活动期间持续存在的个人状态，与即时战斗中的临时 Buff 分开管理。
- 大世界精力、生命、境界、天气与地点动态状态仍由各自系统负责；状态记录本身不替代这些资源或环境数据。
- 首期只接入主角的状态记录。百川 NPC 的持续状态及月度演算效果另行规划，不由本系统自动推演。
- 首批已配置“重伤”。仅符合下文正式战斗败北条件时添加；演法、撤离、性命之争与 NPC 间战斗不触发。

## 二、状态记录

每个状态实例由以下字段标识和展示：

| 字段 | 用途 |
| --- | --- |
| `instance_id` | 当前角色存档内的实例标识，用于精确移除 |
| `status_id` | 状态种类的稳定 ID |
| `display_name`、`description` | 人物档案与悬停提示使用的名称和说明 |
| `stack_count` | 该实例当前明确记录的层数 |
| `source_id`、`source_name` | 追溯施加来源 |
| `applied_at_total_game_hours` | 施加时的累计游戏时辰 |
| `expires_at_total_game_hours` | 绝对到期时辰；`-1` 表示无时限，其他值按游戏时辰到期 |
| `recovery_hours_required`、`recovery_hours_progress` | 需要累计的真实休息行动时数及已完成时数；不按普通历时自动恢复 |
| `recovery_realm` | 施加时的境界快照，便于显示与核对恢复时长 |

状态记录随完整 `HumanData` 一同存档。状态是否叠加、刷新或移除，必须由具体状态定义；“重伤”按本案规定不叠层，再次触发时以新伤为准并重置恢复进度。

## 三、运行时接口

- 添加时校验稳定 ID、显示名称和正层数，并为没有实例 ID 的记录生成唯一 ID。
- 通过实例 ID 精确移除状态；具体净化、休养或事件处理调用该接口，不设全清规则。休息恢复状态按明确的休息行动时数累计，完成后移除。
- 每次游戏时辰变化时移除已到期记录；载入存档后先按当前时辰清理过期记录，再开放交互。
- 状态效果由具体状态规则执行，不从展示字段推导。

## 四、人物界面

- 人物概览在三列资料下方显示独立“状态”纸面区域，逐项列出持久状态及其效果、恢复进度／解除条件与来源；活动中的云息闭关瓶颈作为修炼数据派生展示，列出阶段与吐纳效率，不复制成持久状态记录。内容增加时在状态区内滚动；整体不足以容纳时由页面滚动，不压缩正文。
- 左下常驻人物纸签在生命与精力行下按需显示云息瓶颈与大世界状态摘要，二者分行，避免互相挤掉；空状态不留空行。完整内容仍可在人物概览查看，悬停提示保留摘要。
- 无状态时概览显示“暂无特殊状态”。不以颜色暗示善恶或严重程度。心境仍由既有心境圆盘呈现，不在状态列表重复。

## 五、首批状态：重伤（2026-10-12 用户确认）

### 触发范围

- 主角参加正式战斗并被击倒、战斗结果为败北时添加。
- 演法／训练、成功撤离、NPC 间战斗及明确标记为性命之争的遭遇不触发。
- 只有战斗结果快照确认主角本人生命归零才算败北；双方同时倒下仍按主角被击倒处理。

### 效果与恢复

- “重伤”不叠层；再次符合触发条件时重置恢复进度并记录新的缘起。
- 状态持续期间，主角参加正式战斗时的生命上限暂降 **15%**。只改战斗快照；回到大世界后恢复原生命上限，战斗中实际损失的生命仍保留。
- 恢复只计入玩家明确选择的休息行动时数，包括普通休息及剧情中明确选择的休息至次日；行旅、修炼、闭关和其他时间推进不计入。
- 完成所需休息时数后自动移除。状态进度随角色存档保存。

| 受伤时的大境界 | 恢复要求 |
| --- | ---: |
| 云息（各层） | 120 小时（5 日） |
| 玄基 | 360 小时（15 日，前境界的 3 倍） |
| 金丹 | 1,800 小时（75 日，玄基的 5 倍） |

时长以受伤时境界为准。金丹以上尚未定数值，不外推倍率；运行时遇到未配置境界时不擅自生成恢复时长，并记录提示供后续补案。

## 六、首期实现状态与待定内容

首期代码已接入主角状态记录、存档字段、增删接口、按累计游戏时辰到期清理、重伤休养累计、正式战斗生命上限修正、人物概览状态区及常驻纸签摘要。云息闭关瓶颈由修炼状态即时派生到常驻纸签和人物概览，不进入大世界状态记录。即时战斗 Buff、外伤／内伤、天气与 NPC 持续状态没有因此改写。

其他状态仍需逐项确定名称与分类、触发来源、层数及叠加方式、属性／行动／资源影响、持续与移除条件、战斗携带规则及 NPC 适用范围。金丹以上重伤时长也待确认；未定内容不由框架代填。
