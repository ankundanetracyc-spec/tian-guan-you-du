# 副本种子地图与扩展地形实施

状态：2026-10-11 用户确认“加上新地形，地格可以用种子随机生成”。本记录覆盖东林地外围此前只有固定模板的描述，不改变现行行动、任务、遁速、出口或资源余量规则。

## 已接入

- 竹林、湿地、洞窟地面各两款进入共用地形库，仍使用统一圆角正方形和中央棋子站位。草／林／岩／纯水各四款继续使用。选款由副本种子与稳定格ID决定，不逐帧随机，不把同图翻转冒充新素材。
- 洞窟地面在东林地作为背阴岩隙的地面表现，不表示开启洞穴层；竹林仍属林地环境。泉眼作为湿地上的缩小透明叠层，只是地点特征，不额外恢复体力、产生新资源或增加倍率。
- 新旅程创建时生成东林地种子，外围共128格，范围16×10，保留缺口，只连正交相邻格。原21格ID、坐标与边不变；外围从连通锚点逐步生长，保证所有格可回林缘出口。竹林、湿地、阴岩地面按成片区域分布，不给每格独立抽取杂乱地形。
- 保留8个已配置外围行动点：`outer_03_06`、`outer_06_04`、`outer_09_07`、`outer_12_03`、`outer_05_06`、`outer_12_06`、`outer_13_06`、`outer_08_08`。苦苔根锚点保持林地／竹林，月露苔锚点保持湿地／阴岩地面。任务费用、采集数量、凶狼与事件内容均不重配。

## 存档与兼容

`scene_progress.east_woods_dungeon_state.layout` 保存地图版本、字符串种子、完整地格快照与无向边快照；地格含ID、坐标、名称、描述、地形及特征。字符串种子避免JSON数字精度丢失；保存完整图而不是只存种子，避免以后修改算法改变已探索地图。

新旅程即保存初始布局，即使尚未进东林地，也不因退出青溪里重抽。重进恢复原图与原资源／事件进度；旧档缺少layout时使用此前固定128格并补存快照，不根据原进度猜测新地图。NPC恢复前先恢复图，NPC与玩家继续读取同一正交路线和遁速时间轴。

载入先校验128格、唯一ID／坐标、边有效、原任务与行动锚点、原巡查边、全图连通。无效或未知地图版本报错，不静默随机替代有效存档。正式槽损坏提示沿用现有加载机制，本轮未新增专门地图修复界面。

当前是每段旅程的一份东林地图，不是已经完成多实例系统。后续幽谷等副本应按独立实例保存自己的layout及actions，不能共用东林地字典或全局当前图冒充多实例；本轮不启用未确认的90／180日等出现参数、资源恢复或空白深层。
