## 存档与兼容

`scene_progress.east_woods_dungeon_state.layout` 保存地图版本、字符串种子、完整地格快照与无向边快照；地格含ID、坐标、名称、描述、地形及特征。字符串种子避免JSON数字精度丢失；保存完整图而不是只存种子，避免以后修改算法改变已探索地图。

布局 v2 的地格快照还保存资源节点 ID 与“植物／矿产”类别；副本状态持久保存各点储量和恢复游标。v1 布局载入时迁移补入当前资源节点定义，不重抽地图。该迁移和状态结构已有实现，但正式跨进程存档读回尚待实测。

新旅程即保存初始布局，即使尚未进东林地，也不因退出青溪里重抽。重进恢复原图与原资源／事件进度；旧档缺少layout时使用此前固定128格并补存快照，不根据原进度猜测新地图。NPC恢复前先恢复图，NPC与玩家继续读取同一正交路线和遁速时间轴。

载入先校验128格、唯一ID／坐标、边有效、原任务与行动锚点、原巡查边、全图连通。无效或未知地图版本报错，不静默随机替代有效存档。正式槽损坏提示沿用现有加载机制，本轮未新增专门地图修复界面。

当前是每段旅程的一份东林地图，不是已经完成多实例系统。后续幽谷等副本应按独立实例保存自己的layout及actions，不能共用东林地字典或全局当前图冒充多实例。此处“不启用资源恢复”是 2026-10-11 地形生成快照；常驻资源恢复已按本页 2026-10-14 更新接入。未确认的动态机遇出现参数和空白深层仍未启用。
