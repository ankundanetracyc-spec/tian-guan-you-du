# 战斗构筑与三资源系统

> 版本：3.3
> 日期：2026-10-26
> 状态：已确认设计，待按本文分阶段实现。

> 即时战斗迁移说明：战斗场景现行采用《即时队列战斗系统设计》的固定技能槽与独立队列，不再使用战斗手牌、抽牌堆或弃牌堆；本案中的卡牌费用与效果字段继续作为技能数据来源。云息凝核采用八回合时机小游戏；玄基入境保留独立牌局循环，详见各自专题。

本文规定当前局内三资源制的唯一口径。

## 目标

战斗采用小数字、可连续出牌的构筑节奏。玩家应能一眼读出一张牌是普通动作、当回合法术，还是需要长期御使的法宝；不再面对几十点体力和四条同时付款的资源栏。

即时队列战斗的体力每轮补给并可保留余额；法力在战斗开始时按容量初始化，跨轮保留，不自动回复或清零。局外消耗仍按各自系统处理。

## 资源总表

| 资源 | 规则 | 初始建议 | 设计职责 |
|---|---|---:|---|
| 体力 | 回合开始增加，未用部分保留；受上限限制 | 每回合 +3，上限 6 | 所有主动动作的主费用；决定攒回合后的连段与爆发 |
| 法力 | 战斗开始时按容量初始化；跨轮保留，不自动回复；明确写出的技能或效果可恢复至上限 | 凡人 0，云息初期 1—2 | 术法、剑气与法器驱使的附加费用 |
| 灵识容量 | 不按回合回复；法宝在场时持续占用 | 凡人 0，普通云息约 3 | 限制同时御使的飞剑、法宝、傀儡、阵旗与持续召唤物 |

### 法力与灵识上限的计算

法力上限不由基础属性换算，采用各来源明确列出的加值：

> **法力上限 = 基础法力上限 + 已达境界的法力上限加值 + 已学功法的法力上限加值 + 其他明确来源加值**

人物基础法力上限为0。每项境界或功法在对应规则中明写加多少，不因境界提升、属性增长或修炼时间自动推算。示例：突破至云息一层，法力上限增加1。法力当前值不得高于新上限；上限下降时，当前值随之压至新上限。

灵识容量由神魂与灵慧形成基础值，再由悟性提供温和倍率；不按装备、境界反复叠加一份同源基础容量：

> **灵识基础值 = 最终神魂 ÷ 4 + 最终灵慧 ÷ 20**  
> **悟性倍率 = 1 + 最终悟性 ÷ 200**  
> **凡人灵识上限 = 0**  
> **云息及以上灵识上限 = max(1, floor(灵识基础值 × 悟性倍率))**

“最终神魂”“最终灵慧”“最终悟性”均取人物完成境界成长与永久属性修正后的对应值。神魂是主要贡献，权重为灵慧的5倍；悟性不直接加点，而是温和放大灵识基础值。当前建议系数为：悟性50对应1.25倍、悟性100对应1.5倍。示例：神魂8、灵慧8、悟性50时，灵识基础值为2.4，乘以1.25后向下取整为3点。只在最终乘算后向下取整，避免属性贡献先被截断。除非某项临时效果明确写明会改变灵识容量，战斗中临时属性变化不即时重算灵识。云息以上至少有1点，不另设隐藏软上限。神魂、灵慧提高基础值，悟性提供倍率修正。

功法、器物或明确状态可在公式算出的灵识基础上直接增加或暂时压低容量；应区分“公式基础容量”与“明确来源修正”，重算时以基础公式重新求值后再加修正，不得重复累加上一次结果。灵识占用超过当前容量时仍按本案既有规则处理：在下一次自身行动开始前收回实体至不超限。

本节定义计算口径，不代表运行时代码已完成接入。境界资源和功法没有写明的法力加值不自动补出；灵识公式的重算、存档兼容及战斗快照接入需在实施时一并验收。

UI 统一显示为：体力 `当前/上限`、法力 `当前/容量`、灵识 `已占用/容量`；灵识不是一次性支付的蓝条。

炁是所有可调用它的技能、心法和秘籍共用的战斗资源，不是第四种支付费用：炁跨回合保留；达到当前法力上限两倍时清空炁、将法力补至当前上限，并结算周天触发。完整阈值与时序见[云息公共战斗状态与秘籍构筑规则](云息公共战斗状态与秘籍构筑规则.md)。

周天附加效果再次产炁且达到阈值时，仍清炁并回满法力，但不递归触发周天附加效果链；具体规则见公共战斗状态专题。

## 回合与出牌

### 回合开始

1. 抽取规定手牌，基础值为 5 张。
2. 体力增加 3 点，最多 6 点。
3. 法力保留上一回合结余，不自动恢复；只有明确写出法力回复的技能或效果可恢复法力。
4. 已祭出的法宝保持在场，灵识占用不变。
5. 玩家可连续出牌，直到主动结束回合、手牌不足或资源不足。

### 回合结束

1. 非保留手牌进入弃牌堆；虚无牌移出本场战斗。
2. 剩余法力保留至下一回合。
3. 剩余体力保留到下回合。
4. 法宝、姿态、气血、血炉等明确写为跨回合的局内状态继续存在。

### 费用档位

| 费用 | 含义 |
|---:|---|
| 0 体力 | 条件牌、准备牌或一次性小效果；须由使用次数、弃置、虚无、条件或真实法力费用限制，不能无代价循环。体力与法力均为 0 时必须另有限制 |
| 1 体力 | 普通攻击、防御、位移、基础辅助 |
| 2 体力 | 高效攻击、稳定控制、群体效果或明确强化 |
| 3 体力 | 核心爆发、终结招式、强范围效果 |

普通牌不使用 4 点以上体力。需要更大爆发时使用消耗全部体力、条件状态、消耗牌或多段准备，而不是继续增大数字。单张牌通常至多有两项即时费用：体力，或体力加法力。灵识占用只用于祭出类牌，不与普通施法混写。

2026-10-26 费用限制澄清：用户确认，云帔的体力 0、法力 1、次数不限由持续法力成本构成充分限制，不额外增加使用次数。法力成本可作为 0 体力技能的真实资源限制；是否另设次数或条件仍按具体技能确定。

## 法力

- 法力是当前战斗内持续保留的灵力储备；跨回合不自动回复或清零，只有明确写出法力回复的技能或效果可按当前容量上限恢复。
- 境界、灵根、功法与装备提高法力容量、术法减费、术法返还或法力转化；普通战斗时间不自动恢复法力。
- 凡人可用纯体力牌；进入云息后才逐步接入法力牌。

示例：术法牌可使用体力 1、法力 1；灵爆为体力 2、法力 2；普通拳脚只需体力 1。

## 灵识与法宝

灵识是御物能力的容量，不是每张神魂牌都要扣的资源。

- 祭出飞剑、法宝、傀儡、阵旗或持续召唤物时，支付该牌的体力/法力，并占用灵识。
- 法宝留场期间持续占用；收回、损毁、驱散时释放。
- 已祭出的法宝对应的御使牌只支付体力和法力，不重复占用灵识。
- 神魂压制可暂时降低灵识容量；若占用超过容量，玩家在下一次自身行动开始前选择收回法宝至不超限。
- 普通法术、神魂伤害、洞察和控制不占灵识，除非它们明确祭出一个持续实体。

## 卡牌字段与迁移

新卡使用：

```text
energy_cost          体力费用，0—3
mana_cost            法力费用，0—3 为常态
spirit_occupy        祭出后持续占用的灵识容量，通常 1—3
```

卡牌只保留 `energy_cost`、`mana_cost` 与持续实体的 `spirit_occupy`；不维护其他局内费用字段。

2026-10-10 应对分支补充：应对技能的原费用与效果用于实际应对；可选 `non_response_skill` 引用独立普通效果资源，该资源仍使用上述同一组费用字段。未配置时未应对则免费空放、无效果、不扣次数；两分支互斥付费，共用原技能限次。现行攻击应对与按技能“破绽”关键词匹配的应对扩展提案见[即时队列战斗系统设计](即时队列战斗系统设计.md)第5节；后者未接入运行时。

2026-10-24 技能信息与应对关键词（2026-10-25澄清，迁移待接入）：取消玩家可见的“攻伐／守御／术诀”技能分类；技能信息以实际效果、目标、费用、状态与关键词表达。催血按其实际效果描述为给予自身气血状态，不因给予状态而归为“守御”。直接造成攻击伤害的技能仍须明确近身或远程出手方式。对容易被特定技能应对的技能或行动，在其自身关键词中配置描述可乘之机的词，例如**破绽**；应对技能只有明确匹配“破绽”关键词时才触发。首批对象为催血、休整和战斗服丹。该关键词属于技能／行动自身定义，不是角色持续状态或统一行动类别，也不自动打断行动。应对先结算，只有应对效果明确写出打断才取消原行动。触发应对不改变原行动的费用、目标或效果；被取消的主动技能按现行规则不支付费用、不扣使用次数，服丹不消耗物品，但行动槽仍完成。现有 `skill_type`／`get_card_category` 仍被运行时及旧卡图使用，本方案先退役牌面分类及其推断规则；内部兼容字段须待相关调用迁移后再处理，不在本轮改代码或卡牌资源。

## 构筑与资源协同

- 战斗中所有角色使用同一公共基础技能池；秘籍资格只读取明确配置的学习条件。
- 构筑由已学会并装配的技能、主辅修秘籍提供的心法，以及技能明确调用的公共状态与资源组成。炁、念、气血、血炉等按各自规则供不同来源使用，不属于秘籍专属资源。
- 法宝、御兽、阵法等机制继续按各自装备、召唤与阵法专题规定；灵识容量只约束持续实体，不形成修炼路线。

## 实施顺序

1. 实现连续出牌、体力、跨回合保留法力和灵识占用的统一支付接口。
2. 维护所有角色共用的公共基础技能池，不按主修秘籍切换技能库。
3. 维护现行秘籍的卷章、心法、技能与化法；其公共状态联动以具体秘籍条目为准。
4. 迁移术法、飞剑、阵法与伤势等其余体系，并隔离历史分类字段，确保其不参与运行时判定。
