# 战斗构筑与三资源系统

> 版本：3.0
> 日期：2026-08-31
> 状态：已确认设计，待按本文分阶段实现。

> 即时战斗迁移说明：战斗场景现行采用《即时队列战斗系统设计》的固定技能槽与独立队列，不再使用战斗手牌、抽牌堆或弃牌堆；本案中的卡牌费用与效果字段继续作为技能数据来源。云息凝核采用八回合时机小游戏；玄基入境保留独立牌局循环，详见各自专题。

本文规定当前局内三资源制的唯一口径。

## 目标

战斗采用小数字、可连续出牌的构筑节奏。玩家应能一眼读出一张牌是普通动作、当回合法术，还是需要长期御使的法宝；不再面对几十点精力和四条同时付款的资源栏。

本轮只接入战斗中的精力循环：沿用角色唯一的精力字段，开战时重置、战斗内按回合恢复并可储存。劳作、远行和日程等局外消耗暂不处理。

## 资源总表

| 资源 | 规则 | 初始建议 | 设计职责 |
|---|---|---:|---|
| 精力 | 回合开始增加，未用部分保留；受上限限制 | 每回合 +3，上限 6 | 所有主动动作的主费用；决定攒回合后的连段与爆发 |
| 法力 | 回合开始恢复至上限；回合结束清零 | 凡人 0，云息初期 1—2 | 当回合术法、剑气与法器驱使的附加费用 |
| 灵识容量 | 不按回合回复；法宝在场时持续占用 | 凡人 0，云息初期 1—2 | 限制同时御使的飞剑、法宝、傀儡、阵旗与持续召唤物 |

UI 统一显示为：精力 `当前/上限`、法力 `当前/本回合上限`、灵识 `已占用/容量`；灵识不是一次性支付的蓝条。

## 回合与出牌

### 回合开始

1. 抽取规定手牌，基础值为 5 张。
2. 精力增加 3 点，最多 6 点。
3. 法力恢复至本回合法力上限。
4. 已祭出的法宝保持在场，灵识占用不变。
5. 玩家可连续出牌，直到主动结束回合、手牌不足或资源不足。

### 回合结束

1. 非保留手牌进入弃牌堆；虚无牌移出本场战斗。
2. 剩余法力清零。
3. 剩余精力保留到下回合。
4. 法宝、姿态、气血、血炉等明确写为跨回合的局内状态继续存在。

### 费用档位

| 费用 | 含义 |
|---:|---|
| 0 精力 | 条件牌、准备牌或一次性小效果；必须有次数、弃置、虚无或条件限制，不能无代价循环 |
| 1 精力 | 普通攻击、防御、位移、基础辅助 |
| 2 精力 | 高效攻击、稳定控制、群体效果或明确强化 |
| 3 精力 | 核心爆发、终结招式、强范围效果 |

普通牌不使用 4 点以上精力。需要更大爆发时使用消耗全部精力、条件状态、消耗牌或多段准备，而不是继续增大数字。单张牌通常至多有两项即时费用：精力，或精力加法力。灵识占用只用于祭出类牌，不与普通施法混写。

## 法力

- 法力不是可跨回合囤积的长期蓝条，而是每个行动回合重新运转的灵力额度。
- 回合结束时强制清零；任何法力回复效果只能在当前回合内生效。
- 境界、灵根、功法与装备主要提高本回合法力上限、首张术法减费、术法返还或法力转化，不提供旧式持续回复率。
- 凡人可用纯精力牌；进入云息后才逐步接入法力牌。

示例：术法牌可使用精力 1、法力 1；灵爆为精力 2、法力 2；普通拳脚只需精力 1。

## 灵识与法宝

灵识是御物能力的容量，不是每张神魂牌都要扣的资源。

- 祭出飞剑、法宝、傀儡、阵旗或持续召唤物时，支付该牌的精力/法力，并占用灵识。
- 法宝留场期间持续占用；收回、损毁、驱散时释放。
- 已祭出的法宝对应的御使牌只支付精力和法力，不重复占用灵识。
- 神魂压制可暂时降低灵识容量；若占用超过容量，玩家在下一次自身行动开始前选择收回法宝至不超限。
- 普通法术、神魂伤害、洞察和控制不占灵识，除非它们明确祭出一个持续实体。

## 卡牌字段与迁移

新卡使用：

```text
energy_cost          精力费用，0—3
mana_cost            本回合法力费用，0—3 为常态
spirit_occupy        祭出后持续占用的灵识容量，通常 1—3
```

卡牌只保留 `energy_cost`、`mana_cost` 与持续实体的 `spirit_occupy`；不维护其他局内费用字段。

## 流派职责

- 锻躯：依靠精力储存、气血、血炉与近身连段；几乎不消耗法力。
- 行炁/术法：以每回合法力为爆发窗口；通过减费、返还、额外法力和术法连锁构筑。
- 御器、御兽、阵修：以灵识容量换取持续场面；强度来自在场法宝与御使牌之间的协同。
