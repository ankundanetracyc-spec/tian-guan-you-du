# 玉虚仙宗真传入门与师承培养流程

> 状态：现行剧情方向；首轮可玩闭环已接入：天灵根择师、稳定带教者、玄览峰选书、沿用现有规则研读首卷并回紫府峰汇报。该闭环的选书、研读、汇报均接入共用任务簿与右侧任务栏。首卷云息秘籍为可替换候选。师父定期考核、后续卷册权限、带教弟子与接引委派仍未实现或定案。

## 一、目标与边界

本流程补足天灵根玩家主动加入玉虚仙宗后的真传生活，让入门获得明确的师承、前期战斗手段和后续责任。它是阶段二的可选宗门支线，不取代“行旅与积累”主线，不要求玩家加入玉虚，也不以加入玉虚作为其他玩家的境界引导前置。

- 无灵根不收；玉虚仍按现行灵根规则记录入门身份。天灵根入门即为真传，真传不能通过晋升取得。
- 玄基与金丹的阶段名称均为初期、中期、后期、圆满；玄基、金丹玩法与数值尚未接入。本流程只使用金丹后期和金丹圆满作为师父候选范围。通用高境界 NPC 生成尚未接入；当前首轮师承支线会按稳定 ID 生成专用候选人物，不代表通用规则已完成。
- 真传起居与静室在紫府峰；藏经与功法选择在玄览峰。普通弟子观复峰授业不代替真传师承。
- 师父负责阶段性考核与指点，不全天候带教。师兄师姐承担入门初期的日常引导，不能代替师父决定传承或晋升。
- 师承、带教与弟子关系使用稳定人物身份记录；不得与百川区域声望、势力态度、个人关系、宗门贡献合并成同一数值。
- 时间继续由玩家主动行动推进；不设离线时间、后台钟或未经确认的限时任务。

## 二、师门角色

### 师父

师父由玩家在确认入门时选择，范围为玉虚仙宗内金丹后期或金丹圆满的成员。师父接受后，真传身份仍由天灵根决定；拜师不改变灵根身份规则。

师父不逐日陪练。设计上，玩家在固定时点前往紫府峰接受考核和指点；第一次带教汇报之后进入常规考核节奏。当前首轮闭环尚未加入周期提醒或考核行动；考核间隔、具体考法、未通过后果不能自行填入月份、境界门槛或属性奖励。

### 带教师兄或师姐

师父指派一位云息十层的师兄或师姐，陪玩家完成入门初期的导览和第一卷研读。其身份使用稳定 NPC ID，并在同一玩家存档中保持不变。首轮实现为师父各自关联一位专用带教候选；后续可改为复用通用同门名册。

带教者先带玩家熟悉紫府峰与玄览峰，说明选书和研读流程；第一卷研读完成后，玩家回紫府峰向其汇报。此后仍可作为日常请教对象，但不代替师父的周期考核，也不持续锁定玩家行动。

## 三、首期入门流程

1. **主动拜入**：玩家在玉虚仙宗完成现有入门资质确认，确认拜入。其他灵根档位继续按现有身份规则处理。
2. **择师**：天灵根玩家从符合金丹后期或圆满条件的宗内师父中选择一位；确认后登记师父的稳定身份。
3. **安排带教**：新师父指派一位云息十层的同门担任临时带教者，并记录带教者身份。进峰、重进场景或过月不得重新随机更换。
4. **玄览峰选书**：带教者陪玩家前往玄览峰，在首轮候选中选择一本当前可研读的云息秘籍。候选按现有第一卷门槛过滤；选书只借阅此前未掌握秘籍的首卷，不自动授予贡献或未定义的属性。首卷之后的借阅权限仍未定，因此首轮实现暂不开放该借阅书的后续卷章；玩家入门前已掌握的秘籍继续沿用原有权限。
5. **紫府峰研读**：玩家在自己身份对应的静室完成所选秘籍第一卷。研读沿用现有秘籍章节条件、进度与体力/时间结算，不降低属性门槛、不跳过章节完成事件。完成第一卷后取得该卷原有的主动技能及其既有章节效果。
6. **向师兄或师姐汇报**：玩家回紫府峰汇报；以所选秘籍和章节完成记录核验。若玩家入门前已经完成这本秘籍的第一卷，可直接汇报，不要求重复研读。
7. **进入常规师承**：首卷汇报结束后，师父按固定时点安排考核指点；日常安排仍由玩家自主决定。

## 四、静室研读与宗门事务的关系

真传在紫府峰静室研读，普通弟子在观复峰静室研读；地点边界不变。现有“静室研读一卷”宗门公事仍由玩家主动从和光峰事务板接取，带教剧情本身不自动发放宗门贡献。

若玩家主动接取了“静室研读一卷”，同一卷完成事件可以同时推进带教汇报和该公事；宗门公事按原有唯一事务流水只结算一次。未接取该公事时，只推进师承剧情，不产生贡献。研读进度、技能习得和贡献流水继续分开记录。

## 五、后续培养方向

### 玩家成为带教者

玩家以后可承担师兄师姐职责，带领一位师弟或师妹熟悉宗门、选择传承并汇报第一卷。开放时点、资格要求与带教结果暂未定，不按真传身份自动授予。

### 师父委派接引

师父外出游历时发现一位有培养价值的新人；遇到必须亲自处理的危险事务后先返回宗门，再委派玩家前往已有地点接触并接回新人。此任务可以沿用宗门公事中的“接引”类型，但该任务模板目前尚未开放。

接引对象须有稳定人物 ID，地点必须已开放且可抵达；玩家负责递交邀请、会面和护送，不替对象决定是否入门。除非将来另行确认，不设倒计时、不凭空生成资源、不把“师父正在处理危险事务”做成玩家必须立即完成的限时惩罚。
