# 战斗剑器基础字段规范

> **最新清和范围已确认**：锋锐从剑尖向前连续3格，随剑尖转向；御使本体2×1本轮沿用。范围与行囊／本体占格独立，不占格、不改变攻击射程；旧同尺寸向内两格候选撤回。

> **2026-11-08最新属性边界**：[六项固定属性与剑形硬池](../物品与装备/器物战斗属性白名单与剑形属性池_20261108.md)先限定基础加成范围，池外绝不生成；[化法接口](../物品与装备/器物化法生成与招式改写接口_20261108.md)处理整包绑定及真实结算。[v2材料实算](../物品与装备/剑器属性池与化法接口修订实算_20261108.md)与[卡面](../物品与装备/清和剑新版实算卡面_20261108.md)已重新分配预算，v1普通剑招增伤与清和物防撤回。四池具体成员和换算数字为候选，未接正式生成器。

> **统一技能最新确认**：所有器物能力统一写入技能列表，普通攻击也是其中一项；每项独立检查费用与条件，不满足就跳过，不自动替换其他技能或额外发动普攻。旧资源不足自动回退已撤销。多技能扫描次序仍待定，具体费用的暂定／候选状态不变。

> 2026-11-08。应用户要求，从剑器开始完整整理参与战斗器物的专属与通用字段。**本页是字段组织与填写规范；已确认玩法作为固定边界，未定编排与生成参数仍保留未定标记。**不以清和剑候选数值代表所有剑器，不把已有存储字段视为新版运行已经实现。

> **逐件成器系数最新裁定**：[参数生成与御使物理普攻规范](../物品与装备/剑器成器系数与御使物理普攻生成规范_20261108.md)。每把剑保存炼器形成的稳定与普攻参数，不能全剑类共用一套系数；神魂参与默认剑攻，伤害类型仍为物理。具体映射与曲线已有完整候选，待采用及平衡；旧固定数字仅作人工算例，未实装。

> 星标、手持、灵识及默认动作见[原方案](../物品与装备/剑器星标锋锐与御使稳定度方案_20261108.md)。普攻体力0暂定；法力、扫描时机、稳定度名称与生命结算仍保留候选状态。

依据：[三资源总案](design-plan.md)、[御使灵识与锋锐来源](../物品与装备/新版御使灵识与锋锐来源规则_20261108.md)、[器物现行主案](../物品与装备/器物系统现行主案_20261023.md)、[器蕴现行运行与生成](../物品与装备/器蕴运行与生成接入_20261024.md)、[手持与护具分工](../物品与装备/外围手持槽与护具分工设计_20261107.md)、[现有字段对照](../物品与装备/器物现有字段与新盘改卡对照_20261107.md)、[信息展示规范](../界面与美术/信息展示与规则详解分层规范_20261026.md)。

## 一、固定边界与填值约定

1. 手持剑的锋锐按明示星标范围作用于具有剑关键词的人物招式；御使剑出招使用自己的锋锐，不获得手持星标锋锐。两种来源分别判断，不以旧的全盘实际用器口径取代星标限制。
2. 基础加成仅用生命上限、物防、精准、身法、会心、护心六项整数点数；先按真实剑形过滤硬池，池外绝不生成。已启用手持或御使本器均可提供人物全局贡献，同一实例只计一次；御使动作读取主人最终评分，不再复制加值。化法仍仅限手持本器且启用，器蕴公共奖励另按现行表处理。
3. 启用或重新启用御使只检查可用灵识，不收体力、法力或其他费用；启用后持续占用，跨共同回合保持，收回或停用释放。
4. 器物通常同时支持手持与御使，例外明写。所有能力统一登记为技能，普通攻击也是其中一项，读取本器参数；每项独立判断费用和条件，不满足跳过，不自动替换其他技能。剑类普通攻击读取神魂仍为物理伤害；“器术”不是必需的额外占格块，多技能发动编排仍待定。
5. 同一实物只认一份来源，同名不同实例分开。器蕴贡献、化法对象、出招用器、当前用法分别记录，不因多格或多个技能引用复制一件实物。

| 填写状态 | 含义 |
| --- | --- |
| 必填 | 新剑器定义必须给出真实内容 |
| 条件必填 | 有该用法、能力或结构时必须写完整；没有则明确为无 |
| 无 | 已确定没有该能力或属性，不发放收益 |
| 0 | 已定义且真实数值为0；不能用0代替缺失或未设计 |
| 不限 | 已明确不设该项上限；不等于漏填 |
| 待定 | 尚未确定，不能当作0、免费、不限或可用进入实现 |
| 内部字段 | 用于身份、来源、结算或保存，不堆入玩家效果正文 |

旧剑器缺失锋锐等数据时保留缺失事实，不因新字段必填就给旧物猜一个值。新基础战斗属性加成必须为固定点数；旧百分比效果须重新核算，不能仅把百分号换成点数。

## 二、剑器专属字段：锋锐

| 字段 | 要求 | 定义 |
| --- | --- | --- |
| 锋锐数值 | 新剑器必填 | 本剑可忽略的物理防御点数；不是攻击伤害，也不是穿防百分比 |
| 手持锋锐星标范围 | 必填，按范围条目定义 | 手持本器且启用后，范围内携带剑关键词的人物招式获得本剑锋锐；清和已确认由剑尖向前连续3格、随剑尖转向，不是全盘生效 |
| 手持锋锐对象筛选 | 固定边界 | 只作用人物招式，不强化御使剑；不额外要求该人物招式必须以本剑实体出招 |
| 御使锋锐适用说明 | 必填，遵统一口径 | 本剑本体参与的合格物理攻击，使用本剑自身锋锐，不领取手持星标锋锐 |
| 本段归属与实际用器 | 发生攻击时必须有明确来源；内部记录 | 区分人物招式与器物动作；御使攻击指向实际剑器实例，不能只看角色手持剑 |
| 本体参与范围 | 对有多个御使伤害段的能力条件必填 | 明确哪些段由本剑本体参与，哪些是独立术法或衍生来源；不无条件继承 |

人物剑招在甲剑星标内取得甲剑的锋锐，范围外不取得。御使乙剑飞斩取乙剑自身锋锐，即使乙剑被甲剑星标覆盖也不加甲剑锋锐。多剑御使分段分别取来源，不默认相加；无物理攻击结果的招式不因锋锐生成伤害。

本轮不增加通用“剑攻击力”、剑重伤害、独立剑攻速或额外穿透属性。伤害、目标与出手方式来自具体能力，剑型、长度或品阶不自动生成这些效果。

本剑的默认御使物伤参数属于该剑及其默认动作，不是新增人物通用攻击力；锋锐也不直接复制为物伤基础项。

## 三、通用身份与表现字段

| 字段 | 要求 | 定义与显示 |
| --- | --- | --- |
| 显示名称 | 必填 | 显式专名优先，否则使用实际方向自动名；名字不决定能力 |
| 自动名称auto_name | 无专名的新剑必填 | 本轮候选从最终正数效果取简短有义的两字方向词，默认两组＋真实剑型，额外专属特色才考虑第三组；缺项如实省略，固定保存 |
| 专名custom_name | 有真实命名来源时填写 | 商品／剧情明确命名或玩家自取名，覆盖自动显示；不删除自动名依据 |
| 命名来源name_origin | 内部必填或明确旧来源不明 | 记录自动、明确专名及其来源；不能凭旧Name非空推断专名，旧未知来源保留显示事实 |
| 命名依据与版本 | 内部必填 | 前缀对应效果、真实剑型和命名规则版本；不以材料名反推战斗效果 |
| 器类 | 必填 | 本规范对象为剑；后续其他器类另列自己的本体专属属性 |
| 品阶／器阶 | 必填，同一个等级维度 | 读取真实已定义器阶，不额外造一层品质或凭结果补小档 |
| 形态与form_profile_id | 必填 | 真实长宽比及厚宽比确定剑形和硬属性池；不能从名字或旋转后的占格猜形态，不额外乘伤害或属性倍率 |
| 阴阳 | 必填 | 沿现有七档：至阴、阴、偏阴、和、偏阳、阳、至阳；不自动附送战斗加成 |
| 图标／战斗表现引用 | 必填有效资源 | 保持本器完整轮廓；行囊图标与战斗表现可分别引用 |
| 简介 | 固定保留栏目，可空 | 世界内说明，不放存档、预算和实现备注 |
| 独立实例身份 | 内部必填 | 区分同名实物，供占位、用器、化法、器蕴和保存共同引用 |
| 定义与规则版本 | 内部必填 | 标记生成与解释规则，避免旧物重开页面时被重新计算 |

不新增整器五行或成器功用字段。材料五行、材性及来源分账仍属于炼制记录，不能当成成品的新战斗属性。

## 四、支持的用法与占格

| 字段 | 要求 | 定义 |
| --- | --- | --- |
| 可手持 | 必填，通常支持 | 例外必须明确；支持不等于已经启用 |
| 可御使 | 必填，通常支持 | 例外必须明确；普通攻击可作为统一技能列表中的一项，不因没有其他能力就禁用御使 |
| 当前选择用法 | 人物配置字段 | 本件本场选择手持或御使；同一实例不能同时占两处 |
| 行囊占格与旋转 | 必填 | 真实储物格形、尺寸及可用方向 |
| 御使战斗格形 | 可御使时必填 | 本体在主盘实际占用哪些格；与行囊占格分别定义 |
| 战斗转向 | 有主盘本体时必填 | 可旋转方向、转后实际格形，以及相关范围如何转动 |
| 同一实例数量 | 固定来源约束 | 一件实物只放一份本体，不因有多项技能而复制本体 |
| 额外同类限制 | 有规则时必须明写 | 是否限制同类或同名的多件真实器物；没有明文不凭名字强加唯一性，未定不装作已不限 |

手持剑进入外围唯一手持槽，不占主盘面积；主盘御使按本件战斗格形占位。战斗格形可用实际格坐标表达，矩形时可简写宽高，不能把包围盒里的空洞也当作已占格。是否支持某种复杂格形还须实际接口验收，不能只画图就宣称已支持。

单剑或成套属于真实构成说明。成套仍按一个实例；分体数量、分体属性和多段出击必须另有完整定义，不从“成套”一词复制整器锋锐、局内生命或器蕴。凡器不生成器蕴，不等于禁止有足够灵识的人御使。

## 五、装备效果字段

| 字段 | 要求 | 定义 |
| --- | --- | --- |
| 生效用法与时机 | 固定边界 | 当前手持或御使本器且启用后生效；同一实例只计一次，收藏或待启用不提供贡献 |
| 人物属性加成列表 | 条件必填 | 只写六项白名单中且属本剑形硬池的实际正整数；保存stat_id、value_kind=int_flat、profile_id和源身份。作用人物全局，不用星标筛选 |
| 特殊持用能力 | 有独立批准模板时才填 | 本轮不新增通用技能增伤或事件奖励入口，不能将撤回的普通剑招增伤换名保留 |
| 持续与失效 | 有持续效果时必填 | 何时开始、何时撤去；合法用法切换不重复发值，失去全部有效用法后撤销贡献，不留下永久属性 |

属性通过可撤销的来源贡献账本应用，不写人物永久成长，不用刷新或换装重复发值；提高生命上限本身不治疗。精准／身法／会心／护心是评分，不能写成概率；身法不是移速或状态层数。池内项目不保证全出，池外供给未利用，不补为其他属性。完整许可表见六项白名单主文。

## 六、化法字段

| 字段 | 要求 | 定义 |
| --- | --- | --- |
| 化法方案 | 有化法时必填 | 注册template_id＋版本及完整operations；没有写无，未知操作拒绝 |
| 技能开放接口 | 有化法时必填 | 原招式声明的modifier_slot、实际机制及结算phase，不任意改ActiveSkillData字段 |
| 冻结数值与预算 | 有化法时必填 | 实际来源分配→整包量化→成器冻结，不按主人所学技能重抽 |
| 生效用法 | 固定为手持本器且已启用 | 不开放为御使化法，不另占灵识 |
| 适用目标定义 | 有化法时必填 | 明确必需关键词，或直接指定基础技能；所列关键词的共同要求写清 |
| 实际效果要求 | 有相关条件时必填 | 如必须实际应对物理攻击并施加化解，不能只靠名字或一个关键词放行 |
| 目标份数 | 固定单个对象 | 指定一份匹配的已摆招式，不强化全盘同名所有份数 |
| 追加／改写效果列表 | 有化法时必填 | 全部围绕同一个合法对象设计，不能混合只适用于不同技能的无交集条目 |
| 触发、费用、时长与限次 | 有化法时必填 | 真实结算事件及代价；沿原技能费用时明确沿用，不自行创造额外应对或机会 |
| 兼容及互斥规则 | 有冲突可能时必填 | 与原技能、秘籍化法、其他来源如何共存，按真实结算口径处理 |
| 当前选中的一份招式 | 人物盘面配置字段 | 保存source_instance_id／bundle_id／版本与target_layout_id／placement_id／base_skill_key；移动跟随同份，删除不按同名自动改绑 |
| 预配置与实战状态 | 必填接口 | CanConfigure允许未启用前先选合法手持来源；IsActiveNow另查本件当前手持、启用和目标。失效暂停保留选择，不回滚已结算结果或刷新次数 |

先确定目标，再围绕它形成整套有效修正。指定格剑的化法应让格剑能利用整套效果，不夹带只对气血攻击有用的穿防；也不为凑条件给格剑加新关键词或攻击。

生成只查全局已开放招式接口；人物未学相应技能不改变成器结果，也不免费授予。绑定须已学、已摆，整包不能全适配则拒绝，不挑一半生效。本轮只登记格剑的物理应对化解固定加值，数值须经解析计划进入实际化解事件。详见[化法接口主文](../物品与装备/器物化法生成与招式改写接口_20261108.md)。选择界面、几何指向与器物化法复制继承仍待定，不默认新增占格块。

## 七、御使基础字段

| 字段 | 要求 | 定义 |
| --- | --- | --- |
| 御使用途与能力列表 | 可御使时必填 | 明确本器实际提供哪些功能，可以多项，不固定成只有范围强化 |
| 统一技能列表 | 可御使时必填 | 普通攻击及其他已定义能力使用相同技能字段，各自判断费用／条件；不满足跳过，不自动替换其他项 |
| 本剑稳定参数组 | 可御使时必填 | 本次成器生成的稳定基础项、神魂系数、剑道系数、占用系数；固定保存，不是固定局内生命 |
| 本剑普通攻击参数组 | 已定义普通攻击技能时必填 | 成器生成的基础物伤、神魂系数、剑道系数，供该项技能读取；不套统一品质值，不用缺失参数造自动普攻 |
| 默认剑攻伤害类型 | 固定为物理 | 神魂是公式输入，不决定伤害类型；专属技能各段仍依自身明文定义 |
| 灵识占用 | 可御使时必填明确量 | 本件御使期间持续占用，跨共同回合保持，收回或停用释放；缺失不能按0处理 |
| 启用条件 | 固定规则 | 对合法配置的真物件，只检查可用灵识是否足够；启用与重新启用都不收体力、法力或其他费用 |
| 状态生效条件 | 每项能力必填 | 哪些能力要求御使中，源失效后如何停止后续效果 |
| 主动能力的发动方式 | 必须定稿后才能实现该主动能力 | 当前建议本体每轮首次扫描时执行一次御使动作；时机与次数未确认，不能由体力0暂定推导已定稿 |
| 默认普攻费用 | 明确暂定与未定状态 | 体力0暂定；法力0为候选，用户尚未确认；专属技能按其明示费用 |
| 费用与条件不足 | 最新确认 | 跳过该技能，不付其费用、不扣其次数或启动冷却，不自动替换其他技能或额外普攻；旧资源不足回退已撤销 |
| 执行与动作计数 | 必须明确 | 每项仅在自身合法执行时结算；失败不补其他技能，不产生额外扫格，多技能扫描次序仍待定 |
| 独立技能块的格形与份数 | 仅采用该编排时必填 | 不强制所有御使卡多占一块；编排未定时不填默认值 |
| 御使范围定义 | 有范围法效时必填 | 按下一节填写，不把本体占格当成覆盖范围 |
| 局内生命与反制定义 | 公式和结算定稿后填写 | 推荐名称御使稳定度，以本剑参数代入本件灵识占用与御使者属性派生；不填旧式固定生命值，不与耐久混用 |

新版不设可调的御使启用体力／法力费用，也不设按次施法灵识。旧实现的兼容字段可以归档，但不得作为新卡可调设计项；具体主动能力的体力／法力费用仍写在能力条目。

各项能力统一按技能字段记录，普通攻击也是其中一项；每项技能独立检查费用、目标及其他条件，不满足时跳过该项，不自动替换别的技能或额外补普通攻击。只有实际执行的技能结算自身效果；技能之间的扫描次序与编排仍待定，不能借本条默认同时全放。旧资源不足自动回退已撤销。

两组参数由实际材料、加工和分配形成，公共公式形状统一，参数逐件保存；同阶也可有不同成长侧重。炼器造诣用于当次加工，战斗读取当前御使者的神魂与剑道造诣。品质不新增第二套评分或生成后倍率；来源与共同预算、器蕴预留顺序沿[生成规范](../物品与装备/剑器成器系数与御使物理普攻生成规范_20261108.md)。本轮[完整候选](../物品与装备/剑器属性池与化法接口修订实算_20261108.md)已明确B三分、共同求解、平方根组价值、20／20／3参照价归一及系数四位向下截断；待采用与平衡，不把人工A填成真实清和或任何新剑默认值。

## 八、每项能力共用的完整字段

手持能力、御使攻击、防护、术法、常驻或条件触发均按同一套信息填写；这是一套说明字段，不新增玩家技能类别。

| 字段 | 必须回答的问题 |
| --- | --- |
| 能力名称／简述 | 这项能力具体做什么？ |
| 允许用法 | 手持可用、御使可用，还是两种用法各有明确分支？不能越过手持专属限定 |
| 作用对象 | 对人物、敌方、某份招式还是明文允许的御使物生效？不从器形猜目标 |
| 适用筛选 | 必需关键词、基础技能身份、实际效果及真实用器要求是什么？ |
| 发动／触发方式 | 扫描发动、真实应对、持续在用或哪个既有事件触发？普通攻击及其他技能都逐项判断，具体发动时机和多技能次序仍须定稿 |
| 效果与数值 | 伤害、护盾、化解、角色属性或已有状态如何变化？数值固定还是依公式计算？ |
| 伤害类型与本体参与段 | 哪些段为本剑本体攻击，可以使用锋锐？独立术法和衍生段分别写清 |
| 出手方式与目标范围 | 沿原能力明确近身／远程、单体或其他已定义目标规则，不由物品长度推导新射程 |
| 体力／法力费用 | 具体执行能力时怎样付款；0费要有总案要求的真实约束，不能伪装成启用费 |
| 结算粒度 | 按一次施放、伤害段、受益招式份数或目标结算？多段、多格、多目标是否重复？ |
| 持续时间 | 本次、明示回合数、某事件结束，还是维持本器在用期间？ |
| 次数与冷却 | 每轮／每场／每份／每件是否有限制，何时刷新、与谁共享？没有限制要明确写不限 |
| 叠加与互斥 | 同源、同名不同实物、不同法效重合时怎样计算？不默认层层相乘 |
| 失效处理 | 关闭来源后停止哪些后续收益，已产生的伤害／护盾等沿什么原规则保留？ |
| 来源身份 | 内部记录实际物件、能力和目标份数，供锋锐、次数、复制及保存追溯 |
| 特殊兼容限制 | 有无明确的复制、周天、应对或目标限制？未定不从器物名称推导 |

动态效果沿现行简略／详细规范使用真实公式，固定数值不凑公式。没有新定义的返费、抽牌或额外行动不能靠模糊描述生成；触发效果也不能无限递归调用自身。

## 九、范围必须单独定义

| 范围字段 | 含义 |
| --- | --- |
| 起点 | 明确实际来源锚点；清和锋锐为剑尖，不能改用手持接点或本体中心；其他能力按自身明示对象 |
| 覆盖格位 | 相对坐标或完整格形；不能只写附近、前方、周围 |
| 朝向与旋转 | 哪些方向合法，转向后本体与范围怎样同步变化 |
| 合格受益对象 | 范围内哪些招式或对象符合条件，覆盖不等于自动受益 |
| 多格计数规则 | 一份招式跨多格如何去重；当前候选按份计算，通用规则仍须定稿 |
| 重合与边界 | 多来源重合如何处理，越界、空格、未解锁格是否受影响 |

必须区分行囊占格、主盘本体占格、手持锋锐星标范围、其他法效覆盖格形，以及能力攻击目标与出手距离。范围标记本身不占格；手持星标依新规则向合格人物招式提供锋锐，不能转给御使剑。其他范围法效按明文效果判断，不因覆盖自动转移锋锐。

清和本轮沿用2×1本体，朝右标准格为(0,0)、(1,0)；独立保存剑尖锚点(1,0)及相对偏移(1,0)、(2,0)、(3,0)，覆盖标记落在(2,0)、(3,0)、(4,0)。剑身、剑尖和偏移同时转向。三格是最新确认的锋锐范围，不从本体长度、行囊2×6或图标尺寸推导，不改写攻击射程。元数据保存来源和版本，缺失旧物不默补候选几何。

## 十、器蕴完整字段

### 本件固定保存

| 字段 | 要求 |
| --- | --- |
| 器蕴贡献列表 | 每项写已定义蕴种及本件实际贡献点数；没有贡献写无 |
| 固定来源与规则版本 | 内部保留成器快照及预算来源，旧物不因开页或改版本自动补点 |
| 实例去重身份 | 与真物件共用同一身份，多格、多个技能引用、分体都不重复算本件 |

一把剑可以贡献多种已定义器蕴，不要求固定只含一种，也不因是剑就默认送惊鸿或抱朴。凡器按现行规则不生成器蕴；现行单件同种贡献最多3点，不把一个物品的多条同种贡献当成多件。

### 人物累计与公共奖励

| 字段 | 保存／计算位置 |
| --- | --- |
| 当前有效来源集合 | 人物／战斗侧，按全局来源资格判定，不写成单剑固定属性 |
| 各蕴累计点数 | 从有效真物件贡献汇总，不复制技能或本体格数 |
| 当前激活档位 | 查公共器蕴表，区分未达档与已激活 |
| 实际奖励与适用对象 | 公共规则定义，不把全身总收益冒充这把剑的单件贡献 |
| 距下一档点数 | 人物预览计算，不改写物品 |

现有两种器蕴及试用档位：

| 蕴种 | 适用效果 | 2点档 | 4点档 |
| --- | --- | --- | --- |
| 惊鸿 | 带剑关键词的技能物理伤害 | 总计+10% | 总计+20% |
| 抱朴 | 人物物理防御 | 总计+10% | 总计+20% |

4点档替代2点档，不叠成30%；未达档不发奖励，超过当前最高档不循环加奖。惊鸿不为无伤害招式造伤害、不强化法术／神魂，沿现行比例通道；抱朴不自动给御使物加物防。基础属性固定点数不改写本表公共奖励。器蕴不是新资源，不按次消耗，不额外占灵识或行动。

**来源口径须分清状态：**现运行按已装备实例累计；新版已有手持／御使启用后计入的候选，但完整参战集合与失效重算还须统一定稿。本字段规范先固定“单件贡献”和“人物有效累计”分层，不以旧运行口径冒充新盘已定，也不把整包收藏都计入。新蕴种、6点共鸣等旧候选不列为已开放规则。

## 十一、耐久、局内生命及其他有条件字段

| 字段 | 填写条件与边界 |
| --- | --- |
| 耐久上限／当前值 | 建议作为实物持久状态；具体生成、消耗和修理规则未定，不因稳定下降按1:1扣耐久 |
| 御使稳定上限／当前值 | 推荐局内生命名称御使稳定度，以本剑固定参数代入本件占用与御使者属性；公共生成已有完整数值候选，生命结算仍待定，两者不混淆 |
| 可受击目标与防护规则 | 哪些能力可削减稳定，能否享受主人物防、护盾或应对，均须另定，不自动给人物增加通用护盾 |
| 失控／收回／恢复规则 | 归零停止御使并释放占用、同场收回重放不回满均为候选；不直接等于物品永久毁坏 |
| 成套结构 | 仅真实成套设计填写构成；分体数值、受击与分段规则尚未定时不开放 |
| 行旅能力 | 有真实载具等能力时单独记录，不自动成为战斗技能 |

长期耐久与局内稳定不是同一字段。不再采用器体作为新版玩家名称，也不把旧字段直接换名作为新公式。旧实例耐久保留兼容事实；缺失不按0或满值填补，永久损耗规则未定前不落数值。

## 十二、配置、运行状态与炼制记录分开保存

| 层次 | 应记录什么 |
| --- | --- |
| 固定剑器定义／成器结果 | 显示名、auto_name、可选custom_name、name_origin及命名版本、器类、品阶、形态、阴阳、锋锐、手持星标范围、图标、各自占格、支持用法、固定点数装备效果、化法方案、御使技能或类别模板、本剑稳定／普攻参数及对应版本、默认物理类型、法效、器蕴贡献、真实来源与分配 |
| 实物持久状态 | 当前耐久及对应上限；不随新御使者的神魂改写，不让可变当前值污染固定炼制快照 |
| 人物与方案配置 | 实际选择哪件剑、手持或御使、盘面位置和方向、化法选中哪一份招式、按定稿编排引用哪些器物技能 |
| 单场运行 | 待启用／御使中／停用等状态、该件已占灵识、本轮扫描状态、动作归属、次数／冷却／触发账本、以本剑参数和当前御使者属性计算的稳定上限／当前与当次物伤、真实攻击段用器来源；按候选定稿后接入 |
| 炼制与追溯 | 材料及用量、造诣、工时与精力、长宽厚／体积／结构承载、潜力分配和损失、材料五行贡献、参数与计算记录、固定快照 |

“已扫过”和“仍在御使”是不同状态。单场次数与效果状态不写成物品永久属性；复制或额外施放保留实际物品引用，不能把御使剑换成当前手持剑。不同层共享身份但不共享可被草稿直接修改的运行对象。

旧内炼／外祭互斥、整器五行、成器功用品阶、按次施法灵识、旧召出体力／法力费用，不纳入新版可调战斗字段；历史数据仍保留迁移事实。

## 十三、玩家显示与必需信息

沿现有器物信息栏的身份、器蕴、本体专属属性、效果、化法、技能、简介等组织原则映射新字段。剑器本体显示锋锐；卡面装备效果只列实际数值，化法只列具体目标与事件效果，范围由底部图示表达。双用法资格、化法手持限制及原费用继承由独立规则界面承载，不逐卡重复；器蕴贡献写“惊鸿2、抱朴3”，不写加号。

无化法、无器蕴是正常完整定义，显示无即可；已定义的普通攻击作为技能列出，不因没有其他能力就写无攻击。明确不支持御使的例外不伪造灵识0或稳定0。未定内容不能伪装成无。实际使用的费用、目标、触发、限次、作用范围及真实代价必须保留；内部身份、预算与版本放策划说明或记录页。

详细显示必须使用本剑真实保存的系数，不硬编码原参考数字。展示“预估物理伤害”，不因公式读取神魂写成神魂伤害；旧剑缺参数也不静默套用样例、重炼或改写旧快照。

候选生成按四位向下截断保存系数，显示与计算都读取这份当次结果，不把界面粗略缩写反用于计算。名称从固定命名记录读取；改名不重炼，不因当前法力、用法或化法目标切换而自动改名，同名实物仍按实例区分。

## 十四、尚未确定而不填默认值的规则

1. 默认动作及专属御使技能的扫描时机、每轮次数、多技能选择；普通攻击体力0暂定，法力0尚未确认，独立技能块不作必需项。
2. 手持化法选择一份目标的具体界面与几何指向要求。
3. 御使容量下降时的停用优先级；局内生命名称、受击／归零／恢复，以及耐久生成与消耗。稳定与普攻已有完整公共换算候选，当前待审阅、采用与实战平衡，未接正式生成器。
4. 新盘器蕴有效来源集合及失效重算时机；新蕴种与更高档位。
5. 清和剑尖向前连续3格并随剑尖转向已确认，本体2×1本轮沿用；其他器物范围、通用格形生成、多格覆盖及重合边界仍按完整候选待审。不能把本件确认范围推广为其他物件的默认值，也不能声称正式战斗已经采用。

这些未定项不影响先把字段位置、含义和条件写完整；涉及它们的具体卡在定稿前不能作为可执行新定义接入。
