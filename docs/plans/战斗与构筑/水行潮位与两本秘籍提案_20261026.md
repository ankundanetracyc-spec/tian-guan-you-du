## 二、潮汐公共规则

1. 潮汐是角色身上的公共战斗状态；上限设为显著高于最高节点的固定高值，具体数值待定。不自然衰减，跨回合保留，战斗结束清零。
2. 每本装备的秘籍心法分别提供涨落来源和节点；任何合法来源改变同一份潮汐层数，都可触发这些心法的节点。
3. 节点N对应潮汐层数N。每次潮汐层数从S变为T后，若T>S，则依次触发满足S<N≤T的节点；若T<S，则依次触发满足T≤N<S的节点。涨潮由低至高，落潮由高至低；因此11→12与13→12都会触发12层节点，12→13离开节点不触发。潮汐层数直接变化跨过多个节点时，各节点按经过顺序触发一次。
4. 节点不消耗潮汐，不要求再发动技能。潮汐层数不变时不触发节点；到达上限后继续涨潮、到达0层后继续落潮都不改变潮位，也不触发节点。没有统一的满潮清空规则。
5. 同一行动同时产生涨落时，先结算所有落潮，再结算涨潮，分别触发节点，不合并成净变化。同方向来源依当前主修、辅修的顺序处理。
6. 节点效果不再引发潮汐层数变化，不计入心法的自身行动或攻击计数；节点发动的攻击也不使其他角色的水行心法再次涨落。战斗结束、移除状态的清理不视为退潮。
7. 节点浪击仍遵循现行攻击命中、闪避、会心、化解和护盾规则。无合法敌方时伤害节点落空，不撤销已经发生的潮汐层数变化。
8. （旧队列草案，待重定）心法行动计数按自身实际完成的行动槽统计，真实触发的队首应对计一次；休整计入，跳过、空放和无效行动不计入。攻击按是否发起攻击判断，未命中仍算；自动节点效果不计入。

已确认节点分布：澄渊为8、16层，百川为10、18层。上限须显著高于18层，具体值待定；不把上限本身设为触发节点，也不让封顶反复触发节点。节点位置在四卷中保持不变，通过增长速度和收益升级。

## 四、澄渊抱静听潮宝册

五行：水。可主修、可辅修，主修可修至云息十层。构筑为静中积潮、攻击退潮，以8层护盾和16层定澜护持；不联动气血状态。

### 心法：澄渊听潮

- 第一卷：每连续完成2次未发动攻击的自身行动，潮汐上涨4层并重新计数。自身攻击行动结束后，潮汐下降3层并清除计数。
- 主修额外效果：每回合首次由本心法涨潮时，额外上涨2层。
- 第三卷：连续两次未攻击后的涨潮提高至5层；其余来源和主修额外效果保留。
- 第二卷心法沿用第一卷；第四卷保留第三卷来源，强化节点收益。

### 招式盘适配候选（待确认）

按已确认的3×4目标盘设计；现行人类招式盘没有独立休整；旧稿的“自身行动”需按实际发动事件重新定义。建议采用以下口径：

- 成功发动且不造成直接伤害的招式，计一次未攻击行动；治疗、护盾和增益均可计入。
- 含直接伤害段的招式一律计为攻击，未命中也算；每次招式发动只使潮汐下降3层一次，多段伤害或多格占位均不重复计数，并清空连续计数。
- 实际触发的无伤害应对计一次未攻击行动；未触发的应对、失败扫描和空放不计。
- 3×4盘的真正空格只回复体力，不计未攻击行动；连续计数跨共同回合保留，直到发动攻击时清零。
- 两次未攻击行动累计后，潮汐上涨4层（第三卷为5层）并清零；主修每回合首次由心法引起的这次上涨额外+2。云帔、架招本身可计入未攻击行动次数；其化法自带的潮汐增减仍按各自条件结算，不额外视为心法的这次涨潮。

这是一版供确认的招式盘映射，尤其是“空格不计入”与“跨共同回合保留”尚未确认。

## 五、玄渊承澜荡海真经

五行：水。可主修、可辅修，主修可修至云息十层。自身技能的多段伤害积潮，付法力技能和泄川主动退潮，沿途节点立即冲击敌方。

### 心法：百川承澜

- 第一卷：自身技能行动中，首段之外每个实际命中的追加伤害段使潮汐上涨1层。
- 自身非应对技能实际支付法力并结算后，潮汐下降4层；每次施展最多一次，包含正常结算的自动施展，不以法力费用点数重复计数。
- 第三卷：自身技能行动中，前2个追加伤害段命中时各额外上涨1层潮；其余追加伤害段仍各上涨1层。第二卷沿用第一卷，第四卷沿用第三卷。
- 第二卷心法沿用第一卷；第四卷保留第三卷来源，强化节点收益并增加僵直。

对应潮汐节点：潮位抵达或经过：10层时，对随机1名存活敌方造成A点远程浪击；18层时，对全体敌方造成B点远程浪击。

| 节点 | 解锁卷章 | 双向越过时立即结算 |
| --- | --- | --- |
| 10层·激湍 | 第一卷 | 对均匀随机的1名存活敌方发动一次远程浪击，造成A点物理伤害。 |
| 18层·荡海 | 第三卷 | 对全体敌方各发动一次远程浪击，造成B点物理伤害；第四卷命中后分别以C概率施加D层僵直。 |

第一至三卷：A=round(10 + 灵慧×0.55 + 术法造诣×0.65)；B=round(16 + 灵慧×0.70 + 术法造诣×0.90)。

第四卷：A=round(13 + 灵慧×0.65 + 术法造诣×0.80)；B=round(20 + 灵慧×0.85 + 术法造诣×1.10)。

僵直：C=clamp(20% + (灵慧−目标神魂)×0.5% + 术法造诣×0.8% + 境界概率修正, 0%, 99%)×跨境界削减倍率；D=floor(clamp(45 + (灵慧−目标体魄)×2 + 术法造诣×3, 0, 120)×跨境界削减倍率)。

境界概率修正沿用现行[跨境界状态规则](跨境界状态与净化系统规划.md)；施加者每低一大境界，概率和层数各乘20%。0层不挂状态，重复施加刷新、不累加，1层对应1有效战斗帧。
