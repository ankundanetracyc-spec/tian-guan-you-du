# 手牌队列交锋与费用迁移候选

> 状态：用户授权开始改革；本文件记录已确认方向、试验参数与待裁定接口。现行正式战斗仍以[灵台选行战斗规则](灵台选行战斗规则_20261111.md)和[走位补充案](灵台选行走位、射程与遭遇阶段规则_20261113.md)为准。本案不表示新战斗已接入，也不直接改写现有技能、秘籍或数值。

## 已确认方向

- 局外招式盘作为装配容器及限制，保留格形、份数、学习资格和化法相邻指向。战斗开场每份招式摆放生成一张实体牌，多格仍是一张，同名多份分别保留来源身份。
- 局内以手牌和多条出手队列规划。首轮试验每人两条队列、每条容量5、起手4张、之后每回合补2张，未使用手牌保留。试玩点数：应敌、格剑、聚炁各1；痛击、惊蛰各2；云岚起式3，后续追加不占容量。其他招式另行确定，不从旧盘占格面积自动推导。
- 敌方具体招式保持隐藏。玩家指定敌方交互队列；距离只用于走位与画面演出，不作为射程合法性门槛。
- 首轮试玩灵机公式为 `3 + floor(对应基础属性/10 + 对应造诣/20) + 随机1～6`。例如痛击使用体魄、体道造诣；具体其他招式的对应属性须依据现有招式逐一确认，该公式及波动仅用于试玩。
- 体力、法力和灵识沿现有职责；每张招式第一次实际参与拼点时付一次费用，拼输也付；同一行动后续再拼或落击不重复支付。守招始终未触发则不付款。定力改为跨回合部分回复，具体数值待测试。
- 试玩体力沿用上限6，每回合恢复2点；法力沿现有聚炁／周天机制恢复。正式数值仍需依据对局验证，旧即时战斗按时间恢复体力，不能直接等同于该试玩回合值。
- 云岚三叠只把起式排入队列。起式成功并命中后生成下一式，每一式成功并命中后才生成再下一式；同时只插入一份临时行动。整张云岚共用一次费用：首次参与拼点或直接落击时付原有2体力，后续追加及拼点不重复付费。候选名称为起式、逐风、掠影、归岚。
- 闪避成功后保留并继续应对指定来路的下一次合格攻击；同一张闪避招式只在首次参与时付费，后续不重复支付；失败或平局结束。
- 近战与远程攻击交锋时，远程赢则远程命中、近招结束；近战赢则压散该远程攻势，近招移至自身队列末尾，未命中，不能因此生成云岚下一式；首次交锋双方已支付各自费用，该近招后续交锋及命中不再重复付款。平局双方结束。

## 交锋与费用账本边界

1. 选牌、排队和指定目标不付款；第一次实际交锋前检查目标、资源、技能条件、限次与冷却。资源不足的一招失效，另一招按正常条件继续；目标失效或尚未发动便被打断也不产生费用。
2. 双方各自第一次参与拼点时支付各自的招式费用，不论本次胜负；同一招式已支付后，后续拼点和落击不重复支付，也不应因余额已不足而要求重新付款。无对手而实际发动的招式也支付一次。此前“拼输免费”“破术免费”均已被用户后续明确指示覆盖。
3. 近招赢远术时压散远术并移至己方队尾；这次交锋按上述规则支付首次费用。再次破术、最终命中不重复付款。破术是否触发现有“施放”等心法及限次尚待定义。
4. 云岚生成临时追击时不付款；起式和各伪段共用同一张牌的付费凭证，原有费用暂以2体力试玩，伪段不额外付款。各段的共享施展次数、心法事件与伤害还需对齐现有体系并验证。
5. 守招待命不收费；第一次被调用参加拼点时无论胜负付费。连续闪避保留同一招，只付首次费用；已触发格挡的胜／平／负化解倍率仍需裁定。
6. 双方资格和实际费用须先同步核对；双方首次参加的费用原子提交，避免半边交易。原有资源转换、灵识占用、次数和冷却及效果副作用不能遗漏或重复执行。
7. 复命自身费用与复制招式费用是两笔不同来源；周天本身清炁回法，周天额外施放则依原条件单独支付。两者在手牌、牌堆及队列中的机会和时序尚待裁定。

### 费用方案对照与尚待裁定的边界

历史对照：独立工具 `tools/combat_fee_lab.py` 当时比较了「每次复拼付该次原费」和「同一招后续复拼付1点体力」。用户后续已撤回这两种每次复拼付费的方案，旧方案结果不能代表当前已确认规则。按1,000个随机种子并交换先手，每个旧方案各运行2,000场；两组中位战斗时长都是5回合、90%在7回合内结束。以固定示例中的同一侧计，每场复拼时付不起的平均次数由0.0225降至0.0055，每场体力总消耗由13.331降至13.173。

试验读取当前应敌、痛击、格剑、聚炁、惊蛰、云岚三叠的资源费用；角色属性、生命、每幕回体、容量占用、灵机、追加费用和敌我策略均为工具内明确标出的候选示例，并非正式数据。现有动作战斗是按经过时间和角色属性恢复体力，试验的每幕回复3点没有经过等价换算；闪避样本也不足以评价连续闪避。完整配置、来源文件哈希、种子和逐项付款日志可通过该工具复核。

继续试做时需明确：资源不足的失效牌去向；未触发的守招结束后去向；同速先后；多个队列同时指向一条队列时谁先交锋；同时参与多个动作时法力转换、周天和其他付款副作用的结算顺序。旧独立账本按每次交锋付费及另一版按实际生效付费均已过时，不可作为当前规则接入；新方案尚未接入真实战斗。

## 现有招式迁移范围

- 应敌、痛击为近战物理；灵击、惊蛰为远程物理。近远方式与物理／神魂伤害类型分别判断，不把远程默认当作法术伤害。
- 格剑继续以自身公式和剑道、体魄、神魂产生化解，应对时的剑意收益需与新交锋事件对齐。守御胜／平／负的化解倍率，以及与器物追加的顺序均为待测参数。
- 聚炁仍以明确效果产炁，达到现行阈值后周天；运转不参加攻攻拼点，但可被抢先造成的失神打断。
- 云岚原C／D／E概率与舒卷·逐影围绕原追加概率的效果，需要随逐式交锋重设计；没有批准前不能把旧概率或新效果冒充已迁移。多段的新费用、伤害和定力冲击均待独立对局验证。
- 局外相邻化法、周天指示和器物绑定须保留具体摆放身份；同招共享次数、冷却仍依据原招身份。丹药与符箓保留真实库存和消耗事务，不因抽弃洗牌复制。
- 已有精准、身法评分及身法状态、器物词条和存档的迁移尚未确定。新交锋应避免额外叠加旧自动闪避，但不得在未核对所有来源前静默删除现有数据。

## 平衡与验收

所有灵机范围、出手速度、容量成本、生命、定力、失神、伤害与重复费用均以候选配置测试，不将对话中的算例当作正式数值。测试覆盖真实云息层级和实际人物快照，跨大境界尚无正式资源数值时只标作假设；分别检查近远连续交锋、攻防、连闪、聚炁被打断、云岚逐式、牌堆循环、费用不足和目标离场。

以 `csharp/debug/CloudCombatSnapshotProbe.cs` 进场景树读取现有配置：构造角色的基础体魄、灵慧、神魂均为5，不带功法或装备，七层和十层使用100分凝核。云息一／五／七／十层体魄分别为6.375／20／28.825／28.825，现有生命上限为151／301／406／406，现有棋盘定力为103／152／199／199。当前八至十层资源未配置额外三维成长，故上述同条件样本七至十层一致；不同凝核、功法和装备会改变结果。现行棋盘定力每回合回满，新方案的部分回复尚未接入。

独立候选模拟分别使用一对五层、五对七层快照，每组每种费用方案2,000场：前者高层全胜、中位6幕，后者高层1,986胜、中位12幕。无功法样本法力上限为0、远术不可用，因此这些模拟无法对照近招破术的收费；伤害、灵机、抽牌构筑和回合恢复仍属候选，不能作为正式平衡结果。配置分别见 `tools/combat_fee_lab_cloud_1_vs_5.json`、`tools/combat_fee_lab_cloud_5_vs_7.json`。

另以实装已学首卷的《玄枢含章经》主修与《斫基损契玄经》辅修构造五、七层角色：两者初始法力均为1／1，惊蛰可用且当前正式费用为1法力。输入该快照的独立模拟每方案各2,000场，原额复拼与后续1体力复拼均为12幕中位；五层每场平均复拼付不起的次数从0.0255变为0.005，七层从0.0335变为0.0075。远术复拼出现次数仍少，工具未模拟两书额外施放、燃上限代付、护甲和会心，也未完整验证样本牌组学习资格；不能据此裁定费用。配置见 `tools/combat_fee_lab_cloud_5_vs_7_two_books.json`。

历史试验 `free_tail_check` 当时按近招破术免费、实际命中才付款建模，已被“首次拼点支付一次”覆盖。用上述双书五／七层快照各跑2,000场，跨层中位11幕、90%不超过15幕；同为五层时中位13幕、90%不超过16幕。同境界两侧分别胜1,057／943场；1万种子扩大样本后该偏差未稳定复现。格剑部分化解、连闪收费、每幕回复、牌组与AI均为实验假设，不能作为正式平衡结论。五对五配置见 `tools/combat_fee_lab_cloud_5_vs_5_two_books.json`；`free_tail_unchecked` 仅为故意违背资源门槛的反例压力试验，不是现行候选。

按最新指示另设 `first_clash_once` 试验：首次拼点双方付款、同一行动后续不再付款，近招破术后移队尾；已付款行动之后即使当前资源不足，仍可继续。使用上述双书五对五快照、1,000个种子及速度镜像共2,000场，中位14幕、90%不超过17幕；五对七中位11幕、90%不超过15幕。该次模拟将云岚每一伪段作为新行动独立付款，用户已确认整张云岚共用一次费用，故此结果需重新对照；格挡、AI、牌组和恢复仍是候选假设，不能直接修改正式生命或伤害。

`first_clash_shared` 改为整张云岚只付起式2体力：双书五对五2,000场中位12幕、90%不超过15幕；五对七中位10幕、90%不超过14幕。相同五对五候选条件下，每人每场云岚平均体力消耗约由16降至8.8、云岚累计伤害约由145／141增至155／150；相较样本303点生命占比较高，需检查套牌份数、多段伤害和中断机会。该比较还使用候选格挡、恢复和固定AI，套牌含快照未学习招式，也没有模拟两本心法，不能作为正式数值平衡结论。

以相同双书角色、每组2,000场对照每幕回体1／2／3：同境界对局中位分别为18／12／12幕，跨两小层对局分别为15／10／10幕。回2和回3在固定策略下接近，回1更容易出现没有行动的回合；这支持把已获用户同意的回2作为试玩值，但不证明其他构筑或策略下已经平衡。对照使用上述候选模型而非正式实战。

真实入口验收需要从人物或生灵既有战备盘开战，经抽牌、排队、指定目标、交锋结算至战斗结束并返回世界。需要同时验证身份守恒、化法指向、资源收据、敌方信息隐藏、运行数据与卡面／秘籍词典一致。独立计算器、模型测试或构建通过不能作为正式入口已完成的证据。
