# 灵台选行走位、射程与遭遇阶段规则

> 状态：2026-11-14，按用户授权确定的现行补充规则。本文补足真实格位、行动前走位、远程理想距离、射程、击退与多波遭遇；行选择、目标锁定、行动队列、逐招揭示、费用及应对仍以[灵台选行战斗规则](灵台选行战斗规则_20261111.md)为准。走位与击退已接入正常战斗流程，且原生入口烟测通过；多波与首领阶段仍未接入。

## 借鉴与改造

《废墟图书馆》把移动抵达和行动机会分开：低速度角色即使先抵达目标，也要等待高速度角色完成行动。本项目保留“走到目标旁不自动抢行动”，但出手先后由灵台招式值决定。[官方速度与抵达顺序更新](https://store.steampowered.com/news/posts/?appids=1256670&enddate=1597395459)

图书馆在目标于出招前死亡时取消未用战斗页并返还光芒。本项目沿用目标失效时不执行、不扣资源、不耗次数，但继续推进当前行，不引入手牌或光芒。[官方目标死亡处理更新](https://store.steampowered.com/news/posts/?appids=1256670&enddate=1592018480)

图书馆区分远程与近战招式的交互；本项目借用远程招式必须明示射程与运动方式，不搬入骰子、拼点、远程优先结算或速度骰改派目标。[官方远程战斗修正记录](https://store.steampowered.com/news/posts/?appids=1256670&enddate=1592561937)

本机逆向资料显示原作把击退交给六角格移动器处理，没有可直接套用的受击方体魄减距公式。本案击退公式是项目自有规则。

## 速度、位置与行动值

- 战场使用现有轴坐标六角格，每格最多一名单位。逻辑格位与人物画面位置必须同步；攻击冲刺等舞台演出不能改写格位。
- 六角距离由现有格距算法计算。相邻格称为“接敌”；接敌不冻结行动、不自动打断，也不触发借机攻击。
- 人物速度读取当前有效速度值，只影响移动。每回合初始移动预算为 当前速度 ÷ 80 格，小数在同一场遭遇内累积。例如速度80每回合走1格，速度100每回合平均走1.25格。当前灵台战斗中的人物读取遁速字段；生灵模板未配置速度时按80处理。失神时不行动；其他状态须明文限制走位才会生效。
- 一名单位在本回合的各招式行动前共用同一份移动预算。行动出手值不读取人物速度，计算为 80 × 招式节奏倍率 + 招式主属性加成。移动、先抵达或接敌均不改变行动队列。
- 走位以占格、地图边界和已锁定目标为依据；不穿过单位。被挡时沿最短可行路径绕行；无路时停步。首轮不设置地形移动成本、借机攻击或碰撞伤害。

## 每招行动前的距离调整

目标身份先于走位锁定；目标选择阶段不因距离太远而禁选。轮到每招时依次处理：

1. 确认招式仍可使用、目标仍存活且阵营合法，并且行动费用可支付。
2. 按该招式的走位方式使用本回合剩余移动预算；目标身份不变。
3. 按移动后的格距重新检查射程与其他目标条件。
4. 条件成立才支付资源、扣次数并结算效果；仍超出射程则跳过，不扣费、不耗次数、不启动冷却、不改选目标，随后推进本行。

目标在执行者轮到前改变位置时，执行者追踪的是已锁定的同一单位。前序行动若将目标击退，后续行动可使用剩余移动预算重新调整距离；无法进入合法射程就跳过。

招式新增走位方式字段 **battle_movement_mode**，值为 AUTO、APPROACH、MAINTAIN_RANGE、HOLD。AUTO 按招式用途判定：近战攻击接近至其合法射程；远程攻击维持理想距离；应对、自身行动及不需接敌的辅助行动停留原位。单招可指定其他方式覆盖默认值。该字段只控制走位，不替代射程、目标类型或效果。

新增可选字段 **preferred_range** 表示远程招式理想格距；未填写时取 range_min 与 range_max 的中点并向下取整。理想距离小于最小射程或大于最大射程时，按合法射程边界修正。

## 远程招式与非攻击行动

- range_min 与 range_max 以六角格距离为准，并含上下边界；range 为0表示自身或同格目标。attack_style 仅表示已有招式联动风格，不代替射程。
- 远程行动的默认走位策略是保持 preferred_range：距离太远就靠近，太近就拉开，达到理想距离就停。其调整按移动预算逐格执行；路径受阻时尝试其他空格。预算不足时，只要最终距离仍在合法射程内就照常出招，超出射程则跳过。
- 远程招式分为 **投射物** 与 **术法直击**。投射物有从施术者到目标的飞行演出；术法直击在目标处显现，不表现为实体弹道。范围作用由现有 aoe_range 表示，可与两种远程方式组合。首轮不加入视线遮挡、单位拦截或自动追踪；只有现有应对规则明确匹配时才产生应对。
- 本轮首批配置：狐火点名、惊蛰和炎矢符使用2–4格射程、3格理想距离；惊蛰为术法直击，狐火点名与炎矢符为投射物。近身攻击明确射程1格，武器突刺保留原1–2格；灵击等已配置射程的招式继续使用各自范围。未写 preferred_range 时按该招式实际射程中点取整。
- 辅助、治疗、运功及其他非攻非防行动沿用自身目标和射程，不因不是攻击而自动改成防御或移动。自身与无单位目标行动默认原地执行。
- 敌招仍在该招开始执行时揭示；走位不会预先公开敌招名称、费用或队列。远程弹道仅为演出，命中按招式开始时锁定的目标及移动后的距离结算。

## 击退

逐招新增 **knockback_distance**（体魄为0时的最大击退格数）与 **knockback_force**（冲击强度，与体魄同量纲）；两者默认0，未填写即无击退。计算为：

> 击退格数 = clamp(floor(最大击退格数 × 击退力 ÷ (击退力 + 受击方当前体魄) + 0.5), 0, 最大击退格数)

击退力与体魄之和为0时，击退格数为0。命中且未被闪避时触发；护盾吸收伤害不抵消冲击，完全化解或闪避则不击退。方向为远离出手者的最近六角方向；方向并列按固定方向顺序选择。遇边界或占格即停止，不推挤其他单位，不造成碰撞伤害、定力伤害或行动中断。击退位置立即用于后续行动射程复查。

首个配置招式为公共基础招式「痛击」：**knockback_distance = 2，knockback_force = 20**。目标体魄46.51时击退1格；体魄不高于约6.67时可退2格，体魄高于60时会抵抗至0格。其他招式未明确配置前继续使用默认0，不产生击退。

## 多波遭遇

- 一场遭遇可以配置多个波次。当前行动队列结束后，若当前波清空则部署下一波，再开始下一回合；不在其他单位行动中途插入新波或取消已排定行动。
- 新波在配置入口格部署；格位被占时移至最近空格，距离相同时按固定坐标顺序选择。无空格时等待，不覆盖现有单位。
- 跨波存活单位的位置、生命、护盾、状态、法力、体力和技能使用次数默认保留。遭遇配置可明确指定恢复或重置；未指定时不自动回满。
- 首领阶段阈值在当前行动队列结束后处理，保留存活单位和位置；阶段可变更首领状态或加入新单位，不清除玩家未执行的本回合行动。
- 所有后续波次与首领阶段结束且敌方全灭时判胜；玩家阵营全灭时判负。撤退和战利品仍按各自遭遇规则。

## 不采用的原作机制

不加入拼点、随机骰、速度改派目标、远程优先结算、格挡骰循环、借机攻击、碰撞伤害或自动追踪。原作场景间复位位置也不采用；本项目保留一场遭遇内的格位，让接敌和击退持续影响战局。

首轮代码已接入：每回合速度移动预算与小数累积、六角格占位寻路、阵形画面随逻辑格同步、每招行动前按近身／远程策略走位、走位后射程复查、按 aoe_range 以锁定目标为中心筛选范围目标、投射物与术法直击字段和演出，以及受体魄影响的击退。玩家招式悬停显示射程、理想距离、走位方式、远程方式和击退上限。击退不推挤单位；受阻或到达边界即停止。
