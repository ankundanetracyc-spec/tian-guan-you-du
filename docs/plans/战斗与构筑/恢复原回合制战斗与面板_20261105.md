# 恢复原回合制战斗与面板（当前）

2026-11-06：用户要求战斗允许自动，已在原分段规划战斗中提供可切换的玩家自动规划；默认手动，具体切换及服丹边界见[战斗主案](即时队列战斗系统设计.md)。此更新取代下文玩家仅自行规划队列的表述，不改变回合制结算。

2026-11-05。用户要求“回归原本的回合制战斗，面板等等相关改造，全部还原”。本次决定取代11月4日恢复即时动作及其后续技能、人物页改造方向；不再推进即时动作迁移。

## 现行规则

- 战斗恢复原有分段规划与时序行动循环，完整规则继续以[原战斗主案](即时队列战斗系统设计.md)和[三资源总案](design-plan.md)为准。玩家可手动或自动规划自己的队列，其他参战者保留各自AI队列；全场每次结算一个正常行动，所有队列完成后进入下一回合。
- 角色保留十个固定技能槽及空位；技能点击装配、卸下、拖拽移动或交换。技能学习资格、装备技能引用、玄枢第十槽的应对限制及自动触发沿用原规则。
- 体力每回合补给3点、基础上限6，余额保留；休整占一个行动位、回复2点体力。法力开战按容量初始化，跨回合保留，仅明确效果可回复。灵识仍为持续实体的占用容量。
- 原技能资源继续规定费用、目标、效果、使用次数和回合冷却；原心法与显式绑定化法恢复人物页操作。即时版的拳掌四段、错步、秒冷却、持续回体和五槽不能覆盖原技能。
- 不新增资源、属性、关键词、射程或位移，不添加零费、返费、抽牌、额外行动或资源生成，不把任何回合规则折算成秒。

## 人物页与入口

人物“战斗”页恢复已学技能、两排十槽和化法侧栏，直接读写原`combat_skill_references`／`combat_skill_slot_paths`与`skill_rewrite_bindings`。造诣图谱及已参悟进度保留，未因即时版未适配而屏蔽的原技能重新可装配。

人物“属性”页恢复行动速度、原有战斗属性与遁速布局；基础属性悬停恢复其对行动速度的作用，体力说明恢复轮次补给与休整。撤下战斗移速235、自动恢复0.5、独立行旅区和当前角色即时演练入口。

首页保留原自定义战斗、秘籍与队列入口，撤下即时自选秘籍对练、人类陪练、六招凶狼、血浪NPC和俯视动作对照入口。正式世界遭遇、切磋、战前页、战斗场景、撤退、结算及回传继续使用保留的原战斗管理器。

## 资料与存档

即时动作的独立实验工程、素材和图谱保留为历史资料，不再作为当前玩法依据或从首页进入。人物页不再包含即时装配实现。旧档中的独立五槽字段保留读取兼容，不将其截断、覆盖或迁移为十槽，不清除原技能、化法和人物成长。

地图、立绘、衣装、行囊、炼丹、炼器与其他独立改动不属于本次战斗迁移撤回范围。战斗仍可复用已有美术资源，不凭资源所在的实验目录改变结算规则。
