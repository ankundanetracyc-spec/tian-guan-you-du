## 一、目的与边界

角色战斗页提供“技能库／造诣图谱”两种查看方式。技能库继续负责搜索、来源筛选和十个战斗槽的装配；造诣图谱按脉面展示节点，面数与面片大小由配置内容自然扩展，不构成固定多面体。当前展示气血、纳炁、神魂与剑修四面。选择脉面后，显示该面节点；若节点直接以前置关系连接其他脉面，则交界节点会出现在相关面中，并同时显示其前置节点。点击节点后，侧栏列出关联脉面、前置节点、所授技能、属性与造诣要求及参悟入口。现有丹霞养元、太虚纳炁、灵台观照三根保留各自节点 ID、坐标、门槛与效果；剑修四招均属剑修本身，由“剑式初传”一个无前置节点统一解锁，不依赖气血、神魂或纳炁根节点。节点名称用于表达修行脉络，不要求与其授予的招式同名。参悟技能仍须由玩家手动装配。

造诣图谱授予的技能按人物记录，不扩大所有角色共用的公共基础技能池。公共基础技能池仍只有应敌、架招、痛击。节点解锁记录使用稳定节点 ID 随人物存档；旧存档字段为空时视作尚未参悟任何节点。

解锁只检查该节点配置的前置节点、体魄／灵慧／神魂和相关造诣。节点不收点数、灵石、贡献、物品或时间。原有气血、纳炁、神魂三根保持无前置；剑修以“剑式初传”为无前置根节点，一次解锁四招。

四招的“剑”用于展示、检索，以及供明确引用它的心法或剑器效果匹配；不单独产生额外效果。关键词数量暂不设上限；格剑同时标注效果涉及的“化解”“剑意”和“应对”。

`剑意`为战斗状态，上限10层，战斗结束清除。养锋获得2层、格剑获得1层；尽锋只在命中后消耗全部剑意，未命中时保留。剑意每层为尽锋伤害增加4点。

“催血”只把节点本体的气血量设为 2；各秘籍原有的“催血”化法变体保留自己的效果。运行时按节点基础技能资源路径区分本体与化法，避免波及名字相同的变体。

“聚炁”沿用[云息公共战斗状态与秘籍构筑规则](云息公共战斗状态与秘籍构筑规则.md)：炁不是法力或费用；炁达到当前法力上限两倍时立即清除炁、恢复法力至上限并结算一次周天；超额炁清除，单次获得事件最多结算一次，法力上限为 0 时不触发。炁于新战斗开始时清零。

“寄念”沿用公共念规则：念记录在技能实例上，同一技能重复占槽共用记录；不随时间或行动消退、不因施展而消耗，战斗结束清零。寄念只赋值，不凭空增加该技能的伤害或其他效果；只有明确读取念的技能才使用它。下一招判断跳过已完成、法器和寄念本身；若找不到不同的后续主动技能，则在扣费和行动结算前跳过。

## 三、角色界面

- 战斗页顶部提供“技能库／造诣图谱”切换，切换不重置已装配技能、筛选以外的角色状态或存档。
- 脉面选择区使用不规则墨线多边片，片宽随该脉面节点数量有限变化；面片过多时可横向滚动。该图形只表达彼此相接的脉面，不假定面数、角度或规则多面体。
- 节点仍使用既有水墨框：`textures/ui/skill_nodes/skill_node_small_ink_circle_v1.png` 用于至多一个前置节点，`textures/ui/skill_nodes/skill_node_multi_ink_circle_v1.png` 用于两个或更多前置节点。节点框内只显示节点名与参悟状态，不放技能图标；图面不显示中心枢纽，根节点也不连接到装饰性中心。节点之间只按实际前置关系连线。配置中的节点坐标仍表示主体区内的节点中心位置；三个原有根节点坐标不变。节点图可用滚轮、中键纵向拖动及“－／＋／复位”按钮缩放，右侧参悟详情保持固定。
- 每个节点配置一个所属脉面。一个节点所属脉面与其直接前置节点所在面不同，即视作跨面交界节点；它会同时出现在涉及的脉面中，来自其他面的直接前置节点以弱化样式显示。节点图面显示节点名和参悟状态；侧栏列出该节点授予的全部技能、涉及脉面、前置状态、当前属性／造诣与门槛、不可参悟原因和按钮。条件不足时仍可选中查看缺项；条件满足后可直接参悟。
- 成功参悟后，该节点授予的全部技能加入人物可用技能目录与技能库；不会自动占用技能槽。节点页再次打开时显示“已参悟”。
- 战斗中炁以可悬停的资源徽记显示在角色状态栏；念以小徽记显示在实际附念的队列技能上，队列详情同时显示层数。敌方队列只有在技能情报对玩家可见后才展示念。

## 四、原型门槛与调整原则

当前原型按云息普通修士的属性和造诣量级设置。门槛集中在 `resources/skill_nodes/公共技能节点网.tres`，只为解锁节奏服务；不是属性成长的新来源，不影响战斗公式。三个原有根节点的配置保持不变；剑修节点门槛供后续战斗体验校准。

## 五、实现验收

1. 角色战斗页可切换技能库与造诣图谱；脉面按配置生成，切换时只展示所属节点与相关交界节点，节点大小随前置数量选择，侧栏明确显示关联脉面、前置关系和门槛。
2. 未满足门槛不可解锁；满足后参悟一次成功并持久保存，重复点击不会重复授予。
3. 解锁技能出现在人物技能库但不自动装配；角色间解锁状态互不影响；公共技能池仍保持三项。
4. 催血只对节点基础技能授予气血 2 层，化法变体继续保持配置的效果；聚炁从 2 炁正确触发周天；寄念对不同后续技能赋 1 念，无后续时不扣资源；参悟“剑式初传”一次习得斩剑、养锋、格剑、尽锋，养锋与格剑获得剑意，格剑只应对敌方物理攻击，尽锋命中后消耗剑意并正确计入物理伤害。
5. 战斗队列可见技能实例念层数，未揭示的敌方技能不提前泄露；炁资源显示当前值与周天阈值信息。
6. 进行项目构建及相关场景检查；不安排人工试玩。
