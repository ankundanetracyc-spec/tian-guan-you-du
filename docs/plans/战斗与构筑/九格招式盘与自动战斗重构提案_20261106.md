## 一、玩家体验与已确认方向

玩家把自己会用的招式，以及已具备资格的化法和实际持有、允许战斗使用的物品，摆进同一个招式盘。开战后角色自动行动；走到招式占格时检查费用、目标、次数和该招原有条件，满足即可触发，**不额外设置通用招式蓄势或倒计时**。单体攻击自动从合法敌人中随机选择目标，不要求玩家手选。

**每一份已摆招式的每个实际占格各检查一次，每份每回合最多成功发动一次**；一份若在第一格不满足，之后另一占格满足时可在后一格发动，一旦成功则该份后续占格本轮不能再成功发动，最后占格过去后不额外补查。不同招式或同一招的不同摆放份数，各自具备发动机会，不设角色级的回合总出手次数上限。每个招式各有可同时摆放的份数上限，具体数值待设计；某些招式还可有总使用次数，同一角色同一招摆出的多份共享该总次数，耗尽后均不可再用并显示变暗；不同角色分别检查各自的次数。不是所有招式都必然有总次数限制；总次数何时恢复仍待确认。

用户已确认采用应对方案 A：扫到应对招式后，该份进入待命，直到应对成功或所有参战者完成本回合遍历；在此之前受击且符合该招原条件时可发动，未触发的待命不带入下一回合。多份待命应对都符合来袭条件时，按盘面**从左到右、从上到下**的顺序选择；不符合攻击类型、费用等条件的候选不应被当作成功发动，同一次攻击至多成功触发一个应对。成功应对计入该摆放份本回合一次的发动机会，并消耗该招实际存在的共享总次数；仅进入待命不算发动。

用户决定**所有心法不再自行发起自动应对，其他心法被动保留**；例如太和心法仍可响应招式造成的真实应对。百骸旧心法中的双臂自动应对及其附随的本次化解、应对后气血回落不再触发，但显臂、近身攻击追加、主修加成、公共气血回落规则和架招化法均保留。该决定与旧主图及现行队列运行存在差异，新系统尚未实现；正式迁移时须同步图谱、展示、资源及事件链，不能直接删掉其他应对被动。首项概率判定失败后是否继续、群攻多受击者口径仍待确认。现行个别技能已有冷却、次数和特殊触发，必须逐项审阅，不能把取消通用蓄势误读为自动删除这些原有限制。

每个角色按自身盘面从左往右、从上往下遍历；人物沿旧**行动速度**的独立进度条推进，到点处理自己下一整行，速度较快的角色可连续处理多行。招式本身没有额外通用蓄势条。所有参战者完成本轮遍历后，若战斗继续，可在回合间整理；用户已允许换入本人已学招式和补入本人真实丹药、符箓。战斗提前结束则按终局检查收尾。已使用物品、已结算攻击与应对不会因整理回滚。

每共同回合开始仍为符合条件的角色补给 **3 点体力**，基础上限 **6**，余额保留；遍历没有放置任何对象的真实空格还会额外回体。每空格回复量仍待结合成长盘面和具体占地平衡，不能把旧24格样例直接拿来使用。法力继续按现行周天及明示效果回复。器物启用、御使持续D与器术临时T按[本轮统一规则](../物品与装备/统一器物摆盘与手持御使规则_20261107.md)审阅，不照抄测试常量；旧正式运行仍按原生命周期。

## 二、极早期九格构筑和化法示例

以下仅以 `3×3` 展示关系；催血和应敌暂按 1 格演示，并非已定尺寸。回春丹沿用现行行囊**一瓶 1×2**，图中上下两格是一瓶，不是两颗。假设角色已经学会催血、具有可用的百骸对应卷化法，并确实持有可战斗使用的回春丹：

```text
┌─────────┬─────────┬─────────┐
│  应敌   │  空格   │  回春丹 │
├─────────┼─────────┼─────────┤
│ 化法 → │  催血   │  回春丹 │
├─────────┼─────────┼─────────┤
│  空格   │  空格   │  空格   │
└─────────┴─────────┴─────────┘
```

中间化法只指向紧邻的催血这一份；如果其来源和原适配条件成立，则为催血附上该化法原有追加。化法块自身不是一项自动出招，也不是空格；箭头只决定对哪项技能附化，不改变该技能的战斗目标。遍历到催血占格时仍须检查自身条件、费用和次数，原有追加也仍检查原有触发条件。示例中的图标摆放不授予未学技能、未启用化法或额外物品。

同一个两格招式的任一占格若与箭头相邻，建议识别到同一个技能对象，不因占两格重复追加。方向先建议以四个共边方向表达；朝向、旋转及无合法目标时的具体操作仍需确认。多项不同来源化法作用于一个技能时，沿用各自兼容、累积和替代规则，不把原本需要替代的效果叠加，也不额外发明统一费用或叠加上限。

## 三、全新战斗界面与选招流程

用户允许旧战斗 UI 整体重做。以下是新版的信息与操作建议，具体布局以独立可点击原型和视觉稿为审阅对象：

用户已指定布局：布阵时右侧显示招式／物品来源列表，中间显示招式盘；右侧不显示“招式列表”这几个大标题字，直接从分类／搜索及单项条目开始，不撤去选招能力。方案改为按钮，点击进入独立子页，选择合法方案后直接覆盖当前盘；建议子页在右栏内切换，覆盖后返回选招页。局外保存的自定义组合与推荐布局均可套用，仍可调整单项。详见[方案与装配职责](布阵方案与一键摆盘设计_20261107.md)。开始战斗后右栏及子页隐藏，中央编辑盘收起，招式盘缩小放在左下角；回合间再次整理时恢复。局内使用暗色控件和柔和灰米文字，详情仅悬停，常驻右侧详情与亮纸底退出新方向。[最新范围标记与方案子页理想图](../../美术规范/局内战斗布阵与开战理想图_20261107/README.md)供用户审阅。格距仍以行囊小格作参考，两种显示尺度由控件实现校准；此前浏览器的 40／32 像素只是上一轮展示记录，不锁定新的中央盘或战斗缩盘尺寸。

1. **自动战斗**：中央保留战场演出；界面同时清晰呈现当前回合、双方生命及关键状态、人物行动条、己方招式盘、逐格检查与实际触发。有限次招式用尽后，对应招式的所有摆放份数变暗并显示原因。对方未洞察的构筑和私有位置不能提前显示；可查看战斗记录和暂停，不要求逐招操作。
2. **申请整理**：玩家在战斗中请求整理；本轮继续按既定时序运行，所有参战者遍历结束并处理应有结算后进入整理。可选每轮自动停下以便观察是界面候选，不作为已经确认的强制操作；如果本轮战斗结束，则进入结果，不提供事后战中整理。
3. **挑选方案或来源**：右栏默认提供“招式、化法、丹药、符箓、法宝”来源及搜索／筛选，只撤去大标题；方案按钮进入我的方案／推荐布阵子页，选择后整体校验并直接覆盖，缺项不静默替换，不再另点应用。临时调整不覆盖局外原方案。招式读取本人实际学习、开放状态和使用资格；化法读取真实来源及主辅修／分支资格；物品显示真实可用库存、品质与使用条件。法宝范围强化与合法受益标记分别显示，不凭相邻或图标生成未定义效果。
4. **摆入与调整**：选中或拖动对象按真实候选形状跟手；落点预览明确占格、越界与重叠，招式列表显示该招当前已摆份数与其摆放上限。名称、费用、效果等通过暗色只读悬停卡查看，不再固定占据右侧一栏；拖拽时收起悬停以免遮住落点。指向化法时显示被指向的真实招式及合法原因；确认布局后再应用，取消、无效位置和中断不产生费用或库存变化。方向箭头、次数、名称和费用是界面覆盖层，不烙进透明图标。
5. **继续战斗**：确认后从下一共同回合按新布局运行。移动和更换不刷新原技能身份、已用次数、旧冷却、念及化法来源，也不复活消耗过的物品。每份招式按自身实际占格逐一检查，每份每回合最多成功发动一次，不因条件变化额外回看已走完的占格；同招的总次数在多份之间共享，不能通过换下再摆入刷新。整理时换入新的一份如何继承该轮已用标记及其他实例状态，需要结合回合边界和旧技能逐项审阅。

当前普通行囊的本人真实库存与储物戒内容有不同访问规则：现行戒指内物品需先取回普通行囊才能编入战备。用户允许补入“已有丹符”不自动确定是否可直接从戒内补入；须把这一差异标给玩家并确认是否变更容器规则。旧每人 3 战备位／每位最多 5 件同种物品，与新盘逐件占格的关系也仍待裁定。

## 四、招式图标方向与规格

已查看《造化仙缘》[Steam 官方页面及截图](https://store.steampowered.com/app/2377930?l=schinese)：其术法列表图和摆在丹田格子中的跨格主体属于两层不同展示。参考点是**术法意象有清晰独立轮廓、不同形状与格子直接对应**；本项目重新原创拳掌、剑意、气旋、护持等技能意象，不复制其原图、深底图框或强泛光。

颜色、材质和线条以本项目[行囊图标风格](../../美术规范/行囊全物品图标与占地_20261029/风格定稿.md)为准：透明底、单个完整主体、柔和水墨淡彩、克制体积明暗；不画固定纸底卡片、整张人物肖像、统一玉牌或会暗示未有装备要求的拳套。图像表达招式意象，不意味着获得、消耗或装备了一件实体物品。

现行行囊素材按每格 **128×128 源像素**，主体留约 12% 安全边距，界面既有基准为 48 设计单位／格。新战斗 UI 可为可读性采用独立显示缩放，但需保持图标等比和清晰度，不由透明边缘反推真实占格：

| 候选占地 | 对应源画布目标 | 展示边界 |
| --- | --- | --- |
| 1×1 | 128×128 | 图案与该格匹配；不缩进旧 3:4 卡图 |
| 1×2 | 128×256 | 竖向完整动作或器形构图 |
| 2×1 | 256×128 | 横向完整动作或器形构图 |

是否允许每个招式旋转、旋转后图像是否与占地同步，应结合实际对象设计确认；不能沿用上轮“只旋转框、卡图恒竖”的旧候选冒充已决定。现行丹药仍为独立真实瓷瓶 1×2；符箓若缺少正式战斗规则或形状，须标注未开放而不虚构数据。样张、具体逐招尺寸及其视觉辨识需人工审阅；源画布目标不代表已经批量制作正式 PNG。

## 五、器物统一入盘：手持、佩用与御使

用户明确手持必须入盘并读到后生效。最新[完整器物方案](../物品与装备/统一器物摆盘与手持御使规则_20261107.md)推荐取消独立战斗装备位：手持全盘最多一件，佩用承接护具／饰品的明文能力，御使可多件但需持续灵识。都从待启用开始，扫到实际占格才检查；成功后跨回合保持，多格不重复登记收益。

本案推荐器物启用体力0／法力0，御使另提交本件实际持续D；启用不自动攻击、治疗或回蓝。御使提供范围法效，确有主动能力时授予另占格的器术，扫到器术再检查其真实费用、T、目标、次数与冷却。器体保留但不独立跑行动条；普通角色目标池与明文允许的器物目标池区分。这些是新方案的明确取舍，不称旧御用费用或目标完全不变。

器蕴统一只计已启用盘中真实器物，手持、佩用、御使按实例去重；未读到、停用、器术或分体不多计。范围预览和实际受益标分开，覆盖到多格招式只强化该份一次，范围内真空格仍回体。新同模式挪位保状态，换入／换用法重读，次数／器体不刷新。

旧四槽、装备与盘面并集和仅盘中启用三种来源不能同时运行。旧十槽、装备引用、成器快照、特殊第十槽与真实主动能力均须按专题迁移，不删实物、不假补能力，具体物品数值继续审阅；本轮只定规划，未改正式战斗。

## 六、旧系统迁移与验证

- 从已有学习、原十槽、化法绑定、装备实例和战备生成只读预览；九格容不下的对象列为待摆放，不删除、降级或改写旧存档。
- 将每个可用化法的真实来源转换成一个可摆放对象；旧绑定仅作迁移记录／回退来源，新旧两条路径不能同时加成。目标不邻接、源失效、原绑定不再适配或空间不足时明示原因。
- 玄枢的原第十槽周天施展、焚元“后续队列技能”、百骸三四卷相同追加去重及太和主图／技能资料中应对计数差异须逐项裁定。旧周天自动施展或其他追加施放若会使同一摆放份本回合第二次成功发动，须按用户刚确认的每份次数限制单独核对；不能擅自增设例外，也不能未经确认删除原效果。技能内部的追加伤害段不因名称相似就视为重新施展。用户已决定恢复太和第一、二卷化法；现有主图和资源尚无这两项，具体目标、效果和数值须另行设计并确认，不能凭旧汇总表直接补造或宣称已实装。
- 设计稿阶段核对 1–2 格招式与真实物品尺寸、图标透明和相邻指向；实际实现前须进一步核对资源、费用、目标、原关键词和状态、每次触发及 0 费／返费／抽牌／额外行动限制，验证图谱、展示、运行一致。
- 自动战斗试验需覆盖快者连续处理多行、双人／多人、同一多格摆放份逐格检查、每份每回合至多成功一次、同招多份共用总次数及耗尽变暗、最后占格后不额外补查、空格在招式前后与体力上限、应对、周天、真实丹符一次性扣除、器体与 D/T 清理、死亡／撤退／战后回传及旧档回退。具体平衡需真实测试，不能仅凭九格示意宣布完成。
