## 一、一个化法块做什么

建议把已存在、当前来源合法的每项化法表示为独立的 `1×1` 盘面对象。它不是一次性丹符、不是独立施展的招式；不因遍历到该格而额外触发一次技能、回复空格体力或凭空获得资源。该格已有对象，未指向目标或来源暂不可用时也不是空格。

以紧邻为基础，建议箭头从自己的格子指向四个共边方向之一：上、下、左或右；方向与旋转方式仍待确认，不能擅自将对角、隔格、穿过别的对象的直线或整排都解释为有效。箭头所指的邻格如果属于一个已摆放且满足该化法原有适用范围的招式，则候选为这**一个**招式附上原有追加或改写；邻格为空、越界、是丹符／其他化法或不符合适用范围时不生效，不继续越过它寻找下一个对象。

对占两格的招式，建议箭头碰到其任一实际占格均识别同一个招式身份，不能因它占两个格子重复追加；朝向只决定哪个招式被改写，不能擅自改变技能的敌我目标或攻击方向。是否允许同一源重复摆放、一个目标接收多项化法及不兼容时的反馈见第三节。

化法附着只决定“原有效果有机会作用于哪一招”。实际效果仍由原有技能施展、应对、命中、资源、层数和次数条件决定；例如原本要触发应对、抵消伤害或消耗气血的效果，不因箭头接上就提前结算。现行化法绑定本身不新增统一体力、法力或灵识费用；原文明确存在的施展条件、代价与次数依原有效果保留，不能因为变成盘面对象而新增收费或免去原代价。

## 二、三行三列的示意，不是最终盘面规格

以[百骸第一卷化法](../../秘籍词典/md/百骸衍枝化生宝册.md)和[现行催血](公共技能节点网与首批节点实施.md)为例，假设该角色已按原资格学会催血、已学百骸对应卷且化法来源可用；图中催血仅**假设**占一格，真实形状未在本例确定：

```text
第1行   [空格] [百骸·养络 →] [催血]
第2行   [空格] [    空格    ] [空格]
第3行   [空格] [    空格    ] [空格]
```

箭头指向紧邻的催血时，建议系统展示“已作用于催血”。遍历到该份催血的占格时，按其费用、目标和条件检查并施展；只有施展前自身气血不高于原化法规定门槛时，才结算该化法已写明的气血追加。把箭头转向空格或换成不适配的招式后，下一次新布局生效时显示未作用；**不能把已获得的气血倒扣**。这不是给催血另造一项临时新效果，也不意味着摆下化法立即发动催血。

若箭头指到一个两格技能的任一占格，仍识别该摆放份整体，化法只附着于这一份，不复制化法来源。遍历时该份的两个占格分别检查能否施展；实际施展是否触发化法追加，仍须核对该次施展与原化法条件。同招其他摆放份不会仅因同名自动获得这项指向加成。招式的实际尺寸、化法旋转和空格回体数在本示例中尚未确定。

## 三、来源资格、重叠与冲突

1. **来源资格**：现行主修的已学卷章可用；辅修须启用相应卷章的化法分支，未装备／未启用来源只可查阅且不生效。用户说“已经学会的配置”是否同时放宽此项主辅修资格，尚未确认；保留原资格是迁移候选，不把任意已学未启用来源默认为可用。
2. **技能范围**：当前秘籍化法按明确的原技能路径／身份和已配置的匹配条件适配；不能凭文字含“剑”“应对”或相邻自动扩展为全部同类技能。未来若要设置真正的关键词范围，须有明确配置、玩家文案和运行支持。
3. **同源与多源**：建议同一角色的同一化法来源最多摆出一份，移动或旋转仍是同一来源。不同来源若原规则兼容，可共同指向一个目标，按现行可追溯的合并与结算顺序生效；是否对空间关系另设统一数量限制需确认，不得私增一个削弱已有构筑的隐藏上限。旧内炼器物对同一技能不得绑定第二件内炼器物的原限制仍须单独审阅。
4. **已有重合效果**：百骸第三、第四卷均针对架招，第四卷文本含第三卷的第二臂额外化解；现有实现对第三／第四卷该部分使用同一条件检查，不能因摆出两块而重复得到相同一份加成。其他明确写明替代、不叠加的化法保持各自规则；可累积内容不因“只指向一个招式”被一概删除。
5. **效果时钟和不回滚**：每次施展附带的化法在实际事件中按原次数、条件与代价结算。回合间更换位置或目标只能影响后续有效事件；已造成的伤害、已支付的费用及已经授予且按自身时长持续的状态不倒算。建议每回合／每场限次按稳定化法来源保留，不能通过换格或取下再放回刷新。

是否允许盘面保留没有合法邻接目标的化法块，及此时采用普通放置加“未作用”提示还是禁止确认，待用户决定；无论哪种方案，都不能悄悄把化法切换到别的技能。箭头旋转、多个合法来源的展示、目标变化及盘内可见范围必须由同一份规则生成预览与实际结果。

## 五、器物化法与法宝参战

法宝入盘并提供范围强化的方向已经由用户确定，见[完整规划](../物品与装备/法宝手持与范围强化完整规划_20261107.md)；不再以“主动入口是否入盘”作为当前主问题。现行旧器物化法包括旧内炼实例和新成器快照，旧系统仍按真实来源及原绑定运行；新盘转换前不能直接扩大原效果范围或生成多个来源。

新完整候选建议将器物的旧绑定化法整体归入本件盘面法效，不为同一组收益再额外生成秘籍式化法块。适用条件、加成与覆盖数量须逐件审阅；原数据和绑定保留供迁移／回退，不能既让旧绑定生效，又免费复制为群体强化，也不能擅自丢失旧收益。该建议不改变秘籍化法指向一个合格目标的边界。

## 六、旧档迁移和战中换配置

现行人物的 `HumanData.skill_rewrite_bindings` 保存秘籍及新成器来源到原技能身份的绑定；旧内炼器物还保留各自 `bound_basic_card_path`。来源 ID 包含秘籍资源、卷章及配置序号，器物来源使用真实实例。现行运行时解析技能时，以确认绑定生成效果副本；这是**旧系统的已实现事实**，不是新盘已经完成的实现。

建议迁移分为可回退的两层：先读取但不覆盖旧技能槽、旧化法来源与目标；再生成可供玩家调整的盘面草案。若真实可用的化法和原目标能在候选盘中合法相邻，草案可展示该可能连线；放不下、来源失效、目标不存在或无法摆成邻接关系时列出“待处理”，不能自动补书、释放技能资格、删除旧绑定或捏造加成。九格容量小于旧配置可容纳的组合，尤其不能保证一张旧技能和其多项化法都能同时摆下。

仅在用户确认切换并接受盘面方案后，由新盘的来源与方向建立新系统中唯一的生效关系：旧绑定作为备份／旧版本回退数据，不作为第二份效果再应用。新方案取消、读取失败或回退旧战斗时，旧字段原样保留；两套数据的保存版本及正式转换时机仍待专门设计。

建议整理时可以移动、旋转或换入已具备资格的化法对象；新布局确认后在下一回合使用，战斗中动作与其嵌套应对结算期间不改方向。化法从有效指向变为无效时停止后续改写，不洗掉原限次或撤销已经生效的状态。化法能否不与目标一同带入、移出目标后的保留策略、以及 NPC 如何使用自己的真实来源，均需用户确认。

## 七、验证与待确认事项

- 验证来源确实已学且主辅修资格合法；化法 `1×1`、紧邻唯一目标、横竖多格招式命中其任一占格只作用一次；不符合范围、指向空格或越界时不误加成。
- 验证多个兼容来源、百骸三／四卷重合部分、旧内炼排他及其他明确替代关系；保留原费用、技能目标、关键词、状态、触发条件和每轮／每场限制，不引入新的数值或资源。
- 验证移动、旋转、来源失效／恢复、战中换入与撤回，以及每轮限次不能洗掉；已生效的效果不回滚，预览、详情与实际结算一致。
- 验证旧槽与 `skill_rewrite_bindings`、旧内炼实例及原技能路径读取和回退；新旧两种绑定不能重复生效，未能容纳的来源与旧目标不丢失。
- 待用户确认：方向是否限四个共边方向与如何旋转；没有合法目标是否允许保留；主辅修／分支资格是否放宽；多个来源和器物化法的具体盘面规则；玄枢旧第十槽与焚元“下一项”迁移；太和前两卷新恢复化法的具体目标、效果和数值。恢复方向已确认，不等于效果已经确认或资源已接入。

以上均为可审阅的设计边界，尚未编译或接入新盘；正式实施前仍须按项目卡牌流程核对具体效果、费用、目标、状态、0费与资源循环限制，并运行相称的场景及存档验证。
