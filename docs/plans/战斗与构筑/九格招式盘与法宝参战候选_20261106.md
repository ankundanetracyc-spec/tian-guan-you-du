> **2026-11-07转为上一轮历史候选。**用户已指定法宝入盘、强化范围内合格招式并显示受益标记，且只允许一件手持法宝；因此下文“装备在盘外、主动入口入盘”的A方案不再是新版主推荐。最新综合建议见[法宝手持与范围强化完整规划](../物品与装备/法宝手持与范围强化完整规划_20261107.md)，方案按钮／子页见[布阵方案设计](布阵方案与一键摆盘设计_20261107.md)。下文保留旧器物实现事实和当时比较，不继续作为新盘待选入口。

## 一、先分清装备、御用与御使

- **装备**：真实器物先存在本人行囊并按当前装备规则装上。该器明文配置的装备收益按其真实实例生效；普通装备和手持本身不占灵识。仅有“剑”字或剑图案不自动获得任意装备的锋锐，实际用剑来源和技能须匹配。
- **御用**：有可召出能力的器物，符合来源、体力、法力、灵识等条件并成功结算后建立该器体；器体在场时持续占用灵识 D。装备本身不等于已经召出。
- **御使**：器体在场后使用其对应主动能力；按该能力原模板检查费用、目标、次数、冷却和施法时临时占用 T。施法结束释放本次 T，不释放仍在场器体的 D。
- **直施／借器**：有明确直施能力的器物可按实际模板直接施法，不强制先召出器体。器物没有对应能力时不凭名称、图标或品质免费生成主动招式。

以上不是“法宝 = 一次性物品”：法宝实例、装备和单场在场状态有各自生命周期；丹药、符箓是对应真实物品按各自规则实际使用后的单次消耗。法宝并不会因为一次御使就像丹药那样扣掉一件。

## 二、三种占格方案

| 方案 | 玩家如何使用 | 对九格及空格回体的影响 | 主要取舍 |
| --- | --- | --- | --- |
| **A：装备在盘外，主动入口入盘（推荐候选）** | 先装备本人真实器物；确有主动能力时，将该实例的“御器印”或其他明确标识的主动入口摆入招式盘。它是指向真实器物的使用入口，不是制造第二件实物。 | 入口按最终确认的形状占用盘格，并与招式、化法、丹符竞争位置；所占格不是空格，不能回体。装备的被动收益仍按装备规则生效，不因该入口是否入盘重复计算。 | 沿旧“主动御器占技能位置”的方向，空间选择直观；入口形状、是否可改向、是否能战中换入仍需确认。 |
| B：法宝主动入口放独立区域 | 装备的器物有一个不占招式盘的主动入口。 | 九格里保留更多空格与可能的回体；法宝和普通招式不再竞争同一空间。 | 方便早期使用，但相对于旧技能位增加了盘外主动入口，可能使装备者同时获得额外主动能力和更多回体机会，须重新设计约束与平衡。 |
| C：真实法宝按行囊占地放入招式盘 | 把真实器物本体依其行囊形状放进战斗盘。 | 实际占地越大，剩余招式、化法、物品和空格越少；若物品占地超出整个九格则不能放置。 | 在视觉上很像行囊，但现有炼器验收中已有需要连续 `3×6` 行囊空间的成器样本，比初始九格总面积更大；直接照搬会造成根本放不下。缩小实物占地、扩盘条件或允许部分摆入均是新规则，不能自行确定。 |

对空格回体的比较必须考虑实际摆放：若方案 A 的入口占 `q` 个**原本为空**的格子，其他对象保持不变，它就少 `q` 个可回体的空格；每格名义回复用 `R` 表示时，最多少 `q×R` 的名义回体。实际少多少还取决于体力上限、消耗及遍历顺序；`q`、`R` 均未确定。这不是额外的灵识费用，也不是每轮出手次数上限。

## 三、九格的关系示意

下图采用 `3×3` 只是为理解位置；**没有为法宝入口指定 1 格或任何其他具体占地**。每个方框只标一类对象及方向关系，实际对象能否放下须根据最终占地重新排布：

```text
┌──────┬──────┬──────┐
│ 空格 │ 化法→│ 招式 │
├──────┼──────┼──────┤
│ 丹药 │ 御器印*   │ 空格 │
├──────┼──────┼──────┤
│ 丹药 │ 招式 │ 空格 │
└──────┴──────┴──────┘
* 上下两个“丹药”共同代表一瓶现行 1×2 瓷瓶，不是两件；“御器印”代表本人实际已装备器物的主动入口，图不规定其占格。
```

化法占一格，指向紧邻的一个合格技能，并按该来源明确的适配条件作用；图中的“化法→招式”不是规定所有化法都能修饰所有招式，也不表明该器物自动有化法。器物自带化法与其主动御器能力可同时存在；若将器物化法也改成单格指向，需要逐来源确认资格、来源失效、允许叠加和绑定迁移，不能因两者源于同一实例就误认为复制器物。

## 四、推荐候选的行动流程

以确有御用能力的已装备器物为例，以下仅说明接口，不为该器补造费用或伤害：

1. 战前或允许的战中整理时，选择本人的已装备真实器物对应主动入口并放入盘中；该入口持有唯一器物实例来源。战斗中是否允许将**原本未装备**的物品直接换装、所需时间及收益交接，需要另行设计，不能把“能补真实丹符”扩展为已确认的临战换装备。
2. 按新战斗确认的角色行动条和行遍历检查该入口的实际条件；入口具体如何逐格检查尚待确认。尚未召出时，选择该器真实模板的御用分支；若目标、费用、可用灵识或其他条件不满足，不伪造召出结果或先扣不该扣的资源。
3. 召出确实成功，建立器体并登记持续 D；同一个入口显示为该器在场御使分支，**不再额外制造第二个御使格**。之后何时进入御使、能否同轮再触发，须由新节奏规则明确，不能因切图或换位置刷新。
4. 在场御使按真实效果、合法目标、体力／法力及 T 规则执行；T 随该次施法结束释放，D 随器体在场保留。器体崩解、主人离场及战斗结束按其真实状态清理，不让拖拽或刷新界面复制器体、占用与效果。

一件成器如果**确实同时具有直施和御用能力**，现行规则允许将两个不同主动入口分别装配；它们都指向同一个器物实例，直施入口不依赖召出，御用及在场御使则是另一个入口的两个阶段。该区别见[炼成剑适配](../百工技艺/炼器/炼成剑通用装备与战斗适配_20261024.md)及[动态技能词典](../../卡牌词典/炼成剑器动态技能.md)。不把直施与御用强制合并，也不把御用／御使两阶段拆成两件器物。

## 五、图标、目标与调整边界

- **视觉身份**：建议主动入口使用可辨认、透明底、清晰适配自身战斗占格的物件式新图形，并标明其对应的真实器物及当前“未召出／在场”等状态；不把旧招式纸卡图缩放当成成品，也不暗示图中印记就是可从行囊额外取走的第二件法宝。已有生成剑器的真实实物图可作为风格和身份参考，见[器物斜放图标](../../美术规范/器物斜放图标_20261025/README.md)与[图标派生接口](../../../csharp/panel/ForgedArtifactPresentation.cs)。
- **主动技能来源**：当前炼成剑适配按真实实例和实际能力动态生成入口，详见[生成接口](../../../csharp/systems/ForgedSwordBattleAdapter.cs)和[人物技能来源](../../../csharp/entity/Character.ArtifactSkills.cs)；一件器物的直施与御用可用不同来源键区分，不能只按名字去重。具体炼器结果没有相应能力时，不自动补出法宝招式。
- **敌方目标**：现行[战斗目标候选](../../../csharp/battle/BattleManager.Artifacts.cs)包含符合规则的在场器体，具体技能还须满足器体可受击条件。若在新自动战斗中原样保留，随机选目标时器体可能分流原本针对敌方角色的攻击；是否允许随机选中器体、哪些技能能选、是否与角色等权，需要明确审阅，不能静默排除器体或声称所有技能都能击中器体。
- **移动或取下**：拖动同一入口不得刷新器体、剩余器体、D/T 或次数。已经召出的入口想移出九格时，候选包括“在场期间不能移除”“入口移除而器体及 D 继续在场”“移除并按明确规则收回”；各自的允许条件、回收方式及费用会改变战斗，需要用户确认。不得把 UI 删除直接实现成免费的器体清除或免费补满。
- **状态与材料**：器体是单场在场实体的数值，不是永久耐久；战斗结束清理单场状态并保留本人真实器物。器蕴、装备词条、化法、主动模板各按来源处理，不因格子尺寸或图案产生新属性、伤害、射程或位移。

## 六、旧配置迁移与验收

1. 原人物档案和 NPC 装配保留真实 `instance_id`、原技能槽及化法绑定；在九格仅生成可审阅的候选映射，不修改原配置或把历史十槽直接认作九格。不能容纳、无来源或资格待核的项列为待处理，不删除实物与原引用。
2. 御用与御使按同一入口、同一实例迁移；直施入口若原本独立存在则单独核对。旧器物化法原绑定、主辅修化法和新定向化法的关系必须先审阅，不能自动复制收益或丢失已保存选择。
3. 逐项核验装备收益按实例计一次；召出前后 D／T、器体、同槽阶段、费用和目标按原模板；失败不重复扣费；战斗中移动、取下、再放回不重置或复制状态；战胜、撤退、失败和主人死亡都正确清理单场状态。
4. 对真实九格配置检查占地、空格数量和回体次数，并分别比较共盘入口、盘外入口与实物占地的资源走势。涉及具体格数、空格回复量、法宝检查方式、自动目标与数值平衡的内容须经用户确定后再运行隔离验证。

已实现的现行功能仅按各专题验证范围认定：通用炼成剑的装备、动态主动入口、D/T 及来源校验已有适配记录，旧参数和缺失主动模板仍以真实成器数据为准；本九格及上述法宝参与方式**尚未实装**。
