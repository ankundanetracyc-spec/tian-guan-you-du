# 个人修仙正式存档设计

> 状态：现行实装规格（v1）。存档保存整段单人修行进度，不是地图专用配置，也不等同于新建角色时保存的开局预设。

## 一、存档槽与入口

- 每次新建旅程创建独立存档槽，不覆盖其他旅程；存档文件写入 Godot `user://game_saves/`。
- 标题页“载入存档”列出角色名、境界、游戏内日期与保存时间，选择后恢复对应旅程。
- 当前旅程在关键状态变化后自动保存；快捷键 Ctrl+S 可立即保存；退出主场景时再保存一次。
- 自动保存写回当前旅程槽。新建旅程会创建新槽，不会覆盖已有进度。
- 存档包含格式版本，升级字段时按版本迁移；不能识别的新版本应拒绝载入并保留原文件。

## 二、v1 必须保存的状态

1. **主角**：完整 `HumanData`，包括姓名与外观、九项基础/派生属性、当前境界、修为与小数进度、灵根、已学/装配功法与章节、养成路线、伤势/状态、寿元、行囊、装备、宗门身份、月例、贡献、百川声望、当前/上限大世界体力、单一因果业值与七档心境。大世界体力与战斗精力字段分开保存。旧 `current_mind/max_mind` 数值不再属于人物存档；详细字段规则见[人物属性、因果与心境系统设计](人物属性、因果与心境系统设计.md)。新建预设不是正式进度。
2. **游戏历法**：年、月、日、时，以及不足一小时的累计时间，避免跨格行旅的小数耗时在存读档时丢失。
3. **固定方格世界**：玩家格坐标、当前对应的稳定地点 `node_id`、已发现格、尚未走完的路线。读档从最后一个已结算格继续；尚未结算的当前格不重复扣时。
4. **百川 NPC**：当前世界中已生成的人物完整快照、唯一 ID、九项基础属性、灵根与修行状态、因果业值、七档心境、区域公开名声、稳定地点/子场景、固定格坐标、在途状态、格网行旅路径与下一格索引、当前格内已行进时间、资源、关系、个人携带物、行动历史与月结算游标。东林地副本样板另保存 NPC 的副本 ID、路线节点、边内行进进度、遁速与步数。读档恢复原人物、世界格和副本位置，不重新抽取、复活或重复结算月份。
5. **剧情、任务与地点进度**：青溪里序章阶段及关键里程碑、当前/已完成任务、已获得传闻；已接宗门事务 ID 保存在主角数据内。东林地玩家当前路线节点与已走过路线也写入场景进度；读档不恢复临时弹窗，但再次进入副本时续接路线。

## 三、读档落点与一致性

- 序章尚未离开青溪里：回到李宅常态场景，不重播已经完成的开场对白；未完成的阶段目标仍可继续。
- 离开青溪里后：回到世界地图并以主角格为中心；若存档时正在行旅，则恢复剩余路线。
- 世界固定地貌、节点配置、资源定义等静态内容不复制进存档；存档只记录运行状态与稳定 ID。
- 读档先恢复历法、主角、NPC 月结算游标与地图，再开放场景交互，避免使用默认状态推进模拟。

## 四、边界

- v1 不恢复退出前打开的任意弹窗、地图缩放/平移镜头状态或战斗中的即时队列；战斗发生期间退出时回到最近一次安全的主场景存档。
- 开局设定预设只保存建档选项，不可当作角色进度读档。
- 旧运行时没有正式进度存档文件，因此没有可自动转换的旧槽；未来出现旧版正式槽时按 `format_version` 明确迁移，不能把旧地图已走道路直接换算成全图已探索。

## 五、验收

- 新建两个旅程后，保存与载入任一旅程都不会覆盖另一旅程。
- 改变主角境界/修为/功法/行囊、游戏日期和所在格，退出再载入后数值一致。
- 保存时存在随机 NPC 与行动记录，读档后 ID、状态、历史一致且不重复生成。
- 东林地 NPC 的副本路线位置、部分边程、遁速与个人随身物在存读档后保持一致；NPC 战败死亡后仍保留死因且不会刷新复活。
- 保存时存在宗门已接事务，读档后事务仍在；完成/取消后状态也正确保存。
- 正在逐格移动时自动保存并退出，读档从最近已结算格继续，时间和路线无重复或遗漏。
- 无存档时标题页显示明确空状态；损坏或不兼容的文件不会被静默覆盖。
