# 器物五行与无属性：按实际功用定性（暂缓留档）

> 最新决定（2026-10-22）：用户明确“不给器加上五行字段，暂定这样”。本篇不再作为当前实施依据；整器五行摘要、主副/复合五行及按功用自动定性均暂缓，不以“无属性”字段替代。当前只保留材料五行在炼制配伍中的作用、材料来源记录及七档阴阳。以下为此前提案留档，不据此新增成器字段、技能条件或器蕴资格。

## 一、决定

**先确定实际形成了什么功用，再判断它是否具有五行性质，最后按真正承担该功用的来源定性。**无属性是完整、正常的结果，不是炼制失败或品阶较低。凡器/法器按既有H/S评阶，不能按有无五行来分。

这里的功用指实际属性/效果，不恢复已取消的成器“功用字段”及两功用上限。材料的功用品级仍属于输入；成品保存实际效果与其性质。

必须分清三层：

| 层次 | 回答的问题 | 作用 |
| --- | --- | --- |
| 材料五行 | 投入的材料具有何种材性 | 炼制中的生克、送达、通关与稳定性 |
| 功用属性 | 某条实际能力是无属性、金性、火性等 | 明确该能力的适用和匹配规则 |
| 器物五行摘要 | 成品有哪些已经成立的五行功用 | 从实际效果汇总，供查看及未来合法条件引用 |

原料金行不等于生成金行伤害，木质承接不等于给全器染木。材料来源统计仅用于追溯，不能充当功用属性或伤害比例。

## 二、无属性与五行如何共存

### 2.1 基础性能通常保持无属性

剑的锋锐、物理防御、普通物理增伤、普通护盾等基础内容，默认保持无属性。它们可以来自有五行的材料；材料五行已影响炼制过程，不必再次变成成品的元素性质。

例如玄铁提供刃性，形成锋锐5，这首先是剑的本体性能，不自动变成金行伤害。金行性材支持普通物防，也不自动得到“金行防御”这一套尚未定义的新属性。

无属性与材料“无行”是两个概念：金行材料也能做出无属性功用；无行材料能参与一件有属性器物的结构或通路。无属性不是第六行，不参与五行相生循环。

### 2.2 有五行须形成明确的五行表达

效果原子/通用表达规则声明该效果是否允许具有五行性质，不由材料名字临时决定。规划分两种：

1. 无属性表达：按普通适用范围结算，不附加五行资格。
2. 五行表达：具有明确的五行适用或匹配规则，由实际投入这一表达的来源定性。

例如后续可设计金性穿防化法，要求绑定技能同时满足已定义的类别、关键词、实际伤害条件及金行适用；同一内容也可有无需五行条件的无属性化法。五行匹配读取正式属性定义，不把“金”或“近身”临时塞成新关键词。

五行表达的收益、限制和工艺成本作为公共规则统一标定，不能只加一个五行名字却没有实际区别，也不能在原效果上白送一轮增伤。新增战斗模板前需明确费用、目标、触发、兼容及验证；当前试炼尚未生成这些五行限定能力。

### 2.3 同器可以混合

一件器物可以只有无属性功用，也可有一行、多行，以及有属性/无属性并存。不设“有了金性，其余能力全部必须金性”的规则，也不强制混合材料只能选一个赢家。

阴阳七档与上述属性独立。无属性可以偏阴或至阳，不等于阴阳为和；五行齐全也不等于无属性。

## 三、“谁发挥功用”落实为实际分配账本

只看已经实现的实际分配，不按投料重量、份数最多、材评最高或材料名字定性。每条能力均需追溯到具体材料、岗位和功用分量。

沿用统一材料潜力和共同约束。若一条效果f实际从功用u使用x[f,u]，某材料i在该功用上的可用角色潜力为P[i,u]，则来源追溯可按公共比例分账：

```text
x[f,i,u] = x[f,u] × P[i,u] / Σj P[j,u]
Σi x[f,i,u] = x[f,u]
```

来源比例只解释原分配，不再生成一份额外潜力。对可形成五行表达的候选，再按来源属性分别建立无属性/金/木/水/火/土分支，全部分支共同占用原来的来源、结构、根性与工艺预算。

```text
每个来源：Σ所有效果、表达及属性分支 x ≤ 该来源真实可用量
每个共同资源：Σ成本 × 分配 ≤ 本次实际预算
最终属性分支值 = 公共效果曲线(该分支实际分配)
```

五行分支必须独立达到有效效果下限；不够形成实际效果的碎量不成为属性标签。先完成分配、取整与成立判定，再汇总成品五行；不能先把整炉材料五行并集贴到每条能力上。具体内容系数和五行表达成本待专用样例标定，沿用已有“最低有效效果”机制，不另造百分比主导阈值。

负责连接、维持、通关的材料，只有工艺贡献时不会染到能力上；若其独立份数确实有角色收益潜力并被分配成另一条有效能力，再按那条能力单独计算。某材料已消耗作通关的份数不能再次参与属性分支，燃料也不恢复。

同种新材料只需原有材性及公共加工数据；不会为了定性新增逐材料配方或单独指定“某矿必给某技能”。

## 四、整件器物怎样显示

成品五行摘要由**已成立的有属性效果**汇总，不根据来源构成占比计算。基础性能按无属性描述；不为展示而把物理剑刃染成金性。

| 实际成器 | 摘要 | 能力详情 |
| --- | --- | --- |
| 全部无属性 | 无属性 | 各能力显示普通效果与正常条件 |
| 有金性效果，其余无属性 | 金 | 金性能力标金，其余保持无属性 |
| 金性和火性效果均成立 | 金、火 | 各自标注，不显示伤害占比 |
| 原料含火，但没有形成火性效果 | 摘要不列火 | 来源记录仍可看到火行材料 |

主面板不展示“金95%/木5%”，不设主副五行优先级。详情中的属性标识附在对应能力旁，玩家能看清哪条有条件、哪条通用。只有未来实际支持多行同一能力时才展示该能力的复合规则，不能把两条独立能力误写成混合伤害。

当前v3的成品基础性能与六类候选效果尚无正式五行适用规则，按这份规划应视为无属性能力；现阶段继续显示实际效果和材料来源，不提前补金性/火性标签。

## 五、剑的例子

### A：完整的无属性法器

金行材料做剑身，木行材料负责连接，性材支持普通物理增伤，和材帮助稳定与传导。最终形成锋锐、物伤加成和普通穿防化法，均走无属性表达。只要H/S达到法器标准，它就是无属性法器；材料有金木不强迫成品具有金木属性。

### B：金性化法与无属性性能并存

同样的剑身结构，部分实际来源分配到具备合法模板的金性穿防化法，其余形成普通物防。金性化法独立满足来源和工艺下限时，成品摘要出现“金”；锋锐、普通物防不因此改变伤害类型或获得额外倍率。

### C：加入火行和材也不一定有火性

火行和材被实际消耗于通关，没有来源分给火性效果，成品不标火。如果以后另有独立材料份数和足够预算形成合法火性能力，火性才进入摘要；其数值仍从共同潜力分配，不因材料有火就白送。

以上是结构示例，不是新增正式配方或战斗卡；不在此填未经验证的伤害、费用、状态或器蕴层数。

## 六、器蕴与后续接口

未来器蕴条件若要求某行功用，只能查询已经成立的实际效果属性，不能数来源材料里出现几种五行。无属性器物也应能按其实际功能参与对应器蕴，不因无属性被一律排除。套系、贡献数量、阈值与奖励仍另案设计。

实施时记录：效果的属性模式、实际五行或无属性、各来源实际使用量、适用条件及公共模板版本。器物层只保存可重建的摘要，不同时维护一套互相冲突的材料占比属性。战斗读取具体效果模板，不用整件器物的摘要统一改写所有伤害。

本轮规划不注册新伤害类型、战斗关键词或状态。当前试炼保持无燃料v3，材料生克的实际送达和稳定性作用已通过专门验证；属性表达的生成与战斗接线在模板明确后实施。
