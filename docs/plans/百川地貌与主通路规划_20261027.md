# 百川地貌与主通路规划

桥位与山口已细化：[行旅结构规划](百川桥位山口与行旅结构_20261027.md)。16处道路过河共用15处普通桥位，另13处山口，均复用现有空节点；以下“尚未锁定桥渡坐标”由该补充替代，最终美术河岸仍需对齐。

> 承接用户对整体分布“差不多，继续”的反馈，细化地貌、路线用途与后续素材分层。现有123个具名地点、313个空节点、169条地点间路线保持；三大与十地方宗门、城约、产地归属和仙盟独立状态不变。本稿为规划示意，不是已实装地形或最终美术。

## 一、整体地理依据

西部以山岭衔接玉虚与镇岳，北部以台原和盆地支撑玄都、丹鼎与归藏，中部是河谷与湖泽往来带，东北是河港与水岸，南部为林谷及幽深湿地，东部古寺丘陵承接枯骨与无相方向。

这些地理片区不是一片一个势力。河流可贯穿多方往来区域，同一片林谷也可同时有普通探索、宗门产地与城镇采购联系；中部不归仙盟，也没有为仙盟留下大型空地。

本稿的山脊、水系和湖面只用于检查构图与道路意向。旧运行时仍是既有地格状态，本轮不增加水域格、地形阻断、渡河能力、耗时倍率或新的采集产物。正式地貌与通行校准时，应统一处理地图、路线、迷雾和NPC行旅，不能仅凭背景颜色改变可达性。

## 二、九片自然地貌

| 地貌片区 | 构图意向 | 承接内容 |
|---|---|---|
| 镇岳西岭 | 西侧连续山地，中间留谷口 | 镇岳观、望岫方向及山前野外；自然区分西线与内陆联系带 |
| 玄都台原 | 北部较开阔台地，山脊分段出现 | 玄都、金阙、丹鼎、绛阙及金石产地；不画成一整片无路大山 |
| 归藏盆地 | 高地往中央河谷过渡的盆地 | 归藏、承天、含章等往来，不被三方边界线硬切 |
| 涵虚水乡 | 中部河谷、零散湖泽与陆岸 | 春水、通济及周边镇与野外，保持可活动的中心地带 |
| 沧溟河港 | 东北水岸与入海联系 | 沧溟、临渊、镇海、澜浦，承接玄都方向贸易及跨圈接口 |
| 玉虚叠嶂 | 西南山麓与疏密不同的山脊 | 玉虚、太和、白石及附近林泉；山城分离，不重新挤在一处 |
| 百药南林 | 南部灵林、谷地与开阔地交错 | 百药、青萝、不老林、盘龙涧；保留普通野外和产地的区别 |
| 古寺东陵 | 东部丘陵与遗迹带 | 枯骨、归寂与陵地遗迹；与无相联系，但不等于整个片区都封禁 |
| 幽泉深谷 | 南东部深谷、湿地和丘陵 | 血河、蚀日、暮烟及外围野外；险峻气质不等于默认高阶或强制战斗 |

地貌标签用于描述与后续素材选择，暂不自动套材料池、敌方强度、温度或收益。片区之间留有自然过渡，不做九块硬边拼图；示意色块边线不是最终山川轮廓。

## 三、水系与山脊

主水系沿中部河谷向东北水岸延伸，溪云方向支流由南部林谷汇入，暮烟方向支流由南东深谷汇入。涵虚泽与镜月泽采用小湖盆，不用大水面挤走中部城镇与路线。

水系名称在本稿是构图工作称谓，主河暂称“百川中流”，不额外建立一个世界地点。山脊采用西岭、断岳余脉、玉虚山脊、东陵低脊等自然延伸；地点依附山前与谷口，不把整个宗门图标压在不可通行山峰上。

当前路线和河流构图有16处交会候选。每处须在正式河岸确定后选择陆桥、渡行或沿岸绕行；不要因线条相交就默认可跨水，也不为每次跨河增设一个有名渡口。可把桥头或岸边落在现有空节点上，澜浦渡、问津渡仍是已有具名地点。

候选清单保存在规划数据 `terrainPlanning.crossWaterReview` 中，按路线ID与水系记录；它不产生收费、阻断、舟船、飞行或进入水域等新机制。本轮尚未锁定桥渡坐标，水系示意也不能反过来修改旅行数值。

## 四、五组主要往来方向

| 联系方向 | 主要目的地顺序 | 用途 |
|---|---|---|
| 西南至东部 | 玉虚—白石—溪云—春水—通济—无相—永夜关 | 衔接首期、西南河谷、中央与东部生活圈 |
| 北部 | 春水—承天—绛阙—玄都—金阙 | 中央向北部高地与府城联系 |
| 东北河港 | 通济—归寂—临渊—镇海 | 中部、东陵与东北水岸联系，保留跨圈往来 |
| 西部支接 | 太和—白石—赤水—望岫—承天 | 串起西侧城市，避免每次绕回同一山门 |
| 南部 | 青萝—溪云—暮烟—无相 | 南部林谷、河谷与东部连接 |

表中是沿现有路网依次到达的目的地，不是新增两点直连捷径，也不要求玩家按顺序解锁。这五组联系可共享道路，一段路不因被两组使用就重复计算、重复收费或生成两份背景。

169条地点间路线现分为73条主要通路、15条地方支路、81条野外深入联系。主要通路用于视觉层次，方便辨认城市与大宗之间的方向；分类本身不保证安全、不增加移动速度，也不自动改变人物行旅意愿。

野外深入路线可以终止在遗迹、山谷或产地，不要求每个野外都有另一端出口。抵达节点只到达该地，是否进入探索仍由玩家主动选择；不把主要通路经过野外节点理解为自动进入副本或触发战斗。

## 五、图面与数据检查

本轮检查169条直线示意路线，没有发现两条无共同端点的道路在中途交叉。正式绘制道路弯曲后需再检查；不能把当前直线图的检查结果当作最终美术路线已经验收。

现有436个世界路线节点保持互通，仙盟没有外部连接。每个地点仍有唯一身份，产地仍包含在70个野外内；城约、库存、材料和资源归属不随本轮地貌层调整。

## 六、后续素材的层次

固定倍率、不可缩放的方向保持。后续背景采用栅格拼接，地表、山脉、林带、水系各有可复用素材；具名地点图标、路线、空节点、角色和界面分别叠加，文字不烧进背景。

先用整体低精度草图验证拼接轮廓，再按实际显示尺寸拆分素材；暂不把旧200×200格、40公里／格或AI单张输出尺寸直接定成背景总尺寸。本轮不生成正式美术，也不决定所有地点都需要独立整屏背景。

下一步实施前仍需落实桥渡与绕行、最终道路形状、固定倍率下的显示尺寸和拼块衔接。旅行耗时、NPC路线与存档迁移另按系统主案校准，不在地貌讨论中猜数。
