# 前期丹药与丹方首轮提案（2026-10-22）

状态：**讨论提案，数值可调，尚未接入正式丹药数据。**本文按《炼丹槽位式即时配伍新案》和现有突破丹药规则补充前期药物；不改变丹药的丹阶、丹效、配伍与一次点击自动结算规则。突破丹的参考丹方若进入正式玩法，会增加炼制获取途径；现行境界案只规定新旅程各发一枚、突破成功后消耗，没有规定后续获取，本提案不擅自把新来源写成已确认规则。

> **2026-11-02修订：**本稿关于定脉丹、归元定息丹“缩短突破闭关”的效果已撤回。五档效果以[最新突破丹衔接方案](突破丹五档与境界衔接_20261026.md)为准；此稿相关折时表仅作历史草案。

## 一、统一口径

- **丹阶**是九品至一品的炼制门槛，造诣达到对应门槛才可开炼；**丹效**是成品实际药效，低于20不成丹，20—50为薄效，51—75为良效，76—90为优效，91—99为极效，100为满效。成品界面显示“丹阶九品、丹效优效”这类完整字段，避免把两种概念混为一谈。
- 同一种丹药、同丹阶、同档丹效，药效完全相同；物品按丹药、丹阶和丹效档位区分并堆叠。丹效不再经过第二条连续曲线换算。
- 每炉只有一类君药，剂量可变；君药从丹种列出的候选中选一种。臣、佐、使可自由换材和配量，材料功用按材料原表和对应药位参与计算。
- 配置完成后点击一次【炼丹】，系统自动判定整炉。下表丹方是可复用的候选路线，不是材料白名单，也不要求玩家照方才能成丹；实际丹效须用逐颗分配规则复算。
- 表中五档效果、偏性目标、丹方份数均为首轮测试建议。丹效仍由现行主案的核心药力、配伍、阴阳和成形等短板判定；任一关键缺陷不能靠无关项补分。满效100是独立档位，其丹药效果值不从极效档插值推算。

## 四、完整自动判定示例：青芽纳灵方

本例展示现有公式怎样读取药材，不预设“这几味一放就必成”。丹道造诣取8，灵识上限24、当前精力100；四种材料各一份，点击一次【炼丹】后按下列顺序自动结算：

投料为：君青髓芽×1、臣山蚕长丝×1、佐清音玉片×1、使溪纹藻丝×1。现有材料原表对应：青髓芽聚九品、生九品；山蚕长丝固九品、藏九品；清音玉片明九品、通九品；溪纹藻丝通八品。四味有效得率分别按现行首轮质地参数取85%、85%、75%、85%。

1. **准入和资源：**九品丹门槛A≥8，本例A=8，刚好可开炼。`M=4`种、`N=4`份，实际读取4组材料—功用（君聚、臣固、佐明、使通），所以`F=4`。灵识需求`L=4+2×4+floor((4−4)/3)=12`，低于24。主药理论量`Y主=85×1×1/(25×1)=3.4`；没有臣聚时`R聚=0.75`，所以`K拟成=floor(3.4×0.75)=2`颗。精力需求`ceil(20+1.5×(2−1)+(4−1)+0.5×(4−1)+0.25×4)=27`，低于当前100。最高材料为八品下，正式耗时公式给2游戏时辰；开发试演不推进正式时间。
2. **混合和送达：**四味相性全为“和”，所以阴、阳药性均为0、和药性为330；`Z₀=0`，无阴阳相激。使位溪纹藻丝的通八品在A=8时掌控率为`8/32=0.25`，等效通药力`P通=1.65×0.25=0.4125`，得`R通=0.70+0.10×0.4125=0.74125`；没有使位“行”时`R行=0.60`。每味每颗基础送达量按`Mᵢ×R通×R行/2`计算，依次为18.9019、18.9019、16.6781、18.9019。
3. **五行和君药发挥：**有效五行为木170、水160，实配木51.515%、水48.485%，贴近本丹方目标木51.5%、水48.5%；锚定木行后`K五行≈1.18557`。青髓芽每颗核心质量`m=18.9019`，核心药力`w≈22.4095`；代入主药质量门槛得`Q主质量≈77.95`，主药药力项达到100，因此`Q主≈77.95`。阴阳目标为0，实配也为0，所以`Q阴阳=100`。
4. **稳定和夹带：**山蚕长丝的臣位固九品形成`P稳形≈22.4095`，`Q固=100`。四味基础残余共70；佐位清音玉片的明九品使夹带率从15%降至5%，夹带残余为3.5。整炉送达量为146.7675，夹带比例`J=3.5/(146.7675+3.5)≈2.329%`，所以`Q纯度≈71.52`、`Q稳定≈71.52`。通路项`Q通=74.125`，四味有效材料上限为99。关键项取最低，当前公式得到整炉参考丹效`floor(min(77.95,100,74.125,71.52,99))=71`，对应良效；纳灵丹良效提案效果为每颗补入2缕灵力。
5. **结果边界：**这套算术是按当前主案的全炉均分算法完整复算，证明各项功用分别落在君核、臣固、佐明、使通和五行、阴阳判定上。可是当前主案均分药性，会把两颗都算成71分；你此前要求一炉多丹可以出现不同档位，通常相邻档。两者冲突，所以“71分良效”目前只能当配方强度参考，不能写成最终必出两颗良效。逐颗药性分配规则需要先补定，之后才能算本炉各档颗数。

## 五、落地边界与待评审项

- 两种突破丹的名称、目标关口、新旅程发放和成功晋层后消耗沿用现行规则，不在本案更改。
- 本案列出的突破丹配方只是候选炼制路线。现行规则没有规定玩家能否额外制作、可制作次数或材料来源；开放炼制会改变原有“一枚旅程发放”的获取结构，需单独确认后才能成为正式规则。
- 其余两种丹药是新增候选物品，不等于已经注册 `ItemData`、图标或使用效果资源；正式新增前仍须依物品案确定资源和效果接口。
- 丹效档位要能随丹药实例保存；同丹药、同丹阶、同档效果固定并可堆叠。当前突破丹资源是固定 `ItemData`，还没有逐枚保存丹效档位的实现，正式产物结构需另行接入。
- 当前突破规则只规定丹药为硬性条件，没有规定丹效缩短突破耗时。表中五档折减值是建议测试参数，须确认后才可写入现行突破规则。
- 参考丹方为首轮候选构筑，实际可行性、高效档位、造诣压力与成本需按现行整炉计算复核；不通过时调整参数或路线，不新增材料专属效果，也不加投料外的操作步骤。
- 一炉多丹允许出现不同丹效档、通常相邻；当前槽位主案中的整炉均分公式会强制同档，违反此前的逐颗品质要求。该公式已在本提案示例中作为待修正模型标出，逐颗分配规则确定前不把样方的整炉分数直接换成每颗产物档位。
- **逐颗分配建议（待确认）：**保留一次点击自动结算，不加随机数和玩家操作。先算出每味材料炼出的有效药性与残余，再按丹胚数切分；不能整除的最小质量单位按固定槽位顺序轮流分给各丹胚，残余也用同样方法分配。随后每颗独立计算丹效；不足20的丹胚不成丹。这样同一投入每次结果确定，药材分配有细微差别时才可能跨档；若需要保证大多数炉次都出现相邻档，还需再调整分配粒度与丹炉影响，不能仅靠这条余数规则承诺。
