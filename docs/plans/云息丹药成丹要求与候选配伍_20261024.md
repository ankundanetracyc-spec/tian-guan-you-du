## 一、玩家实际做什么

1. 选一味君药，再自由配置臣、佐、使及整数份数。
2. 查看药材本身、整炉五行与阴阳、本炉灵识需求、精力和时间；已有丹方可以填料，仍能修改。
3. 点击一次【炼丹】，自动结算材料处理、丹种、颗数及每颗丹效。
4. 演出揭晓结果，鉴看后按丹效装瓶，进入现有领取界面。

没有投料时机、手动火候、逐息、排渣按钮或新小游戏。炼前不预报成品和丹效。基础药位为君、臣、佐、使各一种；造诣8／32／68／203／508的药位扩展沿现行规则。份数无固定上限，仍受库存及递增灵识负担限制；同材不重复占位。候选丹胚由君药支持量与批量技术共同自动决定，不让玩家指定颗数；新候选公式见同日批量修订，不再统一截断到4颗。

**顺序是：丹药定义需要怎样的药性 → 玩家自由组合 → 炼出结果 → 把表现合适的组合记成丹方。** 丹方不保存“必出某丹”“固定产量”或品质奖励。

## 二、同一个核心如何得到不同丹药

### 2.1 识别与判丹效分开

- 核心回答药力主要能做什么：生是修复，护是保护，聚是汇集，藏是收敛。含义直接沿用材料案十二功用基础表。
- 全炉五行与阴阳回答这份能力形成怎样的配伍。例如生的平和木水配伍偏回春，偏阴收敛配伍偏续生，偏阳木火配伍偏赤髓。
- 识别出的丹种，再按核心药量／药力、阴阳、通路、稳形和夹带等现行规则逐颗判丹效。五行继续修正实际药力，不另加一条品质评分。
- 同一炉只识别一种丹药；逐颗分配可以让该种丹药出现不同丹效，不让同炉某颗回春、某颗续生。
- 药效由“丹种＋丹阶＋丹效档”固定定义。材料上的藏不额外给某瓶增加持效时间，护也不额外给回春叠护盾；不能长出未登记的随机副药效。

### 2.2 识别算法候选

为避免“先选丹种才能算药力，先算药力才能选丹种”的循环，先用一个不依赖丹种的配伍参考值识别：

```
每味参考质量 = 100 × 整数份数 × 现行材性基础得率
配伍五行 E = 按参考质量加权的木、火、土、金、水份额
配伍阴阳 Y = Σ(参考质量 × 材料阴阳符号) / Σ参考质量
相性偏差 C = 五行总变差距离 D(E,目标) + 0.5 × |Y−阴阳目标|
```

材料阴／和／阳分别取−1／0／+1，沿当前结算使用符号的口径。五行总变差距离为五项份额绝对差之和的一半。识别参考值不是新物品属性，不改变真实质量；后续破化、混合、散失及逐颗分配仍按完整主案算真实药性。

候选步骤：

1. 只考虑君药实际具备核心功用的丹种，材料名不是白名单。没有相应核心不能靠辅药替代君药。
2. 相性偏差C≤0.85才进入已知候选，这是首轮可调的识别范围，不是某档丹效资格。没有候选仍可按原入口尝试，结算为未识别成品，不凭空发新丹。
3. 先比较候选所用君药核心的真实功用品级，较高者优先；相同品级再选C较小者；误差在10⁻⁶内的完全同分按稳定丹种ID处理。这里不比较预估品质、售价或“哪个最划算”。
4. 确定丹种后检查其丹阶准入。识别为高阶丹却造诣不足时阻止开炼，不偷偷降成另一种低阶丹以绕过门槛。
5. 识别之后固定本炉丹种，再以该丹阶重新计算所有真实药力与资源；不使用识别参考质量发药、算丹效或反复切换丹种。

识别用参考组成，品质用实际逐颗组成，二者不可混用。炼后说明可写“君药以生为核心；本炉偏阴，因此形成续生药性”，再说明真实短板。批次边界附近换材或加量可能改变丹种，丹种切换与品质跨档是两件事。

**迁移影响：**青髓芽同时有生、聚，新增纳灵等丹后，部分旧木水配伍可能改识别结果。旧丹方只保留投料，不能靠隐藏标签强制维持原丹种；扩充上线前应重算旧样方、更新说明，原有已领取物品不改种。当前代码仍按旧三丹识别，本稿没有先行改动。

## 四、材料与功用怎样真正参与

材料案基础语义为：固＝稳定承载，聚＝汇集蓄积，通＝连通导流，化＝转换炼化，引＝牵引导向，破＝穿透瓦解，护＝保护隔绝，镇＝压制固定，生＝生长修复，明＝显化辨识，藏＝封存收敛，行＝运行位移。没有新增第十三功用。

君位只读选定丹种核心，供核心药力和自动候选量使用。臣位聚／固；佐位破／化／固／镇／护／明／藏；使位通／行／引／藏，全部维持现行通道。

|位置和能力|本炉做什么|不能误读成什么|
|---|---|---|
|君生／护／明等核心|提供对应丹种的真实核心药力|同一君药上的其他功用全都免费加入辅位|
|臣聚|在君药支持范围内提高候选颗数|聚类君药自动再享臣聚增产|
|臣／佐固|支撑每颗真实丹体|固类君药再白送一次辅位稳形|
|佐破、化|等量把允许处理的残余转成可用药性，沿共享预算|成品必带破甲、化毒，或无中生有药性|
|佐镇、护|分别处理相激、危险|阴阳不合仍能保满效，或每颗成品额外带盾|
|佐明|减少残余夹带|材料实例新增纯度属性，或自动解锁凝念效果|
|使通、行|分别改善混合与药性送达|通核心同时承担全炉通路，或增加角色速度|
|使引|从其他丹胚向首颗搬运已有君药药性|给每颗随机加分，或凭空增加药力|
|佐／使藏|最多挽回现行3%自然散失|任意丹药都因加藏变成持续型丹药|

所以即使丹种以护或藏为核心，也不是把材料的独立“护药水”“藏药水”提取出来。功用属于同一份药性，材性、五行、阴阳和位置共同决定它能形成哪种配伍，物品效果再由登记的丹种实现。

“两条路线”指核心来源、材性处理或性相调配方式确实不同，不把同方份数加一就当第二套成熟丹方。只有一种明核心材料时，先承认选择面窄，后续扩充材料需独立设计并更新原表，不临时给其他材料添明。

## 六、三组容易理解的炼制取舍

### 6.1 同一个生核心：回春、续生、赤髓

想做回春，优先和性木水，避免阴或阳过重。想做续生，加入现有阴性土、木、水材料，使配伍靠近偏阴木土水方向；这些材料按各自药位发挥藏、化、引等原能力，并非强制要集齐“生＋藏”。想做赤髓，可用偏阳赤瓤木核，或由凝露松脂、火性材料把和性生材推向木火阳配伍。

多放辅药会改变组成比例和资源需求，但不会直接扣掉已经投入的君药质量。真正影响每颗核心量的是处理损失、送达、自动候选数和分配；例如臣聚提高候选数后，有限君药会被分给更多丹胚。若为了调配而主动减少君药，即使识别到正确丹种，也可能因核心量不足而不成丹。

### 6.2 同一个固核心：金肌、定脉、培元

金肌偏金土，定脉偏木水，培元偏木火土阳。换君药不是唯一手段：铜髓矿、荒藤结节、凝露松脂都携带固，但其五行、相性、材性和其他岗位贡献不同。不同配伍应能形成不同成本、灵识与得率取舍，不能只凭名字把矿材限定为金肌、木材限定为定脉。

### 6.3 聚增产与引集中仍是通用策略

臣聚可以增加君药支持范围内的候选数，也可能把有限药性分薄；使引只在多颗时重分配已有君药药性，让少数丹更强、其余更弱。玩家通过配伍选择两种方向，不能手选“这一炉只出一颗满效”。使位给引占了位置，也就失去该位置原本可能提供的通或行；高造诣解锁额外使位能缓和冲突，但负担照付。

**初期限制要讲明：**多味配伍若完全没有使通，现行通路完成度只能从65起步，对应75分，不能出优效以上。当前材料中没有同时携带通与引的单味使药。因此基础四位置用引替通的集中路线，会被通路短板压住；不可把它宣传成前期出极效的方法。造诣32解锁第二味使药后，才能用“使通＋使引”同时承担连通与集中，且仍需其他短板达标。已有材料行九品风窍晶屑、行八品乌羽片也都没有通，送达与通路不是同一件事。

## 七、用度、时间与五档要求

- 灵识沿完整主案的材料基础、本位功用、角色系数、剂量递增公式，按整炉最后向上取整；不要手填“每丹固定消耗”。本炉需求必须≤扣除其他事务后的剩余可支配灵识。
- 君位只把本炉被选定核心计入实际功用负担，未被选择的第二核心不收费也不生效；辅位仍按现有允许通道逐项计。**用户2026-10-24确认此口径；当前代码仍对君药所有已登记核心收费，尚待修正。** 材料基础负担仍按全部功用品级形成的材评计算，不因本炉没用某项能力而把材料降阶。识别前的界面资源预检与真正开炼必须使用同一个内部识别结果，炼前可隐藏结果名，不能前后用度不一致。
- 精力沿既有公式，根据实际材料种数、总份数、读取功用数和自动候选量计算。成功、普通失败和炸炉都正常付费，资源／准入预检失败不付费。
- 耗时按最新修订改为丹阶基础时长，再由配伍与批量小幅修正；旧最高材料翻倍、超四味加25%不再采用。具体候选公式见同日批量修订，运行尚未接入。
- 核心药量／药力、阴阳、通路、稳形、夹带的关键缺陷不互相补分。不能为了让新药更容易成丹另给新丹固定加分。
- 所有25种都具有薄效、良效、优效、极效、满效五档；不成丹不是第六种物品。成品同种同阶同档效果固定，五档完整药效互不相同，使用数值以药效提案为准。
- 五档都应有真实可达的配伍空间；现有三丹不能当成新丹已可达的证明。本稿不给未计算组合贴“良效方”“满效方”或捏造性价比排名。

## 八、怎样把草方变成真正的丹方

后续扩充实现按下列顺序进行，本次只写设计，没有运行这些检查：

1. 给目录增加丹种ID、固定丹阶、核心、五行目标、阴阳目标和评分容限；先接统一识别，不逐方硬编码。
2. 复算现有三丹的旧样方，记录哪些被新丹种分流，再修订样方名及投料。不要强制保存旧结果。
3. 首批先做回春、通脉、静心、凝罡、金肌、赤髓、纳灵、定脉；其余逐批增加，单独处理突破丹既有获取渠道与存档兼容，不本轮擅自开放重复获取。
4. 每种丹至少形成两条不同加工或性相路线；记录人物造诣、总／可支配灵识、所有投料、实际占用、精力、时长、候选量、逐颗丹效及失败原因。明核心单一的问题须如实保留。
5. 比较每颗合格丹的材料实际价值、灵识门槛与时间，不只看最高丹效。没有材料价格或供应数据时，不把“份数更少”直接写成“更便宜”。
6. 再补五档可达范围、相邻丹种切换、同炉差异、引转移守恒、君药多核心、造诣不足、其他事务占用及领取物品对照。覆盖不全不得称25种均已实装。
7. 仅把真实达成且有比较价值的组合收录丹方册。样方可以提示“偏阳养血”“土重防护”等已知经验，不实时预告改方后的必然成品。

## 十一、同一种丹的三种配伍路线

这是丹方的经验说明，不是新的制作模式或三个切换按钮。玩家仍只安排材料和份数；少味不等于便宜，增产不保证多出合格丹，集中不保证升档。

|路线|实际改动|主要取舍|收录为成熟丹方前需要证明|
|---|---|---|---|
|少味|使用较少材料种类，尽量让材性与性相自然相合|可能少一个处理岗位；为补足药力增加单味剂量后，灵识未必更省|确实减少用度或采购种类，且合格产出有价值|
|增产|让臣聚支持更多候选丹胚，君药用量在有效区间内|君药分得更薄；臣位由固换聚后须由佐固或天然材性支撑成形|最终合格颗数增多；不是只有候选数增加、废丹更多|
|集中|保留使通，再用额外使引把已有核心药性集中到首颗|其余丹药核心减少，五行与阴阳也可能改变；新增材料与占用|少数丹确实跨档，且整炉收益符合玩家目标|

### 回春丹的三个具体起点

1. **少味起点，造诣8可配置：**君云雾菌1、臣石蜂蜡1、使风络藤丝3，佐位空。三味均为和性；君生、臣固、使通。省下的是一类采购与佐位材料，没有明或化处理残余，不能承诺高丹效。
2. **增产起点，建议造诣32探索：**君云雾菌1、臣灵泉藻2、佐清音玉片1、使风络藤丝3。固定君药先用臣聚提高候选量；其代价是臣固退出，须看天然成形支撑是否够。只比较产量这一小步时，在主材可用质量85、无破化改变它、九品核心已完全掌握的前提下，无聚的候选为floor(3.4×0.75)=2；臣灵泉藻两份的八品聚完全掌握时P聚=3.3，候选为floor(3.4×0.915)=3。这里只证明候选数的取舍，不宣称最终三颗合格。
3. **集中起点，需第二使位：**君云雾菌2、臣山蚕长丝1、佐清音玉片2、使溪纹藻丝3＋雾铃花1。溪纹藻丝承担通，雾铃花承担引；新增阴性木药也改变全炉配伍，要重新识别。用实际逐颗结果看首颗是否跨档、其余是否降档，不将引的25%最大搬运率写成固定25%丹效加成。

其他丹药沿同样的岗位取舍探索，但必须回到它自己的五行与阴阳要求。不能把上述回春组合仅换一个君药就宣称整套目录通用。

### 丹方册怎样写，玩家才看得懂

- 主要展示：方名、适用经验、材料／药位／份数，以及保存时的人物条件。加载后显示当前真实用度，不以旧用度冒充本次报价。
- 经验只来自已经真实结算的结果，可保存“当时造诣、可支配灵识、各档颗数”。这是历史炉次，不是保证；改方后不继续套用旧产出。
- 用一句话解释取舍，例如“臣药聚力，多凝丹胚；单颗药力会分薄”或“多用一味使药牵引，集中首颗药力”。不暴露C、P聚等内部变量。
- 炼后默认只显示逐颗丹效与物品信息。需要解释时再展开一条最主要原因，例如“此方缺少连通药力，限制了丹效”，而不是铺满全部评分。
- 五行目标是方向，不把五种材料或五种元素全部齐备当作高效条件；也不以材料味数给满效资格。
