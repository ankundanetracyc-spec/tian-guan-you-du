# 伤势业障牌系统设计

## 基本定位

`外伤` 与 `内伤` 是通用伤势业障牌。它们不是普通状态，而是会进入技能库循环的负面卡牌。

- 类型：业障牌
- 不可主动打出
- 抽到后占用手牌
- 只要停留在手牌中，就持续生效
- 从手牌离开后，效果立刻消失
- 置顶、翻入手牌、直接加入手牌等强效果由具体卡牌或秘籍另行写明

当前暂不设置单体技能库上限，也暂不设置每回合新增上限。后续如果污染强度过高，再从数值层面补限制。

## 即时队列战斗适配

即时队列战斗没有战斗手牌区。由招式施加的内伤、外伤在即时战斗中转为角色状态，层数沿用本案上限，效果持续 **720 模拟帧**；重复施加会刷新持续时间。720 帧约覆盖两段常式行动（准备 240 帧、收招 96 帧），并留出 48 帧余量，避免一次普通行动结束时伤势立刻消失。

- 内伤：每层使行动速度降低 5%、法力费用提高 10%、法力上限降低 1、护心降低 8%。法力上限惩罚最多 2 点。
- 外伤：每层使行动速度降低 5%、闪避降低 8%、遁身类行动的体力费用提高 10%。
- 内外伤共同计算行动速度，最多降低 30%；外伤单独最多降低闪避 32%、遁身体力费用最多提高 40%。
- 状态图标显示在角色血条上方；悬停显示效果和剩余帧数。身法、化解、借力、游骸等公共状态继续按各自的受击或消耗条件结束，不套用伤势时长。

即时战斗按秘籍与技能的明确配置结算伤势联动；经典牌局仍保留“伤势牌在手牌中生效”的原规则。

## 手牌生效规则

战斗中，角色的手牌不会在自己回合结束时立刻全部进入弃牌堆，而是作为该角色当前持有的手牌持续存在。伤势业障牌因此采用区域持续生效规则：

- `外伤 / 内伤` 从抽牌堆进入手牌后立即生效
- 只要还在手牌中，持续影响行动条、资源消耗与相关属性
- 被弃置、消耗、净化、移出手牌后，效果立刻消失
- 若特殊效果直接把伤势加入手牌，则立刻生效

生命回复等局内持续效果可按时间或行动节点结算。伤势牌不关心回复底层，只要求每次结算时读取当前手牌中的伤势数量。体力的跨回合保留与法力的回合清零由三资源系统统一处理。

## 共同效果

手牌中每有 `1张外伤或内伤`：

- 行动速度 `-5%`

行动速度下降上限：

- 外伤与内伤共同累计，最多 `-30%`

## 外伤

外伤代表皮肉、筋骨、关节、肌腱等形体创伤。它让身体跟不上，动则牵痛。

手牌中每有 `1张外伤`：

- 遁身牌移动距离 `-10%`
- 遁身牌体力消耗 `+10%`
- 身法 `-8%`

叠加上限：

- 遁身牌移动距离最多 `-40%`
- 遁身牌体力消耗最多 `+40%`
- 身法最多 `-32%`

## 内伤

内伤代表经脉、气海、脏腑、法力运行路径受损。它让气机转不动，运功和守心变差。

手牌中每有 `1张内伤`：

- 法力消耗 `+10%`
- 本回合法力上限 `-1`（最低不低于 0）
- 护心 `-8%`

叠加上限：

- 法力消耗最多 `+40%`
- 本回合法力上限最多 `-2`
- 护心最多 `-32%`

## 施加规则

招式、秘籍、妖兽技能或特殊规则接入伤势业障牌时，施加文本写明：

- 施加哪一种伤势：`外伤`、`内伤`，或两者
- 施加数量
- 加入位置：弃牌堆、抽牌堆顶、手牌，或其他指定区域
- 触发条件：命中、造成伤害、会心等；只引用当前技能或状态规则已定义的条件。

默认推荐位置是 `弃牌堆`。直接加入手牌、置顶抽牌堆属于更强效果，应该只给特色招式或秘籍使用。

当前实现的显式效果格式：

```gdscript
{"effect":"add_wound", "wound":"外伤", "count":1, "destination":"discard"}
```

`wound` 可填 `外伤` 或 `内伤`。当前实现只支持加入弃牌堆。

## 防御端

当前不新增任何独立的伤势防御属性。

防御端仍使用现有体系：

- 物理防御 / 法术防御：减少实际生命伤害
- 身法：影响闪避
- 护心：影响会心抵抗

如果以后出现大量专门塞伤势牌的流派，再考虑新增“净伤”“护脉”这类状态或秘籍效果，而不是先做通用抗性字段。
