每本的第一页面所有可见文字均为游戏内文案，保留中央四卷、左心法与招式、右化法的结构，不放内部标签或备注；第二页面记录完整规则与阅读标识。两个页面使用相同效果与数值，分别记录玩家文案与内部结算。

舒卷天章采用流云剑势：剑意门槛9层、主修8层，四卷连续命中档幅为10%／15%／沿用／20%；第三卷习得云岚三叠，四项化法分别指定架招、剑式、云岚三叠、错步。架招化法每次发动首次实际化解时获得2层剑意；基础架招按[已确认的持续防御规格](../../../plans/战斗与构筑/架招持续正面防御修订_20261105.md)规划。本图不授予公共基础招式，也不补造未定养成字段。

以下为百骸云息篇的规则与实装记录：心法为百骸化生，第二卷习得赤潮奔涌，每卷均有化法。

赤潮奔涌仍为体力1、法力0，发动降低气血2层，持续6秒、强化结束后冷却24秒；期间每套普攻末段放浪，伤害由末段基础值和出手时气血决定，范围120°／440单位，0.78秒扩散；命中后按体魄、承载抵抗与境界判定轻微击退。适配拳掌、剑、乐器等泛用规则仅在策划说明中记录。
