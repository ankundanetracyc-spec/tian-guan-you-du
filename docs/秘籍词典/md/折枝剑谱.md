# 折枝剑谱

> 状态：废案（2026/09/25）。折损及其依赖的折枝剑谱技能链已从项目移除；本文仅保留历史设计，不作为当前实现依据。

## 基本定位

- 类型：剑修秘籍
- 灵根要求：有灵根即可
- 可作为：主修、辅修
- 主修可修至：云息十三层
- 辅修可用至：云息九层
- 风格：施加剑痕、制造外伤、降低护心，最后以摧枝一剑打出高伤害
- 倾向：剑修 / 伤势剑 / 单体爆发
- 状态：卷章与首批卡牌资源已接入；数值与结算持续校验。

## 系统规则

- 学习卷章：新增该卷对应牌
- 纳气：提供装配态属性
- 化法：改写基础技能库
- 心法牌：作为习得牌进入对应卷章，提供局内剑势
- 习得：学习卷章后解锁的可装配卡牌，可自由装配或卸下，数量表示玩家可配置张数
- 化法技能库变化：装备秘籍并启用化法时，对基础技能库进行替换或额外加入

## 招式联动总纲

折枝剑谱的招式统一组成以下循环：

拂枝点痕 -> 照痕续息 / 折步寻隙校准 -> 压枝或裂柯消耗剑痕并加入外伤 -> 折枝剑势生成折损 -> 摧枝一剑消耗折损 -> 由伤势重新显痕

各类牌的职责固定如下：

- 拂枝点痕：可靠启动。攻击未留痕目标时一次建立两层剑痕，使本秘籍不依赖别派才能开始积累剑痕。
- 照痕养锋：根据场上已有剑痕恢复精力，并令下一张折枝攻击增加剑痕。
- 压枝：基础伤势招式。先施加剑痕，再检查并消耗剑痕加入外伤，保证牌面顺序清楚。
- 折步寻隙：提高下一次转换的命中与折损收益。
- 裂柯 / 挑枝断筋：中后期高效伤势招式，把已有剑痕持续压成外伤与折损。
- 回锋添痕：从敌方回合重新留下剑痕，避免爆发后完全连续出招中断。
- 摧枝一剑：消耗折损完成爆发，并根据目标已有外伤重新留下少量剑痕，回到下一轮循环。

统一结算顺序：

1. 记录攻击前目标的剑痕、折损与各战斗牌区中的外伤数量。
2. 结算命中、会心与本次伤害加成。
3. 命中后先施加本牌新增剑痕。
4. 再检查是否满足剑痕消耗条件；满足时消耗剑痕并加入外伤。
5. 若处于折枝剑势，因本次消耗剑痕并加入外伤施加折损。
6. 最后结算牌面写明的额外折损或回痕效果。

摧枝一剑 是唯一例外：命中判定通过后先记录并消耗本次用于增伤的折损，再按记录层数计算伤害；若攻击未命中，则不消耗折损。

标准衔接示例：

1. 拂枝点痕 攻击无痕目标，一次施加两层剑痕。
2. 折步寻隙 调整站位，并强化下一张折枝攻击。
3. 压枝 先增加剑痕再消耗两层剑痕，加入外伤；折步寻隙与折枝剑势共同增加施加的折损层数。
4. 裂柯 继续把残留与新生剑痕压成外伤。
5. 摧枝一剑 消耗折损爆发，并按已有外伤重新留下剑痕，进入下一轮。

## 通用 Buff

### 剑意

- 剑意 是剑修通用 buff，应被多本剑修秘籍复用
- 每层 剑意：剑术伤害 +5%
- 剑修基础技能库 中所有攻击牌命中敌人后，获得 1层剑意
- 若当前回合结束时，本次自身行动期间 与 上一回合 都没有获得新的 剑意，则 剑意 清零

### 剑痕

- 剑痕 是施加在敌人身上的剑修通用状态，可被多本剑修秘籍使用
- 每层 剑痕：受到剑术攻击时，攻击者精准 +2
- 精准收益上限：最多按 9层剑痕 计算，即精准 +18
- 持续时间：2个目标回合
- 再次施加 剑痕 时刷新持续时间
- 被消耗的 剑痕 立即从目标身上扣除

### 折损

- 折损 是折枝剑谱施加在敌人身上的专属状态
- 每层 折损：护心 -4%
- 护心下降最多按 5层折损 计算，即护心 -20%
- 持续时间：2个目标回合
- 再次施加 折损 时刷新持续时间
- 摧枝一剑 可以消耗目标全部 折损 获得爆发伤害

### 折枝剑势

- 折枝剑势 是本秘籍的专属剑势，由心法牌 折枝·断势 承载
- 折枝剑势 专注于把 剑痕 转成 外伤 与 折损
- 每次自身行动开始时，若处于 折枝剑势，消耗 1层剑意
- 若剑意不足，本次自身行动期间内 折枝剑势 失效
- 处于 折枝剑势 时，每当折枝系牌消耗 剑痕 向目标弃牌堆加入 外伤，同时向目标施加 1层折损

辅修版：

- 开启时获得 1层剑意
- 每次自身行动期间第一次施加 折损 时，获得精准 +4，持续到本次自身行动期间结束

主修版：

- 开启时获得 2层剑意
- 每次自身行动期间第一次施加 折损 时，获得精准 +6，持续到本次自身行动期间结束
- 每次自身行动期间第一次对已有 外伤 的目标施加 折损 时，额外施加 1层剑痕

### 外伤联动

- 折枝剑谱通过消耗 剑痕 向目标弃牌堆加入 外伤
- 外伤 在手牌中时，按伤势业障牌规则降低行动速度、遁身距离、遁身精力效率与身法
- 折枝剑谱的爆发牌会读取目标手牌中的 外伤，提高会心或伤害

## 拂枝卷

- 学成可修至：云息三层
- 学习条件：
  - 有灵根即可
- 学会永久属性：
  - 剑道造诣 +1.5
  - 体魄 +1.25
  - 敏捷 +0.25
- 习得：
  - 拂枝点痕 *2
  - 照痕养锋 *1
- 纳气：
  - 精准 +4
  - 会心 +2
- 化法：
  - 2张 斩剑 -> 2张 拂枝点痕
  - 1张 养锋 -> 1张 照痕养锋

### 拂枝点痕

- 类型：攻伐牌
- 耗费：精力 2、法力 0
- 目标：单体敌人
；1-1
- 伤害类型：物理
- 伤害公式：
  - 7 + 剑道造诣×0.48 + 敏捷×0.16 + 体魄×0.12
- 效果：
  - 命中后获得 1层剑意
  - 命中后向目标施加 1层剑痕
  - 若目标在本次攻击前没有剑痕，额外施加 1层剑痕
- 描述：
  - 剑若拂枝，轻处留痕。命中后获得1层剑意并施加剑痕；攻击未留痕目标时额外施加1层剑痕。

### 照痕养锋

- 类型：术诀牌
- 耗费：精力 0、法力 0
- 目标：自身
- 关键词：消耗
- 回复精力：
  - 10 + 剑道造诣×0.28 + 体魄×0.10
- 效果：
  - 若场上存在带有 剑痕 的敌人，获得 1层剑意
  - 若场上存在带有 剑痕 的敌人，本次自身行动期间下一张折枝系攻击牌命中后额外施加 1层剑痕
  - 若场上没有带有剑痕的敌人，额外回复 4点精力，作为连续出招中断后的重启补偿
- 描述：
  - 照痕养锋，枝上微霜。恢复精力；场上有剑痕时获得剑意并令下一张折枝攻击加深剑痕，无痕时则额外回复精力。

## 压枝卷

- 学成可修至：云息六层
- 学习条件：
  - 已学 拂枝卷
  - 剑道造诣 >= 12
  - 敏捷 >= 5
- 学会永久属性：
  - 剑道造诣 +2
  - 体魄 +1.25
  - 敏捷 +0.25
- 习得：
  - 折枝·断势 *1
  - 压枝 *2
  - 折步寻隙 *1
- 纳气：
  - 精准 +4
  - 行动速度 +4
- 化法：
  - 2张 点锋 -> 2张 压枝
  - 1张 基础步法 -> 1张 折步寻隙

### 折枝·断势

- 类型：心法牌
- 耗费：精力 0、法力 0
- 目标：自身
- 心法规则：
  - 心法牌打出后默认离开本场战斗牌堆，不额外标注 消耗 词条
- 辅修效果：
  - 获得 1层剑意
  - 进入 折枝剑势（辅修）
- 主修效果：
  - 获得 2层剑意
  - 进入 折枝剑势（主修）
- 维持：
  - 打出所在的自身行动期间不支付维持消耗，第一次维持发生在下一次自身行动开始时
  - 此后每次自身行动开始时消耗 1层剑意
  - 若剑意不足，本次自身行动期间内 折枝剑势 失效
- 描述：
  - 折枝断势，先夺其形。进入折枝剑势；下一次自身行动起消耗剑意维持，剑意不足时本次自身行动期间失效。

### 压枝

- 类型：攻伐牌
- 耗费：精力 2、法力 0
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 6 + 剑道造诣×0.42 + 敏捷×0.20 + 体魄×0.12
- 效果：
  - 命中后获得 1层剑意
  - 命中后向目标施加 1层剑痕
  - 若目标在本次攻击前已有至少 2层剑痕，本次伤害 +20%
  - 若本次自身行动期间使用过任意遁身牌，本次攻击精准 +4
  - 命中并施加本牌剑痕后，若目标拥有至少 2层剑痕，消耗 2层剑痕，向目标弃牌堆加入 1张外伤
  - 若处于 折枝剑势，因本次消耗剑痕并加入外伤向目标施加 1层折损
- 描述：
  - 压枝，循痕入骨。命中后先施加1层剑痕；若目标随后至少有2层剑痕，则消耗2层并向目标弃牌堆加入1张外伤。攻击前已有2层剑痕时伤害提高；处于折枝剑势时，成功加入外伤后再施加1层折损。

### 折步寻隙

- 类型：遁身牌
- 耗费：精力 2、法力 0
- 目标：自身
- 关键词：消耗
- 效果：
  - 移动 1格
  - 本次自身行动期间下一张折枝系攻击牌精准 +8
  - 若该牌原本因本次自身行动期间使用过遁身牌获得精准 +4，改为精准 +8，两者不叠加
  - 本次自身行动期间下一张折枝系攻击牌若向目标加入 外伤，额外施加 1层折损
- 描述：
  - 折步寻隙，压身递剑。移动1格；本次自身行动期间下一张折枝系攻击牌精准提高。若该牌加入外伤，则额外施加折损。

## 裂柯卷

- 限制：主修向核心卷
- 学成可修至：云息九层
- 学习条件：
  - 已将 折枝剑谱 作为主修
  - 已学 压枝卷
  - 剑道造诣 >= 18
  - 敏捷 >= 7
- 学会永久属性：
  - 剑道造诣 +2.5
  - 体魄 +1.25
  - 敏捷 +0.25
- 主修习得：
  - 裂柯 *1
  - 回锋添痕 *1
- 纳气：
  - 护心 +8
- 化法：
  - 1张 敛息观剑 -> 1张 裂柯
  - 1张 格剑 -> 1张 回锋添痕

### 裂柯

- 类型：攻伐牌
- 耗费：精力 3、法力 0
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 8 + 剑道造诣×0.50 + 敏捷×0.18 + 体魄×0.14
- 效果：
  - 只能以带有 剑痕 的敌人为目标
  - 命中后获得 1层剑意
  - 命中后先向目标施加 1层剑痕，再消耗目标 2层剑痕
  - 若成功消耗 2层剑痕，向目标弃牌堆加入 1张外伤
  - 若目标任一战斗牌区中已有 外伤，额外施加 1层折损
  - 若处于折枝剑势，本次消耗剑痕并加入外伤仍按剑势规则施加 1层折损
- 描述：
  - 裂柯，伤自痕开。只能攻击带有剑痕的敌人；命中后先施加1层剑痕，再消耗2层剑痕并向目标弃牌堆加入1张外伤。目标任一战斗牌区已有外伤时，额外施加1层折损。

### 回锋添痕

- 类型：术诀牌
- 耗费：精力 2、法力 0
- 目标：攻击者；由应对触发对象决定
- 关键词：应对
- 应对条件：
  - 敌方攻击自身时触发
- 效果：
  - 自动打出并获得化解：max(1, floor(剑道造诣/6) + floor(体魄/10))
  - 向攻击者施加 1层剑痕
  - 若攻击者已有 折损，额外获得 1层化解，并刷新其折损持续时间
  - 若当前处于 折枝剑势 且攻击者已有 外伤，额外向攻击者施加 1层折损
- 描述：
  - 回锋添痕，守中藏刺。敌方攻击自身时自动打出，获得化解并向攻击者施加剑痕；对已有折损或外伤之敌可获得额外收益。

### 挑枝断筋

- 类型：攻伐牌
- 耗费：精力 3、法力 1
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 9 + 剑道造诣×0.54 + 敏捷×0.20 + 体魄×0.14
- 效果：
  - 命中后获得 1层剑意
  - 命中后向目标施加 2层剑痕
  - 施加后若目标拥有至少 3层剑痕，消耗 3层剑痕，向目标弃牌堆加入 1张外伤
  - 若成功加入 外伤，向目标施加 1层折损
  - 若处于折枝剑势，成功消耗剑痕并加入外伤时再额外施加 1层折损
  - 若目标任一战斗牌区中已有 外伤，本次攻击会心 +10
- 描述：
  - 挑枝断筋，新旧痕迹一并牵裂。命中后施加2层剑痕；若目标随后至少有3层剑痕，则消耗3层，向目标弃牌堆加入1张外伤，并施加1层折损。

### 摧枝一剑

- 类型：攻伐牌
- 耗费：精力 3、法力 2
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 12 + 剑道造诣×0.68 + 敏捷×0.20 + 体魄×0.16
- 效果：
  - 只能以带有 折损 的敌人为目标
  - 命中判定通过后记录并消耗目标全部 折损，最多计算 5层；未命中不消耗
  - 每记录并消耗 1层折损，本牌伤害 +15%
  - 若目标任一战斗牌区中已有 外伤，本牌会心 +12
  - 若目标身上仍有至少 3层剑痕，额外消耗 3层剑痕，向目标弃牌堆加入 1张外伤
  - 伤害与上述消耗结算后，按目标任一战斗牌区中的外伤总数重新施加剑痕：每 2张外伤 施加 1层剑痕，最多 2层
  - 本牌命中后不获得自身剑意
- 描述：
  - 摧枝一剑，伤尽剑落。命中后消耗目标的折损层数，每层使本次伤害提高15%，最多计算5层；目标已有外伤时会心提高。攻击结算后，每2张外伤使目标重新获得1层剑痕，最多2层。

## 联动说明

- 剑痕 提供命中稳定性，并作为折枝系牌制造外伤的消耗资源
- 外伤 进入目标弃牌堆后，会在后续循环中压低目标行动速度、身法与遁身效率
- 折损 会降低目标护心，并可由 摧枝一剑 消耗以提高伤害
- 折枝剑势 负责把消耗剑痕加入外伤升级为加入外伤并施加折损
- 本秘籍先施加 剑痕，再将剑痕转为 外伤 和 折损，最后用 摧枝一剑 对单个目标打出高伤害
- 拂枝点痕负责无条件开始积累剑痕，压枝负责基础消耗剑痕并加入外伤，裂柯与挑枝断筋负责中后期提高转换效率
- 结算统一采用先施加本牌剑痕，再检查并消耗的顺序；若伤害加成取决于攻击前已有的剑痕，会明确写出攻击前
- 回锋添痕可在敌方回合重新施加剑痕；摧枝一剑结算后，也会根据目标已有外伤重新施加少量剑痕，供后续招式使用
- 根据外伤数量产生的持续效果，统一检查目标所有战斗牌区；只有明确写出手牌的效果才只检查手牌
- 主修差异集中在裂柯卷、摧枝卷与折损爆发
- 可与其他秘籍共用的效果集中在 剑道造诣、剑痕 与 外伤；其他剑修秘籍可以共享这些收益，折枝剑谱则专精于把共享剑痕和外伤转化为 折损 爆发

## 与其他秘籍的联动

- 压枝的步后精准接受任意秘籍来源的遁身牌；折步寻隙只是把通用的 +4 提高到 +8 并追加折损收益。
- 流云剑经、辅修剑诀或未来御剑招式施加的剑痕，都可被折枝牌消耗。
- 照痕养锋产生的是通用剑意，可以供任何当前剑势维持，不限定折枝剑势。
- 外伤进入目标任一战斗牌区后，其他秘籍可根据目标行动受限或已有伤口获得效果；折损仍主要由折枝剑谱施加。
- 折枝负责高效率消耗剑痕；其他秘籍应主要根据剑痕获得效果，避免混修时所有流派都争抢剑痕。
