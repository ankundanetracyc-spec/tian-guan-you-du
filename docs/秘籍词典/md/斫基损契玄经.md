# 斫基损契玄经

> 当前招式盘全效果版，2026-11-08。现行规则与迁移边界见[全效果迁移](../../plans/战斗与构筑/人类招式心法全效果迁移_20261108.md)；数值和名称标注见[首轮平衡](../../plans/战斗与构筑/人类招式首轮平衡与名称标注_20261108.md)。学习门槛、永久奖励及修持数值保留。

可主修、可辅修；主修范围至云息十层。

## 第一卷：秉烛

累计研读：24；境界：凡人；前置：无。

属性条件：灵慧≥5。

永久所得：灵慧+0.5、术法造诣+0.5。修持（仅战斗内）：max_mana_yunxi+1。

心法被动：斫基损契
关键词：周天
效果：法力不足的部分，可燃烧等量法力上限支付，至少保留1点法力上限；无法补足费用时，不可施展。
主修额外效果：曾以燃烧法力上限支付过费用的技能，本场后续施展时，以等量体力替代法力费用。

### 折锋*2

关键词：应对
耗费：体力1、法力1
占格：3×1
目标：随机一名合法敌人
出手方式：近身

效果：对一名随机敌人造成A点（A=round(8+灵慧×0.65+术法造诣×0.20)）近身物理伤害；本次燃烧法力上限补费时，此次攻击不可应对。

本卷无化法。本卷心法与折锋原效果照常生效。

## 第二卷：剪灯

累计研读：48；境界：云息三层；前置：秉烛。

属性条件：灵慧≥6、术法造诣≥0.5。

永久所得：术法造诣+0.5。修持（仅战斗内）：最大生命+10%。

心法被动：斫基损契（沿用第一卷，无新增效果）

### 焚元*1

关键词：周天
耗费：体力1、法力0
占格：2×1
目标：自身

效果：燃烧自身法力上限1点，获得炁2；施放前法力上限须至少为2。每回合限一次。
使用次数：每回合1次；同招共享。

### 化法

适用范围：焚元
占格：1×1

化法追加：焚元施放后，本回合下一项法力费用大于0的技能，法力费用改由燃烧等量法力上限支付；体力费用照常支付。至少保留1点法力上限，不足时不可施展。0法力费用技能不触发；未使用则轮末失效。

## 第三卷：续照

累计研读：84；境界：云息六层；前置：剪灯。

属性条件：灵慧≥8、术法造诣≥1。

永久所得：灵慧+0.5、术法造诣+1。修持（仅战斗内）：物理伤害+5%。

心法被动：斫基损契
关键词：周天
效果：法力不足的部分，可燃烧等量法力上限支付，至少保留1点法力上限；无法补足费用时，不可施展。每回合首次以燃烧法力上限支付技能费用后，技能结算后获得炁1。
主修额外效果：曾以燃烧法力上限支付过费用的技能，本场后续施展时，法力费用改为等量体力费用。

本卷无化法。原架招化法已撤下；本卷心法与修持不变。

## 第四卷：长明

累计研读：128；境界：云息九层；前置：续照。

属性条件：灵慧≥10、术法造诣≥2。

永久所得：术法造诣+1。修持（仅战斗内）：最大生命+10%、物理伤害+5%。

心法被动：斫基损契（沿用第三卷，无新增效果）

本卷无化法。本卷心法与修持照常生效。
