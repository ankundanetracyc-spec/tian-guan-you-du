# 明微抱元经

> 状态：废案（2026/09/25）。照痕、定影、魂隙、抱元观微及其依赖技能链已从项目移除；本文仅保留历史设计，不作为当前实现依据。

## 基本定位

- 类型：蕴神主修功法
- 灵根要求：有灵根即可
- 可作为：主修
- 主修可修至：云息十三层
- 风格：养气固本、照见破绽、神魂攻杀、定影制敌
- 倾向：主神魂攻杀 / 控制；物理牌只保留为基础技能库的过渡手段
- 状态：卷章与首批战斗卡牌已接入；数值与结算持续校验。

## 系统规则

- 学习卷章：新增该卷对应牌。
- 淬炼：提供装配态的战斗收益。
- 化法：改写基础技能库。
- 习得：学习卷章后解锁的可装配卡牌；数量表示可配置张数。
- 本经不引入第二种战斗资源。普通招式只支付精力与当回合法力；照痕是施术者留在目标身上的来源型减益，用于放大施术者自身的神魂伤害并开启定影，不提供物理增伤或物理追击。
- 学习首本可主修蕴神秘籍时，角色锁定蕴神路径；当前复用行炁基础技能库作为仙道底板，本经只通过化法改写该底板，不新增蕴神基础技能库。

## 招式联动总纲

本经以照其形、返其势、定其影、烛其微为一条神魂攻杀循环：

照形定标 -> 留痕攻魂 -> 返照压制 -> 定影锁魂 -> 烛微收束

- 神魂对抗：不存在神魂防御属性。每张神魂牌按自己写明的神魂差值、总神魂、缓冲值、权重和上下限结算；不套用统一伤害倍率。
- 照痕：目标身上的来源型减益。每名施术者在同一目标上的照痕独立计层，基础上限均为 3层；每层仅使该施术者造成的神魂伤害倍率 `×1.15`，三层合计 `×1.52`。后续熟练度升级卡牌可明确提高自身施加照痕的上限。
- 照形 / 留痕：均为神魂攻击；前者定标，后者快速叠加自身来源的照痕并提高后续攻魂收益。
- 返照 / 回光：返照在应对时削弱攻击者并补一记神魂反震；回光将已显露的照痕反照回目标神魂，是中段主力神魂攻击。
- 定影：消耗自身施加在该目标上的 3层照痕，使目标持续至下一次行动结束；行动速度固定 -12、精准固定 -8，并使其受到的下一次神魂伤害倍率 ×1.35。
- 烛微 / 见隙：见隙凿开魂隙，烛微以照痕、定影、魂隙三项条件完成高额神魂收束。

## 状态与增益

- 抱元观微：自身心法状态，持续整场战斗；每次自身行动开始后，首次造成神魂伤害命中时，向受击目标施加 1层自身来源的照痕。
- 照痕：敌方来源型减益，基础上限为每名施术者 3层；只放大该施术者造成的神魂伤害。不同施术者的层数、上限与消耗彼此独立；熟练度升级卡牌可提高自身来源照痕的上限。
- 定影：敌方状态，持续至该目标下一次行动结束；行动速度固定 -12、精准固定 -8，受到的下一次神魂伤害倍率 ×1.35。
- 魂隙：敌方状态，仅能施加给处于定影的目标，持续至该目标下一次行动结束；下一次神魂伤害按受击方原神魂 ×0.65结算。

## 照形篇

- 学成可修至：云息三层
- 学会永久属性：灵慧 +2、神魂 +1
- 习得：抱元观微 *1、照形 *1、留痕 *1
- 淬炼：造成的神魂伤害 +6%。
- 化法：行炁基础技能库加入 照形；为 1张基础攻伐牌追加 留痕 的改写效果。

### 照形

- 类型：攻伐牌
- 关键词：无
- 耗费：精力 1、法力 1
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 5 + 神魂×0.55 + 灵慧×0.30，再 × 取限（0.75, 1.45, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 28) × 0.60)。
- 效果：命中后向目标施加 1层自身来源的照痕；若该目标没有自身来源的照痕，改为施加 2层。
- 描述：先照其形，再察其隙。

### 抱元观微

- 类型：心法牌
- 关键词：固有
- 耗费：精力 0、法力 0
- 目标：自身
- 效果：进入持续整场战斗的抱元观微；每次自身行动开始后，首次造成神魂伤害命中时，向受击目标施加 1层自身来源的照痕。
- 说明：此牌固定出现在初始手牌。它只提供定标能力，不提供本经专属的伤害增益、物理追击或会心。

### 留痕

- 类型：攻伐牌
- 关键词：无
- 耗费：精力 2、法力 1
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 8 + 神魂×0.80 + 灵慧×0.30，再 × 取限（0.65, 1.65, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 20) × 0.95)。
- 效果：命中后向目标施加 1层自身来源的照痕；若该目标已有自身来源的照痕，则改为施加 2层。

## 返照篇

- 学成可修至：云息六层
- 学会永久属性：灵慧 +0.5、神魂 +1
- 习得：返照 *1、回光 *1
- 淬炼：自身施加的【照痕】基础上限 +1层。
- 化法：行炁基础技能库加入 返照；为 1张基础攻伐牌追加 回光 的改写效果。

### 返照

- 类型：守御牌
- 关键词：应对
- 耗费：精力 1、法力 1
- 目标：攻击者；由应对触发对象决定
- 伤害类型：神魂
- 反震伤害公式：最终伤害 = 5 + 神魂×0.55 + 灵慧×0.20，再 × 取限（0.70, 1.50, 1 + (施术者神魂 - 攻击者神魂) / (施术者神魂 + 攻击者神魂 + 24) × 0.70)。
- 效果：攻击者带有自身来源的至少 1层照痕时，敌方攻击自身将触发反震；攻击者精准固定 -8，并受到反震伤害；向攻击者额外施加 1层自身来源的照痕。若该攻击者的自身来源照痕因此达到 3层，其本次攻击最终伤害 ×0.75。

### 回光

- 类型：攻伐牌
- 关键词：无
- 耗费：精力 2、法力 2
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 12 + 神魂×1.05 + 灵慧×0.35，再 × 取限（0.60, 1.85, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 16) × 1.20)。
- 效果：结算伤害时，若目标的自身来源照痕恰为 2层，最终伤害额外 ×1.25；若恰为 3层，最终伤害额外 ×1.40；两项额外倍率互斥。回光不移除照痕。
- 描述：回照已留之痕，使神魂裂隙在层层映照中加深。

## 定影篇

- 学成可修至：云息九层
- 学会永久属性：神魂 +1.5
- 习得：定影 *1、息轮 *1
- 淬炼：对处于【定影】的目标造成的神魂伤害 +8%。
- 化法：行炁基础技能库加入 定影；为 1张基础辅助牌追加 息轮 的改写效果。

### 定影

- 类型：术诀牌
- 关键词：无
- 耗费：精力 2、法力 2
- 目标：单体敌人
- 条件：目标拥有至少 3层自身来源的照痕
- 效果：消耗自身施加在目标身上的 3层照痕，使目标获得定影，持续至该目标下一次行动结束：行动速度固定 -12、精准固定 -8；其受到的下一次神魂伤害倍率 ×1.35。

### 息轮

- 类型：攻伐牌
- 关键词：消耗
- 耗费：精力 2、法力 2
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 9 + 神魂×0.85 + 灵慧×0.25，再 × 取限（0.65, 1.75, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 18) × 1.05)。
- 效果：若目标处于定影，最终伤害再 ×1.35，且自身心境回复固定 +12。

## 烛微篇

- 学成可修至：云息十三层
- 学会永久属性：灵慧 +0.5、神魂 +1.5
- 习得：烛微 *1、见隙 *1
- 淬炼：本回合首次主动打出的神魂牌法力费用 -1（最低为 0）。
- 化法：行炁基础技能库加入 烛微；为 1张基础攻伐牌追加 见隙 的改写效果。

### 烛微

- 类型：攻伐牌
- 关键词：无
- 耗费：精力 3、法力 3
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 16 + 神魂×1.65 + 灵慧×0.65，再 × 取限（0.55, 2.20, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 12) × 1.50)。
- 效果：若目标处于定影，最终伤害再 ×1.60；若同时拥有魂隙，再 ×1.50。本次攻击不移除定影。

### 见隙

- 类型：攻伐牌
- 关键词：无
- 耗费：精力 1、法力 1
- 目标：单体敌人
- 伤害类型：神魂
- 伤害公式：最终伤害 = 7 + 神魂×0.65 + 灵慧×0.25，再 × 取限（0.70, 1.55, 1 + (攻击方神魂 - 受击方神魂) / (攻击方神魂 + 受击方神魂 + 18) × 0.80)。
- 效果：命中后向目标施加 1层自身来源的照痕；若目标处于定影，令其获得魂隙，持续至该目标下一次行动结束：下一次神魂伤害结算时，受击方神魂按原神魂×0.65参与该招式的神魂对抗公式计算。

## 累计收益

- 永久属性：灵慧 +3、神魂 +5。
- 淬炼累计：造成的神魂伤害 +6%；自身施加的【照痕】基础上限 +1层；对处于【定影】的目标造成的神魂伤害 +8%；本回合首次主动打出的神魂牌法力费用 -1（最低为 0）。
- 实战节奏：照形、留痕以神魂攻击在目标身上建立自身来源的照痕；返照在已被自身标记的敌方出手时反震并压低其本次伤害；定影只消耗自身施加的 3层照痕打开锁魂窗口；见隙削弱受击方参与神魂对抗的神魂值，烛微在自身照痕、定影、魂隙三项条件齐备时完成主力收束。
