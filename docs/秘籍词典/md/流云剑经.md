# 流云剑经

## 基本定位

- 类型：剑修秘籍
- 灵根要求：有灵根即可
- 可作为：主修、辅修
- 主修可修至：云息十三层
- 辅修可用至：云息十三层
- 风格：轻灵、走位、连段、持势、多段追击
- 倾向：剑修 / 身法剑
- 状态：规划中

## 系统规则

- 学习卷章：新增该卷对应牌
- 纳气：提供装配态属性
- 化法：改写基础技能库
- 心法牌：作为习得牌进入对应卷章，提供局内剑势
- 习得：学习卷章后解锁的可装配卡牌，可自由装配或卸下，数量表示玩家可配置张数
- 化法技能库变化：装备秘籍并启用化法时，对基础技能库进行替换或额外加入

## 招式联动总纲

流云剑经的招式统一组成以下循环：

轻剑起手 -> 遁身换位 -> 乘步出剑 -> 流云追击 -> 回精 / 补充剑意 -> 继续换位或以千叠追锋收束

各类牌的职责固定如下：

- 掠水云锋：双向衔接牌。先出剑可降低下一张遁身牌消耗，步后出剑则获得会心收益。
- 流云转步：移动后强化下一张由玩家主动打出的剑术攻击牌，提高精准，并使其命中时额外获得剑意。
- 踏云穿锋：移动后的主要攻击牌，提高伤害与会心，并恢复精力。
- 澄心藏锋 / 听澜养意：在连续出招中断时补充剑意或精力，帮助剑势继续维持。
- 截云回锋：在敌方回合防守，并强化下一张由玩家主动打出的剑术攻击牌，使其命中后追加一次追击。
- 千叠流云：消耗积累的剑意、法力与精力完成连续追击，不能无代价无限积累剑意。

标准两回合衔接示例：

1. 掠水云锋 命中，获得剑意并降低下一张遁身牌消耗。
2. 流云转步 调整位置，使下一张由玩家主动打出的剑术攻击牌提高精准，并在命中时额外获得剑意。
3. 踏云穿锋 获得移动后的增伤，回复部分精力，并由流云剑势触发追击。
4. 敌方回合由 截云回锋 防守，使下一张由玩家主动打出的剑术攻击牌提高精准并追加一次追击。
5. 下一次自身行动用 听澜养意 补充剑意，再以普通剑式维持，或用 千叠流云 消耗资源收束。

## 通用 Buff

### 剑意

- 剑意 是剑修通用 buff，应被多本剑修秘籍复用
- 每层 剑意：剑术伤害 +5%
- 剑修基础技能库 中所有攻击牌命中敌人后，获得 1层剑意
- 若当前回合结束时，本次自身行动期间 与 上一回合 都没有获得新的 剑意，则 剑意 清零

### 流云剑势

- 流云剑势 是本秘籍的专属剑势，由心法牌 流云·行势 承载
- 世界内可以存在多种剑势，其他剑修秘籍可以拥有各自的心法牌与剑势
- 流云·行势 只负责开启并维持剑势，不会额外强化下一张招式
- 流云剑势 不是层数资源，而是一种需要持续供养的姿态
- 每次自身行动开始时，若处于 流云剑势，消耗 2层剑意
- 若剑意不足，本次自身行动期间内 流云剑势 失效
- 每张由玩家主动打出的剑术攻击牌命中后，追加一段 流云追击伤害
- 流云追击伤害 每一段单独结算命中 / 闪避与会心
- 流云追击伤害 暂不获得 剑意 提供的剑术伤害加成
- 普通情况下，每张由玩家主动打出的剑术攻击牌最多由剑势触发 1次 流云追击
- 其他招式写明的额外追击，可以在剑势的基础追击之外再追加 1次 流云追击
- 通常情况下，流云追击伤害 不会再次触发追击，也不会获得剑意
- 千叠流云 拥有独立的连续追击规则，可让后续 流云追击伤害 继续判定触发追击

辅修版：

- 精准 +4
- 会心 +4
- 每张由玩家主动打出的剑术攻击牌命中后，追加 流云追击伤害
- 追击伤害：4 + 剑道造诣×0.10 + 敏捷×0.06

主修版：

- 精准 +6
- 会心 +8
- 每张由玩家主动打出的剑术攻击牌命中后，追加 流云追击伤害
- 追击伤害：5 + 剑道造诣×0.13 + 敏捷×0.08
- 每次自身行动期间第一次使用遁身牌后，获得 1层剑意

## 卷章设计

## 卷章境界规划

| 卷次 | 卷名 | 学成可修至 | 学习条件 | 定位 |
| --- | --- | --- | --- | --- |
| 第一卷 | 照水卷 | 云息三层 | 有灵根即可 | 入门观剑、养意、替换基础出剑 |
| 第二卷 | 行云卷 | 云息六层 | 已学 照水卷；敏捷 >= 5；剑道造诣 >= 12 | 身法成型，并提前习得剑势心法牌 |
| 第三卷 | 听澜卷 | 云息九层 | 主修；已学 行云卷；剑道造诣 >= 18；敏捷 >= 7 | 主修核心卷，补足持势与守中回锋 |
| 第四卷 | 叠云卷 | 云息十三层 | 主修；已学 听澜卷；剑道造诣 >= 24；敏捷 >= 9 | 主修收束卷，云势层叠，形成多段追击 |

## 照水卷

- 学成可修至：云息三层
- 学习条件：
  - 有灵根即可
- 学会永久属性：
  - 剑道造诣 +1.5
  - 敏捷 +1.5
- 习得：
  - 掠水云锋 *2
  - 澄心藏锋 *1
- 纳气：
  - 精准 +4
  - 会心 +4
- 化法：
  - 2张 斩剑 -> 2张 掠水云锋
  - 1张 养锋 -> 1张 澄心藏锋

### 掠水云锋

- 类型：攻伐牌
- 耗费：精力 2、法力 0
- 目标：单体敌人
；1-1
- 伤害类型：物理
- 伤害公式：
  - 8 + 剑道造诣×0.52 + 体魄×0.16 + 敏捷×0.12
- 效果：
  - 命中后获得 1层剑意
  - 若本次自身行动期间尚未使用过遁身牌，命中后令本次自身行动期间下一张遁身牌精力消耗 -2
  - 若当前回合使用过 遁身牌，本次攻击会心 +4
- 描述：
  - 剑锋掠水，进退相承。命中后获得1层剑意；若尚未移步，则下一张遁身牌消耗降低；若已移步，则本次攻击会心提高。

### 澄心藏锋

- 类型：术诀牌
- 耗费：精力 0、法力 0
- 目标：自身
- 关键词：消耗
- 回复精力：
  - 12 + 剑道造诣×0.32 + 体魄×0.10
- 效果：
  - 若当前没有 剑意，获得 2层剑意
  - 若当前已有 剑意，获得 1层剑意，并获得护盾：4 + 剑道造诣×0.10
- 描述：
  - 澄心敛息，藏锋养意。恢复精力；没有剑意时获得2层剑意，已有剑意时获得1层剑意并获得少量护盾。

## 行云卷

- 学成可修至：云息六层
- 学习条件：
  - 已学 照水卷
  - 敏捷 >= 5
  - 剑道造诣 >= 12
- 学会永久属性：
  - 剑道造诣 +2
  - 敏捷 +1.5
  - 体魄 +0.5
- 习得：
  - 流云·行势 *1
  - 踏云穿锋 *2
  - 流云转步 *1
- 纳气：
  - 闪避 +6
  - 行动速度 +4
- 化法：
  - 2张 点锋 -> 2张 踏云穿锋
  - 1张 基础步法 -> 1张 流云转步

### 流云·行势

- 类型：心法牌
- 耗费：精力 2、法力 0
- 目标：自身
- 心法规则：
  - 心法牌打出后默认离开本场战斗牌堆，不额外标注 消耗 词条
- 辅修效果：
  - 获得 1层剑意
  - 进入 流云剑势（辅修）
- 主修效果：
  - 获得 2层剑意
  - 进入 流云剑势（主修）
- 维持：
  - 打出所在的自身行动期间不支付维持消耗，第一次维持发生在下一次自身行动开始时
  - 此后每次自身行动开始时消耗 2层剑意
  - 若剑意不足，本次自身行动期间内 流云剑势 失效
- 描述：
  - 行云无定，剑势相随。进入流云剑势；下一次自身行动起消耗剑意维持，剑意不足时本次自身行动期间失效。

### 踏云穿锋

- 类型：攻伐牌
- 耗费：精力 2、法力 0
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 6 + 剑道造诣×0.42 + 敏捷×0.24 + 体魄×0.08
- 效果：
  - 命中后获得 1层剑意
  - 若当前回合使用过 遁身牌，本次伤害 +25%
  - 若当前回合使用过 遁身牌，命中后回复 4点精力，每张踏云穿锋只触发一次
  - 若当前处于 流云剑势，本次攻击会心 +6
- 描述：
  - 踏云递剑，一锋穿隙。命中后获得1层剑意；若本次自身行动期间使用过遁身牌，则提高伤害并恢复少量精力；若处于流云剑势，则本次攻击会心提高。

### 流云转步

- 类型：遁身牌
- 耗费：精力 2、法力 0
- 目标：自身
- 关键词：消耗
- 效果：
  - 移动 2格
  - 本次自身行动期间下一张由玩家主动打出的剑术攻击牌精准 +8
  - 该剑攻击牌命中后额外获得 1层剑意
- 描述：
  - 云回一步，锋随身转。移动2格；本次自身行动期间下一张由玩家主动打出的剑术攻击牌精准提高，命中后额外获得1层剑意。

## 听澜卷

- 限制：主修向核心卷
- 学成可修至：云息九层
- 学习条件：
  - 已将 流云剑经 作为主修
  - 已学 行云卷
  - 剑道造诣 >= 18
  - 敏捷 >= 7
- 学会永久属性：
  - 剑道造诣 +2.5
  - 敏捷 +1
  - 体魄 +0.75
- 主修习得：
  - 听澜养意 *1
  - 截云回锋 *1
- 纳气：
  - 精准 +8
  - 闪避 +6
- 化法：
  - 1张 敛息观剑 -> 1张 听澜养意
  - 1张 格剑 -> 1张 截云回锋

### 听澜养意

- 类型：术诀牌
- 耗费：精力 0、法力 0
- 目标：自身
- 关键词：消耗
- 回复精力：
  - 10 + 剑道造诣×0.24 + 敏捷×0.12
- 效果：
  - 获得 2层剑意
  - 若当前处于 流云剑势，下一次自身行动开始时的 流云剑势 维持消耗减少 1层剑意，最低降至 0
- 描述：
  - 听澜收息，补充剑意如潮。恢复精力并获得2层剑意；若处于流云剑势，则降低下一次自身行动开始时的剑势维持消耗。

### 截云回锋

- 类型：术诀牌
- 耗费：精力 2、法力 0
- 目标：攻击者；由应对触发对象决定
- 关键词：应对
- 应对条件：
  - 敌方攻击自身时触发
- 效果：
  - 自动打出并获得化解：max(1, floor(剑道造诣/6) + floor(敏捷/12))
  - 成功触发后获得 回锋，保留至自身下一次自身行动结束
  - 回锋：下一张由玩家主动打出的剑术攻击牌精准 +6，命中后触发 1次流云追击伤害，随后消耗
  - 回锋触发的追击不会再次触发新的追击
  - 回锋触发的追击若命中，向目标施加 1层剑痕
- 描述：
  - 截云卸力，回锋待发。敌方攻击自身时自动打出，获得化解；下一张由玩家主动打出的剑术攻击牌提高精准，命中后追加一次追击。

## 叠云卷

- 限制：主修向核心卷
- 学成可修至：云息十三层
- 学习条件：
  - 已将 流云剑经 作为主修
  - 已学 听澜卷
  - 剑道造诣 >= 24
  - 敏捷 >= 9
- 学会永久属性：
  - 剑道造诣 +2
  - 敏捷 +1
  - 体魄 +0.75
- 主修习得：
  - 千叠流云 *1
- 纳气：
  - 会心 +8
  - 行动速度 +10
- 化法：
  - 基础技能库额外加入 1张 云行递锋
  - 千叠流云 仅作为本卷习得牌，不通过化法加入或替换基础牌

### 云行递锋

- 类型：遁身牌
- 耗费：精力 2、法力 1
- 目标：自身
- 来源：叠云卷化法
- 关键词：消耗
- 效果：
  - 移动 1格
  - 本次自身行动期间下一张由玩家主动打出的剑术攻击牌命中后，触发 1次流云追击伤害
  - 这次额外触发的 流云追击伤害 不会再次触发追击
  - 若当前处于 流云剑势，下一次自身行动开始时的 流云剑势 维持消耗减少 1层剑意，最低降至 0
- 描述：
  - 云行递锋，剑随身转。移动1格；本次自身行动期间下一张由玩家主动打出的剑术攻击牌命中后触发一次流云追击；若处于流云剑势，则降低下一次自身行动开始时的剑势维持消耗。

### 千叠流云

- 类型：攻伐牌
- 耗费：精力 3、法力 2
- 目标：单体敌人
；1-2
- 伤害类型：物理
- 伤害公式：
  - 10 + 剑道造诣×0.58 + 敏捷×0.22 + 体魄×0.12
- 效果：
  - 若当前不处于 流云剑势，命中后获得 2层剑意，并触发 1次流云追击伤害
  - 若当前处于 流云剑势，本牌命中后不获得自身剑意；由流云剑势触发的基础追击作为本牌第一次追击，不再额外叠加一段
  - 处于 流云剑势 时，第一次 流云追击伤害 结算后，判定是否触发第二次 流云追击伤害
  - 第二次追击初始概率：80%
  - 第一次追击结算前记录当前剑意层数，后续追击概率使用该层数计算
  - 对数系数：min(0.90, log2(记录的剑意层数 + 1) / 4)
  - 第三次及以后追击概率：本次追击概率 = 上一次追击概率 × 对数系数
  - 例如第二次追击成功后，第三次追击概率为 80% × 对数系数
  - 从第二次追击开始，每多触发 1次流云追击伤害，追加消耗 1层剑意、法力 1、精力 6
  - 若无法支付任意一项追加消耗，则停止后续再次追击判定
  - 后续每次触发的 流云追击伤害 与第一次追击伤害相同，不递减
  - 每一次 流云追击伤害 都单独结算命中 / 闪避与会心
  - 流云追击伤害 暂不获得 剑意 提供的剑术伤害加成
  - 若当前回合使用过 遁身牌，本次攻击会心 +10
- 描述：
  - 千叠流云，锋势不绝。若不在流云剑势中，命中后获得2层剑意并触发一次流云追击。若处于流云剑势，则在第一次追击前记录当前剑意层数；第一次追击后有80%概率触发第二次，之后每次追击的触发概率继续降低。自第二次追击起，每次额外追击都会消耗剑意、法力与精力。

## 联动说明

- 流云剑经使用剑修通用 剑意，不额外创建流云层数 buff
- 流云剑势 只负责姿态维持与追击，不负责堆叠层数
- 本秘籍通过 遁身牌、剑术伤害、会心、流云追击伤害 形成轻灵连段
- 基础衔接采用剑接步、步接剑：掠水云锋降低步法消耗，流云转步提高下一张剑术攻击牌的精准与剑意收益，踏云穿锋负责恢复精力
- 防守衔接采用格后回锋：截云回锋在防守后强化下一张由玩家主动打出的剑术攻击牌，使其命中后追加一次追击
- 持续作战由澄心藏锋在连续出招中断时补充剑意，听澜养意负责下一次自身行动的剑势维持；维持消耗的减少效果统一在下一次自身行动开始时结算
- 千叠流云会在额外追击时逐次消耗剑意，因此需要先积累剑意，并在攻击后再次补充
- 主修差异集中在听澜卷、叠云卷与剑势维持收益，不提供主修额外纳气属性

## 与其他秘籍的联动

- 所有本次自身行动期间使用过遁身牌的条件接受任意秘籍来源的遁身牌，不限定流云剑经。
- 剑痕对玩家主动打出的剑术攻击与流云追击都提供精准收益，因此折枝剑谱或辅修剑诀施加剑痕后，流云多段会更稳定。
- 截云回锋追加的追击命中后施加 1层剑痕，可以供折枝招式消耗，也可以触发其他以剑痕为条件的招式。
- 流云招式只根据剑痕获得精准，不会消耗剑痕，避免与折枝剑谱争用剑痕层数。
- 其他秘籍提供的精力回复、剑术攻击减耗和额外追击可以帮助流云继续出招，但每张由玩家主动打出的剑术攻击牌仍最多触发一次流云剑势的基础追击。
