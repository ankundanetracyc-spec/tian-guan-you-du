# 剑修仅辅修秘籍总览

## 总规则

- 只能作为辅修，不能作为主修。
- 没有学成可修至或修炼上限，角色境界只由主修秘籍推进。
- 每卷均有学习要求、学会永久属性、纳气与化法；装入辅修位时整本只能选择纳气或化法一边。
- 通常只有一至两卷，主要为主修秘籍补充移动、施加剑痕、防守或远程攻击手段。
- 通过剑意、剑痕、遁身、应对、护盾、法力等公共联动条件连接主修秘籍。
- 完整数值与逐牌说明见 docs/plans/剑修仅辅修秘籍设计.md。
- 本文件仅保留为设计索引；每本仅辅修秘籍均以自己的独立 Draw.io 作为主图，不再设置总览图。

## 联动方向

- 流云可借剑痕和卸力，提高多段攻击的命中，并在敌方回合结束后继续出招。
- 折枝可借身法与施加剑痕，更快进入消耗剑痕并加入外伤循环。
- 重剑可借卸力降低高消耗攻击的精力压力，并用剑气补充远程攻击。
- 巨剑与御剑后续可分别接入站位、剑痕和剑气联动条件。
