# 太和感物养元宝册

四卷现行秘籍。共授予《乘势再攻》《虚怀纳劲》两项技能；可主修、可辅修，灵根任意，主修可修至云息十层。

## 心法：太和感物养元

关键词：气血、应对

效果：自身每次触发应对后，获得气血1层；受气血上限限制。

第四卷升级：每个完整回合内首次触发应对后，获得气血2层；该回合内其余应对后仍各获得气血1层，均受上限限制。

主修额外效果：无。

## 第一卷：听息

研读值（累计）：24；凡人境及以上；前置：无；研读属性：体魄≥5。学成可修至云息三层。学会永久属性：体魄 +1；体道造诣 +0.5。

修持：最大生命 +15%。

心法被动：太和感物养元（完整效果见心法条目）。

习得：乘势再攻。

### 乘势再攻


关键词：应对

耗费：体力 1、法力 0

目标：指定1名敌方


效果：造成A点物理伤害。目标以应对技能应对此次攻击时，触发一次应对并追加一段攻击，造成A点物理伤害；初始攻击段结算后未造成伤害时，再触发一次应对并追加一段攻击，造成A点物理伤害。两项条件分别判定，同时满足时各触发一次。计算公式：A=round(8 + 体魄×0.65 + 体道造诣×0.2)。

使用次数：不限

冷却：无

## 第二卷：回澜

研读值（累计）：48；云息三层及以上；前置：听息；研读属性：体魄≥6；体道造诣≥0.5。学成可修至云息六层。学会永久属性：体魄 +0.5；体道造诣 +0.5。

修持：气血上限 +1。

心法被动：太和感物养元（沿用第一卷，无新增效果）。

习得：虚怀纳劲。

### 虚怀纳劲


关键词：护盾、应对

耗费：体力 1、法力 0

目标：自身；位于行动队列队首且受到敌方攻击时触发

效果：获得A点护盾。计算公式：A=round(4 + 体魄×0.20 + min(体魄×0.20,神魂×0.20))。

使用次数：不限

冷却：无

## 第三卷：藏锋

研读值（累计）：84；云息六层及以上；前置：回澜；研读属性：体魄≥8；体道造诣≥1。学成可修至云息九层。学会永久属性：体魄 +0.5；体道造诣 +1。

修持：物理伤害 +4%。

心法被动：太和感物养元（沿用第一卷，无新增效果）。

习得：无。

### 化法

适用范围：架招

化法追加：架招触发应对时，若自身至少有1层气血，消耗1层气血，本次架招获得的化解层数改为架招基础化解层数的2倍；否则不消耗气血，化解层数保持基础值。心法仍按应对次数结算气血获得。

## 第四卷：返元

研读值（累计）：128；云息九层及以上；前置：藏锋；研读属性：体魄≥10；体道造诣≥2。学成可修至云息十层。学会永久属性：体魄 +1；体道造诣 +1。

修持：最大生命 +10%；物理伤害 +6%。

心法被动：太和感物养元（第四卷升级：每个完整回合内首次触发应对后获得气血2层；该回合内其余每次触发应对后获得气血1层，均受气血上限限制）。

习得：无。

### 化法

适用范围：乘势再攻

化法追加：每段由《乘势再攻》追加的攻击命中后，独立判定B；判定通过时使目标获得C层僵直。

## 设计说明

定位：提升每回合首次应对收益，以僵直延缓敌方攻势。

战斗风格：《虚怀纳劲》在应对来袭时获得护盾；《乘势再攻》借目标应对或首段无伤追加攻击，第四卷心法提升每回合首次应对收益，化法使追加攻击有概率造成僵直。

成长曲线：第一卷习得《乘势再攻》并建立应对循环；第二卷习得《虚怀纳劲》以应对承接攻势；第三卷以气血强化架招；第四卷提升心法首次应对收益，并使乘势再攻追加攻击有概率造成僵直。

与其他秘籍的区分点：气血由自身触发应对获得，并用于强化架招；第四卷以每回合首次应对增益和追加攻击僵直延展攻防节奏。

## 结算边界

- 《乘势再攻》目标应对此次攻击与初始攻击段未造成伤害分别判定；同时满足时各触发一次应对、各追加一段攻击，心法按两次应对分别结算。
- 同一技能已学卷章的化法追加累积生效。
- 所有追加攻击沿用《乘势再攻》的伤害公式，不额外消耗体力或技能使用次数；追加攻击不重复检查两项条件。
- 第四卷化法对目标应对或首段未造成伤害所追加的每一段攻击，在命中后分别进行一次僵直判定；初始攻击段不判定。僵直1层对应1战斗帧，重复施加刷新为本次层数，不累加；其效果、层数和概率公式见状态规则。
- 僵直期间目标行动条停止推进，但保留已有进度；每推进1战斗帧减少1层，计时跟随战斗倍速；暂停和动作演出期间不递减。
- 每个完整回合指所有角色的行动队列均已结算、跳过或清除后完成的一次规划与行动循环。
- 气血获得受当前上限限制；达到上限时不产生溢出效果。
- 跨境界修正按[状态施加规则](../plans/跨境界状态与净化系统规划.md#24-跨境界修正)直接加入成功率；卡牌境界修正依《乘势再攻》卡牌所属境界计算。

- 跨境界削减倍率：施加者每低一个大境界，概率和时长各乘20%；同境界及更高境界为1。高境界修正：高一大境界+10个百分点，高两大境界及以上+20个百分点，其余为0。层数乘算后向下取整，0层不施加，上限120层。
