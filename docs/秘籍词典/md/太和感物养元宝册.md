# 太和感物养元宝册

四卷设计提案，尚未接入运行时。共授予《叩山》《涵虚》两项技能；可主修、可辅修，灵根任意，主修可修至云息十层。

## 心法：太和感物养元

关键词：气血、应对

效果：自身每次触发应对后，获得<u>气血</u>1层；受<u>气血</u>上限限制。

第四卷升级：每个完整回合内首次触发应对后，获得<u>气血</u>2层；该回合内其余应对后仍各获得<u>气血</u>1层，均受上限限制。

主修额外效果：无。

## 第一卷：听息

研读值（累计）：24；凡人境及以上；前置：无；研读属性：体魄≥5。学成可修至云息三层。学会永久属性：体魄 +1；体道造诣 +0.5。

修持：最大生命 +15%。

心法被动：太和感物养元（完整效果见心法条目）。

习得：叩山。

### 叩山

类型：攻伐

关键词：应对

耗费：体力 1、法力 0

目标：指定1名敌方

伤害类型：物理

效果：造成A点物理伤害。目标以应对技能应对此次攻击时，触发一次应对并追加一段攻击，造成A点物理伤害；初始攻击段结算后未造成伤害时，再触发一次应对并追加一段攻击，造成A点物理伤害。两项条件分别判定，同时满足时各触发一次。计算公式：A=round(8 + 体魄×0.65 + 体道造诣×0.2)。

使用次数：不限

冷却：无

## 第二卷：回澜

研读值（累计）：48；云息三层及以上；前置：听息；研读属性：体魄≥6；体道造诣≥0.5。学成可修至云息六层。学会永久属性：体魄 +0.5；体道造诣 +0.5。

修持：气血上限 +1。

心法被动：太和感物养元（沿用第一卷，无新增效果）。

习得：涵虚。

### 涵虚

类型：守御

关键词：护盾、应对

耗费：体力 1、法力 0

目标：自身；位于行动队列队首且受到敌方攻击时触发

效果：获得A点<u>护盾</u>。计算公式：A=round(4 + 体魄×0.20 + min(体魄×0.20,神魂×0.20))。

使用次数：不限

冷却：无

## 第三卷：藏锋

研读值（累计）：84；云息六层及以上；前置：回澜；研读属性：体魄≥8；体道造诣≥1。学成可修至云息九层。学会永久属性：体魄 +0.5；体道造诣 +1。

修持：物理伤害 +4%。

心法被动：太和感物养元（沿用第一卷，无新增效果）。

习得：无。

### 化法

技能：架招

类型：守御

关键词：气血、化解、应对

耗费：体力 1、法力 0

目标：自身；处于行动队列队首且受到敌方物理攻击时触发

原技能效果：触发时获得A层<u>化解</u>。

化法追加：架招触发应对时，若自身至少有1层<u>气血</u>，消耗1层，本次架招获得B层<u>化解</u>；否则获得A层<u>化解</u>。心法仍按应对次数结算<u>气血</u>获得。计算公式：A=3 + floor(体魄÷4) + floor(min(体魄×0.25,神魂×0.20))；B=2×A。

使用次数：不限

冷却：无

## 第四卷：返元

研读值（累计）：128；云息九层及以上；前置：藏锋；研读属性：体魄≥10；体道造诣≥2。学成可修至云息十层。学会永久属性：体魄 +1；体道造诣 +1。

修持：最大生命 +10%；物理伤害 +6%。

心法被动：太和感物养元（第四卷升级：每个完整回合内首次触发应对后获得<u>气血</u>2层；该回合内其余每次触发应对后获得<u>气血</u>1层，均受<u>气血</u>上限限制）。

习得：无。

### 化法

技能：叩山

类型：攻伐

关键词：应对、僵直

耗费：体力 1、法力 0

目标：指定1名敌方

伤害类型：物理

原技能效果：造成A点物理伤害。目标以应对技能应对此次攻击时，触发一次应对并追加一段攻击，造成A点物理伤害；初始攻击段结算后未造成伤害时，再触发一次应对并追加一段攻击，造成A点物理伤害。两项条件分别判定，同时满足时各触发一次。

化法追加：每段由《叩山》追加的攻击命中后，独立判定B；成功时使目标进入僵直1秒。僵直期间目标行动条停止推进，已有进度保留。计算公式：A=round(8 + 体魄×0.65 + 体道造诣×0.2)；B=clamp(15% + 施加者体魄×1% − 目标体魄×0.75% + 卡牌境界修正 − 跨境界修正, 1%, 99%)。

使用次数：不限

冷却：无

## 设计说明

定位：提升每回合首次应对收益，以僵直延缓敌方攻势。

战斗风格：《涵虚》在应对来袭时获得护盾；《叩山》借目标应对或首段无伤追加攻击，第四卷心法提升每回合首次应对收益，化法使追加攻击有概率造成僵直。

成长曲线：第一卷习得《叩山》并建立应对循环；第二卷习得《涵虚》以应对承接攻势；第三卷以气血强化架招；第四卷提升心法首次应对收益，并使叩山追加攻击有概率造成僵直。

与其他秘籍的区分点：气血由自身触发应对获得，并用于强化架招；第四卷以每回合首次应对增益和追加攻击僵直延展攻防节奏。

## 结算边界

- 《叩山》目标应对此次攻击与初始攻击段未造成伤害分别判定；同时满足时各触发一次应对、各追加一段攻击，心法按两次应对分别结算。
- 同一技能已学卷章的化法追加累积生效。
- 所有追加攻击沿用《叩山》的伤害公式，不额外消耗体力或技能使用次数；追加攻击不重复检查两项条件。
- 第四卷化法对目标应对或首段未造成伤害所追加的每一段攻击，在命中后分别进行一次僵直判定；初始攻击段不判定。僵直不叠层，重复施加刷新持续时间；其效果、时长和概率公式见状态规则。
- 僵直期间目标行动条停止推进，但保留已有进度；持续时间按行动阶段有效时间计算，暂停和动作演出期间不递减。
- 每个完整回合指所有角色的行动队列均已结算、跳过或清除后完成的一次规划与行动循环。
- 气血获得受当前上限限制；达到上限时不产生溢出效果。
- 目标应对结果目前无法回传施招者，相关联动尚待运行时支持。
