# 玄枢含章经

可主修、可辅修，灵根不限；主修可修至云息十层。

## 心法：玄枢含章

关键词：周天

效果：术法槽10限装非应对术法，且不可排入行动队列。周天完成后自动施展；需要目标时随机选择合法目标。无合法目标则落空，不支付费用、不计次数或冷却。自动施展期间再次周天仍清炁、回满法力，但不再次触发自动施展。

## 第一卷：蛰雷

累计研读24；凡人境及以上；灵慧≥5。学会后灵慧+0.5、术法造诣+0.5；习得惊蛰。修持：最大生命+10%。

惊蛰：攻伐，关键词散血，体力0、法力1，目标为指定1名敌方。造成A点物理伤害。本技能不经行动队列施展时，命中后<u>打散</u>目标1层<u>气血</u>。计算公式：A=round(8 + 体魄×0.65 + 体道造诣×0.2)。

化法
技能：惊蛰
类型：攻伐
关键词：散血、穿盾
耗费：体力0、法力1
目标：指定1名敌方
伤害类型：物理
原技能效果：造成A点物理伤害。本技能不经行动队列施展时，命中后<u>打散</u>目标1层<u>气血</u>。计算公式：A=round(8 + 体魄×0.65 + 体道造诣×0.2)。
化法追加：本次攻击无视目标<u>护盾</u>。
使用次数：不限

## 第二卷：云垂

累计研读48；云息三层及以上；前置蛰雷；灵慧≥6、术法造诣≥0.5。学会后术法造诣+0.5；习得云帔。修持：会心+8%。

云帔：守御，关键词护盾，体力0、法力1，目标为自身。自身获得A点<u>护盾</u>。计算公式：A=round(6 + 灵慧×0.20 + 神魂×0.20 + 术法造诣×0.25)。

化法
技能：云帔
类型：守御
关键词：护盾
耗费：体力0、法力1
目标：自身
原技能效果：自身获得A点<u>护盾</u>。计算公式：A=round(6 + 灵慧×0.20 + 神魂×0.20 + 术法造诣×0.25)。
化法追加：术法槽10自动施展时，为当前<u>护盾</u>值最低的一名其他存活队友施加B点<u>护盾</u>；并列时随机选择，没有其他存活队友时不追加。计算公式：B=round(A×0.50)。
使用次数：不限

## 第三卷：折冲

累计研读84；云息六层及以上；前置云垂；灵慧≥8、术法造诣≥1。学会后灵慧+0.5、术法造诣+1；无新增技能。修持：物理伤害+5%。

化法
技能：架招
类型：守御
关键词：化解、护盾、应对
耗费：体力1、法力0
目标：自身；位于队首且受到敌方物理攻击时触发
原技能效果：触发时获得A层<u>化解</u>。计算公式：A=3 + floor(体魄÷4) + floor(min(体魄×0.25,神魂×0.20))。
化法追加：本次来袭的全部伤害段结算后，按架招实际抵消的物理伤害总点数获得等量<u>护盾</u>；未用于抵消伤害的<u>化解</u>不计入。
使用次数：不限

## 第四卷：照影

累计研读128；云息九层及以上；前置折冲；灵慧≥10、术法造诣≥2。学会后术法造诣+1；习得复命。修持：最大生命+10%、物理伤害+7%。

复命：术诀，关键词无，体力0、法力1，另支付被复制技能的费用。复制最近施展的非应对技能，从其合法目标中随机选择目标。复制技能消耗自身使用次数，并受其冷却影响。使用次数：不限。冷却：2回合。

化法
技能：复命
类型：术诀
关键词：护盾
耗费：体力0、法力1，另支付被复制技能的费用
目标：从被复制技能的合法目标中随机选择
原技能效果：复制最近施展的非应对技能；复制技能消耗其自身使用次数，并受其冷却影响。
化法追加：复制的技能施加<u>护盾</u>后，为当前<u>护盾</u>值最低的一名其他存活队友施加等量<u>护盾</u>；并列时随机选择。没有其他存活队友或本次未施加<u>护盾</u>时不追加。
使用次数：不限
冷却：2回合
