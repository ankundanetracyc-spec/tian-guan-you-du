# 玄枢含章经

可主修、可辅修，灵根不限；主修可修至云息十层。

> 2026-10-26设计归属调整（运行时资源待迁移）：云帔基础技能改由个人造诣图谱独立授予，玄枢含章经第二卷不再授予云帔；第二卷原有云帔化法仍保留。当前运行时资源仍按旧配置在第二卷授予云帔。

## 心法：玄枢含章

关键词：周天

效果：术法槽10限装非应对术法，且不可排入行动队列。周天完成后自动施展；需要目标时随机选择合法目标。无合法目标则落空，不支付费用、不计次数或冷却。自动施展期间再次周天仍清炁、回满法力，但不再次触发自动施展。

## 第一卷：蛰雷

累计研读24；凡人境及以上；灵慧≥5。学会后灵慧+0.5、术法造诣+0.5；习得惊蛰。修持：最大生命+10%。

惊蛰：关键词散血，体力0、法力1，目标为指定1名敌方。造成A点物理伤害。本技能不经行动队列施展时，命中后打散目标1层气血。计算公式：A=round(8 + 灵慧×0.65 + 术法造诣×0.20)。

### 化法

适用范围：惊蛰

化法追加：本次攻击无视目标护盾。

## 第二卷：云垂

累计研读48；云息三层及以上；前置蛰雷；灵慧≥6、术法造诣≥0.5。学会后术法造诣+0.5；无新增技能。修持：会心+8%。

云帔基础技能由个人造诣图谱独立参悟，玄枢不重复授予；见[云帔技能卡](../../卡牌词典/基础技能节点/云帔.md)。

### 化法

适用范围：云帔

化法追加：术法槽10自动施展时，为当前护盾值最低的一名其他存活队友施加B点护盾；并列时随机选择，没有其他存活队友时不追加。
计算公式：B=round(云帔本次基础护盾值×0.50)。

## 第三卷：折冲

累计研读84；云息六层及以上；前置云垂；灵慧≥8、术法造诣≥1。学会后灵慧+0.5、术法造诣+1；无新增技能。修持：物理伤害+5%。

### 化法

适用范围：架招

化法追加：本次来袭的全部伤害段结算后，按架招实际抵消的物理伤害总点数获得等量护盾；未用于抵消伤害的化解不计入。

## 第四卷：照影

累计研读128；云息九层及以上；前置折冲；灵慧≥10、术法造诣≥2。学会后术法造诣+1；习得复命。修持：最大生命+10%、物理伤害+7%。

复命：关键词无，体力0、法力1，另支付被复制技能的费用。复制最近施展的非应对技能，从其合法目标中随机选择目标。复制技能消耗自身使用次数，并受其冷却影响。使用次数：不限。冷却：2回合。

### 化法

适用范围：复命

化法追加：复制的技能施加护盾后，为当前护盾值最低的一名其他存活队友施加等量护盾；并列时随机选择。没有其他存活队友或本次未施加护盾时不追加。
