# 玄枢含章经

> 当前招式盘全效果版，2026-11-08。现行规则与迁移边界见[全效果迁移](../../plans/战斗与构筑/人类招式心法全效果迁移_20261108.md)；数值和名称标注见[首轮平衡](../../plans/战斗与构筑/人类招式首轮平衡与名称标注_20261108.md)。学习门槛、永久奖励及修持数值保留。

可主修、可辅修；主修范围至云息十层。

## 第一卷：蛰雷

累计研读：24；境界：无境界限制；前置：无。

属性条件：灵慧≥5。

永久所得：灵慧+0.5、术法造诣+0.5。修持（仅战斗内）：无。

心法被动：玄枢含章
关键词：周天
效果：招式盘内默认放置一枚单格周天指示，可移动转向、不能卸下。指向共边紧邻的一份非应对招式；每回合允许其在普通扫格之外，由周天额外施放一次，照常支付费用并检查原次数及冷却。无效指向或无合法目标时不施放、不付费。额外施放中再次周天只清炁、回满法力，不递归施放。

### 惊蛰*2

关键词：散血
耗费：体力0、法力1
占格：3×1
目标：随机一名合法敌人
出手方式：远程

效果：对一名随机敌人造成A点（A=round(8+灵慧×0.65+术法造诣×0.20)）远程物理伤害；由周天额外施放并命中时，打散目标气血1层。

### 化法

适用范围：惊蛰
占格：1×1

化法追加：由周天额外施放惊蛰时，本次攻击绕过目标护盾，直接作用于生命；目标护盾不变。普通施放时仍按惊蛰原规则结算。

## 第二卷：云垂

累计研读：48；境界：云息三层；前置：蛰雷。

属性条件：灵慧≥6、术法造诣≥0.5。

永久所得：术法造诣+0.5。修持（仅战斗内）：会心+8%。

心法被动：玄枢含章（沿用第一卷，无新增效果）

本卷无化法。

## 第三卷：折冲

累计研读：84；境界：云息六层；前置：云垂。

属性条件：灵慧≥8、术法造诣≥1。

永久所得：灵慧+0.5、术法造诣+1。修持（仅战斗内）：物理伤害+5%。

心法被动：玄枢含章（沿用第一卷，无新增效果）

本卷无化法。原架招化法已撤下，不进入当前构筑。

## 第四卷：照影

累计研读：128；境界：云息九层；前置：折冲。

属性条件：灵慧≥10、术法造诣≥2。

永久所得：术法造诣+1。修持（仅战斗内）：最大生命+10%、物理伤害+7%。

心法被动：玄枢含章（沿用第一卷，无新增效果）

### 复命*1

关键词：无
耗费：体力0、法力1
占格：2×2
目标：自身

效果：复制最近施展的一项非应对招式，不能复制自身；另付原费用，并消耗盘序最前的一份该招式剩余机会。没有剩余机会时不发动、不付费。原次数、冷却照常结算；从原招式合法目标中随机选择。
冷却：2回合；同招共享。

本卷无化法。
