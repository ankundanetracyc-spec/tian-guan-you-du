## 心法：百骸衍枝化生

### 第一卷·养络

关键词：气血

效果：自身气血层数达到5层时显化1只手臂，最多1只。每次近身物理攻击结算时，显化的手臂追加一段A点物理伤害；气血层数变化后立即重新判定显化状态。

主修额外效果：手臂追加攻击伤害提高20%。

计算公式：A=round(1 + 气血层数×0.15 + 体魄×0.10 + 体道造诣×0.15)。

### 第二卷·生枝

关键词：气血

效果：自身气血层数达到4层时显化1只手臂，最多1只。每次近身物理攻击结算时，显化的手臂追加一段A点物理伤害；气血层数变化后立即重新判定显化状态。

主修额外效果：手臂追加攻击伤害提高20%。

计算公式：A=round(1 + 气血层数×0.15 + 体魄×0.10 + 体道造诣×0.15)。

### 第三卷·双擎

关键词：气血、应对、化解

效果：自身气血层数达到4层时显化第1只手臂，达到8层时显化第2只，最多2只。每次近身物理攻击结算时，每只显化手臂各追加一段A点物理伤害；气血层数变化后立即重新判定显化状态。

双臂显化时，受到近身物理攻击并进入伤害结算前，每个来袭技能至多判定一次：以B概率自动应对，获得C层化解。触发后，本次来袭攻击结算完毕时气血层数降低1层，并触发气血层数降低时的回复效果。

主修额外效果：每段手臂追加攻击伤害提高20%。

计算公式：A=round(1 + 气血层数×0.20 + 体魄×0.12 + 体道造诣×0.20)；B=clamp(30% + 4%×(自身气血层数−攻击者气血层数) + 0.5%×自身体魄 + 1%×体道造诣 − 0.5%×攻击者体魄, 5%, 80%)；C=round(1 + 气血层数×0.20 + 体魄×0.10 + 体道造诣×0.20)。

### 第四卷·化生

关键词：气血、应对、化解

效果：自身气血层数达到3层时显化第1只手臂，达到7层时显化第2只，最多2只。每次近身物理攻击结算时，每只显化手臂各追加一段A点物理伤害；气血层数变化后立即重新判定显化状态。

双臂显化时，受到近身物理攻击并进入伤害结算前，每个来袭技能至多判定一次：以B概率自动应对，获得C层化解。触发后，本次来袭攻击结算完毕时气血层数降低1层，并触发气血层数降低时的回复效果。

主修额外效果：每段手臂追加攻击伤害提高20%。

计算公式：A=round(1 + 气血层数×0.20 + 体魄×0.12 + 体道造诣×0.20)；B=clamp(30% + 4%×(自身气血层数−攻击者气血层数) + 0.5%×自身体魄 + 1%×体道造诣 − 0.5%×攻击者体魄, 5%, 80%)；C=round(1 + 气血层数×0.20 + 体魄×0.10 + 体道造诣×0.20)。

## 技能与化法

### 第二卷·生枝习得：血臂撼岳

类型：攻伐

关键词：气血

耗费：体力2、法力0

目标：指定1名敌方

出手方式：近身

伤害类型：物理

效果：造成A点物理伤害。

计算公式：A=round(7 + 体魄×0.55 + 体道造诣×0.25)。

### 第一卷·养络：催血

类型：守御

关键词：生命、气血

耗费：体力1、法力0

目标：自身

原技能效果：获得气血2层。

化法追加：施展前自身气血层数不高于3层时，额外获得气血1层。

### 第二卷·生枝化法：血臂撼岳

类型：攻伐

关键词：气血

耗费：体力2、法力0

目标：指定1名敌方

伤害类型：物理

原技能效果：造成A点物理伤害。

化法追加：至少一只手臂显化时，本技能额外追加一段A点物理伤害。该化法追加段与心法显化手臂追加段分别结算。

计算公式：A=round(7 + 体魄×0.55 + 体道造诣×0.25)。

### 第三卷·双擎：架招

类型：守御

关键词：化解、应对、气血

耗费：体力1、法力0

目标：自身；位于队首且受到敌方物理攻击时触发

原技能效果：获得A层化解；每层抵消本次来袭攻击1点物理伤害，剩余化解在攻击结算后消散。

化法追加：第二只手臂显化时，本次架招额外获得B层化解。

计算公式：A=3 + floor(体魄÷4) + floor(min(体魄×0.25, 神魂×0.20))；B=min(round((3 + floor(体魄÷4) + floor(min(体魄×0.25, 神魂×0.20)))×0.20),20)。

### 第四卷·化生：架招

类型：守御

关键词：化解、应对、气血

耗费：体力1、法力0

目标：自身；位于队首且受到敌方物理攻击时触发

原技能效果：获得A层化解；每层抵消本次来袭攻击1点物理伤害，剩余化解在攻击结算后消散。

化法追加：显化至少一只手臂时，本次架招额外获得化解1层；第二只手臂显化时，额外获得B层化解；本次架招实际抵消至少1点物理伤害后，若自身气血未满，获得气血1层。

计算公式：A=3 + floor(体魄÷4) + floor(min(体魄×0.25, 神魂×0.20))；B=min(round((3 + floor(体魄÷4) + floor(min(体魄×0.25, 神魂×0.20)))×0.20),20)。

## 结算边界

- 出手方式由技能资源显式标记：`attack_style = melee` 为近身，`ranged` 为远程；本书血臂只对近身物理攻击生效，不从动画、接近表现或空间距离推断。
- 只有至少一只手臂显化时，近身物理攻击才追加对应手臂段；每次技能行动按手臂数追加，不按原技能分段数重复触发。
- 双臂自动应对不施放《架招》或其他技能，不占技能槽或行动队列；未触发时不消耗气血。成功触发后，化解按当前来袭攻击的固定抵消池结算，再于本次攻击结束后降低气血1层。
- 气血基础上限、降低气血后的回复及化解池清理沿用公共规则。
- 所有技能均不限使用次数、无额外冷却。
