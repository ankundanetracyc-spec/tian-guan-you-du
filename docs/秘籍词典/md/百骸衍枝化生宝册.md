# 百骸衍枝化生宝册

> 当前招式盘全效果版，2026-11-08。现行规则与迁移边界见[全效果迁移](../../plans/战斗与构筑/人类招式心法全效果迁移_20261108.md)；数值和名称标注见[首轮平衡](../../plans/战斗与构筑/人类招式首轮平衡与名称标注_20261108.md)。学习门槛、永久奖励及修持数值保留。

可主修、可辅修；主修范围至云息十层。

## 第一卷：养络

累计研读：24；境界：凡人；前置：无。

属性条件：体魄≥5、体道造诣≥0。

永久所得：体道造诣+0.5。修持（仅战斗内）：最大生命+5%。

心法被动：百骸衍枝化生
关键词：气血
效果：自身气血层数达到5层时显化1只手臂，最多显化1只。每次近身物理攻击结算时，显化的手臂追加一段A点（A=round(1 + 气血层数×0.15 + 体魄×0.10 + 体道造诣×0.15)）物理伤害；气血层数变化后立即重新判定显化状态。
主修额外效果：手臂追加攻击伤害提高20%。

### 化法

适用范围：催血
占格：1×1

化法追加：施展前自身气血层数不高于3层时，催血改为分段施加气血：施展后立即获得1层；自身下一次近身物理攻击开始时，在判定显臂前获得剩余1层。战斗结束时尚未结算的气血不再获得。

### 血臂撼岳*2

关键词：气血
耗费：体力2、法力0
占格：3×1
目标：随机一名合法敌人
出手方式：近身

效果：对一名随机敌人造成A点（A=round(10+体魄×0.65+体道造诣×0.35)）近身物理伤害。

本卷无化法。本卷心法与修持照常生效。

## 第三卷：双擎

属性条件：体魄≥8、体道造诣≥1。

永久所得：体道造诣+1。修持（仅战斗内）：最大生命+5%。

关键词：气血
效果：自身气血层数达到4层时显化第1只手臂，达到8层时显化第2只，最多显化2只。每次近身物理攻击结算时，每只显化手臂各追加一段A点（A=round(1 + 气血层数×0.20 + 体魄×0.12 + 体道造诣×0.20)）物理伤害；气血层数变化后立即重新判定显化状态。

本卷无化法。原架招化法已撤下；本卷显臂心法继续生效。

### 化法

适用范围：架招
占格：1×1

化法追加：架招扫到并进入待命时，若自身至少显化一只手臂，未触发的待命可延续至下一个共同回合结束；期间触发应对则立即解除。期满仍未触发，待命解除。
