## 第一卷：云舒

心法被动：流云剑势
关键词：剑、剑意
效果：剑意达到6层时，流云剑势生效。带剑关键词的攻伐技能首段命中后，在原技能攻击段结算完毕时追加1段攻击，沿用原目标，造成A点物理伤害。
主修额外效果：触发所需剑意层数减少1层。
计算公式：A=round(2 + 体魄×0.20 + 剑道造诣×0.30)

修持（仅战斗内）：最大生命 +10%

### 化法

适用范围：养锋

化法追加：施放前剑意不高于5层时，额外获得剑意1层；每回合最多触发1次，仍受剑意上限限制。

## 第二卷：回岚

心法被动：流云剑势
关键词：剑、剑意
效果：剑意达到6层时，流云剑势生效。带剑关键词的攻伐技能首段命中后，在原技能攻击段结算完毕时追加1段攻击，沿用原目标，造成A点物理伤害；剑意层数超过6时，每多1层使追加攻击伤害提高1点。
主修额外效果：触发所需剑意层数减少1层。
计算公式：A=round(2 + 体魄×0.20 + 剑道造诣×0.30 + max(本次行动开始时剑意层数−6,0))

修持（仅战斗内）：精准 +8%

### 化法

适用范围：格剑

化法追加：格剑触发并结算后，若剑意达到6层，额外获得剑意1层；每回合最多触发1次，仍受剑意上限限制。

## 第三卷：逐影

心法被动：流云剑势（沿用第二卷，无新增效果）

修持（仅战斗内）：物理伤害 +5%

### 习得：云岚三叠

云岚三叠
资源路径：res://resources/activeskills/舒卷天章/云岚三叠.tres
关键词：剑、剑意
耗费：体力 2
目标：指定1名敌方
出手方式：近身
效果：造成A点物理伤害。首段命中后，以C概率追加攻击；追加攻击命中后，依次以D、E概率继续追加，最多追加3段。任一概率判定失败、攻击未命中或目标离场，后续攻击停止。每段追加攻击均攻击原目标，造成B点物理伤害。计算公式：A=round(5 + 体魄×0.40 + 剑道造诣×0.50)；B=round(2 + 体魄×0.20 + 剑道造诣×0.30 + max(本次行动开始时剑意层数−6,0))；C=clamp(40% + 本次行动开始时剑意层数×5% + 剑道造诣×0.5%,40%,80%)；D=max(0%,C−20个百分点)；E=max(0%,C−40个百分点)。
冷却：无

### 化法

适用范围：云岚三叠

化法追加：首次追加攻击概率提高10个百分点，上限80%。
计算公式：C=min(80%,50% + 本次行动开始时剑意层数×5% + 剑道造诣×0.5%)；D=max(0%,C−20个百分点)；E=max(0%,C−40个百分点)

## 第四卷：天章

心法被动：流云剑势
关键词：剑、剑意
效果：剑意达到6层时，流云剑势生效。带剑关键词的攻伐技能首段命中后，在原技能攻击段结算完毕时追加攻击，沿用原目标；本次行动开始时剑意达到10层，追加2段，其余满足条件时追加1段。每段造成A点物理伤害。《云岚三叠》按自身攻击段数结算，不另加心法攻击段。
主修额外效果：触发所需剑意层数减少1层。
计算公式：A=round(2 + 体魄×0.20 + 剑道造诣×0.30 + max(本次行动开始时剑意层数−6,0))

修持（仅战斗内）：最大生命 +10%
物理伤害 +7%

### 化法

适用范围：尽锋

化法追加：若本次行动开始时剑意已达到心法要求，且尽锋首段命中，心法追加的每段攻击伤害提高20%。尽锋命中后消耗剑意，不取消本次行动已触发的追加攻击。

## 构筑

构筑主轴：养锋与格剑积累剑意，达到6层后启用流云剑势；第三卷《云岚三叠》以逐段递减的概率追加攻击，最多3段。
心法与追加攻击不消耗剑意；尽锋原有的命中后消耗剑意规则保留。
