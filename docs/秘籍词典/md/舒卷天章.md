# 舒卷天章

> 当前招式盘全效果版，2026-11-08。现行规则与迁移边界见[全效果迁移](../../plans/战斗与构筑/人类招式心法全效果迁移_20261108.md)；数值和名称标注见[首轮平衡](../../plans/战斗与构筑/人类招式首轮平衡与名称标注_20261108.md)。学习门槛、永久奖励及修持数值保留。

可主修、可辅修；主修范围至云息十层。

## 第一卷：云舒

累计研读：24；境界：凡人；前置：无。

属性条件：体魄≥6、剑道造诣≥0。

永久所得：体魄+0.5、剑道造诣+0.5。修持（仅战斗内）：最大生命+10%。

心法被动：流云剑势
关键词：剑、剑意
效果：本次行动开始时剑意达到6层，带剑关键词的攻击招式首段命中后，在原招式攻击段结算完毕时追加1段攻击；每段对原目标造成A点（A=round(2 + 体魄×0.20 + 剑道造诣×0.30)）物理伤害。云岚三叠按自身追加段数结算，不另加心法攻击段。
主修额外效果：触发所需剑意层数减少1层。

本卷无化法。

## 第二卷：回岚

累计研读：48；境界：云息三层；前置：云舒。

属性条件：体魄≥7、剑道造诣≥0.5。

永久所得：剑道造诣+0.5。修持（仅战斗内）：精准+8%。

心法被动：流云剑势
关键词：剑、剑意
效果：本次行动开始时剑意达到6层，带剑关键词的攻击招式首段命中后，在原招式攻击段结算完毕时追加1段攻击；每段对原目标造成A点（A=round(2 + 体魄×0.20 + 剑道造诣×0.30 + max(本次行动开始时剑意层数−6,0))）物理伤害。云岚三叠按自身追加段数结算，不另加心法攻击段。
主修额外效果：触发所需剑意层数减少1层。

本卷无化法。

## 第三卷：逐影

累计研读：84；境界：云息六层；前置：回岚。

属性条件：体魄≥8、剑道造诣≥1。

永久所得：剑道造诣+1。修持（仅战斗内）：物理伤害+5%。

心法被动：流云剑势（沿用第二卷，无新增效果）

### 云岚三叠*2

关键词：剑、剑意
耗费：体力2、法力0
占格：2×2
目标：随机一名合法敌人
出手方式：近身

效果：造成A点（A=round(8 + 体魄×0.50 + 剑道造诣×0.60)）物理伤害。首段命中后，以C概率（C=clamp(40% + 本次行动开始时剑意层数×5% + 剑道造诣×0.5%,40%,80%)）追加攻击；追加攻击命中后，依次以D概率（D=max(0%,C−20个百分点)）、E概率（E=max(0%,C−40个百分点)）继续追加，最多追加3段。任一概率判定失败、攻击未命中或目标离场，后续攻击停止。每段追加攻击均攻击原目标，造成B点（B=round(4 + 体魄×0.30 + 剑道造诣×0.50 + max(本次行动开始时剑意层数−6,0)×4)）物理伤害。

### 化法

适用范围：云岚三叠
占格：1×1

化法追加：追加判定失败后仍继续检查下一项既有概率；追加段数和C、D、E概率不变。追加攻击未命中或目标离场时，后续攻击停止。

## 第四卷：天章

累计研读：128；境界：云息九层；前置：逐影。

属性条件：体魄≥10、剑道造诣≥2。

永久所得：体魄+0.5、剑道造诣+1。修持（仅战斗内）：最大生命+10%、物理伤害+7%。

心法被动：流云剑势
关键词：剑、剑意
效果：本次行动开始时剑意达到6层，带剑关键词的攻击招式首段命中后，在原招式攻击段结算完毕时追加攻击；本次行动开始时剑意达到10层则追加2段，否则追加1段；每段对原目标造成A点（A=round(2 + 体魄×0.20 + 剑道造诣×0.30 + max(本次行动开始时剑意层数−6,0))）物理伤害。云岚三叠按自身追加段数结算，不另加心法攻击段。
主修额外效果：触发所需剑意层数减少1层。

本卷无化法。
