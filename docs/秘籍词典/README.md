# 秘籍词典

本目录收秘籍图谱和对应文字稿。

## 一、目录用途

- drawio/：秘籍主图
- md/：秘籍文字稿

## 二、维护规则

- 一本秘籍一张主图
- 一份文字稿对应一张主图
- 图负责结构，文字负责补充
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)

## 三、秘籍图最少要有

- 秘籍总览
- 卷章主链
- 每卷的纳气、化法、习得、状态或技能库改写
