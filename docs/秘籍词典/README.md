# 秘籍词典

化法格式统一遵守[现行规范·四、化法](../plans/云息现行秘籍战斗技能与费用规范.md#四化法)：完整“原技能效果：”在前，下一行单列“化法追加：”；次数、回合冷却各占一行。习得框不放化法内容，不逐框复述通用应对与空放规则。七本现行图谱、八本待审提案和模板均适用。

本目录收秘籍图谱和对应文字稿。

现行数值：[研读奖励、造诣门槛与十五本逐卷修持初调](../plans/云息秘籍研读奖励与修持数值初调_20261012.md)。七本现行秘籍同步运行时，八本提案仅更新图谱；造诣每卷0.5—1，四卷合计3。

## 二、维护规则

- 一本秘籍一张主图
- 一份文字稿对应一张主图
- 图负责结构，文字负责补充
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)

- 秘籍总览
- 卷章主链
- 每卷的修持、化法、习得、状态或技能库改写
