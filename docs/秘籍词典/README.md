现行数值：[研读奖励、造诣门槛与十五本逐卷修持初调](../plans/云息秘籍研读奖励与修持数值初调_20261012.md)。十一本现行秘籍同步运行时，七本提案仅更新图谱；造诣每卷0.5—1，四卷合计3。

## 斫基损契玄经（现行）

四卷为秉烛、剪灯、续照、长明。法力不足时可燃烧法力上限补足费用，至少保留1点；主修可将该技能后续的法力费用改为体力费用。授予《折锋》《焚元》两项技能；第三卷心法在燃烧法力上限支付技能费用后产炁，第四卷《折锋》化法在法力上限为1时禁止应对。详见[图谱](drawio/初步设计好的/斫基损契玄经.drawio)、[文字稿](md/斫基损契玄经.md)与[卡牌图](../卡牌词典/秘籍技能/斫基损契玄经/)。
