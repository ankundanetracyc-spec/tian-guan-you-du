## 文件分类

- `drawio/初步设计好的/`：已确认五本主图。

- `md/`：对应图谱的文字展开。
- [预览](预览/README.md)：从当前 drawio 原生导出的 PNG。
- `../卡牌词典/秘籍技能/<秘籍名>/`：技能、心法与化法卡图。
