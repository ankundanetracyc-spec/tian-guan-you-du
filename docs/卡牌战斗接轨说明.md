# 卡牌战斗接轨（2026-09-06）

> 即时战斗迁移补充（2026-09-20）：战斗场景已改为固定技能槽与独立队列；本页关于手牌、牌堆和回合清理的条目仅适用于铸玄基牌局与卡牌回归测试，不再作为即时战斗操作规则。云息凝核现采用八回合时机小游戏。

## 数据口径

- 现有锻躯牌的费用、公式、条件以《锻躯气血体系卡牌规划.xlsx》的“卡牌总表”为准，不使用“基础技能库升级”中冲突的基础数值。
- 状态说明参考《战斗状态与Buff词典.xlsx》。提取结果保存在 `resources/card_reference.json`；游戏不直接读取 Excel。以后修改表格需要同步此快照与相关卡牌资源、结算代码。
- 已确认初始技能库保持应敌×6、架招×4、养息×2、痛击×1；锻躯基础技能库同步为发劲×5、催血×2、平息×1、卸力×4、撼山×1。
- 本轮针对已有资源接轨，不代表卡表中所有“策划待实装”牌已经制作完成。

## 手牌与关键词

- 结束自身回合：整手保留，剩余精力保留供应对支付。
- 自身下回合开始：旧手牌进入弃牌堆，然后抽牌；“保留”跨过清理，“虚无”在清理时移出本场战斗。
- 应对仅从手牌自动使用，检查攻击类型和费用。一张敌方攻击牌最多触发一张应对，多段伤害不会逐段重复抽取应对牌。
- 消耗牌使用后进入移除区。架招、卸力、承机的化解按卡表公式计算，避免特殊效果与状态配置重复叠加。
- 现有乘势攻击牌按上一张主动牌检查条件，使用资源中的属性系数计算会心率加成。

## 展示

- 牌面只显示当前持有者计算后的整数；自身增伤与结算共用入口，目标防御、命中和会心在攻击时结算。
- 通用关键词解释不在牌面重复铺开；长按右侧只展示实际被划线的词条，相关公式放入对应词条。右侧没有独立的精力、法力信息栏。
- 长牌文按长度调整文字区域；牌类标签随实际类别变化。
- 战斗快照保留体道、剑道、术法造诣，避免进入战斗后少算属性加成。

## 回归验证

`CardSystemSmoke.tscn` 是旧手牌/牌堆与卡面布局回归场景，仅供铸玄基牌局底座和历史卡牌组件使用；它仍含即时战斗迁移前的冷却、准备帧断言，不作为即时队列战斗规则的验收入口。

即时队列物理减伤规则使用独立场景验证：先运行 `dotnet build Stacklands.csproj --no-restore`，再用项目 Godot 启动 `res://tscn/battle/InstantBattleDamageSmoke.tscn`。它检查独立减伤乘算、内景心法开关、90% 百分比减伤上限、物防最低伤害、完全化解与神魂伤害边界；并调用真实 `SkillExecutor` 结算三段《冯虚》，覆盖跨段化解池、逐段读取伤势、护盾吸收、外伤生成和内景心法 Buff 栏专属图标。本轮实跑结果：20 项检查通过；构建无警告、无错误，Godot 冒烟场景正常退出。
