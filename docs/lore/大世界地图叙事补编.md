# 昭明界地图叙事补编

这份补编用于把地理、势力与探索机制绑在一起：每一处地名都应对应一个时代遗留、一个现实势力和一种可发生的故事，而不只是好看的标签。

## 一、白玉京与断天航路

“天上白玉京，十二楼五城”并非一座完整留存的天界城池。垂天纪末，仙庭曾以天柱山为锚，在云海中铸成十二座巡天楼与五座浮城，统称白玉京。道崩之劫后，浮城大多坠毁或遁入虚空；当代修士见到的“白玉京”，只是其中一座楼城在灵潮、月相与天道裂隙重合时投下的短暂投影。

因此白玉京是 L1 世界要地，却不应提供稳定的城镇功能。它是长期剧情目标：玩家先在各地取得“巡天铜符”“云阶残图”“五城钟铭”，才可在特定时节进入一次。

## 二、大光道与人间路网

大光道取“光被四表”之意，是人道纪末由人皇旧部铺设的石道。它连接玉虚道域、千机城和东部海港，原本兼作凡人迁徙、修士传讯与灵卫调度之路。道崩后，石道被山河切断；残存路段夜里会出现无主灯火，沿着它们前行的人，偶尔能抵达已从现世消失的旧驿站。

大光道是 L2 枢纽：它给旅队减行程、承载商队与护送任务，也最适合刷新“古驿开门”“失路行商”“巡天傀儡”等 L4 事件。

## 四、势力与地点如何产生冲突

- 玉虚仙宗想以白玉京残图追查天道裂隙，天机阁认为贸然进入会重演仙庭灾难。
- 天衡仙国需要大光道恢复跨区域运输，西陵戍所则担心古道复通会引来鬼哭岭的阴物。
- 万妖谷将建木视为祖脉，人族药师会却觊觎其问道果；这不是单纯善恶，而是生存权与传承权的矛盾。
- 蓬莱仙盟以航路谋生，海族认为弱水津和天问崖的异变正侵蚀海脉。

这些冲突应使 L4 事件有来源：事件不是随机奖励点，而是某个势力、地脉或旧时代遗产在地图上短暂露出的后果。

## 六、L4 海域与山野事件模板

“海兽巢”“矿洞”“瘴气洞”不作为固定地名。它们改为临时事件类型：例如海域可刷出“月潮鲸歌”“沉舟龙息”“蜃门回航”，山地可刷出“地火裂脉”“坍道遗府”，南荒可刷出“相柳毒雨”“建木落果”。这些事件会带出对应势力的委托或敌对，而不会占据常驻地图。
