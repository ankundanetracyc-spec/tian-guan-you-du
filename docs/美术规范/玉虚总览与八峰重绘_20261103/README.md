## 用户当前要求

- 大世界的配色与笔触作为风格依据，整套沿用同一母图作为直接色调参照，不为不同峰另设冷暖、浓淡或主题滤镜。
- 一级大宗体现辽阔山域与无从一眼数尽的宫阙规模。总览不用靠细描每栋建筑体现内容，山脉、屋脊群、延伸和遮挡建立规模感。
- 最新裁定：八峰内景仅画一处局部功能场景，取景与现有场景同层级；不再要求每张内景同时表达大片宫阙和整个峰域。宏观规模主要交给总览，局部优先交代地面、通路与入口。
- 本轮追加：各峰实装原图分别提供地形、取景和功能关系，和光峰已认可试稿只提供笔触与色调；不把一个大院构图重复套给各峰。总览以高峻叠嶂、遮挡和出画建立规模，不再沿用大弯路山城方案。
- 保留俯瞰视角；四边与角落清晰，不用虚化、渐隐白边或景深模糊掩盖范围。
- 无人物、文字、界面、签牌或水印。环境图不预先烘焙交互控件。
