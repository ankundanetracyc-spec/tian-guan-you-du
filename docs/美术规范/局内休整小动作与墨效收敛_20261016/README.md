## 本轮调整

- **人物休整动作**：新增男女各一张站立收势静帧，将抬起／伸出的手臂轻收至腹前，另一手靠近腰间，短暂调息再回待机；沿用默认衣装、中分长披与留白侧脸。待机→收势约0.16秒过渡，后段约0.27秒回待机，人物地面原点与运行比例保持，不增加休整镜头拉近。
- **休整特效**：保留48张透明PNG序列帧，重新烘焙7个短寿命光点及两条短气息，位于身前手掌／腹部附近。显示区域从1375×1600改为460×550，图中实际点线范围更小；没有全身光环或地面圈。人物为两张关键姿势之间的过渡，特效仍按30帧／秒明确逐帧播放。
- **手刀命中**：保留原挥砍轨迹与接触定格，将末端爆点显示宽高从1000缩至560，约为原宽度56%、面积31%；位置仍对齐手掌末端。16帧挥砍和20帧命中规格保持。
- **自然消散**：移除通过固定噪声阈值密集挖洞的退场方式。主笔触按不同区域连续淡出，少量碎墨／光点各自有出生时刻、寿命、阻尼漂移和透明度衰减；墨屑带轻微下坠，避免同一时刻齐消失。受击与防御也沿用这种消散修订，源纹理、姿势和接触节奏不变。

上述运动均烘焙进PNG及透明图集。运行时继续使用SpriteFrames／AnimatedSprite2D和统一时间轴，没有改成实时粒子发射器。
