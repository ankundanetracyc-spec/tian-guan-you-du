## 已接入内容

行囊以正式角色库存为数据源，胸前6×4、左右袖各3×4、腰间6×4、背囊6×8，共120格。普通物品独立占格并有稳定实例身份；清册按相同定义汇总数量，双击逐件循环定位，各组独立记忆进度。搜索和十分类不改真实摆放。右侧按实际尺寸拖动，R每次顺时针转90度，落格独立预览；越界、重叠、Esc及失焦取消，不改变数量或原位。坐标和朝向进入 `HumanData.inventory_placements`，资源保存／重载已专项验证。

交易为我方可交易目录、我将交出、我将获得、对方可交易目录。行内不放图标，共用悬停仍展示物品图及真实占格；沿用原数量选择、估值、精力和关系规则。成交重新校验实时数量和完整空间，失败不部分转移、不扣精力。角色入包、出包、炼丹及锻造等调用共享空间模型。

善功堂保留指定屋檐木框、灰蓝山水列头、暖纸细纹、细描边及雕花兑换底栏。默认材料／秘籍／器物／丹药四列，九类横滑，各列独立纵滚；搜索和原确认流程保留。显示实际贡献余额，单件兑换经正式 `YuxuExchangePurchase` 复核资格、实时价格、余额及空间后，原子扣贡献并入包。当前目录74项；[价格表](../../plans/物品与装备/善功堂临时贡献价_20261030.json)81项是配置候选，现行可用性筛选仍生效。

领取入口按选中批次精确试放，一次提交；失败保留领取队列，不部分入包。整理领取前的假想丢弃使用深复制角色数据校验，不提前改变实际行囊。通用采集与战利品按批次试放，失败复用领取页，连续掉落依次展示；旧田陌／后山专属入口已删除。该领取流队列仅在当前场景内保留，没有新增存档待安置容器。

实际玩家的库存变化事件已连接自动保存标记，单独移动或旋转物品也会记录。正式快照深复制摆放数据；领取、交易、善功堂均读取相同空间模型。
