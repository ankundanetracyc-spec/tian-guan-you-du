## 本轮对齐修正

用户反馈不对齐后，逐项对照炼丹原生界面和炼器纸墨样稿：

- 顶栏采用炼器的紧凑行，按钮字号22、高46、设计顶边18；返回位于1534×18，与炼丹、炼器一致。
- 数量减号、输入框、加号均为36高，分别有独立边框和间隔。纸面样式不再把小按钮撑回46高或撑宽造成重叠。
- 单行文字垂直居中；换行文字按实际行数限制在卡内，修复首次零宽排版把说明区撑高、文字落到卡外的问题。
- 左右区域标题、卡片起点与底边统一；用度标签、数字和耗时按列对齐，底部确认按钮左右留白一致。
- 继续保留准备页无成品字段、竖排技艺、中央只放意象、普通纸面页签及直线分隔的既有裁定。

## 实际验证

最终项目编译0警告、0错误。1280×720和1920×1080各394项通过，共788项；每档11张原生Viewport截图，共22张，已逐页实看。

验收使用真实鼠标输入命中控件，覆盖选材、用量、技艺、保留功用、购笔、研习、三工艺制作与鉴看、重复点击保护及地点返回。包含顶栏中心／字号／坐标、数量三件组同高与互不重叠、留墨按钮间距、左右底边、技艺卡与材料卡实际文字边界检查。

规则检查覆盖50项原料自动发现、逐品级来源及批次守恒、0／80造诣的真实保留和用度差异、缺料／缺精力／缺灵识不扣、满包购笔不扣、无聚不能凝毫、无通行不能透纸、两张基础包不被第一张聚势吞用、存读档后改900造诣也不重算旧成品。两份报告：[1280](talisman_checks_1280.json)、[1920](talisman_checks_1920.json)。
