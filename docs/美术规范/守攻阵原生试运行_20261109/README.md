## 先试这三个动作

1. 把试验生命设为20：比较器进入守备，真实支付2阵能取得18护罩；本次初始12阵能变为10。
2. 再设为45，点“完成一次施法”：保留守备，事件被开关拦下，敌人不受伤，也没有新增付款。
3. 再设为80，点“完成一次施法”：本器罩停止，实际支付3阵能，敌方生命100变91，源10变7。

上述数值是默认试验参数，均可在右侧修改后重新试运行，不是正式图谱价格或强度。“完成施法”输入表示上游施法已经成立，不额外制作或施放一张牌。

普通补盾与本器护罩共用公共盾。先开罩、再普通补盾、受击后转攻，可看到关罩只撤本器剩余，普通来源仍在。同段再次转守不刷新已取得过的容量。

下一共同回合会实际补给并尝试续付；观察未知时不攻击，仍运行的护罩继续真实续费。供能来源失效时不能输出，也不自动补能；恢复不追补。重发上次使用同一事实身份，不复制伤害、护罩、补给或费用。
