## 本轮裁定

- 无论双方人数，人群主体各自居于左右半边战场的中间，不偏向中央分界线；本轮支持双方各 1～5 单位。
- 依据双方较多人数统一使用目标高度 320／280／240／210／190；上下错排，各自人数决定阵型。少人一方不额外放大。
- 用户确认生成男、女修士各一张，脸部不画五官；采用当前生灵图鉴的哑光淡彩、细墨线、手绘笔触。男款青绿，女款蓝灰与象牙白，纹饰使用低饱和米色。
- 新图用于局内人物主体；战前、结算及人物详情的真实外观头像继续由原人物外观系统显示。

## 站位锚点

以 1672×941 为设计画布，可见人群外包框中心为我方 (418,540)、敌方 (1254,540)。按有效 Alpha 轮廓计算中心，不把图片透明留边算入人物高度；前后排高度随统一缩放调整，前排脚点在技能栏上方约 y=720。单个角色也使用相同人群中心，因此 1 对 5 时双方主体仍在同一高度附近。
