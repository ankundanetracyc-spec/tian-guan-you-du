## 已接入

左清单按正式定义汇总，图标、名称、数量分列；单击切换自动放入选择，拖动逐件领取。右侧胸前、两袖、腰间、背囊保持原120格，复用 `StorageItemSlot`、原生空间绘制控件、物品悬停与角色空间数据。物品跟手、R旋转、抓取点变换及有效/无效轮廓与现有行囊一致。

工作台中的移动、放入和丢弃先预览；结束领取时一次性写入精确实例身份、位置和朝向。拖出右行囊正文、放到左清单或下方提示区表示丢弃，不产生可返回拾取的暂存区。正文内分区间的空白、碰撞或界外放置失败回原处。使用中物品与突破预留药受保护。

自动放入整批试放，不挪动其他物品；失败恢复本次自动放入前的布局。结束时保留已经放入的产物，确认放弃剩余；按来源和实际数量拆分领取/放弃回调。提交期间屏蔽重入，每次成功只发布一次库存变化，获得通知只统计实际入包物品。真实库存若在界面外发生变化，提交失败并重新读取库存，不消费奖励或覆盖别人已经完成的修改。

正式规则见[主案当前领取节](../../plans/行囊索引与空间联动方案_20261029.md#2026-11-03-领取改为同屏空间收纳当前)。普通行囊界外松手仍撤销，新的丢弃语义仅用于领取工作台。没有待领奖励存档、储物戒指或旧档迁移改动。

独立人工体验场景为 `res://tscn/scene/ItemClaimPreviewScene.tscn`，使用临时人物，结束回首页，不读取或写入活动人物存档。

## 理想图来源

理想图使用内置 imagegen，以原生行囊截图为风格与布局参考生成；当前实装复用既有纸墨素材和物品图标，未把生成图作为整张UI背景。生成提示主要要求：暖纸水墨、左待领取清单、右同格尺度五区120格、拖入与R旋转、拖出丢弃、自动放入、确认领取及放弃剩余，不设暂存。
