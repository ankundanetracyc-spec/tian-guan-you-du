## 三页分别看什么

| 页面 | 主要操作 | 玩家字段与呈现 |
| --- | --- | --- |
| 制符纸 | 选择本批材料、增减份数，选养脉／凝纹／叠脉。 | 灵性、承墨量、渗墨性、韧性；仅在成品鉴看和选用已有纸墨时展示，准备页改为竖排技艺。 |
| 研墨 | 选择墨源与调和料、份数、想保留的功用，选均研／澄灵／聚蕴。 | 四字段仅在成品鉴看和选用时展示；准备页为竖排技艺与保留功用。 |
| 画符 | 选符谱、实际纸墨笔、一种写法与准备张数。 | 比较所选纸墨的四字段，以少量配伍提醒辅助选择；进阶配置按需展开。 |

中央分别用悬纸、融墨和成纹意象，不要求手动描线、研磨节奏或操作现实造纸器具。三工艺可以直接切换，各自保留当前网页中的选择；画符可直接用成品夹具，不需要先做前两页。

## 查看与操作

1. 游戏页眉切换制符纸、研墨、画符。右上“返回 ▸”只收起本样稿，可再回到案前，不跳转或修改游戏。
2. 制纸、研墨点击“选材”，按质地筛选，按名称、五行或功用文字搜索；可显示不适用材料并查看原因。材料卡支持查看真实资料、增减正整数份数与移除，另有清空。
3. 制纸只接纤维、液体与可选胶；研墨接致密、颗粒、液体主源及可选胶，纤维不接收。纯液料可调墨；纯胶不是墨源。缺必要质地时说明原因，不能开始。
4. 研墨从已选材料的真实功用中勾选想保留的项，最多四项；选择只是保留意图，不保证每项满额或得出某个品阶。
5. 画符更换纸、墨、笔与符谱。纸墨按甲批、乙批等区别数据，不设置厚承纸等预设纸种；可兼用多份墨，没有三个必填墨岗位。缺符谱必要来源时显示不足，例如炎矢符在当前三份墨中缺破来源。
6. 常法可直接使用，也可选择已展示的写法，查看其用途；进阶配置呈现沿用符谱的必要辅纹、收口优先预留和本批相同情形沿用处置，不逐笔编辑。
7. 顶部“准备／自动过程／鉴看样例／应变样例”为外部看稿工具，不属于正式游戏操作。鉴看与应变状态的提示会明确展示夹具性质。
8. 开始只演示自动过程，可跳过。应变是独立手填工况，匀息镇纹仅在夹具有镇来源时可选；未选择处置时跳过不能代选。画符鉴看的符效与张数仍为“—”。
9. 配伍册可载入演示配伍，也可题名记录当前选择；仅存当前网页内存，刷新复位，不读写人物存档或浏览器持久存储。

## 鉴看为什么使用样例

纸墨的转换曲线、字段单位、产物品阶、产量及正式用度还没有标定。本页不能根据真实材料假算一个确定产物，所以准备时不预报成品字段、品阶、张数、成功率或符效。

符纸、符墨鉴看读取独立手填成品夹具，用来展示完成后怎样阅读四项字段。它们不根据当前投料变化，不消耗原料、不生成库存；“去画符”只是进入画符页，不把鉴看样例作为新产物加入行囊。画符仍读取独立已备纸墨夹具。

实际原料与夹具边界：

- **真实资料**：50项现有材料的身份、图标、质地、五行、功用及真实品级已核对资源。每种12份是统一演示库存，非人物库存。
- **手填夹具**：两批符纸、三批符墨、两支符笔及符谱展示项；纸墨字段、数量与符笔能力均不代表已验证配方或正式生产结果。
- **只做提示的规则**：选材资格、份数边界、实际必要作用是否存在、功用保留上限和定性生克关系；不计算真实来源消耗、收益、产量、费用或战斗效果。

详见[目录与夹具声明](catalog.json)、[资格及提示模块](rules.js)和[原料核对](../../plans/百工技艺/制符/符箓原料自动匹配资料核对_20261108.json)。材料功用品级内部1为九品、9为一品，真实来源分层保留，不把最高一项当成全批品级。
