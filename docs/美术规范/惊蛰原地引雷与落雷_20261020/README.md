# 惊蛰：原地提指引雷与自上而下落雷

状态：2026-10-20雷柱修订版，按用户“闪电太细、缺少雷柱感”反馈加厚主雷。惊蛰基础版与化法版共用最新演出，动作与战斗规则保持原样。

## 雷柱修订（当前）

主雷由细电线改为有实体厚度的灰蓝雷柱：不规则柱身包着三道交错冰白电流，外缘只保留窄幅柔光与细小噪点；落下时先见细先导，接触前迅速撑开柱身，主放电短停后收窄复闪，末段破碎为细电消散。外侧分叉仍从柱身向下伸出。没有用放大整张贴图或大范围泛光制造厚度。

落点增加短促的蓝白压地亮痕和破碎椭圆电纹，随后只留小范围分叉、电屑，避免长时间遮住角色。仍为78帧透明PNG，30fps；沿用原0.30秒接触点、接触停顿与局部特写，不新增伤害段、击退、技能费用或范围规则。

## 动作设计

人物原地稳住重心，一手收在腹前，另一手提起并拢的食指、中指引诀；袖摆与披发轻向后扬。使用独立全身关键姿势，不制作骨骼绑定，不向目标前冲。脚下原点、角色大小、留白侧脸和现有衣装保持一致：男碧岚云叶袍、女青瓷云梅袍。

新动作键`cast`共用2048×2048 RGBA透明画布、(1024,1900)地面原点和1375参考身高。两张源图分别人工配准到原待机身高；运行时不单独裁边、缩放或居中。动作约1.25秒，入势0.12秒交接，末段0.18秒回待机；接触停顿暂停同一姿势时钟，不单独增大人物。

## 落雷设计

| 层次 | 表现 | 素材 |
| --- | --- | --- |
| 指端引诀 | 指尖附近三缕细电，收束后熄去，不形成巨大法阵 | 18帧，512² |
| 向下落雷 | 细先导自上向下显露，第9帧撑开实体蓝白雷柱与交错白芯，随后收窄复闪 | 36帧，768×1024 |

共78张透明RGBA PNG，打包SpriteFrames图集，源帧30fps。灰蓝柱身、少量灰紫边缘与交错冰白芯构成亮暗关系，亮度集中在雷柱上，不使用整屏白闪或大片加色泛光。

人形来袭接触点沿用当前0.30秒，主雷第9帧对齐；雷路在接触点短停约0.155秒。命中继续使用既有受力姿势、接触短停、交锋局部取景与微震；雷击不额外叠加旧受击墨效。

雷路始终自上而下，方向不随角色左右镜像翻转。指端电随施法者姿势，落雷按目标脚下定位并在接触后固定，闪避时不会追着撤开的身体移动。起点按可用战斗取景高度调整，实验室保持在展示区内。与当前护罩、人物、墨痕共同进入局部特写。
