# 新器物行囊存取底座

2026-10-23。本轮实现新成器快照与真实行囊组件之间的存取/展示适配，不修改未定的战斗参数，不实施同化。

## 已接通

- `ArtifactInstanceData` 增加可选固定快照字段；旧物品为空，仍按原资源读取。新物品的收益和炼制来源留在完整快照中，不塞入旧内炼/外祭、主功用或五行字段。
- `ForgedArtifactInventory` 从成器快照创建唯一行囊资源，并检查版本、身份和必要字段；保存后重新读取不再次炼制，也不引用可变输入对象。
- 现有角色入包接口承接新资源，重复ID拒绝、同名不同实例分别占格、满包拒绝、移出释放位置。保留已有外观衣物与普通物品占格。
- 正常行囊的图标、悬停和点击详情读取同一份新快照；器物分类显示“器物”。新快照不显示旧主功用、内炼/外祭或整器五行，也不提供旧版装备操作。
- 新器物暂不进入旧装备/战斗分支；不会因此意外提供旧内炼化法、灵识占用或过时收益。

## 验证与边界

最终全量编译成功（0警告、0错误）、47项隔离运行检查及4项新进程读档检查通过。读档使用现行 `PersistentGameSave` 容器和独立测试文件，新进程验证后删除该文件；无正式人物或用户存档写入。新字段为可选追加，不迁移/覆盖既有旧实例，也不提升存档版本。

测试快照取自现有独立炼器公式，测试只证明归档与展示保真。其百分比等旧参数未在此层改成固定值，截图不是新效果平衡样本；物品底座不擅自校准数值。

实际正式炼制仍未接通真实库存扣料、时间/精力提交和成器入包事务。正常工坊仍为原试炼，不提供将免费试炼产物收入正式行囊的按钮。本轮没有向玩家赠送测试器物，也没有实现新装备、单槽变换、D/T或同化。

已验证旧实例入包、装备和卸下兼容，最终源码与“器物”分类文案已重新编译及运行。额外旧战斗集成检查停留在功法目录解析，已结束本次进程，未取得通过结果；不将物品层检查表述为完整战斗回归通过。工作区持剑动画脚本曾出现缺失符号，后续恢复，最终复编无此错误，本轮未修改该动画脚本。

读档检查退出时有1项纹理回收错误；最终带行囊的47项运行日志无此提示。未进行人工鼠标试玩。
