用户指出岚溪一带有明显色差、树木断头。先前像素一致与交互检查不能证明接边美术合格，撤回据此推断整幅视觉已合格的说法。

## 接边处理

修正暖黄纸底被最低RGB分量误判为墨线、缺少相邻局部时未与原连续地形比较的两处错误。对每幅原图测量干净纸色，并平滑校正色差；接边同时比较连续原地形，完整取用选定绘图区的像素，避免叠加出树木、山线的虚影。保留原绘制几何，不采用形变拉扯山体。建筑蒙版重新从最终图提取，名称、逻辑坐标与路线规则保持。

## 用户新增参考：影之刃零的整体地图画风

用户明确强调看的是地图整体风格。参考[公开营地地图画面](https://cdn.mos.cms.futurecdn.net/urxdKj5oNNKf3MjSqMTLkQ.jpg)与[官方实机演示](https://www.youtube.com/watch?v=blh1v1dGJ2s)，研究方向为传统山水舆图的整体组织：

- 连续山势与谷地组织空间，笔法有细线、皴染、浓淡变化；建筑随地形嵌入。
- 山脚与远景渐淡，纸底和留白承接各片地形；地表纹理克制。
- 树、山、建筑有统一的笔触和空间关系，减少孤立的符号感。
- 对照目前版本，重复低峰、粗黑硬轮廓、统一粗壮针叶树及高黄度是整体画风差异，修接边不能替代这部分研究。

本条记录参考研究，不将原作的营地全景、地图结构或交互规则自动改为项目需求。此前用户明确的入口表现、宗门山地、城镇平地与逻辑节点要求继续有效。当前没有完成按此新参考重画整套地图。
