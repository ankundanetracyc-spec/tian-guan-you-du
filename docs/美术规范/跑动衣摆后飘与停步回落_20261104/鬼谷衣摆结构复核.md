## 可直接确认的结构

衣服Sprite **79450** 是一个连续网格，21顶点、19三角形，使用4根骨骼。其下摆没有独立成一个永远不动的前片。

| 骨骼 | 层级与覆盖 |
| --- | --- |
| `shenti1` | 上半身；影响8个顶点 |
| `shenti2` | 下摆根部；影响6个顶点，动画直接控制其位置和旋转 |
| `shenti2_1` | 接在下摆根部之后的中段；影响6个顶点，挂有DynamicBone |
| `shenti2_2` | 中段的子骨骼，覆盖末缘；影响10个顶点 |

顶点数有交叠，因为相邻骨骼混合权重。权重由上身、腰下、中段渐变到下缘，原蒙皮权重和约为1。末骨覆盖下摆的前后轮廓，因此形变不会只发生在被固定前片遮住的背后。
