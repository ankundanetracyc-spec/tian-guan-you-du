# 百川整图与节点落位验收

2026-10-28，按用户认可的简笔舆图、少量森林和细化节点模板完成一套可验收地图。此目录是当前美术与游戏测试入口的记录；早先独立九图、1254分块和母图放大试验保留作历史稿。本轮完成的是整套美术在独立测试场景中的接入，等待用户验收。

游戏首页 → **试演与预览 → 百川九图 · 地图测试（固定倍率）**。

可拖动、用方向键浏览；左下缩略图定位，顶部三个一级宗门快捷跳转，以及含全部123个地点的索引。建筑和名称均可点选。道路、空节点、地点分别开关。滚轮、捏合不缩放；地图保持每个素材像素对应一个视口像素，退出后恢复游戏原有窗口适配设置。

## 图幅与清晰度

九张底图均为2048×2048，组成6144×6144地表。先在一个6144画布中，按显示尺寸排入地形素材、连续水系、山门台地、林簇和桥景，再直接裁切九张底图。每张图与母图对应区域逐像素一致，不再分别生成边缘或叠边淡化。

6144是**原像素分层合成并渲染的工作画布**，并非声称AI单次生成了原生6144插画。纸纹来自1254原图，以原尺寸镜像连续铺入；地形、建筑与野外地标由生成原图裁切，只缩小到实际使用尺寸。没有把一张低分辨率整图放大，也没有让九个分块独立重画出不同河岸。

三大宗门建筑宽164像素，地方宗门118，城邑142，镇100；坊市94、村78、渡口92，野外地标72—80。地形采用280／340／400像素的低山模板，树林采用92／116／140像素的林簇模板。运行时底图和节点均按1倍绘制，字标单独绘制，避免建筑被锐化或放大成另一种清晰度。原图与显示尺寸逐项列在[像素与接缝验收](像素与接缝验收.json)。

保留灰褐线、浅墙面与低饱和屋顶；底色加入少量灰绿谷地和旧盐地色差，森林仅作稀疏点缀。三大宗门分别使用宗门、天府和圣宗模板，其余地点按类型复用，不表示123座建筑均已设计为独有造型。

## 节点如何落地

| 情形 | 本轮处理 |
|---|---|
| 山腰山门 | 玉虚仙宗、无相圣宗、镇岳观、抱朴山、丹鼎宗、蚀日宫、枯骨寺七处：低山背坡在后，建筑位于留出的缓坡台地，入口由薄台阶与两侧山坡轮廓承接；不会把屋底直接压在尖峰线上。附近野外地标可以共用同一山坡。 |
| 谷地宗门 | 玄都天府、太微道宫、归藏书院、百药谷、沧溟水府、血河教：院落保持开阔地，山景或林簇退在外围，不统一套山巅底座。 |
| 城镇、坊市、村落 | 以门口或建筑前沿为落脚点，保留通路和名称空间；城市不压山脊，地形排布避让建筑范围。 |
| 桥岸临水聚落 | 青萝城、雁回镇的规划坐标紧邻固定桥位，建筑分别向岸地退48／120、72／−24像素，用短引路接回原节点。这里调整的是建筑绘制位置，不是世界坐标或路线。 |
| 渡口 | 澜浦渡临东北海湾，问津渡临暮烟水系；岸房落在陆侧，栈桥朝水面。 |
| 洞口与野外 | 洞窟、残墟、山岗、谷地、林地、水岸采用对应自然地标；空节点仍用小圆环，不恢复石头路标。 |
| 河流、湖泊 | 春水府附近河道绕开建筑；涵虚、镜月两处湖岸给已有道路和地点留岸地。林簇和普通地形避让水域，源点、汇流处连贯收口。 |

全123处地点的逻辑坐标保持原样；图标及字标无互相覆盖记录。落位清单包含每处素材、绘制范围、落脚类型、显示偏移与名称位置，便于继续替换独有建筑。

无生谷、天碑原、蕴辉岩等邻桥的干地野外地标也按退岸处理，保留通向原节点的短引路；不会因为它们属于野外就允许山石或残墟浮在河中。退岸名录与实际偏移见落位检查，水潭地标及渡口另按水岸形态处理。

15个既定桥位全部保留，河流中心与其对齐。曲线河岸另需两幅小桥景，均标为`presentationOnly`：只处理已有道路与美术水线的交会，不增加节点、路线、收费或通行规则；桥长随实际交会角度调整，不能只画固定长度而够不到两岸。

## 地图层级和范围

沿用《觅长生》宁州行走图“背景、地点、路网、运动、界面分离”的组织经验；本轮使用原创地形、建筑和路面表达，不导入其游戏贴图，也不复制参考视频的界面、岩石路标或布局。

游戏中九张地表位于底层，498段共享曲线与321个空节点单独绘制，123个地点及名称再独立绘制，测试界面与缩略图放在最上层。123地点、321过渡点、177条地点联系及资源归属均来自现行规划数据，没有添加旅行结算或存档写入。仙盟继续为图外独立节点，不占中心区域；青溪里不恢复为大世界节点。
