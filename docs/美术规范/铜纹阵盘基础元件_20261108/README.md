## 两类线路的美术适配

信号为细朱砂刻脉，供能为较宽淡赭金嵌脉；两者共用墨色边沿、低对比笔触和克制亮部，配合铜口颜色与槽形区分。基准一格128设计单位时，信号内芯约6～7，供能内芯约10～11；转角连续圆转，避免把两段方管硬接成黑色断缝。具体颜色和笔触仅是美术参数，不表示新资源或传导属性。

元件PNG保留短槽和铜口，外部直线、转角、支路及断头由对照页单独绘制。连接先到真实逻辑格边，再沿端口轴延伸到图片中的可见铜口，补齐透明留白；口内短接段按需要放在元件上层，避免墨色封边横截线路。仅此处补接，不让线穿过其他部件，也不增加隐藏端口。

断开时在实际线端显示空心端点，信号用菱形、供能用圆形，保留元件原有铜口；接上后端点收起，内芯连贯进入接口。查看接点时也沿用此类形状区分，不给固定铜耳增加标记。接头不能靠突然变粗、强光晕或大色块遮缝。旋转时元件、真实端口与美术接点一起旋转。

直段、圆转、断头均有两类对应版本。只给供能展示T形分供；信号分合继续需要实际逻辑部件。本轮不画四向交叉或可免费跨越的造型。
