# 水墨演出素材提示词

使用内置图像生成工具，以本目录 `理想图.png` 为编辑参考。最终 UI 不使用含字整图。

## 背景

Extract the background layer of this approved 16:9 Chinese ink-wash game UI. Remove the entire central circular ring and all its strokes and wisps, remove ALL text, all dates, the timeline and its markers, and every UI element. Reconstruct those areas with the same dark charcoal ink-washed handmade paper texture as surrounding areas. Preserve the approved muted warm charcoal palette, very low contrast dry-brush ink splashes at the corners and faint irregular paper fibres. Center should be a calm dark ink wash with ample clean negative space. Full bleed 16:9 image, no transparency. This is a production background texture to sit behind separately animated UI. No circles, no text, no light, no dots, no borders, no scenery. Match original brightness and subdued ink feel exactly.

## 圆环（透明背景）

Create a production transparent UI asset derived from the circular dry-brush ring in the reference. Only ONE complete closed 360-degree circle, frontal view, centered perfectly in a SQUARE transparent canvas with 10% clear padding each side. Use the same authentic calligraphic brushwork as the reference, rough dry-bristle gaps, feathered pigment edges, varied organic stroke width. The entire full ring must have ONE uniform subdued matte warm gray-ochre ink color, no two-color progress segment, no dark incomplete segment; the game will recolor and reveal the progress itself. Ring should be approximately 8% of canvas width thick, with a large empty circular center. Absolutely no text, no background, no timeline, no icons, no particles, no shadows, no glow, no external wisps or brush strokes, no gold foil. Genuine transparent background including the center hole. Preserve ring dry brush hand-painted quality from reference, not a clean geometric vector ring.
