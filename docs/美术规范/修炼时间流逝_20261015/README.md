## 画面与动态

背景与圆环分别生成独立素材，文字、历法和时间轴由游戏控件绘制。背景为低对比深墨晕染，圆环材质使用旧金灰褐色，无发光粒子。填充沿笔触顺时针铺开，圆环有约 0.4% 的缓慢呼吸缩放，背景只有极轻微的墨染流动。

普通吐纳主体演出约 3.5～9 秒，131 小时示例约 6.36 秒，结束后结果停留 0.9 秒。演出中的日期从开始推演至预计结束，真实历法、灵力及跨月人物演算仍由既有行动末尾的一次结算提交。连续点击不会排入第二次行动。其他行动共用视觉；后台计算不增加人为演出时长。

时长与静室页面共用 `GameTimeText.Duration`：361 日→1年1日、25 小时→1日1小时。归元九息仅改剩余时长显示，不改独立闭关流程。

## 独立局内预览

### 全部加载入口统一（同日后续用户要求）

普通行动、行旅和过月演算沿用同一加载视图；战斗切场原青灰纯遮罩现改用共用 `SceneLoadingScreen`，新旅程、标题页读档、暂停菜单返回首页以及战后返回也接入同一层。先绘制加载画面，再沿用原主线程资源缓存读取，按准备／读取／布置／就绪阶段报告进度，保持至新场景就绪后淡出。跨场景层不登记为行动结算节点，避免干扰新旅程初始化和正式存档的原检查。

加载层固定为 CanvasLayer 240，覆盖其他常驻界面。重复场景请求返回忙碌状态，准备失败或缺失资源时退出加载并保留原页面；加载不推进历法。纯场景加载不显示吐纳的日期推演。

新旅程的 `JourneyCreationLoadingView` 保留按实际创建阶段更新的接口与等待初始化完成的流程，其显示层同样复用 `ActionTransitionPanel`，取消独立浅纸背景和横向进度条。新旅程失败后的返回首页操作也经过共用加载层。

独立检查入口 `res://tools/UnifiedLoadingSmoke.tscn` 覆盖通用行动、战斗加载视图、资源读取、打包世界返回、重复请求、失败收尾、暂停状态归属和历法不变；不读取或写入正式旅程。
