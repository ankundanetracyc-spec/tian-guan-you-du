## 页面与数据

静室保留吐纳修行、功法研读、闭关突破三页。人物姓名、境界、日期、灵力、修炼效率、精力、秘籍目录、卷章进度、研读门槛、突破条件及所需丹药均来自原正式人物和资源接口，没有引用网页样例数值。

- 吐纳沿用指定灵力、指定天数、指定日期、下层所需四种安排。淡青色只用于灵力值、缕数与其进度。计划显示真实预估与结束日期；原确认行动才推进时间。
- 研读保留原选书与真实研读入口、首卷访问和后续卷章校验。卷章清单可展开阅读，不改变当前应研读卷，也不跳过门槛。
- 突破保留原条件、丹药选择、闭关与凝核请求。归元九息仍嵌入吐纳页，原气机表现、暂停与续修不改，只统一纸面控件。
- 灵感、修命、修性、修行总览不出现在新版静室导航；不显示主修摘要、瓶颈减速或时辰。旧只读接口和兼容字段继续保留，不迁移或重算养成数据。

## 材质与交互

沿用1672×941设计画布并等比适配1920×1080、1280×720。三个分页共享原静室场景，保留山水留白，分别采用修炼安排纸页、秘籍目录与阅读纸页、闭关准备纸页。

主框、题签、导航、普通与主操作、输入、进度、滚动均显式使用 `CraftingPaperStyle` 已有素材。侧栏用独立导航原PNG及其装订边：纸面和文字一起右移18设计单位，220毫秒缓出；装订边140毫秒显隐。快速切换从当前进度转向，命中区不移动；`SetRoomReducedMotion(true)` 可直接设置终态。

按钮状态通过 `PaperButtonFeedback` 使用未绘入中央选中色块的 `selectedFalse` 原纸纹，并对整张纸轻染。四模式、书目与卷章均使用普通完整纸面；导航、主操作与输入保持各自类型。选中态不在文字后另加矩形，按住／松开有整纸压暗与轻微下沉反馈。原PNG、共享基础样式及修行规则不改。

数字输入保留原 `SpinBox` 作为数值接口，明面改为有素材的输入槽与两个裸三角。页面返回固定右上角，文字右侧为实心小三角，使用锚点偏移定位。日期与返回同一行，均为46高、22字号并垂直居中；日期靠右，只显示年月日。卷章浮层可用返回或Esc收起。

验收场景支持 `--quiet-width=1280` 或 `--quiet-width=1920`、`--quiet-output=res://output/quiet-room-paper-native/ui_1280`。启动前将APPDATA隔离在项目 `output/` 内；脚本会拒绝普通用户目录。图形运行通过NativePaperCaptureHost固定GPU SubViewport，使用真实鼠标命中并从该Viewport取图；不截图桌面。

已检查三页和日期布局、导航节点连续性与减少动态效果、裸三角与原数值同步、真实卷章目录、零精力吐纳、实际研读费用、归元九息保留和统一返回。两档均使用原生鼠标命中：查看三页不推进时间、不耗精力、不增灵力；开始吐纳后真实获得2缕且零精力可行；研读真实推进24小时、消耗24精力并产生卷章进度。日期与返回的同一行／同高／同字级及三角位置均有断言。最终复验追加已选模式按住及松开复位检查。本轮另核对选中导航实际引用 `selectedFalse` 原纹理，四模式／书目／卷章五态均为普通纸按钮，并通过真实按住、松开检查导航纸面和普通选择按钮的反馈。
