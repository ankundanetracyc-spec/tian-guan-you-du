# 百川九宫格背景构图引导

道路已按用户要求改成弯曲路形，九张引导与固定倍率体验同步更新。具名地点、桥位和山口保持，空节点沿弯路调整；早先固定倍率截图记录的是当时直线版本，不作为本轮路形验收图。

现行方案见[九宫格背景与地图分层](../../plans/世界与探索/百川九宫格背景与地图分层方案_20261027.md)。本目录为程序根据现行地点、山水和路网绘制的规划图，不是AI生成的九张正式背景。

工作方案：3×3块，核心2048方图，世界6144方图，单块每边128接缝参考区，工作画面2304方图。这里的引导图仅900方图；棕框内为核心区，框外为接缝参照，外边界可保留纸色。

比例图中的宗门、城市与路线用来指导留位，不能烧进最终地貌。水系与道路交会仍使用15处桥位，13处山口复用现有空节点。现有1254整体AI稿只作画风参考，不把它放大或裁成九张冒充正式素材。
