## 时序、暂停与锚点

- 共享人物参考高度1375，按既有190～320局内高度整体缩放。布局读取待机轮廓，动作不逐图裁边／居中／缩放，镜像围绕统一地面原点。
- 挥砍第5帧映射到原0.18秒接触点；既有应对插入会冻结同一个来袭序列节点。近身0.18秒接近、0.22秒倒身回位及命中短停保持原流程。
- 休整气息从动作起始播放，人物在其后0.12秒开始轻收手臂，约1.37～1.64秒回待机，动作总长1.72秒；画布600×660、中心(140,-860)，无休整镜头拉近。特效30帧／秒。
- 新效果使用`battle_action_visuals`组和Pausable处理模式；系统动作仍通过原有表现完成等待，在人物／特效收尾后推进下一行动。序列不写战斗结果。
- 特效跟随对应人物的全局缩放、镜像与应对特写；挥砍抵达接触后固定原处，避免随攻击者倒身回位拖走。死亡、移除或切换兽形时清理相应效果，随场景释放。
- 缺少某个姿势时保持同性别当前默认衣装待机，特效可正常播放。
