# 百川简笔舆图风格小样

用户否决了青绿山水插画方向后，回到平缓地表、简笔山形、克制设色与微缩建筑的游戏地图语言。地理构图和建筑为新设计，仅参考用户视频的大类风格；《觅长生》用于学习地图层级，不作为复制图标或布局的来源。

[v01](简笔舆图风格小样_v01.png)曾用石头路点与长虚线；用户要求更换，因此由[v02](简笔舆图风格小样_v02.png)替代：小圆环路点、淡灰褐连续曲线，资源分支更细。v02为内置图像生成的风格小样，图内建筑与路径只用于确认观感，不直接作正式底图。

已将该方向拆分用于[可操作初版展示](../../prototypes/百川地图初版展示_20261027.html)，实际地点与道路分别成层，避免把样稿里画死的道路用于行走。
