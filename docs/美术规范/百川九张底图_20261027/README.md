|---|---|---|
|11 西北|西北源岭|西侧断续低岭与山间缓谷，给山口、野外地点留出间隙。|

|22 中央|中央河湖|横贯主河、南来支流和汇流湖汊；平地支撑中部城镇联系带，不为仙盟挖空。|
|23 东中|东中泽陵|西侧湿地与东侧低陵交错，主河北折，另一水脉向南续入盐泽。|
