## 依据与当前问题

以[序章现行细案的见闻与任务定义](../../plans/单人版序章_静室灯火_策划案.md)、[UI视觉规范](../../UI视觉规范.md)为功能依据。已查阅 `JournalPanel.cs`、`MainHUD.TaskTracker.cs`、`EstateOverview.TaskTracker.cs` 与 `MainScene.cs` 的条目及点击入口。现行要求：右侧最多阶段目标与当前任务两条；点击进入见闻任务页并定位对应条目；序章和离村后复用同一入口与交互。

代码中的布局风险：卷轴、页签、内容和收卷按钮分别使用独立锚点，卷轴还延伸到屏外，难以维持纸内安全区；十个纵向页签占高较大。两套任务栏有不同的右边距，固定138像素高度配合13号字号、21字摘要裁切，影响信息层级。当前条目列表没有明确的持续选中态，详情正文缺少独立滚动区。以上为代码核查结论，本轮没有操纵用户正在运行的游戏或验证其实际交互。

## 建议布局

阅读页与任务页使用一个共同卷面：细木轴、哑光浅宣纸、墨青选中、深墨正文，降低金属与做旧装饰。顶栏固定名称、游戏时间与收卷，下面统一三栏顶线、底线和间距。左侧五个已开放栏目等高；五个预留栏目放入紧凑的“待续”区，保留可查看的预留入口。

条目列表以窄墨青边及淡底表示选中，正文标题与该条目严格对应。来源、地点与状态按列对齐；正文和列表独立滚动，滚动不影响顶栏。任务页共用全部背景与公共位置，只替换列表及详情。当前目标优先呈现，任务说明随后；已完成记录收在下方，不编造进度百分比、奖励、传送或领取功能。

任务栏建议在1672×941画布上宽约340–380像素，按正文自然高度约240–280像素，标题约22、正文18、类别与状态16。右边缘贴屏幕边界，顶部仍遵守现行约四分之一屏高；收起控制宽约28–36，与面板共用同一高度。阶段目标与当前任务标题、摘要和状态分别对齐，短摘要自然换行，完整信息在详情页读取；不强行按固定字符数截断。序章与后续只换数据，不换组件。
