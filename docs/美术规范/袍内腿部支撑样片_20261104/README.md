## 本次复核

正反两个朝向分别运行 270 帧，覆盖待机、起步、持续前进、急停回落、转向、后退、错步与暂停。每帧保留两条完整腿链、同一连续闭袍网格，两张腿脚渲染网格均隐藏，因此没有外露膝裤、鞋缘或鞋脚；新形变由实际腿骨包络驱动。腰肩颈连接、原贴图与袖形保持，布边未沉入地面。

以上位移均为骨架局部单位。前跑膝高的局部鼓起与抬脚侧的下摆褶形会随两腿更换支撑；停下后局部膝部支撑继续释放并消退。前膝轮廓仍有较紧的局部折点，保留为本版目视复核项，不把数值通过视为美术终审。

本版使用轻量二维腿段包络与局部弹簧回落，不声称完整三维布料自碰撞。独立场景可演示新皮肤；默认运行皮肤的接入由主任务在目视后另行处理。本轮采集不改变移动、技能、费用或冷却规则。
