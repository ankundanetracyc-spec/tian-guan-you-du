# 白石讲法会序章首版实装

2026-11-03。入口为首页新建旅程；已有存档不补走新序章。现行规则见[讲法会细案](../../plans/剧情与宗门/白石讲法会与序章入道流程_20261103.md)。

主角在青溪里外野地醒来，从公共人物列表与方远交谈、选择同行。白石的本期随机主持及两宗来使沿用同一人物列表和交互菜单，听讲、验灵、选书、研习指点和去向均从人物交互进入。无新增全屏操作页、中央操作框或绳签；开场复用青溪既有野外背景，白石讲法处暂复用既有讲席背景。

开局不选择功法；验灵不重抽资质，选书复用人物功法页的书目及详情弹窗，首卷权限与正常研读、装配、吐纳相衔接。方远返乡后移出名单。主角达到云息后自行在世界地图行旅至玉虚，继续原迎真与录籍。主持角色、本期职责、剧情进度和首卷权限保存，旧档不丢书或重抽主持。
