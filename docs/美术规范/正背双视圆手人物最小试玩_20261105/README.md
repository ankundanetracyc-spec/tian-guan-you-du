## 现行水墨风格要求

**“省略肢体是水墨的简化，不等于卡通美术。”** 用户明确要求人物和场地使用水墨表现，地图不能采用规整卡通、玩具般的圆石、重复草簇或统一硬描边。保持克制的墨色与淡彩、自然不规则的石块和草竹、干湿笔边与少量皴染；省略肢体不构成改用卡通美术的理由。

当前battlefield.png已换为本轮新水墨地图，保留无地平线、轻斜俯视、连续可行走地面的用途。generation.json中最新field_ink_revision及field_style_requirement是本轮场地要求，早期提示中的卡通／chibi描述只保留生成历史，不再指导当前制作。

## 本轮造型裁定

- 仅正面、背面两个主体视图，先把首款做好，不继续以侧面和四方向扩款作为当前目标。
- 大头、锥形筒衣身、独立圆手；双手向身体收近，不连接手臂。
- 不画眼睛。
- 两只圆脚上半为深灰裤腿色、下半为蓝灰鞋色；双脚上下交替，躯干只作轻微垂直反馈，不横摇、不横向摆动。步频按实际位移推进，顶到边界时停止迈脚。
- 统一黑发，只制作一款前发、一款后发。两槽使用独立图层和挂点合成，不制作前后发组合专用的整头图表，也不把同图换行冒充多款。
- 场地采用没有地平线的轻斜俯视水墨视角；镜头缩放0.82，较此前拉远。用户最新另要求地图变大，扩大范围与跟随镜头按下节单独落实。

以上为本轮最新要求。旧记录中的“无腿脚”、四方向及三前发×三后发不再作为本版应完成的造型范围。
