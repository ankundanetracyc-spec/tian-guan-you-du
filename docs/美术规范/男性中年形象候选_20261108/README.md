## 后续拆件边界

- 中年脸底与配套眉、眼、鼻、嘴共同形成年龄感，胡须作为可选部件。
- 发型、衣服在兼容时继续共用；只补足确有区别的部件。
- 整稿保持原有构图参照，但生成图尚未通过模块化锚点标定。拆件时须统一画布、眼位、鼻口位置、下颌、颈部及领口接点。
- 需检查双眼开合、遮挡关系、局部颜色与透明边缘连续性，再以实际组合验收。当前整稿不能视为所有部件组合均已验证。

## 年龄系统的现有边界

依据[模块化角色立绘系统](../模块化角色立绘系统.md#身份年龄与境界)，项目已有按 `current_age`、`min_age` / `max_age` 筛选部件的入口；境界筛选视觉池，不改写先天脸部。当前男性活动素材偏青年，胡须仅有无须选项，需要先补齐成熟素材。

本轮提示词中的年龄数字仅用于画面设计，不设为自动换脸阈值。实际年龄、外观年龄、驻颜及境界的关联规则需另行明确；本轮不改这些规则或存档。
