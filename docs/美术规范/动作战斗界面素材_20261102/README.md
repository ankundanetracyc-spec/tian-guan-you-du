## 2026-11-03：分层水墨资源栏与右下圆形技能槽（当前试玩实装）

本轮按用户选择的分层布局接入全部动作试玩入口。左上为生命、体力、法力三条递减宽度的浅纸底槽，边缘规整，填充使用静态水墨浓淡纹理；无手绘毛边、泛光、金属高光或大面积外框。体力6格、法力3格沿用测试样例，生命值、资源和填充均实时绘制，不烘入图片。实际效果见[1280×720实机](../../../output/action_battle_ui_full_1280_20261103.png)、[恢复中实机](../../../output/action_battle_ui_recovering_1280_20261103.png)和[1920×1080实机](../../../output/action_battle_ui_recovering_1920_20261103.png)。

体力下一格依照现有每2秒恢复1点的真实计时从左向右填充；填满后该格轻微回弹，不提前给予可支付资源。法力只显示现有真实数值，没有新增自动回复。资源恢复规则、技能费用、目标、伤害、判定和角色骨架均保持。法力下方仅为实际存在且有现成图标的自身状态显示图标，不显示“状态”标题，不预置护盾、气血等示例 Buff；本轮默认无状态图标。

右下为两枚基础操作图标与五个自由技能槽，独立圆形实底，不设整条底板；复用现有战斗技能及身法图标，资源费用以圆点提示。去掉常驻试玩标题、分组标题、Tab调整及WASD说明；悬停可看技能说明，原Tab换位、F1操作帮助、Esc返回保留。HUD位于独立CanvasLayer，普通试玩也使用1280×720逻辑画布并随窗口等比显示；退出恢复原窗口设置。

### 2026-11-03：动态反馈补充

左上消耗格子增加0.18秒的轻描边，真正恢复满格时轻微回弹；恢复与消耗相邻发生时清掉旧反馈，避免空格仍弹动。实际法力增加只触发同类回弹，不添加法力自然回复或虚构的恢复进度。体力不足由真实施放失败回调触发0.42秒的局部轻晃及朱红细边，只标记费用超过当前体力的技能，不影响0费拳掌。右下技能在真实冷却起始时轻微压下，并按当前技能冷却显示淡墨遮罩与回退弧线；不按旧版攻击间隔推测冷却。帮助和换槽期间反馈动画冻结，关闭后续播，无泛光。
