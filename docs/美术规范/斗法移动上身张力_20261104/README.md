# 斗法移动上身张力

本页为已被用户否定的历史版本：前手固定在胸前、后手拉开，且实际倾身不足。当前改为明显倾身、双臂自然交替的跑动，见[新版动态与验收](../斗法跑动倾身与交替摆臂_20261104/README.md)。下文仅记录当时制作结果。

2026-11-04。本轮依据[用户52秒截图（原附件缺失，查记录）](../../引用与附件核对.md#ref-55475b37975f)，重点打开肩胸和双臂轮廓：近手离开腰部、向胸前伸出，前臂接近水平；远臂向身后反摆，髋部承重与胸部形成配合。普通前进的肩胸前压进一步加强，保留加减速缓冲、低脚回收和末摆弹性。规则边界见[单一移动主案](../../plans/界面与美术/参考归墟行单一移动步态_20261104.md)。

仍只有一种普通移动，沿用首页试玩114，不增加移动耗体力或战斗效果。静止外形与专用出招、架招、运功和错步的优先级保持。
