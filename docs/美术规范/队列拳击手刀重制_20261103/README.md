- 手刀用向右的弧形切劲，与拳击区分；两套各八帧，含起势、峰值、破碎和消退。
- 所有资源、费用、目标、状态和伤害结算保持不变；预览不扣费、不造成伤害、不新增判定。0费、返费、抽牌、额外行动及资源生成规则不涉及改动。
