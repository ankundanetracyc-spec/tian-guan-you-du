## 三、锚点、占位与UV注册

坐标约定统一为图片左上原点、X向右、Y向下，支持亚像素浮点数。

| 锚点类别 | 本轮必要内容 | 落点约束 |
| --- | --- | --- |
| 骨骼旋转／连接点 | 肩、肘、腕，髋、膝、踝，头颈挂点、发根及发骨 | 对应真实关节或装配轴；允许位于透明区，不以该像素是否不透明判定正确性 |
| 可见轮廓 | 头顶、发顶、发前缘、发尾、指端、靴底及鞋尖／后缘 | 对应实际绘制的轮廓；注明使用软边、有效Alpha边缘或像素外边界的定义，不用画布边缘冒充 |
| 覆盖与宽度 | 肩根覆盖、袖宽、腕口、裤腿和靴宽 | 同时核对邻接件覆盖及分段宽度；不能仅对准骨点而让袖子、手或鞋整体变粗变长 |

`source_uv` 是原Sprite裁图的归一化UV；`target_px` 是本项目真实高清图的像素位置。二者必须分别测量与保存。原绑定矩阵反求的骨pivot提供源位置，高清目标锚点提供新图内部占位；适配器执行每件注册表中的分段轴、仿射或控制点换算：

`高清采样位置 = 该部件注册映射(源UV)`。

直接计算“源UV×高清宽高”只在新旧图内部占位完全相同时成立，不能作为本轮注册标准。手、头发、靴子的目标位置必须按当前高清实际绘制区标定；不得为补偿错位而任意改变源骨长、拉长身体、放大头部或整体缩小某件。

分段注册需同时保持肩→肘→腕、髋→膝→踝→靴底的顺序及关节处连续性。局部横向宽度、手掌与腕口、鞋尖与脚底须分别核对。头脸和发件分别注册到同一个头颈装配关系，不能各取图片中心后叠放。头颈、发根等外部挂点与蒙皮内部骨点的换算方法应区别记录；源绑定矩阵和源renderer矩阵不能相互替代。

## 四、世界尺寸、脚点与朝向

模型在固定的源Idle包围框上建立一次等比基准：`target_native_height = 104`，外层 `display_scale = 0.72`。该高度是模型坐标中的固定归一化尺度，乘显示比例后为74.88单位，之后再由镜头缩放；它不是每张PNG的像素高，也不要求每个姿势的可见Alpha高度都相同。

固定基准把Idle腿网格的脚底映射为模型局部 `Y = 0`，角色位置继续表示地面脚点；水平原点按同一源包围框居中。移动、出招和停步使用同一基准，不逐帧依据Alpha包围盒重新居中、缩放或拉腿“锁脚”。靴底目标锚负责贴图内脚的位置，世界脚点负责角色在地面的落位，两者须同时验收。

面向通过模型整体X镜像处理，Y比例保持。头发、手、鞋、肩根覆盖和所有实时骨挂点随同一次变换；不得在镜像时另行偏移脸或手，近远件也不另套一套未登记的图像偏移。左右朝向均须检查遮挡和接缝。

## 五、圆肩、遮挡与手部特效

两侧袖根轮廓圆润，在衣身下保留覆盖，抬臂与跑动旋转时不出现尖角、斜切棱边、透明缝或断口。PNG轮廓与承载网格共同检查；只有材质变圆、网格仍把它裁成尖角，不算通过。

肩根补片随真实肩骨运动，使用该袖同一套高清UV注册与材质，层级位于衣身之后。补片负责覆盖袖根连接，不能变成浮在胸前的圆块，也不能用扩大整只手臂掩盖断缝。远袖、衣身、近袖以及头发的层序按模型部件关系处理，不靠临时每帧改层号遮住错误。

手部特效读取当前模型 `near_hand` 的实时全局挂点，再转换到战斗场景坐标；跑动、转向、出掌、停步和收束阶段均跟随当前手位。模型有效时不能回退到固定的“人物位置加偏移”，也不能缓存施放起点。静止贴合一次不代表移动过程已贴合。
