# 百川八千公里底图

显示分片最新修订：用户反馈5×5地图过大，已改为[3×3紧凑底图](../百川八千公里3x3紧凑底图_20261104/README.md)，世界仍8000公里见方。本文保留25张原生图的生成、校色和拼接来源，6270母图继续复用。

2026-11-04。本轮按用户最新要求，将百川用于自由行旅的底图重画为纸墨青灰山水，并采用 **5×5、共25张独立原生细化图**。美术资源已发布并冻结，地图尺度为 **8000公里×8000公里**，运行时虚拟画布为 **12288×12288**；地点、导航与运行验收见[百川全域自由行旅现行案](../../plans/百川全域自由行旅_20261104.md)。

## 画风与地理约束

用户参考采用浅米灰宣纸、淡灰青绿山体、细墨皴线、克制林簇和淡蓝溪河，山群之间保留广阔浅色平原。底图只承载自然地形，地点牌、建筑图示、角色、路线和界面由游戏独立绘制。东侧海岸、西侧入境河流、湖盆与山群的总体相对关系取自原3762地理母图；地物保持大区域俯瞰尺度。

参考输入已保存为[用户风格图](../../../textures/world/bai_chuan/free_world_8000_20261104/references/style_user_20261104.png)，地理来源为[原3762母图](../../../textures/world/bai_chuan/acceptance_20261030/master_3762.png)。风格图中的UI、人物、城门、纸签和虚线路网均未作为地形绘制内容。

## 生成方式与提示词

全部绘制使用 **内置image_gen**。先以用户风格图和旧地理图生成一张连续母图，再按精确5×5裁切生成局部细化图。最终25张细化均以各自CORE裁切为唯一图像输入；周边context裁切保留作人工核对资料。

最初多参考细化出现扩展视域的情况，随后重画`r0c0`、`r0c1`、`r0c2`与`r2c0`，将河道交点和山体切口收回各自CORE范围。被替换图保留在候选或原生来源目录。

## 纸色和接缝处理

在保留原生图及未处理拼合图后，采用逐块处理控制内存：抽样每块明亮纸面的中位色，向全体中位纸色`RGB(221,214,202)`靠拢，每个RGB通道加减最多6。该步骤调整像素颜色，保留原位置和线条分辨率。

四条竖拼接线及四条横拼接线均位于6270图中的1254、2508、3762、5016。每条线两侧各处理16像素，合计32像素宽的边带；使用原生相邻边缘颜色进行轻羽化。按半开区间记录为：`[1238,1270)`、`[2492,2524)`、`[3746,3778)`、`[5000,5032)`，横竖方向相同。交叉处依次处理竖带、横带。

这些边带的几何覆盖约1588736像素，占全图4.04%。正式图使用原生细化块的像素进行校色与接边，没有铺入首张1254母图的放大替代层。空间分辨率始终保持6270，最终25片在处理完成后从母图重新裁切。

处理脚本为[`tools/world_map/finalize_bai_chuan_5x5_20261104.py`](../../../tools/world_map/finalize_bai_chuan_5x5_20261104.py)；完整参数、逐块校色量、原生SHA256与发布SHA256见[最终组装审计](../../../textures/world/bai_chuan/free_world_8000_20261104/final_5x5_assembly_audit.json)。
