## 布局与外观

- 战备入口位于底部技能栏左侧，建议起始尺寸为 136×64 设计像素，文字 22；沿现有 1672×941 画布统一缩放。复用当前“确认队列”的 `control_button_v2.png` 按钮皮肤及字体。
- 点击后在按钮上方竖排三个战备位，每位建议 136×94、间隔 8。图标、名称、丹效档位、持有数量常显，空位显示“未编入”；丹药和未来的消耗型符箓共用这些位置。每位最多五件同一物品的规则不变。
- 悬停某位时突出该位，通过现有 `HoverInfoManager` 显示药名、丹效、本人使用、具体效果、队列占位和已排次数。正文跟随实际物品与行动配置，预览良效回春丹的 50 点采用当前丹药扩充提案样例，不构成本轮平衡或运行数值修改。
- 说明优先出现在该战备位右侧，由现有说明系统约束在视口内。它可以盖住常规 HUD，不能被中央队列或底部技能栏裁剪；移开后恢复完整视野。
- 打开战备不会修改队列；点击有效物品才按丹药战备提案加入第一个空行动位。再次点击入口或点击外部收起；悬停说明和战备展开存在时，Esc 先关闭顶层界面，再恢复原队列撤销行为。确认队列进入选目标／行动阶段时收起。

## 画布层级

| 内容 | CanvasLayer | 依据 |
|---|---:|---|
| 角色生命条、状态 | 5 | 现有战斗分层 |
| 战斗飘字等反馈 | 6 | 现有战斗分层 |
| 中央队列、技能栏等常规 HUD | 10 | 现有战斗分层 |
| 战备按钮及竖排位置 | 20 | 本轮建议，独立于技能栏的裁剪容器 |
| 角色详情 | 90 | 现有角色详情层 |
| 统一悬停说明 | 160 | 直接复用 HoverInfoManager |

战备根控件不拦截整屏输入；仅按钮与战备位接收点击。说明内容沿现有系统保持鼠标穿透，角色详情等更高界面打开时关闭战备。不能只增加 `ZIndex` 来跨越不同 CanvasLayer。
