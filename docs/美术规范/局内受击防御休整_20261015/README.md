## 动作用途

用户确认：当前手刀姿势可作为没有明确拳、腿或武器动作要求的通用出手，例如“应敌”这类招式。姿势表示角色出手，具精力量性质和辨识交给特效；有明确身体／武器构图的动作另行绘制。此条是美术复用约定，不改招式伤害类型、应对条件或技能效果。本轮测试页将原「下劈」选项命名为「通用出手」，正式战斗路由尚未切换。

| 演出 | 人物姿势 | 特效形状与配色 | 节奏 |
| --- | --- | --- | --- |
| 通用出手 | 已认可的手刀下劈 | 保留原16帧挥砍＋20帧命中 | 原拉近、同步定格、碎墨消散 |
| 受击 | 男女各一张后仰、屈膝、收臂的受击图 | 24帧，赭红／炭墨向后碎散，胸口一瞬暖白锐光 | 短冲击、0.14秒同步定格、轻后移／倾斜、回稳 |
| 应对防御 | 男女各一张双臂架挡图 | 30帧，身前开放灰青玉弧面、金白接触点、余劲拨散 | 先架势、接触帧定格0.18秒、余辉碎散、回位 |
| 休整回气 | 保留原待机图 | 48帧，淡青／象牙白／少量暖金光息，绕身并归拢 | 缓入、呼吸式小幅拉近、后段收拢与消隐，不做受击震动 |

三类新特效均为 **768×768 RGBA8，30帧／秒，不循环，共102帧**，首尾透明，外边缘透明。由三个独立生成的彩色笔刷纹理通过Godot确定性展开、扩散／扰动与消隐烘焙，不是逐帧单独手绘。保留笔刷飞白，亮面集中在接触点与气息线条，未启用全屏Bloom或背景光雾。

休整作为自我恢复演出的样片；正式规则仍由[分段规划与时序行动战斗系统](../../plans/即时队列战斗系统设计.md)规定。当前休整回复体力，战斗不提供通用吐纳行动；法力只由明确写出的技能或效果回复。样片不增设回血或回复其他状态的规则，也不伪造资源增量数字。
