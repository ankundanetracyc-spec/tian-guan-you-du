# 男修 Spine 素材样片（2026-10-15，v1）

状态：独立可动候选，供美术和动作评价。**现行局内正式人物仍使用静态 V2**；本包未接入正式战斗、结算或局外外观系统，不构成正式角色表现的替换。

## 来源与制作范围

- 以[局内静态 V2 规范](局内静态立绘与站位_20261011/README.md)及 `textures/characters/combat_static_20261011/male_v2.png` 为身份、配色和比例参考。保留无五官、青绿／象牙白、黑发、哑光淡彩和三分之四朝右视角，不画剑。
- 用户此前认可的生成样图只提供风格参考；旧 `c1_male_puppet_v2` 仅提供骨名、父子关系和动作接口历史，不沿用旧绘图。
- 遵循[模块化角色立绘系统](模块化角色立绘系统.md)的透明拆件与拼合检查原则，并参考[Spine 拆件研究](杀戮尖塔2_Spine拆件与绑定研究_20261010.md)中的关节遮挡、柔性躯干和专用死亡绘图方法。不使用研究对象的任何原游戏像素。
- 内置 imagegen 绘制两张拆件图、一张跪地姿势图及修订图。生成图保留；导出仅进行语义部件选择、缩放、旋转、同原点放置和图集打包，没有程序绘制替代原画。提示词见[生成记录](男修Spine素材样片_20261015_生成提示.md)。

## 资源包与启动

包：[male_spine_sample_20261015_v1](../../textures/characters/male_spine_sample_20261015_v1/README.md)。

- `source/master_1024x1536.png`：1024×1536 RGBA 拼合母稿。
- `layers/`：26 张同原点、同尺寸 RGBA 图层，原点为画布点 `(512,1450)`。
- `images/`：与 Spine 附件尺寸相符的裁边贴图，供 JSON 导入编辑器；不会把整画布误当作小附件缩放。
- `alignment.json`：源选区、变换、图层顺序、关节锚点和有效 Alpha 外包框。
- `runtime/male_sample.json`、`.spinejson`：Spine 3.8.99 JSON 数据。
- `runtime/male_sample.png`、`male_sample_portable.atlas`：标准 PNG 图集及便携图集文本。
- `runtime/male_sample.atlas`、`male_sample_texture.res`：Godot 原生预览使用的二进制纹理版本。专用预览从 PNG 生成 `.res`，避免为本次检查重新扫描／导入用户的整个工作区；此格式不当作 Spine 编辑器图集页。
- `preview.gd`：独立 SceneTree 预览，不实例化正式游戏场景，不运行正式战斗或结算，不写正式存档。

双击[专用启动器](../../tools/run_male_spine_sample_20261015_v1.cmd)。它调用用户指定的 `tools/run_stacklands_spine38_game.cmd`；公共运行器只追加参数透传 `%*`，无参数时沿用原行为。使用项目内 Godot 4.7.2 / Spine 3.8，未使用 4.6。

预览支持动作按钮、暂停／继续、左右方向键按 60 fps 逐帧、骨骼叠图、浅深底和截图。死亡完成后停在终姿，只有主动选另一个动作才重开预览。

## 骨架、附件与动作

保留旧包 64 个骨名及父子关系，按新素材重新测量设置姿势；不宣称旧的数值关键帧无需重定向即可直接套用。新增 6 骨：后发、发梢、飘带及近／远／中央袍片，总计 **70 骨、23 槽、26 附件、6 张加权网格**。

拆件包括前后发、飘带、完整颈头、躯干、腰封、近远袍片、中央与后侧衬裙、近远上臂与前臂袖、近远大腿与小腿、靴子。近手有手掌／剑指／拳替换，远手有手掌／拳替换。手指链保留供兼容和后续扩展，本轮手势由绘图替换承担，不宣称每根手指都已绘成可独立弯曲的网格。

躯干在腰胯、腹、腰、脊柱、胸之间渐变赋权；后发与袍片有独立控制。袖肘和腕分开，闭合的上臂肘端延伸藏在前臂袖下，避免出现两个袖口。近侧在躯干前，远侧在躯干后。

| 动作接口 | 内容 | 时长 |
| --- | --- | --- |
| `idle` | 克制的掌式防守与呼吸 | 2.40 s |
| `ready_cast` / `ready_sword` | 施法／剑指准备，无剑 | 各 2.40 s |
| `cast` | 胸前蓄势、抬腕放出 | 1.25 s |
| `attack` | 转腰横击 | 0.95 s |
| `attack_rising` | 下压后上挑 | 1.05 s |
| `attack_leap` | 收膝跃起、举臂下落 | 1.20 s |
| `hurt` | 可打断动作的短促受击 | 0.60 s |
| `knockback_return` | 向后腾起、落地并回原位 | 1.25 s |
| `rest` / `breath` | 调息／吐纳轻动作 | 各 1.20 s |
| `death_kneel` | 收身、垂手，0.82 s 换专用跪地整姿并定格 | 1.50 s |

本轮使用全身跪地姿势替换，而非只换袍片。切换前通过腿链逆解关键帧控制脚点，袍摆抬升、折入衣内的裤腿按遮挡隐藏；切换后全身姿势使用专用绘图。它仍属于样片的绘图切换，精细到逐帧的透视过渡和新的跪姿局部网格留待用户评价。

- 没有 C# 改动，因此未做无关全项目编译；验证范围为新 GDScript 的解析、指定原生运行器实机播放与资产数据。未回滚用户内容。
