普通休息可选按时长、指定日期、精力回满。手动默认8小时，范围1—720；日期继续30日／月、12月／年，并保留当前隐含小时。回满按 ceil(max(0,上限−当前)/WorldStaminaRules.RestRecoveryPerGameHour) 取最少整小时，不受手动720小时限制；已满为0且不可开始。固定剧情隐藏三种自由选择，保留调用传入的时长和备注。未知人物或日期显示“—”，不可确认。

Open签名和确认回调保持。预览、改数值、切方式及返回不修改人物或时钟；确认只把正整小时交给既有回调，并立即清除回调防止重复执行。生命恢复、精力结算、休息状态累计与历法推进仍由原调用方负责。原 MainScene.Rest.cs、open_general_rest_dialog、WorldStaminaRules、QuietRoomStyle 及两张卧房PNG的本轮前后hash相同，见[源码边界核对](源码边界核对.json)。
