## 原素材应保留的共同语言

1. 工笔细线与低对比淡彩、纸感颗粒共同构成画面。眉眼鼻口都应融入同一脸底；单独生成得更锐、更亮或更立体并不代表能拼合。
2. 前后发共享哑光炭黑与克制暖灰高光，先有成束的发量关系，再有细发丝。不能用密集灰白线代替层次，也不能各张自由改变头宽与蓬松程度。
3. 鼻子原件包含鼻翼、鼻尖及向鼻梁延伸的半透明淡染。去肤色底片不等于删掉这些明暗；新稿只剩两条鼻孔的处理不合格。
4. 眼部包含眼白、虹膜、上下眼缘和轻微眼周笔触。保持原有细节密度；需要优化旧款形状，不应同步加粗眼线、拉长眼尾或增加夸张睫毛。
5. 唇部是低饱和暖色、柔和边缘和轻局部阴影，不能与鼻部采用不同强度的高光。

## 分件与配合

- 每款每部件独立1024×1536透明PNG，沿用原共同原点及定位，不改变运行时接口。
- 脸型含完整头、双耳与颈部。前发只有头发，包括发顶、发际、鬓角和完整胸前发束；没有耳朵或肤色残片。
- 后发是完整连续的后脑、颈后和肩后发量，隐藏区域补全；不是在整个人物周围挖洞所得的外圈。
- 眉与眼分别成对，鼻与嘴各自独立。连续透明度用于笔触融合，不是大块肤色遮盖。
- 实测旧基础衣服存在细发线残留，须与前发自身的多余碎发区分。后续局部修正应保持服装结构花纹。

此前各部件分开生成时，分别改变了线条、明暗、发量和五官细节，虽然画布与定位一致，整体仍不统一。几张新鼻部为消除皮肤底片而丢失体积，部分发型外形也偏离参考。
