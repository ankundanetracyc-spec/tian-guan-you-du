## 全遮脚的实现与验证边界

每方案保留21根自有骨骼、6个主网格、完整双腿骨链、鞋底采样和双足接地点。闭袍专用策略关闭两张腿脚网格的绘制，保证旧鞋头不会从纹理透明边缘漏出；脚下接地阴影保留。因此，本次验证的是**鞋脚显示关闭、连续袍摆和接地观感**，不声称布料逐像素物理遮挡已通过。

正向及反向回放各270个模拟帧，逐帧检查3个方案的两张腿脚网格均不可见、骨骼与网格数一致、袍身为连续网格、两个脚接地点持续存在、朝向与驱动一致。出掌和错步均经过原战斗技能调用；错步第204–208帧使用真实Step1中间相位。关键帧另检查待机、前进、转向、后退、出掌、错步和停止回落的袍形及腰袍连接。
