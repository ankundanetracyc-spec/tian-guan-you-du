# 信件与邀约 · 纸墨木石独立样稿

2026-11-09。[本轮范围](../../plans/界面与美术/信件邀约纸墨木石样稿_20261109.md) · [现行信件行为](../../plans/剧情与宗门/信件与限时邀约界面_20261014.md)。本轮只做可操作样稿，尚未替换游戏内信件入口。

左侧灰蓝信匣与三类目录，右侧完整展信纸页及信尾约笺。沿用已批准纸面、布面、楷体和信件图标；普通细分割线、整纸选中／按下反馈、同高日期与右上“返回 ▸”。按用户首轮反馈撤去了偏出边框的底纸，清掉底部白线。不重复角色七页侧栏。

打开信匣不自动读信，点信才标已读。保留检索、日期排序、独立正文／目录滚动与未读操作；应邀／婉拒只写独立内存信匣，未注册活动不开放赴约。预览文案复用原示例信及正式留书模板；不读取旅程、不写正式存档、不推进时间。

入口：[双击打开可操作样稿](../../../tools/open_letter_paper_preview.cmd) · [独立场景](../../../tscn/scene/LetterPaperPreview.tscn)。默认1600×900，可用配套脚本切换1280或1920宽；只使用隔离示例信匣。

本轮主项目编译0警告、0错误；1280×720与1920×1080各58项原生检查通过，共18张完整图已逐张检查。[汇总记录](验收记录.json) · [1280原始记录](验收记录_1280.json) · [1920原始记录](验收记录_1920.json) · [素材来源](素材来源.json)。正式信件面板、信匣数据及入口7个文件与开始时一致，未接入游戏。
