# 凝核起手与牌面信息

正式凝核与试演在入局后显示六张起手牌，可选最多两张换牌；不换或换好后直接进入第一回合。起手界面使用新生成的水墨山水纸纹，游戏中的文字、牌面和按钮仍是独立控件。

按用户最新要求，凝核界面按钮统一复用原“结束回合”的水墨笔触素材，包括起手、正式局、试演、回弹选择和结算窗口；普通、悬停、按下和禁用状态保留可辨反馈。右上角“收益／玩法／重开／返回”及对应的正式局按钮同样使用，正式“返回修炼”加宽以容纳文字；不再使用上一版新生成的金边按钮。

牌面将凝核、紊乱、回弹和条件分行。长按手牌显示项目共用信息栏，详细模式按当前状态展示数值和计算；开始拖动后收起。拖牌不再显示旧提示圈与右侧预览。第一回合以后的换牌、多个回弹目标选择及致败确认沿用现行规则。

“本回合”指八回合中的当前回合。左侧显示当前紊乱、按当前紊乱预测的回合末扣除、本回合到达回弹的股数与总强度，以及不引回的扣除或引回收益；上方回合轨道显示其余回弹。悬停左侧状态可查看当前结算说明。观气仍不提前公开未知牌序。
