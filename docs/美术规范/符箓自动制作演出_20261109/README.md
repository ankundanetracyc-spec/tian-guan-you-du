## 支付与跳过

演出约3秒，只负责展示已提交的实际结果。开工时材料、精力、历法与产物入包一次提交；播放、跳过和自然结束不再制作或扣发。跳过和自然结束使用同一鉴看入口；旧批次回调、重复跳过及场景移除不会再次开结果或改变支付。

播放时 Esc 不撤去遮罩，返回、切页和配伍册受忙碌保护；结束及移出场景时恢复演出前各区域的可见标记。原料字段、纸墨能力、固定符效、造诣作用及实际费用均保持。

辅纹、主动应变、造诣成长没有在本轮增加规则；意象阶段不是新的后台加工收益，也不构成玩家必须完成的工艺操作。
