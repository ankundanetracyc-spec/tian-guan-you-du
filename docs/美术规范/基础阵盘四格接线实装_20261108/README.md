## 实际接线显示

格线位于完整部件图之下；名称、选中、端口和线路独立显示。线路按真实自动连接掩码画出直段、转角或合法分支，不把所有线格都画成十字。错误侧不接线，部件旋转后端口与接线同步更新。

信号与供能共同使用颜色、线型和端口区别；异类线不相接，四向跨线被拒绝。基础信号三岔需对应逻辑件，供能只允许同源T形分供。“隔络桥”只保留规划名称，本批没有相应素材或操作入口。
