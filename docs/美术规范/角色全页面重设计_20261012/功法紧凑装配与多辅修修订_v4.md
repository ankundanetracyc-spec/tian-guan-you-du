# 功法页紧凑装配与多辅修修订 v4

状态：2026-10-12，根据用户对理想图的反馈修订，仍为设计交付。本文覆盖 v1—v3 功法页中的研读区域、大面积主辅修卡及固定一主一辅布局；其他页面继续沿用 v3，属性与检索约束继续沿用 v2。

## 页面职责

- 角色功法页展示和配置主修、辅修，浏览所选秘籍的篇章、修持与化法。
- 研读在静室进行。删除角色功法页的研读标题、研读位、研读进度与开始／暂停／选读操作；本轮不改动静室的研读流程。
- 秘籍与篇章说明沿用现有悬停内容，不建立专门详情页面或常驻详情列。新版图展示未悬停的默认状态，浮层样式继续采用 v3。

## 紧凑装配栏

1. 页眉下放一排紧凑槽卡，主修固定在最左，其后按实际可用数量排列辅修。图标、身份标签、秘籍名和小型更换入口在同一卡内；单排高度约76—90设计像素，不再放大幅秘籍插画与重复描述。
2. 当前示例一主修、一辅修只显示两个槽卡，槽卡维持合理宽度，剩余空间留白，不强行拉伸成两个半屏面板。
3. 扩展示例一主修、三辅修沿用相同槽卡尺度，同宽画幅中四卡仍放在一排。该示例不规定上限或境界解锁门槛；今后更多可用槽位也按数据排列。
4. 窄画幅或更多槽位优先换行，仅装配栏增加所需行高；章节区保持独立滚动，不缩小正文来塞下全部内容。选中槽位应可见，顺序稳定。
5. 未装配的可用槽显示“尚未设置”及添加入口；未开放槽位不在当前图中虚构展示。槽位数由实际已确认规则与角色状态提供，不由这次 UI 写死。
6. 长秘籍名优先保持可读字号；必要时省略并在悬停中给出全名。槽卡之间不挤占操作目标。

## 共用章节区

- 所有装配槽共用一个章节区域，不为每个辅修复制一套大面板。
- 点击已装配槽可切换查看该秘籍；选中槽以墨绿细边标识。更换入口独立命中，空槽点击打开原有选择入口。
- 下方标题及“篇章／修持／化法”按当前查看的秘籍刷新。查看与更换分离，浏览不会直接替换秘籍。
- 当前展示《乘物游骸真经》的游骸、托身、解形、冯虚四篇。图中只有首篇已掌握，其余未掌握，均为排版示例，不写入存档。
- 主修与辅修的实际生效分支沿用秘籍规则和已有数据。切换查看对象后必须展示对应真实状态，不能将图中主修的双分支状态复制给辅修。
