## 本次明确的方向

- 复用当前悬停内容、真实字段与文案生成入口，不重做信息规则，不新增专门详情页面。
- 技能、装备、功法正文不常驻预留右侧详情列。需要阅读具体对象时显示锚定该对象的浮层。
- 将腾出的空间分给技能库与装配位、穿戴与法宝区、功法章节。页面不被大幅插画或重复说明挤压。
- 浮层美化集中于纸面与墨面材质、灰褐细边、图标适配、标题／正文层级、标签和分隔线。属性计算、效果数值、关键词定义均不变。
- 原有真实选择窗口仍可保留，例如更换秘籍、衣着选择；它们是操作入口，不是额外详情页。

## 共用浮层表现

| 元素 | 设计要求 |
| --- | --- |
| 外框 | 正矩形细边及克制角笔，清楚的纸面或墨面轮廓，不用泛光与浓重阴影 |
| 头部 | 图标与名称横排；图标常规约64—80设计像素，保持原比例，不裁切，不扩成半张浮层的大插画 |
| 标签 | 按现有数据显示；可换行，不增加不存在的属性或机制 |
| 正文 | 保留已有内容、顺序与计算结果，以行距、留白和分隔线提高可读性 |
| 字色 | 浅宣纸配深墨，深墨底配浅纸色；山水只在低对比背景，不压正文 |
| 尺寸 | 宽度有合理范围，高度随真实内容增长；不因空字段占固定大块空白 |
| 位置 | 复用对象锚定与屏幕边缘避让，避免挡住被悬停对象；切页、关闭时清理 |
| 触发 | 保留现有悬停延迟与移开关闭方式，纯悬停只承担阅读 |
| 缺图 | 使用现有类别图标或简洁占位，不凭空画成另一件物品 |

技能、装备、功法、属性及其他角色说明统一沿用行囊的黑色墨底浮层，保留原纸墨纹理、灰金细边与四角角笔；浅纸色标题与正文、低对比分隔，不使用与正文面板同色的浅纸底。保留完整现有内容和图标比例。

图中浮层仅举例展示已有内容。接入时须逐项保留当前完整信息，不能因为理想图只画了部分条目就删掉真实字段或截断长描述。

## 操作与阅读分别落位

- 技能：左侧列表点击装配，右侧已装配技能整格点击卸载、整格拖拽排序；图标占满名称栏以上区域，不再保留编号行、箭头或移除按钮，纯悬停只展示信息。
- 检索：名称／效果、关键词、秘籍来源与类别仍在固定检索栏组合；不要求把鼠标移进悬停浮层点击来源或标签。v2“点击详情快捷筛选”不再是必要交互。
- 装备：穿戴／卸下沿用原有操作入口或物品单击行为；衣着选择仍是实际操作。悬停只查看装备信息。
- 功法：主辅修更换、研读安排、暂停、分支选择留在相应卡片／节点上；卷章与分支说明悬停查看，不为阅读另设页面。
- 行囊：悬停只读；左键选中可用物品后才显示相应操作与取消。保留消耗品接口，不编造物品及使用效果。
- 数量始终在名称后，例如“灵石 * 12”，图标内没有数量徽标。
- 属性页保持 v2 移除灵核、造诣可扩展的布局，读取当前真实数值；按用户确认不修改任何公式。
