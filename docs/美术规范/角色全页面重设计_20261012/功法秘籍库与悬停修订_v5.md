# 功法秘籍库与悬停修订 v5

状态：2026-10-12，按用户连续反馈修订，随后已获认可并授权实装，见[角色各页实施记录](角色各页实施记录_20261012.md)。本文覆盖此前功法页的大面积卷章布局及心法直接展示尝试；保留紧凑装配栏、多辅修、静室研读与共用悬停规则。

## 最终反馈与页面结构

- 用户不认可心法常驻说明区，改回悬停查看完整效果。
- 修持、化法、习得只在卷章行内保留简洁文字入口，不铺开属性数值、目标技能、招式或长说明；不放图标。
- 删除功法正文区竹叶、山水插画，保留干净纸面；边缘背景继续沿用项目风格。
- 页面必须能浏览未设为主修／辅修的已学或持有秘籍，并能检索秘籍、关键词和习得内容。

页面依次为：紧凑主辅修栏；检索与筛选栏；左侧秘籍库与右侧共用卷章区。卷章行约60—80设计像素，文字入口约34—40高，不为少量标签放大整块面板。

## 秘籍库与浏览状态

1. 秘籍库来源为当前角色已知／已学秘籍及当前持有秘籍，按资源路径去重；未装配的已学秘籍必须可见。现有 `Character.get_known_gongfas()`、已学卷章记录和行囊资源可复用，不能只读取主修及第一个辅修。
2. 筛选“全部／已学／持有”独立于是否装配。持有但未学时照实标注，实际可阅内容遵守现有权限；这次 UI 不额外授予学习权限或披露未知内容。
3. 浏览库中对象只更新当前查看的秘籍，不改主修、辅修，不启动研读，不推进时间。主辅修栏始终反映真实装配；列表选中态反映浏览对象，两者不混用。
4. 右侧展示所选秘籍名称、已学卷章数量和装配状态，以及紧凑卷章列表。心法文字入口只保留名称与版本提示，完整内容悬停显示。
5. “设为主修／设为辅修”沿用真实学习、兼容性和槽位限制。多辅修时先选择实际可用目标槽，不把三辅修示例作为槽数上限或境界规则。
6. 图中主修《胎息经》，浏览《乘物游骸真经》且标注“未装配”，用于说明浏览与装配分离；列表数量、学习进度和装配均为排版示例，不能写入存档。

## 悬停信息

| 入口 | 展示内容 |
| --- | --- |
| 心法 | 当前最高已学卷章版本的完整心法效果、主修额外效果及真实生效状态；未装配时明确是预览，不标“已生效” |
| 卷章 | 学习条件、学会永久所得、已学／未学状态，沿用现有字段 |
| 修持 | 本卷修持内容与仅战斗内生效范围；不在格子中写属性加成 |
| 化法 | 只显示适用范围、化法追加及必要公式；目标技能自身的信息栏保留完整效果、费用、目标、次数及冷却 |
| 习得 | 本卷授予的主动技能、大世界术法及其他已定义内容；区分“可习得”与“已掌握”，没有新增时照实展示 |

未学卷章允许在既有可阅范围内预览该卷心法版本；不把后续升级堆在首卷，也不将多个完整版本重复叠加。纯悬停浮层不放操作按钮。已有辅修分支选择操作留在相应节点，查看说明不自动改变分支。

## 检索

- 文本框支持秘籍名、当前已有的关键词及习得内容名称；多条件与“已学／持有”、关键词筛选共同生效。
- 关键词复用秘籍、心法和所属技能已有的明确构筑标签；检索标签不产生新效果、职业或学习门槛，不把秘籍归属本身当成关键词。
- 检索结果显示匹配秘籍；如匹配来自某卷技能或大世界术法，进入所选秘籍时定位对应卷章，具体说明仍由悬停查看。
- 未匹配时保留筛选栏并给出空状态；不改变当前装配或把临时检索写入养成数据。
