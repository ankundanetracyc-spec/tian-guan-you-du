# 行囊界面实施记录

状态：2026-10-12，用户认可行囊理想图并授权还原 UI 与布局，已接入正式行囊场景；角色各页实装与后续拥挤布局修正见[角色各页实施记录](角色各页实施记录_20261012.md)。

## 本轮接入

- 使用从认可图生成的无字纸墨外壳素材；文字、按钮、物品格、图标与浮层均为原生控件和真实角色数据。
- 以1672×941设计坐标统一缩放并居中，保留左侧分类栏、顶部返回／整理、名称搜索与排序、八列通宽网格和底部提示。正文重复标题按后续反馈删除。
- 保留真实30格容量；按最新“避免不必要滚动”反馈，格高调整为164、正文网格高704，八列四行共698高，可完整排列30格。分类和检索作用于普通物品与唯一法宝；没有匹配时显示空状态。
- 物品格采用宣纸底、细线角笔、墨绿悬停／选中框；数量只显示在名字后，如 `灵石 * 12`，数量1不重复显示。
- 墨色浮层采用横排图标与名称、类别标签、真实元信息及完整原有说明，高度随内容变化；长内容内部滚动，并避让屏幕边缘与当前物品格。
- 悬停只读；左键可操作物品固定浮层，显示“使用／取消”，已装备时显示“卸下”。点击空白、取消、切类、关闭面板清理选择，Esc优先取消固定操作。
- 装备和法宝仍调用现有装备／卸下逻辑；`IInventoryItemUseHandler` 继续作为消耗品扩展接口，未新增任何物品使用效果。
- 名称／数量／类别／位置排序只改变浏览顺序；“整理”才使用已有移位接口整理真实位置。“位置”且未筛选时保留拖动调序。
- 共享的 `StorageItemSlot` 只在行囊显式启用新布局，交易面板继续使用原方格展示。

## 通用领取与整理布局修订（2026-10-24）

- 用户要求领取页缩小为居中弹窗：1000设计单位宽、六列，按物品数显示一至三行，更多物品在列表内纵向滚动。默认全选、整份领取；按2026-10-25最新反馈，物品格只显示名称，数量在悬停详情中查看。
- 领取物品格改为148×148正方形，网格不横向拉伸；随行数同步调整弹窗高度，保留完整行与底部按钮安全区。
- 领取页底部仅“领取”“取消”两个等宽按钮，整组水平居中；取消放弃未领取物品。空间不足时点击领取进入整理，提示居中置于按钮上方独立一行。
- 整理行囊改为交易同款全屏纸面背景，左右等宽五列物品栏，中间显示腾格提示与确认丢弃，右上返回领取。保留原领取选择，确认丢弃后回到领取页。
- 标题、数量、按钮与物品名均在框内安全区排布；领取外壳裁除原素材透明留边，长物品名最多两行并省略超长内容，提示可换行，不允许文字越框。
- 正式控件为 `csharp/panel/ItemClaimPanel.cs`。编译0警告0错误；已运行 `ItemClaimPreviewScene` 查看1920×1080领取、长列表及全屏整理画面。此记录不等同正式旅程全流程交互验收。
