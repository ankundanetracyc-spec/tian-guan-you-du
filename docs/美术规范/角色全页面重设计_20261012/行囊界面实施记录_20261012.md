# 行囊界面实施记录

状态：2026-10-12，用户认可行囊理想图并授权还原 UI 与布局，已接入正式行囊场景。功法仍为设计阶段。

## 本轮接入

- 使用从认可图生成的无字纸墨外壳素材；文字、按钮、物品格、图标与浮层均为原生控件和真实角色数据。
- 以1672×941设计坐标统一缩放并居中，保留左侧分类栏、顶部返回／整理、正文标题、名称搜索与排序、八列通宽网格和底部提示。
- 保留真实30格容量，超出首屏三行后在网格内滚动。分类和检索作用于普通物品与唯一法宝；没有匹配时显示空状态。
- 物品格采用宣纸底、细线角笔、墨绿悬停／选中框；数量只显示在名字后，如 `灵石 * 12`，数量1不重复显示。
- 墨色浮层采用横排图标与名称、类别标签、真实元信息及完整原有说明，高度随内容变化；长内容内部滚动，并避让屏幕边缘与当前物品格。
- 悬停只读；左键可操作物品固定浮层，显示“使用／取消”，已装备时显示“卸下”。点击空白、取消、切类、关闭面板清理选择，Esc优先取消固定操作。
- 装备和法宝仍调用现有装备／卸下逻辑；`IInventoryItemUseHandler` 继续作为消耗品扩展接口，未新增任何物品使用效果。
- 名称／数量／类别／位置排序只改变浏览顺序；“整理”才使用已有移位接口整理真实位置。“位置”且未筛选时保留拖动调序。
- 共享的 `StorageItemSlot` 只在行囊显式启用新布局，交易面板继续使用原方格展示。

## 文件与素材

- `csharp/panel/StoragePanel.cs`：真实数据、筛选、排序、选择与使用。
- `csharp/panel/StoragePanel.View.cs`：布局、样式、浮层自适应与缩放。
- `csharp/panel/InventoryPaperFrame.cs`：纸墨材质、细框角笔、悬停边框与浮层指向。
- `csharp/panel/StorageItemSlot.cs`：行囊格布局扩展，保留交易使用方式。
- `tscn/panel/StoragePanel.tscn`：正式行囊入口。
- `textures/ui/inventory_20261012/approved_shell_v1.png`：无字外壳。
- `textures/ui/inventory_20261012/category_icons_v1.png`：分类与公共小图标。

新素材由内置 imagegen 生成，提示词见本目录 `生成提示_行囊实施_*.txt`。纸面细框与可伸缩轮廓由控件绘制，复用现有字体和纸面素材；不是整页静态图替代 UI。
