## 统一风格与后续还原

- 暖宣纸、深墨导航、灰褐细线、克制墨绿强调；山水与竹影集中在边缘，正文保持清楚。沿用现有悬停内容与触发方式，优化图标、标题、纸面／墨面和正文排版。
- 六个角色页共用导航宽度、页眉、间距、标题层级和按钮样式；行囊沿用相同外壳，左栏改为分类。
- 按最终 PNG 的画幅比例、模块位置和留白还原，优先复用项目现有背景、立绘、物品图及字体 `LXGWZhenKaiSlabGB-Regular.ttf`。
- 图中的新增小图标只是设计方向，认可后需与真实资产统一。文字、状态、数量和进度由真实数据填充。
- 战斗使用固定十技能位，不展示心法或主辅修横栏；相关内容集中在功法页。功法不设研读位，研读在静室；主辅修使用紧凑装配栏，辅修数量可扩展，示例秘籍为现行四篇。关系不虚构人物和好感。
- 正式实现不将示例装配、篇章状态、属性或法宝槽状态写入存档；长名称与多条内容在对应模块内换行或滚动。

## 行囊交互

1. 删除固定右侧信息栏，网格使用完整正文宽度。
2. 悬停显示锚定物品的浮动详情，移开关闭，靠近屏幕边缘时避让。
3. 左键选择可用物品后，浮层显示“使用／取消”；取消、点击空白、退出页面关闭。不可使用物品不显示使用按钮。
4. 图中布甲的“使用”映射现有穿戴行为；已装备物品按实际状态提供卸下动作。消耗品保留可用性判断与执行接口，**目前不配置物品或使用效果**。
5. 数量只出现在名称后，例如 `灵石 * 12`；图标内及角落均不显示数量。数量一时只显示名称。
6. 两张行囊图分别展示悬停、单击状态；实际同一时间只保留当前物品的浮层。
