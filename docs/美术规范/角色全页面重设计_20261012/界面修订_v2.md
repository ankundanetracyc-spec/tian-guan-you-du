- 条目增多后仅造诣区内部滚动；保持字体和单项高度。当前不编造未来造诣名称或显示无定义的占位属性。
- 名称悬停解释用途，数值悬停解释真实来源；不在常驻页面堆公式。

## 技能检索设计

| 控件 | 行为 |
| --- | --- |
| 文本搜索 | 忽略首尾空白，按技能名称、展示关键词、玩家可见效果文本匹配；不搜索内部效果 ID |
| 来源秘籍 | 下拉内可按秘籍名查找；选中后只显示该秘籍对应的已学可装配技能。保留全部来源和通用来源 |
| 关键词 | 使用项目已有展示标签：生命、闪避、回复、体力、增伤、伤势、防御、攻防联动；下拉内可搜索标签 |
| 类别 | 全部、攻伐、术诀、守御；沿用技能现有分类 |
| 快捷筛选 | 点击技能详情的秘籍来源或关键词，直接设置对应筛选；再由重置恢复全部 |
| 空结果 | 显示“没有符合条件的技能”及清除筛选入口；不显示空白无解释列表 |

- 文本、来源、关键词与类别以交集组合；显示真实匹配项数。
- 示例：来源“乘物游骸真经”＋关键词“闪避”，示例已学列表中匹配蜕形、托身。
- 已装配技能不受检索影响：筛选不会自动卸下技能、重排槽位或隐藏中间已装配项。
- 搜索与筛选不改动存档和技能数值；没有选择新技能时保留当前详情，不因输入搜索就执行装配。
- 来源优先使用技能的秘籍来源；需要时通过秘籍章节授予技能关系补全，化法变体按实际所属秘籍与基础技能关联处理。没有依据时标为通用／未标注，不用资源目录猜来源。
- 构筑检索使用 ActiveSkillData.tags；keywords 是内部机制标记，不能原样当作玩家标签暴露。
- 大世界术法和不可装配心法不混入即时战斗技能列表；功法页继续展示相应学习内容。
