# 共享袖母图与独立承载

本轮选用共享v15母图。新生产图不再沿用原near／far两张不同布局的紧袖Sprite：两侧使用同一衣袖画布、同一横向物理尺度和同一手部尺度，只将各自源动作的肩肘腕位置作为目标。远臂原动作前臂较短不构成缩小手掌、缩窄整袖的理由。原35／39点袖网格保留在source数据中作研究与关闭优化时的基准，不作为本轮宽松袖的正式承载。

## 实际画稿锚与形状

当前母图实际原生1254×1254；不是提示词工程尺寸。肩连接轴选为S(615,272)，最细肘截面实测平台y572—582，选E(595,577)，裸手真实出口选W(610,870)。S是本轮装配轴的选择，不伪称可从无骨画稿精确反推出肩关节。腕必须落在皮肤出口，不能沿用旧far source腕位置落在衣布里的情况。

袖口低端约(468,908)、高端约(688,847)，袖口斜线约`y=-0.276922x+1037.56665`。当前实际腕到两侧口缘距离约1:1.81、袖口约掌宽2.5—2.7倍；它们是选定图的测量，不写成提示词精确1:2或2倍已经满足。详细像素、肤色分区、有效Alpha和色差见[共享母图实测](共享袖主图实际锚位与色彩复核_20261105.json)。

当前形状采用上臂从上向下收细、肘最窄、小臂向口单调展开的轮廓；不添加肘部鼓包、额外褶皱或中段比袖口更大的袋形。下侧余布来自不对称画稿本身，承载不另加球形puff，也不把整个肩／上臂扩粗。当前两侧衣布由同一母图读取，手部按独立舒展／握拳变体选择，方向遵从用户最新裁定：近手手背朝屏、远手掌心朝屏，两侧拇指均在画面右侧；不据youbi等原骨名把图片翻回。

## 新承载的实现约定

`tools/action_battle_test/ink_outfit_sleeve_mesh.gd`独立创建连续条带Polygon2D，使用母图原归一UV，不改PNG、不作局部UV挤压。默认S／E／W按`实际像素/1254×60`进入共享60×60逻辑图；这个逻辑图是本轮生产约定，不表示恢复原两侧Sprite的不同布局。

布料以两段直骨轴承载，并在整段内平滑横截面方向。截面宽度按画稿和统一物理尺标保持，不在线性骨权混合中压瘪；没有局部高曲率肘弧、没有额外肘鼓包。轻微垂量为确定性的0.25逻辑像素，未使用逐顶点物理。腕之后的手区采用独立刚性变换，弯肘不会拉长、缩窄或揉挤手掌。

导出的`model_frames_20261104.json`已经是Unity坐标乘100后的Godot源像素；完整逻辑图的一个像素进入rig只乘`skin.source_scale`一次，不能再除100。近远两侧使用同一尺标，源远侧短前臂只影响肩肘腕目标和纵向骨段，不改变手的横向／纵向物理尺寸。

helper用WeakRef读取所属skin，不形成RefCounted互相持有。它隐藏源袖绘制节点、创建独立袖节点，源frame、source mesh记录和`current_vertices`数组不变。关闭helper时恢复源袖，便于纯源坐标检查；这一开关不是最终宽松袖的视觉方案。

## 接口与调用次序

- `build(skin, author_overrides={}) -> bool`：在源附件和手材质创建之后调用。覆盖项按`sleeve_near`／`sleeve_far`分组，`shoulder`／`elbow`／`wrist`均用60×60逻辑坐标Vector2。
- `update_pose(delta, clip)`：源姿态、源骨附件和手变体更新之后调用；暂停由skin入口统一早退。
- `set_enabled(bool)`／`set_visible(bool)`：管理源节点与新节点的显示，不切回旧UV来掩盖新图形变。
- `get_component_mesh(component)`：返回实际新袖节点，隔离截图必须使用它，不能误打开隐藏源袖后宣称展示的是新carrier。
- `get_diagnostics()`：记录实际author、网格数、刚性手误差、源数据未改等事实。

衣摆secondary独立处理衣身网格，不参与袖形变。手区斜袖口遮罩由skin维护，两侧衣布只取共享near母图，far及fist变体只替换裸手区域。

## 已完成检查与实际画面

独立几何探针用当前母图Alpha与六段源动作各144帧，共864姿态检查：不透明三角翻转0、非有限顶点0，刚性手横宽最大数值误差约`7.63×10⁻⁶`；最小有向双面积约0.05411。另用同一图、同一手尺度和各自骨段长测试两臂伸直、弯90°、弯130°三态，不透明翻转均为0。见[几何与锚位自检](袖carrier几何与锚位自检_20261105.json)。探针是数学检查，不代替画面或用户评价。

已独立目视实际渲染的[隔离全露四袖弯伸板](../../../tools/action_battle_test/output/ink_outfit_v15_sleeve_pose_review/isolated_bent_extended_same_scale.png)、[四种普通手](../../../tools/action_battle_test/output/ink_outfit_v15_hands/four_normal_hands_native.png)、[近手预备手型](../../../tools/action_battle_test/output/ink_outfit_v15_hands/near_optional_hands_native.png)与[整套静站／跑动相位](../../../tools/action_battle_test/output/ink_outfit_v15_showcase/showcase_041.png)：两侧袖轮廓同尺度对应，弯伸未见先前挤团或不透明翻面，手完整且未被弯肘拉扁，斜口处未见明显断腕，旧肩黑圈未出现。弯肘转角偏利落、接近直角，属于这版无褶皱的图形化结果，不宣称真实布料折叠。隔离板使用的统一长度只用于形状审查，不新增玩法动作；正式跑动继续读取原动作肩肘腕目标。

当前未声称完整布料物理或原游戏运行时完全重现；最终衣袖自然程度以独立试衣场景的实际画面判断。主README、主案与索引由本轮主记录统一维护。
