# 信件界面

按[信件与限时邀约主案](../../plans/剧情与宗门/信件与限时邀约界面_20261014.md)实装。使用项目现有无字纸墨外壳、宣纸纹理、楷体、信件图标和角笔，原生文字和控件排版。

左侧仅保留“全部、未读、邀约”，中间可检索信笺列表，右侧展信；邀约时间、地点与答复独立排列。按用户反馈删除熟人／陌生人／事务分类、来信类型标签及珍藏操作，署名直接显示在信中。按钮不使用灰底遮盖素材；读信不自动建立相识，长信和长列表仅在所属区域滚动。

游戏内点击底部“信件”进入当前旅程的真实信匣。首页“试演与预览 → 信件界面预览”使用独立示例信件，展示熟人邀约、陌生来信、过期邀约与事务通知，不读取或写入正式旅程。示例宴席和结伴外出不是已开放活动；真实活动后续接入。

底部信件沿用首封信后可用的现行规则，未读数显示在原信件图标旁；首次收信前可从首页查看示例。实际信件为空时不向旅程补塞示例。
