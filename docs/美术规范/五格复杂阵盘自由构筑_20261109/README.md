# 五格复杂阵盘自由构筑

2026-11-09。本轮按用户授权保留最低4×4并新增5×5，补齐状态控制件的自由构筑。规则以[本轮主案](../../plans/百工技艺/阵法/五格复杂阵盘自由构筑_20261109.md)为准，沿已选B·墨绘铜纹与当前百工纸墨木石样式，不改源PNG。

## 当前操作

从百工“阵法”进入“绘制阵图”。顶栏选择4×4或5×5，左下“接线示例”选择“守攻阵（5×5）”可载入完整可编辑图。左侧将13种可放置部件分为输入、逻辑、输出、阵眼阵源四类，阵眼单列为固定件。Q为信号线，E为供能线，R转向，右键取下／擦线，Esc回移动。格线常显，没有元件名称或状态签；新增行列编号用于定位。

右侧“部件”配置状态、比较阈值、分流信号类型、开关许可及旧筛选／计数参数；“信号”保留旧事件草图检查；“试演”真实运行当前物理图。改图后重开隔离试演，保存与切页不重置。无法编译时明确拒绝，不代跑固定图。

完整例包含10部件、14格部件足迹、7格信号、3格供能，剩1空格，复杂度9/10。8个控制节点、7条具名连接，独立取反仍在图中，两输出共用一阵源；没有跨线、穿件或免费信号分叉。

## 试演语义

原例在生命≤30%时开持续护罩，≥60%时撤罩并允许新术法事件触发火击，中间保留原模式。比较条件来自当前部件参数，不读取旧固定示例的阈值代跑。所有输出按节点保存额度与来源，并共享阵源能量和峰值。

逻辑悬停显示“本次采样／本次控制”；输出悬停和侧栏显示实际运行、余量、付款和执行，阵源显示结算后余量。同次重发不重复付款或执行。试演使用独立人物及明确试验参数，不改正式人物、库存、图谱或战斗扫描。

用户最新追加可见传导与短报错。朱砂沿实际通过的信号路传播，赭金只沿本次成功付款的供能路流动；“回放传导”只看同一记录，不重算或扣能。报错为“护罩未接信号线（4,1）”一类短句，内部排查链和参数名不显示；坐标先列后行，左上(1,1)，向右数列、向下数行，盘边与盘下均有提示。
