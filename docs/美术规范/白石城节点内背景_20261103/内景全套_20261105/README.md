## 画面依据

直接使用当前实装白石 v7 总览与讲法前院 v2 两张图作为每一次生成的共同参考。白石保持灰砖木构、封火山墙、层层廊窗和临街檐廊；配色沿用灰蓝、灰白、橄榄绿与克制木色。没有改回玉虚宗门宫殿的建筑样式。

各处按实际用途分别取景：主街、商业转角、官署台阶、旧巷、客栈大堂、交易廊、藏书室、公示廊、公务前厅和研习侧屋。室内采用自然日光与中性灰蓝阴影，不单独切成暖黄／橙色灯光风格。

全套采用 1672×941 横屏背景规格，四边保持清晰，不画人物、可读文字、标签、UI、水印和绳签。告示、书脊保留空白，前景及通道给后续原生控件与角色留出空间。
