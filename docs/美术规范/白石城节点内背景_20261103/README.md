## v5：仙城建筑与更大俯瞰范围（历史接入）

素材：[白石城 v5](../../../textures/baishi/baishi_city_inner_overview_v5.png)，原生1672×941。重新以大世界底图为画风参考生成，未将 v4 作为构图模板。

- 视角：镜头进一步升高拉远，画面包含更多完整街坊与屋顶，四周继续延伸且保持清晰；高低与仙城气象最终仍以用户审阅为准。
- 建筑：以浅石铺地、青灰／玉色屋瓦、白墙、朱柱及克制金饰表现仙城；加入重檐高阁、多层商楼、成组城守府院落与园林宅院，普通民居穿插其中，不再让褐色木屋与小院主导。
- 布局：南街在画面下方中央向府前街延伸；东市在右侧，以多层商楼及相连铺街为主；府前街与城守府在中上部；西城旧巷位于左侧，以曲巷、旧宅与园林院落为主。四片街区不变。
- 法坛：继续作为轮值驻守在城守府内承担的子功能，不新增独立讲法区或巨型蒲团场。
- 限制：无城墙、城门、人物、可读文字、界面或边缘虚化；民居院墙与城守府普通院墙不属于城防围墙。

生成时已检查图片尺寸、建筑层次、四片布局与边缘；2026-11-05进一步接入正式地点容器与原生HUD，具体检查见上方接入记录。画中楼阁属于环境表现，不据此增加物品、资源或玩法系统。

## v4：四片街区俯瞰（历史，用户否定视角与市镇感）

素材：[白石城 v4](../../../textures/baishi/baishi_city_inner_overview_v4.png)，原生1672×941。以 v3 为修改目标，抬高俯视角度，取消四边虚化、雾化留白与景深模糊，街巷、建筑和院落延伸至画外，边缘保持可辨。

- 南街：画面下方中央至城中弯曲的主街；客栈、酒楼、商铺与车马院沿街分布。
- 东市：画面右侧中部的多条相连铺街；店铺、散摊和后侧作坊混合。
- 府前街：画面中上部；城守府、相邻城务办事建筑与告示场地。
- 西城旧巷：画面左侧中部；窄巷、民居、小院和零散店铺，非独立封闭住宅园区。

四片街区之间通过街巷连通，不画全城边界或城防围墙，不将一个独立大建筑等同一片城区。法坛归在城守府外院，是轮值驻守的子功能；研习侧屋随府内安排，不作为总览上的独立讲习院、修行区或巨大蒲团场。

画风主参考：当前节点地图使用的 `textures/world/bai_chuan/acceptance_20261030/tiles/bc_22.png`，采用暖土色地面、灰青屋顶、橄榄绿树木和简化的灰褐线条。不是继续使用玉虚旧图的高密细线纸本画法。无人物、文字、界面或水印；不画城墙、城门。低矮民居院墙保留。

已目视检查视角、边缘清晰度、四街区相对位置及法坛未独立占位；尚未做实际HUD叠加、热点配置或点击验收，画风最终以用户审阅为准。
