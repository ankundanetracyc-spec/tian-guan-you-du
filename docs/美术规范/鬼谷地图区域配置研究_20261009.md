此前只能读取 IL2CPP 调用包装；本轮找到教程表后，可以确认配置层的区域结构与占格数据。仍没有还原原生随机数生成算法和种子映射。

## 对上一版的修正

上一版固定六块矩形范围，各自产生少量山群、紧凑同类林团和孤立点景，组间留距相似，林地只靠相邻生长，缺少低地物穿插及跨组衔接。

本轮改为原创的区域分布规则：

1. 六条山地走势和七处林地走势提供地理骨架；种子改变控制点与边缘起伏，范围不用矩形裁边。
2. 山地先选中心山，再在不规则周围位置放低丘、坡石和少量次峰，外圈转为稀疏松木、散石与低脊；山地过渡随同一地理骨架延伸。
3. 林区采用连续密度场，密处有空隙，边缘有疏树；同一区域混入少量低坡、树石、灌木、散石和枯木，维持主树种识别。
4. 潭、泉、岸景在林缘附近形成局部组合，柳、竹和石随周围环境出现；洞口跟随山群。
5. 补充 28 处三至六格的小林子及少量平原点景。节点安全区保留，节点之间的留白路线轻微弯曲，避免旧版直角切林。
6. 所有图片保持原方向，树干直立；可见图形主体控制在各自占格内，景物占格互斥。基础水块仍为零，局部水面只作装饰。

以上走势、比例、噪声、密度参数为本项目原创美术参数，不是提取到的原作算法。默认种子仍为 20261009，布局算法升级为 `regional_center_surround_edge_v2`；旧算法与新算法的相同种子不会产生相同布局。当前仍采用编辑器生成并保存，运行中不重排。

## 当前成果与限制

已写入原 `BaiChuanDualGridTerrainPrototype_v1.tscn`，默认密度 1.0：40 个中心山群及连接山坡、7 处可分叉/断续的林地大范围、28 个小林子、20 组水岸景；实际 Sprite 为 929 山体/短崖、3,027 树/竹丛、1,337 坡石/灌木/枯木等、46 局部水景。原固定遗迹另计，四十款素材全部选用。

素材没有重画或改源图。本轮只运行美术布局生成与合成预览，没有运行游戏、引擎或测试。预览省略固定遗迹、绿染、地点与迷雾，不能当作游戏截图或完整视觉验收。后续由用户在原场景评价实际观感。
