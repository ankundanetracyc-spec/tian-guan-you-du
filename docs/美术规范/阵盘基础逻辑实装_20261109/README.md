## 如何使用

在百工“阵法”进入设计台，或运行独立启动器。右上“示例”可切换直连、筛选、计数、分频与分合；点选盘内部件，在右侧“参数”页修改并应用。

切换“信号试运行”，选择已有事件、填写来源与幅值，点击“送一次”。计数器显示进度，筛选器显示拦下原因，分合实例的两条线路汇回后只出现一次护持控制请求。可点“重发上次”验证同一次发生不重复计数，点“清试运行”从头比较。

试运行测试信号抵达，不实际扣阵能、加护盾或改人物。按真实接线和参数运行的逻辑核心也已用于旧战斗阵图；4×4草图尚不自动授为实物或装入正式战斗。

保存保留参数；真实修改后重建局外试运行。保存、普通刷新、被拒绝的移动／旋转均保留计数。面板与选中说明都读取当前参数，避免显示旧N。
