# 局内战斗特效：淡彩水墨与受力表现

本轮实现是战斗表现候选，视觉质量待用户验收。保留角色现有画风，采用哑光淡彩、干湿笔触和颜料沉积。主动作由有方向的劲痕描述，命中由短暂压缩、受力展开和角色局部后仰共同表现。

## 表现分组

| 现有攻击 | 形态与色彩 |
| --- | --- |
| 应敌、短打 | 暖灰短笔，快速加速到接触点，少量断笔余劲 |
| 发劲、挟势 | 暖灰宽笔，叠加错开的细枯笔，接触后向受力方向展开 |
| 撼山、痛击、蓄势重击、合劲 | 深赭灰厚笔，更大的顿笔和较重的角色受力反馈 |
| 解形、冯虚 | 灰绿曲折笔势，每段命中单独表现顿挫 |
| 灵击、灵爆 | 青灰灵息与淡染拖尾；灵爆更厚重 |
| 魂刺、摄魂 | 灰紫细锋或向内收束的双流，落点指向头部 |
| 雷击符 | 蓝灰折线从目标上方落下，受力方向向下 |
| 爆炎符 | 暗赭卷流，命中后向上卷散 |
| 撕咬、裂喉 | 上下合拢的深墨牙痕 |
| 掠影扑杀 | 三道错开的深墨撕痕 |
| 拱撞、疾拱 | 低伏宽墨与沉重顿笔 |
| 守御、回复 | 身侧护持或向内回流的淡墨；护盾受击处局部积墨 |

轻击与重击保留大小、粗细、浓度和动作反馈差异。形态尽量留出角色五官与身体动作的阅读空间。攻击轴采用施术者到目标的实际方向；男女角色和狼形使用各自的胸部、头部锚点。

## 材质和节奏

主笔锋保持清楚轮廓，淡染边缘只占较窄的范围；用不同尺度的噪声表现颜料池、纤维断痕和纸面颗粒。推进、湿边和侵蚀由局部播放进度驱动，跟随战斗暂停。近战采用准备、加速、接触压缩、余劲展开的节奏；受击身体沿受力方向短促后仰再回正。表现不修改技能资源、伤害、费用或结算规则。

剑斩仅作为实验室练手项目，现有拳脚、术法和兽类技能按上表路由。实验室从当前技能资源生成列表，并支持切换左右与斜向交手。

接触顿挫采用局部表现停留：轻击约 45–55 毫秒，重击约 80 毫秒，暴击再延长 25 毫秒。出手笔触抵达目标后停住，命中笔触和受击姿态在短促后仰后保持，再释放余劲。Spine 动画也在该姿态短暂停留；被下一次出手、受击或死亡打断时立即恢复。仅延长表现的存续时间，伤害结算和其他单位的行动继续正常运行。
