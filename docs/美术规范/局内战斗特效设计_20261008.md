# 局内战斗特效：淡彩水墨与受力表现

本轮实现是战斗表现候选，视觉质量待用户验收。保留角色现有画风，采用哑光淡彩、干湿笔触和颜料沉积。主动作由有方向的劲痕描述，命中由短暂压缩、受力展开和角色局部后仰共同表现。

## 表现分组

| 现有攻击 | 形态与色彩 |
| --- | --- |
| 应敌、短打 | 暖灰短笔，快速加速到接触点，少量断笔余劲 |
| 发劲、挟势 | 暖灰宽笔，叠加错开的细枯笔，接触后向受力方向展开 |
| 撼山、痛击、蓄势重击、合劲 | 深赭灰厚笔，更大的顿笔和较重的角色受力反馈 |
| 解形、冯虚 | 灰绿曲折笔势，每段命中单独表现顿挫 |
| 灵击、灵爆 | 青灰灵息与淡染拖尾；灵爆更厚重 |
| 魂刺、摄魂 | 灰紫细锋或向内收束的双流，落点指向头部 |
| 雷击符 | 蓝灰折线从目标上方落下，受力方向向下 |
| 爆炎符 | 暗赭卷流，命中后向上卷散 |
| 撕咬、裂喉 | 上下合拢的深墨牙痕 |
| 掠影扑杀 | 三道错开的深墨撕痕 |
| 拱撞、疾拱 | 低伏宽墨与沉重顿笔 |
| 守御、回复 | 身侧护持或向内回流的淡墨；护盾受击处局部积墨 |

轻击与重击保留大小、粗细、浓度和动作反馈差异。形态尽量留出角色五官与身体动作的阅读空间。攻击轴采用施术者到目标的实际方向；男女角色和狼形使用各自的胸部、头部锚点。

## 材质和节奏

主笔锋保持清楚轮廓，淡染边缘只占较窄的范围；用不同尺度的噪声表现颜料池、纤维断痕和纸面颗粒。推进、湿边和侵蚀由局部播放进度驱动，跟随战斗暂停。近战采用准备、加速、接触压缩、余劲展开的节奏；受击身体沿受力方向短促后仰再回正。表现不修改技能资源、伤害、费用或结算规则。

剑斩仅作为实验室练手项目，现有拳脚、术法和兽类技能按上表路由。实验室从当前技能资源生成列表，并支持切换左右与斜向交手。

接触顿挫采用局部表现停留：轻击约 45–55 毫秒，重击约 80 毫秒，暴击再延长 25 毫秒。出手笔触抵达目标后停住，命中笔触和受击姿态在短促后仰后保持，再释放余劲。Spine 动画也在该姿态短暂停留；被下一次出手、受击或死亡打断时立即恢复。仅延长表现的存续时间，伤害结算和其他单位的行动继续正常运行。

## 2026-10-11 近身与远程的统一攻击演出

最新用户要求：近身攻击先移动到被攻击方身前，抵达后才发动攻击动作与特效；触发应对时插入到这次来袭中；结束后保持面向对方，沿短促腾空弧线倒身飞回原位。远程攻击原地发动，共用相同的来袭、应对、命中与收尾流程。

近身类别沿当前表现分组识别：拳脚、发劲、重击、游骸身法、撕咬、扑杀、冲撞、突刺。灵力、魂术、雷火采用原地出手。靠近的站位按双方当前模型尺寸计算，人形与兽形各自留出接触间距。这里的移动是演出，逻辑地格、射程、目标、费用和伤害规则不变。

点招后近身移动约 0.18 秒，抵达后进入现有 0.18 秒攻击接触节奏；远程直接进入该节奏。应对发生在接触前，整个应对插入期间来袭笔触保持原进度，待应对演完再续上最后一段接触。命中短停后，近身以 0.22 秒后退弧线回到原坐标并恢复原遮挡顺序；远程原地完成收尾。实验室同步采用相同的近远程分类、接触间距与归位轨迹。

停步距离追加调整：原人形接触半径仅按显示高度的 20% 估算，导致肩臂、衣袖挤在一起。改为每人显示高度的 32%，保留原有额外间隔，使当前 1280×720 双人编队的双方中心间距由约 80 像素增至约 130 像素，给出拳与命中笔触留出空间。兽形仍按较长的身体轮廓计算，人与兽混合时采用双方各自半径之和；距离只影响演出停步位置。

距离调整后重新通过原 7 项演出检查，并追加人对狼、狼对人两项真实技能链路与画面检查，共 9 项通过。编译通过，原有百科空引用警告及运行退出时的纹理释放警告仍存在。

独立验收入口：`tools/BattleAttackStagingSmoke.tscn`，使用真实 SkillExecutor、角色、地图与队首应对。仅在隔离测试场景内设置队列，不写入存档。

本次通过近身、远程、反向近身、反向落雷、真实应对插入、接近时暂停恢复、目标在接近途中消失共 7 项检查，归位坐标与遮挡顺序恢复，逻辑地格保持不变。真实应对支付一次费用、推进一次应对槽，伤害在特写结束后结算。修正战斗编队遮住特效的问题，主笔触置于角色上方、伤害数字下方。编译通过；百科面板存在本轮范围外的空引用编译警告。
