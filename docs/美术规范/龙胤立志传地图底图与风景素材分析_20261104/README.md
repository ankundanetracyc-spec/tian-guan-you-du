## 适合百川的改进顺序

1. **保留纸墨底色，增强地域差别。** 按现有地域设定，为林地、山地、湿地和荒地等使用克制的青绿、土褐、灰白差异。先让远看时能辨区域，再补局部细节。
2. **整理留白和山林组合。** 平原减弱均匀墨纹；山群形成主脉、支脉与山口，树木采用少量林块配合零散树，保留可辨识的谷地与入口空地。
3. **让局部素材能够独立布置。** 继续用3×3承载大地形，后续为树丛、孤树、局部道路、桥渡和石景制作自己的透明素材。这样可围绕地点手工整理疏密，减少整幅画内重复的装饰图案。
4. **突出建筑，收敛背景的抢眼细节。** 地点周围留干净地面，建筑使用统一地基/短阴影与少量识别色；当前河流可降低高亮与密集波纹，让入口、桥渡和建筑更容易读取。

建议方向是“纸墨底色＋克制的地域色差＋独立装饰素材＋清晰地标”。8000公里见方、123个具名地点及[3×3紧凑版](../../plans/百川八千公里3x3紧凑地图_20261104.md)继续作为当前实现；后续若重画会影响山体/水域边界，仍应同步烘焙导航并验证已有行旅坐标。
