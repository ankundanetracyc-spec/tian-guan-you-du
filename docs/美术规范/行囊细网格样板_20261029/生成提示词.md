# 行囊样本生成提示词

工具：内置 `image_gen`，所有调用均设置 `transparent_background: true`。各物品独立生成；素材最终位置见本目录README。下列为实际采用四份源图的提示词，参考图通过 `referenced_image_paths` 传入。

## 秘籍

参考：`textures/items/item_secret_manual_ink_v1.png`。

```text
Use case: precise-object-edit. Asset: Chinese ink watercolor RPG inventory manual sprite. Edit the reference book into a FRONT FACING UPRIGHT portrait book with exact overall canvas aspect ratio 2:3 for a 2x3 fine-cell inventory footprint. Preserve the reference identity: blue charcoal cloth cover, warm ivory page edges, delicate gold cloud river and ink mountains, stitched binding on RIGHT, blank cream title label. Orthographic near-flat view, edges parallel to canvas, no diagonal tilt. One complete book only, fills about 88% of width and 90% height with modest even transparent margins. Hand-painted charcoal ink contours and subdued watercolor matching reference, restrained readable detail at 80x120 display. TRUE alpha transparent outside book. No background paper, no floor, no shadow, no grid, no text, no glow, no other objects. Output portrait 1024x1536 if possible. Preserve appearance, change orientation and composition only.
```
