# 局内下劈序列帧样片（2026-10-15）

状态：已接首页「局内动作姿势库预览」原入口；实际 D3D12 场景验证通过，效果供用户评价。沿用用户认可的男女四张人物图，本轮只调整独立墨效、样片演出与查看方式。

同日后续：用户认可本页墨效方向，现行人物已换为[立绘对应的男女默认衣装](../局内默认衣装_20261015/README.md)。墨效素材与时序保持，仅按新手掌登记落点；本页图片保留上一轮人物版本用于追溯。

## 当前表现

- 挥砍 **16 帧**、命中 **20 帧**，每帧 **768×768 RGBA8**，30 帧／秒，无循环；首尾透明，所有帧外边缘透明。墨迹由两张新生成的有机笔刷纹理，通过确定性的展开、扩散、碎裂与消隐烘焙，属于逐帧 PNG 动画，并非每帧独立手绘。
- 墨迹采用灰青、青玉与象牙白层次；浅底保留墨青主体，深底使用灰青提亮，保留透明飞白。亮部仅限纹理内的劈砍锋面与短促命中中心，未启用全屏 Bloom，不增加大面积背景光雾。
- 蓄势 0.26 秒，挥砍至命中约 0.167 秒；命中先展开 2 帧，再同步定格 0.20 秒，随后继续飞墨扩散、碎散消退。完整预览循环 3.8 秒。
- 单人演出最大拉近至 1.28 倍，男女对照最大 1.12 倍；190／320 标准高度关闭拉近。镜头围绕地面原点拉近，命中轻震短于 0.065 秒，结束恢复原位。镜头不会改变人物素材本身或各姿势的注册比例。
- 人物、挥砍和命中节点共用角色朝向；统一时间轴直接设置序列帧，暂停、拖动、逐帧查看及命中定格不会各自跑动。缺少下劈图时保留同一人物待机并继续墨效。

## 游戏内查看

首页「试演与预览」→「局内动作姿势库预览」，目的场景仍为 [BattlePoseLibraryShowcase.tscn](../../../tscn/scene/BattlePoseLibraryShowcase.tscn)。默认男修单人，按钮可重播、暂停、切换男女／对照、镜像、浅深背景、边界、局内尺寸与返回。

时间轴可拖动定位；Space 暂停，左右方向键逐帧，Tab 男女，C 对照，E 墨效显隐，M 镜像，B 背景，G 边界，V 自由／190／320 高度，F 缺图回退，R 从待机重播，Esc 返回首页。
