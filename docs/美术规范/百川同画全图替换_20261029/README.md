# 百川同画全图替换

接边修订与新参考：用户指出当前图仍有色差、树林截断，先前像素和交互通过不代表美术合格。[接边修订与《影之刃零》整体地图风格研究](../百川接边与色调修订_20261029/README.md)为后续状态入口；新参考尚未批量重画。

用户在两处同画与悬停验证后，于2026-10-29明确要求全部替换。本轮范围为53处建成地点入口（13宗门、16城市、14镇、5坊市、3村、2渡口），70处自然地点保留整体地形及独立地点信息；原123节点、逻辑坐标、归属和路网保持。

## 制作要求

- 入口与当地地形一起绘制，建筑和山水处于同一细节尺度。宗门有连续山肩／山间承托，城镇、坊市、村落在连通平地，渡口接干燥河岸；建筑及其周围清除树木，不压水或树冠。
- 一级／地方宗门、城门和其他入口保持尺寸层次；只画入口，不恢复院落全景、山路、台阶或桥。
- 保留完整同画图，再从最终整图提取原像素建筑蒙版。平时不显示另一张建筑覆盖图，悬停才显示局部提亮层；只需悬停、名称和点击，不需隐藏或移动建筑。
- 虚线路径仍单独绘制并避开实际建筑蒙版范围和名称。
