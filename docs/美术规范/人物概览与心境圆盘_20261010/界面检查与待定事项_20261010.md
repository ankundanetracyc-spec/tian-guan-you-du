# 人物概览界面检查与待定事项

日期：2026-10-10。规则来源：[人物属性、因果与心境系统设计](../../plans/人物与修炼/人物属性、因果与心境系统设计.md)。

## 已修正

- 安宁不再占扇区；圆心无心绪表示稳定，外缘以强烈情绪候选标注。首版分类已获用户确认。
- 详情入口可打开纸面详情；关闭与返回键优先退出详情。没有持久变化记录时显示暂无记录。
- 节点悬停显示当前状态与来源；扇区、圆心使用人物页统一悬停样式。
- 切换页面或人物清理悬停与详情；演示落点不会泄漏到实际人物状态。
- 已知落点变化时加入平滑视觉过渡；无真实落点时停止节点重绘，不随机游走。
- NPC 共用三列概览、真实灵根及权重、独立性别年龄、中文地点、阿拉伯数字区域声望及业力；补充资料有内边距，交谈与交易沿用原入口。
- 心境详情标题及关闭文字使用深墨色，避免宣纸上白字辨识困难。

## 尚未实现、需先定规则

1. 真实心境落点、初始状态、来源记录和存档迁移。现阶段正式页面显示未详，独立预览明确标记外观预览。
2. 首版情绪分类及界面排列已确认；相邻过渡规则、事件推移、心魔触发及修炼影响仍须细化。
3. NPC 福缘、悟性、魅力、交际、治事的生成与持久保存；目前无字段，显示未详，不由界面随机补齐。
4. 混合心绪和强度称谓的具体文案规则；当前基础名称只指明所属情绪，不设置未经确认的强度阈值。

全项目编译通过。实际 Godot 场景检查圆心、节点来源悬停、无安宁扇区、方向对应、非法坐标、详情开关及返回键、主角/NPC 共用布局、真实灵根、性别分行、演示状态隔离；保存实际页面、悬停与详情截图。预览只读取存档副本，不写正式进度。日志仍有已有窗口图标缺失及渲染器退出资源释放提示，截图和上述检查正常。
