## 本次用户修订

- 左侧整条血臂向外展开，肘部、前臂和手同步移动，给头部周围留出空间。
- 根部位于肩背高度附近，悬浮在身后，与衣服和身体保持间隔；最新要求取代此前“必须硬接两侧肩部”的表现约束。保留类似多臂法相的独立悬浮感，不额外绘制头部或躯干。
- 两臂体量接近；用户后续要求右侧略小一档，保留粗壮感。远近结合遮挡、角度、透明度和明暗表达，不把其中一臂缩成小型附肢。
- 双手仍高于人物，一左一右。用户后续指定单臂版采用画面左边的血臂，保持它在双臂版中的大小、姿势和位置；不再采用右臂单独显化的候选。
- V2先对左侧前臂、腕与手作小幅侧转；V3再将右侧血臂略缩小，并重画右侧前臂与拳头的侧向关系，让拳面朝人物右前方，减少正对镜头的四指节平铺。左臂与单臂版维持V2。
- V4按用户纠正翻转右手掌面：侧视保留，掌心／屈指内侧朝向人物自身，不能把“侧着”解释为朝敌人推掌或出拳。右臂保持略小，左臂与单臂选择沿用V2；V3的外向掌面不作为方向依据。
