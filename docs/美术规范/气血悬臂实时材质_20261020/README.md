## 当前方向

- 完整的血色半透明悬浮手臂，使用游戏实时轮廓与透明膜材质生成。无肌肉贴图、火焰根部或不透明背景；此前图像生成版本已归档并排除运行时导入。
- 掌根、前臂和上臂偏粗大；四指分别分节弯曲，拇指对掌。用户确认常驻掌心朝身体内侧、半握蓄拳；出手握拳、化解时展掌。
- 近侧臂向人物一侧外展，手掌仍高于头顶，透明膜叠于人物前方；远侧臂向另一侧外展、更高、更靠后、略小，根部被肩背遮住。左右展开在最低与最高显示层数均保留中央空隙。两臂使用不同的掌面投影和明暗，避免只靠上下平移制造深度。
- 用户后续明确肩端必须位于人物肩部。近／远侧根部固定在各自肩线，上臂向后展开，前臂绕向前方；增长从肩端向外伸展，不把根部一起放大偏移。仅保留轻微悬浮起伏，整体随人物实际姿势位移、朝向和局部取景同步。
- 三道柔和血色浮光沿肩端、肘、腕、掌到指尖单向行进。保留透明膜，不使用大片泛光。出现沿同一路径凝聚，退出收淡。

## 层数与演示边界

显臂起始层数由调用方给出为 `T`。视觉增长比例为 `clamp((当前气血-T)/16, 0, 1)`，到 `T+16` 层达到最大，再增加层数也不继续放大。例如样片默认4层出现、20层最大。

当前美术比例在0.95至1.65之间平滑变化。该比例属于画面标定，不代表气血上限、触发门槛或任何战斗数值。层数低于演示起点时血臂收淡。

单臂演示追加出拳；双臂均可追加出拳，双臂阶段额外演示近身来袭的展掌化解。实验室按钮主动触发表现，不计算自动化解概率，不扣气血、不追加实际伤害，也不修改秘籍、角色属性或存档。
