# 常驻法力护罩：淡蓝、完整包覆与浮动光影

状态：现行，2026-10-19。用户否定首轮过淡的青灰轮廓，要求改为淡蓝法力感、至少罩住完整人物，并补充罩面光影浮动。

同日形状纠正：用户否定合并全部动作轮廓后横向撑大的罩形，恢复贴合站姿的竖向椭圆。淡蓝、增强浮光及随人物移动继续生效。

## 当前表现

- 使用低饱和淡蓝、灰蓝与冰白；边界比首轮更明显，中间保留透明感。普通混合叠加，不使用加色泛光、大面积白雾或黑色罩面。
- 读取完整站姿不透明轮廓拟合竖向椭圆，包含发梢、衣摆与双足，上下留出余量。取消把全部动作最远点合并后撑宽罩形的做法。结果按素材缓存，随显示高度与朝向适配。
- 罩面增加四道不同速度、不同方向的游走亮弧，两组交错移动的薄光带，以及边缘掠光与细微色阶变化。受力侧出现两道短促涟漪和小片冰白接触光，约0.58秒收淡，不产生大型爆点。
- 护盾大于0且人物存活时维持；出现约0.24秒展开，护盾归零约0.34秒碎淡退出，死亡直接隐藏。护盾值只轻微影响颜料浓度，不影响罩体大小。
- 使用绝对前景层级，与角色、攻击墨效共同进入现行局部特写。常驻循环不加入行动收尾等待；暂停沿用原Pausable处理。
- 每个性别的各姿势共用站姿拟合的固定椭圆尺寸，出手伸臂与跨步时不让罩体忽大忽小；兽类沿用自身轮廓或体型回退。
- 护罩跟随角色实际渲染位置，包括前冲、局部发力、闪避与回位；在绘制前同步最终位置，不保留初始世界坐标。预览护罩也直接挂到演示人物下，保持与正式角色相同的父子移动关系。
