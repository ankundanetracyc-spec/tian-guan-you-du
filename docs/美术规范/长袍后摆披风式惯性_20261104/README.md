## 复核结果

- 静站与原 V21 的逐行轮廓差、头身及腿链关节位置差均为 0；鞋部与地面区域像素相同。
- 四档实际速度的步幅、步频及抬脚幅均递增；从逐帧相位反算的频率与皮肤记录一致，相位每个模拟时刻只推进一次。
- 后摆由真实速度、加速度及转向驱动。急停后有反摆与衰减，最终角度范数约为 0.00000128；暂停 12 帧时相位、物理步数及原生近景像素冻结，恢复后继续回落。
- 两条完整腿链与原裤鞋显示保留，肩颈、腰部和手部衔接已目视复核。最终全段包含两个朝向。额外反向物理检查早于最后摆臂幅度窄调，单列在[历史反向检查](历史_摆臂协调前反向检查/)。
- 后摆与步态专项 20 项通过，含更高普通速度、暂停、重开、瞬移及错步；摆臂协调专项 12 项通过，攻击、架招、准备动作、连招和错步优先级保持。

这是轻量二维悬挂后摆表现。当前没有新增御空动作；相关姿态接口为后续动作留出扩展位置。
