> 用户已认可简笔舆图方向，要求去掉石头路点、避免路径与底图割裂，并按既定规划制作初版。此目录与展示页落实这些要求；只作可操作视觉原型，未接游戏运行时、存档和旅行结算。

**打开：[百川地图初版展示](../../prototypes/百川地图初版展示_20261027.html)。**

拖拽或方向键浏览；滚轮不缩放。右上可切到玉虚、玄都、无相、中部。点选地点查看性质、归属与物产，并勾出游标前往该地的演示路线；“演示行走”按共享曲线移动，停止时返回出发点。右上“图层”可分别显隐底图、水面、路径、空节点、地点、行旅游标。左下总览只移动相机位置。

## 一、画风与层级

采用简笔灰褐山体、少量皴线、淡灰橄榄植被和暖灰米纸，撤回未被用户接受的青绿设色方案。微缩建筑是独立图标，地形、布局和建筑造型另作原创，不剪取参考视频或《觅长生》的美术。

只借鉴《觅长生》的层级经验：地貌背景、地点、可见路线、实际移动轨迹、界面分别管理。世界坐标仍为6144方图、3×3背景管理单元；背景分块不改变地点归属或路线相邻关系。

初版的六个视觉层：

1. 地表：使用自生成底图中一小块安静地表作为原尺度纹理，按九宫格铺展；避免整张低分辨率概念图放大后树木和纸纹发糊。
2. 地形细景：原生透明山体与林簇图集，独立放置，优先在山脊和林地意向附近；此版仍是疏排示意，细景位置不增加逻辑障碍。
3. 水系：独立读取规划水系，灰蓝水面、淡岸缘；可调整岸线和桥位，不重生成建筑。
4. 路径：淡土色宽底晕与细灰褐线叠加，曲线圆角；资源便道更轻，选中行程才加深。圆环空节点透明减淡，不用石头。
5. 地点：三大各用不同建筑形象；地方宗门、城市、镇坊、遗迹初版复用对应基础图标，名称与点击区域独立。资源暂用草木／山脊小符号，不把矿产统一画成药草，也不把空节点当资源堆。
6. 行旅与界面：游标沿共享曲线行走，界面独立于世界平移。演示速度只用于观看，不是遁速规则。

## 二、接入的规划内容

123个具名地点保持，包含70个野外，其中21处为有归属的知名产地。沿既有路网追加8条短资源便道，通往太素原、长生坞、万毒谷、断岳山、黑瘴大泽、凝素泽、鸣玉溪和沉锋谷；没有新增具名产地。

便道从既有空节点分叉，各补1个普通过渡点，因此空节点由313增至321，联系由169增至177，世界图共444个节点；仙盟仍单独保留，不接外界。产地已有其他连接时，便道提供另一处入口，不强制将全部产地改成死路。

所有联系使用同一份显示与移动曲线；原482段共享相邻联系加16段便道联系，共498段。正反向行走只反转读取顺序，不画第二套轨迹。

## 四、实际验证

在1920×1080浏览器实际检查：地表与图集加载成功，九个背景组存在，地图宽度6144，固定倍率；玉虚、玄都与中部可浏览。实测点选太素原并演示行走，游标抵达规划坐标1474.56／4485.12，未结算时间或资源；控制台无错误。

原图保持不覆盖；游戏主场景、NPC、库存与存档未修改。路线与归属引用、444节点连通性、498段曲线以及15桥位／13山口仍由规划检查工具验证。
