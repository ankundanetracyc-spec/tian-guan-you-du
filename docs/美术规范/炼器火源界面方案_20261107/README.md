本次为浏览器交互草案，不是Godot实机，也没有接入火种系统。保留左投料、中炼制、右用度，两种布局分别为“火源贴近炉台”和“火源常驻侧栏”。可在两个来源之间切换、查看品阶／条件／消耗留位、预览开炼后UI收起及中央火源参与炼合。

草案材料来自当前“复合投料”参考，使用现有物品缩略图；24份、8时辰、16精力为现行参考配伍的制作数据。没有读取玩家背包或假定火源无消耗。品阶与未定字段显示“—”，外观的火形凝练开关只供比较等级表现，不绑定任何来源的真实等级。

推荐“火源贴近炉台”：当前火名靠近实际火口，点更换后右侧临时切到火源详情，避免增加第四列。常驻侧栏作为经常换火时的备选。正式美术需将旧背景内的橙火拆出，才能随实际火源更换。

原始交互草案随本聊天显示；本目录保留浏览器采集画面。未修改正式炼器界面、成器公式、费用、人物持有或存档。

## 验证

浏览器中完成9项主流程检查：选火及刷新保留、演出收起材料／用度／顶栏、保留火源、跳过到成器、返回恢复材料／用度及火源保持。常驻侧栏切换也同步更新中央火源。

两种布局分别检查1024、736、320宽窗口（预览外框各留16边距，实际内容为992、704、288）：无横向溢出，按钮、标题与炉台均在各自边界内。已查看桌面、演出、成器与窄窗截图；脚本语法检查通过，浏览器无运行错误。首轮截图中的炉体和火焰为几何示意，最新图已换成生成素材；两轮浏览器预览均不能代替Godot实机验证。
