## 固定用途与保留边界

以[按钮用途与素材映射规范](../../plans/界面与美术/按钮用途与素材映射规范_20261109.md)为准，优先于三个快照的早期建议。

| 用途 | 现行口径 |
| --- | --- |
| Regular | 普通文字操作、返回、取消、文字关闭、保存维护、页内筛选、互斥选择、目录行 |
| Primary | 每个独立操作区的主提交组；同一任务的并列执行方式可同族，不以数量判错 |
| Navigation | 人物七页、静室分区等真正跨页导航，保留已批准装订位移 |
| Icon | 问号、无文字关闭等纯图标操作；不能仅因窄或按钮文字为空就归类 |
| Input | 数量、名字、检索等输入及数值增减；保留裸三角例外 |
| 专用入口／控件 | 丹方册、实体书册、场景挂牌、物品槽及战斗占形分别登记，不借专用形状给普通筛选 |

原始JSON逐字保留。其“返回=Navigation”“每页仅一颗Primary”等早期建议如与现行主案不一致，按上表覆盖，不能据此否定已批准控件。完整登记表已把普通文字返回移入Regular用途摘要，没有据此改源文件。

批准保留：

- 善功堂、藏经阁、凝核整体；地图／场景挂牌身份和轻量HUD。
- 战斗暗幕及专用边框；人物战斗首页五类同配招边框，语义仍是分类选择。
- 人物／静室导航装订位移；归元九息“养成一息／连续养息”同一主提交组。
- 数值裸三角；深墨悬停、F1键盘提示、转场暗旧金笔环。
- 行囊浅绢v5与既定物品操作菜单尺寸。

百工物理书签、部分行内链接等仍属候选专用表现，不能写成用户已批准。专用外观不推广为普通同用途按钮的第二套随机材质。
