## 唯一固定模板

[固定 rig](../../mods/appearance/approved_portrait_split_20261002_v2/rig/portrait_rig_v2.json) 是本套点位和接口数据的来源。模板 ID 为 `approved_portrait_fixed_rig_v2`，男女分别为两个兼容族。不能把另一性别或旧游戏素材按文件名直接换入。

所有九层均为 1024×1536 真透明 PNG，原点在左上，x 向右、y 向下。最终导出位移为 `(0,0)`，比例为 1；禁止按不透明边框裁小后重新居中。男女头部中轴分别为 x518、x516，衣服构图中轴为 x512，均取自本套已确认位置，不强制移成另一条中心线。

层序为：后发 → 头脸、双耳和延长颈部 → 整套衣服 → 眼 → 眉 → 鼻 → 口 → 胡须或妆容 → 前发。身体与袖子不另拆层。

固定模板同时包含头脸母图、无五官头脸、逐行颈侧轮廓、耳部遮盖范围、领口开口和显示用点位。它们保存在素材包的 `rig/`。颈部轮廓必须沿用模板；衣服遮住颈部下端，不能把颈部裁到衣领高度。完整点位表见下表及 rig 的 `anchors`，归一化坐标一并保存在 JSON。

当前几何版本为 V2：男修左领口 (430,559)、右领口 (603,559)、前交领底点 (528,711)。V1 的男修高领起点已撤回并保留追溯；其余五官、头发和身体点位均未移动。本轮去描边属于表面修稿，不另改几何版本。

## 点位的用途

五官的中心、内外眼角、鼻翼和唇角用于定位和等比尺寸校准，不能因款式改变而整体挪动。新五官使用同一无五官底图和浅暖肤色，保留随笔触轮廓变化的透明边缘，不能带独立肤色矩形。

头发按固定发际、太阳穴、耳根及后颈连接位置制作。普通发顶包住头骨；发髻、饰物和蓬松度可以改变外轮廓。当前女修中分的细小分缝可以透出头皮；它只限于模板记录的中央狭窄范围，不能用此规则放过颅顶侧缘露肤。男修当前前发在后发隐藏时也须完整盖耳。

左右领口接合点绑定固定颈侧；前交领底点、肩部和腰封作为当前服装构图控制点。衣服可以有新款式，但颈侧接口保持，前交领形状的改变须作为款式设计明确记录，不能拿改变 V 点去弥补脖子错位。后领绕颈贴合，前领从接合点自然向下交叠；领口透明开口不能伸到颈部真实轮廓以外造成空隙。

## 后续换款流程

1. 从同一性别的 `rig/*_anchor_guide_v2.png`、`*_head_master_v2.png`、`*_face_blank_v2.png` 和 `*_neck_alpha_v2.png` 开始制作。生成时明确把头颈模板作为位置依据，衣服或发型参考只负责款式。不要用已知不合格组合反推锚点。
2. 在新素材原始坐标中实测本部件的接合点，记录部件、性别、输入文件和 `landmarks`。眼睛至少包括双眼中心和一个眼角；衣服至少包括两侧领口和前交领底点。两点的成对眉或胡须按其模板记录，其他部件至少使用三个点，不能只对准一个中心。
3. 使用素材包的 `register_variant.cjs` 和绑定 JSON 把素材整层等比配准到固定画布。示例为 `rig/calibration_example.json`。配准结果另存为新款，记录来源、变换和点位残差；不会覆盖当前交付图。若点位残差大于 2 像素，退回修稿或重新测量，不分别挪动左右部件来掩盖问题。
4. 新款导出必须通过对应接口检查：领口接合点、上颈不穿模、开口内有连续皮肤，前发不遮瞳孔，当前男修前发完整盖耳。肤色与笔触仍需视觉复核；几何配准工具不会把不同底色自动变成同一套皮肤。
5. 在浅底、深底和隐藏后发的实际拼合中检查，然后再加入同一兼容族的选择列表。模板给出制作约束，未经配准和验收的任意原图不能直接宣称可互换。

## 本轮实测结果

[检查记录](../../mods/appearance/approved_portrait_split_20261002_v2/rig/rig_qa_report.json)包含实际 PNG 轮廓和像素检查。女修左右领口距接合点分别为 2、1 像素；男修分别为 2、1 像素。两性领口开口没有实心衣料侵入，开口内没有缺失颈部皮肤。男修耳部要求范围共 8082 个实心像素，前发未完整覆盖的像素为 0。

五官文件及头脸 Alpha 轮廓保持原位；男女头颈的轮廓表面经内置图像编辑柔化，保留自然的颌下阴影。完整头部与同一肤色母图重组的最大 RGB 差为 1/255；女修前后发、男修后发保持原文件。两套衣服 y780 以下与指定服装原图 RGBA 一致。男修前发由内置图像编辑重绘，原生画笔覆盖耳部，最后补齐 7 个已有正 Alpha 的耳根边缘样本；不向空白缺口复制皮肤或颜色块。

配准工具已通过一个实际偏移输入验证：将眼部素材平移 `(7,-5)` 后导入，输出回到模板位置，Alpha 与可见颜色均无差异。把右侧点位额外改错 18 像素会被拒绝导出。这验证配准和拒收机制，不代替新款的绘画验收。
