## 可操作范围

切换符谱与岗位；添加、更换、移除材料及增减份数；名称、十二功用、五行、质地与相性叠加筛选；换符笔；载入参考配伍；保存本次会话中的配伍；分砚与辅纹安排；查看工艺说明；开始、跳过和结束演示；弹层关闭与Esc。所有交互留在独立样稿内。

五档符效采用薄效、良效、优效、极效、满效的建议名称；不填未经定稿的战斗数值，也不通过样稿配伍推算档位。结果页为鉴看布局演示，不向行囊发符。

符纸上的折线和环纹是运笔路径示意，不是已经定稿的正式符图。纸材与笔型尚无正式物品定义，样稿选项不代表已开放的工具或材料。
