## 本轮边界

保持当前人物的低饱和、克制手绘方向，狼使用自然头身比例和柔和灰褐色。旧第二版母图仅作为本轮一致性参考，并非用户已认可造型。先查看人物同屏实际尺寸、放大和半速下的步态，重点检查四足承重、肩胯与脊背配合，以及第八帧回第一帧的连续性。

本轮只制作走路样片与独立预览，不把八帧走路冒充待机、扑咬、受击或倒地，也不替换整套战斗动作。正式接入范围和后续动作须按该样片的实际视觉结果推进；费用、伤害、速度、碰撞与人类NPC模拟方向保持。

## 素材与封装

使用内置 imagegen 生成四列两行、八个完整身体姿态的原生透明图集。统一画布、缩放和脚点；不逐帧拉伸轮廓包围框，不通过骨骼生成中间帧。
