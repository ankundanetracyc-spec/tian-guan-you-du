## 当前交互

- 符纸与墨砚两类准备对象；一砚即可承担整张符。
- 增加墨砚、逐砚配料、份数输入、同材合并及按份数移往别砚。
- 每笔指定墨砚、趁湿／候底纹定形、额外补墨；起笔和换砚自动蘸墨。
- 在符谱依赖范围内前移／后移笔段；放大符纸定位当前笔段及蘸墨点。
- 本次会话保存与载入纸、笔、全部墨砚和笔序；切符保留各自准备草稿。
- 按当前安排演示调墨、蘸墨、候干、运笔和收口，支持跳过及减少动态。

材料名称、图标与材性仍使用[只读目录](catalog.json)；正式制符加工适用尚未建立，选材、数量和笔型仅作样稿夹具。干湿、墨量、候干时长、笔上残墨、工时与成符档位没有真实数值结算，未定义的值继续留空。笔序图是几何示意，尚非正式符图。

墨砚材料移入只改变准备草稿，原砚同步减去相同数量。新增砚为空砚，不复制原砚；有笔段引用的砚暂不允许移除，先在笔序中改用其他砚。收起未引用的砚仅取消它的选材，不消费真实库存。
