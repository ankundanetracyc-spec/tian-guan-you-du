## 3. 关节：拓扑、拆件和遮挡共同处理

### ceremonial_beast 的实际结构

- 四条腿分别建链：前肢有 `arm_*_upper → arm_*_lower → arm_hoof_* → arm_hoof_bend_*`，后肢有 `leg_*_upper → leg_*_lower → leg_hoof_* → leg_hoof_bend_*`。四个 IK 约束绑定各自的下段与蹄段，不能简单说成整条腿只用两根骨骼。
- 四个脚部目标都在 `root_adjust` 下；腿上段分别来自 `shoulders` 或 `rump`。这使躯干与末端目标可分别控制，具体落脚仍由动作关键帧决定。
- 非发光腿网格分别是 **20、23、35、36、42、47、48、54 个顶点**。腿上段和下段网格的骨骼影响范围存在交叠；例如 `L back leg top` 由 `leg_f_upper`、`leg_f_lower`、`leg_hoof_f` 共同控制，单顶点最多 3 个导出影响。
- 躯干网格 72 顶点，影响骨骼包括 `shoulders`、`body_front`、`body_back`、`rump`、`breathe`；颈网格 53 顶点，共同绑定 `shoulders` 和三段颈骨。
- 非发光绘制顺序中，远侧四肢在身体之前，近侧四肢在身体之后。腿根的遮挡属于结构的一部分。
- 查看叠图可见网格分布适应轮廓和关节，不是统一的矩形密网；“手工布点”属于工作方法推断，导出文件本身不能证明作者采用何种编辑操作。

### Mawler 的实际结构

- 四条肢体各有 IK，足／手还分别有 `*_rot_const` 变换约束，朝向来源是对应末端目标。
- 前肩有独立骨骼、`shoulder_*_lock` 约束；近侧前肢还有 `arm_upper_f_adjust` 和 `arm_folds`，提供局部形体控制。
- 四肢网格不是一刀切：有分段，也有跨越多关节的连续网格；`leg_b` 42 顶点，影响大腿、小腿、脚和脚趾；`arm_bottom_b` 53 顶点，影响上下臂以及掌根、掌部。

**对狼的启示：**完整腿与分段腿都能成立，关键是原图的解剖、腿根遮挡、弯曲区形体以及局部权重。单纯把整条腿切成几块或改成整腿，并不会自动解决关节。

## 4. 下颌：口腔是一个连贯的变形系统

### Mawler

实际骨骼：`head → jaw_adjust → jaw_1 → jaw_2`；另有 `lip_upper`、`snarl`、`brow`。

- `head-top`：91 顶点，共受头、头冠、颈、两段下颌、上唇、龇牙及眉部骨骼影响；**并非整张头部只挂在一个头骨上**。这些骨骼分布在不同区域，单顶点最多 4 个导出影响。
- `mouth_cheek`：13 顶点，嘴角在 `head` 与 `jaw_1` 之间过渡。实际混合顶点中可见下颌／头部权重约 **0.046／0.954** 和 **0.534／0.466**。
- `mouth_gums`：17 顶点，同样由 `head` 与 `jaw_1` 共同控制；实际渐变包含下颌占比 **0.267、0.374、0.481、0.611、0.740** 的顶点。
- `teeth_top`：36 顶点，影响骨骼是 `head`、`lip_upper`、`snarl`，不随下颌整体转下去。
- 设置姿势中，嘴角／牙龈先画，上齿及头部随后覆盖，口腔内外层次明确。

### 双尾鼠

- 有 `jaw_lower → jaw_lower2 → jaw_lower3`，另有 `jaw_back_corner` 嘴角控制。
- `head_bottom` 36 顶点，共受下颌链、嘴角、头部和面部抵消骨骼影响；单顶点最多 5 个导出影响。
- `head_main` 84 顶点，另有上下眼睑控制；嘴下段和眼部并不是孤立硬贴片。

**对狼的启示：**下颌支点应落在真实颌关节附近；嘴角要有头部与下颌之间的柔性过渡；上齿、下齿、口腔暗面需有清楚归属。素材原本下颌前突、嘴角断裂或颅骨视角不一致时，应先重画配套原图，再绑定。换完整头可以用于特定表情，但无法提供连续开合过程。

上述具体权重用于说明研究对象的做法，不能直接复制成犬科参数。

## 5. 大动作：确实使用替换绘图

- 双尾鼠死亡轨道在 **1.133 秒**切入 `dead bottom` 与 `dead top`，同步隐藏常规躯干、头部和大量四肢附件；`dead top` 本身又是 78 顶点加权网格，受 `die_head` 三段链控制。因此死亡是“骨骼过渡＋专用倒地图＋继续变形”，不是把活体姿势一直压扁。
- Ironclad 的 `attack` 有 **30 条附件轨道**，例如身体切为 `attack/bod attack`，四肢、手、脚、膝和护甲有对应攻击绘图；`die` 有 **51 条附件轨道**，含专用死亡头、身体、头发和手臂。
- 这些附件轨道也包括隐藏、还原和特效显示，轨道数量不等于同等数量的新绘图。
- 动态绘制顺序也被使用：例如双尾鼠死亡、Mawler 待机和受击、Ironclad 攻击与死亡存在 `DrawOrderTimeline`。
- 这几个兽形样本的待机／受击主要靠骨骼变换与已有网格权重；所查四种基本动作中，Mawler、双尾鼠和 Chomper 没有 `DeformTimeline`。ceremonial_beast 攻击只有颈鬃的一条变形轨道；不能把效果好都归因于大量逐帧网格修形。

**对狼的启示：**扑咬、侧倒等大姿势可以准备配套替换部件，仍然保留骨骼动画。先保证关键姿势的轮廓和透视，再确定哪些部分连续变形、哪些部分替换绘图。

## 6. 对当前 v5 狼的具体诊断

依据当前 `tools/build_forest_wolf_spine_rig_v5.py` 与已导出资源；以下是改造建议，不代表已经修改或得到用户认可。

| 当前做法 | 局限 | 下一次应如何处理 |
| --- | --- | --- |
| 每条腿从矩形区域统一细分，289 顶点／512 三角形 | 顶点多，但布点不贴合关节、肌肉和脚部轮廓 | 按各条腿实际轮廓与弯曲处布点，关节内外侧分别处理 |
| 腿权重主要按原图纵坐标和固定 44 像素带渐变 | 后腿弯折、斜向肢段、掌根不一定沿同一水平带变化 | 沿真实骨段与关节局部区域分配权重，分别处理内外侧 |
| 闭口／张口／闭眼完整头切换，头部全权重归 `head` | 避开旧版独立下颌拼缝，但开合过程不连续，颈头连接也缺少柔性 | 先确定同视角头颅与正常闭口咬合，再制作上吻、下颌、口腔和嘴角配套拆件 |
| 腿根统一混合躯干，使用固定绘制顺序 | 大幅抬腿与侧倒时可能需要另外的遮挡和形体 | 单独设计肩胛／髋部过渡，逐姿势确定覆盖关系，必要时换件或调绘制顺序 |
| 死亡主要由站姿素材下沉、伸腿与折腿形成 | 侧倒的胸腔、头颅、四肢透视不能仅靠二维旋转保证 | 先画符合本项目视角的死亡关键姿势，再确定专用部件与骨骼过渡 |

狼的原图需先在静态拼合中确认：四肢数量正确、前后腿解剖正确、近远比例一致、足点符合地面、闭口时上下吻关系正常、肩胯没有球状拼口。造型未通过前，不进入整套动作精修。
