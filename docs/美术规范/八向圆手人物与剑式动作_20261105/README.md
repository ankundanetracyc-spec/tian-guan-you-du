## 造型与空间
- 固定一款黑色半束发、木簪；无五官，圆手、双色圆脚沿用水墨简化表现。本轮允许固定整头八视图，不宣称已完成立绘全部发型映射。
- 衣身从48加高15%至55.2，静态宽度40.5～42；头部与圆手尺度沿用。不通过挥剑动态拉伸身体制造长短变化。
- 八向依次为正前、右前、右、右后、背、左后、左、左前；每向使用独立衣身和头发图格。
- 统一固定浅斜俯视正交视角：不是只看头顶的垂直俯视。人物、地面、手、剑沿同一空间关系显示。
- 正侧衣身主要显示侧面布、腰带和侧云纹，前襟交叉和腰结不放在可见侧面中心；斜前仅露出转到轮廓边缘的部分前襟。首轮方向错误图被用户否定，保留为历史，不接当前场景。
- 行走身体不横摇；攻击允许有限转体、压身、副手配平和头身错峰，双脚与接触影保持地面基准。

## 剑式制作标准
| 段 | 可读动作 | 参考基准时长 | 准备前压 |
| --- | --- | --- | --- |
| 斜斩 | 提剑蓄势、右上向左下切落，穿过接触点带出余势 | 0.40秒 | 0 |
| 回斩 | 承接落势，从另一侧反切，主副手配平 | 0.44秒 | 6 |
| 直刺 | 腰侧收剑后送锋，身体随刺前压，收剑回架 | 0.52秒 | 14 |
| 横扫 | 撤剑转身蓄势、宽幅扫过正面，收势较长 | 0.74秒 | 0 |

接触参考为各段40%／40%／45%／45%；准备可调整方向，释放锁定。此处只约束动画时序和空间，不表示接入判伤或资源结算。
剑器使用既有批准PNG，通过三维刃轴／宽轴投成二维纹理四边形；握柄随角色右圆手，表现朝向纵深时的缩短、刃面翻转及前后遮挡。人物本体仍为八向二维素材。正交投影不以远近距离改变场景物体大小。
墨迹沿实际剑路短促退去，实体剑、持剑手和身体动作必须可读；不能以大片特效遮住动作，也不让残墨产生判伤。移动挥剑时圆脚仍跟随实际位移。
