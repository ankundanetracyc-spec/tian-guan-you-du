## 当前规则

- 山门／城门与山水同一张图、同一尺度和笔触生成，不另贴高细节图标；正式逻辑坐标、等级和节点ID保持。
- 宗门在可辨识的山肩、山间或缓坡承托处，城镇在连通平地。建筑脚下和周围留出干净落脚面，不压树冠、树干或水面；不得仅写一个地貌字段就算通过。
- 只画入口，不画宗门院落全景、山路、台阶或桥；细虚线路径单独显示并避开建筑及名称。
- 完整同画图保留原貌。从最终图提取原像素建筑蒙版，平常不叠另一张可见图片；悬停才显示由同一图抠出的建筑提亮层，点击仅命中建筑蒙版与名称。提亮层不缩放、不重新绘制建筑，不包含周围树林和山体。
- 原“地点”开关后续改为地点信息／反馈开关，不承诺隐藏已画入地图的建筑；本轮用户明确不需要独立隐藏。
