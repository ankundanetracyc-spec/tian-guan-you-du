**历史字段说明：**下方原五字段、四项灵力指标及旧精简模型保留为来源资料，玩家字段与后台用途以本页上方最新方向及完整细案为准，不同时叠算。

## 打开与操作

[打开双页交互样稿](index.html)。可在浏览器直接打开本文件夹的 index.html；保留项目内相对位置，字体、现有材料图标和纹理均从项目读取。自动化检查使用本地 HTTP 与 Microsoft Edge，未以自动化工具验证 file 协议。

1. 顶部切换“制符纸／研墨”，各页独立保留本批选择。
2. 左侧“选材”按名称、质地、五行和十二功用筛选；默认仅显示适用材料，“显示不适用”可查看禁用原因。同种材料重复选择会合并，份数可直接修改或增减；点材名查看实际材料资料。
3. 右侧先看“承灵品阶／灵蕴品阶”，点字段了解软适配，再更换目标规格、选择兼容工法；五项工艺字段仍可逐项查看。研墨另列“目标留存”，显示目标功用是否有实际材料来源。
4. 中下方显示纸基／调和／固形，或墨质／取蕴／调和／定性，以及本批五行关系。点“查看配伍”阅读具体接触关系说明。
5. 满足基础演示条件后可开始，自动演出后进入外观示意；也可跳过。配伍册可在当前浏览器保存、载入样稿配伍。最外层“准备／自动过程／鉴看示意”仅供直接查看状态。

右上角“返回”遵守当前全局返回样式；此样稿没有外部游戏场景，点击只显示样稿提示。

## 样稿数据与结算边界

原样稿目录来自50项物品及其实际 craft_data：纤维18、致密22、颗粒5、液体3、黏胶2；当时制纸可选23项，研墨可选50项，该目录没有气体。最新制墨范围以上方更正为准。名称、图标、五行、质地、功用及品级按资源展示，空简介仍为空。功用内部等级1对应九品、9对应一品，没有反转；材料品阶和相性仅供资料查看。

匹配依据为现有质地、功用及品级、五行和所选份数；没有给正式原料添加字段、专属配方或用途名单。目录中的演示库存、显示用派生值与来源路径仅服务此样稿。

每种材料统一12份是演示库存，各页分别演示，不能据此判断正式纸墨批次共享库存。目标规格的名称、定性字段、目标功用组合、工法兼容关系均是界面候选数据；它们用于展示选择后如何呈现，不是已批准的完整产品定义，也不是材料算出的预测值。承灵品阶、灵蕴品阶、每份墨量、造诣、灵识、精力、工时与产出数量仍显示“—”。

制作按钮仅检查演示份数、必要质地以及目标功用是否有来源；不证明份数、功用品级、工具、造诣或真实生克处理足够达到目标。承灵／灵蕴只显示已确定的字段语义，未计算实际术式负担或灵力损失，也没有新增境界或品阶禁用条件。五行关系仅识别当前材料之间的关系和阶段对象，不计算损伤、收益或来源分配。自动过程与鉴看不扣料、不产生物品、不推进游戏时间、不写人物存档。浏览器配伍仅使用此样稿专用存储项。
