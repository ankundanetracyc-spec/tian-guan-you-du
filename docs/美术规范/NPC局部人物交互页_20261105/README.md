## 实际表现

单击原有左侧名单打开人物页。左侧复用真实组合立绘，右侧列姓名、种族／性别／年龄、境界、身份、所属、状态，以及既有交谈、交易、本地话题和本次切磋、攻击入口。页面不加全屏暗幕，左侧名单可继续点选换人。纸框使用大世界同一套 `WorldHudFrame`，文字为深墨；攻击为暗赭色。

1920×1080时人物页约760×580，位置348、132；1280×720时约536×438，仍与312宽的人物名单分开，也为右侧任务栏和底部入口留出空间。动作区优先双列，较多选项独立滚动。

## 行为边界

- 非同门切磋适用于当前正式支持的双方云息。对方依原性情、认识经历和旧怨决定是否接受，商议精力1；取消免费。训练不写回伤亡，不夺物，完成切磋沿用敬重证据。
- 攻击经过局部确认和原战前准备，实际开战前仍会复核目标在场。正式快照回写伤亡，玩家战败沿用原恢复及重伤；已发生的伤势不会因撤离撤销。
- 攻击奖励只取NPC实际携带物与战后剩余物品的交集。NPC转换参战时补入的默认服装、商贸库存不计入可夺物。真正领取后才扣目标携带账并登记转移，重复回调或打开不会再次领取。
- 受害者实际受伤才沿用单向怨结基础影响18；取消或无伤撤离不登记伤害，玩家方向也不被自动补怨结。
- 冲突记录持久保存，玩家案件不混入NPC调查差事、自动裁断或执中峰当前办案入口。具体罚款、拘捕、城防AI尚未接入，当前仅保存待核事实。序章引导、接引和师承职责人物保留明确保护原因。
