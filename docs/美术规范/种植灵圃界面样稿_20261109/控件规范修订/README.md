## 依据与落实

权威来源为[全局界面统一风格规范](../../../plans/界面与美术/全局界面统一风格规范_20261108.md)，优先采用11月9日整纸中灰绿、无中央染色与无选中细线的最新裁定。具体对照[角色与静室控件](../../角色与静室纸墨木石样稿_20261108/preview.js)、[炼丹输入与按钮](../../炼丹纸墨木石样稿_20261108/preview.css)及[炼器按钮说明](../../炼器纸墨木石样稿_20261108/README.md)。不套用这些页面的布局或玩法。

| 对象 | 当前种植页采用的做法 |
| --- | --- |
| 普通操作 | 统一22字、46高，引用常规纸面；需求对照、培育详览、添加材料、查看阵法、详情等不再使用下划线式链接 |
| 主要操作 | 实际“加入”采用主操作纸面，22字、52高；进入材料页使用普通按钮 |
| 返回与切田 | 返回右上距顶18、距右24、最小114×46、22字；文字右侧独立实心三角，切田与其同高同行，前后切田用46图标底座 |
| 数量输入 | 同族输入槽内右置上下三角，不用方框加减号；到一件下限或剩余持有上限时禁用对应方向并说明原因 |
| 页签与材料行 | 共用整纸中灰绿、深墨文字；没有中央色块、选中底线或侧线，材料行另有勾选标记 |
| 悬停与按下 | 悬停轻微提亮；按下整纸和内容下沉1设计单位，外部点击区域保持不动，释放复位 |
| 焦点与不可用 | 键盘焦点2px实线；不可用保留可读文字与纸面，降低材质对比，数量错误与输入关联 |
| 弹窗与动态效果 | 关闭使用同族图标底座，确认与取消区分主次并居中对齐；遵循减少动态效果设置 |

以上尺寸均为既有1664×936种植画布的设计单位，不是固定屏幕像素。引用项目共用PNG和选择样式，种植自己的适配集中在[controls.css](../controls.css)，未修改共用原图、其他样稿或正式Godot界面。
