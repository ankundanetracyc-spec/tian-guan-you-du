## 第三版确认：统一背景与常驻时间（当前约束）

用户确认修炼方式名称为 **指定灵力、指定天数、指定日期、下层所需**，按此顺序排布，分别对应已有四种方式。名称缩短不改变计算规则。生成图个别字形有偏差，正式文字以此处确认内容为准。

[统一背景及时间母版](08_统一背景与时间_v3.png)由内置 imagegen 编辑。顶部固定显示完整游戏年月日及当前小时，例如“一年三月十五日 · 07时”；从 GameTimeMgr 读取，进入及 time_changed 时刷新。所有静室子页均可见且位置一致，切页不推进时间。当前时间与右侧行动的预计结束时间分别标明。

**同一张背景，切换前景内容**：吐纳、研读、突破、修命、修性五页只使用一个共享静室环境背景层，保持同一张背景纹理、位置、缩放、纸面底色、外框、公共导航和顶栏。不按子页换书桌、山水、人体或心相场景，也不以每页单独生成的近似背景冒充统一背景。子页只替换内容控件、列表、选择项、详情、进度和行动区；秘籍原图、六部位图示及三景缩略图属于前景内容，不覆盖或替换整个环境背景。

第二版研读页的大幅书桌与展开书本不再作为页面场景使用，仅保留其列表和研读信息组织；研读前景覆盖在共享静室背景之上，采用局部纸面保证文字对比。所有子页共用同一个界面容器，切换时背景不卸载、不重绘、不移动。

休息是独立地点行动页，继续使用同一卧房的白天／夜晚配对图，不属于静室五个子页；沿用上一轮确认的游戏时间驱动昼夜与常驻时间。昼夜是时间导致的变化，不是切换功能导致的换景。

本轮更新概念母版与约束，未修改游戏代码。生成图仍只说明布局；正式字体与数值进度条由控件渲染。

## 第二版修订（当前视觉方向）

用户认可分页布局，并要求：使用项目原秘籍图标、休息随游戏昼夜变化、减弱泛光与生成感，向项目水墨风格靠拢。本节覆盖首版的固定夜景和新绘秘籍封面方向。

- [研读第二版](05_功法研读_v2.png)
- [白天休息第二版](06_休息白天_v2.png)
- [夜晚休息第二版](07_休息夜晚_v2.png)

秘籍图标以 `textures/items/item_secret_manual_ink_v1.png` 为原件；已核查《黄庭养形篇》《乘物游骸真经》物品定义均引用此文件。概念图使用原图作为编辑参考，生成过程仍有笔画与角度偏差；正式实现直接加载物品的 `icon_path`，保持透明通道和宽高比，不把概念图中的改绘图标裁成新资源，不按秘籍名称另造封面。

休息页以游戏历法当前时间显示昼夜状态，进入时刷新，并随游戏时间变更刷新；不跟随系统时钟，不另开会推进游戏时间的计时器。白天窗外纸白、灰绿竹叶，灯不点亮；夜晚用青灰淡墨压低环境亮度，灯火仅为克制赭色点，不加泛光。昼夜使用同一卧房构图与控件位置，正式资源需配准，避免切换跳动。顶部时间与实际时间一致，醒来时刻仅作结算预览，不因为修改休息时长提前改变当前背景。昼夜边界应接共用时间规则，本轮只示范10时与22时状态，未新增未经确认的精确日出日落规则。

风格参照实际项目素材 `textures/village_overview/qingxi_li_residence_v3.png`：工笔建筑勾线、山石皴染、竹叶笔触、哑光纸本和克制淡彩；去掉体积光、光晕、柔焦、强烈投影和写实材质。减少左导航下方额外风景装饰，保留留白。夜景只改变环境画层，纸面操作区保持清楚对比。

本轮四图均由内置 imagegen 编辑并已目视检查。布局和昼夜表达已展示；生成图进度条仍有比例误差，实施时必须按真实数值绘制。仅更新视觉草案和资源引用约束，尚未接入游戏，也未实现实时昼夜切换。

## 页面结构

采用 1672×941 基准横屏，功能覆盖层明确管理常驻 HUD 的隐藏和恢复，避免遮挡与误触。地点入口仍使用项目既有悬绳竖签；本方案调整进入后的功能页面。

| 页面 | 主要内容 | 主行动 |
| --- | --- | --- |
| 吐纳修行 | 当前灵力、主修、修炼方式、时长、消耗、结束时间 | 开始修炼 |
| 功法研读 | 可读功法列表、当前卷、进度、耗时、精力预览 | 研读一日／可研读时长 |
| 闭关突破 | 当前境界、下一阶段、逐项条件、缺项原因、已定义消耗 | 闭关突破 |
| 修命·淬体 | 皮筋骨血脏心六部位、法门、材料、已有收益预览 | 开始淬体 |
| 修性·观法 | 天象／地文／物华、聚焦景、观法、配置时长 | 开始观法 |
| 休息（独立入口） | 时长或日期、精力恢复、生命恢复、醒来时间 | 开始休息 |

静室五页共用固定左导航与顶栏，无额外首页。顶部统一为地点、境界、精力和主修；右上退出。各页底部固定行动与消耗预览。修行总览保留为查看入口，不再与本次行动争夺主按钮位置；凝核测试不作为正式功能导航。

## 交互约束

- 导航和设置不推进时间；行动后沿用统一暗宣纸过渡与结果结算，概念中的卧房与静室插画仅用于行动前配置页。
- 未装主修时禁用吐纳，说明原因并链接角色页；研读仍可用。切换读本保留原进度，首卷读成停止。
- 普通休息保留按时长／指定日期两种方式。剧情限定休息只显示固定醒来时间，隐藏自由选择。
- 精力不足必须显示真实可完成时长或中断原因；预览只显示真实规则已支持的数据，不虚构灵力增量。
- 十层吐纳页切换为归元九息的已有进度与阶段；未定义的突破条件不可展示为可执行操作。
- 无功法、无法门、材料不足和境界未解锁使用短说明及对应行动提示，不新增数值。
- 六部位与三景分别复用已有数据；修性图景的未配置属性和效果不在页面补填。
