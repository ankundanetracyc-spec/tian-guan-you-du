## 运行表现与入口

[原游戏内测试场景](../../../tscn/scene/BattlePoseLibraryShowcase.tscn)继续实例化独立预览。人物根节点位于地面原点；两姿势均以左上坐标负偏移(-1024,-1900)绘制。显示比例取标准人物高度，整个循环使用固定比例。

人物和独立墨效节点共用同一个地面父节点；镜像使用父节点的X负比例，因此墨痕、命中点和位移方向同步翻转。墨效不裁到人物图片边界。动作结束恢复原地面位置；缺图时使用同一人物待机，继续播放墨效。

页面提供重播、暂停、镜像、浅／深背景、画布边界、局内尺寸、返回首页按钮；键盘Space/R/M/B/G/V/F/Esc对应暂停、重播、镜像、背景、边界、自由／190／320标准高度、缺图模拟与返回。

本轮为独立样片与测试入口；局外立绘与正式战斗消费接口不采用本轮新画布。
