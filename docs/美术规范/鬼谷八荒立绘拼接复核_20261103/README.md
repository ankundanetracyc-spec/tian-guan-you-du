## 1. 定位由共同角色空间和各部件节点确定

官方示例不是同尺寸图自动居中。每张Sprite有自己的图片大小，pivot均为(0.5,0.5)，100像素对应1个Unity单位；实际头部位置由预制体中`sprite`子节点的坐标决定，节点比例为1。必须把图片大小、pivot、节点位置一起考虑。

| --- | --- | --- |
| 前发 | 150×118 | -0.010 / 7.990 |
| 后发 | 166×71 | -0.010 / 8.505 |
| 脸底 | 136×171 | -0.010 / 7.515 |
| 成对眉毛 | 104×14 | -0.010 / 7.590 |
| 成对眼睛 | 109×37 | -0.015 / 7.465 |
| 鼻 | 28×59 | -0.020 / 7.305 |
| 嘴 | 35×19 | -0.005 / 6.915 |

游戏另一个女性前发`1702`为159×413，其节点y=6.815。虽然图片中心明显更低，但上端仍用于同一头部，较低的中心包含了长垂发的长度。因此，用整个前发PNG的外接框中心去对齐头部，会把长束的长度错误地计入头部定位。

本项目1024×1536同原点画布可以继续使用；它相当于把节点位移提前烘焙在透明画布内。必须核对的是画布里的实际发际、头围、鬓角、瞳孔及颈领位置。图片尺寸相同不证明这些内容相同。

## 2. 前后发的拆分遵循遮挡关系，后发没有统一外形

官方女性示例的前发是普通发冠、发际与两侧鬓部，后发只包含后侧发髻与簪子；后发不是一整块从头顶画到腰部的长发板。本机另取的女性前发`1702`包含长垂束，女性后发`123`是后脑与辫子；男性后发中也有长披发。

这说明前后发要按该发型的遮挡设计确定，不能按长度划分，也不能让每款后发强行满足同一种轮廓。可见发束要有连续、干净的外轮廓，被挡住的连接区要满足混搭时不露空；具体补足范围取决于实际遮挡。

本项目用户要求前发不带耳朵／肤色，仍然有效。官方部分资源有自身特殊分法，不能直接变成本项目的硬规则，也不能把8张样本概括成所有原版资源都同一种结构。

## 3. 层序负责覆盖，局部图片不能自行承担所有体积

官方预览节点的相关深度，从后到前为：后发`.13`→身体`.12`→头`.11`→鼻`.10`→眼`.07`→嘴`.06`→眉`.04`→前发`.02`。局部节点先把部件放对位置，层序再形成遮挡。

示例头层保留完整头皮、脸和双耳，不包含眉眼鼻嘴；其完整颈部主要在Body里。我们的脸层含完整颈部、衣服盖在颈部前方，是项目自己的接口，不能机械复制原作的Body／Head归属。要学的是各层如何自然接上，而不是强行照搬原作槽位。

## 4. 五官是完整绘画笔触与连续Alpha

官方眼图109×37，包含成对眼球、上下眼缘与眼周局部阴影。眉图左右一对，鼻图包含鼻梁、鼻尖鼻翼与淡影，嘴图包含唇色和唇下明暗。浅深底对照可直接看见它们通过连续透明度融入底层。

例如眼层非透明像素2765个，其中Alpha>240仅354个；鼻层非透明904个，其中863个为部分透明，Alpha>240为173个。不能把鼻部压到只剩两个鼻孔，也不能把眼层清成生硬的两块眼球；反过来，生成一块不透明肤色再盖到脸上，也不是这种做法。

这里的边缘柔化只处理边界和局部明暗，不等于在整个头发外面加一圈光晕，也不等于把头发内部高光用阈值删掉。

## 5. 统一颜色必须覆盖整个绘画体系

官方随附模板这8张PNG的非透明RGB均为灰度；RoleDress确有`colorGroup`、`color`字段。安装包抽样却包含带紫色、青色等局部原色的发型，不能据此宣称所有原作图片都是灰度，或宣称已经还原其运行时完整调色算法。

对本项目的直接启示是：前后发要共享底色、明暗跨度、线条密度和高光强度；单独写同一个“炭黑色”提示词不够。脸、耳、颈与五官的局部皮肤过渡也要在同一色光下检查。

## 6. 本次我们做偏的地方

1. **把能加载、画布对、目录对当成组合合格。** 前面的330项运行检查只能证明加载、选款、回退和合成路径正常，不能证明造型或审美合格。
2. **提示中的锚点没有稳定变成图片内的真实位置。** 最近一张前发试稿提示中央发际y265，实际中央Alpha主边界到y369，直接遮到了眉眼。生成后应在试拼时立刻淘汰，而不是凭画布尺寸继续推进。
3. **后续为锁轮廓画了过硬的环形前发模板。** 最近的低前发布局中央边界y264，生成结果约y266，坐标已经接近，但轮廓仍像厚发壳、两束细条，发色还偏褐亮。说明坐标正确也不能补救不自然的发量和材质设计。
4. **前发、后发各自承担过多头部体积。** 两个单层都做得蓬松，叠起来更鼓；发髻高度和普通发冠高度也曾混在一起判断。
5. **抠图阶段用颜色阈值与逐行最长段清理。** 深色衣纹被误纳入，真实浅色发丝被切断，造成碎片、梯级断口和耳缘残片。这些试稿应废弃，不继续局部补成成品。
6. **五官各自缩放／定位改变了整体神态。** 位置与形状必须放在同一脸上看，不能以每个部件单独更精细来替代整体协调。
