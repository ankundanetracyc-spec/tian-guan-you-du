## 接线美术

- 朱砂控制线较细，赭金供能线较宽；都是带深墨边的嵌入纹路，转角连续圆折。
- 线路由运行界面独立绘制，PNG只包含器件与短槽口，不烘焙外部走线。
- 外线延伸到图片内实际槽芯，转向与贴图同步；必要时在墨边封口处补一小段同宽桥，不用方块掩盖接缝。
- 控制线只在真实分流元件内分支；供能只保留一个同源T口。单层，不交叉、不穿器件、不加隐形桥。
- 盘面没有棋盘底纹，平时不画格线。小纸签解释名称及当前值，器件本身保持无字。

线路材质颜色表示控制／供能类别，实际许可、等待事件、放行及运行状态由真实结果纸签表示；无事件不会误写成“拦截”。
