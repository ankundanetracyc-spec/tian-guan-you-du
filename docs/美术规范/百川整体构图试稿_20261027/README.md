## 二、首张草稿的用途

使用内置图像生成，提供干净地貌引导与用户早前的水墨地图截图。前者约束方位，后者只参考纸色、笔触和低饱和风格，另画原创地理，不复制界面、建筑和地名。

底图只画地表、山林、水系；不画宗门、城镇、桥、道路、文字和人物。大部分平原与山谷保持低对比，给后续节点图标留出空间。中部是有活动内容的河谷，不做仙盟专用空地。

完整提示词见[生成提示词](生成提示词.txt)。生成尺寸仅是预览尺寸，不是最终地图大小、格长或固定倍率下的实际显示尺寸。

## 三、素材分层与复用

| 层 | 后续素材 | 复用方式 |
|---|---|---|
| 地表 | 暖纸地表、少量淡色土坡与草色变化 | 统一纸色与笔触，避免背景拼块各自染色 |
| 山地 | 低丘、主峰、山脊转折、谷口 | 山体方向与疏密形成变化，不为每个空节点画一座山 |
| 林地 | 疏林、密林、林缘和林间空地 | 小簇组合，低对比承托地点图标 |
| 水系 | 岸线、河段转弯、汇流、小湖盆 | 先定水系连续轮廓，再匹配局部段落，避免四块分别生成后河口对不上 |
| 地点 | 三大山门、地方宗门、城镇、遗迹等独立图标 | 独立透明图，不烧进背景；普通城镇可用少量基础款组合变化 |
| 行旅 | 道路、空节点、桥位与山口小景 | 根据路线数据叠加，调整节点无需重生成山水 |
| 界面 | 名称、选中态、人物和功能入口 | 继续由界面呈现，不混入地形素材 |

透明素材只在后续单独生成图标、山体或树簇时请求真实透明背景；不从这张整体稿里直接抠取作为正式素材。

## 四、拼接顺序

先完成一张统一的整体构图，再按画面尺度划分背景块。相邻块共享同一岸线、山脊和纸色参考，局部生成时保留邻块参照与重叠范围；块缝尽量经过普通地表和疏林，不切主要山峰或汇流口。

“把整体预览切成四块”只能证明切图能复原，不等于完成多张素材生成和接缝验证。正式拼接必须另检纸纹、颜色、笔触尺度、岸线与山脊方向，不用每块单独完成的四幅山水画硬拼。

此阶段不锁定背景总像素、块数与固定倍率。整体稿需要先检查节点可读性；旧200×200格、40公里／格也不直接决定图片大小。

## 五、验收边界

画风、山水占比及总体方位可以先看草稿；实际节点与岸线是否冲突，需要将地点与路线数据覆盖到同一画面检查。AI图里的地貌细节不能反过来移动已讨论的城镇或改变通行。

若山峰压住主要节点、河流错位或中央留白过大，继续调整底图，不默默修改规划来迁就图像。本轮不连接运行时、改变库存或配置旅行数值。

### 首批可复用素材候选

先以少量基础素材验证组合：统一地表1款，山脊／低丘3款，林缘／小树簇3款，坡石2款，石桥与木桥各1款。共11款候选是制作顺序建议，不是游戏规则或已生成清单；水系优先按规划轮廓独立处理，不靠各块AI图自行对齐河口。

三大宗门图标后续各自设计：玉虚偏层叠道院与青白山门，玄都偏台原仙府与府院秩序，无相偏深色古殿与峻拔轮廓。地方势力与城镇再用较小尺度表现，避免图标重新形成第四个一级中心。具体建筑细节仍须配合既有宗门内景，不在本稿替换宗门设定。
