## v02：森林与节点细化

用户反馈v01节点过素，本轮维持相同叠放位置和宽度140／128／100像素，补屋脊、柱廊、门楼、城墙角楼、层叠屋舍与布棚。屋顶增加少量蓝灰，墙面保留米灰，修饰控制在灰褐墨线与低饱和设色范围；不增加厚重石台、浮岛底座、强投影或纸面矩形。

底图加五簇森林，位于山脚与河岸开阔地外缘，林簇小而疏密有别；三处模板留位保持清楚。试阅页可切换森林版与原始底图，也可独立显隐节点。

节点与底图采用相近的灰褐墨线、低饱和屋顶与浅墙面，撤去密集瓦片、砖缝、厚重石台、景观底座和投影。叠放图中的节点宽度为140、128、100像素，直接以透明度覆盖底图；没有另外画白色纸块或地面圆盘来遮住边缘。

透明通道范围均为0—255。单独模板仅从生成图集中裁切并保留透明边；叠放预览仅缩小显示，不放大素材或重新描绘。核查了三张PNG的边缘、图集格间分离、叠放后的实际尺寸与背景协调程度。后续可继续调节线重和墙面明暗；这是模板初稿，不是三类全部正式建筑设计。

## 使用范围与生成方式

本轮使用内置 imagegen，未调用生成API/CLI。[底图提示词](底图提示词.txt)、[节点提示词](节点提示词.txt)和[模板尺寸清单](模板清单.json)已保存。用户提供截图的地貌裁片仅为风格参考，不进入游戏素材。

本轮没有把通用试阅底图直接拉伸成整个百川，也没有用这三个模板批量覆盖现有123地点。正式九图仍须遵循统一母图、分块细化、共享接边的制作流程，游戏测试入口的倍率锁定保持。现有母图细化版本的阶段验收见[母图与九块细化记录](../百川母图与九块细化_20261028/README.md)。
