# 灰背野猪、精英与变种设计

## 1. 为什么先做灰背野猪

灰背野猪是最适合的第一只凡兽：它不靠高闪避、毒或复杂状态取胜，而是以**厚皮承伤 → 拱撞施压 → 拱身架招**形成最易读的回合。玩家第一次见到它，就能学会读物理防御与化解。

它也是区分精英与变种的好试验体：精英野猪只是数值全面更高；铁鬃、迅蹄、巨牙等变种才改变被动、卡牌与行为。

## 2. 普通模板：灰背野猪

| 字段 | 数值 | 说明 |
|---|---:|---|
| ID | `wild_boar` | 保留现有遭遇 ID |
| 危险度 | 2 / 5 | 云息前期的标准单体敌人 |
| 体魄 / 灵慧 / 敏捷 / 神魂 | 10–12 / 1–3 / 4–6 / 1–3（均值 11 / 2 / 5 / 2） | 首次生成时按截断正态分布抽取；厚重、迟钝、意志普通 |
| 生命 | 157–188 | `60 + 体魄×8 + 敏捷×3 + 神魂×3 + 灵慧×1.5`；妖兽的基础与最终体魄均取当前体魄 |
| 物理防御 | 3–4 | 厚皮提供；仅减物理伤害 |
| 精准 / 身法 | 22–39 / 24–39 | 由随机四维派生；整体仍低命中、低机动，允许玩家风筝 |
| 会心 / 护心 | 10–15 / 42–59 | 由随机四维派生；厚皮承受物理伤害，护心避免遭高倍率会心轻易斩杀 |
| 行动速度 | 92.5–99.5 | `80 + 体魄×0.5 + 灵慧×0.75 + 敏捷×1.5 + 神魂×0.75`；由最终四维派生 |
| 行动牌 / 起手 | 1 / 2 | 每回合只做一件明确的事 |
| 法力 | 0 | 凡兽没有妖力资源 |

### 种族天赋：厚皮

```text
厚皮
物理防御 = round(体魄 × 0.30)。
```

厚皮是野猪固定拥有的种族天赋，不占技能槽，也不属于精英或变种词条。物理防御由最终体魄计算：普通野猪约为 3，精英或变种野猪会因体魄变化自然提高。它不做百分比减伤；小伤害技能仍可造成至少 1%伤害，法术和神魂伤害则自然成为替代解法。

### 基础技能库

| 技能 | 费用 | 条件 | 效果 | AI 优先级 | 视觉提示 |
|---|---:|---|---|---|---|
| 拱撞 | 精力 1 | 无 | `15 + 体魄×1.2` 物理伤害；面板约 27–29；准备 144 帧、收招 96 帧、冷却 240 帧 | 常规动作 | 低头、小幅前冲 |
| 拱身架招 | 精力 0 | 准备完成后持招；敌方物理攻击自身时自动打出 | 获得 `3 + floor(体魄/4) + floor(敏捷/5)` 层化解；准备 96 帧、收招 48 帧、冷却 240 帧 | 应对牌，不占主动行动 | 蜷身低首、獠牙朝外 |

野猪没有额外预备技与爆发技；它的反制窗口来自实时队列中的“拱身架招”。敌方妖兽发现玩家已排入尚未结算的物理攻击时，会优先把架招预备到队首；玩家可先以低伤害技能消耗化解，或用非物理手段绕开厚皮。

### 实时技能库构成

普通灰背野猪的资源配置仍保留 4 个拱撞与 4 个拱身架招，用于技能库数据和变种替换关系；进入即时战斗后按技能名去重为两个固定技能槽。行为频率由准备、收招、冷却和敌方队列规划决定，不再抽牌。

| 技能库条目 | 数量 | 作用 | 实时队列规则 |
|---|---:|---|---|
| 拱撞 | 4 | 稳定输出与变种替换基底 | 队列规划选择主动技 |
| 拱身架招 | 4 | 受到物理攻击时取得化解 | 准备完成后持招，匹配攻击时自动打出 |
| **合计** | **8 条配置** | 2 种技能 | 简单、稳定、没有隐藏连招 |

实时战斗配置为：局内精力上限 6、初始精力 0、法力 0、灵识 0；固定技能槽最多 10 个，个人队列最多 3 个。`initial_hand_size` 与 `cards_per_turn` 仅为旧凝核/兼容字段，即时战斗不读取它们。

灰背野猪不设额外的单次行动次数上限；连续行动受精力恢复、技能准备/收招和冷却共同限制。

### 精英、变种叠加后的技能库

| 单位类型 | 基础技能库的改动 | 技能配置上限 | 技能种类上限 |
|---|---|---:|---:|
| 普通灰背野猪 | 无 | 8 | 2 |
| 精英灰背野猪 | 无；只重算最终属性缩放数值 | 8 | 2 |
| 迅蹄变种 | 用疾拱×2替换拱撞×2 | 8 | 3 |
| 铁鬃变种 | 用硬鬃架招×2替换拱身架招×2 | 8 | 3 |
| 精英·任意野猪变种 | 保留变种改动；精英不加牌 | 8 | 3 |

“疾拱”公式为 `10 + 体魄×0.8 + 敏捷×1.6`；“硬鬃架招”的化解层数为 `5 + floor(体魄/3)`。两张牌同样引用最终属性，因此随机个体、变种与精英修正都会反映在牌面数值上。

### 凡兽卡牌的属性缩放规范

凡兽的伤害、护盾和状态强度必须优先引用其四维，不能把同一张卡写成所有个体都固定伤害。这样随机属性、精英数值修正和变种加成才会真实影响战斗。

| 招式类型 | 推荐公式 | 适用例子 |
|---|---|---|
| 蛮力撞击、践踏、重爪 | `固定基础 + 体魄×系数` | 野猪拱撞、山魈拍击、獾爪击 |
| 爪咬、扑击 | `固定基础 + 体魄×0.6 + 敏捷×0.6` | 狼撕咬、狐扑咬 |
| 迅疾突袭 | `固定基础 + 敏捷×系数` | 蛇袭、狼扑杀 |
| 毒液、吐息 | `固定基础 + 灵慧×系数`；持续伤害可再按灵慧取整 | 蟾蜍毒舌、蛇毒 |
| 恐吓、凶威 | `固定基础 + 神魂×系数` 或按神魂决定层数 | 山魈凶威、后续魂啸 |
| 护体、缩甲 | `固定护体 + 体魄×系数` | 岩背獾缩甲、野猪护体变种 |

系数由兽种决定，但凡兽首期遵循：普通攻击最多使用两个基础属性；不使用法力、悟性、功法造诣等人修字段。

### 行为规则

1. 主动队列只规划“拱撞”。
2. “拱身架招”准备完成后持招；匹配玩家的物理攻击时自动打出并获得动态化解。
3. 尚未结算的主动指令可以被架招替换；已结算或收招中的动作不打断。

### 掉落

| 掉落 | 概率 / 数量 | 用途 |
|---|---|---|
| 野猪肉 | 保底 1–2 | 食物、恢复类配方 |
| 粗兽皮 | 70% | 初级护具、交易 |
| 獠牙 | 25% | 武器材料、任务物品 |
| 厚脂 | 15% | 炼药、灯油或诱饵 |

## 3. 精英规则：只大幅强化数值

精英不再拥有随机行为词条、额外被动或额外卡牌。它就是一只体魄、灵慧、敏捷与神魂都更强的同种个体；玩家应该从金色边框、更大的体型和显著升高的面板数值判断威胁。

```text
精英修正：体魄 / 灵慧 / 敏捷 / 神魂 +25%（向上取至一位小数）
       + 掉落数量 +50%、名称前缀、金色精英边框
       + 随后重算生命、物理防御、行动速度、派生属性与属性缩放卡牌
```

精英修正在基础随机与变种修正之后应用；所有属性缩放卡会自然从最终四维重新计算伤害。精英不直接加生命、物理防御、行动速度或任何派生属性，也不增加每回合行动数、不改变牌组张数、不额外提供被动或卡牌。

| 类别 | 可获得 | 不可获得 |
|---|---|---|
| 普通凡兽 | 固有被动、基础牌组 | 额外词条、额外卡 |
| 精英凡兽 | 大幅基础与派生属性修正、金色精英标识 | 新被动、额外卡牌、第二个精英修正 |
| 变种凡兽 | 专属名称、外观、被动、专属牌 | 第二个变种效果 |
| 精英变种凡兽 | 精英数值修正 + 1 个变种效果 | 第二个变种效果、额外行动数 |
| 首领 | 手工牌组与领地机制 | 随机精英/变种修正 |

以均值四维的普通野猪为例，精英化后为体魄 13.8、灵慧 2.5、敏捷 6.3、神魂 2.5；妖兽的基础体魄同样视为 13.8，因此生命为 201、物理防御为 4、行动速度为 100.1；拱撞会因体魄提升自动获得约 15% 伤害增幅。它不多出任何机制，但面板压迫和容错明显提高。

## 4. 野猪变种与精英的区别

### 已落实变种

变种与精英独立判定、可以叠加；每只野猪至多拥有一种变种。

| 变种 | 四维修正 | 种族天赋 | 牌组替换 | 战斗题目 |
|---|---|---|---|---|
| 迅蹄野猪 | 体魄−10%、敏捷+40%、神魂+10% | 保留厚皮；额外行动速度 = 敏捷×0.5 | 疾拱×2替换拱撞×2 | 抢先手、持续进攻 |
| 铁鬃野猪 | 体魄+35%、敏捷−15% | 物理防御 = 体魄×0.50 | 硬鬃架招×2替换拱身架招×2 | 高物防、压制物理攻击 |

变种百分比修正完成后，若命中精英，再将四维各提升 25% 并向上取至一位小数，最后统一计算生命、派生属性、种族天赋和属性缩放牌。

## 5. 精英生成与数据字段

生成顺序必须固定，便于复现与存档：

```text
读取凡兽模板
→ 判定普通 / 精英 / 变种 / 首领
→ 若为变种：应用变种模板
→ 若为精英：应用精英数值修正
→ 若同时为精英与变种：两套修正均保留，名称显示为“精英·变种名”
→ 生成战斗快照与掉落表
```

建议 `BeastModifier` 字段如下：

```text
modifier_id, display_name,
physique_multiplier, intelligence_multiplier, agility_multiplier, soul_multiplier,
racial_talent_override, deck_override
```

野猪精英遭遇率：后山教程 0%，东林外层 10%，东林中层 15%；变种概率对应为 3% 与 5%。两次判定独立，因此复合概率为 0.3% 与 0.75%。固定首领山魈不进入这个随机生成流程。

## 6. 灰背野猪验收

- 普通野猪面对同阶段单人云息角色，牌组仅含拱撞与化解，不出现隐藏连招。
- 精英野猪不新增任何卡牌或被动，但四维、生命、物理防御和属性缩放牌的数值都显著上升。
- 铁鬃、迅蹄两种变种仅看名称、外观与起手动作即可辨识主轴。
- 铁鬃野猪迫使玩家换用破甲或非物理伤害，而不是单纯多打几回合；精英·铁鬃野猪仍应保留同样的反制路径。
- 任何野猪单位都不出现法力、灵根、功法或突破字段。
