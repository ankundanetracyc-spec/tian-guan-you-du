# 公共基础技能池

所有角色共用同一公共基础技能池；技能学会后进入可装配池，不随主修或辅修秘籍切换。

## 技能名录

| 范围 | 技能 |
| --- | --- |
| 公共基础技能 | 应敌、架招、痛击 |

以上三项由所有角色共用。各技能费用、目标、公式与限制以对应技能资源及现行战斗规则为准；休整与吐纳是自带队列行动，不属于技能池。

## 装配与行动

- 公共基础技能与秘籍授予技能均进入可装配技能池；学会不等于自动装配。
- 化法可以追加公共基础技能池中的指定技能，也可以追加本秘籍授予的技能；追加效果保留目标技能的原有效果。
- 休整、吐纳是所有角色自带的队列行动，不占技能栏或术法槽。休整回复 2 点体力，吐纳回复 1 点法力；两者各占一个行动位，不支付资源。
