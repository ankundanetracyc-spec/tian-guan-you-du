# 公共基础技能池

所有角色共用同一公共基础技能池；技能学会后进入可装配池，不随主修或辅修秘籍切换。

## 技能名录

| 范围 | 技能 |
| --- | --- |
| 基础攻守与应对 | 应敌、架招、痛击、发劲、卸力 |
| 气血与调息 | 养息、催血、平息 |

以上为原通用八项。各技能费用、目标、公式与限制以对应技能资源及现行战斗规则为准。即时队列战斗中的精力回复行动使用系统自带的“休整”；历史基础技能“养息”保留在公共通用技能名录，但不占即时战斗技能槽。

## 装配与行动

- 公共基础技能与秘籍授予技能均进入可装配技能池；学会不等于自动装配。
- 化法可以追加公共基础技能池中的指定技能，也可以追加本秘籍授予的技能；追加效果保留目标技能的原有效果。
- 休整、吐纳是所有角色自带的队列行动，不占技能栏或术法槽。休整回复 2 点精力，吐纳回复 1 点法力；两者各占一个行动位，不支付资源。
