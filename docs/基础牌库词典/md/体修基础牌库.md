# 体修基础技能库

---
词条类型: 基础技能库
技能库名: 体修基础技能库
适用对象: 当前主修侧重为锻躯，且满足底板解锁条件的角色
资源: 精力；不消耗法力，不占用灵识
定位: 气血调度与受击应对的锻躯底板
---

|---|---:|---:|---:|---|---|---|

## 通用系统行动

所有角色自带“休整”和“吐纳”。两者不是基础技能，不占技能栏，也不支付资源；排入角色行动队列时各占1个行动位。休整回复2点精力，吐纳回复1点法力，均不超过角色上限，且没有每轮或每场使用次数限制。它们取代旧版技能“养息”的局内回精力用途；“养息”不再进入即时战斗技能栏。

## 解锁与边界

- 即时战斗使用上述技能名对应的规范资源路径；旧版 `拳脚.tres` 与 `吐纳归元.tres` 仅作为存档兼容别名，不再由新技能库引用。
- 解锁条件：学习可主修锻躯秘籍，且体魄≥8或敏捷≥8，且体道造诣≥10。满足后可将锻躯设为当前侧重并使用本技能库；更换侧重不清除其他两途养成进度。
- 本技能库不由主修秘籍整体替换；每卷化法可改写当前基础技能，也可改写授予该秘籍的技能。
- 气血的公共规则为：基础上限3层；每下降1层回复最大生命×3%；即时战斗中没有回合末自动下降，只由明确技能或状态事件改变。

本技能库只建立气血入口、基础攻伐与应对，血炉、伤势、借力、游骸等方向由相应秘籍开启。
