# 行炁基础技能库

---
词条类型: 基础技能库
技能库名: 行炁基础技能库
适用对象: 当前主修侧重为行炁或蕴神，且满足底板解锁条件的角色；蕴神复用本技能库，再由蕴神主修秘籍化法改写
资源: 精力与当回合法力
状态: 初步构成已定；具体数值仍待后续平衡
---

## 解锁与边界

- 行炁侧重条件：学习可主修行炁秘籍，且灵慧≥8或神魂≥8，且术法造诣≥10。满足后可选择行炁作为当前侧重并使用本技能库。
- 蕴神侧重条件：学习可主修蕴神秘籍，且神魂≥8或灵慧≥8，且术法造诣≥10。满足后可选择蕴神作为当前侧重并复用本技能库。当前不另设第四套蕴神基础技能库，再由蕴神秘籍的化法改写。
- 更换主修可以切换当前侧重；当前底板不限制角色推进另外两途的独立养成。
- 行炁基础技能库不与体修基础技能库混用。
- 本技能库只承载精力与当回合法力这两项公共资源。行炁的术法连锁、蕴神的照痕与定影，均应由各自秘籍开启，不能写成行炁公共状态。
- 化法可以新增秘籍牌，或为本技能库中的某张基础牌追加效果；追加效果必须保留该基础牌的原有效果，不直接把原牌替换为另一张牌。

| 技能 | 精力 | 法力 | 关键词 | 目标 | 效果 |
|---|---:|---:|---|---|---|
| 灵击 | 1 | 1 | 无 | 指定1名敌方（单体） | 造成灵力伤害：`round(4 + 灵慧×0.50 + 神魂×0.35 + 术法造诣×0.20)`。 |
| 聚息 | 1 | 0 | 无 | 自身 | 获得当回合法力1点。 |
| 凝元 | 0 | 0 | 无 | 自身 | 仅当当前法力为0时可打出；获得当回合法力1点。 |
| 护元 | 1 | 1 | 无 | 自身 | 获得护盾：`round(5 + 灵慧×0.20 + 神魂×0.15 + 术法造诣×0.25)`。 |
| 灵爆 | 2 | 2 | 无 | 指定1名敌方（单体） | 造成灵力伤害：`round(13 + 灵慧×0.90 + 术法造诣×0.60)`。这是行炁基础技能库的标志技能，承担当回合法力爆发的位置。 |

`灵爆`是本技能库唯一的标志技能。蕴神角色使用本技能库时，仍保留以上原有效果；蕴神主修秘籍通过化法追加其神魂路线效果。
