# 公共基础技能池词典

本目录收公共基础技能池总览和技能名录。

## 一、目录用途

- 展示所有角色共用的基础技能池
- 记录基础技能池与秘籍技能、行动队列的边界
- 作为单卡词典与秘籍词典之间的中层文档

## 二、维护规则

- 所有角色使用同一公共基础技能池，不按修炼侧重切换
- 角色自己的属性节点技能单独收录于[卡牌词典人物技能节点网](../卡牌词典/基础技能节点/README.md)，不扩充所有角色共用的公共基础技能池
- 技能学会后进入可装配技能池；角色自行安排至技能槽
- 休整是角色自带的队列行动，不属于基础技能池；法力只能由明确写出的技能或效果回复
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)
