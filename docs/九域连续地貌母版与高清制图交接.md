# 大陆连续地貌母版与高清制图交接

当前地貌连续性参考（旧资源名保留）：
[`zhaoming_nine_domains_continuity_master_v1.png`](../textures/world_map/production_samples/zhaoming_nine_domains_continuity_master_v1.png)

它是旧九域资源命名下的大陆连续低细节母版，只用于锁定北方雪原、西部荒岭、百川湖盆、东陆海岸、南部山脉、荒林水网与两片海域的相接关系。它不是最终运行时贴图，不得直接放大或裁切为 4×4 成品。

## 成品原则

1. 以旧底稿 `世界地图九域功能底稿.drawio` 校验历史节点，以连续母版定山、水、路、海岸的跨格走向；当前交互区域以百川专题和运行时节点数据为准。
2. 16 张正式地形格分别重绘为 2048×2048；每张向四边保留 64px 出血，确认接缝后裁出正式区域。
3. 只能在格内补充地形细节。任何跨格河流、山脊、道路、海岸和岛链，必须从相邻格以相同位置、相同宽度、相同方向继续。
4. 地图采用克制的俯视水墨设色：低饱和、地貌大形清楚、道路和水系易读；不要光效、边框、文字、城镇插画或装饰性花纹。
5. 节点落在平原留白、山口、河湾、港湾、岛屿台地等预留区，不直接压在密集山体、水面或悬崖纹理上。

## 大陆与百川地貌锚点

| 方位 | 地貌锚点 | 必须保留的地貌关系 |
|---|---|---|
| 西北 | 北方冰雪大陆 | 冰原与雪岭向北收束，南缘山麓过渡至百川所在大陆。 |
| 北部 | 北部寒海 | 崖岸、群礁和寒海，西接雪岭，东接东海岛链。 |
| 西部 | 西部荒域 | 赭黄荒盆、盐地与暗色裂谷，东侧以山口接百川。 |
| 中部 | 百川湖盆 | 青溪湖、北来河、环湖大道和低山环抱；是当前道路汇合核心。 |
| 东部 | 东陆海岸 | 丘陵河谷与古道，西接百川，东开海岸。 |
| 东北 | 东海群岛 | 外海与岛链，不画规则岛格；航路留给节点层显示。 |
| 西南 | 西南山脉 | 长而连贯的山脉走向，保留数条山口通向荒域、百川和南部荒林。 |
| 南部 | 南部荒林 | 深林丘陵、泽地和分汊水网，向东南汇海。 |
| 东南 | 南冥海疆 | 温暖海湾、半岛、群岛与归墟潮流，和南部河口自然相连。 |

## 区域交互资产

每一张地形格同时交付两张透明 PNG：

- `world_territory_id_r00~r33.png`：纯色 ID，当前已配置区域使用资源 `WorldTerritoryData.mask_color` 的颜色。
- `world_territory_edge_r00~r33.png`：只保留真实区域边缘，供悬停时染成淡金高亮。

运行时优先采样 ID 蒙版命中区域；矢量多边形仅在美术蒙版尚未配置时作为兼容回退，不能作为正式边界表现。大陆自然边界不等同于政治边界。
