- 人类战斗当前采用灵台选行：每回合选择一行、行内从左向右，各单位当前招式按出手值交错结算；敌方招式和行隐藏，只显示其已选目标。旧逐行个人结算、随机目标及共享幕术语以灵台选行案为准；凝核牌局独立。
- 人物战斗与配招已在 2026-11-09 正式接入本人配置、存档和开局副本；局内只载入。旧“独立样稿未接入”的状态不覆盖该接入案。

- 制符三工艺已接入真实人物制作与存档；首轮参数及固定符效仍为可调候选，不是最终平衡结论。
- 地图从当前自由行旅与后续修订读起；旧200×200格网、行政格局、短峰改山和旧显示尺度不覆盖已有明确后续裁定。
- 凝核读八回合主案及 2026-11-04 数值修订；旧六回合、旧属性奖励与旧“尚未接入”记录不覆盖。玄基未定内容不补数值。
