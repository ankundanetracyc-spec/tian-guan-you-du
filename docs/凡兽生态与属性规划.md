# 凡兽生态与属性规划

## 1. 定位

凡兽是“未入道但已具战斗威胁的野生动物”，不属于妖兽六大境之一。正式境界链仍为：

```text
凡兽（未入阶）→ 通智 → 妖府 → 内丹 → 蜕形 → 天妖
```

凡兽负责序章、后山、东林外层的生态压力与材料来源。它们应让刚踏入云息的角色感到危险，但不应拥有妖力、完整功法循环或人修式资源管理。凡兽的战斗关键词是：**兽性明确、行动简单、可读可防、同种有少量变数**。

> **通用规则：**随机基础属性、种族天赋、变种、精英数值模板、精英与变种叠加，并非凡兽专属。它们属于所有妖兽的共同生成框架；通智、妖府及更高境只是在此框架上追加境界倍率、资源与更复杂的技能循环。

首期建议制作 **6 种可战斗凡兽 + 2 种非战斗生态单位**。现有的野猪、狼、蟾蜍、毒蛇、山魈直接纳入；新增岩背獾与青尾狐补足防守与扰乱玩法。

## 2. 属性：复用底层，不复刻人类面板

`LivingData` 可继续作为存档和战斗快照基类，避免分裂结算公式；但凡兽不需要继承人类的全部可见属性。

| 属性组 | 是否保留 | 凡兽中的显示或用途 |
|---|---|---|
| 生命、物理防御、行动速度、行动节奏 | 保留且展示 | 凡兽的核心可读战斗数据 |
| 体魄 | 保留，展示为“体魄” | 决定生命、会心、护心；厚皮与蛮力来源 |
| 灵慧 | 保留且沿用原名 | 决定精准、护心与异常招式稳定性；数值高不表示会说人话 |
| 敏捷 | 保留且沿用原名 | 决定精准、闪避、会心与先手倾向 |
| 神魂 | 保留且沿用原名 | 决定会心、护心与未来恐惧抗性，不开放神魂功法 |
| 精准、身法、会心、护心 | 保留且展示 | 由四项核心属性派生，完全复用现有战斗公式 |
| 心境 | 底层保留，默认隐藏 | 主要服务日常系统 |
| 法力、灵识、灵力缕、灵根、丹毒 | 固定为 0，不展示 | 凡兽未入妖道，不使用妖力条 |
| 悟性、福缘、魅力、社交、管理、职业造诣 | 不使用、不展示 | 这些是人类成长或经营字段；凡兽模板不写入 |
| 年龄、寿元、功法、装备槽、突破条件 | 不使用、不展示 | 凡兽不会修炼、穿装备或主动突破 |

这意味着凡兽详情页只显示：**名称、兽种、危险度、生命、物理防御、体魄/灵慧/敏捷/神魂、精准/身法/会心/护心、被动、招式关键词、掉落**。不显示“灵根、境界、法力、功法、悟性”等人修字段。

### 四维与派生属性

| 底层字段 | 展示名 | 主要体现 |
|---|---|---|
| `physique` | 体魄 | 野猪、山魈、獾的血量与近战压迫 |
| `intelligence` | 灵慧 | 蛇的捕猎准确、蟾蜍的毒舌命中 |
| `agility` | 敏捷 | 狼、狐、蛇的先手和闪避 |
| `soul` | 神魂 | 凶兽的会心、护心、抗恐惧潜力 |

凡兽没有统一的“怒气条”。个别招式需要蓄势时，用可见状态层（如“冲势”“伏猎”“鼓腹”）实现；这比给所有野兽增加一根资源条更直观，也不把凡兽做成低配修士。

## 3. 首批可战斗凡兽

所有数值使用项目当前公式计算：

```text
人类生命 = 60 + 最终体魄×6 + 基础体魄×2 + 最终敏捷×3 + 最终神魂×3 + 最终灵慧×1.5
妖兽生命 = 60 + 体魄×8 + 敏捷×3 + 神魂×3 + 灵慧×1.5
心境 = 30 + 最终神魂×4 + 最终灵慧×1.5 + 最终体魄×0.5
精准 = 灵慧×4 + 敏捷×3 + 神魂 + 体魄×0.5
身法 = 敏捷×4 + 神魂×2 + 灵慧 + 体魄×0.5
会心 = 体魄×0.5 + 敏捷×0.8 + 神魂×1.2 + 灵慧×0.3
护心 = 体魄×3 + 灵慧×2 + 敏捷×2 + 神魂×1.5
行动速度 = 80 + 体魄×0.5 + 灵慧×0.75 + 敏捷×1.5 + 神魂×0.75
```

派生属性不单独随机，也不接受精英或变种的直接数值加成。生成与结算顺序固定为：**基础四维随机 → 变种百分比修正 → 精英百分比修正 → 一次性重算全部派生属性 → 执行种族天赋的派生属性修正 → 计算卡牌公式**。妖兽不区分基础与最终体魄，生命公式中的两项体魄贡献合并为当前体魄 ×8。需要例外派生规则（如“厚皮按体魄增加物理防御”）时，直接写在该兽种的种族天赋中；它不是功法，也不占用卡牌。

### 四维随机规则

每个凡兽模板存储四项属性的最小值、均值与最大值，在**首次生成**时按截断正态分布抽取最终值，并保留一位小数：

```text
value = round_to_1_decimal(clamp(Normal(mean, σ), min, max))
σ = (max - min) / 4
```

例如灰背野猪的体魄为 `min=10 / mean=11 / max=12`，大部分个体会落在 11，10 与 12 都会出现，但罕见；四项属性独立抽取，不人为重掷或修正总和。四项全高本身就是极低概率的自然结果，可作为普通怪中的小惊喜，但不会拥有精英数值修正或额外卡牌。

- 招式配置与行动节奏为模板固定值；物理防御默认固定，只有“厚皮”等明确写有属性公式的种族天赋会随最终四维变化。
- 生成完成后，将四维、随机种子、精英标记、变种 ID 写入存档与战斗快照；读档、重进战斗不能重掷。
- 玩家详情页只展示最终数值，不展示范围；图鉴可展示“常见范围”。
- 变种与精英修正在四维抽取之后应用，顺序为：**基础随机 → 变种 → 精英基础属性修正 → 派生属性、种族天赋与卡牌重算**。

| ID | 凡兽 | 体/慧/敏/魂范围 | 生命范围 | 物理防御 | 出现与职责 |
|---|---|---:|---:|---:|---|
| `wild_boar` | 灰背野猪 | 10–12 / 1–3 / 4–6 / 1–3 | 170–194 | 3–4 | 后山、林地；厚血冲锋单体 |
| `forest_wolf` | 林地凶狼 | 4.2–6.3 / 1.6–2.8 / 8.1–10.7 / 2.4–3.9 | 128–158 | 0 | 林地；两只一组的群猎敌人 |
| `giant_toad` | 巨沼蟾蜍 | 9–11 / 3–5 / 3–5 / 3–5 | 158–182 | 2 | 水泽；中毒与拖回合 |
| `poison_snake` | 赤环毒蛇 | 5–7 / 4–6 / 11–13 / 3–5 | 110–134 | 0 | 草丛、洞穴；高闪避低血毒杀 |
| `rock_badger` | 岩背獾 | 8–10 / 2–4 / 6–8 / 2–4 | 146–170 | 5 | 石坡、矿洞；高物理防御的物理防守题 |
| `gray_fox` | 青尾狐 | 4–6 / 4–6 / 10–12 / 3–5 | 98–122 | 0 | 林缘；扰乱、退避、偷取战术位 |
| `demon_ape` | 山魈 | 12–14 / 3–5 / 6–8 / 4–6 | 194–218 | 4 | 稀有手工遭遇；凡兽区域的小首领 |

山魈保留现有 ID，属于**稀有凶兽**而非随机普通怪；只在首领节点、剧情或精英池的最高档出现。第一批的普通随机池只放野猪、狼、蟾蜍、毒蛇、獾、狐。

### 种族天赋与招式

每个凡兽种都拥有一项固定的**种族天赋**。它相当于妖兽的先天心法：不占技能槽、不随机、不因精英而改变；精英只会通过更高的最终属性放大其中的数值。变种可以额外加入专属机制，但不替换原有种族天赋。

种族天赋要满足三个约束：只描述一个明确战斗主题、优先使用百分比或属性公式、玩家能从兽种名称和首次行动读出效果。

| 凡兽 | 种族天赋（先天心法） | 基础技能 | 特征技能 | 设计目的 |
|---|---|---|---|---|
| 灰背野猪 | 厚皮：物理防御 = `round(体魄×0.30)` | 拱撞（伤害） | 拱身架招（物理应对、化解） | 教玩家识别防御与应对窗口 |
| 林地凶狼 | 群猎本能：主动攻击后，其他同阵营凶狼获得逐猎；每层物理伤害 +10%、行动速度 +5%，最多 3 层 | 撕咬 | 游身架招（物理应对、化解） | 教玩家优先击杀与拆群 |
| 巨沼蟾蜍 | 湿鳞：每次行动首次受到的物理伤害 -15% | 咬噬 | 毒舌（中毒 2 回合，每回合 4） | 教玩家处理持续伤害 |
| 赤环毒蛇 | 滑行：首回合行动速度 +15%，且首次蛇袭伤害 +15% | 蛇袭 | 返身（受击后获得 1 层闪避状态） | 教玩家备高精准/范围牌 |
| 岩背獾 | 裂岩劲：物理攻击无视目标 50% 物理防御 | 爪击 | 缩甲（获得护体，下一回合不能攻击） | 教玩家不能只靠物理防御硬抗 |
| 青尾狐 | 狡逃：生命低于 35% 时受到的最终伤害 -20%；自身回合开始时按行动速度判定撤退 | 扑咬 | 扬尘（目标精准 -25%，持续 1 回合） | 非杀尽型遭遇与轻控场 |
| 山魈 | 凶威：起手获得 1 层蓄势；每层蓄势使物理伤害 +10% | 拍击 | 擂胸（再获 2 层蓄势）→ 裂爪（消耗蓄势） | 首期首领的爆发窗口 |

凡兽普通技能伤害控制在 17–30，蓄势后爆发控制在 35–48；毒伤每次触发不高于 5、持续不超过 2 回合。山魈可例外到 55，但必须先出现蓄势状态，且玩家能用应对、护盾、控制或集火化解。

## 4. 非战斗生态单位

| 单位 | 行为 | 玩家互动 | 用途 |
|---|---|---|---|
| 黄角鹿 | 受惊逃离，不主动战斗 | 跟踪、狩猎、喂食 | 皮革、鹿角、引导探索路线 |
| 山野兔 | 逃跑并暴露附近资源 | 捕捉或放生 | 低风险肉食、教程生态反馈 |

它们不生成完整战斗技能配置。这样世界既有“可战斗的危险”，也有不该被视作经验包的普通生物。

## 5. 精英与变种：必须分开

精英与变种都让同种凡兽出现差异，但来源不同，不能混为“随机加一堆数值”。两者独立判定，**可以叠加**；首领由手工配置且不从随机表抽取。

| 类别 | 是什么 | 生成方式 | 能获得什么 | 掉落 |
|---|---|---|---|---|
| 普通 | 标准兽种模板 | 常规遭遇 | 固有被动 + 2 张牌 | 基础兽材 |
| 精英 | 更凶、更大的同类个体 | 独立精英判定 | 只提升四项基础属性；生命、物理防御与卡牌数值由重算获得 | 材料数量 ×1.5，追加精英材料 |
| 变种 | 受环境、食材或血脉影响的特定亚种 | 兽种专属模板，手工或低概率出现 | 改名、外观、专属被动 + 专属牌 | 专属材料与配方线索 |
| 精英变种 | 同时命中精英与变种 | 两套修正按固定顺序叠加 | 一套变种机制 + 一套精英大数值 | 精英材料 ×2 + 变种专属材料 |
| 首领 | 有领地、剧情或巢穴的命名个体 | 只在固定节点配置 | 完整专属循环，可有阶段变化 | 保底稀有掉落 |

### 5.1 通用精英数值修正

精英不再抽取行为词条。所有凡兽共用同一套精英修正只有：四项基础属性 **+25%**（向上取至一位小数）与掉落数量 **+50%**。生命、物理防御、行动速度、精准、闪避、会心、护心和属性缩放卡牌，都必须在基础属性变更后统一重算；精英绝不直接修改这些派生属性，也不增加技能、被动、牌组张数或行动数。

精英变种允许叠加一套变种机制与这套精英数值，但**卡牌种类封顶为 4、含重复的总卡牌数封顶为 9**，每回合行动数不增加。变种改变“怎么打”，精英只决定“同样打法有多强”。

### 5.2 兽种专属变种

变种不是单纯更强，而是种族天赋的一个**分支进化**：保留原天赋，再附加一项百分比属性修正、一项专属机制和一张专属或替换卡。它应改变解题方式。每次生成只会命中一个变种；每个兽种首期做 1–3 个变种，出现率合计为该兽种遭遇的 3–5%，教程和新手地图不生成变种。

| 原种 | 变种名称 | 被动变化 | 新卡牌 | 属性调整 | 专属掉落 |
|---|---|---|---|---|---|
| 灰背野猪 | 铁鬃野猪 | 铁鬃：厚皮系数 +100%（`0.30 → 0.60`） | 铁鬃反冲：受到物理伤害后下次冲撞伤害 +25% | 体魄 +10%，敏捷 -10% | 铁鬃、硬皮 |
| 林地凶狼 | 月痕狼 | 月痕：夜间围猎伤害加成 +50% | 月影扑杀：目标生命低于 40% 时伤害提高 | 敏捷 +10%，神魂 +10% | 月痕狼牙 |
| 巨沼蟾蜍 | 瘴囊蟾 | 毒雾：回合结束给全体敌方 1 层中毒，最多 2 层 | 鼓腹喷瘴：蓄势一回合后的群体中毒 | 灵慧 +15% | 瘴囊 |
| 赤环毒蛇 | 玉鳞蛇 | 玉鳞：首个负面状态持续时间 -1 回合 | 灵息吐纳：清除自身 1 个负面状态 | 灵慧 +10%，敏捷 -10% | 玉鳞、蛇胆 |
| 岩背獾 | 裂岩獾 | 裂岩：每两次攻击施加 1 层破甲 | 裂石扑击：无视目标 50% 物理防御 | 体魄 +10%，灵慧 -10% | 裂岩爪 |
| 青尾狐 | 迷踪狐 | 迷踪：狡逃的低血门槛提高至 45%，撤退判定成功率 +25%（上限 75%） | 狐火障眼：目标精准 -25% | 灵慧 +10%，神魂 +10% | 幻尾毛 |
| 山魈 | 负碑山魈 | 负碑：起手护体为最大生命 3% | 碎碑：消耗护体，造成范围震荡 | 体魄 +10%，敏捷 -10% | 乌碑骨 |

变种会在名称、立绘色调或角标上明确表现，例如“铁鬃”“玉鳞”“月痕”，不能只靠玩家点开详情才知道。这是为了让失败看起来是可学习的遭遇，而不是随机暗骰。

### 5.3 青尾狐“狡逃”撤退判定

青尾狐在生命低于 35% 后，不会立刻消失；它仍会承受伤害，并在自己的下一个回合开始时尝试撤退。撤退概率只比较它与存活敌方单位中最高的行动速度：

```text
撤退概率 = own_initiative_speed / (own_initiative_speed + highest_enemy_initiative_speed)
迷踪狐：撤退概率 × 1.25，最高 75%
```

| 狐 / 敌方最高行动速度 | 基础撤退概率 | 说明 |
|---|---:|---|
| 100 / 100 | 50% | 双方相当，狐狸有一半机会脱身 |
| 115 / 100 | 53.5% | 迅捷或增速后更容易撤离 |
| 90 / 120 | 42.9% | 被高速敌人压制，较难逃脱 |
| 120 / 80 | 60% | 明显跑得更快，但仍非必然 |

判定成功时，青尾狐从战场移除，不计为击杀；若它是最后一个敌方单位，战斗按“敌方撤离”结束，玩家获得已结算的探索收益但不获得该狐的击杀掉落。判定前被定身、眩晕或标记为“不可撤离”时，不能尝试撤退。UI 应在低血时显示“伺机脱逃”图标，并在行动条上预告本回合将进行撤退判定。

## 6. 出现概率与新手保护

| 区域 | 普通 | 精英 | 变种 | 精英变种 | 首领 |
|---|---:|---:|---:|---:|---|
| 序章、后山教程 | 100% | 0% | 0% | 0% | 固定剧情山魈（若需要） |
| 东林外层 | 87.3% | 9.7% | 2.7% | 0.3% | 固定巢穴节点 |
| 东林中层 | 80.75% | 14.25% | 4.25% | 0.75% | 固定领地节点 |

普通狼群最多 2 只；精英、变种、精英变种、山魈默认单体出现。新手地图不投放精英、变种或精英变种；非新手地图允许精英与变种叠加，并以“精英·铁鬃野猪”这类名称、金色边框和变种外观明确告知玩家。

## 7. 数据结构与实施顺序

建议新增 `BeastTemplate`（通用妖兽模板）和 `BeastModifier`（精英/变种修正）资源；`Beast` 只负责把它们转换为当前 `LivingData` 与战斗快照。凡兽、通智、妖府共用同一结构，差别只在模板的境界、资源与卡牌配置。

```text
BeastTemplate
  beast_id, display_name, habitat_tags, danger_rank
  physique_min/mean/max, intelligence_min/mean/max
  agility_min/mean/max, soul_min/mean/max, physical_defense
  passive_id, skill_paths, ai_profile, loot_table_id

BeastModifier
  modifier_id, modifier_kind (elite / variant)
  eligible_beast_ids, display_prefix, attribute_multiplier
  fixed_stat_bonus, extra_passive_id, extra_skill_path
  visual_variant, loot_bonus

BeastInstance
  spawn_seed, rolled_physique, rolled_intelligence
```

## 8. 验收标准

- 凡兽面板不出现灵根、境界、法力、功法、悟性、装备栏或突破条件。
- 玩家仅看名称、物理防御、四维与招式关键词，就能判断它是高物理防御、群攻、毒杀或闪避敌人。
- 精英与变种可以叠加，但每只单位最多各有一个；精英提供数值主轴，变种提供机制主轴。
- 同一兽种的变种改变战斗决策，而不是只增加 10% 生命；精英变种也不能突破 4 种牌、9 张总牌、每回合行动数与爆发上限。
- 云息前期两名角色能稳定处理一只普通凡兽；面对精英或变种时需要保留应对、控制或恢复资源。
