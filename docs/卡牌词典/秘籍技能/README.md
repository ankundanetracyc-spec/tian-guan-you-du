# 秘籍技能图稿

本目录保留按技能拆分的秘籍图稿。较早的五本开放秘籍图稿可能包含已撤回机制或旧数值；它们用于追溯，不作为当前人类招式盘的规则来源。

当前人类招式与化法以[招式盘词典](../招式盘/README.md)及其链接的现行主案为准：二十招中只保留七项机制化法，五本开放秘籍各保留1～2项；其余旧化法不进入卷章配置、来源选择或战斗结算。逐项撤回理由见[化法历史撤回目录](../招式盘/化法/历史撤回/README.md)。
