# 技能设计错题集

> 2026-10-26用户最新修订（现行）：游戏内可设置简略／详细；简略只显示结果，详细在结果后紧接括号公式，默认详细。策划案与draw.io固定采用详细版；通用结算说明仍由规则详解承载。本条覆盖此前“默认页不显示公式／只在独立页查看”的约定。

记录技能与秘籍图稿中出现过的错误，新增或修订前对照检查。

## 术语

- 固定触发位置按要求称“技能槽10”；仅可装配非应对技能，且其中的技能不允许排入“行动队列”。“技能库”的“技能槽”和“行动队列”中的“行动槽”各有既定含义，不得混用，也不要另造槽位名称。
- 伤害类型使用“物理伤害”或“神魂伤害”，不写“法术伤害”。
- 伤害类型按招式实际机制判断，不要把错误的“法术伤害”机械改成“神魂伤害”。《玄枢含章经》走物理攻击构筑，修持加成为物理伤害。
- 应对机制也要显示为关键词；展示标签与运行时规则字段分开维护。心法直接调用周天时，关键词写“周天”。关键词标注效果中实际涉及的具体机制或状态，不标法力等费用资源或“防御”等笼统方向；没有合适标签时写“无”。化法保留原技能关键词，也可为新增机制增加关键词。《玄枢含章经》中，惊蛰基础效果标“散血”，其化法另加“穿盾”；云帔基础技能标“护盾”，现由个人造诣图谱独立授予；玄枢第二卷保留其化法。架招标“化解、应对”，复命标“无”。
- 云帔基础技能消耗体力0、法力1，次数不限；法力费用足以限制使用。玄枢第二卷不再授予基础云帔，原化法仍适用；《惊蛰》消耗法力1；《复命》自身另消耗法力1，再支付被复制技能费用。

- 出手方式是招式风格分类，不是距离或射程：技能资源用 `attack_style = melee` 标记近身、`attack_style = ranged` 标记远程。不能根据接近、前冲或其他动画、位移表现或目标射程推断；该字段只用于明确的招式联动，伤害类型另行填写。

## 效果与公式

- 静态图稿的效果用 A、B 等字母标记动态数值，并在对应结果后紧接括号符号公式，例如“造成A点物理伤害（A=表达式）。”不得在静态公式中代入角色属性或附加样例结果。局内简略展示结果，详细在结果后紧接括号代入公式，不向玩家显示占位字母。 每次修改技能文案后，必须全量检查所有 drawio 与对应技能文字稿，清除属性代入值（如“属性[角色数值]”）和算式计算结果；公式常量与倍率保留。
- 静态图稿与秘籍技能统一写技能自身的基础公式，不在公式末尾追加通用物理伤害加成倍率，也不逐项另列通用增伤提示。技能或化法独有的倍率仍须写明。运行时按既有伤害规则结算，不把预估值冒充目标承受的最终伤害。结果取决于未来目标状态或来袭攻击时，写“本次结算后确定”并给出计算方式，不猜数字。
- 普通伤害、普通护盾等没有独有机制的招式，优先由公共造诣图谱授予；秘籍通过化法改写明确指定的公共技能，不为填满习得列表重复设计同类专属技能。专属技能须承担本书独有的状态、资源或结算机制。
- 固定数值不重复堆公式；同一技能中不同动态结果按首次出现顺序使用 A、B、C 等字母，完全相同的结果或公式重复出现时复用原字母。公式统一放在对应结果后的括号中。原效果与化法属于同一技能，沿用同一顺序；引用原效果数值时沿用原字母。不同技能重新从 A 开始。
- 技能公式须直接列出实际参与计算的基础属性及各自系数；原“身心协调值”项展开为 `min(体魄×a, 神魂×b)`，a、b 按技能效果分别设置，不在技能效果公式中使用“身心协调值”等复合属性。
- 公式中的结果字母必须先出现在对应效果里；不要只给公式而漏写结算结果。
- 同一技能的卷章化法默认累积；替代前卷效果时须明示。该技能的动态数值字母跨卷连续，不因拆分到不同卷而重置。
- 多项触发条件须分别判定；用户明确各条件分别算一次应对时，相关心法效果按次数分别结算，不得合并为一次。

## 文案

- 心法首卷及变化卷写完整版本；未变化卷仅写“心法被动：心法名（沿用第X卷，无新增效果）”，不重复心法字段。X引用最近一次完整版本：首卷完整、第三卷升级时，第二卷沿用第一卷，第四卷沿用第三卷。修持、化法或习得变化不算心法变化；运行时详情仍保留完整效果。
- 秘籍 drawio 排版严格复用现有秘籍图：顶部标题与总览、中央四卷主链、左侧心法与习得及修持、右侧化法；沿用对应框的配色、字号、尺寸和连线。未定内容标“待定”；文字超出时按规范扩框并顺移下方内容。
- 技能效果框只写该框需要说明的效果；卷章说明、作者旁注等不塞进技能框。
- 通用机制按通用规则描述，不点名无关的特定技能；技能名称已在字段标题出现时，正文无需重复点名。
- 《复命》自身另消耗法力1；仅复制最近施展的非应对技能，不复制应对技能。目标从被复制技能的合法目标中随机选择；复制时消耗原技能1次使用次数，并受其冷却限制。复命冷却2回合，且不作为后续复制对象。描述保持简洁，不重复展开公共规则。
- 《惊蛰》不经行动队列施展时，命中后打散目标1层气血；打散规则见[云息公共战斗状态与秘籍构筑规则](../plans/云息公共战斗状态与秘籍构筑规则.md#散血)。化法无条件使本次攻击无视目标护盾。不得追加被动重复攻击。
- 删除多余解释和重复规则。只保留理解与执行效果所需的信息；公共规则已明确的内容不在每个技能里重复铺陈。

## 修改后核对

- 检查术语、目标、触发条件、次数与冷却是否沿用现行规则。
- 检查静态图稿的动态结果使用有序字母，公式在效果末尾且不含角色属性代入值或样例结果；运行时显示具体结算值与代入公式；无法预知的结果明确标为待本次结算。
- 检查化法与原技能的目标、费用、次数和效果描述一致，不额外创造机制。
