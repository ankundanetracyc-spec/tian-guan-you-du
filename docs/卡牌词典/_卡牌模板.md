## 设计说明

动态数值写法：详细版主稿为不同结果按出现顺序使用 A、B 等字母；同一结果或完全相同公式重复出现时复用原字母。正文结束后集中列计算来源，逐项写“A = 算式”“B = 算式”，有名称则写“名称：A = 算式”，项间空一行。技能公式直接列出实际参与计算的基础属性和各自系数；原“身心协调值”项展开为 `min(体魄×a, 神魂×b)`，a、b 按技能效果分别设置，`max(...)`同样保留。运行时由共享格式化器代入当前角色；简略版只显示结算值，详细版末尾写“名称：最终结果 = 具体代入式”，无名称时不强加名称，不使用全角等号或逗号计算格式。效果、化法追加等长段字段标题后换行，消耗、目标、次数等短字段同行。悬停时无法确定的结果标为“本次结算后确定”，不向玩家显示 A、B 等占位符，也不代入虚构角色数值。

旧`sync_board_effects_20261108.py`的`inline`／`static_text`仍输出历史同行格式，后续新增或修订不得直接将该旧输出当作新版主图；使用前须先适配本规范。本轮不改脚本、验证器或历史卡图。
