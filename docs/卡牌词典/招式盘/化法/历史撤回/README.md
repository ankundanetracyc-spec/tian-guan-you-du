# 化法历史撤回

本目录保存从现行构筑撤下的14张化法旧图，仅供追溯，不参与章节配置、来源选择、招式解析或战斗结算。现行保留清单见[招式盘词典](../../README.md)，逐项审查记录见[人类招式心法全效果迁移](../../../../plans/战斗与构筑/人类招式心法全效果迁移_20261108.md)。

| 原来源 | 撤回项 | 审查结论 |
| --- | --- | --- |
| 玄枢含章经 | 云垂、折冲、照影 | 盾刷新、化解段序和复现限制未形成必要分支；一卷惊蛰周天破盾化法仍保留。 |
| 斫基损契玄经 | 秉烛、续照、长明 | 一卷折锋绕盾机制已改归玄枢的周天额外攻击；架招削盾和单招免闪未形成斫基资源路线所需的独立构筑。 |
| 百骸衍枝化生宝册 | 双擎、生枝 | 多段化解分配及手臂伤害段排序只改结算顺序；一卷分段催血、四卷显臂架招仍保留。 |
| 太和感物养元宝册 | 藏锋、返元 | 末段化解分配与条件追加段共用闪避判定均是通用防守边界，不足以形成太和构筑分支。 |
| 太和感物养元宝册 | 回澜 | 虚怀纳劲已改为主动预置护盾，延后应对护盾的机制不再适用；该化法与资源保留作历史记录，不进入当前卷章配置。 |
| 舒卷天章 | 云舒、回岚、天章 | 延后剑意获得或消耗只调整结算时点，未形成必要的剑意构筑机制；云岚三叠的追加判定延续保留。 |

撤回化法不等于撤回同卷心法强化。特别是舒卷的`shujuan_c2`与`shujuan_c4`仍作为心法升级生效；本目录只记录对应的旧化法图，不改变心法规则。
