# 卡牌词典

本目录收录战斗内主动技能和心法被动，不收世界实体卡。

## 一、收录范围

- ActiveSkillData 对应的技能卡
- 心法（主修或辅修槽位中的秘籍自动提供的战斗被动，不单独装配）
- 基础通用手牌
- 武器技能牌
- 符箓牌

不收：

- 角色、建筑、物品、事件实体
- 背包实体
- 地图掉落物

## 二、维护规则

技能文案与数值公式修订前，先对照[技能设计错题集](技能设计错题集.md)，避免术语、描述和公式格式反复出错。

战斗技能的动态效果统一按[技能动态数值展示规范](../plans/技能动态数值展示规范.md)：运行时先显示当前角色结算值及代入公式；静态图稿在效果中用 A、B 等字母标记数值，并在效果末尾列出符号公式，不代入属性示例值或计算结果。原“身心协调值”项在技能公式中展开为 `min(体魄×a, 神魂×b)`，a、b 按具体技能分别确定。运行时无法预知的结果标为本次结算确定，不向玩家显示占位字母。

2026-10-10 应对口径：实际应对才支付应对费用并结算原效果；未明确写出独立普通效果的，未触发时免费空放、无效果、不扣使用次数。双效果由可选 `non_response_skill` 独立配置普通目标、效果与费用，两分支不叠加付费。现有12份应对资源均按仅应对型迁移，含基础架招／卸力／避锋、承机及相关化法、三份妖兽架招；见[现行战斗总案第5节](../plans/即时队列战斗系统设计.md)。通用空放与支付规则集中在本案说明；秘籍图谱不逐框重复，仅注明技能特有差异。

- 每项主动技能或心法被动一个 .drawio
- 图是主稿，文字是补充
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)

## 三、图里优先写清楚的内容

- 卡名
- 类型
- 主动技能耗费（体力、法力；明确消耗灵识时另列）与灵识占用（仅持续法宝类）
- 目标
- 关键词（标注效果实际涉及的具体机制或状态；没有合适标签时写“无”）
- 状态效果
- 升级、替换、联动关系

主动技能主信息必须逐行书写：技能名、资源路径、类型、关键词、耗费、目标、效果；有限次数的技能同时注明每轮或每场使用次数，不限次时不必写次字段。凡出现使用次数字段，必须在效果之后独占一行，格式为“使用次数：每轮1次”或“使用次数：本场1次”；“使用次数：不限”若保留也独占一行。首次触发、每第二次受击等效果触发计数仍写在效果或触发条件中，不属于使用次数字段。关键词只标注效果中实际涉及、可用于检索的具体机制或状态；不把法力等费用资源或“防御”等笼统方向列为关键词，可标注“护盾”“化解”“周天”等具体机制；没有合适标签时写“无”，每项最多列三项。化法版本保留原关键词，可为其新增的具体机制增加关键词。牌面关键词由 ActiveSkillData.tags 提供；应对根据 ActiveSkillData.keywords 自动补入展示列表；详情面板显示已登记关键词的说明。引擎规则字段 keywords 保持不变，不得混入其他构筑关键词。限次、乘势等机制继续写在效果、触发条件或机制字段中；应对机制由运行时规则字段判定，同时显示为可检索关键词。即时战斗不列准备或收招时间；配置回合冷却时，在效果后另列“冷却：N回合”，与独立的“使用次数”行分开。回合冷却与次数同时限制使用，不能混写在效果内。冷却N回合（N > 0）表示使用当回合不可再用，随后跳过N个完整回合；第R回合使用，第R+N+1回合恢复。0表示不设冷却。费用列明实际使用的体力与法力；仅在技能明确消耗灵识时列出灵识费用。法宝等持续实体另列灵识占用，普通技能不写灵识占用 0。心法由主修或辅修秘籍自动提供，不单独学习或装配，也不设心法槽位；心法可列与主动技能相同的构筑关键词，但不写费用、目标或独立生效方式。战斗开始时，当前主修与辅修秘籍的心法被动作为常驻 Buff 显示在 Buff 栏，持续至战斗结束；淬炼只修正战斗属性，并列入对应心法 Buff 的信息详情。展示文案不使用引号或反引号。

关键词直接使用实际涉及的具体机制或状态名，例如护盾、化解、应对、周天、散血、穿盾；不使用法力等费用资源或“防御”等笼统方向。关键词只用于检索，不产生额外规则；化法版本保留原关键词，并可增加本次化法引入的具体机制关键词；没有合适标签时写“无”。

效果文案中的百科术语与状态名使用下划线提示可查词条；下划线只表示可在修行百科检索，不增加效果。通用术语解释集中写入百科，技能正文只保留该技能的触发条件、层数和专属变化；百科尚无词条的术语不得先标下划线。

心法版本固定写法：首卷完整书写；心法效果、主修额外效果或关键词有变化的卷章，完整写该卷“效果”和“主修额外效果”。未变化卷仅写“心法被动：心法名（沿用第X卷，无新增效果）”，X引用最近一次完整版本，不重复心法字段。沿用行之后空一行，再写本卷习得及技能正文；修持、化法或习得变化不算心法变化。运行时与游戏内详情仍读取当前已学的完整版本。
