## 二、维护规则

人类招式盘的化法按[当前实施案](../plans/战斗与构筑/人类招式盘实施与验收_20261107.md)摆放，只强化实际相邻指向的一份；基础技能保持完整说明，不因学会化法而替换整个技能库。现有生灵固定盘位见[生灵固定招式盘](妖兽/生灵固定招式盘_20261111.md)；生灵技能效果和种族天赋仍以各自资源及主案为准。

## 三、图里优先写清楚的内容

- 卡名
- 主动技能耗费（体力、法力；明确消耗灵识时另列）与灵识占用（仅持续法宝类）
- 目标
- 出手方式（直接造成攻击伤害的技能必填：近身或远程；不表示射程或空间距离）
- 关键词（标注效果实际涉及的具体机制或状态；没有合适标签时写“无”）
- 状态效果
- 升级、替换、联动关系

主动技能主信息必须逐行书写：技能名、资源路径、关键词、耗费、目标、效果；直接造成攻击伤害的技能在目标行后另列“出手方式：近身”或“出手方式：远程”。有限次数的技能同时注明每轮或每场使用次数，不限次时不必写次字段。凡出现使用次数字段，必须在效果之后独占一行，格式为“使用次数：每轮1次”或“使用次数：本场1次”；“使用次数：不限”若保留也独占一行。首次触发、每第二次受击等效果触发计数仍写在效果或触发条件中，不属于使用次数字段。构筑关键词标注效果中实际涉及、可用于检索的具体机制或状态；不把法力等费用资源或“防御”等笼统方向列为关键词，可标注“护盾”“化解”“周天”等具体机制；没有合适标签时写“无”，目前暂不限制每项关键词数量。化法版本保留原关键词，可为其新增的具体机制增加关键词。牌面构筑关键词由 ActiveSkillData.tags 提供；应对根据 ActiveSkillData.keywords 自动补入展示列表；详情面板显示已登记关键词的说明。引擎规则字段 keywords 保持不变，不得混入其他构筑关键词。限次、乘势等机制继续写在效果、触发条件或机制字段中；应对机制由运行时规则字段判定，同时显示为可检索关键词。描述可乘之机的应对关键词标注在被针对技能／行动自身（例如“破绽”），应对技能须明确写出匹配哪些关键词；此为规则关键词而非普通检索标签，具体字段待运行时接入时确定，现有资源不改。即时战斗不列准备或收招时间；配置回合冷却时，在效果后另列“冷却：N回合”，与独立的“使用次数”行分开。回合冷却与次数同时限制使用，不能混写在效果内。冷却N回合（N > 0）表示使用当回合不可再用，随后跳过N个完整回合；第R回合使用，第R+N+1回合恢复。0表示不设冷却。费用列明实际使用的体力与法力；仅在技能明确消耗灵识时列出灵识费用。法宝等持续实体另列灵识占用，普通技能不写灵识占用 0。心法由主修或辅修秘籍自动提供，不单独学习或装配，也不设心法槽位；心法可列与主动技能相同的构筑关键词，但不写费用、目标或独立生效方式。战斗开始时，当前主修与辅修秘籍的心法被动作为常驻 Buff 显示在 Buff 栏，持续至战斗结束；淬炼只修正战斗属性，并列入对应心法 Buff 的信息详情。展示文案不使用引号或反引号。

构筑关键词直接使用实际涉及的具体机制或状态名，例如护盾、化解、应对、周天、散血、穿盾；不使用法力等费用资源或“防御”等笼统方向。普通构筑关键词只用于检索，不产生额外规则；化法版本保留原关键词，并可增加本次化法引入的具体机制关键词；没有合适标签时写“无”。目前暂不限制每项关键词数量。剑修基础招式统一增加“剑”作为武器类别检索标签，仅供展示与检索，不产生额外规则。描述技能破绽的应对关键词按上文说明，由应对技能明确匹配，不能与普通检索标签混为一谈。

效果文案中的百科术语与状态名在游戏内不使用下划线提示；通用术语解释集中写入百科，技能正文只保留该技能的触发条件、层数和专属变化。词典中的术语标记如有保留，只用于编辑查阅，不应转换为游戏内的视觉下划线。
