# 卡牌词典

本目录收录战斗内主动技能和心法被动，不收世界实体卡。

## 一、收录范围

- ActiveSkillData 对应的技能卡
- 心法（主修或辅修槽位中的秘籍自动提供的战斗被动，不单独装配）
- 基础通用手牌
- 武器技能牌
- 符箓牌

不收：

- 角色、建筑、物品、事件实体
- 背包实体
- 地图掉落物

## 二、维护规则

- 每项主动技能或心法被动一个 .drawio
- 图是主稿，文字是补充
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)

## 三、图里优先写清楚的内容

- 卡名
- 类型
- 主动技能耗费（精力、法力；明确消耗灵识时另列）与灵识占用（仅持续法宝类）
- 目标
- 关键词（七本锻躯秘籍使用构筑关键词）
- 状态效果
- 升级、替换、联动关系

主动技能主信息必须逐行书写：技能名、资源路径、类型、关键词、耗费、目标、效果；有限次数的技能同时注明每轮或每场使用次数，不限次时不必写次字段。七本锻躯秘籍以关键词呈现可检索的构筑方向，不再标注锻躯路径归属。关键词只对应效果中直接涉及的既有资源、状态或属性，是非机制性的分类信息；每项最多列三项，不因关键词相同而产生额外规则。牌面展示值复用 ActiveSkillData.tags 字段；引擎规则字段 keywords 保持不变，不得混入构筑关键词。应对、限次、乘势等战斗机制继续写在效果、触发条件或机制字段中，不占关键词栏。即时战斗不列准备、收招或冷却时间。费用列明实际使用的精力与法力；仅在技能明确消耗灵识时列出灵识费用。法宝等持续实体另列灵识占用，普通技能不写灵识占用 0。心法由主修或辅修秘籍自动提供，不单独学习或装配，也不设心法槽位；心法可列与主动技能相同的构筑关键词，但不写费用、目标或独立生效方式。战斗开始时，当前主修与辅修秘籍的心法被动作为常驻 Buff 显示在 Buff 栏，持续至战斗结束；淬炼只修正战斗属性，并列入对应心法 Buff 的信息详情。展示文案不使用引号或反引号。

七本锻躯秘籍共用八个可跨秘籍复用的构筑方向——生命、闪避、回复、精力、增伤、伤势、防御、攻防联动。专属状态仍用实际机制名写在效果中，例如游骸和身法归入闪避方向，血炉归入增伤方向，化解归入防御方向，借力归入攻防联动方向。构筑方向仅用于阅读、检索和构筑提示，不是引擎关键词或触发器。
