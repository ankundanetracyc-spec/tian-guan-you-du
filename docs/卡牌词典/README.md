# 卡牌词典

本目录收录战斗内主动技能和心法被动，不收世界实体卡。

## 一、收录范围

- ActiveSkillData 对应的技能卡
- 心法（主修或辅修槽位中的秘籍自动提供的战斗被动，不单独装配）
- 基础通用手牌
- 武器技能牌
- 符箓牌

不收：

- 角色、建筑、物品、事件实体
- 背包实体
- 地图掉落物

## 二、维护规则

2026-10-10 应对口径：实际应对才支付应对费用并结算原效果；未明确写出独立普通效果的，未触发时免费空放、无效果、不扣使用次数。双效果由可选 `non_response_skill` 独立配置普通目标、效果与费用，两分支不叠加付费。现有12份应对资源均按仅应对型迁移，含基础架招／卸力／避锋、承机及相关化法、三份妖兽架招；见[现行战斗总案第5节](../plans/即时队列战斗系统设计.md)。通用空放与支付规则集中在本案说明；秘籍图谱不逐框重复，仅注明技能特有差异。

- 每项主动技能或心法被动一个 .drawio
- 图是主稿，文字是补充
- 通用流程看 [词典工作流](E:\stacklands\docs\词典工作流.md)

## 三、图里优先写清楚的内容

- 卡名
- 类型
- 主动技能耗费（体力、法力；明确消耗灵识时另列）与灵识占用（仅持续法宝类）
- 目标
- 关键词（现行云息秘籍使用通用构筑关键词）
- 状态效果
- 升级、替换、联动关系

主动技能主信息必须逐行书写：技能名、资源路径、类型、关键词、耗费、目标、效果；有限次数的技能同时注明每轮或每场使用次数，不限次时不必写次字段。凡出现使用次数字段，必须在效果之后独占一行，格式为“使用次数：每轮1次”或“使用次数：本场1次”；“使用次数：不限”若保留也独占一行。首次触发、每第二次受击等效果触发计数仍写在效果或触发条件中，不属于使用次数字段。现行秘籍以关键词呈现可检索的构筑方向；关键词只对应效果中直接涉及的既有资源、状态或属性，是非机制性的分类信息；每项最多列三项，不因关键词相同而产生额外规则。牌面展示值复用 ActiveSkillData.tags 字段；引擎规则字段 keywords 保持不变，不得混入构筑关键词。应对、限次、乘势等战斗机制继续写在效果、触发条件或机制字段中，不占关键词栏。即时战斗不列准备或收招时间；配置回合冷却时，在效果后另列“回合冷却：N回合”，与独立的“使用次数”行分开。回合冷却与次数同时限制使用，不能混写在效果内。冷却N回合（N > 0）表示使用当回合不可再用，随后跳过N个完整回合；第R回合使用，第R+N+1回合恢复。0表示不设冷却。费用列明实际使用的体力与法力；仅在技能明确消耗灵识时列出灵识费用。法宝等持续实体另列灵识占用，普通技能不写灵识占用 0。心法由主修或辅修秘籍自动提供，不单独学习或装配，也不设心法槽位；心法可列与主动技能相同的构筑关键词，但不写费用、目标或独立生效方式。战斗开始时，当前主修与辅修秘籍的心法被动作为常驻 Buff 显示在 Buff 栏，持续至战斗结束；淬炼只修正战斗属性，并列入对应心法 Buff 的信息详情。展示文案不使用引号或反引号。

七本现行秘籍共用八个可跨秘籍复用的构筑方向——生命、闪避、回复、体力、增伤、伤势、防御、攻防联动。公共状态仍用实际机制名写在效果中，例如游骸和身法归入闪避方向，血炉归入增伤方向，化解归入防御方向，借力归入攻防联动方向。构筑方向仅用于阅读、检索和构筑提示，不是引擎关键词或触发器。

心法的主修额外追加在学会第一篇并作为主修时生效；后续篇章追加是对主辅修都有效的心法强化，不得把主修核心机制延后解锁。技能调用公共气血回落只写“触发气血层数降低时的回复效果”，不重复写固定回复率。

心法成长统一按卷章展示完整版本：首卷只写初始心法；有变化的后续卷章分别写完整“效果”和“主修额外效果”，不使用“第二卷追加”等差量描述。主修基础效果由首卷主修直接提供，后续可在指定卷章强化；主修效果与通用心法效果的升级分布可以不同。未变化的卷章沿用上一版本。
