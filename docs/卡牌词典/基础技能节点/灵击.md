# 灵击

来源：造诣图谱·纳炁面·灵息成击

节点ID：spirit_strike_root

参悟条件：灵慧≥8；术法造诣≥6。无前置节点，参悟不收取资源，学会后由玩家手动装配。

资源路径：res://resources/activeskills/灵击.tres

关键词：无

耗费：体力2、法力0

目标：指定1名敌方

出手方式：远程

效果：造成A点物理伤害。

计算公式：A=round(4 + 灵慧×0.50 + 术法造诣×0.20)。
