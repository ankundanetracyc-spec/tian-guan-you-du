# 云帔*3

参悟条件：灵慧≥8、术法造诣≥6，无前置，无额外参悟费用。学会后自行配入招式盘。

关键词：护盾

耗费：体力0、法力1

占格：2×1

目标：自身

效果：自身获得A点（A=round(6+灵慧×0.20+神魂×0.20+术法造诣×0.25)）护盾。
