# 人物技能节点卡

本目录收录由角色“造诣图谱”独立授予的技能卡。它们进入对应人物的技能库并由玩家手动装配，不计入所有角色共用的公共基础技能池。

- [催血](催血.drawio)：催血根脉；体魄与体道造诣达标后参悟。
- [聚炁](聚炁.drawio)：炁根脉；灵慧与术法造诣达标后参悟。
- [灵击](灵击.drawio)：纳炁面“灵息成击”独立节点；灵慧与术法造诣驱动的远程物理冲击。
- [云帔](云帔.drawio)：由个人造诣图谱独立授予；保留体力0、法力1、次数不限，节点ID、前置、门槛与位置待定。玄枢含章经第二卷不再授予，但保留云帔化法；运行时迁移尚未接入。
- [寄念](寄念.drawio)：念根脉；神魂与术法造诣达标后参悟。
- [斩剑](斩剑.drawio)：剑式初传节点统一授予的四招之一。
- [养锋](养锋.drawio)：剑式初传节点统一授予的四招之一；积累剑意。
- [格剑](格剑.drawio)：剑式初传节点统一授予的四招之一；应对物理来袭并积累剑意。
- [尽锋](尽锋.drawio)：剑式初传节点统一授予的四招之一；命中消耗剑意强化物理伤害。

剑式初传的四招均包含构筑关键词“剑”，仅供展示与检索，不改变战斗规则。格剑的关键词为“剑、化解、剑意、应对”；关键词数量暂不设上限。

现行门槛、运行时效果和存档边界见[造诣图谱与首批技能节点实施](../../plans/公共技能节点网与首批节点实施.md)。节点墨印是界面识别素材；本目录卡图仍按技能资源表达，不增加额外效果、关键词或费用。
