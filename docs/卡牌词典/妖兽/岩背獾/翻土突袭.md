# 翻土突袭

- 资源路径：res://resources/activeskills/妖兽/岩背獾/翻土突袭.tres
- 来源：岩背獾试玩技能库。
- 费用：1体力、0法力；无灵识占用。
- 目标：指定1名合法敌方。
- 出手方式：近身。
- 伤害类型：物理。
- 关键词：无。
- 效果：对指定1名敌方造成A点物理伤害。A = round(12 + 体魄 + 神魂×0.5)。
- 状态与附加效果：无。
- 使用限制：无额外次数或回合冷却；固定盘中摆一份，占2×1格且不旋转。
