# 狈啸

- 资源路径：`res://resources/activeskills/妖兽/林地妖狈/狈啸.tres`
- 来源：林地妖狈技能库。
- 费用：1体力，0法力；无灵识占用。
- 目标：指定1名敌方。
- 出手方式：远程。
- 伤害类型：神魂。
- 关键词：无。
- 效果：对指定1名敌方造成A点神魂伤害。A=round(4＋灵慧×0.6＋神魂×0.8)。
- 状态：无。
- 使用限制：无额外次数或回合冷却，仍需正常行动槽和足额体力。
- 表现：固定待机切抬爪短啸图；灰紫声纹指向目标，接触短停，随后回待机。头身朝左，整体镜像朝向对手。
