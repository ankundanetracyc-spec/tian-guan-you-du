# 唤猎

- 资源路径：`res://resources/activeskills/妖兽/林地妖狈/唤猎.tres`
- 来源：林地妖狈技能库。
- 费用：1体力，0法力；无灵识占用。
- 目标：全体存活的友方林地凶狼，包含同物种变种；无需点选单体。
- 关键词：逐猎。
- 效果：上述每只狼各获得1层逐猎，最多3层；不作用于狈、敌方狼或其他兽种。
- 使用限制：无额外次数或回合冷却，仍需正常行动槽和足额体力。满层没有实际增量；AI没有可受益狼时不优先选择。
- 联动：狈首只在狼触发群猎时补给该狼自身；唤猎本身不造成攻击，不额外触发群猎或狈首，不生成额外行动。
- 表现：抬爪短啸，灰青声纹与实际获得逐猎的友狼反馈；不增加中间姿态图。
