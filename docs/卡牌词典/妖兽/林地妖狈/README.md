两招均不消耗法力、不占用灵识，无额外次数或回合冷却；占正常行动槽，不返费、不抽牌、不提供额外行动。狈啸的神魂伤害走原有神魂对抗与实际伤害结算，不附加新状态。

狈首属于物种固有天赋，不是秘籍心法或可装配技能卡：狈存活时，同阵营狼触发群猎，也给发起者自身1层逐猎；多狈不叠加，狈离场停止后续补给，已有层数沿用现行持续规则。天赋不占技能槽，具体见主案与种族天赋资源。
