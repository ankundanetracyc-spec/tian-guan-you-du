# 裂风扑击

- 资源路径：res://resources/activeskills/妖兽/赤鬃狼/裂风扑击.tres
- 来源：赤鬃狼试玩技能库。
- 费用：1体力、0法力；无灵识占用。
- 目标：指定1名合法敌方。
- 出手方式：近身。
- 伤害类型：物理。
- 关键词：无。
- 效果：对指定1名敌方造成A点物理伤害。A = round(9 + 体魄×1.5)。
- 状态与附加效果：无。
- 使用限制：无额外次数或回合冷却；固定盘中摆一份，占2×1格且不旋转。
