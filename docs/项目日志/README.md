# 项目日志

本目录按日期保存项目日常记录，每日一份：`YYYY-MM-DD.md`。每日记录概述当天可核实的项目进展、验证结果和待续事项；完整规则与系统状态仍以 `docs/plans/` 中的现行主案及各专题文档为准。

## 记录约定

- 只记录当天有证据支持的变化。参考当天文件改动、代码差异、提交记录和带日期的项目文档；未提交内容没有明确时间依据时，不把它写成当天完成。
- 写清哪些内容已实现、哪些仅有方案，验证是否实际运行，以及尚未完成或待确认的事项。
- 不从代码表现推定策划结论，不补造规则、数值或用户决定；出现文档冲突时，按 `AGENTS.md` 的权威顺序记录并指出冲突。
- 当天没有可核实的新进展时，也创建当天文件，简要说明未发现可确认的新变化，并列出仍在推进的事项（如能从现行记录确认）。
- 日志只作每日摘要，不取代 `docs/README.md`、策划案摘要或专题主文档。

## 每日记录

由日期文件组成，例如 `2026-10-15.md`。
