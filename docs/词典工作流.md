# 词典工作流

词典相关只看这一份，别在几个 README 里来回找同样的话。

## 一、统一规则

- `draw.io` 是主描述格式。
- `.md` 是辅助说明稿。
- 你改图，我负责同步资源或整理文字。

## 二、你负责什么

1. 在对应词典目录新建或修改 `.drawio`。
2. 把关系、条件、数值备注画清楚。
3. 直接告诉我“按这张图生成资源”或“按这张图同步现有资源”。

## 三、我负责什么

- 读取图结构
- 生成或修改 `.tres`
- 补齐引用关系
- 整理描述文案
- 检查命名、路径、字段是否和现有系统一致

## 四、图怎么画

统一只建议三种元素：

- 矩形：实体
- 箭头：关系
- 注释框：数值、条件、说明

## 五、秘籍图最少要表达的内容

- 秘籍总览
- 卷章顺序
- 每卷带来的纳气、化法、习得、状态或改写

## 六、卡牌图最少要表达的内容

- 卡牌本体
- 来源或前置
- 升级或替换
- 状态、关键词、触发条件

## 七、默认同步规则

- 同名框默认对应同名资源。
- 标注“新牌”默认新建资源。
- 标注“替换”默认写入技能库改写关系。
- 图中文字若已能直接当描述，我只做润色，不改原意。
