## 文档使用与维护

1. 快速摘要 → 分类入口 → 主案及所属词典，跨系统内容沿链接补读。不要只读某一份旧摘要或代码。
2. 主题只保留一个明确的主入口；新修订在原案或专题中维护，分类入口说明必要的覆盖关系。
3. 正式策划写入 `docs/plans/` 的对应分类；词典、美术证据、原型与工作日志保持各自用途。
4. 规则冲突且没有明确覆盖关系时先请求确认，不自行拼规则或猜数值；归类不改变原案批准状态。
5. 新增、移动或删除文档后更新分类入口，执行 `python tools/design_docs.py --refresh --check`，避免漏收录和失效链接。
