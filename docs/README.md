## 三、当前合并规则

### 1. 战斗系统

- `即时队列战斗系统设计.md` 是即时战斗现行主案，规定分段规划、每名角色 5–10 项独立行动队列、角色统一速度与轮次资源。玩家只手动规划主控角色，队友与敌人由 AI 各自规划；AI 按威胁、预计时序、资源和队伍协同规划整段行动，队友参考玩家锁定队列，敌人不读取玩家私有队列或未揭示情报。主案还规定顶部姓名时序总览、行动阶段固定显示玩家队列、技能悬浮详情与公式展示、应对、敌方意图和无距离规则；修行小游戏继续独立于即时战斗循环。
- `design-plan.md` 保留三资源身份、费用档位与灵识容量；即时战斗体力每轮补给，法力在战斗开始时初始化并跨轮保留，不自动回复或清零；战斗没有通用吐纳行动，只有明确写出的技能或效果可恢复法力。补给节奏、费用支付与行动队列以即时战斗主案为准。其战斗手牌、抽弃牌和旧自动应对条目不适用于即时战斗。
- 【炁】与周天、技能附着【念】、敌方破绽【心隙】均是可由不同秘籍明确调用的公共战斗接口。完整规则见[云息公共战斗状态与秘籍构筑规则](plans/云息公共战斗状态与秘籍构筑规则.md)；新秘籍图稿仍按各自标记审阅状态，未接入运行时的内容不得写成已实装。
- 具体子系统单独放在对应专题文档，不再把实现细节写回总案。

- 解锁与替换流程统一看 `基础牌库词典/drawio/基础牌库总览.drawio`。
