## 三、当前合并规则

### 1. 战斗系统

- `即时队列战斗系统设计.md` 是即时战斗现行主案，规定分段规划、每名角色 5–10 项独立行动队列、角色统一速度与轮次资源。玩家只手动规划主控角色，队友与敌人由 AI 各自规划；AI 按威胁、预计时序、资源和队伍协同规划整段行动，队友参考玩家锁定队列，敌人不读取玩家私有队列或未揭示情报。主案还规定顶部姓名时序总览、行动阶段固定显示玩家队列、应对、敌方意图与无距离规则；修行小游戏继续独立于即时战斗循环。
- `design-plan.md` 保留三资源身份、费用档位、灵识容量与流派职责；即时战斗每轮补给、费用支付与行动队列以即时战斗主案为准。其战斗手牌、抽弃牌和旧自动应对条目不适用于即时战斗。
- 具体子系统单独放在对应专题文档，不再把实现细节写回总案。

### 2. 基础技能库

- 当前只保留凡俗通用、体修、行炁三套基础技能库。
- 解锁与替换流程统一看 `基础牌库词典/drawio/基础牌库总览.drawio`。
- 修行长期养成按修命／修性组织，细案见[性命双修养成重构提案](plans/性命双修养成重构提案.md)；蕴神观想文档只记录三景的旧运行时表现，五行参悟文档保留已有进度与迁移线索。

### 3. 词典流程

- `词典工作流.md` 是统一入口。
- 各词典 `README` 只说明本目录收什么，不再重复整套流程。

### 4. 当前个人修仙模式

- `plans/当前项目_个人修仙改造路线.md` 是当前项目的主入口。
- `plans/单人版剧情与任务流程设计.md` 是现行剧情与任务流总设计：四阶段主线 + 序章任务链，与路线文档互为上下层。
- `plans/单人版序章_静室灯火_策划案.md` 是现行序章（出村前）唯一细案；`plans/单人版序章_静室灯火.md` 仅保留概览与历史素材。剧情与任务流采用单主角、主动时间推进，修炼地点限定李宅内。
- `plans/大陆格局与百川区域设计.md` 是现行世界空间与首期内容范围：世界只按若干大陆组织远行，大陆内部使用区域、势力辖域和地点；当前完整制作区域为百川。玩家可保持散修，也可依组织规则成为家族客卿、宗门弟子或仙国成员。
- `plans/百川区域仙盟大势力与天人议盟规划.md` 是百川区域四个一级势力和首期十二个二级固定辖域的现行专题（后续可扩展至每个一级四个）；仙盟只负责对外防卫，天人由原势力神胎突破而来，魔道也可在履行共同防卫义务的前提下入盟。
- `plans/云阙州_首期势力与归属规划.md` 是早期云阙方案的迁移资料，不覆盖现行百川方案；当前势力态度仍使用七阶声望，正式身份是否可兼任由各势力门规决定。
- `plans/云阙州_地点旅行与NPC月度演算规划.md` 文件名保留路径兼容，但内容按百川区域地点、旅行与 NPC 月度演算执行。
- 青溪里是天道衍化的序章接引之地；李守拙为天道化身之一，其余村民皆为幻象。离村后不作为可返回据点或后续关系网络。
