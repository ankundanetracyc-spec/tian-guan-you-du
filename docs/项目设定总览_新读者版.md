## 一句话认识这个项目

项目从 Stacklands 式经营方向收束为**单主角个人修仙**：玩家围绕修行成长、旅行探索、人物交往、战斗和制作建立个人修行循环。项目最终目标是**完成开天**。

玩家经营的是自己的修行与行旅，不是家族、辖地或多角色派遣。加入宗门、家族或其他组织是可选发展方式；玩家也可以长期保持散修身份。

## 世界背景

### 五太、天道与飞升

**五太**不是五位神祇，而是上位世界规则在此界的投影。五太共同完成创界，各自指向世界从无到有、气、形、质与关系秩序的不同层面：

| 五太 | 根本意象 | 在世界中的体现 |
| --- | --- | --- |
| 太易 | 从无到有、未定与未显 | 世界由“无”转向“可有”的根本层 |
| 太初 | 气始 | 天地运行之气开始成立 |
| 太始 | 形始 | 事物的形态与结构开始成立 |
| 太素 | 质始 | 万物性质获得稳定区分 |
| 太极 | 关系与秩序 | 阴阳、五行及诸关系归于可持续运转的平衡 |

创界末期发生意外，上下界通道未能建立，五太投影相继沉睡。太极在沉睡前维持世界平衡，并分出**天道**代管此界。天道不是太极本身；它最初按规则维持平衡，后因既定背景中的意外产生私欲。天人果位原本应继续托举修士飞升；上下界链路缺失后，这一功能失效，天人因此滞留于此界。

### 六个纪元

| 纪元 | 时代主题 | 关键变化 |
| --- | --- | --- |
| 混沌纪 | 五太沉睡、神兽横行 | 天道首次发动清洗，史称天裂之变 |
| 荒古纪 | 荒古妖兽称雄、人族图腾崇拜 | 人族逐步摸索灵气修炼与愿力运用 |
| 人道纪 | 人族崛起、修炼体系成形 | 人皇整合修炼道路；留下的飞升之象被后世误认作成功飞升，实未抵达上界 |
| 垂天纪 | 仙庭与修仙文明鼎盛 | 天人研究飞升真相，引发道崩之劫与大清洗 |
| 烬余纪 | 灵气枯竭、传承断裂 | 修仙界长期混乱；涤瑕仙君终结乱世，此后不知所踪 |
| 昭明纪 | 当代、秩序重建 | 灵气回升；太易逐渐苏醒，天道维护秩序的方式反而加剧失衡 |

当前时代为昭明纪。背景设定还包括更广阔的历史、奇地与势力；当前首期并不要求玩家先游历全部世界。

游戏开局的精确纪年现定为昭明历 2371 年，等于入世第 1 年；时间栏可切换两种读数，详见[游戏历法与纪年显示](plans/游戏历法与纪年显示.md)（2026-10-11 用户授权设定）。

六纪的大方向作为世界背景使用；真灵类别与谱系、归纪之劫的完整因果、应龙在相关事件中的具体职责仍属【已讨论待定】，旧背景草稿不能代替后续确认。**【已确认】凤与凰是一对、不等同于九凤，并共同作为一个候选首领登场；具体双体战斗机制仍待审。**

### 修炼根基与力量来源

灵根是人族先天感应灵气的资质，不能靠后天修炼获得。五行是人族理解灵根属性的分类体系；灵根数量越少，感应通常越纯，但这不等同于“所有少灵根者都注定更强”。灵根也影响宗门收徒与社会机会。所有修行以灵力为根源；妖丹、香火、煞气等可作催化、承载、引导或污染因素，不另成一套平行的宇宙能量。

世界观设定三种力量路径：

- **清灵**：直接炼化天地灵力，未经外来意志或浊煞改质，是首期默认开放的源流。
- **愿力**：以神坛、神名和众生愿念为引，将灵力转为可调动的愿力；缺少信众或神坛时，增长与部分能力受限。
- **魔炁**：以煞气、怨念、血祭或心魔染化灵力；见效快，但会带来反噬、失控和社会敌对等代价。

这三种是世界观中的源流，不是可以随意互换的战斗资源。愿力与魔炁会改变资源循环、突破条件和社会关系；首期只有清灵默认开放，其他源流须由对应世界系统与改源事件承接。

【已确认】巫道是愿力的前身。现存[背景设定](lore/背景设定.txt)把这一源流追溯到荒古纪图腾时代：部落图腾汇聚集体心神，巫在特定仪式中触及法则碎片，愿力也散入部落集体记忆。巫道是否在当前玩法中作为独立修行道路，以及其传承、规则与阵法接口，仍属【已讨论待定】。

## 项目目标

项目以单主角的个人修行为核心，涵盖境界成长、地图行旅、探索、人物关系、战斗、制作与势力互动。最终目标是完成开天。

## 故事开场与主线

主线采用四阶段结构：**初醒青溪 → 行旅与积累 → 镜照与寻天 → 开天**。主角以单人修士身份从序章进入百川自由修行；不以家族经营或强制加入势力作为主循环。青溪里是天道衍化的临时接引之地，李守拙是天道化身之一，其余村民为幻象；序章不揭示青溪里的完整真相。序章 T0–T7 和第一阶段细节以[单人版序章策划案](plans/单人版序章_静室灯火_策划案.md)为准，后续阶段仍有未完成的剧情细节。

## 世界空间与百川势力

### 空间层级

现行世界结构为：

```text
大陆
└─ 区域
   └─ 势力辖域（一级势力 → 二级辖域）
      └─ 地点
```

大陆描述自然地理和远行方式；区域是内容制作与旅行单元；势力辖域表达政治归属；地点才是玩家抵达并执行行动的锚点。现行空间不设“州”这一层级，旧云阙州、九州方案只作迁移或历史资料。

长期世界暂按三块互不相连的大陆组织远行：北方冰雪大陆、百川所在大陆、东南海陆大陆。**百川是当前唯一完整制作和开放交互的区域**，其他大陆暂时只提供世界观背景与后续远行接口。

### 百川的组织格局

百川由四个实力接近、彼此制衡的一级势力统辖，每个首期设三个固定二级辖域：

| 一级势力 | 气质 | 首期二级辖域 |
| --- | --- | --- |
| 玉虚仙宗 | 重师承、传法和明文秩序的正统大宗 | 青岚观、白石城、东林镇妖会 |
| 太微道宫 | 传承完整，兼有道场、商路与隐修地 | 海川会、长风护道会、春水府 |
| 玄都天府 | 府院、家族、工坊和城镇组成的复合势力 | 关山府、赤炉堂、赤水城 |
| 无相圣宗 | 具有完整生产、交易和军力的魔道圣宗 | 幽泉教、夜行会、灰骨寺 |

仙盟是百川势力为应对区域外敌而组成的松散共同体，负责共同防线和战时议盟；它不是第五个一级势力，也不管理盟内日常事务。无相圣宗是否参与议盟按其是否履行对外防卫义务判断，不单凭“正道/魔道”标签决定。

背景设定还包括玉虚仙宗、北极仙宫、天机阁、天衡仙国、万妖谷、海族与鬼道等世界级势力。它们补充世界的远景和历史关系，不都属于百川首期可抵达内容。

## 玩家每一轮在做什么

```text
确定近期修行或探索目标
→ 准备功法、装备、补给和路线
→ 旅行、探索、交易、交谈或战斗
→ 带回资源、传闻、关系变化或法则线索
→ 在地点整理、休息、修行与构筑
→ 达成突破条件，选择更远目标
```

地点采用“先进入地点内景，再从场景标签进入功能或副本”的两层交互。城镇、山门、渡口、野外、遗迹和临时异象由静态数据、动态状态、地点模板和行动配置组合，不把所有功能都堆到大地图按钮上。

大世界时间由玩家主动行动推进；跨月时 NPC 按月份逐月演算。旅程有独立的大世界精力池，与战斗内体力分开。正式存档按旅程建槽，保存人物、时间、地图位置、战争迷雾、未完成路线和稳定 NPC 快照；读档不重新抽取 NPC，也不重复结算已处理月份。

## 世界地图与旅行

百川地图为固定的 200×200 方形逻辑格，共 40,000 格，每格代表 40 公里；所有存档共享同一地貌和地点布局。**当前地图基础格全部为普通陆地**，局部水景仅为装饰，不代表水域地形。地物可在编辑器中按模板、种子和密度生成，确认后保存为固定场景；游戏运行、开图和读档时不随机重排。

玩家逐格移动，点选目的地预览路线与预计时间，再次点击同一目的地确认起程；行旅揭开战争迷雾，也可能发现地点、事件或遭遇。地图用 WASD 逐格行走，右键拖动画布；滚轮、界面按钮或中键上下拖动缩放，并以视野中心为锚点。已规划的势力节点和具名地点可常驻识别，未发现地貌与动态事件仍受迷雾规则约束。地形旅行系数和遁速仍以地图专题为准。

地图交互借鉴《鬼谷八荒》的逐格行旅和探索揭雾；百川的地理与地点布局固定，只有编辑器生成地物并保存后才进入场景；不照搬其随机地图或专属路标、坐骑等系统。

## 人物、修行与成长

### 五大境界的递进

凡人阶段是正式修行前的状态，不计入五大境界。人族修士依次经历**云息、玄基、金丹、神胎、天人**。这条阶梯从感应与运用灵气，逐步走向承载灵力、承载太痕、理解法理，最后取得对一类天地规则的直接支配资格。

| 境界 | 核心变化 | 当前设定重点 |
| --- | --- | --- |
| 云息 | 感气、运气并建立灵力结构 | 十层；十层后养成归元九息，九息圆满后准备铸玄基 |
| 玄基 | 将前期修行转为稳定的道基与承载结构 | 具体承载与能力发展由个人修行、所学秘籍和实际构筑决定，不再划分固定战斗路径 |
| 金丹 | 灵力结构升为金丹，开始接触天地法则痕迹 | 真丹纹承载太痕，并形成具体本命神通 |
| 神胎 | 金丹中孕育神胎，神魂与法理理解进一步提升 | 保留金丹太痕，理解神通背后的共同法理，并满足求果的前置阶段 |
| 天人 | 占据唯一果位，获得相应性权 | 五太各辖四种权柄，共二十果位；飞升托举功能因上下界链路缺失而失效 |

#### 云息：十层与归元九息

云息当前规划为十层。六层至七层进入凝核阶段；三环完整后修至云息十层，再于十层内部养成归元九息。九息不是额外境界层数，九息圆满后才准备铸玄基；不再采用云息十一至十三层或十三层后积云的旧规则。

归元息按周行、牵引、平衡连续养成；中断只清除当前未成一息，已成归元息保留。九息时间和运行时实现以[现行十层归元九息方案](plans/云息十层归元九息修炼设计.md)为准。铸玄基正式玩法、门槛与消耗待重订。
#### 玄基：建立更高阶的承载

玄基承接云息圆满后的灵力结构，重点从“能否感知、运转和组织灵气”转向“以什么方式长期承载修为”。它与云息灵核是前后两个阶段，不能把凝核当作玄基突破。

- **修命**：所有修士都可淬炼皮、筋、骨、血、脏、心六部位；云息期的淬体炼度独立成长，不直接消耗灵力修为。
- **修性**：所有修士都可观修三景心相图；它与修命共同构成长期养成，不是战斗路径。
云息战斗中，所有角色使用公共基础技能池；已学秘籍提供技能、心法和化法，围绕公共状态与资源形成不同构筑。

各境界统一使用当前境界规则；秘籍主题不构成固定职业，也不限制角色修习其他秘籍或参与修命、修性养成。

#### 金丹：从术的效用走向法理

金丹阶段进入太痕与本命神通体系。五太创界后留在天地间的规则痕迹称为**太痕**或**五太之痕**；真丹纹承载太痕，由此形成金丹修士的本命神通。假丹纹不能承载真正神通，也不能转化为真丹纹。此时修士可以“得其用”，知道某种神通如何生效，但还未必理解它为何成立。

金丹阶段的神通属于“术”，不等于天人性权。修行经历与具体神通可以影响角色对法理的理解，境界和修行经历不限制神通资格。境界规划中的金丹劫属于背景设定；神通映射、具体消耗与成长刻度仍以专题案为准。

#### 神胎：由神通参悟共同法理

背景设定描述金丹内部孕育与修士神魂相连的灵胎；灵胎破丹而出后，可作为第二元神独立于肉身存在。确认稿进一步明确，金丹真丹纹所承太痕随神胎结构保留；神胎修士开始从多门神通之间理解其共同法理，连接“金丹得其用”与“天人执其权”。

神胎的法理理解会影响后续求果的契合与难度，但早期神通与修行选择不硬锁未来果位。神胎圆满并满足求果条件后，进入占果成为天人的阶段。神胎也称元婴；元婴阶段需面对雷、风、火三劫。现行资料只确认这三类劫难，具体先后、触发条件和结算流程仍待专题细化。

#### 天人：果位、性权与飞升失效

现行果位结构为**五太各辖四种权柄，共二十种权柄、二十个唯一果位**。每个果位同一时间只由一人占据。神胎圆满者满足求果条件并占果后，首先由神胎升为天人，取得该果位所辖规则的直接支配资格，称为**性权**。

##### 求果计算：读取什么、如何择位

求果计算以神胎圆满后的个人积累为依据，目标是从五太各自辖有的四种权柄中确定一项，再映射到该权柄的唯一果位。计算输入包括：

| 输入类别 | 读取信息 |
| --- | --- |
| 根性与命理 | 灵根、五行性材、阴阳、定干、天干合化、命辰 |
| 个人道途 | 本命相性、原有道途、主修功法 |
| 修行积累与时机 | 太痕积累、纪时 |
| 亲和与难度修正 | 神通经历可修正求果亲和或难度，但不构成绝对资格锁 |

```text
神胎圆满并满足求果条件
→ 读取个人根性、命理、道途、功法、太痕与纪时
→ 综合确定五太之一所辖的某项权柄
→ 映射到该权柄对应的唯一果位
→ 占果成为天人，获得对应性权
```

五行、定干和命辰是计算输入，不是果位标签；五行不与五太或权柄一一绑定，同一五行合化结果也可能因命辰、功法、太痕或纪时不同而指向不同权柄。现行确认稿尚未给出各输入的数值权重、评分公式和权柄映射算法，因此这里说明的是求果的读取范围与判定步骤，不代表已经确定可按数值复算的公式。

#### 太虚与钧纪：所见与所以然

高层结构按认知与规则深度分为**现世、太虚、钧纪、上界**。它们不是四张彼此平行的地图，而是同一世界由可见现象到根本规则的不同层次。可用一句话概括：**太虚是所见，钧纪是所以然。**

| 层级 | 性质 | 主要内容 |
| --- | --- | --- |
| 现世 | 物质与常规灵力活动层 | 肉身、地形、法器、术法表现与可直接观察的灵机现象。 |
| 太虚 | 神识可感知的高层现象层 | 灵力流向、魂魄痕迹、术法残痕、神识轨迹及部分高阶异象。 |
| 钧纪 | 太虚现象背后的规则结构层 | 果位映位、五太投影留下的规则结构与世界秩序的深层关联。 |
| 上界 | 本世界之上的规则源头与合法高位世界 | 五太投影的源头，以及原定的飞升接引、登籍任职秩序。 |

【已确认】“钧纪天”是“钧纪”的别称，不新增第五个世界层级。

神胎的认知进阶可概括为**见痕、通理、触纪**：先在太虚中观察真丹纹、神通与天地现象留下的太痕；再比较多门神通，理解它们背后的共同法理；神胎后期逐渐感知这些法理在钧纪中的归属、牵连与规则位置，为求果作准备。能够触及和理解钧纪，不等于可以任意改写规则；取得果位后，天人才能按所占权柄直接介入相应规则。

上界与钧纪层不同。此界与上界的连接自创界时便未完成，果位原本应有的托举飞升功能因此失效；钧纪描述的是本界深层规则结构，不是飞升后到达的另一张地图。

金丹、神胎阶段获得的本命神通会保留到天人阶段；神通是性权固定、成熟的用法，性权本身不另占普通技能槽。果位原本还应继续托举修士脱离此界、升往上界，但创界末的上下界连接并未完成，因此这一托举功能失效，天人会滞留于此界。

天人五衰是果位托举失效后针对位主发生的五重劫难，不是自然衰老、寿元耗尽或周期性掉属性。五衰可导致坠果、道毁，并为果位更替形成窗口；神胎修士可以围绕位主的五衰谋划目标果位。五衰的正式名称、各衰流程和天人阶段成长刻度尚未确认；二十果位与各神通的具体映射、性权边界及消耗也待专题设计。

### 修行源流、技艺与功法

修行中有三类互相配合的信息：

```text
源流：灵力的性质与取得方式（清灵 / 愿力 / 魔炁）
术统：技艺与派系传统（剑、拳、符、阵、丹、傀儡、身法等）
功法：具体秘籍及其卷章
战斗构筑：已学技能、自动生效的心法与公共状态的组合
```

剑、火等术统或派系标签表达技艺与构筑主题，不单独决定灵根、战斗资格或突破材料；同一术统可与不同秘籍和公共机制组合。

长期养成分为两轴：**修命**以锻体为主体，云息期沿皮、筋、骨、血、脏、心六部位淬炼，淬体炼度与灵力修为分开积累；**修性**以所有修士共用的三景心相图为主体，按“天象观变、地文察势、物华应物”组织。图景细案仍在整理，未定效果不补造数值。秘籍主题由具体技能与公共机制表达，不与性命双修的长期养成轴混为一谈。

秘籍、境界、突破、战斗技能库与修行活动各有专题。主修和辅修秘籍自动提供相应心法被动，不另设心法槽。

### 人物状态与关系

主角与 NPC 共用九项基础属性：体魄、灵慧、敏捷、神魂、福缘、悟性、魅力、交际、治事。人物状态彼此独立记录：

- **业力**：单一、可正可负的因果综合值；不是货币，也不等于声望。
- **心境**：当前待审提案以圆盘记录修士个人长期主导的心绪，首版圆周强烈形态为狂喜、渴求、焦灼、惊惧、悲恸、暴怒、怨恨、绝望。八风改作外缘诱因；同一得失或评价会因人物经历不同而牵动不同心绪。扇区按常见过渡关系相邻排列，不强制直径两端的情绪互为反面；圆心“无心绪”表示没有持续主导情绪、心境稳定，越靠圆心表示情绪越轻。这八种是游戏分类，不声称古籍定有一套固定八情。水墨色域与单一墨珠呈现状态；对心魔、修炼与事件的具体作用仍待审，详见[人物属性、因果与心境系统设计](plans/人物属性、因果与心境系统设计.md)。
- **区域声望**：当地公开事迹带来的认知度。
- **势力态度**：各势力分别记录的七阶关系，从仇视、敌视、不满、冷淡、友善、亲近到尊敬。
- **个人关系**：主角与某个 NPC 的私人交往。

这些字段不能自动合成一条“好感/善恶”数值。NPC 有稳定身份与人物快照，并按地点和月度规则参与世界演算。

妖兽生态另有境界与属性专题：首期以凡兽模板为基线，区分普通个体、精英修正与兽种变种；掉落、招式和数值必须按相应生态专题配置，不能从“妖兽”二字自行推演。四类生灵提案不附修士境界映射。

【已确认】人、妖、精、魔、鬼、异兽是正式生灵分类。各类与妖兽、真灵等既有概念之间的从属关系仍待细化。四类低阶生灵的 48 种术法与生态方案现以[《妖精魔鬼生灵设计汇总》](plans/妖精魔鬼生灵设计汇总.md)保存为【已讨论待定】提案；其中个体设定、状态效果、首领机制与遭遇尚待审阅，且不附修行境界。

## 战斗、卡牌与能力

即时战斗采用“**分段规划 → 独立读条 → 时序结算**”：

- 每名角色有独立队列和连续行动进度条；每轮容量为 5–10 个固定行动槽。队列并行推进，角色读条达到结算点时执行自己的队首行动。玩家只手动规划主控角色，队友和敌人由 AI 分别规划。
- 每个角色保留整轮完整槽位。未填行动的空槽也按角色行动速度完成一次等待读条；不付费、不回复资源、不产生技能效果，不能通过少排技能缩短队列。队友 AI 可参考玩家已锁定的队列协作，敌人不能读取玩家未公开的计划。
- 技能不设独立冷却、准备或收招；强力技能可限制每轮或每场使用次数。游戏没有即时战斗的抽牌堆、弃牌堆或手牌。
- 常规战斗配置为 **10 个普通技能槽、独立神通槽和物品栏**。即时战斗不使用距离格或射程系统；目标是否合法由技能目标规则和战斗状态决定。应对行动正常占队列、支付费用并受次数约束。
- 体力、法力与灵识各有不同职责，按轮次规则结算；具体补给、上限、费用、目标、次数和状态以[即时队列战斗主案](plans/即时队列战斗系统设计.md)及技能专题为准。

**铸玄基牌局是例外场景**：它保留自己的抽牌、打牌和结算循环，与即时战斗队列完全分开。云息六至七层的凝核已改为八回合时机小游戏，不使用牌组。

【历史版本已废弃】独立的“局外卡牌经营”构想已作废。现行局外技能库、秘籍研读、技能学习与装配仍有效；即时战斗技能槽和玄基入境独立牌局分别遵循各自现行规则。

阵法首期从基础组合逻辑开始：阵法录声明输入输出，阵道造诣解锁逻辑元件，阵盘、阵眼、阵源和灵络限制规模与负荷；阵脉传递控制信号，阵源提供能量。

## 物品、装备、生产与经济

物品系统用统一词缀表达五行、质地、功用、相性和品阶；材料、丹药、符箓、炼器与阵法共用素材和功用体系。玩家通过交易、探索、委托、采集与制作获得修行物资。

武器装备、法宝、丹药和生产设施各有独立规则。法宝长期设计强调器形、材性、内炼/外祭和铭文；当前首批实装规格收束在云息至玄基阶段的双剑。材料品阶与法宝品级不是同一套分级。炼丹、炼器、画符和后续阵法从“百工”入口逐步解锁。

灵石是基础流通货币，贡献则属于特定组织的事务/兑换账目；不同组织的声望、贡献、身份与灵石不应混为一个资源池。坊市、仓储、奖励结算和资源来源以物品资源总案为准。

玉虚仙宗是当前首期最具体的组织循环样板：观复峰按灵根决定入门身份，和光峰承接宗门事务与善功堂兑换，天问峰提供凶狼演法；接取演法公事并回传一场战斗结果，可核发 5 点测试贡献，不掉落物品，普通未接取演练不发贡献。首轮公事还包括静室研读、瑶圃值守、雾铃花培育、东林地巡查、兽骨和苦苔根交付、东林地冲突事实核验与上呈；相关奖励和门槛仍是可调测试值。

## 界面与呈现

主界面常驻入口围绕主角行动组织为**角色、修炼、行囊、传闻、信件、百工**。玄镜是无意识、无人格、不对话、不会替玩家做决定的古镜器物，也不直接用于战斗；它提供映照、推演和记忆等有限功能，不占主界面的常驻按钮。世界地图、地点内景和功能面板分层进入，返回操作逐层退出。

整体视觉遵守水墨淡彩、纸本留白与横屏安全区规范。人物档案和 NPC 简档使用局外立绘；人物外观由模块化部件组合，战斗人形则采用无五官的彩色皮影戏质感与 Spine 动作，不等同于局外角色立绘。当前外观素材和锚点仍按专项规范持续验收。

环境图默认规格为 **1672×941、横屏 16:9**，采用水墨山水与工笔建筑的淡彩纸本风格，以纸白、墨黑、青灰、墨绿和暖米色为主，少量赭石或淡金点缀；界面按实际 HUD 留出安全区。静室修行分页、角色外观、战斗素材和地图地物均有独立专题规格，具体操作与素材验收不在本总览内重复定义。
