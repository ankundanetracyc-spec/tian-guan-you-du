# UI视觉规范

## 主界面 CanvasLayer 层级（现行）

主场景按 CanvasLayer 分层，CanvasLayer 顺序优先于面板内部的 `z_index`。不要依赖全屏面板的高 `z_index` 压过或让出其他画布层；新增主界面面板时，应先归入下表对应层，再设置同层内部的局部顺序。

| CanvasLayer | layer | 内容与职责 |
|---|---:|---|
| `MapLayer` | 0 | 世界地图场景本体；未打开地图时隐藏。 |
| 地图内 `MapOverlayLayer` | 5 | 地图标题、节点标记、说明侧栏和地图操作，仅随地图场景显示。 |
| `SceneLayer` | 10 | 地点、宗门、青溪里场景背景与场景交互；进入节点时隐藏世界地图，地点场景在 HUD 下方。 |
| `HUDLayer` | 20 | 常驻角色栏、主操作栏、时辰信息与任务入口；进入地点内景时仍显示，不得被场景底图或其局部 z 值覆盖。 |
| `CanvasLayer` | 30 | 角色详情、行囊、修炼、宗门功能、任务等可交互功能面板。 |
| `DialogueLayer` | 40 | 剧情对话与旁白，显示在功能面板及 HUD 之上。 |
| `TestingOverlay` | 100 | 仅测试入口和调试控件。 |

进入地点节点只隐藏世界地图并显示对应地点场景；不得因此隐藏常驻 HUD。地点场景需要遮挡背景时，应将遮罩留在 `SceneLayer`，让 HUD 及其按钮处于更高 CanvasLayer。若全屏体验确实需要临时隐藏 HUD，必须由该流程明确管理显示与恢复，不能依赖遮罩、节点树顺序或高 `z_index` 的偶然效果。

## 常驻时间与人物状态（2026-10-11 用户要求）

时间签末端提供「切换」按钮，在昭明历与入世年数之间切换；精确纪年基准以[纪年现行案](plans/游戏历法与纪年显示.md)为准。底部入口按角色、行囊、修行、境界、百工、见闻、信件、世界排序。展开／收起使用直径 60 的浅纸圆框，固定在右下，只显示 ▶／◀ 三角符号，不显示文字；功能说明保留在悬停提示，隐藏入口时圆框仍保留。

时间与左下角生命／行旅体力栏统一为浅暖宣纸、深墨常规楷体。按最新参考，时间主栏采用左上角细边切角长签，单行显示年月日与小时，天气等信息以辅行保留；人物状态采用姓名／境界首行、两组「数值在上、通长墨条在下」，不再使用首版印记及短条横排。淡墨细边与短角笔提供艺术感，不增加泛光、闪烁、外阴影或花哨装饰。当前值／上限放在进度条外并右对齐，空条也须清楚显示数值。共用 `WorldHudStyle` 和 `WorldHudFrame`，后续相似常驻控件优先复用；现行尺寸与素材见[实施记录](美术规范/常驻时间与状态栏_20261011/README.md)。

## 常驻任务栏（2026-10-11 用户修订）

右侧任务追踪栏采用整齐矩形浅宣纸面、1 像素灰褐细边，不使用撕纸、毛边、锯齿轮廓、泛光或阴影。复用常驻 HUD 字体与墨色；纸纹仅采样素材内部，由控件绘制完整直边。面板宽 336，右侧留 52；内边距横向 16、纵向 14，高度随内容变化。

每项任务依次显示来源与状态（14／13 号）、标题（20 号）、目标正文（16 号，最多两行，超出省略）；两项之间用淡墨细线及 12 间距分隔。完整正文保留在悬停提示中，双击仍打开对应任务详情。追踪选择、任务顺序与最多两项的规则沿用现有逻辑。

收起入口为 30×44 的整齐浅纸细框，位于面板右侧并垂直居中，只显示 ▶／◀。收起后固定保留该入口，距屏幕右缘 14，避免原有贴屏细长条。

## 已验证场景与控件复用（现行）

青溪里是序章引入内容，不是一次性界面。其角色列表、任务栏、全屏地点场景和行动控件，都是后续玩法可复用的公共原型；后续优先复用相同的场景结构、控件、脚本与数据接口，用配置表达地点、身份和行动差异，不为相似功能复制一套新 UI。只有既有控件确实无法满足功能或可用性要求时，才新增控件；需在对应主案说明原因，并优先把可共用的实现抽成公共组件。地点交互细则见《地点模板与节点互动框架》。

### 场景行动入口排布

地点内景与峰内功能默认直接叠加在场景上，不额外套用大面积深色面板；标题、简短说明采用清楚的文字层级，公共行动控件使用纸面竖签。若背景局部确实影响文字或按钮可读性，应只对相应内容做克制的局部对比度处理，不以整块黑框遮盖场景。

地点/峰内行动入口统一使用一根从左缘连至右缘的自然弧形主绳，绳端高于中部、平顺下垂且不在中间打结；竖向签牌从左到右按阅读顺序挂在绳上，整体落在屏幕中央可点击安全区。签牌响应附近的鼠标横向移动，围绕上端挂点产生适度摆动并以弹簧阻尼回稳；签牌底部的小撮红绳穗另有独立、稍滞后的摆动和阻尼回稳。不得让物理摆动遮蔽文字、改变点击目标或把签牌甩入边缘 HUD。该悬绳菜单用于地点/峰内行动入口，不替代锚定在地标上的总览热点标签。

签牌数量按可见行动配置，通常保持 1～4 项；超过 4 项按功能分组或拆为下一层页面，避免挤在一起。布局变化不得另造近似控件；新地点优先沿用青溪里 `SceneActionButton`、`SceneActionRope` 及红绳穗脚本。

## 暗色界面

暗色背景必须配亮色文字，不要靠描边硬救。

推荐：

- 主文字：`#F4F0DF`、`#FFFFFF`、`#EAF7F2`
- 次级文字：`#C9D8D2`、`#D8D0B8`
- 强调文字：`#8FE5D6`、`#F1D77A`

避免：

- 深色背景配黑字、深灰字、深棕字
- 低对比度文字
- 只靠描边补可读性

最低原则：

`背景越暗，文字越亮。`

## 世界场景背景插画（现行）

世界地图、区域、宗门与地点的环境背景统一采用**中国传统水墨山水与工笔建筑相结合的淡彩纸本风格**。画面应保留可辨的宣纸纤维、墨色浓淡和干湿笔触、山石皴染、云气渲染与有意留白；以纸白、墨黑、青灰和墨绿为主，少量赭石或淡金只作克制点色。这里的“水墨淡彩”不等于黑白单色：须控制整体明暗反差，避免大面积纯墨黑与高亮纸白紧邻、密集黑白斑驳或硬边强烈跳变；应以青灰、灰绿、暖米色及浅赭等柔和中间调形成连续色阶，让墨色作为结构点缀。画面观感须柔和舒适、不刺眼，同时保持建筑轮廓与环境层次清晰可辨；不做照片、3D 渲染或电影概念图质感。

项目环境背景默认规格为 **1672×941 像素、横屏 16:9**。新场景须保持可供界面叠加的低细节留白区，前、中、远景以水墨浓淡建立层次；不同地点靠功能与空间布局区分，不靠文字标签。除非对应策划案明确要求，画面不得生成可读文字、书法、匾额字、UI、边框或水印。

### 场景标签与界面安全区

世界、区域、宗门及地点总览图必须按实际游戏界面预留可操作安全区：节点标签、人数徽标及其对应的关键地标不得贴屏幕边缘，也不得落入左侧名单/信息栏、顶部标题与返回按钮、右侧任务栏或底部角色 HUD 覆盖范围。以 1672×941 设计画布为基准，默认将交互标签及其主要地标安排在画面中部约 **横向 18%–82%、纵向 16%–80%** 的区域；如果某界面有更大的动态面板，应进一步向内收。生成前须先核对节点位置与当前 UI 覆盖范围，生成后逐个验看标签中心、标签外框和人数徽标的点击余量；禁止只把标签本身移开、却仍压在被 UI 遮挡的地标上。

环境背景一律不画人物（包括远景剪影、行人、角色或人形雕像）。需要表达生活功能时，使用空置的桌凳、器具、建筑布局、生活痕迹和环境物件传达，不以人物填充画面。

后续生成新环境素材时，以本规范和对应现行场景策划为准，并使用已确认的水墨淡彩项目素材作为风格参照；不得引用已废止的家族/庄园设计，也不得无说明地切回写实、3D 或高饱和数字概念图风格。青溪里仍是序章接引之地，村景保持朴素日常，不以家族宅院或经营庄园作为视觉主体。
