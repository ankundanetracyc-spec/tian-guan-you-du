# 最新普通地图自然地物 · 2026-10-09

最新布局已由十八族四十款的种子模板布局替换，本目录素材继续作为全库的一部分；下文 85 山体、898 树格与旧预览仅为此前实装记录。当前目录与使用方法见 `../natural_families_20261009/README.md` 及 `docs/plans/百川模板随机地物生成_20261009.md`。

本目录为重新绘制的二十张自然景物候选素材，以及一张配套暖米黄纸纹地块。此前整片大山水方向已被用户否定，本批以普通地图局部地物的类型和相对尺度为准。

- `01`–`06`：单峰、圆丘、双峰、紧凑三峰、矮脊、淡远岫。
- `07`–`12`：圆冠乔木、疏冠乔木、直松、垂柳、白杨、竹丛。
- `13`–`15`：苔石、层岩坡、碎石浅岭。
- `16`–`20`：柳岸、浅溪、疏荷、清泉、石岸。
- `21_warm_paper_tile.png`：配套地表，底色目标约 `#E5D5BC`，不计入二十张景物。

## 查看与使用

`contact_sheet.png` 为暖米黄底上的素材展示，各框自适应缩放，不代表场景实装画面或实际相对大小。建议占格与原图尺寸见 `asset_manifest.json`。

本批已实装到原 `BaiChuanDualGridTerrainPrototype_v1.tscn`：85 处小型山体、898 个单树/竹丛格、40 处坡石和局部水景。原 5,745 个水格全部改为普通陆地，旧水域显示层清空。布局见 `installed_scene_layout.json`；`installed_start_region_preview.png` 与 `installed_northwest_preview.png` 只按保存的地物位置合成，省略绿染、遗迹、节点和迷雾，不是引擎截图。本次未运行游戏或测试。

景物 PNG 使用内置 imagegen 独立生成并原样复制，保留透明通道；无程序重绘、抠图、改色。预览图只对副本排版、缩放，正式源图不变。

完整最新生成提示见 `prompts_revised.json`；`prompts.json` 是已中断作废的大山方向记录。生成来源见 `generation_sources.json`。

07、08 选用文件名含 `_upright_v2` 的直干修订，追加提示与来源见 `tree_revisions.json`。这两件初稿已移出正式素材目录，保存在研究临时目录中，不计入二十张选用素材。

本机原游戏解出图只供研究类型、轮廓复杂度和大小层次，未直接作为正式素材。采用用户提供的暖纸色参考，山形、树冠等重新设计。
