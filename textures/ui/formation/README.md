# 阵法界面素材

本目录承载百工「阵法」页的可复用图像资源。整体沿用现有功法与信息面板的浅宣纸、水墨、古铜与翡翠高亮语言；背景优先复用 `res://textures/ui/infopanel_fullscreen_bg_v1.png` 或 `res://textures/ui/realm_yunxi_paper_v3.png`，避免重复制造不一致的全屏底图。

## 图集

### `formation_logic_atlas_v1.png`

- 尺寸：1448 × 1086；四列三行，单元格按等距分割。
- 用途：云息期阵道造诣页的元件小图标；作为图集切片使用，不直接整张显示。
- 从左到右、从上到下：感应枢、鉴脉门、候枢、三候枢、定数枢、抑脉门、分脉枢、合脉枢、节律枢、阵源、护持阵器、震雷阵器。

### `formation_action_atlas_v1.png`

- 尺寸：2172 × 724；三格横向等宽图集。
- 用途：阵法页右下角的固定操作入口。
- 从左到右：布阵、阵图蓝图、行囊阵盘。

## 使用约定

- 图标只承担识别；名称、解锁状态、格位、复杂度与功能均由 UI 文本和数据驱动。
- 逻辑元件详情与标准接线预览留待悬停交互阶段制作，不把说明文字烘焙进图像。
- 选中态采用翡翠色外发光；未解锁态由代码灰化，不另生成一套重复图标。
