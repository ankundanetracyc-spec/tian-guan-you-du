# 世界地图势力节点素材（最新版）

**状态：当前使用版本，更新于 2026-09-28。**

本清单中的节点 PNG 是当前最新素材。一级节点占 3×3 格，二级节点占 2×2 格；均为 2048×2048 透明画布，地面接边使用纯白，画风统一为淡彩水墨地图插画。

一级节点素材放在本目录，二级节点素材放在 `second_level/`。旧版 `*_node_v1.png`、`*_v2_map_tone.png`、`*_node_v1_map_tone.png` 保留作历史稿，不作为当前节点图引用。现行名录以策划案中确认的四个一级势力、十二个二级势力为准。
