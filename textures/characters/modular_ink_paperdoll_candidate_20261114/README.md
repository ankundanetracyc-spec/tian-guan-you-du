# 水墨局内人物拆换样稿

这是一套供审阅的局内人物素材候选，参考用户提供的白衣青边剑修形象，按三类外观槽整理：

- **发型**：后发与前发组合为一个可替换发型。
- **眼睛**：独立替换眼部线稿；鼻嘴保留在身体组。
- **身体／衣装**：脸部底色、衣身、双袖、双手、裤靴作为一套身体外观，不单独提供手臂、袖子或腿的换装槽。

`poses/` 中每个动作状态是一张完整透明角色图，共待机、移动、闪避、防御、受击、失衡、斩击、突刺八张。本轮根据用户对手部和姿势的反馈重新生成，属于待审阅候选；原始动作图保留在 `mods/appearance/turn_based_cutout_actions_20261114/actions/`。当前三槽拆分预览仍是旧待机样稿，尚未适配这次重绘，也没有接入游戏运行时。

斩击弧光和突刺气流分别放在 `effects/07_slash_arc.png`、`effects/08_thrust_trail.png`，人物姿势图不包含这两项特效。特效与重绘人物的叠放位置尚待人工调整和确认。
