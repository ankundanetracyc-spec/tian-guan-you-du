## 绑定

- 43 根骨骼、10 个绘制槽、6 个 IK 约束、4 个脚掌朝向约束。
- 四肢分别使用完整连续图，沿弯曲骨段的弧长渐变赋权，腿根加强与胸／髋的共同权重；肩胯由身体自然毛边覆盖。后肢包含大腿、小腿、跗部、掌部。
- 轮廓网格加关节内部布点，并做局部三角形调整；不是整块矩形等距细分。各独立网格为 27–275 顶点、39–396 三角形，低于当前渲染器容量。
- 上吻、下颌、口腔分别绘制；下颌在后侧铰接，嘴角共同绑定头部、下颌及嘴角骨，提供连续开合。
- 身体绑定胸、脊柱中段、髋、颈及呼吸骨；尾巴三段，耳朵分别控制。脚掌目标位于根控制下，身体呼吸不直接搬动目标。
- 死亡在 0.78 秒换入专用倒地附件，并隐藏常规附件；倒地附件仍是加权网格，由五个局部骨与整体控制骨继续完成落地、回弹和静止。此做法参考塔 2 双尾鼠的骨骼过渡及死亡换件。

## 动作

| 运行名称 | 时长 | 内容 |
| --- | --- | --- |
| `idle` | 2.40 秒 | 胸腹呼吸、头耳轻动、三段尾摆，脚掌落点固定 |
| `attack` | 0.95 秒 | 蓄力、前脚抬起前伸、身体扑咬、下颌连续张合、收势 |
| `hurt` | 0.65 秒 | 身体后缩、头颈与耳尾响应、恢复站姿 |
| `death` | 1.65 秒 | 支撑下沉、低头、换入侧卧附件、落地回弹、末帧保持 |

百科保持原三列布局：目录、外观及四个动作、属性资料。攻击／受击结束回待机，死亡停末帧。百科与战斗均由 `BattlePaperDoll` 的两条共享路径引用 v6。
