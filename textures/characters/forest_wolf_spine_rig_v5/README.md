## 绑定

- 29 根骨骼、7 个绘制槽、6 个 IK 约束；4 条连续加权腿网格、躯干、尾部以及头部槽。
- 每条完整腿网格在关节附近渐变赋权，上腿根部同时绑定躯干；躯干毛发覆盖肩胯连接。前腿腕部与后腿跗部、掌部使用独立支点。近远腿分别控制和分层。
- 躯干在 hips／torso 之间过渡；尾巴分三段。每个附件最多 289 顶点、512 三角形，低于当前引擎附件容量。
- 完整闭口／张口／闭眼头部通过 Spine 附件轨道切换；无独立 jaw 骨骼。身体、四肢和尾部的运动仍由骨骼及加权网格驱动，不是整只角色的序列帧。

## 动作和运行产物

- `idle` 1.6 秒，站立呼吸与摆尾，脚部控制点保持。
- `attack` 0.82 秒，蓄力、扑咬、前腿前伸与回位；0.18–0.55 秒使用张口头。
- `hurt` 0.5 秒，身体回缩、头部回弹。
- `death` 1.4 秒，身体下沉、前腿向前沿地面伸出、后腿收拢；0.6 秒闭眼，头颈继续下伏，结束保持末帧。每个动作显式恢复姿势与 IK 混合，死亡后可以重播待机。
