# 林地凶狼 v3：独立部件绑定

替代 v2 整张图的区域权重。保留旧素材与旧资源，百科和战斗通过 `BattlePaperDoll.ForestWolfSpineResourcePath` 共用本包。

## 素材来源

- 工具：内置 `image_gen__imagegen`，透明背景，两轮生成／编辑。
- 参考：`../forest_wolf_spine_rig_v2/source/wolf_rig_master.png`。
- 最终图集：`source/wolf_parts_atlas.png`，1448×1086 RGBA。
- 提示要求：保持参考狼的炭黑毛、象牙色胸毛／脚掌与青绿云纹，细墨线游戏插画，轻俯视三分之四朝左视角。四列三行共十二个独立拆件；第一行躯干、上颌头部、下颌、尾巴，第二行近前腿上段／下段与脚掌、远前腿上段／下段与脚掌，第三行近后腿上段／下段与脚掌、远后腿上段／下段与脚掌。完整绘制关节遮挡处和圆形毛发接缝；无背景、文字、地面、阴影或额外肢体。
- 第二轮编辑要求：保持同一角色与部件顺序，拉开部件间距，头部移除下颌并独立绘制下颌，透明边缘干净。生成结果未完全留足格间空白，因此运行网格使用独立 UV 多边形边界避开相邻部件，不在代码中重绘位图。

## 绑定与动作

- Spine 3.8 JSON／atlas，26 根骨骼、12 个独立网格、4 组双骨 IK。
- 远腿绘制在身体后方，近腿在前方；上下腿独立支点，脚掌保持朝向，膝踝附近使用渐变权重。头部与下颌独立，尾部三段渐变权重；四肢不共享整图网格。
- `idle` 1.6 秒，呼吸与摆尾循环、四足落点保持。
- `attack` 0.82 秒，蓄力、前扑、前脚伸出、张口与恢复。
- `hurt` 0.5 秒，身体后缩与头部回弹。
- `death` 1.4 秒，身体下沉，站立 IK 在 0.25–0.65 秒渐退，再由关键帧将四肢向前收折，尾部侧放，结束后静止。
- 各动作显式写入姿势恢复轨道；死亡切回待机时重置身体位移、关节角度和 IK 混合。
- 每个附件顶点数小于 1024、索引数不超过 3072，满足项目当前原生渲染器容量。
