# 林地凶狼 v4：下颌、腿根和跗关节修订

当前由战斗与百科共同引用。v3 保留为历史版本；本包沿用 v3 生成的十二部件图集，源位图未重绘。原始生成工具、提示要求和参考图见 [v3 记录](../forest_wolf_spine_rig_v3/README.md)。

- [Spine 官方 Raptor 示例](https://en.esotericsoftware.com/spine-examples-raptor)：腿根同时绑定 hips／torso，脚部单独控制，多个 IK 按顺序求解；下颌支点附近同时赋予 head 权重。此项目为机制参考，本包未复制其角色、美术或骨骼文件。
- [官方四足动物绑定讨论](https://en.esotericsoftware.com/forum/d/6763-rigging)：躯干控制与脚部控制分离。

## 当前结构

- Spine 3.8；30 根骨骼、12 个独立网格、6 组 IK 约束。
- 前腿：肩—肘—腕，脚掌维持独立朝向；落脚目标位于腕部，不再位于趾扇中心。脚掌宽高独立于长腿段，避免细长、垂直的趾扇。
- 后腿：髋—膝—跗关节—掌部，膝朝前、跗关节朝后；上部双骨 IK 求解到跗部，单骨 IK 控制跗部至落脚点。跗控制点随落脚目标移动，躯干上下移动时腿链独立弯曲。
- 腿根顶部与 torso／hips 渐变赋权；近侧上腿放在身体网格之前绘制，身体毛发覆盖连接处，下腿仍在身体前方。
- 下颌缩短并后收，闭合角度为 -18°；头部覆盖上方牙列，下颌末端在鼻尖之后。铰链附近的顶点同时受 head 与 jaw 控制，降低张口时脱节感。
- 关节中性形状通过 UV 网格与绑定坐标适配；位图保持原样。网格每个附件少于 1024 顶点、不超过 3072 索引。

## 动作与导出

`idle` 1.6 秒、`attack` 0.82 秒、`hurt` 0.5 秒、`death` 1.4 秒。死亡渐退全部 IK，再用各腿段关键帧收折；后腿跗段独立设角度。每个动作写入恢复轨道，防止死亡姿势残留。
