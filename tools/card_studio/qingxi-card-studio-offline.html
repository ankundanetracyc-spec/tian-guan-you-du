PROJECT REFERENCE

规则索引

这里把工具实际执行的约束集中显示，便于在手机上制作时随时回看。

01

三资源费用

精力负责常规动作，每回合增加 3、上限通常为 6；法力回合开始恢复、回合结束清零；灵识是持续实体的占用容量。

energy_cost · mana_cost · spirit_occupy
02

卡牌牌头

每张牌都应写明类型、关键词、精力、法力、灵识占用、目标与射程。应对和消耗属于关键词，不是牌型或资源。

ActiveSkillData
03

秘籍层级

学会永久加成、辅修被动、纳气加成、化法改写和习得卡牌分开填写，不把技能库收益伪装成属性收益。

GongfaResource · GongfaChapterConfig
04

化法边界

加入只填结果牌与数量；替换必须写原基础牌、结果牌和数量，且原牌应存在于当前路线的基础技能库。

ADD · REPLACE
05

词典权威

正式设计仍以 docs/ 下的主文档、卡牌词典图谱和秘籍词典图谱为准。工具是编辑和推演助手，不反向覆盖主稿。

docs/README.md · docs/策划案摘要/README.md
06

导出流程

建议先导出 JSON 留档，再把确认后的内容同步到卡牌词典、秘籍图谱/文字稿和 resources/*.tres，并运行项目校验。

JSON · Markdown · Godot .tres draft
