# 青溪问道 · 卡牌与秘籍工坊

这是项目内的手机浏览器编辑器和小型推演沙盘，不会直接覆盖项目原有资源。

## 已包含

- 预置 `resources/activeskills/` 下当前收录的主动技能。
- 预置 `resources/gongfa/` 下当前收录的秘籍及卷章。
- 预置 `resources/realm/` 下现有凡人、云息一层至七层境界档案。
- 卡牌编辑、费用/目标/关键词/状态/公式校验和牌面预览。
- 秘籍总览、卷章、习得、纳气和化法编辑。
- 回合、抽牌、精力/法力/灵识、伤害、护持、状态和秘籍门槛推演。
- JSON 工作包、卡牌 JSON、秘籍 JSON、秘籍文字稿以及 Godot `.tres` 草稿导出。
- 浏览器本地自动保存；可以安装到手机主屏幕，电脑关机时仍可使用已缓存的工具和本机草稿。
- 提供单文件离线版 `qingxi-card-studio-offline.html`，适合复制到手机后直接打开，不依赖电脑持续开机。
- 局域网同步：电脑开机时，手机可在“局域网同步”面板合并本地卡牌、秘籍和测试设置；正式项目资源仍然只读。

## 手机打开

在项目根目录启动一个静态文件服务，然后用手机访问电脑的局域网地址：

```text
node tools/card_studio/serve.mjs --host 0.0.0.0 --port 8765
```

电脑浏览器打开 `http://127.0.0.1:8765/`，手机打开 `http://电脑局域网IP:8765/`。如需离线安装，先在手机浏览器访问一次，再使用添加到主屏幕。首次访问并缓存成功后，即使电脑关机，手机仍可打开已安装的工具并继续使用本地数据。

电脑重新开机且双方处于同一局域网时，在工具顶部点击“局域网同步”，确认同步地址后点击“合并同步”。同步服务会把副本保存到 `tools/card_studio/.data/sync-workspace.json`；该目录已加入忽略列表，不会进入项目正式资源。若电脑 IP 变化，可在同步面板手动修改地址。

同步是局域网内的本地副本交换，不依赖云服务；电脑关机期间无法同步，但不影响手机离线编辑和推演。同步接口默认不做账号认证，只建议在可信的家庭/个人局域网使用，不要把端口暴露到公网。

如果手机浏览器无法在局域网地址安装离线应用，可在项目根目录运行：

```text
node tools/card_studio/build_offline.mjs
```

然后把生成的 `tools/card_studio/qingxi-card-studio-offline.html` 复制到手机并用浏览器打开。单文件版在电脑关机时可正常编辑和推演；电脑开机后，在同步面板填写 `http://电脑局域网IP:8765` 即可同步。

也可以直接打开 `index.html` 使用编辑和推演功能；直接打开文件时浏览器不会启用 Service Worker，但本地保存和导出仍可用。

## 更新现有资源目录

项目新增或修改卡牌、秘籍、境界资源后，在项目根目录运行：

```text
node tools/card_studio/generate_catalog.mjs
```

脚本会重新生成 `project-catalog.js`。工具中的项目现有内容只读入本地草稿库，导出后仍应按项目词典流程同步到正式图谱、文字稿和 `.tres`。
