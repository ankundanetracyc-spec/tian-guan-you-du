# 阵盘几何与接线检查

从项目根目录运行：

```powershell
dotnet run --project tools/formation_grid_checks/FormationGridChecks.csproj
```

验证项目直接链接 `FormationGridModel`、`FormationLogicCircuit` 与 `FormationGridSimulation`，使用 .NET 8；不引用 Godot、战斗解释器、卡牌资源或正式存档。

检查范围：4×4全格可用、真实足迹与旋转端口、四邻自适应掩码、异类及错误侧隔离、直接相邻端口、信号隐性分支与四向交叉拒绝、移动与删除后的重算、原子拒绝、断点校验、旧阵眼草图迁移、严格JSON结构恢复，以及350步确定性编辑的往返一致性。

`TryPlace*` 允许保留悬空草图；`GetIssues()` 给出未完成原因，`IsCircuitConnected` 只有完整合法阵图才为真。JSON恢复接受这类结构合法的草图，拒绝越界、重叠、非法类型、重复身份或线格及非法分支，并会略过旧草图中的固定阵眼；失败不暴露半份模型。

这些检查不代表阵图已经授予真实部件、装配进战斗或执行护持效果。

基础逻辑检查另外覆盖：输入／来源／幅值筛选不误推进计数，计数器“数满再发／先发一次”两种相位（含N=1），同次发生重发与内容改写拒绝，嵌套长短分支和多输入合流去重，非法反馈与缺口连接拒绝，参数跨移动／旋转／新旧JSON保存，坏参数原子拒绝，以及实例按实际旋转端口编译。分合配对实例保留一条直接路径和一条两线格路径，不在编译时提前合并平行连接；两路汇回仅产生一次控制请求。

计数合并的迁移检查覆盖旧`Divider`／`Rhythm`的稳定编号与四向端口、全部支持间隔的旧新相位一致性、旧无参N=2和显式间隔、实例ID与转向保留、统一写回`Counter`及可选`first_immediate`、重复读取不再改变，以及错误模式字段原子拒绝。旧别名只为读取兼容，不再作为另一种新物品。

试运行只验证信号抵达，不扣实际阵能、不发护盾、不改变草图或正式战斗状态。
