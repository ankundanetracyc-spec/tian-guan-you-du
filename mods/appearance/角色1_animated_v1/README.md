# 角色1 动画序列帧 生成规范

## 角色锚点（每个 prompt 必须复述）
- 水墨国风插画，古风男修全身像
- 面部无五官
- 黑色长发束成高发髻，青绿色发带系扎并自然垂落
- 浅米白色交领长袍，衣缘/袖口/腰带为青绿色镶边，腰间系青绿色腰带
- 右手握一卷带流苏的竹制卷轴（攻击施法时为左手出指、右手持卷轴）
- 黑面白底布鞋
- 纯白色背景，无阴影、无投影、无文字、无任何其他元素，全身完整入画，线条干净

## 序列规格
- 四种序列：idle(待机) / attack(攻击) / hurt(受击) / death_kneel(死亡跪地)
- 每种 64 帧，逐帧 PNG，720x960，透明底（白底生成 → 后处理去背）
- 锚点对齐：内容包围盒底边中点 → (360, 940)，全程同一条地面线
- 帧命名：001.png ~ 064.png
- 播放：64fps，1 秒/序列
