# 男女水墨立绘九部位基础套 v3

这是本轮男女各一套的可显隐基础件，均为 1024×1536 真透明 RGBA PNG、共同左上原点、零位移。九件在 `male/` 和 `female/`：前发、后发、眉毛、眼睛、鼻子、嘴巴、脸型、衣服、面饰。当前面饰为空槽。开始菜单的“水墨立绘九部位测试”读取本包。

## 本轮修正

- 脸型只含无五官的头皮、脸、双耳和颈部；内部皮肤取自同风格的无五官生成稿，但头形、轮廓和坐标沿用本轮光头参考，不使用生成稿偏移的外轮廓和光晕。
- 原成稿中正面可见的头顶、鬓发、肩侧垂发和胸前发束统一归前发。后发只承接被头脸和衣服遮挡的外侧发束；不再用胸前是否超出光头参考轮廓判断前后。
- 衣服从用户本轮光头参考中取无发束的整袍，避免发丝粘在领口。前发压在衣服上层。
- 取消为了追求母图逐像素复现而把残差强塞进错误部位的回填步骤。

从后向前顺序见 [portrait_manifest.json](portrait_manifest.json)。本套独立锚点和换款限制见 [portrait_rig_v3.json](rig/portrait_rig_v3.json)；旧 `2026-10-02` 固定坐标不用于本套。

## 图像生成请求

使用内置图像生成编辑工具分别制作男女无五官皮肤内部纹理。请求的共同约束为：保持原皮肤的浅暖象牙桃色与水墨纹理；去掉残留发丝和五官痕迹；不添加服装、妆容、文字、背景。生成结果只作为脸型内部纹理来源，后续保留原光头参考的轮廓与五官锚点。
