# 新绘男女前后发

当前为男女各一组新发型，共四张独立生成的透明发层。内置 imagegen 生成；原始画稿与完整提示词保存在 `source/`。男性已重画为严格正视中分，女性中分柔顺，统一炭黑淡彩水墨。男女前发均已去掉刻意绕耳的凹口，后发保持完整底画；不绘制耳形孔洞，耳部显隐交给图层自然覆盖。

- 前发：前侧颅顶、发际、贴脸发束与胸前发束。
- 后发：完整后脑、颈后、肩后披发，位于脸型和衣服下方。
- 画布：1024×1536；九件原点一致，运行时零偏移。
- 新绘源图仅整层等比缩放和平移，无逐束拉伸；试装数值见 `registration.json`。当前为视觉配准候选，未宣称三点控制架认证。
- 眉、眼、鼻、嘴、脸型、衣服、空面饰沿用本轮自己的七部位。新发型不借用鬼谷八荒美术素材。
- 游戏开始菜单“水墨立绘九部位测试”读取此包。视觉候选未经用户确认；前后发各五款的扩款目标尚未完成。
