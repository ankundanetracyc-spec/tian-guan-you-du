## 本轮处理

- 眼球、睫毛和必要的眼缘保留；清除眼层的皮肤底片和鬓发碎线，眼缘晕染柔化为连续 Alpha。男性上眼睑高光改为两侧同尺寸、同强度的淡笔触。清掉眉尾、眼角混入前发的笔触。
- 前发按正视遮挡关系归属：凡正视可见且位于头脸或身体前侧的发束，包括发顶、发际、鬓角、耳前发丝及肩前/胸前/衣襟前的完整长发束，均保留在前发层；不得沿头部轮廓、肩线或衣服边缘截短。
- 后发包含后脑、颈后及肩后的披发。基于本轮完整底画恢复母版的肩后发体并补齐遮挡区；不挖前发轮廓洞。只有明确处于身体后侧的发量才归后发层。后续 v4/v5 的前发造型未采用。
- 男性前发本轮只修正头顶中分与额前发际的歪斜；同原点、同尺寸，原有胸前长发束与完整末端保留。修正不替换脸部、衣服或后发。
- 本次男性前发生成提示词与局部合成边界记录在 `source/male_front_hair_revision_prompt.md`；只更新头顶至额前区域，前发图层原透明通道与胸前长发原像素保留。
- 脸型使用自己的连续无五官底画，并匹配选定皮肤的光色，消除隐藏五官后残留的旧轮廓。完整耳形取自己的原光头图，补齐连续颈部；交领描线与边缘投影归衣服。
- 衣服遮挡区使用自己的原光头服装补画，清除旧长发。

五官、肤色和可见头发以用户选定母版为依据。《鬼谷八荒》仅提供部件组织和透明度经验，本包不含其美术像素。制作使用用户已授权的原位像素清理，未重新生成整张脸，也没有本轮新的图像生成提示词。

## 定位与验证

权威 rig 仍是 `../selected_ink_portrait_rig_20261003_v1/rig/portrait_rig.json`。性别兼容族、固定五官点、颈领控制架及导出原点不变。四个发梢款式参考点已按实际长发重新测量；这些点不参与强制配准。

`asset_verification.json` 核对画布、透明、眼周不透明肤色、连续后发、完整颈部与实际重组。两眼位、唇心、鼻尖附近的母版像素采样差为零；全幅存在清边与补画差异，不宣称全图逐像素一致。`game_verification.json` 保存实际入口、两性九项显隐、还原和锚点显示的实测与 PNG 哈希。工程检查不代替视觉验收。

重建：`tools/build_selected_ink_portrait_clean.py`。素材检查：`tools/verify_selected_ink_portrait_clean.py`。游戏检查：`tools/verify_selected_ink_portrait_clean_ui.gd`。

当前仍是每性别各一套，面饰默认空；每性别前后发各五款、其他部位各三款的扩款尚未开始。本包仅用于测试入口，不替换正式角色或存档。正式规范见 `docs/美术规范/本轮男女立绘锚点规范_20261003.md`。
