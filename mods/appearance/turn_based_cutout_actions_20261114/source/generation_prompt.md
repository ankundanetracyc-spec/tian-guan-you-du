# 生成记录

首张透明动作图集提供待机、移动、闪避、防御、受击、失衡、斩击、突刺八种整身姿态；抽出前六种作为状态原画。为避免斩击与突刺拆分时的邻格串入，之后单独生成斩击、突刺双格补图，并以补图替换这两个状态。原始两张图分别保存在本目录。

角色参考项目白衣青绿剑修的高束深色长发、青色发带、交领白袍、宽腰封与双指剑诀。画面采用中式手绘水墨与淡彩，炭墨粗线、干笔颗粒、纸上颜料质感、青绿少量点染、透明底。动作特效只出现在斩击和突刺姿势内。

源图前六个姿势直接拆分；斩击、突刺按统一人物高度缩放到 768×512 透明画布。最终图集由八张动作单图排成四列两行。SHA-256、顺序和路径见 asset_manifest.json。
